The Script Engine

When the Edit script button is pressed, when deriving a Custom agent, you need to choose the required scripting engine either Yes to use JavaScript or No to use VBScript.

Then Adroit Script Editor is launched and the following applicable script components are added by default to this derived custom agent’s script:

  • The slots of this derived agent are defined as constants, starting from 0 in the order in which they have been created.
  • Script procedures are created for this derived Custom agent, which can either be left empty– to not provide a script engine for the derived custom agent or they can be coded to provide any additional functionality for this agent.

Note: An event is logged if a script is executed that contains compilation errors, preventing it from being run. Since this event can FLOOD the event log PLEASE ensure that the event log is closely monitored and that any buggy scripts are either fixed or disabled ASAP!

The Custom agent script code uses a Custom object to communicate with the Agent Server, via the following methods:

AgentName

GetSlot

LogEvent

SetStatus

Sound

CDateTime

GetTag

SetSlot

SetTag

 

IMPORTANT: You cannot pass a tag (string) as the parameter to the GetSlot function, you must pass the slot index of the Custom agent!

Note: To gain help concerning the use of the Adroit Script Editor, press F1 when this editor is selected.
