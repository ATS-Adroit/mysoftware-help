Manually Polling OID Values

If necessary, you can immediately retrieve the values of all the OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.s in the list and sets their corresponding tags to the new values. For instance, this could be set from a button on a mimic.

Note: A scan point is consumed for every unique OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. that is retrieved (polled).

Set the pollAllNow slot to 1.

Note1: The value of any OID that does NOT have an associated Tag in this list will NOT be returned.

Note2: This polling occurs immediately, over and above the normal poll cycle.
