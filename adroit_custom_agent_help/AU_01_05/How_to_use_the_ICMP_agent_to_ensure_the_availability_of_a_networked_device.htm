How to use the ICMP agent to ensure the availability of a networked device

The ICMP or PING agent uses the Internet Control Message Protocol to determine the existence of a remote device on the network.

By continuously polling the specified remote IP address, this agent is therefore able to identify potential network problems as they occur by generating alarms when errors are obtained when attempting to contact the specified remote IP address and/or when the round trip timeThe time to send an ICMP message to the network device and receive a reply. exceeds specified High and High-high times.

Things you need to know or do before you can assess the availability of a networked device:

  • Ensure that the network supports the Internet Control Message Protocol.
  • Ensure that you know the IP address of the required device and that this IP address does not change.
  • ONLY IP addresses can be specified, so if you need to contact a web address, you need to resolve this to an IP address first.

If necessary, locate the required agent, as follows:

 

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit ICMP agent dialog:

  1. Specify the IP address of the network device, in the Remote IP address edit box (STRING ipAddress slot).

Note: ONLY IP addresses can be specified, so if you need to contact a web address, you need to resolve this to an IP address first.

Tip: Ideally copy and paste this address into the edit box to ensure that it is correct.

  1. Specify how often you want to check the availability of this device on the network, in seconds, in the Poll rate (secs) edit box (INTEGER interval slot).

  2. Specify how long you want to wait, in milliseconds, to receive a response from the device before you determine that this device is unavailable in the Timeout (ms) edit box (INTEGER timeout slot).

    Note: If the specified timeout is too short then you will never get a "host unreachable" error because the network will not have the necessary time to respond.

  3. Specify how many times you want to query the availability of the network device before determining that it is unavailable in the Retry count edit box (INTEGER retries slot).
  4. Specify the time, in milliseconds, that indicates that the time to send a message to the network device and receive a reply has moved outside its acceptable range and therefore implies that corrective action must be taken as soon as possible in the Round trip time: high alarm value (ms) edit box (INTEGER hi slot).
  5. Specify the time, in milliseconds, that indicates that the time to send and receive a message and from the network device has moved further from its acceptable range and reached the second alarm limit. This implies that the first warning has been ignored and that urgent and immediate corrective action is now required in the Round trip time: high-high alarm value (ms) edit box (INTEGER hiHi slot).
  6. Check the Enabled checkbox to start sending ICMP messages to the specified Remote IP address.
  7. The dialog provides the following information concerning the attempts to contact the device:
  • The Round trip time (ms) edit box (INTEGER roundTripTime slot), displays the time taken, in milliseconds, to send the last ICMP message to the network device and receive a reply.

  • The Failure count edit box (INTEGER failure_Count slot), indicates the number of attempts to contact the device that failed, in other words those attempts that timed out before a response from the device was received for the specified number of retries.

    Tip: If you need to reset the failures to 0, then type in a value of 0 into this edit box.

  • The Last execution time edit box (TIME last_Execution_Time slot), specifies when the last attempt to contact the device occurred.
  1. Further mechanisms that you can use to obtain diagnostic information from this agent :
  • The status bits and their alarm types can be alarmed to alert you when the device cannot be contacted or when the round trip time exceeds the specified High and high-High times. For details, see Specific Status Bits of the ICMP Agent.
  • The STRING pingStatus slot provides a textual description of the status of the last ICMP message used to contact the device, as follows: OK from [IP Address] if it succeeded; Retries exhausted when retrying to contact the device (a timeout failure) and Host unreachable from [IP Address] if it is not possible to contact the device.
  • The BOOLEAN pingNow slot performs an immediate ping.
