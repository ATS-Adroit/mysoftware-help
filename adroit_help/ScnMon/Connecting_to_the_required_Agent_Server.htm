Connecting to the Required Agent Server

The Scanning Monitor utility provides information on the scanning (communications) configuration for a particular Agent Server, so this information can be used to manually fine-tune the scanning subsystem to achieve optimal performance. For details, see Monitoring Scanning in Adroit.

For this reason, it is necessary to specify the Agent Server whose scanning configuration is to be monitored. This can be performed as follows:

On launching, the Scanning Monitor utility can connect to its default Agent Server, this is either the Agent Server running on the same computer as the utility or a specified remote Agent Server. For details, see Launching the Scanning Monitor Utility.

Note: The name of the currently selected Agent Server and any connection-related errors are displayed within the status bar of this utility. For details, see Current Agent Server Connection Details.

Once launched, the required Agent Server can also be selected as follows:

  1. The Servers combo box, contains a list of all the Agent Servers that are detected within the current network domain/workgroup in which the local computer is a member.

To connect to a detected Agent Server:

  1. Simply click on the combo box below the Servers title (in the top right hand corner).

This will display a list of all the Agent Servers that are detected within the current network domain/workgroup, as follows: computerName.AgentServerName(ProjectName).

  1. Select the name of the required Agent Server.
  1. The Connect… button can be used to manually connect to any other Agent Servers that are not displayed in the Servers list box. For instance, any Agent Server, running in other domains/workgroups or across a network switch.

To connect to an undetected Agent Server:

  1. Click the Connect… button.

The Enter AS to connect to dialog is displayed.

  1. Type in the name of the required Agent Server and the network name of the computer upon which it is running in the following format: computerName.AgentServerName
  2. Click the OK button.

Note: Once an Agent Server has been connected to, reselecting the same Agent Server again will refresh the list of devices that have been used to scan one or more tags in the WGP file currently opened on this Agent Server. For details, see Devices within Selected Agent Server Database.
