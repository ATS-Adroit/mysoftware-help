Scheduling and Triggering Scripts

This enables the remote execution of the main subroutine by the Script agent.

The following combinations of triggering and scheduling can be configured:

  1. Triggering only: This is used when the execution of the script is only required after a particular condition, defined within the script, has been met by one or more of the tags within Adroit.

This requires checking Run when one of the following tags change and then configuring one or more triggers.

  1. Scheduling only: This is used when the execution of the script is required at a set time period, which is set by the user. It is also possible to synchronise the start of the scheduling at a specified time.

This requires the configuring the scheduling. Ensure that both the, only if one of the following tags change and Run when one of the following tags change options, are unchecked.

  1. Triggering and Scheduling: In this case the script is executed when its scheduled to and when a value of the one of the triggers change.

This requires configuring one or more triggers and configuring the scheduling. Only the, Run when one of the following tags change option, should be checked.

  1. Scheduling if Triggered: In this case the script is only executed when it is scheduled to, if a value of the one of the triggers also change.

This effectively applies a time deadband to the triggering, preventing a flood of triggers that would initiate multiple executions.

This requires configuring one or more triggers and configuring the scheduling. Only the, only if one of the following tags change option, should be checked.

Note: An event is logged if a script is executed that contains compilation errors, preventing it from being run. However, this event could result in the event log from being flooded, therefore ensure that the event log is closely monitored and that any buggy scripts are either fixed or disabled ASAP!
