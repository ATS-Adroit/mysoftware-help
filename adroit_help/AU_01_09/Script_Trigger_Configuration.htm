Script Triggering Configuration

In order to use triggering as an option, this requires browsing in at least one Adroit tagA fully qualified named value in Adroit (agentName.slotName)..

Each trigger has an identification number that corresponds to its position in the list of triggers.

Reordering this list will change the trigger identification numbers.

The following buttons are used to configure the triggering tags:

  1. To add a new trigger simply click the button, this opens up the Adroit agent browser and selects the required tag.
  2. To remove the selected trigger, click the button.
  3. To move the selected trigger up in the list order, click the button.
  4. To move the selected trigger down in the list order, click the button.
