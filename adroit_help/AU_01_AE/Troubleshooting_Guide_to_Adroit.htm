Troubleshooting Adroit

If you are unable to diagnose a problem yourself, create a performance log file containing the problem and mail it, along with a description of the problem, to the Adroit support desk.

Note: It is also possible to use the PerfMon agent to log the value of counters to Adroit tags etc.
