Glossary

@scan
(pronounced at-scan), which is a method of linking the value of one tag to another, by scanning the required tag value directly.
active
the monitored condition of this incident (alarm/event) is still in effect and has not yet returned to its normal operating state.
agent
an instance of an agent type, that stores data and typically provides the ability to operate or act on this data.
agent group
an agent that facilitates the logical grouping of other agents. For example, an AgentGroup agent could contain all agents related to a specific section of a plant, or all agents required for a specific report.
alarm
the process of monitoring an agent for the occurrence of a specific abnormal condition or state (alarm type).
alarm type
a named (abnormal) condition or state of an agent that is defined by which of its status bits are simultaneously ON or OFF, which can also list the slots of this agent to report when this condition occurs.
alarming strategy
a set of guidelines or a plan to optimise the configuration of the alarming of agents. Once created it can easily be transferred and adapted for other projects, as required.
aspect ratio
a ratio or comparison of its width to its height. The screen resolution determines the aspect ratio of a monitor. More than one screen resolution can have the SAME aspect ratio e.g. the following screen resolutions 800×600, 1024×768 and 1280×960 all share the SAME aspect ratio of 4:3.
Behaviours
can be assigned to picture elements to display process values either actually or graphically to provide a dynamic visual indication of events taking place in the process.
block period
the interval over which your electricity provider monitors your maximum demand, which is typically 30 minutes.
Boolean
a value that only has two discrete states, 0 (FALSE) or 1 (TRUE).
cleared
the monitored condition of this incident (alarm/event) has returned to its normal operating state.
CSV
Comma Separated Value file containing data, which consists of a number of fields in one or more rows, in which the different fields (values) are typically separated by commas.
data logging
the process of recording changes in agent slot values over time for the purpose of analysis.
Datalog catchup
only applies to clustered Agent Servers and refers to the process of synchronizing, unsynchronised sections of logged data between the two Agent Server partners in the cluster.
device
added to an installed protocol driver to communicate using this protocol to a specific front-end device - in other words a logical connection to this FED.
dialog
a window that appears when an application requires further information from the user, also known as a wizard.
DLL
a dynamically linked library file
DNS
stands for Domain Name System and is one of the industry-standard suite of protocols that comprise TCP/IP, which is used to translates domain (computer) names to and from their IP addresses.
driver
a DLL that interfaces Adroit to front end devices, these are the only Adroit components that are device specific.
EEMUA
the Engineering Equipment & Materials Users' Association
EEMUA 191 guidelines
a document created by the Engineering Equipment & Materials Users' Association ( EEMUA) of alarm management guidelines, developed by the users of alarm systems, and is the globally accepted and leading guide to good practice for alarm management.
event
an incident (a significant occurrence) that does NOT require user action, unlike an 'alarm' which DOES require user interaction.
event logging
the process of recording significant system and process events. For example, a process event such as changing a PID setpoint, or a system event, such as a printer fault.
FED
front-end device, which is a device that is accessed directly by the user, such as a PLC or RTU.
glossary term
This glossary term is for illustrative purposes only to demonstrate how glossary terms are displayed in this help system.
HMI
An acronym for Human Machine Interface. An HMI is a software application that presents information to an operator or user about the state of a process, and to accept and implement the operators control instructions.
housekeeping
the removal of unnecessary records from a database
ICMP
The Internet Control Message Protocol is used to determine the existence of a remote device on the network. Any IP network device is able to send, receive and process ICMP messages. These messages are only used for troubleshooting network problems and not to transfer data. The most common use of the ICMP protocol is by the PING diagnostic utility.
IIS
Internet Information Services
incidents
signified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action).
IoT
The Internet of Things (IoT) is the concept of connecting any device with an on and off switch to the Internet (and/or to each other).
jotting
text entered manually by an operator in the Execute Command Behaviour.
KPI
Key Performance Indicator, a quantifiable measurement that measures how well something is accomplishing its goals and objectives.
KPIs
Key Performance Indicators, quantifiable measurements that measure how well an organization or individual is accomplishing its goals and objectives.
local file path
this path, as opposed to a UNC path, can ONLY be accessed from the computer that it refers to, this path adopts the following general format: <driveletter>:\directories\filename.
log
also known as data log, the process of recording the changes in a value over time to a log file or OLE DB compatible database.
log set
this provides the ability to log the same slot (value) to a different destination and/or use a different logging rate and/or use a different logging period.
MIB
SNMP Management Information Base, this is a database that lists uniquely described and organises SNMP managed objects hierarchically.
NASA
This stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks.
NTFS
this stands for NT File System, the secure and robust file system for Windows NT operating systems. It allows you to set permissions for groups or individual users to access files.
OEE
stands for Overall Equipment Effectiveness, which typically identifies the productivity or utiltization of a machine or an entire plant, as a percentage.
OEM
a component in Adroit that requires a SEPARATE license BEFORE it can be used, which is added to the Agent Server license by means of an appropriate textual description of this component.
OID
SNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.
OLE
stands for Object Lnking and Embedding, which is a software technology designed to allow different applications to exchange data.
OLE DB
The open standard for accessing data from a variety of sources. An OLE DB data provider is required, before a database can become OLE DB compliant.
OPC
stands for OLE for Process Control, which is designed to alllow an I/O server developed by a 3rd party to communicate to any SCADA.
OPC client
an application that uses the data provided by an OPC server.
OPC HDA
OPC Historical Data Access (OPC HDA) is used to retrieve and analyse historical process data.
OPC item
a string, uniquely describing an individual data element residing in an OPC server. It may be up to 80 characters long, and structured hierarchically typically using a period "." to separate each level.
picture
a collection of one or more picture elements representing a process or a specific plant item, when a picture is toggled into Operate mode then it is known as a mimic.
picture elements
primitive graphical objects such as a Rectangle or Ellipse used to construct pictures, which can have one or more associated Behaviours to enhance its display.
PLC
a Programmable Logic Controller or programmable controller is a digital computer used for the automation of industrial processes.
precedence
rules that state which mathematical operators should be executed first in an expression.
protocol
a set of rules or conventions governing the exchange of information between a computer and a front-end device.
putslot
the process of writing (or the utility that writes) a specific value to a slot of a specific agent.
Real-time Catchup
The Real-time catchup is a process that applies to clustered Agent servers only and not to stand-alone servers. The process occurs during the start up of a standby agent server, if a master agent server is already running. If this is the case, then every agent that is loaded from the WGP file and also supports real-time catchup will request the current state of the agent from the master server and then synchronise itself.
round trip time
The time to send an ICMP message to the network device and receive a reply.
RTU
an Remote Terminal Unit is a device installed at a remote location that collects data and transmits this data back to a central station, or master.
SCADA
Supervisory Control And Data Acquisition, used to monitor and control an industrial plant or process and its related equipment.
scan point
a scan point licence that is consumed from your Adroit license when information is being manipulated.
scanning
the process of communicating a value (slot), typically to and/or from a front-end device (FED).
scanning overrun
this occurs when the scan task takes longer than the required scan rate due to an overloaded or defective scanning subsystem.
select
position the mouse pointer over the item and press the left mouse button; also known as clicking.
session
each time an application is started and stopped on a computer constitutes a single session of this program.
shelve
alarm shelving is the process of removing an alarm from the entire alarm system for a specific time period. This also known as inhibiting an alarm.
slot
a value (attribute) or field within an agent that can be retrieved and/or set.
SMS
Short Message Service is a service (protocol) for sending short text messages to and from mobile phones.
SNMP
Simple Network Management Protocol (SNMP) is used to monitor and manage a diverse range of devices on a computer network.
SNMP agent
DO NOT confuse this with an Adroit agent, this is simply software running on a device that allows it to be managed by SNMP.
SNMP managed objects
management data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device.
SNMP manager
a program that is responsible for managing and monitoring SNMP devices, such as the Adroit SNMPManager agent.
SNMP traps
unsolicited SNMP messages sent by a device to notify an SNMP manager of significant events.
Sparkline
A sparkline is a very small line chart, typically drawn without axes or coordinates. It presents the general shape of the variation in some measurement, such as temperature or stock market price, in a simple and highly condensed way.
subscription
an economical method of accessing the data within agents whereby an agent subscribes to a specific slot (value) of another agent; then when this value changes the agent that has subscribed to this slot is notified of this change in value.
tag
A fully qualified named value in Adroit (agentName.slotName).
telemetry
an automated communications process by which measurements and other data are collected at remote or inaccessible points and transmitted to receiving equipment for monitoring.
UNC
Universal Naming Convention (UNC) is used to specify the location of servers, printers, files and other shared resources on a local area network (LAN). UNC names begin with \\ (two backslashes) and take the form: \\Computer_name\Share_name
URI
stands for Uniform Resource Identifier, which simply identifies the name and location of a file or any resource in a uniform format to provide a standard way for resources to be accessed by other computers across a network or over the Internet (or a private intranet or extranet). While a URL is the most common type of URI, the Uniform Resource Name (URN) is the historical name for the URI.
URL
stands for Uniform Resource Locator and is a reference (an address) to a resource, typically a document, on some computer on the local network or the World Wide Web(Internet).
UTC
stands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI).
WINS
stands for Windows Internet Name Service, which predates DNS as the method used to resolve (translate) computer names and their IP addresses in a network. Unlike DNS which uses a hierarchical namespace, WINS uses a flat namespace.
WYSIWYG
What you see is what you get
XML
stands for Extensible Markup Language, which defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
