Applying Security Policies

The Adroit Security Manager allows you to implement the specified security settings on the local and/or a remote computer.

It is also possible to save these security settings to create a global Adroit security policy (security configuration), which can be applied to another Adroit computer, by simply opening this policy in its Adroit Security Manager. For instance:you may have one security configuration for your remote Classic User Interface or operator–only computers and one for your Agent Server computers.

 

To implement all the enabled security policies on the local computer: this applies ALL the security policies (options) that you have enabled to the local computer.

Note: It is recommended that you log off the computer to ensure that these changes are made.

  1. Click on the Apply policy menu item.

This applies all the security policies to the local computer that have their Apply Policy checkbox checked.

IMPORTANT: These security policies affect ALL the users and groups on this computer and not just the Adroit users and groups.

To apply or deploy the selected options on a remote computer: this allows you to apply ALL the security policies (options) that you have enabled to a remote computer.

IMPORTANT: These security policies affect ALL the users and groups on this computer and not just the Adroit users and groups.

  1. Click on the Deploy policy … menu item.
  2. Select the required computer using the Browse for Computer dialog.

This applies all the security policies that have their Apply Policy checkbox checked to this remote computer.

Note: It is recommended that the specified computer is logged off to ensure that these security changes are made.

Note: You need Adminstrative rights on the selected computer in order to perform this configuration.

 

To save the security configuration: this saves the configured Adroit groups and users and their group memberships and all the security policies that have been enabled and/or the Classic UI document and/or menu security settings. This allows you to create different Adroit security configurations for different computers. For instance:you may have one security configuration for your remote Classic User Interface or operator–only computers and one for your Agent Server computers.

  1. Click on the Save as … menu item.
  2. Specify the name of the required security profile (*.sec.ini) that will contain these settings.
  3. Click the Save button.

To apply a saved security configuration: this applies the Adroit groups and users and their group memberships and all the security policies that have been enabled and/or the Classic UI document and/or menu security settings to this local computer.

  1. Click on the Open … menu item.
  2. Locate the required security profile (*.sec.ini) that contains the required settings.
  3. Click the Open button.
