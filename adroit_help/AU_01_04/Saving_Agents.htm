Saving Agents

After making the necessary changes to the configuration and content of the Agent Server, it is important to save this as the current .WGP load file, to do this:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Select the Save item in the Classic UI File menu.

By default, Adroit does not periodically save the state of neither any agent nor any realtime values of agent slots.

It will only save these values when the Agent Server is deliberately shutdown, and then only if you have the "save on exit" checkbox ticked in the Advanced dialog of the Setup.

Should your application require periodical saving you can, for instance, use an Expression agent linked to a timer to drive the savenow slot of the SystemInformation agent.
