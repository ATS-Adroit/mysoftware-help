The Configuration SystemInformation Page

The System Information agent acts as an information center containing 5 tabbed pages of data slots that are global to the Agent Server. For details on how to access these pages of data, see Editing the SystemInformation Agent.

Note: The actual slot names and NOT their literal descriptions are specified, for ease of reference, since you most likely will need to display one or more of these slots on mimics.

Parameters on startup

These parameters should be configured in Adroit Setup (Config) BEFORE the Agent Server is started.

  1. startMaxChannels: This specifies the maximum number channels used by this Agent Server. A channel is a Client-Server connection from the Agent Server to the outside world, such as to the User Interface, other Agent Servers, DDE links. The default setting is 20.
  2. startGranularity: This specifies the time granularity used by the Agent Server, which is the time interval, in seconds, that this SystemInformation agent updates itself.
  3. startProject: This specifies the current project name of this Agent Server. This project name must not be longer than 8 characters, nor contain any embedded spaces. When more than one project name is being used on the same network, ensure that the first 3 characters are unique.
  4. startName: This specifies the name of this Agent Server. This must be unique across the same network and when more than one Agent Server is being used within a project, ensure that the first 7 characters are unique.
  5. startLoadFile: This specifies which agent database file is loaded by the Agent Server when it starts up.

  6. maxAgents: This specifies the total number of agents that this Agent Server can use.

    This number accounts for both the number of agents in the project and additional Agent Servers explicitly connected to the project. Hence determine the number of expected agents on all the connected Agent Servers and multiply this number by two.

  7. startSaveOnExit: The status of this checkbox indicates whether the WGP file is forced to save when the Agent Server is shut down.

    Note: On large installations, saving can take a long time, so for quick shutdowns, leave this unchecked and manually save at planned intervals.

  8. startDebug: This is a bit mask of the Debug flags as found in Adroit Setup (Config), which should only be configured by advanced users.
