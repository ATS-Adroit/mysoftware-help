The AgentGroup Agent

Agents that are considered to have something in common can be combined into groups by means of AgentGroup agents. For instance, all agents belonging to the north side of a process plant could be grouped in the NORTH_PLANT agent group. Agent groups may, and usually do, have overlapping memberships (i.e. an agent is allowed to belong to more than one group). For details, see Grouping Agents Together.

  1. Normal mode, the AgentGroup agent simply acts as a container for the agents grouped with it, and does not modify its status if any of its group member’s status changes.
  2. Fan in status bits mode, the AgentGroup agent will set its status bits in accordance with the status bits of its members. Only one member agent needs to set a given status bit for it to be "fanned in" to the AgentGroup’s status bit.
  3. Bulk editing of agent type mode, this is only possible if all the agents contained by the AgentGroup are of the same type, any changes made to an AgentGroup agent’s control status bits will "fan-out" to the same control bits belonging to the members of the group. Furthermore, only this mode will ungrey Edit Members button.

Slots to expose via OPC Server (comma separated) : this field (the exposeViaOpc slot) allows you to specify which slots, of the agents that have been added to this group, that you want to be browsable by the Adroit OPC Server.

Note1: This comma separated list of slots cannot exceed 80 characters in length.

Note2: While this feature is not intended for mixed agent groups, any specified slot not supported by a member agent type will be ignored.

Clicking the Edit Members button will bring up the appropriate Edit Agent dialog for the member type and allow bulk editing of the member’s slots.

As an example, consider the situation when part of a plant (say the North Plant) is shut down for routine maintenance, and it is required to disable scanning of all agents belonging to this plant section.

By setting the Scan Inhibit bit for the NORTH_PLANT AgentGroup agent and stopping and starting all the device agents used by this selected group, the Scan Inhibit bits would be set for all the agents that belong to the North Plant.
