Hardware Requirements

The MINIMUM hardware requirements for your computer to run Adroit successfully are:

Processor: i5 1.70 GHz.

Tip: The CPU usage should also not exceed 40% on average when all processes are running (see CPU Usage in the Performance sheet of the Task Manager).

Memory (RAM): 4 Gb.

Hard disk space: 500 MB on the Windows drive, 250 MB on the Adroit installation drive, 1 TB on the Adroit datalog drive.

Note1: These memory and disk requirements may increase depending on the number of agents configured and the size of the project of the Agent Server.

Note2: The datalog disk size requirements will also depend on the amount of datalogging configuration.

Tip: The file system should be NTFS instead of FAT, to avoid datalog file corruption if loss of power should occur.

Display: 65536 colors SVGA (1024x768 resolution)

Peripherals: DVD-ROM drive (for installation) and mouse.

HASP software protection key: Attached to a parallel port or USB port of each Agent Server, programmed in accordance with your specific license agreement. Supplied with the Adroit package.

Note: Existing Adroit users will also require a HASP update to upgrade their licences to the new version before installing Adroit. For details, see Adroit Licensing or "Working with the Adtech Licensing Utility" on page 1 .
