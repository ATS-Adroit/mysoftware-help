Removing a Device from a Protocol Driver

Since a Device is configured both externally and internally to the Agent Server, its removal involves a two-step process:

Step One:Remove the scanned values from the Device agent for the current Adroit database (.WGP) file, which has the same name as the configured device. For details, see Removing scanned values from a device.

Step Two: Remove the configured device from its protocol driver, as follows:

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

  1. Click on the Drivers tab and the required configured Device (, , ) in the Installed Drivers and Devices list and then
  2. Click the Remove () button.

This will display the Protocol Driver Device confirmation dialog, which reports the name of the device to be deleted; click either the Yes or No button, as required.

Tip: This can also be displayed by right clicking on the required configured Device (, , ) in this list and selecting Remove Device from the menu.

Note: This device will only be removed, if all of its scanned points have been removed from the current Adroit database (.WGP) file. If this is NOT the case, then the device is not removed and a message box will display this warning instead.

To prevent this message box from appearing, remove this device from the current Adroit database (.WGP) file via the Configurator, save the WGP file and then right click in this Installed Drivers and Devices list and select the Scan/Re-Scan for used devices option from the menu.

 

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

  1. Click Agent Server Configuration in the right hand pane.
  2. Click Driver Configuration in the right hand pane.

  3. Right click the required Device () of an installed Protocol Driver () in the Installed Drivers and Devices list and select Remove from the menu.

    This will immediately remove the selected device, provided that all of its scanned points have been removed from the current Adroit database (.WGP) file.

    If this is NOT the case, then the device is not removed and a message box will display this warning instead.
