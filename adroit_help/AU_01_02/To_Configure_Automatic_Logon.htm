Configuring Automatic Logon

IMPORTANT: If you are using Windows 7 or later, then please use the following method to configure automatic logon: To Configure Automatic Logon in Windows.

If, for some reason, you’re not able to configure Windows to automatically logon by following the above method, please use this method:

WARNING: Registry settings are recorded as ADVANCED information and should not be used unless you understand exactly how these will affect the operation of your Adroit  installation, IF YOU HAVE ANY DOUBTS, PLEASE CONTACT Adroit SUPPORT, BEFORE CHANGING THE REGISTRY.

PLEASE NOTE: When working on a 64 bit operating system, remember to add "\Wow6432Node" to the path of each registry setting after "\SOFTWARE", for instance: "HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\Adroit Technologies".

If the following settings are correct the system will automatically log you on the next time that you boot. If the changes are bad, a message box will notify you, closing the box will invoke the standard logon procedure.

  1. From the Start menu, select Run…, type in REGEDIT and click OK
  2. Go to the section: HKEY_LOCAL_MACHINE\Software\Microsoft\WindowsNT\CurrentVersion\WinLogon.
  3. Select Add Value from the REGEDT32 Edit menu and enter the name of AutoAdminLogon with a data type of REG_SZ and a string value "1".
  4. Select Add Value again and enter the name DefaultPassword with a data type of REG_SZ and a string that is the password for your computer.

Note: that you must use a password or the logon will not function.

  1. Ensure that the DefaultUserName and DefaultDomainName reflect the user name and domain or computer name that you want to use when you logon. You can change these values using the Edit String menu option.
