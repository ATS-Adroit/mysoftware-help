Project Explorer Tree View Right Click Menu

The Adroit Project Explorer configures and manages both local and distributed Adroit projects. For details, see Project Explorer.

Launching options from within Adroit.

To display this tree windowpane menu, either right-click in tree windowpane or select this windowpane and press F4.

Note: This menu is context-sensitive, so that only the commands relevant to the currently selected object will be available. 

The following commands are applicable each object that you selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. in the tree view windowpane:

  1. FindTo Find Matching Text in the Tree View Windowpane.
  2. Find nextTo Find the Next Occurrence of Text in the Tree View Windowpane.
  3. RefreshTo Refresh the Display of the Selected Object in the Tree View Windowpane.

The following commands are specific to selected Computer objects and their children objects, in the tree view windowpane:

  1. Add PCTo Manually Add a Remote Computer to the Tree View Windowpane.
  2. Delete PCTo Remove a Computer from the Tree View Windowpane.
  3. Find server PCsTo Find and Add All Remote Agent Server Computers to the Tree View Windowpane.
  4. Send message to PCTo Send a Message To a Remote Computer in the Tree View Windowpane.

The following commands are only specific to selected Agent Server objects, in the tree view windowpane:

  1. Start Agent ServerTo Start the Selected Agent Server in the Tree View Windowpane.
  2. Stop Agent ServerTo Stop the Selected Agent Server in the Tree View Windowpane.
  3. Save WGP fileTo Save the WGP file for Selected Agent Server in the Tree View Windowpane.
  4. Basic agents, Advanced agents, System agents, etc.To Only Display the Agent Types within a specific Default Agent Group beneath the Selected Agent Server.
  5. All agentsTo Display All Agent Types beneath the Selected Agent Server.

The following command is only specific to selected Agent Type objects, in the tree view windowpane:

  1. Create agent/sTo Create and Bulk Create Agent/s of the Selected Agent Type.

The following commands are only specific to selected Agent objects, in the tree view windowpane:

  1. Edit agentTo Edit the Currently Selected Agent.
  2. Alarm agentTo Alarm the Currently Selected Agent.
  3. Remove agentTo Remove the Currently Selected Agent(s).
  4. HeaderTo Display the Header Dialog of the Currently Selected Agent.
  5. MembershipsTo Display and Modify the Memberships of the Selected Agent.
  6. Used byTo Display a List of Agents that Use the Selected Agent.
  7. Open documentTo open the Mimic Associated with the Selected Agent.

The following command is specific to selected Classic UI Document Files objects, in the tree view windowpane:

  1. Open documentTo open the selected Classic UI document file.

The following command is specific to selected Template Set objects, in the tree view windowpane:

  1. Open documentTo open the selected template set.
