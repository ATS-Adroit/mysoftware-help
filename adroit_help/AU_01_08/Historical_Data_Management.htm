Historical Data Log Management

Note: Backup (LGB) files can be created when logging to the Adroit proprietary datalog (.LGD) files so that this historical data can be retrieved by the datalogging system when needed. This can also create CSV files too, to make this historical data available to third party applications such as Microsoft Excel and formatted to create reports. For details, see Datalog backup and retrieval.

Extracting Logged Data

Adroit uses a data extraction facility called Extract that retrieves information from an AgentGroup consisting of DataLog agents, or from a single DataLog agent, for a specified time period.

The data is then converted into a CSV (comma separated value) file format that can be opened by a third party application such as Microsoft Excel and formatted to create reports.

Merging Data Logs

Adroit also provides a utility for merging values from a .CSV file into an existing historical database of DataLog agents.

The .CSV file may have been originally created by the EXTRACT utility above, or by choosing the Export... button in the Datalog Retrieval dialog, or by using a text editor to modify existing files taking care to adhere to the format.
