Specifying the Scheduled Command or Utility

When the Scheduler is launched and its window displayed, enter the Program details:

By default, this list box specifies Customised below… in which case:

  1. The required program/file should be specified / browsed for in the Execute the following program edit box and browse button.
  2. If required, specify the required command line parameters in the and pass the following parameters edit box.

Alternatively:

  1. Select the required Adroit operation from the list: either Adroit Extract, Adroit Merge or. Adroit Putslot
  2. Then use the browse button to the right of this Program details list box to display the appropriate dialog box to specify the required details for this commonly-used Adroit operation

In particular these Adroit operation-specific dialogs assist with the specifying of the time and date parameters, by displaying the following control for this purpose:

Then specify whether this command or utility should be executed now or later.
