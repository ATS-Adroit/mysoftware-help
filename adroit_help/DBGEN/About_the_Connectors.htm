About the Connectors

The Adroit DB Generator requires a specific Connector to connect to and access the information stored in each required database of the 3rd party application. Each Connector can create one or more Links that actually connect to the specific applications and are configured to create .WGP files from them.

Since these Connectors are separate modules (.DLL files) that can be added or removed, you can develop your own Connectors to allow the Adroit DB Generator to creates Adroit agent databases from your 3rd party application. The Connector DLL files:

  • Adhere to the following naming convention: dbconn_*.dll, where * represents the unique name of the specific Connector. For instance, the CSV Connector file is called dbconn_csv.dll
  • Are located in the Adroit installation folder, which is typically C:\Program Files\Adroit Technologies\Adroit.

 

There are two categories of Connectors:

  • Device-centric Connectors: This is the more common Connector where its Links configure agents from information (tags) within individual front end devices. For instance the OPC Connector Link configures agents from the items within an OPC Server.
  • Complex Connectors: This Connector creates Links that globally configure agents (NOT device specific). For instance, a CSV Connector Link can create a fully configured Adroit agent database (.WGP file) from information contained in CSV files.

Note: The Connector category determines how the Links of these Connectors are named.

The functionality of the Connector determine the following Connector attributes:

  • if the 3rd party Connector can be remotely accessed or not, determines whether the Adroit DB Generator can access the Agent Server remotely or whether it has to be installed on the same Agent Server computer on which such 3rd party programs themselves are installed.
  • if the Connector supports templates, determines whether you can use templates to determine your own customised agent creation, scanning, logging and/or alarming default settings or not.

Note: Those Connectors that support templates, implement them uniquely by using the features and fields of information available to the Connector’s specific 3rd party application. 

 

To create a Link: each Link can create a WGP file from the selected 3rd party application.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required Connector on the required Agent Server computer.
  2. Select the Create Link menu item. 
  3. Provide a name for this Link, as follows:

If this Connector is Complex: 

  • Type in a name for the Link.
  • Click the OK button.

If the Connector is Device-centric:

  • Double click the required device from the Select device tree, which lists the applicable protocol drivers and their configured devices for the selected Agent Server.
  • Configure this Link using the displayed configuration dialog, if one is provided by this Connector.

This Link is added beneath this Connector with one of the following icons:

  • : a healthy Link that can be used to create a .WGP file from the specified 3rd party application.
  • : a Link that is currently unavailable
