Logging Templates

You can add Logging templates to configure the default logalso known as data log, the process of recording the changes in a value over time to a log file or OLE DB compatible database. settings for one or more log sets, which are usually manually specified when logging agents.

Log sets, in Adroit, specify the logging settings, such as the rate and logging destination, for a particular slot of an agent (process value).

Note: The Connector used by the Adroit DB Generator utility to connect to the required source (3rd party application) determines whether templates can be used or not.

Usage Example:You can create a logging template to use for a cluster, which automatically specifies 2 log sets, one for the master and the other for the standby Agent Server.  

Default templates:The _LoggingDefault template is added for you, providing the Adroit default settings, which you can customise accordingly.

Each logging template allows you to specify the Slot (value) that if provided by the agent that you want to log, will be selected by default. The Adroit default for this is the value slot. Then you can specifythe following settings for EACH log set:

  • The required log Set: Specify the zero based index of the required log setthis provides the ability to log the same slot (value) to a different destination and/or use a different logging rate and/or use a different logging period.. In other words a value of 0 indicates the first set; 1 indicates the second set; etc. .

In Adroit this is the first log set, by default (0).

  • The logging Destination: the location of the logs of this value, which is determined by the method you are using to log this value, as follows:
    • Proprietary Adroit log files: specify the full path and file name of the required log (.LGD) file  and
    • OLE DB-compliant database: specify the connection string to the required database.

    Tip: It is recommended that you copy this connection string from another application instead of manually typing it in, due to its complexity.

In Adroit this is not specified, by default (“”).

  • The log Period in days: specify the required length or time period for logging this value.

The Adroit default for this is 10 days, but 31 days are used as the default setting for the logging templates.

  • The log Rate in seconds: Specify how often this value must be logged. This setting can REDUCE the amount of logging required for this value, as follows:if this value changes more than once during this period then the specified Algorithm is used to determine what value is actually recorded.  

The Adroit default for this is 10 seconds, but 1 second is used as the default setting for the logging templates.

  • The value Deadband: Specify the MINIMUM amount which ANY change in value must EXCEED in order for it to be logged. This setting can also REDUCE the required number of logged entries for this value.

In Adroit this is not specified, by default (0).

  • The Algorithm to be used: If you are using a Rate greater than 0, this algorithm determines the value that is logged when this value changes more than once during the Rate interval, as follows:

    0: actual - the value at the end of the Rate interval.

    1: average - a time-weighted average of all the changes that occur during this Rate interval.

    2: minimum - the lowest or minimum value at the end of this Rate interval.

    3: maximum – the highest or maximum value is logged at the end of this Rate interval.

In Adroit this is 0 (actual), by default.

 

 

Note: By default the slots of the logging template are usually set to the Adroit default settings.

 

To create a logging template: this creates an logging template for the Logging category that is listed beneath the Templates folder.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Logging category within the Templates folder.
  2. Select the Create template… menu item.
  3. Type in the required Template name.

Tip: Provide a brief name that makes it easy to identify the purpose of this template.

  1. Click the OK button.

This selects and adds this template to the bottom of the list of templates beneath the Logging category.

The logging-specific slots are displayed in the right hand pane, with their Adroit Default value.

  1. Customise the default logging parameters (slots) for this template, as follows:

To change the value of a slot in the logging template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

To delete a slot from the logging template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

Note: If you delete one of these slots then the Adroit default value will be used.

To add another log set to a logging template: by default each logging template provides one log set, although you can add more logs sets to each logging template. 

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required logging template in the Logging category in the Templates folder.
  2. Select the Add set... menu item.

The default logging-specific settings (slots) for the log set are displayed in the right hand pane (see above for a detailed description of each one).

  1. Provide the required settings (slots) for this log set, as follows:

To change the value of a slot in the logging template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

To delete a slot from the logging template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

Note: If you delete one of these slots then the Adroit default value will be used.

IMPORTANT: Ensure that you INCREMENT the Set number of each log set that you add. Otherwise, the log settings of the first log set will be overwritten with these!

To sort the list of logging templates: by default each template is added to the end of the existing list of logging templates, it is possible to sort this list, alphabetically, in ascending order, to make it easier for users to select the templates. 

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Loggingcategory within the Templates folder.
  2. Select the Sort menu item.

This rearranges the list of logging templates alphabetically, in ascending order.

To delete a logging template: to remove an existing logging template.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required logging template in the Loggingcategory in the Templates folder.
  2. Select the Delete template… menu item.

The selected template is removed from the list of templates.
