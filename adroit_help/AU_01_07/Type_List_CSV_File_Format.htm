Type List CSV File Format

This file is created when an Alarm agent is exported to store its alarm types that have been created. The filename adheres to the following naming convention: xxxxx-TYPLST.CSV, where xxxxx represents the name of this Alarm agent.

The rows in this CSV file are sorted alphabetically and the alarm type name is used as an index, so that the first alarm type name has an index of 0.

This file consists of the following columns, from left to right:

  1. Alarm type: The name for this alarm type, which MUST NOT be duplicated per agent-type.
  2. Agent type: The type of agent that this alarm type applies to.
  3. Bit-mask: A bit-mask of the relevant header bits that are set. This is the sum of all the bit-positions, which are calculated as 2n , where n is a position from 16 through 31 of the agent status bit as the built-in status bits occupy the positions from 0 to 15.
  4. Value: If applicable, this contains the slot value that is shown with the alarm. For instance for Marshal agents this could be dig##.textValue.
  5. Alarm off-states: 0 is the normal alarming of bits in the mask, while 1 is the alarm off state.
