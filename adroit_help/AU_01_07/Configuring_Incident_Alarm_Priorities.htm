Configuring Incident (Alarm) Priorities

One way to ensure that your operators ONLY receive IMPORTANT alarms is to prioritise your alarms into categories of importance so that you can filter your incidents, based on their priority.

There are two ways to prioritise your incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action).:

  • Per Agent: Use this method if ALL the incidents (alarm types) of this agent have the SAME priority. Alternatively, use this method to specify the LOWEST priority for the incidents (alarm types) of this agent and then use the other per-incident method to specify the incidents that differ. Five levels of importance are supported from 0 the lowest up to 4 the highest.

To configure an agent-specific priority:

  1. Select the required agent in the Agent Configurator dialog. For details, see To Select an Agent.
  2. Click the Header button.
  3. Specify the required priority level for ALL the incidents (alarm types) of this agent, in the Alarm priority edit box in the lower right corner of the Agent Header dialog, as follows:

    0 : lowest

    1: low

    2: normal

    3: high

    4: highest

    The default is 2 (normal).

The Alarm agent will discard any alarms that are triggered if its own priority filter is greater than that of the alarmed agent it is monitoring.

  • Per Incident: Use this method if SOME incidents of an agent have DIFFERENT priorities. For instance the High alarm limit of an Analog agent will have a lower priority than the HighHigh alarm limit.

Note: The agent priority setting is the default priority used when configuring an incident for the first time, thereafter the incident priority setting is always used.

To configure an incident-specific priority:

  1. Select the required agent, in other words the agent containing the alarmed alarm type/s. For details, see To Select an Agent.
  2. Right click this agent and select the Alarm… menu item.
  3. Click on the required alarm type in the Current list of the Alarming dialog.
  4. Click the  button of the Priority list box, in the lower right corner of the dialog.
  5. Select the required level of priority for this incident, as follows:

    0 : lowest

    1: low

    2: normal

    3: high

    4: highest

    The default is 3 (high).

     

 

For further details about filtering incidents based on their priority level, see About Filtering Prioritised Incidents.
