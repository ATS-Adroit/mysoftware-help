Recover a Deleted Group

Tag groups manage the communication settings for the tags whose values need to be communicated to or from the remote Agent Servers via their associated WanServers.

Groups are server-specific. For details, see Tag Groups.

Note: A deleted Group can ONLY be recovered, if the database has NOT been packed since it was deleted. For details, see Packing databases.

To recover a deleted group:

  1. If necessary launch the WanClient and open the WanClient Configurator, by selecting the Open Configurator item from the File menu.
  2. Ensure that the required server is selected in the Select server list box. For details, see Servers.
  3. Click the Recover Groups button to display the Recover Deleted Groups dialog.
  4. In the Deleted Groups list, select the tag group that is to be recovered.
  5. Click the Recover button.
  6. Repeat Steps 3 & 4 as often as required and then click the Ok button to return to the WanClient Configurator.
