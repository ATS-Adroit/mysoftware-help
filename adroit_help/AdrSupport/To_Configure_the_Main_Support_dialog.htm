Configuring the Main Support dialog

This dialog can be completed as follows:

  1. The Company Name is read from the registry, and automatically inserted. If necessary change or update this name accordingly.

This name will also be remembered when the Support program is next run.

  1. The Site Name has to be entered by the client, this only needs to be entered when the Support program is first run on a site, after which this will be remembered.

This name can be changed at any point.

  1. The Contact Details button opens the Contact Details dialog, so that all relevant details concerning the Adroit user, including the highest level of Adroit training completed and whether a TA agreement exists, can be recorded.

Note: The Version edit box in the Adroit group, specifies the current version of Adroit that is running.

  1. Check the WGP File and/or Event Log checkboxes to automatically copy and save these files in the directory that is created. You can select one, none or both.

Note: It is recommended to send both files, the default setting, since it is always better to supply to much rather than too little troubleshooting information.

  1. Specify a brief description of the problem in the Please give a brief description of the problem edit box.

Note: Please give as complete a description of the problem as possible, because you need to help us so that we can help you and the more fully that our Support Desk understands the problem, the faster they will be able to troubleshoot it and sort this problem out.

  1. Click the Create Report button once you are happy with all your selections and inputs to connect to the Agent Server, create and compress the report file and place it in the Support sub-folder of the Adroit installation folder, typically: C:\Program Files\Adroit Technologies\Adroit.
  2. Then email this report file to the Adroit support department. For details, see Methods of emailing the report file to the support department.
