Frame Agent - Slot Details

The Frame Agent stores 32 80 character ASCII strings (79 chars max. with zero terminator).

This agent is located in the following file: T_FRAME.DLL

Slots:

Slot Name Type Function

fieldnn

STRING

Storage of (nn+1)th string value, where nn is equal to any integer value from 0 to 19. This slot is provided for version 3.1 compatibility

index

INTEGER

a value from 1 to 32, being an index to that string value.

vnn

STRING

Storage of nn’th string value, where nn is equal to any integer value from 1 to 32. These string values map over those referenced by field(nn-1).

value

STRING

This is the string value as pointed to by the index.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16 to 32

 NONE

The bit corresponding to (15+index) is set.

Therefore, when the index is 1, bit 16 will be set.

Methods of creation:

Manual

Agents created by default:

None
