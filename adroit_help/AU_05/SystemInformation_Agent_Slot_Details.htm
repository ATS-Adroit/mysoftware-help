SystemInformation Agent - Slot Details

The SystemInformation Agent is a central repository containing various items of information global to the Agent Server.

Every Agent Server always contains one and only one SystemInformation agent, which is called systemInfo.

This agent is located in the following file: Compiled into POOL.DLL

Slots:

INTEGER

Specific status bits: 

Note1: These are of type BOOLEAN.

Note2: These statuses usually change when a master/standby switch is occurring or has just completed.

Bit Number Name Function

status bit 16

In Master mode

On when the Agent Server is clustered and in Master mode.

status bit 17

In Standby mode

On when the Agent Server is clustered and in Standby mode.

status bit 18

Searching for partner

On when the Agent Server is clustered and is searching for its partner.

status bit 19

Waiting for master load

On when the Agent Server is clustered and is waiting for master load.

status bit 20

Going to standby

On when the Agent Server is clustered and is going to standby.

status bit 21

Going to master

On when the Agent Server is clustered and is going to master.

status bit 22

Not joined cluster

On when the Agent Server is not joined to a cluster.

status bit 23

Lost cluster partner

On when the Agent Server is clustered and has lost its cluster partner.

status bit 24

Gained cluster partner

On when the Agent Server is clustered and has gained a cluster partner.
