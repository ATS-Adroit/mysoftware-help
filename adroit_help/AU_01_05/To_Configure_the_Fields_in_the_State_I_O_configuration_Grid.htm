To Configure the Fields in the State I/O configuration Grid

Replace or edit the contents of the cell in the grid.

Either

  1. Click the browse button.
  2. Select an external Adroit tag to determine the value of this cell using the agent browser dialog.
  3. Click the Update button to save the change made to the configuration.

Or type or paste the required value into this cell.
