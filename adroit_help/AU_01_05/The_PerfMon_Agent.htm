The PerfMon Agent

The Perfmon agent is used to monitor Windows Performance counters, which belong to performance objects such as the Agent Server, Processor, Memory, and others.

These counters facilitate the monitoring of the computers performance and assist in detecting performance bottlenecks that could adversely affect the functioning of Adroit.

The values of these counters are updated every second and can also be assigned to other tags, such as Analog agents, which can then be appropriately alarmed. Up to 16 performance counters can be monitored per agent.

The following performance counters are added, by default, to first PerfMon agent created:

  • CPU load i.e. \\Processor(_Total)\\% Processor Time
  • Agent Server CPU load i.e. \\Process(as)\\% Processor Time
  • Total memory used i.e. \\Memory\\Committed Bytes
  • Agent Server memory usage i.e. \\Process(as)\\Private Bytes and \\Process(as)\\Virtual Bytes
  • Agent Server put slots i.e. \\Agent Server(name (project))\\PutSlots

 

Since Adroit is a 32 bit application, if you have installed a 64 bit operating system then when you run the default Performance Monitor (PERFMON.EXE) all the counters for Adroit will be missing, because the 64 bit version of PERFMON is being run which can only load 64bit counter dlls! Therefore, in order to force Windows to load the 32 bit version of PERFMON, open the Command Prompt and specify the following statement: mmc /32 perfmon.msc
