Configuring an ARec Agent

The ARec agent.

The AREC agent performs two separate functions, which can operate independently from one another and need to be separately configured, these are:

  • A logic table or truth table, in which up to 255 states can be defined for up to 32 bits, which can also be optionally programmed as a sequence controller.

Truth Table Configuration.

  1. Use the State I/O configuration tab to specify up to 32 input and/or output bits I/O bits, which are also slots of the ARec agent.
  2. Use the State configuration tab to specify up to 255 states that define the truth table of the ARec agent and to set or clear any output bits that have been configured.
  • A numerical sequence to display text, that is able to set alarm status bits.

Numerical Sequence Configuration.

  1. Use the Sequence configuration tab to specify up to 255 sequence steps for the ARec agent.
