The Statistical Agent

Statistical Process Control and Acceptance Sampling are methods used to detect significant changes in the manufacturing process and to monitor the quality of manufactured items being produced in batches.

The problem is to decide whether a batch should be accepted or rejected on the basis of a sample, which is randomly or otherwise, drawn from the batch. There are many ways to make a sample - whether at timed intervals or on triggered events.

The Statistical agent provides the basic functionality for a user to build a statistical process control strategy using its built in data collection method and by linking the agent to other Adroit agents.

Note1: The Statistical agent supports real-time catch-up.

Note2: Use agent persistence files to prevent Statistical agents from losing their statistical data, instead of saving the Agent database (.WGP) file frequently. For further details, see Agent Persistence Files.

PLEASE NOTE: When exporting Statistical agents, ensure that the Floating average enabled checkbox is UNCHECKED, then save the WGP file and export. After importing, re-enable this checkbox for the applicable Statistical agents.

There is a Statistical agent Wizard to demonstrate its operation, which can be found in the Wizards folder under the Adroit system folder, typicallyC:\Program Files\Adroit Technologies\Adroit\Wizards.
