Connecting to the required Agent Server

The Tag Monitor utility can display current values of one or more tag values from a particular Agent Server, in tabular and trend format, without having to specifically draw a mimic or create a trend to do so. For details, see Monitoring Tags (Values).

For this reason, it is necessary to specify the Agent Server whose tags will be monitored. This can be performed as follows:

  1. If necessary launch the Tag Monitor utility, which will attempt to connect to an Agent Server running on the same computer as the utility. For details, see Launching the Tag Monitor Utility.

The required Agent Server can also be selected as follows:

Note: This is necessary when using a command-line option to obtain a tag list from a specific remote Agent Server.

The Servers combo box, contains a list of all the Agent Servers that are detected within the current network domain/workgroup in which the local computer is a member.

To connect to a detected Agent Server:

  1. Simply click on the combo box below the Servers title (in the top right hand corner).

This will display a list of all the Agent Servers that are detected within the current network domain/workgroup, as follows: computerName.AgentServerName(ProjectName).

  1. Select the name of the required Agent Server.

 

The Connect… button can be used to manually connect to any other Agent Servers that are not displayed in the Servers list box. For instance, any Agent Server, running in other domains/workgroups or across a network switch.

To connect to an undetected Agent Server:

  1. Click the Connect… button.

The Connect to agent server dialog is displayed.

  1. Type in the name of the required Agent Server and the network name of the computer upon which it is running in the following format: computerName.AgentServerName
  2. Click the OK button.
