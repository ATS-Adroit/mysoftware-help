1. Overview
Adroit supports communication with the following :
Any simple asynchronous TCP/IP listener that will receive Ascii text , this will be sent to "D0" string
agent and then onto a script for more advanced decoding.
The system allows telemetry functionality for efficient communication to large highly distributed
systems.
