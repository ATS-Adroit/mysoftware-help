1. Overview 
 
Adroit supports communication with the following : 
Any simple asynchronous TCP/IP listener that will receive Ascii text , this will be sent to “D0” string 
agent and then onto a script for more advanced decoding. 
 
The system allows telemetry functionality for efficient communication to large highly distributed 
systems.

5. Protocol Definition and Considerations 
5.1. 
Script 
 
 Example Script Agent “bas” File triggered on the incoming string. 
REM ----------------------------------------------------------------------- 
REM - This is a simple demo script that will take a lora string in the 
REM - format : AAAAAA,BBBBBB,CCCCCC<LF> and strip it out an update 
REM – “AAAAAA_A0” <- BBBBBB as analogue register value 
REM – “AAAAAA_A1” <- CCCCCC as analogue register value 
REM - 
REM - IOT agent is xml could and should be prototyped in here and then 
REM - make an official lora driver and matching IOT agent pair... 
REM - 
REM - The string scanned to scanEth address D0 , is used as the trigger 
REM - Its value is consumed in here as above 
REM ----------------------------------------------------------------------- 
 
Sub Main() 
 
Dim msg 
Dim instring 
Dim tagname 
Dim AAAAAA 
Dim BBBBBB 
Dim CCCCCC 
Dim ch 
 msg = "The following tags triggered this script..." & Chr(13) & Chr(10) 
 For i = 1 To Adroit.TriggerCount() 
 
If Adroit.TriggerActive(i) Then 
 
 
msg = msg & Adroit.TriggerName(i) & " = " 
 
 
msg = msg & Adroit.TriggerValue(i) & Chr(13) & Chr(10) 
 
 
instring = Adroit.TriggerValue(i) 
 
 
 
End If 
 Next 
 
 If (Len(instring) = 21) Then 
 ch = Mid(instring,7,1) REM prechecks 
 
 
If (ch <> "," ) then 
 
 
MsgBox "1"+ch 
 
 
exit sub 
 
 
End if 
 
 
 
 
 
ch = Mid(instring,14,1) 
 
 
If (ch <> "," ) then 
 
 
MsgBox "2"+ch 
 
 
exit sub 
 End if 
 
 
 
 
 ch = Mid(instring,21,1) 
 
 
If (ch <> Chr(10) ) then 
 
 
MsgBox "3" 
 
 
exit sub REM <LF> 
 End if 
 
 
 
 
 
 
 
 
 
 
 
 AAAAAA = Mid(instring,1,6)
