2.1.1. For Modems
Connect PLC via the [DTE<->DCE] cable to the receiving Modem.
Connect PC via a straight modem cable (usually ships with modem) to the Transmitting modem.
Recommended US Robotics Modem config Setups:
Configuring PC-side modem use Hyper-terminal:
Start with "AT&F0" factory reset. "ATI4" displays current configuration. Alternatively, insert this
string into device modem configuration for auto loading:
"ATE0&B1&N10&C1&D2&R2"
Save with "AT&W0", "AT&W1".
&B1, &N10 forces it to connect at only 19200.
Careful: to match your configuration, see your modem documents for specific details.
&D2, &R2 forcing hang-ups, etc., during communications attachment.
Configuring PLC-side modem use Hyper-terminal:
"ATE0S0=1&B1&N10&C1&D0&H1&S1&R2"
"&D0" forces modem to accept incoming connections without terminal ready (TR).
"&H1", "&S1", "&R2" enables handshaking to the PLC.
"S0=1" auto answer mode.
"&B1", "&N10" forces it to connect at only 19200 (Careful: make sure to match your device
configuration.)

Stop bits - Forms part of the serial communication setting. For example, 8 data bits, 1 or 2 Stop bits,
no parity serial communication. Ensure that the Stop bit settings are the same on the local and remote
machines. (Data bits are fixed to 7)
Retry - The number of times that Adroit will try to gain communication with a PLC before failing a
transaction.
Timeout (ms) - The time that Adroit will wait for a valid response from a PLC before failing a
transaction (Read or Write).
Trans delay (ms) - (Default = 60) If non-zero CTS (Clear-to-send) flow control is enabled, and the
driver uses this value as a "settle" time for the outgoing CTS signal whenever it is about to send any
requests.
3.1.3. PLC Details
PLC Type - Applicable Hitachi PLC types (as detailed above.)
Use RS-422 Network - Uncheck/disable for point-to-point connection. Check/enable for RS-422
multi-dropped connection.
PLC Station ID - (RS-422 only) station ID as set on PLC.
Link Number - (Default = FF) Link # in hexadecimal.
Unit Number - (Default = FF) Unit # in hexadecimal.
Module Number - (Default = 00) Module version number.
Port Number - (Default = 00) Port # in hexadecimal.
Delay (TM) - (Default = 2) The TM (TW) delay in hexadecimal.
3.1.4. Advanced
Use Occupy Task Codes - (Default = unchecked) This option will be set depending on CPU model
selected. If it was automatically set for a CPU, this option will be disabled but "ON".
3.1.5. Defaults Button
Load Default values - Will reset all settings shown to what they were before this device was
created.
Specific CPUs only operate correctly with special parameter changes viz.
H300, H302, H700 and H702 models require that the Trans delay parameter be adjusted to 60ms or
more. (Rev 20c onwards of the driver does this).
Models H200 H300 H307 H700 and H2000 require the Task codes option turned on. In this case, the
driver does not allow the user to manipulate the setting either.

6.3.
Troubleshooting Notes
1. H200 type PLC's require CTS handshaking. This is automatically enabled if the PLC Type is
H200, but not for other types.
2. A Transaction Delay value of 60-100ms has been found to suit most applications. It is
required as some Hitachi PLC's cannot handle too many transactions in quick succession. Check
the Windows NT event log to see if you are getting too many retries or timeouts and try
adjusting the Transaction Delay value to optimise performance. The default setting here is 60
milliseconds, newer controllers may be able to use 20 ms. Adjust this setting until stable comms
is achieved for maximum performance.
3. Another factor sometimes causing excessive errors/retries in the H200/250/252 PLC types is
if the PLC program is too short. Some users have reported much more reliable communications
to these PLC's simply by increasing the PLC program size.
4. If you get intermittent comms failures on older models … try setting the tm delay to 2. This
delay's default value is 2, a value of 0 may be used for some newer CPU models.
