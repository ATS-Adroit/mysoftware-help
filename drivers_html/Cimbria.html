1. Overview
This document describes the setup of, and the communication protocol implemented in the Adroit
protocol driver, with the following logic unit: Cimbria level sensor.
The Cimbria devices can take up to 12 seconds to reply to a single line request, for this reason it is
recommended that scans are only added when the device is stopped.

3. Device Configuration
3.1.
Device Configuration
3.1.1.
Configuration Selection [not implemented]
Enable Secondary - Enables secondary configuration for dual redundant Controllers. This setting
is disabled for this driver.
Primary/Secondary - Select the primary or secondary button depending on which connection you
wish to configure.
This feature is not available for this driver.
3.1.2.
Port Setup
Port - Select the serial port to use for communications.
Parity - Select even or uneven parity in a single serial transmission message.
DataBits - Select the number of data-bits per packet.
StopBits - Select the number of stop-bits per packet.
Baud Rate - The transmission rate of data (including start and stop bits). The default baud rate
for a Cimbria unit is 9600.

5. Protocol Definition and Considerations
5.1.1.
Cimbria Protocol Instruction Structure
Message
Start
Message start:
The exclamation mark character (0x21) indicates the start of a new instruction.
Cimbria Station Address:
This three digit number indicates the address of the Cimbria device, to which the message will to be
sent.
Command/Instruction:
This single character instruction identifies the type of information that is requested by the user. This
could be any one of the instructions described in the previous section (Supported Addresses).
Command Parameters:
These parameters are command specific and vary in length between commands.
Message stop:
The Asterix character (0x2A) indicates the end of the instruction.
