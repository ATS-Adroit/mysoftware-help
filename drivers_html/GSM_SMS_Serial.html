1.
Overview
The GSM_SMS protocol driver for Adroit using GSM modems. Messages configured in String or Notify
Agents may be sent via SMS. Alarms that occur in Adroit can thus be routed to a person via SMS.
The driver only handles the transmission of the intended message, which can originate as an alarm,
a message entered by an operator or from programming done in Adroit. This driver is intended for
easy use with any cellular SMS protocol. No Windows drivers for the modem are needed, this driver
provides its own interface to the modem via the serial port assigned to it.
All tests and designs were carried out using a 'WAVECOM WMOD2' model GSM Modem.
PLEASE NOTE
This driver does not currently support secondary ports.

Device Configuration
3.1.
Driver Installation and Setup
Installation of the GSM_SMS protocol driver is done in the standard way in Adroit Setup. After
installation of the driver, the user may then create and configure devices for the GSM_SMS driver.
3.1.1. Devices
At a minimum, you must create at least one GSM_SMS device for each modem. A new device must
be created per service provider. Currently, the port settings for all devices on a port must be identical.
In other words, it is not permitted for example to use Vodacom and MTN together.

9.
Appendix B - Unicode (Multi-byte)
Languages (Send only)
When using Unicode languages there are some points to consider.
Due to the Hex mode used on the modem only half the amount of characters can be sent. i.e 70.
The correct code page must be selected, if incorrect the message will likely be garbled. It is
usually best to have the computers local setting match the code page.
English can be sent simultaneously due to the fact that the English alphabet is always
accessible, but again due the use of hex mode the 70 character limit still applies.
If a code page is visible in the Unicode Code page combo box in setup , that means it is a valid
and may be used, the driver will acquire the installed and compatible codepages automatically.
Not all code pages are clearly marked, in those cases an online search may prove use full. For
example : Polish is a Latin based language and its special characters are available on ISO-88592 Latin-2 code page.
When selecting Hex mode, the 4th value of the +CSMP string will automatically be changed to 8
from 0 and vice versa.
The GSM_SMS driver only supports sending of Unicode strings. Reception of Unicode strings will
still be interpreted as single byte strings.
The Command Agent does not recognise Multi-byte strings, so receiving any string in that
format will not be accepted. It is therefore recommended to not use Hex mod when using the
Command Agent in command reception mode.
The Command, Notify or String Agent can be used to send Unicode messages.
