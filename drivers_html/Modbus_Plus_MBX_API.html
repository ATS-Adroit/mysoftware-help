1. Overview
Adroit supports communication with the following PLCs: Modicon 84, 884, 184, 384, 484, 584 , 984
and Moscad via the SA85 adapter and accompanying Cyberlogic device drivers. This driver does not
support peer cop.

3. Device Configuration
3.1.
Device Configuration
3.1.1. Port Selection
Enable Secondary - Enables secondary configuration for dual redundant Controllers. This setting
is disabled for this driver.
Primary / Secondary - Select the primary or secondary button depending on which connection
you wish to configure.
3.1.2. PLC Details
Routing Address - Routing path of up to 5 levels, e.g. 25.2.200.0.0 will address multiplexer node
25, port 2 slave device 200.
PLC Type - Applicable Modicon PLC types (as detailed above)
Network delay - Network inter-PLC quiet time (see below).
3.1.3. Local Details
Card No. - The SA85 adapter number on your machine. (0 corresponds to the first card)
Retry - The number of times that Adroit will try to gain communication with a PLC before failing a
transaction.

6.3.
Troubleshooting
6.3.1. After installing the Adroit driver, I do not see it in setup!
If you have not installed Cyberlogic drivers for the adapter, the Adroit driver will not be shown in
setup. Adroit setup version 5.0.4.0 onwards will also alert you that the driver modbusp.dll failed to
initialize correctly. Driver Version 18 onwards utilizes the Cyberlogic MBXAPI, when installed
mbxapi.dll will be placed in the %WINDOWS%\SYSTEM32 folder, this driver supersedes the netlib.dll
interface.
6.3.2. To verify card operation and network paths:
Run the mbpdemo program either from the diagnostics tab in the driver setup program as shown
in the Device Driver Installation Notes section.
Or Click "Start/Programs/WinConX/MBX Driver/MBX Demo"
