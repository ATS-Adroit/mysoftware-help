3. Device Configuration 
3.1. 
Device Configuration 
 
 
 
3.1.1. Port Selection 
 
Enable Secondary – Enables secondary configuration for dual redundant Controllers. This setting 
is disabled for this driver. 
 
Primary / Secondary – Select the primary or secondary button depending on which connection 
you wish to configure. 
 
3.1.2. PLC Details 
 
Routing Address - Routing path of up to 5 levels, e.g. 25.2.200.0.0 will address multiplexer node 
25, port 2 slave device 200. 
 
PLC Type - Applicable Modicon PLC types (as detailed above) 
 
Network delay – Network inter-PLC quiet time (see below). 
 
3.1.3. Local Details 
 
Card No. - The SA85 adapter number on your machine. (0 corresponds to the first card) 
 
Retry - The number of times that Adroit will try to gain communication with a PLC before failing a 
transaction.

3.2. 
Data Master Path Note: 
 
The Data master path is a logical path or connection resource, paths are assigned automatically. Any 
configured devices on the same route now automatically use a new path as well. This means that 2 
devices on separate “paths” may communicate simultaneously for better speed. 
 
3.3. 
Network Delay Note 
 
Applies to RS-232/422 gateway use only. 
The network delay is an optional instituted delay, inserted before a different station is polled on the 
same Data master-path. Using a value of zero will disable this feature. The network delay or quiet 
time is needed to allow a slave to detect the end of the communication cycle. 
 
A Modbus slave interprets a 2.5 character time delay at the end of a message as a signal that 
communication has been broken off, and thus allows communication to be initiated by the master to 
a new slave. By default, the Adroit driver does not implement this delay or network quiet time. 
 
To calculate the necessary time use the following formula, we have used 5 characters instead of 2.5 
as this is always good engineering practice. 11 bits per byte have been used. 
 
1/Baudx11x5. 
 
e.g. For a baud-rate of 2400, 1/2400 x11x5= 0.022916. or 23 ms. 
 For a baud-rate of 19200, 1/19200 x11x5= 0.002863. or 3 ms. 
 
Devices using separate Data master paths will not wait using this network quiet time, so that all 422 
communications must take place on the same data master path.

6.3. 
Troubleshooting 
 
6.3.1. After installing the Adroit driver, I do not see it in setup! 
 
If you have not installed Cyberlogic drivers for the adapter, the Adroit driver will not be shown in 
setup. Adroit setup version 5.0.4.0 onwards will also alert you that the driver modbusp.dll failed to 
initialize correctly. Driver Version 18 onwards utilizes the Cyberlogic MBXAPI, when installed 
mbxapi.dll will be placed in the %WINDOWS%\SYSTEM32 folder, this driver supersedes the netlib.dll 
interface. 
 
6.3.2. To verify card operation and network paths: 
 
Run the mbpdemo program either from the diagnostics tab in the driver setup program as shown 
in the Device Driver Installation Notes section. 
 
Or Click “Start/Programs/WinConX/MBX Driver/MBX Demo”
