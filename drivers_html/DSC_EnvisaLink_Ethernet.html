DSC EnvisaLink Ethernet Driver
DSC EnvisaLink Ethernet Driver
Overview
This document describes the setup of, and the communication protocol implemented in the
Adroit protocol driver, with the following logic unit: DSC EnvisaLink.
Device Configuration
Configuration Selection
Enable Secondary - Enables secondary configuration for dual redundant Controllers.
This setting is disabled for this driver.
Primary / Secondary - Select the primary or secondary button depending on which
connection you wish to configure.
This setting is disabled for this driver.

IP Settings
IP Address - The IP Address that will be used for communicating with the controller.
Passwords
Please note. Passwords are encrypted using 16 bit key encryption before being stored in
the registry.
TPI Password - Enter your envisalink webpage password here
DSC Master Code - Enter the DSC alarm panel's master code. This is used to arm and
disarm the alarm panel.
DSC Installer Code - Enter the DSC alarm panel's installer code. This is used when
configuring the alarm panel.
Internal Settings
Note. This driver has an internal thread which handles the scanning. Changing these
settings, change the frequency in which the scanning thread adds the following to the read
queue.
Keep alive poll frequency (ms) - This is the time delay between keep alive polls. This
value is measured in milliseconds and must be between 1000 and 10000.
Status poll frequency (ms) - This is the time delay between status polls. This value is
measured in milliseconds and has a minimum of 10000ms.
Set alarm system time from SCADA - If this checkbox is checked, the alarms panel's
system time will be set with the time from the Adroit agent server.
Time update frequency (m) - The time on the alarm panel may drift, if "Set alarm
system time from SCADA" is check, the alarm panel's system time will be updated with
this frequency.
Timeout (ms) - If the driver does not receive a valid response from the device within this
period (measured in milliseconds), the port will be closed. Note. This value must be greater
that the "keep alive poll period" in the "Internal Settings" section.

Address Descriptions
The addresses are either read only or write only. Read only addresses are sent from the
driver to adroit in an unsolicited manner. Write only addresses will be cleared (to 0
if digital or integer and to "" if string) once the write is complete.

Message Protocol Description
DSC EnvisaLink message structure
Command
Code
This three digit code when sent to the device issues a command, i.e. tells the device what
to do. However when receiving a message from the device, this code tells the driver what
type of information is being received.
Data:
This part of the message is variable length depending on the command code sent, and
contains the data required for the command code.
Checksum:
The checksum is two characters wide. The checksum is calculated by adding the hex value
of all command and data digits, and truncating the result to 8 bits.
Carriage-return-linefeed:
The carriage-return and linefeed characters are appended to the end of each message.
