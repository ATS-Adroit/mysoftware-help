1. Overview 
 
The Conet driver makes use of third-party software to interface with the hardware. Therefore, to 
run this driver successfully, the “C6193A CONET PCI Interface Card” software must be installed. A 
Conet card is not required to configure. Follow the instructions in Section 4. Device Configuration for 
more details.

2. Wiring 
 
The Conet network itself, including the wiring between the card and the stations, consists of a two-
wire cable (usually shielded). As physical wiring is not within the scope of this document, please 
consult documentation accompanying the Conet PCI card for details.

3.1. 
Hardware Installation 
Please follow the instructions provided with your card, the instructions below are correct at time of 
compilation, and may differ from the prescribed procedure. 
Unless the card is already successfully installed and working in the host machine the following steps 
must be followed. 
 
Enable Plug-N-Play on your computer’s BIOS. 
 
 
Switch off your computer and unplug the power cable. 
 
 
Insert the card into a blank PCI (white) slot. 
 
 
 
Card OID /Node Address(SW1 1to SW1 7). The own ID of the card must be set to a unique 
address between 1 and 127. Remember that optimum performance (owing to the nature of the “Next 
Node searching algorithm employed for token passing) is achieved when there are no gaps between 
the node numbers. 
 
 
Mode Setting (SW1 8). Select between (N)ormal mode and (S)low mode. Mode N is 62500 
baud and Mode S is 7800 baud. Typically Mode N is used, but for networks with high interference 
levels, or large distances between the terminators, Mode S will be more reliable. 
 
 
Turn on the computer, windows will automatically install the Jungo card drivers for you from 
the Conet Software CD, which must be inserted into your CD-Rom drive. 
 
 
Run the Omniflex CD setup program to install the COM component needed by the Adroit 
driver, a small test program will also be installed at this time.

and selecting the “Drivers” tab, choosing the “Add Driver” button, selecting the Conet PCI driver,

3.3. 
Device Configuration 
 
The driver setup dialog will allow you to configure your driver devices. Configure one device per 
Conet Network Node. A maximum of 127 devices may be used at one time. More than 32 devices 
on the Conet Network may significantly reduce the speed of data transmission and is not 
recommended. 
 
3.3.1. Select FEP Card for this Device 
FEP Card (1 – 4) - This Radio Button Group requires the selection of a Card Number. This Card 
Number has nothing to do with settings on the proprietary card itself; the Card Number is a driver 
option, which will be allocated to a physical card to identify it. This means that a maximum of four 
Conet cards may be installed in a single machine. 
3.3.2. FEP Card State 
TEST - Test button to verify that the device driver and card are functioning. 
3.3.3. Outstation Settings 
Outstation - (1-127) The outstation number is the Own ID (OID) of the device on the Conet 
Network with which this device must communicate. 
 
Retries - Before failing a communications transaction, the device has the option of retrying. The 
value here will be the number of times the device will retry. 
 
Timeout (ms) - In version 6c of the driver onwards, the retries setting does now work, and the 
dialog appears differently. The new offline retry time however does not have any effect.
