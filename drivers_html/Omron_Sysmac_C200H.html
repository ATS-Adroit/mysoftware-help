OMRON SYSMAC C200H protocol driver
Overview
The Adroit Omron protocol driver provides serial connectivity using RS-232 or 
RS-422 to omron host link modules The C200 and C1000 ,CS1 series amongst 
others, as well as KEYENCE PLC and Process-Plus modules are supported in 
this driver.
Device configuration
Note: The most commonly used 
settings are for multi-link 
system operation with station 
zero even when on RS232. A 
baud rate of 19200 is suggested 
if the default of 9600 does not 
work. Re-start your agent 
server after changing any of 
these settings for them to take 
effect.
PLC Details
Multi-link System
Select to enable multiple link protocol on a RS-422 line. If 
this option is selected, the Link Unit number must be 
entered in the ‘PLC Station ID’ field.
Single-link System
Select to disable multiple link (for point to point 
communication).
PLC Station ID
Host Link unit number for multi-link (multidrop) 
connections
PLC Type
Applicable SYSMAC PLC types. The PLC type selected will 
apply to the primary and secondary port if available. This 
selection currently has no affect on communications.
Local Details
Port
The available serial ports on the machine.
Baud 
Rate
The speed of data transmission. Any of the following Baud Rates may be 
specified 300, 600, 1200, 2400, 4800, 9600, 19200 or 38400.

Format
The transmission format used for the port.
Retry
The number of times that Adroit will try to gain communication with a
PLC before failing a transaction.
Time-out
The time that Adroit will wait for a valid response from a PLC before
failing a transaction (Read or Write).
Advanced dialog
The settings visible in the advanced dialog should only be modified to optimise
configuration.
Maximum frames
The number of frames that Adroit will grow transactions to.
A larger number reduces the number of poll records used, but
will reduce performance if the scan points are widely
scattered.
Force PLC into
monitor mode
Allow the Driver to put the PLC into monitor mode on
startup as well as whenever the PLC mode is changed to run.
If at any stage the driver attempts to write to PLC memory
and fails because the PLC is in run mode this option will
allow the driver to set the PLC mode while running. The
driver will fail to write values to PLC memory if it is in run
mode.
The settings in the advanced dialog will be applied to primary and secondary
configurations.

The RS-422 line should be terminated at either end, the total resistance must be
100Ω minimum. The maximum cabling length recommended is 500m. For
further details refer to your Host link and RS-422 adapter manuals.
Terminating resistance's may not be necessary for cables shorter than 20m.
PC COM Ports - Hardware Setup
If communications appears inconsistent or unreliable, the serial port settings
may need some adjusting. Reducing the serial port RX FIFO buffer to 1 (or
minimum) may help. If the computer does not have a buffered UART, this
setting may not help, in sucha case, set the PLC for a lower baud rate.
