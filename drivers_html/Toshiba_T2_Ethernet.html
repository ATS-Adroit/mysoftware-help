Toshiba : TOSHIBA
Toshiba T2 Ethernet protocol driver
Overview
The TOSHIBA Ethernet driver currently only supports the ascii-based protocol. This driver
supports the PROSEC T2 PLC. Communication is UDP/IP. The ADROIT TOSHIBA driver will
act as the master in a master-slave transaction system.
PLC Details
IP Address - This must be any available class B address on the network ie(OCTET1 must be >
127) setup in the PLC.
Port - The first available UDP port setup in the PLC
Local Details
Retry - This is the number of times the ADROIT TOSHIBA driver will attempt a particular
scan job before failing.
Timeout - This is the maximum time the ADROIT TOSHIBA driver will wait for a response to
its request message from the PLC.
Local UDP Port - For indication only of the Local UDP port used for this device. NOTE: This
is not a fixed parameter it can change at startup depending on available ports.
Wiring
Standard Ethernet interconnection. (10BASE-T)
