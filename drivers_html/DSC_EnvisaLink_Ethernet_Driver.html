4.1.3. Passwords 
TPI Password – Enter your EnvisaLink webpage password here

alarm panel. 
 
DSC Installer Code – Enter the DSC alarm panel’s installer code. This is used when configuring 
the alarm panel.

 PLEASE NOTE

4.1.4. Internal Settings 
Keep alive poll frequency (ms) – This is the time delay between keep alive polls. This value is 
measured in milliseconds and must be between 1000 and 10000. 
 
Status poll frequency (ms) – This is the time delay between status polls. This value is measured 
in milliseconds and has a minimum of 10000ms. 
 
Set alarm system time from SCADA – If this checkbox is checked, the alarms panel’s system 
time will be set with the time from the Adroit agent server. 
 
Time update frequency (m) – The time on the alarm panel may drift, if “Set alarm system time 
from SCADA” is check, the alarm panel’s system time will be updated with this frequency. 
 
Timeout (ms) – If the driver does not receive a valid response from the device within this period 
(measured in milliseconds), the port will be closed. Note: this value must be greater that the “keep 
alive poll period” in the “Internal Settings” section. 
 
 PLEASE NOTE 
This driver has an internal thread which handles the scanning. Changing these settings changes 
the frequency in which the scanning thread adds the Adroit jobs to the read queue.

5.1. 
Address Descriptions 
The addresses are either read only or write only. Read only addresses are sent from the driver to 
Adroit in an unsolicited manner. Write only addresses will be cleared (for example, to 0 if digital or 
integer type and to “” if it is a string type) once the write is complete.

6. Protocol Definition and Considerations 
6.1. 
DSC EnvisaLink Message Structure 
Command Code 
Data 
Checksum 
Carriage return & line feed 
CCC 
DDD…DDD 
KK 
\r\n 
 
Command Code: 
This three digit code when sent to the device issues a command, i.e. tells the device what to do. 
However when receiving a message from the device, this code tells the driver what type of 
information is being received. 
 
Data: 
This part of the message is variable length depending on the command code sent, and contains the 
data required for the command code. 
 
Checksum: 
The checksum is two characters wide. The checksum is calculated by adding the hexadecimal value 
of all command and data digits, then truncating the result to 8 bits. 
 
Carriage return & line feed: 
The carriage return and line feed control characters are appended to the end of each message.
