1.
Overview
The Adroit Siemens protocol driver supports a set of various PLC models and communication
protocols.
1.1. Supported Communication Protocols
ISO over TCP/IP - Ethernet connection.
o supported PLC models: S7-200, S7-300 and S7-400 and S7-1200 and S7-1500
MPI - Serial connection.
o supported PLC models: S7-300 and S7-400 and S7-1200 and S7-1500
MPI via IBH Link S7/S7++ - Ethernet connection from Adroit to IBH Link, serial connection
from IBH Link to PLC.
o supported PLC models: S7-300 and S7-400 and S7-1200 and S7-1500
PPI - Serial connection.
o supported PLC models: S7-200
PPI via IBH Link S7/S7++ - Ethernet connection from Adroit to IBH Link, serial connection
from IBH Link to PLC.
o supported PLC models: S7-200
See Appendix A for a list of tested CPU's and CP's and their respective part numbers.
See Appendix B for some considerations about the protocol and how it is used effectively.
See Appendix C for MicroWin S7-200 configuration.
See Appendix D for Siemens TIA Portal configuration for S7-1200/S7-1500.
The system requires no third party drivers, software, stacks or plc code to run, provided the
Siemens PLC and/or IBH Link and/or CP card is supported and has been configured
appropriately.

4.1.1. Redundancy
Enable Secondary - (Default = unchecked) Turn this option to have the driver maintain 2 channels
of communication, where the radio buttons Primary and Secondary can then be used to toggle
between configurations.
4.1.2. Device Details
PLC Model - (Default = S7-200) Select which PLC model the driver will connect to, S7 200, S7 300
or S7 400. In the case of using S7-1200 or S7-500 select the S7300 option.
Protocol - Select which communication protocol should be used when the driver communicate with
the PLC. See the Overview: Supported Communication Protocols section for more details on
supported protocols.
Retry count - In the event of communication failure, this value indicates the number of retry
attempts before the driver enters a back-off state.
Back-off Period - The time in milliseconds which the driver idles when in the back-off state.
Connection Timeout - Maximum time in milliseconds Adroit will wait for a device to reply, before
timing out and retrying.
PDU Length - The maximum bytes to read in a single transaction.
4.1.3. Connection Configuration
Ethernet Configuration
This block will only be active if either of the following protocols are selected: ISOTCP, MPI by IBH,
or PPI by IBH.
IP Address - Configurable Ethernet Address. 127.0.0.1 (default).
Port - Usually 102 when ISOTCP is selected and 1099 when MPI by IBH, or PPI by IBH is selected.
Change not recommended.
Serial Configuration
This block will only be active if either of the following protocols are selected: PPI, MPI
Com Port - The available serial ports on your machine.
Baud Rate - The speed of data transmission. Any of the following Baud Rates may be specified:
300, 600, 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200.
Parity - The parity bit setting used in the data transmission. This can be Even, Odd or None.

4.1.4. Protocol Configuration
Rack - The rack number in which the PLC is installed. The rack is only applicable to the S7-300 and
S7-400 PLCs. All the other PLC models have no concept of racks and is therefore always 0.
Slot - The slot number in which the CPU is installed. By default if using the S7-300 the PSU takes
slot 1 and the CPU slot 2. In the case of S7-400 you could get the PSU to take slot 1 and 2 and then
CPU is in slot 3. For S7-1200/S7-1500 the CPU is actually slot 1 as there is no actual bus system.
For the S7-200 the slot is always 2.
Type - (Default = PG) Options are PG(1) programming interface, OP(2) operator panel , S7(3)
standard Scada communications.
4.1.5. MPI/PPI Configuration
Local Address - Local MPI/PPI address, usually 0.
PLC Address - MPI/PPI address of the PLC.
Speed - The speed at which the MPI/PPI connection has been configured.
4.1.6. Test Device Configuration for Connectivity
This is used to check whether or not the configuration currently on the dialog can establish a
connection and communicate correctly with the PLC. Use this feature instead of having to start the
Agent Server only to find your configuration does not establish a connection or communicate
correctly with the PLC.
Test Address - The Siemens PLC address which the driver will attempt to scan.
IO Type - The Adroit type in which returned values from the PLC will be displayed in.
Start Reading - If this button is clicked, the driver will attempt to connect to the PLC using the
current configuration on the dialog and the driver datascope will automatically open. If the driver
does not connect or does not receive any information back from the PLC within 5 seconds, the scan
attempt will be deemed unsuccessful and an appropriate error message will be displayed in the
message box to the right of the button.
INFORMATION
Note, be sure to read messages on the device's datascope and read message box on the righthand side of 'Test Device Configuration for Connectivity'. These messages will help you determine
whether the device is operating correctly.
4.1.7. Watchdogs
Enable PLC program running check - Enable to activate.
This is a master side check that will force all I/O offline if the SPU is stopped and not the CP card.
Data will become latched and stale. Use this to check for activity.
Address DB:DBW any DBx:DBWy that has activity, if the value is stale in this register for more
than 1 second, all I/O on this device will be marked bad.

This is the most important screen of all. This is where we setup the connection to allow Adroit to
communicate to the PLC. The screen above is the exact setting required to make the communications
work. We want a server connection that allows the PLC to operate as the server and Adroit as the
client which connects and requests data from the PLC. The Local TSAP on this page refers to the
PLC TSAP settings. This setting is not changeable and when 'The server will connect with an Operator
Pane(OP)' is selected the TSAP will change to 02.00. This means the SLOT setting in the driver is 2
and RACK setting is 0. Also make sure 'Accept all connection requests' is checked. This will allow for
any IP address to create a connection to the PLC. The Remote TSAP properties refer to the PC TSAP
and always leave it as 02.01. Once ready click the OK button to continue to the next screen.
