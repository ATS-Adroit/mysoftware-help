The time that Adroit will wait for a valid response from a PLC before

Supported Data types are as follows:
PLC Data Type
Bool
Integer
NB All addresses with the Koyo DL205 PLC are expressed in Octal.
When reading or writing data to or from the DL205 the driver is actually always using 16 bit words. The
driver, depending on the prefix, will work out the type of data and get or put only the correct information.
For example when a digital input "X" prefix is used it can be mapped to any Adroit data type. The global
equivalent for X0 is V40400. This is a word and X0 to X20 (The next 16 bits) are stored here. This can be
read into any Adroit data type except BOOLEAN or any of its derivatives. The most efficient way of
reading or writing digitals is to use a multistate agent and read the global equivalent address.
Troubleshooting
During the installation of the driver the following files will be copied:
KDL205KS.DLL
The driver itself.
KDL205KS.PDF
The driver help file.
KDL205KS.WGP
KDL205KS.MIM
Once the driver has been installed and setup, run the REG file, you may then set the Adroit database file to
the KDL205KS.WGP and start the agent server.
When the agent server is ready, start the user interface and open the file KDL205KS.MIM. You will then
see a representation of a DL205 base unit with a 240 CPU, an input simulation module and an output
module.
The database will work with the 230 and 250 as well.
If all is installed correctly and the driver has successfully started, you will be able to see the inputs change
when the simulator module switches are changed and also will be able to change output states when the
output lights are highlighted and clicked.
This is the first thing to run when first setting up the unit. It can also be used as a training aid to see how the
unit works.
