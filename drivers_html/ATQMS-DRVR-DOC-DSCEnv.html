scanning thread adds the Adroit jobs to the read queue.

Address Descriptions
The addresses are either read only or write only. Read only
addresses are sent from the driver to Adroit in an unsolicited

manner. Write only addresses will be cleared (for example, to 0 if
digital or integer type and to “” if it is a string type) once the write
is complete.

Keypad Sequence (KEY)
[Write only address]. This address allows the driver to simulate a
keystroke sequence as if it were being pressed on a specific
partition's (1-8) keypad.
Only the following characters can be sent:
'1 2 3 4 5 6 7 8 9 * #'
If any other chars are found in the character sequence, the write
will fail.

Data:
This part of the message is variable length depending on the
command code sent, and contains the data required for the
command code.
Checksum:
The checksum is two characters wide. The checksum is calculated
by adding the hexadecimal value of all command and data digits,
then truncating the result to 8 bits.
Carriage return & line feed:
The carriage return and line feed control characters are appended to
the end of each message.
