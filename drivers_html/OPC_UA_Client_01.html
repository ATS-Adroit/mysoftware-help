Overview
OPC UA (OLE for Process Control Unified Architecture) is a standard specification that makes it
possible for automation/control software applications and field systems/devices to interoperate and
communicate data between each other.
To learn more about what OPC UA is, visit the OPC foundation website
https://opcfoundation.org/about/opc-technologies/opc-ua/
The OPC UA client driver for Adroit communicates to OPC servers that expose an OPC UA interface.
Connectivity
The OPC UA client driver communicates with OPC UA Servers in accordance with the OPC UA
Specification whose details are beyond the intended scope of this document.
Driver Installation and Setup
If the Adroit OPC UA Client driver is not installed, you will need to install it. Installation of this driver
for the first time will install the OPC Foundation's OPC UA reditributables if not already installed on
your PC.
The following files will be installed agent server folder:
d_opc_ua.dll
d_opc_ua.doc
as well as the following 3rd party dependency files:
libeay32.dll
libxml2.dll
If any of these files is not in the agent directory, then the driver did not install properly.
OPC UA Instance Certificates
The OPC UA specification requires that all UA clients have an instance certificate that positively
identifies client to the server. The instance certificate for Adroit OPC UA is automatically created on
the agent server PC when the OPC UA Protocl driver DLL is loaded by PSEXE or AS.EXE for the first
time.
The instance certificate can also be created manually by executing the %ProgramData%\Adroit
Technologies\Adroit\certs\create_instance_certificate.bat file which is found in the folder. Once the
batch file has completed, the following folders will have been created under the certs folder:

types should be the same.
OPC UA Server Certificates
The OPC UA specification requires that all UA clients trust the server certificate for the OPC UA
server that they are connecting to. By default, server certficates will be place in the
%ProgramData%\Adroit Technologies\Adroit\rejected folder when a client connects to the OPC UA
server for the first time. These must be manually copied to the %ProgramData%\Adroit
Technologies\Adroit\trusted folder before a successful connection will be allowed.

Connect To Server
Server name / Server IP address - This is the name or IP address of the machine on which an
OPC UA server discovery will be conducted. To initiate a discovery on the machine or IP
address entered, click on the refresh button.
Discovered Servers - This list displays all available OPC UA servers which are discoverable
on the machine or IP address specified in "Discovery Host Machine.
The [+] button allows you to enter a server manually that is not discoverable on the network if
the format opc.tcp://hostname:port e.g. opc.tcp://klaus:1234. Manual entries are stored as a
CSV entry in the registry value HKEY_LOCAL_MACHINE\SOFTWARE\Adroit
The [-] button allows you to remove the currently selected server, if it is a manually added
server.
If any of the servers displayed in "Discovered OPC Servers" are clicked on, then the "Connection
Details" will automatically populate with the selected server's details.
