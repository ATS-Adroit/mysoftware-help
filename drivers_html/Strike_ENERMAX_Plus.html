3. 
Device Configuration 
3.1. 
Device Configuration 
 
 
 
 
Comms Type – Select communications type: 
Select ‘Serial’ for Serial communications. 
Select ‘Ethernet’ for Ethernet communications. 
 
Serial ID – Serial identification number unique to the meter. 
 
Retry - The number of times that Adroit will try to gain communication with the meter before failing 
a transaction. 
 
Timeout – The time that Adroit will wait for a valid response from the meter before failing a 
transaction (Read or Write). Ensure proper timeout if using modem connection as it is much slower, 
where the maximum is 9600bps. 
 
Modem – Opens the Modem Dialog if using Modem Connection. 
 
Port – The available serial ports on your machine.

*2) The display reads numbers can be found in Emaxplus-CM-RDU-3rd-Party-0v01.xls 
Please remember that Dx:y , x is the row and you usually want to scan D2:y not 1 , which will give you the 
display name… but it can be scanned if you really want to… just use D1:y 
 
*3) 8 profile channels available as floating-point values, only Real/Analog agents will be supported for profile 
data. 
 
 WARNING 
Channels are dynamically ordered from the smallest period to the largest. If you add a channel or 
edit a channel in the meter, the SCADA MUST take this into account that channels positions could 
move. 
Example: channel 1 period = 10 minute sample rate, channel 2 = 30 minute sample rate, now you 
add channel 3 = 5 minute rate, then channel 3 will become channel 1 in memory, and the old 1 
and 2 will become 2 and 3 respectively. So, if channel 1 was VOLTS, and channel 3 was VARS, the 
next profile read, channel 1 would have VARS instead of VOLTS. This is like swapping two digital 
jumpers on a digital output card without telling the SCADA engineer to update the user interface 
– a wrong indication is presented. 
 
 WARNING 
Channels cannot be skipped in the read. So, for example, if channel 2 were to be deleted from the 
meter, the remaining channels would move down the list in this case channel 3 would move to 
channel 2. 
Profile modifiers: Modifiers can be added to a channel to modify the value before it is sent to 
Adroit. 
You can multiply(divide) a value and/or subtract(add) a value. (See Profile Modifiers Appendix.) 
 
*4) These are administrative registers used in advanced function that may require more than one type of data 
to be present before execution can take place, for example profile retrieval of multiple days. 
 
Admin area consists of 5 16bit registers only available to integer type agents such as Integer/Marshal. 
 
Register 0 (Address A:0) is not persisted data, will be reset when the Agent Server restarts. 
Register 1-4 (Address A:1-4) are persisted, so these will be preserved between Agent Server restarts, and 
there is no need to save WGP file manually, the data is persisted to the device config in the registry. 
 
Register 0 [bit packed 16 (unpersisted)] 
{ Bit 0 = Do time synchronisation (>20min will cause a fast set) 
 Bit 1 = Do profile read (will use Registers 2 and 3 for required parameters) 
 Bit 2 ... Bit 15 = not used yet.} 
 
Register 1 [bit packed 16 (persisted)] 
{ Bit 0 = Enable “fetch yesterday” profile data (uses Register 4 as time in minutes from 00:00 to start) 
 Bit 1... Bit 15 = not used yet.} 
 
Register 2 [unsigned short] = day offset from today for profile read (see bit 1 of register 0) (1 = yesterday) 
(0 = today) (>1 days further into the past)

Register 3 [unsigned short] = count of number of days to fetch from offset (Register 2) 
Examples: 
Reg2 = 1, Reg3=2, Reg0.1=1 (NB write Reg0 last) will result in a profile read for yesterday and today up to 
the last recorded value. 
Reg2 = 30, Reg3=15, Reg0.1=1 will result in a profile read from 30days ago for 15 days. 
 
Register 4 [unsigned short] = time in minutes to add to 00:00 as when to start a fetch yesterday. 
Examples: 
Reg4 = 120, Reg1.0 = 1 will result in a profile read to “fetch yesterday’s data” at 2:00am every morning. 
Remember Reg1.0 will be persisted.

7. 
Appendix A - Profile Modifiers 
 
Each channel’s address can be postfixed with a modifier to allow for manipulation of the value before 
it is sent and stored in Adroit. This is used to convert the profile reading from Raw values to True 
Value readings, additional ratios (CT/VT) could be added. 
 
Only 1 multiplier is allowable so True value factor must be merged with other multiplication 
requirements such as VT ratio etc. 
 
Additionally, only 1 subtractor is allowable. 
(Subtraction takes place after multiplication, if a multiplier is specified, else if only the subtractor is 
specified only that will be applied.) 
TVF – True Value Factor, CT – Current Ratio, VT – Voltage Ratio. 
 
Example: Profile 1 modified by TVF 0.01 (division by 100) 
“P:1 M0.01” 
P:n Mv – (P)rofile : (n)umber (M)ultiply by (v)alue. 
 
Example Profile 2 modified by TVF 0.01 and VT 10 
0.01*10 = 0.1 total. 
“P:1 M0.1” 
P:n Mv – (P)rofile : (n)umber (M)ultiply by (v)alue. 
 
Example Profile 3 modified by TVF 0.01 and subtract 400. 
“P:1 M0.01 S400” 
P:n Mv Sv– (P)rofile : (n)umber (M)ultiply by (v)alue, finaly (S)ubtracting a (v)alue.
