1. Overview
Adroit supports communication with the Mitsubishi FX PLC range, using the red Beijer RS-232/422
converter cable and other programming cables. MitFXS is designed to replace the existing MitsuFX
and MitsuFXS drivers which are discontinued (see Appendix A for compatibility with deprecated
drivers).
This driver also supports communication using Dial-Up Modem.
This driver also supports communication using "Serial over Ethernet" connection that wraps the serial
FX extended protocol into the data portion so as to be usable by Ethernet to serial gateways, the
protocol is not modified.

Retry - The number of attempts that Adroit will try to communicate with a PLC before failing a
transaction.
Timeout - The time that Adroit will wait for a valid response from a PLC before failing a transaction
(Read or Write).
PDU Length - Indicates the maximum number of bytes that will be requested in a single Transaction
from the PLC.
Use Single Protocol - This checkbox allows some of the protocol transactions to be combined and
sent through as a single transaction, this is sometimes necessary when using modems. This checkbox
is off by default and this option should only be used when necessary as the ACK/NAK/READY
commands will be combined with other messages and sent as in a single transaction.
This has the effect of not exceeding tight timing considerations for protocol such as the READY and
ACK transactions, which would otherwise be delayed due to delays produced by the modems.

3.1.5.
Test Device Configuration for Connectivity
This section is available to help users determine whether the settings they have entered are valid
and Adroit can communicate with the device. The Agent Server is not required to be running.
Test Address - An address in your device which will be polled when the "Read Address" button is
clicked. The address entered must be valid and will match the IEC or Standard Modbus addressing
scheme selected in the advanced dialogue.
IO Type - Defines the base address type to be read, i.e. Boolean, Integer, Real or String80.
Read Address - Click this button to poll the PLC with the current settings in the dialog.
Reply -The successful or failed result will be updated to this static text control.
