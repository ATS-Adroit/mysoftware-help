Tag to Database Field Mapping

Each transaction type requires a mapping between tagA fully qualified named value in Adroit (agentName.slotName)./s and the field name/s within the selected table in the connected database, except for the delete transaction. Each mapping consists of the following columns:

  1. Index: added to each mapping automatically and is a means of reference for the mappings used within the current table.
  2. Tag: either contains the tag that is setting or getting a value in the database or contains the time of the transaction itself.

Either type in the tag directly into this column or click on the column and use the displayed browse button (...) to browse in the required tag.

Note:To send the timestamp of this transaction to the database, click the Transaction Time button

  1. Field: the name of the field within the selected table in the connected database that is to receive or set the information in the Tag column.

Table names and field names should not contain spaces as each database vendor supports spaces differently.

Either type in the name of the field in the selected table directly into this column or click on the column and use the displayed browse button to browse in required field name from a list of all the fields within the selected table.

  1. Field format: an OPTIONAL column, unlike the Tag and Field columns, which is used to format the data from Adroit before it is sent to a database table.

For instance, specifying the format for a date/time field, or setting the number of decimal places for a numeric field. Different field format specifiers are available for formatting Real numbers , Integer numbers , Strings and Date/Time information .

Note: Use of single inverted commas are required for all formatted string type fields i.e. for all Date/Time Information specifiers and in any number specifier that contains formatted text. EXCEPT when using an Access 2000 database is being used (either directly or via an ODBC connection) to Retrieve data, from a table containing a dateTime field, in which case, encapsulate the date time field in #'s and not single inverted commas e.g. #%d#
