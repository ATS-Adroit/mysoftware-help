Management Information Tools

A number of tools are provided with Adroit to facilitate the organization and communication of information from operations to management.

Data can either be taken live from the Agent Server or collected from historical Data Logs. The data is then manipulated and reported by third party applications to provide relevant management information quickly.

The tools have been designed to retrieve data from Agent Servers belonging to more than one project, providing management with the ability to get an overall view of their operations. They use several data retrieval methods listed below:

DbAccess Agent

The DbAccess Agent that provides a link between Adroit and various external databases, by using OLE DB technology.

It is ideally used in applications where data inside the Agent Server is periodically written to a database (such as at the end of a batch job) for reporting reasons. It is not suited for fast logging of data.

OLE Interface (MISSRVR)

This OLE Server Interface , formerly known as the MISSRVR, forms the standard API (Application Programming Interface) for Adroit Agent Servers.

Adroit Server ActiveX Control

The Adroit Server ActiveX Control (adroitx.ocx) is provided as an alternative to the current Adroit Server OLE interface.

While it honors the current OLE Server interface, its prime feature is that of supporting subscriptions via an event interface.

Data Retrieval Utilities

Extracting Logged Data : retrieves information one or more DataLog agents, for a specified time period and converts this data into CSVComma Separated Value file containing data, which consists of a number of fields in one or more rows, in which the different fields (values) are typically separated by commas. file format, which can be opened by a third, party application such as Microsoft Excel and formatted to create reports.

Merging Data Logs : merges values from a CSV file into an existing historical database of DataLog agents

Putting Values into Agents : enables a specific value to be written to a specific agent’s slota value (attribute) or field within an agent that can be retrieved and/or set..

Tip: These utilities can be scheduled to perform their operations at specific times by using the Scheduler utility.
