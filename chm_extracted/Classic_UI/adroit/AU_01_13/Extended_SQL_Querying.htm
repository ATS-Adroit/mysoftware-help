Extended SQL Querying

If no row identifier is specified, then the selected (update, delete or retrieve) transaction could return multiple records and even if a row identifier was specified, the first record returned was always used for the transaction.

Note: It is assumed that the user is familiar with the SQL querying language and is able to perform SQL queries unassisted.

However it is also possible to specify which record is to be returned first, by adding the following commands to the SQL Query in the Identify Row edit box:

  1. In order for the DBAccess agent to use the first sorted record, append the following commands: $ORDER BY fieldname
  2. In order for the DBAccess agent to use the last sorted record, append the following commands: $ORDER BY fieldname DESC

Note1: "fieldname" refers to the name of the field by which the table will be sorted in ascending order (from the largest to the smallest)

Note2: Only add the "$" character if this is the ONLY SQL query command.

Furthermore, the SQL query in the Identify Row edit box, for both the retrieve and delete transactions, supports free SQL format queries, these are identified from the normal SQL queries by starting the SQL query with two ‘$’ characters.

Note: The update and insert transactions do not support free SQL format queries.

  1. This is an example of a free SQL format delete query:

$$DELETE FROM tablename WHERE fieldname=value1 OR fieldname=value2

Note: The "tablename" does not need to match the name of the table, currently specified in the Table name edit box.

  1. This is an example of a free SQL format retrieve query:

$$SELECT fieldname1,fieldname2 FROM tablename WHERE fieldname3=value ORDER BY fieldname4 DESC

Note1: The field name(s) used after the SELECT keyword (fieldname1, fieldname2), in retrieve queries must be the same as the field names specified in the tag to field mapping grid.

Note2: The "tablename" does not need to match the name of the table, currently specified in the Table name edit box.

Note: To test the syntax of the SQL query in the Identify Row edit box, click on the Trigger now button, then click the Details… button and check that this transaction succeeded in this dialog box.
