Tag to Field Mapping Buttons

To add a new tag-to-field mapping simply click the button.

To remove a tag-to-field mapping, click the button.

To send the timestamp of this transaction to the database, click Transaction Time button, either after adding another tag-to field mapping or selecting any cell of the mapping to be used for recording the time of the transaction.

This button will automatically replace the Tag field with ‘Transaction Time’, which will generate the time and date of the transaction in a format recognised by all databases.

Note1: By default the time that is generated by ‘Transaction Time’, contains millisecond resolution, which is NOT supported by the Date/Time fields in Access databases, use a Text field instead, if millisecond time resolution is required.

Note2: If an alternate time and date format is required, make use of the date/time field specifiers, but if this format is not recognised by the database then the entire transaction will fail.

Alternatively, both the analog and digital agents have a time slot that represents the timestamp of the value slot. This slot can also be sent to the database table if the timestamp is required.

Note: You CANNOT export DBAccess agents that contain single quotes (‘) in their format strings.
