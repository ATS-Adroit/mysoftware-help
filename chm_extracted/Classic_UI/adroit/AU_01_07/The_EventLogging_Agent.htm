The EventLogging Agent

The logging of events in Adroit is managed by the EventLogging agent, which is provided as a destination for one or more alarm routes. This agent is able to log events to the following locations:

  • to the Applications event log on any Windows computer on the network.
  • to an OLE DB compatible database, such as MS Access or MS SQL.

Note: Events logged to this database CANNOT be viewed in the Event Log Viewer window.

Typically, events include undesirable states, process values and the malfunction of control devices. Logged events are used to analyse process conditions over a specified period. Some of the types of events that can be logged by Adroit include:

  • incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). : agents going into alarm, being acknowledged and cleared
  • change monitoring events : when the values of Analog or Digital agents change that are configured for change monitoring
  • control events: any operator control action that is configured to log events, such as the opening or closing of a valve, changing the set-point of a process controller, recipes etc
  • system events: the start-up and shutdown of the Agent Server, communication failures, etc
  • jottings: typically notes entered by control staff via the Execute Command Behaviour to indicate an unusual event, occurrence or action.

For details on configuring the EventLogging agent, see Configuring the EventLogging Agent.

If logging events to an event log, then set the size of this event log large enough to contain and/or overwrite old events. 

Since this Applications event log is a standard feature of the Windows operating system, this is configured by Windows. For details, see Setting up the Event Log in Windows.

Adroit also provides additional event-specific settings, such as logging detailed Adroit system events for troubleshooting or changing the language of the event descriptions and categories. 

Instead of using the Windows Event Viewer to view these logged events, Adroit provides an Event Log Viewer window as an alternative, which allow you to perform the following functionality:

  • allows these events to be filtered
  • allows you to export the filtered events to a .TXT file.
  • allows you to save separate windows with their own filter view settings to .EFF files
  • allows you to archive the basic event log to .EVT files
  • allows you to print the logged events

For details, see Event Log Viewer Windows.
