Global Incident Destinations

The Eventlog route (global) destinations () section in the Routes tab of the Edit Alarm Agent dialog specify possible destinations for active incidents that apply to ALL Alarm agents. Click here for more details:in other words, route 2 of the defaultAlarmAgent routes incidents to the same Output(s) and EventLog(s) destinations as will route 2 of myAlarmAgent etc.

This section consists of the following categories:

Outputs, which allows you to report active incidents using the following destinations:

  • The AlarmManagement agent, which can collect and if necessary, configure incidents from one or more alarm agents and send them to an OLE DB compatible database, so they can be analysed to improve your alarm configuration.
  • The EventOutput agent, which can print incidents locally or remotely; save them to a .CSV file and if necessary, log them to an OLE DB compatible database for reporting and/or analysis purposes.

Tip: The EventLogging agent accessed from the Event Logs list provides the simpler method for logging incidents to an OLE DB compatible database.

  • The Notify agent, which can transmit incidents via SMSShort Message Service is a service (protocol) for sending short text messages to and from mobile phones. or a paging service direct to a designated person. This can inform off site personal of unacknowledged alarms and if necessary of process values and operator messages.

To add an Outputs destination:

  1. If necessary, edit the required Alarm agent, as follows:
    1. If necessary, add an Alarm agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.
  3. Select the Add button above the Outputs list in the Edit Alarm Agent dialog box.
  4. Browse for the required agent in its respective folder in the left pane of the dialog. For more details, see .

Tip: If necessary, you can create a new agent by clicking the Add… button.

  1. Click on the OK button.

To edit an Outputs destination:

  1. If necessary, edit the required Alarm agent, as follows:
    1. Select the name of this Alarm agent. For details, see To Select an Agent.
    2. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.
  3. Select the required agent in the Outputs list in the Edit Alarm Agent dialog box.
  4. Click the Edit button above this Outputs list to display the edit dialog of the selected agent.

To remove an Outputs destination:

  1. If necessary, edit the required Alarm agent, as follows:
    1. Select the name of this Alarm agent. For details, see To Select an Agent.
    2. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.
  3. Select the required agent in the Outputs list in the Edit Alarm Agent dialog box.
  4. Click the Delete button above this Outputs list to remove this entry from this list.

Note: This only removes the selected agent from the list and does NOT DELETE the agent from the Adroit agent database.

 

Event Logs, which allows you to report active incidents using the following destination:

  • The EventLogging agent, which can log incidents to the Windows Application event log on a specific computer and/or to an OLE DB database for reporting and/or analysis purposes.

Note: By configuring the EventLogging agent you can disable event logging from some or ALL alarm routes and can discard events based on the Alarm priority of the agent or incident.

Tip: This provides the simpler method for logging incidents to an OLE DB compatible database, than that provided by the EventOutput agent.

To log incidents to Windows event log on the Agent Server computer:

  1. If necessary, edit the required Alarm agent, as follows:
    1. If necessary, add an Alarm agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.

Ensure that the Event Logs list does not already contain an event log called “LOCAL”.

  1. Select the Add button above the Event Logs list in the Edit Alarm Agent dialog box.
  2. Check the Local computer checkbox in theSelect Computer dialog to use the event log on the Agent Server computer.

Note: ONLY select the My Computer item if the current computer IS the Agent Server computer.

  1. Click the Connect to button to log events to the Windows Application event log on the local computer.

This adds an event log called LOCAL to the Event Logs list of the selected route.

Note: If an event log called LOCAL already existed there will now be TWO such event logs in the list, in this case delete the second instance.

To log incidents to Windows event log on another computer on the network: this computer must be accessible by the Agent Server computer by using normal Windows security.

  1. If necessary, edit the required Alarm agent, as follows:
    1. If necessary, add an Alarm agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.
  3. Select the Add button above the Event Logs list in the Edit Alarm Agent dialog box.
  4. Expand the Entire Network branch until you locate the required computer in the Select Computer dialog.
  5. Click on the required computer.
  6. Click the Connect to button to log events to the Windows Application event log on the selected computer.

This adds an event log with the name of the selected computer to the Event Logs list of the selected route.

To remove an Event Logs destination:

  1. If necessary, edit the required Alarm agent, as follows:
    1. Select the name of this Alarm agent. For details, see To Select an Agent.
    2. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. If necessary, select the required route number.
  3. Select the name of the event log that you no longer require in the Event Logs list in the Edit Alarm Agent dialog box.

Tip: These event logs typically have the same name as the computer they connect to.

  1. Click the Delete button above this Event Logs list to remove this entry from this list.
