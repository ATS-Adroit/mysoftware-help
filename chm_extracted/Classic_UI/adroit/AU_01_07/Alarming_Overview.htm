Alarming Overview

The alarm system is a critical component for any process, which alerts your operators when components of the process are operating outside of their normal functioning.

Adroit provides a flexible alarming capability in that any slota value (attribute) or field within an agent that can be retrieved and/or set. of any agentan instance of an agent type, that stores data and typically provides the ability to operate or act on this data. can be alarmed. In this way any situations, ranging from plant upsets or process variable excursions to failures within the Adroit system itself can be monitored.

Alarming is managed by an Alarm agent, which communicates the incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). when they occur, to the relevant personnel and/or applications. You can announce an alarm by using one or more of the following methods:

  • by a siren or through the activation of audiovisual multimedia
  • by a list of unacknowledged and acknowledged alarms
  • by SMS or mobile pager messages or electronic sign display
  • by logging the alarm to an OLE DB compliant database
  • by logging the alarm to the Windows application event log
  • by printing the alarm to hardcopy
  • by launching a process-specific page of hypertext help
  • by graphical display on a mimic
  • by textual display on a mimic

In the past alarms were hardwired into the panels, which limited their number; now alarms are software-driven, which can lead to an unlimited number of alarms.

While one’s intention is often to keep the operators better informed by increasing the number of alarms, the result is that operators become overloaded and confused and may even start ignoring alarms! Therefore LESS alarms are MORE effective.

Alarm Management is therefore an important aspect of process control as it counteracts inefficient alarming. This allows you to create an alarming system that alerts the operator to the most relevant alarm for the current incident.
