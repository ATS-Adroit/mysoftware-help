The Beeper Agent

The Beeper agent provides simple audio output using the built-in PC loudspeaker and is usually controlled by an Alarm agent.

The beeping sound is started when the value in the start slot is set to an integer greater than zero.

The pitch or tone of the beeping sound depends on the contents of the start slot, and will become higher as it is incremented.

The Alarm agent puts a value equal to the number of current unacknowledged alarms into this slot, to indicate that more than one agent is in alarm at the same time.

Note: The pitch increases each time a new alarm is signaled, and decreases when an alarm is acknowledged.

When the start slot is set to zero, or the reset slot is pulsed, the beeping sound will stop.

The beeping sounds will become more urgent (i.e. interval between beeps will decrease) if the Beeper agent’s priority is increased from 0 to 4.

This is a useful feature if you wish to route high priority alarms with high priority settings to one Beeper agent and low priority alarms with low priority settings to another Beeper agent.

Normally, the contents of the start slot will not be saved to the loadfile (WGP file, by clicking the Save toolbar button or File menu item when the Configurator window is selected or when the Agent Server is Shutdown (if the SaveonExit advanced option is enabled).

To save the contents of this slot, check the Store values when saving checkbox, which sets the dataPersist slot to 1.
