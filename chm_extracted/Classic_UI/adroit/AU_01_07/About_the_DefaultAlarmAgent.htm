About the DefaultAlarmAgent

The defaultAlarmAgent Alarm agent is created by Adroit when a blank or empty Adroit database (.WGP) file is loaded. This Alarm agent provides 4 alarm routes, which should be used to route the following incidents:

Best Practice:  Always alarm agents from route 2 onwards never use routes 0 and 1. These routes are used internally by Adroit for reporting the system alarms and events.

  • 0: a predefined Adroit system route used for system alarms such as software faults and communication errors, which by default provides the following alarm destinations:
    • The alarm list of this Alarm agent, so these incidents can be viewed in an Alarm List Viewer window that is connected to the defaultAlarmAgent.
    • The default Beeper agent, aBeeper, which uses the PC speaker to audibly alert users to these active alarms.
    • The default EventLogging agent, eventLog, which records these active alarms to the Windows Application event log on the Agent Server computer. These events can be viewed in an Event Log viewer window on this computer.
  • 1: a predefined Adroit system route used for system events, which by default provides the following alarm destinations:
    • The alarm list of this Alarm agent, so these incidents can be viewed in an Alarm List Viewer window that is connected to the defaultAlarmAgent.
    • The default EventLogging agent, eventLog, which records these active events to the Windows Application event log on the Agent Server computer. These events can be viewed in an Event Log viewer window on this computer.

     

  • 2: this route is intended for reporting your activethe monitored condition of this incident (alarm/event) is still in effect and has not yet returned to its normal operating state. process alarms, in other words incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). that need to be acknowledged and ACTED UPON by the operator e.g. a tank level reaches a high level. By default, this route provides the following alarm destinations:
    • The alarm list of this Alarm agent, so these incidents can be viewed in an Alarm List Viewer window that is connected to the defaultAlarmAgent.
    • The default Beeper agent, aBeeper, which uses the PC speaker to audibly alert users to these active alarms.
    • The default EventLogging agent, eventLog, which records these active alarms to the Windows Application event log on the Agent Server computer. These events can be viewed in an Event Log viewer window on this computer.
  • 3: this route is intended for reporting your active process events, in other words any incident that is provided for INFORMATION ONLY e.g. if a set point value has changed. By default, this route provides the following alarm destinations:
    • The alarm list of this Alarm agent, so these incidents can be viewed in an Alarm List Viewer window that is connected to the defaultAlarmAgent.
    • The default EventLogging agent, eventLog, which records these active events to the Windows Application event log on the Agent Server computer. These events can be viewed in an Event Log viewer window on this computer.

We recommend that you also add an AlarmManagement agent to route 2 and 3 to configure and log these incidents to the same OLE DB compatible database.
