About Alarm Routes

An alarm route simply tells the Alarm agent how it must deal with active incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action).. In other words it specifies which reporting mechanisms (output destinations) this incident must use to effectively notify the relevant plant personnel and/or applications of its occurrence.

An Alarm agent can use one or more alarm routes to specify which alarm destinations to send the active incidents of the agents that it is monitoring. Where each route in an Alarm agent consists of two following elements:

Best Practice:  Always alarm agents from route 2 onwards never use routes 0 and 1. These routes are used internally by Adroit for reporting the system alarms and events.

  1. A route number, starting from 0. For details about and the recommended usage of the 4 alarm routes provided by the defaultAlarmAgent, see About the defaultAlarmAgent.

To add a route to an Alarm agent:

    1. Edit the required Alarm agent.
    2. Select the Routes tab from the Edit Alarm Agent dialog.
    3. Click the Add Route button to create a new route for this Alarm agent
    4. Specify the required destination/s for incidents that use this alarm route.

To use an existing route of an Alarm agent:

    1. Edit the required Alarm agent.
    2. Select the Routes tab from the Edit Alarm Agent dialog.
    3. Select the existing route number, from the Select route number list box.
    4. Specify the required destination/s for incidents that use this alarm route.

To remove a route from an Alarm agent:

    1. Edit the required Alarm agent.
    2. Select the Routes tab from the Edit Alarm Agent dialog.
    3. Select the required route number, from the Select route number list box.
    4. Click the Remove Route button.

Note: You can ONLY remove a route if NO alarm types have selected this route number. Otherwise a “Couldn’t delete routing message box is displayed.

  1. One or more route destinations (options) to report the incidents that are communicated via this route to the necessary personnel and/or applications. Click for more details:

    So if an alarm or event is assigned to a specific Route, it is automatically sent to ALL the destinations that are configured on this alarm Route.

    These alarm destinations are grouped into the following 4 main categories:

    Note: Each destination is typically managed by a specific agent type.

    The following two categories are specific to individual Alarm agents:

    Alarm Lists: The AlarmList agent, allows you to separate or combine your active incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). and/or to LOCALLY acknowledged them from one or more Alarm windows.

    Note: You CANNOT locally acknowledge the active alarms listed by an Alarm agent.

    Audio Devices:

    • The Beeper agent, which provides simple audio output using the built-in computer loudspeaker.
    • The MultiMedia agent launches a Windows compatible multimedia file, such as .WAV, .MID, .AVI or .RMI

    The following two categories apply to ALL Alarm agents:

    Outputs:

    • The AlarmManagement agent, which collects and if necessary, configure incidents from one or more alarm agents and sends them to an OLE DB compatible database, so they can be analysed to improve your alarm system.
    • The EventOutput agent, which can print incidents locally or remotely; save them to a .CSV file and if necessary, log them to an OLE DB compatible database for reporting and/or analysis purposes.
    • The Notify agent, which can transmit incidents via SMSShort Message Service is a service (protocol) for sending short text messages to and from mobile phones. or a paging service direct to a designated person. This can inform off site personal of unacknowledged alarms and if necessary of process values and operator messages.

    Event Logs: The EventLogging agent, which can log incidents to the Windows Application event log on a specific computer and/or to an OLE DB database for reporting and/or analysis purposes.

Note1: Each route can use different output devices or share the same output devices with other routes.

Note2: You can specify a different alarm route for each alarm type of the monitored agent.

These alarm destinations are classified according to their scope, as follows:

  •  LOCAL destinations, which are specific to the Alarm agent that is being used and so apply to all the agents that are being alarmed by this agent or
  • GLOBAL destinations, which common to ALL Alarm agents and so apply to ALL agents that being alarmed in this Adroit installation.

Local Incident Destinations: to select and manage incident reporting options SPECIFIC to each Alarm agents.

Global Incident Destinations: to select and manage incident reporting options COMMON to all Alarm agents.

Therefore, if your strategy involves using different Alarm agents to split other various sections of our plant up, these routes will be different but end in the same destinations e.g. same alarm list
