Agent List CSV File Format

This file is created when an Alarm agent is exported to store the agents which are alarmed by this agent. The filename adheres to the following naming convention: xxxxx- AGNTLST.CSV, where xxxxx represents the name of this Alarm agent.

This file consists of the following columns, from left to right:

  1. Tagname: the name of the agent that is being alarmed.

Note: This does not specify which slot (value) of this agent is being alarmed.

  1. Typeindex: this specifies the zero-based index number of the required alarm type.

This can be calculated when the required TYPLST.CSV file is opened in MS Excel, by subtracting two from the specified row number of the required alarm type.

For example if the required alarm type is in row 51, then its index value will be 49. For details of the format of this CSV file, see Type List CSV File Format.

  1. Route number: A valid route number from the route list file.
  2. Acknowledge: 1 is a normal acknowledgeable alarm, while 0 is an alarm that cannot be acknowledged.
  3. Reserved: 1
  4. Reserved: 0
  5. Reserved: 0
  6. Inhibit time: The future date/time when this incident (alarmed tag) will be re-enabled, as specified using the Inhibited until checkbox of the Alarming dialog. It is saved to the CSV as the two parts of a FILETIME variable e.g. if this is not set then the following value is saved: ",0 0"

Note: Inhibit times are DISCARDED when IMPORTING alarm configurations.

  1. Delay time: The number of seconds that the alarm system should wait, once this incident (alarmed tag)becomes active, before this incident is recognised as being ‘officially’ active.
  2. Conditional expression: An expression that must be true before this incident becomes active.
