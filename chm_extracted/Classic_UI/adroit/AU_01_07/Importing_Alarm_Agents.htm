Importing Alarm Agents

Bulk-alarming configuration can be performed by exporting Alarm agents, configuring them in a third party CSV editor and then importing them.

Alarm agents can be imported INDIVIDUALLY, using the Import… button in the General tab of the Alarm agent edit dialog.

Once this button is clicked, Adroit will look for the default import files for the selected Alarm agent in the current WGP file folder. These are the files that are created by Adroit when Alarm agents are exported.

If these default files are found, then the user will be prompted to perform either a full (automated) import using these files (Yes) or a selective (manual) import (No).

Note: If these files are NOT found then the Choose alarm types import file OR press 'Cancel' to bypass dialog is immediately displayed to perform a selective import. This same dialog is also displayed when No is selected in the Import alarm agent dialog.

Alarm agents can only be imported individually because unlike other agents, THREE separate CSV files are created for EACH of the configured Alarm agents.

It is therefore IMPORTANT to ensure that these 3 files are able to correctly relate to one another.

For instance, the alarm types listed in the xxxxx-TYPLST.CSV file are referred to, by index, in the xxxxx-AGNTLST.CSV file.

Therefore any alarm types added to the xxxxx-TYPLST.CSV file must be sorted in ascending order by column A and then column B. If not, the indexes in the xxxxx-AGNTLST.CSV file will be incorrect and will cause errors when importing this file.
