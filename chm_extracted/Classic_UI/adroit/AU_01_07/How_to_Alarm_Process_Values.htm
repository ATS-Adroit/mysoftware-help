How to Alarm Process Values

In Adroit, your process values (tags) are stored as slots within agents. You therefore alarm your process values by alarming the agent in which they reside.

To alarm an agent (process value):

For instance: we will alarm an agent called ANA001 of the Analog agent type, using the defaultAlarmAgent:the Alarm agent that is created by default by Adroit.  

Things to be aware of when alarming process values:

Since the Alarm agent manages the alarming of agents, you need to ensure that the Alarm agent you use provides the following:

  • Alarm routes that provide the required destinations (methods) to communicate these alarms or events to the relevant personnel.

In this case we will use the default configuration for alarm route 2 and 3 provided by the defaultAlarmAgent, which routes alarms to the LOCAL Alarm List (within the Alarm agent itself) where they can be displayed in the Alarm List Viewer window and the LOCAL event log, where they can be displayed in the Event Log Viewer window.

  • Alarm types that represent ALL the necessary alarm-able state/s for the agent type of the agent that contains this process value.

In this case we will use the default alarm types for the Analog agent type.

Tip: Is it recommended that you create an alarming strategya set of guidelines or a plan to optimise the configuration of the alarming of agents. Once created it can easily be transferred and adapted for other projects, as required. BEFORE you start alarming agents to determine how best this can be achieved.
