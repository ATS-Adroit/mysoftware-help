Configuring EventLogging Agents

The EventLogging agent manages the logging of events in Adroit and/or can log events to an OLE DB compatible database.

This assumes that the Edit EventLogging Agent dialog is open, which can be done, as follows:

  1. Select the default EventLogging agent called eventLog. For details, see To Select an Agent.
  2. Right click and select the Edit... menu item to display the Edit EventLogging Agent dialog.

Note: There is only one default instance of this agent per Agent Server, called eventLog.

To disable event logging for specific routes: Select the required alarm route number from the Select route number list box.

  1. Check the Disable this route checkbox.

To disable event logging from ALL alarm routes:

  1. Check the Disable all routes checkbox in the General Event Logging details section (set the totalDisable slot to 1).

To set the default alarm route that events are logged for ALL Alarm agents:

  1. Specify the number of the required alarm route in the Default Routing edit box (the defaultRoute slot) in the General Event Logging details section.

For more details about alarm routes, see About Alarm Routes.

 

To configure the MAXIMUM priority level of the EventLogging agent: this will DISCARD any event from an agent or incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). that has priority level LOWER than the configured level. This setting can be used to filter out unnecessary events, by simply not logging them.

  1. Specify the highest Alarm priority (an integer from 0 to 4)  in the Discard Level edit box (the discardLevel slot) in the General Event Logging details section.

Note: The default setting of 9999 disables this feature.

For details of configuring the Alarm priority setting for an agent or an incident, see Configuring Incident (Alarm) Priorities.

 

To log events to an OLE DB compatible database: this allows you to log events to an OLE DB compatible database preferably on the SAME computer as the Agent Server.

This allows you to use the in-built querying functionality of the database to assist you in performing queries on the logged events to analyse them.

Note: These logged events cannot be viewed in the Event Log Viewer window

  1. If necessary, check the Enabled checkbox in the Local OLE DB logging section.
  2. Click the browse button to the right of the Custom OLE DB connection edit box, to specify the required OLE DB compatible database. For details on specifying this connection string, see Connecting to an OLE DB database.

By default, Adroit deletes events older than 90 days from this database to ensure that the database does not become too large.

If necessary, specify the MAXIMUM number of days that you need to keep the logged events for in the Delete records older than edit box.

 

The Destinations section of this dialog displays which physical event log files (one per computer) and which EventOutput agents are allocated to each route.

Typically these are configured within the Alarm agent edit dialog. For details, see Global Incident Destinations.
