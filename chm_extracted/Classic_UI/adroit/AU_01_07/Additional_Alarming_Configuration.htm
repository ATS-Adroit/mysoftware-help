Additional Alarming Configuration

The alarming system in Adroit is very flexible and provides the following additional capabilities:

  1. Incident Acknowledgement: Acknowledgment of incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). is typically recommended for alarms i.e. all incidents that require some sort of reaction or attention from the operator.

    When you create incidents, you can specify whether it needs to be acknowledged before it can be removed from the Alarm List Viewer window.

  1. Prioritizing or Filtering Incidents: One way to ensure that your operators ONLY receive IMPORTANT alarms is to prioritise your alarms into categories of importance. Since some alarms are critical, whereas others are more informational in nature.
  1. Delaying Incidents: Delay an activethe monitored condition of this incident (alarm/event) is still in effect and has not yet returned to its normal operating state. incident from entering the alarm system to:
  2. prevent intermittent alarms from flooding your alarm system or to
  3. ensure that this alarm is raised when the operator needs to respond to it.
  1. Creating Conditional Expressions for Incidents: To implement first-up alarming, which ensures that each incident is unique and does not duplicate existing active incidents, which can unnecessarily distract your operators.
  2. Temporarily Suspending Alarming: Usually you need to do this when you are performing maintenance on a plant section or a particular item of equipment or when an alarm indicator is not functioning correctly or is being tested.
  1. Bulk alarming configuration: Bulk-alarming configuration can be performed by exporting Alarm agents, configuring them in a third party CSV editor and then importing them.
  2. Creating incident-specific documents: If you are using the AlarmManagement agent, you can specify an optional document that clarifies the incident and provides assistance on how to deal with it or react to it.

This document can then be launched from the Alarm List Viewer window. For details, see Configuring Listed Incidents.
