How to Use the Support Program

This application ensures that the correct and pertinent troubleshooting-related information is automatically supplied to the Adroit Support Desk so that your problems can be speedily resolved.

When a possible problem is detected in the operation of the Adroit application, use this Support program to gather together and compress the necessary Adroit files and ALSO provide a detailed description of the problem for the Support department, as follows:

Note: If possible, ensure that the Agent Server is running.

  1. Press the Windows key and start typing in the required application name and select it from the list, in this case:

    Support Program

  1. Now complete this Support dialog, giving as complete a description of the problem as possible.
  2. ONLY complete the Contact Details dialog, if this is the FIRST TIME that you are using the Support Program or details have changed, such as Adroit training that has recently been completed.
  1. Click the Create Report button to display a progress bar for this process.

Note: The More info required warning indicates that you have NOT specified a contact name and email address in the Contact Details dialog.

  1. If the Agent Server is NOT running, then specify the Serial Number of its HASP license in the displayed dialog.
  2. The Successfully created report dialog indicates that no problems occurred when creating this report.

Note: If an existing file has the same date and time, then the report file will not be created.

  1. Email this report file to the support department, as follows:

If you CAN send emails from this computer, then do the following:

  1. Click on the link provided by the Successfully created report dialog to automatically open and create the required email.
  1. Attach the specified .ZIP file in the specified folder (using the Insert File toolbar button).
  1. Send this email to specified email address.

If you CANNOT send emails from this computer, then do the following:

  1. Open the Start Menu and click on the Run… command.
  1. In the Run dialog type in the path to the required ZIP file, as specified in C:\Program Files\Adroit Technologies\Adroit\support
  1. Click the OK button to display this folder.
  1. In this folder, locate the .ZIP file, which has the following format support(day-month-year)Hour-minute.zip, select the .ZIP file with the current date and the most recent time.
  2. Copy this ZIP file to a computer that has email and manually open an email message, attach this ZIP file and add an appropriate Subject Line.
  3. Type the Adroit Support email address into the Address edit box.
  1. Send this email to specified email address.

The Adroit support department will contact you as soon as they receive this file and will keep you informed regarding the progress of your Adroit query.
