Import Master Recipe

This is used to import a master recipe and its associated control recipes from a .CSV file.

Note: When importing recipes, the CSV file that is being imported CANNOT contain ‘%’ characters, if these characters are present then the file will not be imported.

After selecting the appropriate CSV file, click OK to import the master recipe and the requested control recipes. The master recipe is always imported, and the existing master recipe is overwritten. Select an option under Control Recipes: to regulate which control recipes to import. The options are:

  • Import All. Import all of the control recipes in the CSV file. Any already existing control recipe will be overwritten. New control recipes will be added.
  • Import New. Import only new control recipes. Hence, no existing control recipe will be overwritten.
  • Import None. No control recipes found in the CSV file will be imported.

Note: This importing can also be achieved by setting the recipe agent’s "importName" slot to the full path and filename of the CSV file that is to be imported.
