Phase Actions and Tag/Value of a Master Recipe

A phase always ends with a Phase Action, and therefore may have several ingredient steps preceding it. A phase action can be any of the following keywords:
 GOTO STEP <step number>; DELAY <milliseconds> or VARIABLE.

  • A GOTO STEP action will cause an active recipe to jump to the step given in the Tag/Value field. The Tag/Value for a GOTO STEP action may either be an explicit step number or an agent.slot that holds the step number.
  • A DELAY action will delay the execution of an active recipe by the number of milliseconds given in the Tag/Value field.

Note: The Tag/Value for a DELAY action may either be an explicit delay time or an agent.slot that holds the delay time.

  • A VARIABLE action will alter recipe execution based on the value of the agent.slot given in the Tag/Value field, as follows:
Slot value Action

0

Wait until the slot value changes to a value between

1 and 6 and then perform the action associated with this number

1

Go to next step

2

Go to previous step

3

Go to first step

4

Go to last step

5

Perform verification failure rollback

6

Stop recipe execution

Note: the Tag/Value for a VARIABLE action is usually an expression or a slot that returns a Boolean value. The Tag/Value field may also be an explicit number between 0 and 6. This is usually done to force the end of a phase and thus ensure verification checking to take place.
