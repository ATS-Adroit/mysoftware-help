Test Control Recipe

Test the validity of the selected control recipe.

The following errors that will cause recipe execution to fail are reported:

Error message - "Control recipe ingredient [agent.slot] not found".
The control recipe ingredient was not found in the Agent Server. The agent has either not been added or is misspelled.

Error message - "Master [agent.slot] and control recipe [agent.slot] ingredients are not equal".
The control recipe ingredient for a step must be the same as the master recipe ingredient. In this case, check that the control recipe is valid for the current master recipe.

Error message - "Control recipe ingredient must be a Boolean, Real, Integer, String or a VarString".
The control recipe ingredient type is not supported. (a VarString is a character array whose size can be variable - see document AU-05 "Agents Types and Structures")

Error message - "Control recipe ingredient value [value] is invalid".
This occurs when attempting to set a control recipe ingredient to an illegal value, e.g. setting a real number to a string.
