The Recipe Agent

A Recipe agent consists of a master recipe and one or more control recipes. This can be used to defines how the control system is to process its raw materials to make the desired product and byproducts.

Description of recipe agent.

Note: Names used in the recipe agent e.g. to define recipes and batches, CANNOT contain the ‘%’ character.

The Master Recipe consists of all the process variables or "ingredients" and the sequence in which they are to be downloaded. It is here that the procedure and associated tag names will be defined.

Components of a Master Recipe.

Editing the Master Recipe.

Each Control Recipe will contain specific quantities and values for customizing the Master Recipe for a given production run, thus allowing a plant to produce variants of its base product; for example, differing colors of paint, different flavors of cola. For each master recipe, there may be one or more Control Recipes.
