Advanced Script Agent Properties

This dialog allows an initialization and a clean-up subroutine to be specified, which are separate from the main subroutine and can be executed when needed.

This dialog box is divided into the following sections:

  1. Initialization subroutine: This subroutine can be used to initialise global variables, establish database connections, or to open file handles. Its called directly after a script has been compiled i.e. after the Agent Server has started up or whenever the agent is modified from within the Agent Configurator.

This subroutine can be used to perform the initialization normally performed on Agent Server startup; this is particularly useful for triggered scripts that are only executed when a trigger tag changes after the Agent Server starts up.

The browse …button next to the edit box, allows the selection of the initialization subroutine from the list of available subroutines in the added modules.

The run button, will execute the initialization subroutine.

  1. Cleanup subroutine: This subroutine can be used to close all open database connections, or to close all open file handles, etc. The cleanup subroutine gets called directly as soon as a script is completed.

The browse … button next to the edit box, allows the selection of the clean-up subroutine from the list of available subroutines in the added modules.

The run button, will execute the cleanup subroutine.
