Recipe Agent Description

A recipe is a statement of the ingredients and procedures necessary for the making or compounding of some preparation or formulation. It defines how the control system is to process its raw materials to make the desired product and byproducts.

In Adroit, this is achieved by the Recipe agent which provides the means for automatically downloading information to process variables. These variables allow a plant to produce the final product. Mundane tasks can be automated saving time and removing the element of human error.

In common with modern industry practice (SP88), the recipe agent consists of a master recipe and one or more control recipes.

Note: Names used in the recipe agent e.g. to define recipes and batches, CANNOT contain the ‘%’ character.

The Master Recipe consists of all the process variables or "ingredients" and the sequence in which they are to be downloaded. It is here that the procedure and associated tag names will be defined.

Each Control Recipe will contain specific quantities and values for customizing the Master Recipe for a given production run, thus allowing a plant to produce variants of its base product; for example, differing colors of paint, different flavors of cola. For each master recipe, there may be one or more Control Recipes.

For example, the Master Recipe could describe a Fruit Juice mixing plant. Several Control recipes would provide the data to manufacture various flavors and mixtures of fruit juice such as Orange, Mango, Pineapple, Mango and Orange, Pineapple and Orange etc.

The Adroit recipe system allows:

  • Each Control recipe to be assigned a batch identification.
  • Accumulation of batch histories through event logging.
  • Downloading of process variables that are of type Boolean, Integer, Real or String.
  • The sequence of execution to be delayed by a specified amount of time, to be paused until a desired condition in the plant is met, or to be redirected to another step.
  • Master recipes and Control recipes to be imported or exported to files using the comma separated variable (CSV) format, for ease of viewing and editing by 3rd party products (e.g. Excel).
  • The progress of a working recipe to be monitored.
  • Verification of the values scanned out to PLC.
  • Optional Rollback can be performed should the verification fail.
