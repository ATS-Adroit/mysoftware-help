Agent Templates

You can create one or more Agent template per agent type to specify (customise) your own default slot values, when this template is used to create an agent of this type.

Note: The Connector used by the Adroit DB Generator utility to connect to the required source (3rd party application) determines whether templates can be used or not.

Usage example:

For instance, you can create a template for Analog agents that represent 12 bit A to D water temperature signals from a PLC.

In this case, you will create an Analog agent template, possibly called 12BWATERTEMP. Then you would set the default values for its rawMax and engMax slots of 4095 and 100 respectively.

Each time an Analog agent is created using the 12BWATERTEMP template; these default slot values are used.

Default templates:Agent templates are added for the Analog and Digital agent types called _AnalogDefault and _DigitalDefault respectively, providing the Adroit default settings, which you can customise accordingly.

 

To create an agent template for a new agent type: this creates an agent template for an agent type that is not yet listed beneath the Templates folder, this also adds the selected agent type as its own category to the Templates folder.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Templates folder.
  2. Select the Create template… menu item.
  3. Click the to the right of the Agent Type list box.
  4. Select the required agent type.
  5. Type in the Template name that you want to create for the selected agent type.

Tip: Provide a brief name that makes it easy to identify the purpose of this template.

  1. Click the OK button.

The specified agent type is added as a separate agent template category beneath the Templates folder, containing the name of the added template.

The configuration dialog for this agent type is launched so that you can specify the default values of the displayed slots for the specified template.

  1. Click OK once you have finished configuring the new default configuration of this dialog.
  2. Click Yes to Retrieve All Changes, which retrieves ALL the changes you have made to this dialog.

Note: If you click No then NONE of your changes are saved and the template simply uses the usual default values.

The modified slots are displayed in the right hand pane, with their new Default value.

  1. If necessary, delete any slots whose values you DO NOT want to change or change the default values of these slots.

To delete a slot from the agent template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

To edit the value of a slot in the agent template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

Tip: Provide a brief name that makes it easy to identify the purpose of this template.

To edit an agent template: to change (add, delete or modify the new default slot values) of an existing agent template.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required agent template in the required agent type category in the Templates folder.
  2. Select the Edit template… menu item to launch the configuration dialog for this agent type.

You now have the following TWO editing options available:

If you want to change ALL the existing default slot values for this template: this method ONLY ADDS the slots that you change in the edit dialog, any existing slots that are UNCHANGED will be REMOVED.

  1. Edit ALL the fields of this dialog that you want DIFFERENT default values for.
  2. Click OK once you have finished configuring the new default configuration of this dialog.
  3. Click Yes to Retrieve All Changes, which retrieves ALL the changes you have made to this dialog.
  4. Only the slots that you have modified in the dialog are added to the right hand pane, with their new Default value.
  5. If necessary, delete any slots whose values you DO NOT want to change or change the default values of these slots.

To delete a slot from the agent template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

To edit the value of a slot in the agent template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

If you ONLY want to MODIFY a few of the EXISTING default slot values: this method ensures that the slots you have ALREADY added to this agent template are NOT REMOVED, so that their values can be manually modified.

  1. Click OK immediately – do NOT edit ANY of the fields of this dialog.
  2. Click No to Retrieve All Changes, as you do not want to remove the existing slots of this template.
  3. The EXISTING slots of this template are displayed in the right hand pane.
  4. If necessary, delete any slots whose values you DO NOT want to change or change the default values of these slots.

To delete a slot from the agent template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

To edit the value of a slot in the agent template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

To add a slot to an agent template: typically to add a new slot value to an existing agent template, so that you can specify its required default value.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required agent template in the required agent type category in the Templates folder.
  2. Select the Add slot… menu item to launch the Add template slot dialog.
  3. If you want to add ANOTHER existing slot to this agent template, then CLEAR the Display unused slots only checkbox (as is the case when you are configuring multiple values for the Stringlist agent).
  4. Select the required slot from the Slot name list box.
  5. Click the OK button to add this slot to the list of slots in the right hand pane.
  6. Double click this Slot entry in the right hand pane.
  7. Provide the required default value for this slot in the Edit template slot value dialog.
  8. Click the OK button.

However, this can also be used to add another existing slot value to an agent template.

For instance, in the case of Stringlist agents, this allows you to specify which individual strings to use in the Stringlist agent by creating multiple index and value entries.

To delete an agent template: to remove an existing agent template.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:
