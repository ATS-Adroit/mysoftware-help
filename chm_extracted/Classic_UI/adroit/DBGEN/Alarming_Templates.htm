Alarming Templates

You can add Alarming templates to configure the alarmthe process of monitoring an agent for the occurrence of a specific abnormal condition or state (alarm type). settings for one or more alarm types, which are usually manually specified when alarming agents.

Alarm types, in Adroit, define the conditions or states of your process values (agents) that are set when they no longer operate within their normal operating range.

Note: The Connector used by the Adroit DB Generator utility to connect to the required source (3rd party application) determines whether templates can be used or not.

Usage Example:You can create an alarming template for a particular agent type, like Analog agents and pre-configure the required alarming settings for each of their default and/or custom alarm types, to save your users engineering time.

Default templates:Since these templates are alarm type-specific, NO default template can be created.

Each alarming template allows you to specify ONE alarm agent that is used to monitor the alarm types that you specify. Then you can specify the following settings for EACH alarm type:

  • The name of the alarm Type: The string defining the alarm agent, which is MANDATORY as there is NO default value for this, hence the “?” is displayed in the Default value column for this field.

Note: This string is CASE SENSITIVE; please provide the EXACT case and combination of letters that specify the required alarm type.

  • The required Route, which specifies the required mechanisms (agents) used to report this incident to the necessary personnel and/or applications. Click here for more details:
    • The Adroit default for this is 2, which is the route specified for process alarms, which is any incident that requires remedial action from an operator.
    • If this alarm type, specifies an event i.e. an incident that is for information only and requires no input from an operator then assign it to route 3 of the defaultAlarmAgent, which is intended for all process events.
  • The Acknowledge required status: The Adroit default for this is 1. Process alarms should have this set to 1, while process events should have this set to 0.

 

To create an alarming template: this creates an alarming template for the Alarming category that is listed beneath the Templates folder.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Alarmingcategory within the Templates folder.
  2. Select the Create template… menu item.
  3. Type in the required Template name.

Tip: Provide a brief name that makes it easy to identify the purpose of this template.

  1. Click the OK button.

This selects and adds this template to the bottom of the list of templates beneath the Alarmingcategory.

The default alarming-specific settings (slots) for the alarm type specified by this template are displayed in the right hand pane.

  1. Provide the required settings (slots) for the alarm type specified by this template, as follows:

Note: Ensure that this alarm type exists in the Alarm agent specified by this alarming template.

To change the value of a slot in the alarming template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

To delete a slot from the alarming template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

Note: If you delete one of these slots then the Adroit default value will be used.

WARNING! You should NOT delete the alarm type, as all the settings relate to this.

Note: By default only ONE alarm type is specified.

To add another alarm type to an alarming template: by default each alarming template provides a single alarm type for a specific Alarm agent, although you will usually need to add more alarm types. 

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required alarming template in the Alarmingcategory in the Templates folder.
  2. Select the Add type... menu item.

The default alarming-specific settings (slots) for the new alarm type are displayed in the right hand pane (see above for a detailed description of each one).

  1. Provide the required settings (slots) for this alarm type, as follows:

To change the value of a slot in the alarming template:

  1. Double click the required Slot entry in the right hand pane.
  2. Provide the required default value for this slot in the Edit template slot value dialog.
  3. Click the OK button.

To delete a slot from the alarming template:

  1. Right click the required Slot entry in the right hand pane.
  2. Select the Delete slot menu item.

WARNING! The selected slot is IMMEDIATELY removed.

Note: If you delete one of these slots then the Adroit default value will be used.

WARNING! You should NOT delete the alarm type, as all the settings relate to this.

Note: Ensure that the alarm types that you add, exist in the Alarm agent specified by this alarming template.

To sort the list of alarming templates: by default each template is added to the end of the existing list of alarming templates, it is possible to sort this list, alphabetically, in ascending order, to make it easier for users to select the templates. 

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Alarmingcategory within the Templates folder.
  2. Select the Sort menu item.

This rearranges the list of alarming templates alphabetically, in ascending order.

To delete an alarming template: to remove an existing alarming template.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the required alarming template in the Alarming category in the Templates folder.
  2. Select the Delete template… menu item.

The selected template is removed from the list of templates.
