Available Connectors

This lists the available Connectors and their specific functionality and configuration of their Links, such as their support and/or implementation of templates.

  • CSV Connectors are complex Connectors, in that they are not device-specific but instead can globally configure agents and can create a fully configured Adroit agent database (.WGP file) via four CSVComma Separated Value file containing data, which consists of a number of fields in one or more rows, in which the different fields (values) are typically separated by commas. files.

Template support: Yes

Link configuration dialog: No

  • Mitsubishi GX Developer Connectors are device-centric connectors that configure agents from the MxChange tags within a CSV import file that is exported from Mitsubishi GX Developer.

Template support: Yes

Link configuration dialog: Yes

  • Mitsubishi IEC Developer Connectors are device-centric connectors that configure agents from a CSV file that you need to create from the Excel tag configuration file exported by the Mitsubishi IEC Developer.

Template support: Yes

Link configuration dialog: Yes

  • OPC Connectors are device-centric connectors that configure Analog, Digital and Text agents from the items within an OPC Server and also configure the scanning of these agents.

This Connector can connect to remote OPC Servers if the DCOM configuration permits this.

Template support: No

Link configuration dialog: Yes
