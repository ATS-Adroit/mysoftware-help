Creating a WGP file From a 3rd Party Application

The Adroit DB Generator creates Adroit agent databases (.WGP files) from information stored in 3rd party applications, such as front-end devices.

Things you need to know beforehand:

  • Have you installed this utility from the Additional Adroit Components installation?
  • Does the required Connector exist for the 3rd party application that you want to create a .WGP file for?
  • Has this Connector (DLL) file been added to the required Agent Server?
  • Can this Connector be accessed remotely or do you need to use the Adroit DB Generator on the Agent Server computer on which the required 3rd party application resides.
  • Does this Connector support the use of templates? Templates can be used to customise or fine-tune your agent creation, scanning, logging and/or alarming default settings.

How to create a WGP file from a 3rd party application

  1. Press the Windows key and start typing in DB Generator and select it from the list.
  2. If necessary, add the required remote Agent Server.

Note: ALL the available Connectors of this Agent Server are displayed, whether they can be accessed remotely or not. If necessary, create a Link for the required Connector.

  1. If a Configuration dialog is displayed, configure this Link.
  2. Right click the Link and select the Import menu item to retrieve the complete configuration for the Link.
  3. Perform any post editing that is necessary, such as the implementation of any templates, if these are supported for this Link.
  4. If necessary, configure the global options that determine the default actions that are performed in Adroit after committing an import. These options are used for ALL the connectors. For details, see Global Post Committing Options.
  5. Right click the Link and select the Commit menu item to generate an agent database (.WGP) file from the current Link configuration files.

Note: When DBGen starts it obtains the connectors specified from a previous session from the DBGEN.INI file. If this DBGEN.INI file does not exist, then the connectors are obtained from the selected computer’s Adroit installation folder, typically: C:\Program Files\Adroit Technologies\Adroit.
