About the Connector Links

The Adroit DB Generator requires a specific Connector to connect to and access the information stored in each required database of the 3rd party application.

Each Connector can create one or more Links that connect to the specific applications and are configured to create .WGP files from them.

Once a Link has been created, the following options may be available:

To configure a Link: this launches a Connector-specific dialog to perform Connector-specific configuration.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Configure Link… menu item. 
  3. If this Connector provides a configuration dialog then this is displayed.

Note: Not all Connectors support this option.

To import configuration for the Link: to retrieve the complete configuration for the Link and to optionally commit the necessary configuration on the Agent Server.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Import menu item. 

The imported configuration is available for post editing before this is committed to the Agent Server.

Note: Not all Connectors support this option.

To get changes for the Link: to retrieve all changes since the last operation for the Link and to change the configuration on the Agent Server..

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Get changes menu item. 

This imported configuration can be further configured, before this is committed to the Agent Server.

Note: Not all Connectors support this option.

To commit the configuration of the Link: Having completed an import or “get changes” and any subsequent editing of the configuration, this option will commit the current configuration to the Agent Server.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Commit menu item. 

Note: Not all Connectors support this option.

To export configuration for a Link: this allows you to retrieve the complete Agent Server configuration and to export the configuration for the currently selected Link.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Export menu item. 

Note: Not all Connectors support this option.

To delete a Link: you can ONLY delete an Agent Server once ALL the Links of ALL its Connectors are removed.

  1. Press the Windows key and start typing in DB Generator and select it from the list.

In the explorer type view on the left of this application:

  1. Right click the Link of the required Connector on the required Agent Server computer.
  2. Select the Delete Link menu item. 

WARNING! The selected Link is immediately removed.
