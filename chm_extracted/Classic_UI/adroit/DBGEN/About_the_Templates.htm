About the Templates

Templates can customise or fine-tune your agent creation, scanning, logging and/or alarming default settings, when using the Adroit DB Generator to create Adroit agent databases (.WGP files) from information stored in 3rd party applications.

The Connector used by the Adroit DB Generator utility to connect to the specific source (3rd party application) determines whether templates can be used or not.

Note: Connectors that supports templates, implement them differently by using the features and fields of information available to this Connector’s specific 3rd party application.

 The following four template types are displayed in the left hand explorer type pane of the Adroit DB Generator utility, within the Templates folder:

  1. Agents : You can create one or more template per agent type and configure the required default slot values that should be used when an agent of this type is created when using this template. For more details, see Agent Templates.
  2. Scanning : You can specify the default scanning (communicating) parameters that are specified in the Tag scanning configuration dialog, when scanning the slots of agents in Adroit. For more details, see Scanning Templates.
  3. Alarming : You can configure the default alarming settings that are used per alarm type (an alarmed condition or state within an agent). For more details, see Alarming Templates.
  4. Logging : You can specify the default logging configuration for each log set. For more details, see Logging Templates.

 

Available Connectors: this lists the available Connectors and their specific functionality and configuration of their Links, such as their support and/or implementation of templates.
