About CSV Connectors

CSV Connectors are complex Connectors, in that they are not device-specific but instead can globally configure agents and can create a fully configured Adroit agent database (.WGP file).

Each CSV Connector Link creates four CSV files that can be configured to provide the information necessary to configure a WGP file. Each of these files can create agents and are located in the CSV subfolder of the designated project folder, which is typically C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\CSV.

Link configuration:This Connector does NOT provide a Link configuration dialog. Since the four CSV filenames automatically use the name of the Link ,as follows:

If the Link name is AS1 then the associated CSV filenames are:

  • AS1.agents.csv: the agent definition file (see below)
  • AS1.scanning.csv: the scanning definition file (see below)
  • AS1.alarming.csv: the alarming definition file (see below)
  • AS1.logging.csv: the logging definition file (see below)

Template implementation: Specify the applicable template names in the designated columns within the four CSV files.

 

The agent definition file: This file should ONLY contain those agents that have not been alarmed, scanned or logged. Each agent is specified by the following 4 columns:

Note: ONLY the first TWO columns are REQUIRED.

  1. Agent Name: The name of the agent that you want to create. For instance, ANA001 or DIG001.

Note: Please ensure that you adhere to the Adroit agent naming conventions when specifying this name.

  1. Agent Type: The type or category of this Agent Name, most often this corresponds to the required data type, such as Analog or Digital although this can specify a more complex agent such as Counter or Expression etc.
  2. Agent Template: If necessary, specify the name of the agent creation template that customises the default values (slots) of this Agent Type.
  3. Description: If necessary, specify a brief description of the intended purpose of the Agent Name, which is purely for information purposes.

Note: This file does not need to contain any agents that are defined in any of the other scanning, alarming or logging definition files. 

The scanning definition file: This file should contain all your process values that you want to configure for scanningthe process of communicating a value (slot), typically to and/or from a front-end device (FED).. Each process value that you want to communicate is specified by the following 11 columns:

  1. Agent: The name of the agent that you want to scan. For instance, ANA001 or DIG001.

Note: Please ensure that you adhere to the Adroit agent naming conventions when specifying this name.

  1. Agent Type: The type or category of this Agent, most often this corresponds to the required data type, such as Analog or Digital although this can specify a more complex agent such as Counter or Expression etc.
  2. Agent Template: If necessary, specify the name of the agent creation template that customises the default values (slots) of this Agent Type.
  3. Device: The name of the device, configured in Adroit Setup (PSEXE) that communicates to the required FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..
  4. Slot: The name of the slota value (attribute) or field within an agent that can be retrieved and/or set. of this Agent that you want to scan.
  5. Address: The address within the FED (Device) that this Slot (value) should be communicated to/from.
  6. Rate (msecs): The time, in milliseconds, which will elapse before this value is communicated to or from this Device.
  7. Deadband: The deadband limit for this value. Any CHANGE in value LESS than this deadband limit will NOT be communicated.
  8. Output (0/1):  To enable or disable the output enable setting for this scanned value. If enabled (1) then this value can be written to this Device (FED).

Note: This setting does not prevent this value from being updated by the FED.

  1. Inhibit (0/1): To enable or disable the scan inhibit setting for this scanned value. If enabled (1) then this value CANNOT be changed by this Device (FED).

Note: This setting does not prevent this value from changing the value in the FED.

  1. Template: If necessary, specify the name of the scanning template that customises the default values for the following columns of this file: Slot, Rate (msecs), Deadband, Output (0/1) and/or Inhibit (0/1) and can ALSO specify a scanning suffix for the Address.

Note: If you are using a template, then ONLY specify these columns if they DIFFER from the default values provided by this template.

The alarming definition file: This file should contain all your process values that you typically want to alarmthe process of monitoring an agent for the occurrence of a specific abnormal condition or state (alarm type).. Each alarm typea named (abnormal) condition or state of an agent that is defined by which of its status bits are simultaneously ON or OFF, which can also list the slots of this agent to report when this condition occurs. required by a process value is typically specified by the following 8 columns:

  1. Agent: The name of the agent that you want to alarm. For instance, ANA001 or DIG001.

Note: Please ensure that you adhere to the Adroit agent naming conventions when specifying this name.

  1. Agent Type: The type or category of this Agent, most often this corresponds to the required data type, such as Analog or Digital although this can specify a more complex agent such as Counter or Expression etc.
  2. Agent Template: If necessary, specify the name of the agent creation template that customises the default values (slots) of this Agent Type.
  3. AlarmAgent: The name of the Alarm agent that monitors the specified Agent for the condition specified by this alarm Type.
  4. Type: The alarm type or condition within this Agent that is being monitored by the specified AlarmAgent.
  5. Route: The route within the specified AlarmAgent to send incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). when that becomes activethe monitored condition of this incident (alarm/event) is still in effect and has not yet returned to its normal operating state..
  6. Ack (0/1): The status of the acknowledge required option for this alarm type.
  7. Template: If necessary, specify the name of the alarming template that customises the default values for the following columns of this file: AlarmAgent, Type, Route and Ack (0/1).

Note1: If you are using a template, then ONLY specify these columns if they DIFFER from the default values provided by this template.

Note2: This template can configure one or more alarm types for the specified Agent.

Note: Agents (process values) requiring more than one alarm type are typically defined as separate entries in this file, unless the specified alarming template provides multiple alarm types.

The logging definition file: This file should contain all your process values that you typically want to logalso known as data log, the process of recording the changes in a value over time to a log file or OLE DB compatible database.. Each log setthis provides the ability to log the same slot (value) to a different destination and/or use a different logging rate and/or use a different logging period. required by a process value is typically specified by the following 11 columns:

  1. Agent: The name of the agent that you want to log. For instance, ANA001 or DIG001.

Note: Please ensure that you adhere to the Adroit agent naming conventions when specifying this name.

  1. Agent Type: The type or category of this Agent, most often this corresponds to the required data type, such as Analog or Digital although this can specify a more complex agent such as Counter or Expression etc.
  2. Agent Template: If necessary, specify the name of the agent creation template that customises the default values (slots) of this Agent Type.
  3. Slot: The name of the slot of the specified Agent that you want to log.
  4. Set: The zero based index of the required set. In other words a value of 0 indicates the first set; 1 indicates the second set; etc.
  5. Destination: the location for the records of this Slot for this log Set. This is determined by the method you are using to log this value, as follows:
    • Proprietary Adroit log files: the full path and file name of the required log (.LGD) file  and
    • OLE DB-compliant database: the connection string to the required database.

    Tip: It is recommended that you copy this connection string from another application instead of manually typing it in, due to its complexity.

  6. Period (days): The required length or time period for logging this Slot for this log Set in days.
  7. Rate (secs): Specify how often to log this Slot for this log Set in seconds, also known as the time deadband, since if the Slot changes more than once during this period then the specified Algorithm is used to determine what value is actually recorded.
  8. Deadband: The Slot (value) deadband limit, which is the MINIMUM amount which ANY change in this value must EXCEED in order for it to be logged for this log Set.
  9. Algorithm: If you are using a Rate (secs) greater than 0, this algorithm determines the value that is logged when this value (Slot) changes more than once during the Rate (secs) interval, as follows:

    0: actual - the value at the end of the Rate (secs) interval.

    1: average - a time-weighted average of all the changes that occur during this Rate (secs) interval.

    2: minimum - the lowest or minimum value at the end of this Rate (secs) interval.

    3: maximum – the highest or maximum value is logged at the end of this Rate (secs) interval.

  10. Template: If necessary, specify the name of the logging template that customises the default values for the following columns of this file: Slot, Set, Destination, Period (days), Rate (secs), Deadband and Algorithm.

Note1: If you are using a template, then ONLY specify these columns if they DIFFER from the default values provided by this template.
