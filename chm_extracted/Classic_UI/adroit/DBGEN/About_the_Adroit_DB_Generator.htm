About the Adroit DB Generator

IMPORTANT: This utility is NOT included in the Adroit installation NOR the Additional Adroit Components installation.

The Adroit DB Generator creates Adroit agent databases (.WGP files) from information stored in 3rd party applications, such as front-end devices. In other words the Adroit DB Generator:

  • imports the configurations from these 3rd party applications and
  • creates, scans, logs and/or alarms agents as defined in these 3rd party databases

This utility requires a specific Connector (DLL) to create Links that connect to and access the information stored in each required 3rd party database.

Note: When DBGen starts it obtains the connectors specified from a previous session from the DBGEN.INI file. If this DBGEN.INI file does not exist, then the connectors are obtained from the selected computer’s Adroit installation folder, typically: C:\Program Files\Adroit Technologies\Adroit.

You can also fine tune exactly how the agents are created, scanned, logged and alarmed, by creating different agent creation, scanning, logging and alarming templates. 

Note: How a 3rd party application implements these templates, if at all, depends upon its available features and fields of information.
