Monitoring Scanning in Adroit

The Scanning Monitor utility is designed to assist experienced users in fine-tuning the Adroit scanning subsystem to achieve optimal performance, by providing an intuitive report-like view of advanced diagnostic information.

This utility provides information on the scanning (communications) configuration for a particular Agent Server to and from its configured front-end devices, such as PLCs, RTUs etc. and is particularly useful in tuning polled driver's polling intervals.

How to use the Scanning Monitor

Tip: The Scanning Monitor utility can generate a report of your current scanning configuration of an Agent Server to indicate how well it has been configured. For details, see Creating and using the Scan Configuration Report.

However, OPC Server devices not in "sync-poll mode", and telemetry applications will find this utility less useful. For additional ways to optimise the scanning configuration see Scanning Optimization Tips.

To launch the Scanning Monitor Utility.

For details on how to specify the Agent Server in order to monitor its scanning configuration, see Connecting to the required Agent Server.

This utility consists of following three hierarchically arranged list boxes, each of which expose increasingly detailed communication information for the selected Agent Server:

Note: The contents displayed in a list depend upon the selection(s) made in the list immediately above it.

  1. The device list, which displays all the devices that have been configured in the .WGP file (Agent Server database file) of the selected Agent Server. For details, see Devices within Selected Agent Server Database.

Note: This will ONLY list the devices, which have been used to scan tags within the current project that is running on the Agent Server, even though other devices may have been added and configured on the computer.

  1. The scan job list, which displays the scan jobs for the selected device or devices. For details, see Scan Jobs within Selected Devices.

Note1: Any configured @scans will NOT appear in this utility because scan agents are NOT involved in @scanning functionality - these are simply internal slot-to-slot subscriptions that change in real time mode.

Note2: Scan jobs are automatically created by Adroit to group the scanned tags together in such a way as to minimise scanning load and to maximise throughput.

  1. The tag list, which displays the tags (scan points) grouped within the selected scan job or jobs. For details, see Tags within Selected Scan Jobs.

In addition to these lists, the Servers combo box and the Connect… button can be used to specify the Agent Server whose scanning configuration is to be monitored, while the Help button displays this help topic.

Note: The name of the currently selected Agent Server and any connection-related errors are displayed within the status bar of this utility. For details, see Current Agent Server Connection Details.
