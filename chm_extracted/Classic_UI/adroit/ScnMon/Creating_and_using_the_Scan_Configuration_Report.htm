Creating and using the Scan Configuration Report

The Scanning Monitor utility can generate a report of your current scanning configuration of an Agent Server to indicate how well this scanning configuration is configured.

To generate the scan configuration report:

  • Either browse to the Adroit installation folder (typically C:\Program Files\Adroit Technologies\Adroit) in Windows Explorer and open the command prompt (SHIFT + right click on folder) and type in the following command and press ENTER: Adrcomms.exe [computer.agentservername] /report
  • Or copy or use the existing Scanning Monitor utility shortcut and add the ' /report' to the end of the Target field. For details, see Launching the Scanning Monitor Utility.

This report is saved to C:\temp\adrcomms report.csv. This c:\temp folder is created if it does not exist.

The report is then opened, immediately after it is saved, using the current application associated with opening .CSV files (if one has been specified on the computer).

To interpret this scan configuration report:

The report is divided into the following sections:

  • Details: describes the actual scan configuration of every Scan agent of the specified Agent Server.
  • Summary: summarises the Scan agents used by each configured Device agent.
  • Scores: this section attempts to rate the scanning configuration (as a percentage from 0-100%) based on the number of tags configured per Scan agent and the number of Scan agents per Device agent.
