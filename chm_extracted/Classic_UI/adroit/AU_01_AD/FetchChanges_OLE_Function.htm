FetchChanges OLE Function

See Also: List of all the OLE Functions.

 

Use the following function to retrieve a list of actual logged values from the Adroit proprietary datalog files:

Note: This cannot retrieve numeric values that are of type STRING.

VARIANT FetchChanges (

LPCTSTR AgentSlot,

const VARIANT FAR& Start,

const VARIANT FAR& End

)

The function takes one input parameters, of type constant ANSI or UNICODE character string (LPCTSTR), and two of type VARIANT reference (VARIANT FAR&)

  1. AgentSlot: Name of agent and slot to retrieve data for.
  2. Start: Start time of retrieval period.
  3. End: End time of retrieval period.

The function returns an OLE Automation VARIANT structure containing the data fetched. The type of the returned VARIANT is two-dimensional array (VT_ARRAY | VT_BSTR), containing 3 columns for each change that occurred:

  • date and time at which the change occurred
  • the changed value
  • a data integrity flag (1=NORMAL, 4=LAST LOGGED, 5=POST STARTUP, 6=BAD)

Sample VBA code:

p = dataObj.FetchChanges("DIG001.value", "18 / 5 / 2004 14:06:00", "18 / 5 / 2004 14:06:10")
