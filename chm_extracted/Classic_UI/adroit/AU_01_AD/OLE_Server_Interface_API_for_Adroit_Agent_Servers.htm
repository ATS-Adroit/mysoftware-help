OLE Server Interface (MISSRVR) API for Agent Servers

This OLE Server Interface Specification forms the standard API (Application Programming Interface) for Agent Servers.

It effectively defines a contract, by means of which third party client applications can interact in a rich variety of ways with standalone or distributed Adroit configurations.

Because OLE is a programming-language-independent standard, third party applications can be written in any OLE enabled development environment, such as Visual Basic™, (VBA) Visual Basic for Applications™ , Borland Delphi™, PowerBuilder™, C++, etc.

It is an implementation of the Windows Open Services Architecture, Extensions for Real-time Market Data (WOSA/XRT) standard, as created by the Open Market Data Council For Windows (Microsoft Part Number 098-54432).

Unlike other WOSA standards such as MAPI, ODBC, and TAPI, WOSA/XRT does not require new APIs to be defined, nor does it require any production code from Microsoft (other than the OLE DLLs).

This is possible because WOSA/XRT leverages the existing architecture and binary standard provided by OLE. Specifically, WOSA/XRT uses the existing OLE interfaces: Uniform Data Transfer and OLE Automation.
