ScanTag OLE Function

See Also: List of all the OLE Functions.

 

PLEASE NOTE: This function uses scan points because it uses putslot functionality internally, therefore ensure that the Agent Server computer either is licensed (i.e. has a HASP Software Protection Key attached) or that the Agent Server is run using the Limited Time License HASP.

In order to configure an agent.slot value for scanning, the following function is used:

VARIANT ScanTag (

LPCTSTR Agent,

LPCTSTR Slot,

LPCTSTR Device,

LPCTSTR Address,

INTEGER Rate,

INTEGER Deadband,

INTEGER OutputEnable

)

The function takes four input parameters, of type constant ANSI or UNICODE character string (LPCTSTR) and three of type INTEGER:

  1. Agent: Name of agent or tag (agent.slot) to be scanned.
  2. Slot: Name of slot to be scanned.

Note: This parameter is ignored if the Agent parameter contains a tag.

  1. Device: Name of Device agent interfacing to the PLC or other front-end device.
  2. Address: Scan address, dependant on the protocol used.
  3. Rate: Scan period, in milliseconds.
  4. Deadband: Scanning deadband, in scanned units.
  5.  OutputEnable: 1, if scanned point must be an output, otherwise 0.

Note: To UNSCAN a specified item, specify the Rate (at which this item was scanned) as a negative value, while keeping all the other parameters correct. In this case, the Agent, Slot and Address parameters are case sensitive. E.g. if the item was scanned at a rate of 1500 milliseconds, then it is necessary to specify its Rate as –1500, in order to unscan it.

 

The function returns a properly initialised, but empty, OLE Automation VARIANT structure when it succeeds.

Sample VBA code:

p = dataObj.ScanTag ("ANA-01", "rawValue", "SIMPLC", "DB2:DW0", 1000, 10, 1)

'To Unscan this tag

p = dataObj.ScanTag ("ANA-01", "rawValue", "SIMPLC", "DB2:DW0", -1000, 10, 1)

In order to create a Device agent and add a scan point to it, the following lines of code are required:

'Create the Device agent 

dataObj.CreateAgent "SW_PUMPS", "", "Device" 

'Perform a "dummy" Fetch to initialise this Device agent 

dataObj.Fetch "SW_PUMPS", "start" 

'Add all the required scan points 

dataObj.ScanTag "ANA-01", "rawValue", "SW_PUMPS", "40001", 60000, 0, 0
