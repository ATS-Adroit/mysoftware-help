LogTag OLE Function

See Also: List of all the OLE Functions.

 

PLEASE NOTE: This function uses scan points because it uses putslot functionality internally, therefore ensure that the Agent Server computer either is licensed (i.e. has a HASP Software Protection Key attached) or that the Agent Server is run using the Limited Time License HASP.

In order to configure an agent for historical data logging, the following function is used:

VARIANT LogTag (

LPCTSTR Agent,

LPCTSTR Slot,

INTEGER Set,

INTEGER Period,

INTEGER Rate,

LPCTSTR Filename

)

The function takes three input parameters, of type constant ANSI or UNICODE character string (LPCTSTR) and three of type INTEGER:

  1. Agent: Name of agent or tag (agent.slot) to be logged.
  2. Slot: Name of slot to be logged, "value" by default.

Note: This parameter is ignored if the Agent parameter contains a tag.

  1. Set: Number of logging set, 0 by default.
  2. Period: Time to log data, in hours.
  3. Rate: Shortest logging interval (time deadband), in seconds.
  4. Filename: Path and filename of the data log.

The function returns a properly initialised, but empty, OLE Automation VARIANT structure when it succeeds.

Note: If the tag is already being logged, then this function will simply overwrite the existing logging settings.

Sample VBA code:

p = dataObj.LogTag ("ANA-01", "rawValue", 1, 240, 10, "C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\History")

Note: To delete the historical data logging for this Adroit tag, use the RemoveAgent function and specify the following name: "LOG$Agent$Slot", where Agent, is the specified Agent name and Slot is the specified slot that was logged. For instance, to remove the logging for the example above, type the following: p = dataObj.RemoveAgent("LOG$ANA-01$rawValue")
