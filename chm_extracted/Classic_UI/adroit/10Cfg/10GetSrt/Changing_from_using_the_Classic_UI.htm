Changing from using the Classic UI

What you should know when using the SmartUI Designer as a user interface to the Adroit Agent Server:

Although the SmartUI provides similar functionality, the means by which this functionality is implemented has changed somewhat from the Classic UI.

For details on how to import your existing Classic UI projects into the SmartUI, see Converting Classic UI projects into SmartUI projects.

  1. To familiarise yourself with this new designing environment, see Working with the Designer
  2. For a quick start guide to using this new designing environment, see Quick designing guide.
Classic UI Feature SmartUI UI Equivalent

Accessing agent data

Add an Adroit datasource and connect it to the required Agent Server. For details, see Adroit datasources.

Agent server configuration

Once an Adroit datasource has been added, its associated agent server can be configured. For details, see Configuring the Agent Server.

User Interface security

In addition to customizing the user interface display, profile settings can also be used to limit the access users have within them. For details, see Working with profiles.

Mimics

(Picture windows)

Mimics are now known as graphic forms. For details, see Working with graphic forms.

Note: When displaying Adroit tags you can display bad-tag status indicators on relevant controls and/or vectors. For details, see Bad tag status indicators.

Tip: You can import your existing Classic UI mimcs directly into the SmartUI, see Converting Adroit Classic UI mimics into SmartUI graphic forms.

Vector graphics

Vector graphics are collectively known as graphic elements, which can be added to graphic forms (mimics). For details, see Working with vectors (graphic elements).

Behaviours

Behaviours are provided to graphically display your values. For details, see About Behaviours.

You can also use spiders, which in addition to animating controls on graphic forms (mimics) also provide a visual programming language that is able to manipulate data, by means of drag and drop. For details, see Introduction to spiders and silks.

Trend windows

This is now performed by a charting controls that can be added to a graphic form (mimic). For details, see Charting controls or specifically LineChart controls.

Tip: You can import your existing Classic UI trends directly into the SmartUI, see Converting Adroit Classic UI mimics into SmartUI graphic forms.

Alarm Viewer windows

This is now performed by a custom control that can be added to a graphic form (mimic). For details, see AlarmViewer controls.

Event Log windows

 Events within event logs can now be exposed by using the Event log datasource. Once this datasource has been added, event logs can be displayed within a EventViewer control on any graphic form (mimic). For details, see Event Log datasources or EventViewer controls.

Wizards

Wizards or the ability to create re-usable controls from graphic forms, that can be inserted in other graphic forms is provided by TemplateGO controls and through the creation of Wizards. For details, see TemplateGO controls and Working with wizards.

Recipe windows

Since a native recipe control, does not exist in this UI, it will need to be manually created as a graphic form, if necessary.

Tip: This recipe graphic form can also be re-used, by using TemplateGO controls.

Template

mimics and trends

SmartUI Templates are reusable graphic forms that can be used at run-time, like template mimics. For details, see Working with SmartUI Templates.

Template sets can now be used to create sets of data, which can be selectively displayed by a graphic form.

Therefore, once the required controls within a graphic form, have been suitably configured, this graphic form will behave as template mimics did in the past. For details, see Working with template sets.

Note: Since Trend windows have been replaced by trend controls, these controls can also be configured to behave as template trends did in the past.
