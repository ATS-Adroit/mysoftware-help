Bind Value Behaviours

This Behaviour can drive a data element (value) to and/or from the value of a property of a control or vector.

Usage examples:

  • Displaying a value on a label or button with applied string formatting.
  • Driving a gauge control from the value of an Adroit agent.
  • Driving a slider control from the value of an Adroit agent and writing this value back to Adroit when the slider is manually adjusted.

 

The Bind Value Behaviour provides the following options:

  • To Control Property: this is the default option, where a value (data element) is linked to a property of a control/vector. If this is a String property, then you also have the option of applying string formatting to this value before it displayed.

This allows a data element (value) to drive the value of a property of a control/vector.

  • From Control Property: this connects a property of a specific control or vector to a value (data element) and specifies which event of this control or vector is used to update this data element with the current value of this property.

This allows the value of a property of a control or vector to drive the value of a data element.

  • Both (To/From Control Property): this both sets a property of a control or vector to a data element and when a specific user event occurs to this control or vector, then the current value of this property is written back to this data element.

This facilitates a two-way feedback connection between the specified property of the control/vector and the data element.

 

To bind a value to a property of the currently selected control or vector:

  1. Add or edit a Bind Value Behaviour for the currently selected control or vector to display its configuration dialog.
  2. If necessary, click the To Control Property option, which displays the To Control Property tab.

The Data Element Browser dialog provides the following features to assist you in this task of selecting the required value:

  1. The Recently selected elements list, which displays the last 10 selected data elements - so that these data elements can be quickly selected again, whose display is controlled by the or button in the top right hand corner.

If the data element, in this Recently selected elements list, does not have an associated icon, then either this data element does not exist or, in the case of the Adroit datasource, that you have not opened the associated Agentgroup in the Adroit datasource tree and so if this data element is selected it will not be found in the Browser window.

  1. The ability to display the current value of the data elements you are currently or have previously selected, by clicking the button in the top right hand corner, which adds the Watches column to the Recently selected elements list (when this is displayed) and the icon and current value to the right of the currently selected data element at the bottom of this dialog.
  2. A data element searching capability to quickly locate similarly-named values without manually browsing for them: simply type the required search criteria into the Search in browser for edit box and all the data element names containing the specified search string are displayed in a list providing the name of the data element and its path. If necessary, click the button to return to the tree view.

By default, to speed up searching on large Adroit Agent Server projects, the searching stops at the agent and not the slot level.

  2. When selecting tags from an Adroit datasource, you can also create on-the-fly agents by editing the selected data element string to create another tag. In this case, when you click Finish, a message is displayed asking whether you want to create this new tag or not, if you select Yes then this tag is created and selected.

Note: If a DataSet value is selected, such as a field of a database, the Filter DataSet configuration dialog is displayed to select which value to display.

    Typically this list displays the commonly used properties and their data types for the currently selected control or vector.

    If you want to select a property or sub properties that is not listed, then click the browse button to the right of this property list to manually select it from the Property Selection Browser, which displays the currently selected property, by default.

    Note: Any properties or sub properties that you select will be stored for you in your user profile settings so that they will be listed, by default, in future - this means that you do not need to browse for them again.

  2. If the Type of selected property is String, then you can also use the String Formatting edit box to align and/or format this value before it is displayed, as follows:

    The required formatting is defined as a string, which adheres to the following syntax: {0[,alignment][:dataFormat]} 

    • either type in the required formatting string directly and/or

      For further assistance on creating format strings, see String formatting syntax.

    • click the browse button and using the Format String Editor configuration dialog to specify and/or preview the specified formatting.

    Tip: This is usually required when the default formatting of the value is not expressive or informative enough to be useful.
