Saving the Tag Monitor Utility

The Tag Monitor utility can display current values of one or more tag values from a particular Agent Server, in tabular and trend format, without having to specifically draw a mimic or create a trend to do so. For details, see Monitoring Tags (Values).

This utility can either be saved by clicking the Close or Save button.

When this utility is saved only the list of monitored tags and its operational parameters are saved, so that these settings will be enabled when this utility is restarted.

However, any other configuration within the Graph and Subscription log pages; such as which of the monitored tags are trended and the subscription log messages will be lost.

By default the list of the monitored tags are saved in the ‘default_tags.txt’ file located in the folder in which the utility is run, however it is possible to create different tag lists for different servers, simply by start the utility with a suitably named command-line parameter. For details, see Launching the Tag Monitor Utility.

The following additional operational parameters are also saved, per tag list, in the ‘adrmonitor.ini’ file that is located in the folder in which the utility is run:

  1. The currently connected Agent Server.
  2. The current window position and size of this utility.
  3. The operational status of this utility i.e. whether it is started or stopped.
  4. The currently selected time span of the trend.
