Trending Monitored Tags

The Tag Monitor utility can display current values of one or more tag values from a particular Agent Server, in tabular and trend format, without having to specifically draw a mimic or create a trend to do so. For details, see Monitoring Tags (Values).

The Graph tabbed page displays a trend of the values of any tags that has been added to this trend, including a legend at the bottom of this page containing a list of the trended tags, each displayed in the colors used to represent their values, much like that displayed by the Tags tabbed page. For details, see Configuring Monitored Tags.

Note: The tags that have been added to the Graph page are NOT saved when the utility is saved i.e. whenever the utility is started no tags will be added to this page.

To add a tag to the Graph tabbed page:

  1. Ensure that the tag monitoring process is stopped i.e. the Stop button is clicked and is currently greyed out.
  2. In the Tags tabbed page, select a tag whose value is required to be trended.
  3. Right-click and select Add to graph.

 

The values of any tag(s) that have been added to this page, will be trended when the tag monitoring process is started i.e. the Start button is clicked and is currently greyed out.

The view of the tag (agent.slot) values that have been or are being trended can be modified by means of the right-click menu that provides the following commands in this tabbed page:

  1. Inspect: When this command is enabled for a trended tag, each distinct value is indicated by means of a square box, which when clicked, displays a tool tip containing the value and time at which this value occurred.

To enable this command for a trended tag, click on the row representing the tag in the legend, at the bottom of the page, this will select the line (causing it to become white) then right-click this row and select Inspect.

Note: This can also be performed by selecting the required trend line and pressing CTRL+I.

  1. Stairs: This command, when enabled, changes the method of interpolation used when displaying the trended line between successive values from a straight connecting line to horizontal and vertical lines (steps).

This command can be enabled or disabled as required, when enabled a tick mark appears to the left of this command in the right-click menu.

Note: This viewing option can also be enabled or disabled by pressing CTRL+S.

  1. Delete: This will remove the selected trended value from this tabbed page.

To delete a trended tag, click on the row representing the tag in the legend, at the bottom of the page, this will select the line (causing it to become white) then right-click this row and select Delete.

Note: This can also be performed by selecting the required trend line and pressing Delete.

  1. Graph time span…: This displays the Change graph time span dialog, which allows the entire period of time displayed by this Graph window to be specified in the following format: hours:minutes:seconds.

The default is one minute i.e. 00:01:00.

Note: The required time span for the trend can also be configured by pressing CTRL+W.

 

Furthermore, the view of the tag (agent.slot) values can be zoomed into or out of as follows:

  1. Zooming in: It is possible to enlarge a portion of the displayed trend, for instance, to better inspect or determine the values of the trended values, as follows:
  1. Click the top left most corner of the area that needs to be magnified or enlarged in the trend.
  2. Hold the left mouse button down and drag down towards the bottom right hand corner of the required area.
  3. This will display a white box that defines the area of the graph that will be enlarged.
  4. Release the left mouse button once the required area has been defined.
  1. Zooming out: It is possible to return the original magnification once an area has been zoomed in, as follows:
  1. Simply click anywhere in the graph, hold the left mouse button down.
  2. Drag upwards towards the top left hand corner and release the left mouse button.

Note: Ensure that a sizable area has been defined before releasing.
