Monitoring Tags (Values)

IMPORTANT: This utility is NOT included in the Adroit installation and must be separately installed from the Additional Adroit Components installation.

The Tag Monitor utility is designed to display the current values of one or more tagA fully qualified named value in Adroit (agentName.slotName). values from a particular Agent Server without having to specifically draw a mimic to do so. While these values are initially displayed in tabular format, they can also be monitored in a trend format too.

Launching the Tag Monitor Utility.

For details on specifying the Agent Server whose tags are to be monitored, see Connecting to the required Agent Server.

This utility contains the following three tabbed pages, each of which display a different view of the values of the tags that are being monitored by this utility from the selected Agent Server:

  1. Tags: This is the default page, in which the list of tags monitored by this utility can be configured. This page displays the most current value of each tag, from the selected Agent Server, in tabular format and also allows tags to be added to the trend. For details, see Configuring Monitored Tags.

Note: While the list of tags configured by this page are saved, the Graph and Subscription log pages are not.

  1. Graph: This displays a trend of the values of any tags that have been trended. For details, see Trending Monitored Tags.
  2. Subscription log: This contains a record of the most recent values that have been received for all the tags that have been added to this utility. For details, see Logging Recent Subscriptions.

The utility also provides the following functionality that is common to all three tabs:

  1. Close: This button saves and closes this utility. For details on what is saved, see the Save button below.
  2. Start: This button starts the tag monitoring process.

Note: In this operational mode, tags cannot be added or removed from the Tags tabbed page.

  1. Stop: This button stops the tag monitoring process. 

Note: In this operational mode, tags can be added or removed from the Tags tabbed page.

  1. Save: This button saves the list of tags monitored by this utility and a number of operational parameters but not the Graph and Subscription log pages. For details, see Saving the Tag Monitor Utility.
  2. Write value: This button displays the Enter new value dialog, to change the value of the currently selected tag.

Note: When modifying the value of a tag, only valid values will be accepted.

  1. Browser: This button launches the agent browser utility. 

Note: Any tags that are double-clicked in the browser will be automatically added to Tags list of monitored tags, provided that this utility is in the stopped state.

  1. Server info…: This button displays a dialog of information concerning the currently connected Agent Server, whose tags are being monitored.
  2. Help: This button displays this help topic.
  3. Both the Servers combo box and the Connect… button can be used to specify the Agent Server whose tags are to be monitored. For details, see Connecting to the required Agent Server.

Note: The status bar displays information concerning the current operation of the tag monitoring process. For details, see Current Operational Status.
