Configuring Monitored Tags

The Tag Monitor utility can display current values of one or more tag values from a particular Agent Server, in tabular and trend format, without having to specifically draw a mimic or create a trend to do so. For details, see Monitoring Tags (Values).

The Tags tabbed page is displayed by default, when this utility is launched.

This page contains and manages the list of tags (agent.slot), whose values are monitored by this utility. Interaction with this page is dependent upon whether the status of the tag monitoring process, as follows:

Note1: The list of tags configured by this page is saved, when the utility is saved. For details, see Saving the Tag Monitor Utility.

Note2: The status bar also displays the current operational status. For details, see Current Operational Status.

When the tag monitoring process is started i.e. the Start button is clicked and is currently greyed out.

The right-click menu is disabled and this tag list cannot be modified, instead the current values of these tags are displayed. This list, consists of the following columns:

  1. Tag: The name of the tag (agent.slot), whose value is being monitored.
  2. Value: The current value of this tag.
  3. Time: The time at which the value of this tag last changed.

 

When the tag monitoring process is stopped i.e. the Stop button is clicked and is currently greyed out.

The right-click menu is enabled, so that the list of tags (agent.slot) displayed by this page can be edited, as follows:

  1. Add to graph: Add a selected tag to the Graph tab, this will allow the value of this tag to be trended against time.

Note: If more than one tag is selected, all selected tags are added to the Graph tab on the graph and legend.

  1. Copy: This will copy the selected tag (agent.slot) to the clipboard, so that it can be pasted into this utility etc.

Tip: This can also be performed by selecting the tag and pressing F2.

  1. Paste: This will paste (add) a tag (agent.slot) to the end of the current list from the clipboard.

Tip: This can also be performed by pressing F3.

  1. Add: This will display the Add a tag dialog, so that the name of the required tag, from the currently connected Agent Server can be typed in. This tag will be added to the end of the current list.

Tip: This can also be performed by pressing F5.

  1. Edit: This will display the Edit a tag dialog, so that the name of the selected tag can be modified.

Tip: This can also be performed by selecting the tag and pressing F6.

  1. Insert: This is identical to the Add command except that the Insert a tag dialog is displayed and the tag is inserted to the list into the currently selected row, instead of being added to the end of the list.

Tip: This can also be performed by selecting the required row and pressing the Insert key.

  1. Delete: This removes the currently selected tag(s) from the list.

Tip: This can also be performed by selecting the required tag(s) and pressing the Delete key.

  1. Move up: This will move the currently selected tag up in the list.

Note: This operation will not work if more than one tag is selected.

Tip: This can also be performed by selecting the required tag and pressing F7.

  1. Move down: This will move the currently selected tag down in the list.

Note: This operation will not work if more than one tag is selected.

Tip: This can also be performed by selecting the required tag and pressing F8.
