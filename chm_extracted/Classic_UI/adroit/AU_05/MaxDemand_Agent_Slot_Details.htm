MaxDemand Agent - Slot Details

The MaxDemand agent predicts the maximum kVA demand for the current block periodthe interval over which your electricity provider monitors your maximum demand, which is typically 30 minutes. so you can create alarms if the predicted consumption exceeds a predefined limit.

This agent is located in the following file: T_MAXDEMAND.DLL

Slots:

Slot Name Type Function

blockPeriod

INTEGER

Block period length (mins).  If block pulses are enabled, this time must be equal to block pulse times.  Valid values are from 2 to 60 minutes.

blockPulse

BOOLEAN

External block period pulse scanned from the front-end device (PLC).

blockPulseEnable

BOOLEAN

When True (1) this enables the external block period pulse.

blockPulseTime

TIME

The time of the last external block period pulse.

blockTimeLeft

INTEGER

Time-in-hand (minutes) to the end of the block period.  If block pulses are used then this time is simply blockPeriod - (currenttime - blockPulseTime).  This is value is zero if the agent is not enabled.

catchupData

RAWBYTES

For internal use only (used for datalog and real-time data catch-up).

demand

REAL

The actual demand for the current block period.  This value is rest to zero at the end of the month and is zero if the agent is not enabled.

enable

BOOLEAN

Inhibit maximum demand control input for the periods of the day when maximum demand is not counting.

enableMDAlarm

BOOLEAN

Set Alarm bit when the predicted maximum demand exceeds maximum demand limit.

enableTag

TAGNAME

Browse in a Boolean or Real tag to control the value of the enable slot.

kVA

REAL

The instantaneous kVA (apparent power) input.
kVAOptimal REAL The recommended kVA consumption to meet maximum demand.

kVAr

REAL

The instantaneous kVAr (reactive power) input (optional).

kVArCalc

REAL

Calculated instantaneous reactive power

kVArhTotal

REAL

Totalised reactive power for the month.  If the kVAr slot value is zero, then the kVArCalc slot value is used. This value is reset to zero at the end of the month.

kVArTag

TAGNAME

An optional dereferencing tag for kVAr value.

kVASpare

REAL

The amount of spare kVA capacity for the current period = difference between the current and the optimal or recommended kVA.

kVATag

TAGNAME

An optional dereferencing tag for kVA value.

kW

REAL

The instantaneous kW (real power) input (optional).

kWhTotal

REAL

Totalised kWh for the month

kWTag

TAGNAME

An optional dereferencing tag for kW value.

mdActual

REAL

The actual maximum demand for the month (same as the value slot).

mdLimit

REAL

Maximum demand limit (kVA)
mdOverUnder REAL The difference between the current period’s predicted demand and the configured maximum demand.

mdPredict

REAL

The predicted maximum demand for current the block period.  This value is zero if the agent is not enabled.

mdPrev

REAL

The previous month’s actual maximum demand.

pf

REAL

Calculated instantaneous power factor

resetDay

INTEGER

Day of month for monthly meter reading/reset.

0 means the last day of the month, otherwise use 1 to 28.

resetNow

BOOLEAN

When set to True (1) this forces a reset of all the calculated readings to zero.

resetTime

TIME

The time of day for the monthly meter reading or reset.
timeToMD TIME

The time left before reaching the maximum demand at the current consumption for the current block period.

Note: If you are running safely, this will ALWAYS indicate the end of the current block period.

value

REAL

The actual Maximum Demand for the month (same as the mdActual slot)

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

MaxDemand

Set to TRUE (1) when the predicted block maximum demand exceeds maximum demand limit.

status bit 17

Unlicenced

NOT USED

status bit 18

PulseError

Set to TRUE (1) when an error occurs in the timing of external block pulses i.e. they are taking too long.
 

Methods of creation:

Manual

Agents created by default:

None
