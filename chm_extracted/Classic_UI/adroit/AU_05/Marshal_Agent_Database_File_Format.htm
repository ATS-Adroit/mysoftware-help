Marshal Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

## = 00 to 15, for the 16 digital agents

 

VAL =nnnn

value slot, a 16 bit integer value

RAW=nnnn

rawValue slot, a 16 bit integer value

MAP=n

Value (0 or 1), if set to 1 then reverse mapping is used

TME=nnnnnnnn nnnnnnnn

The time stamp of the Value slot

VBIT##=n

Cold start value for Bit ##, either (0 or 1)

INVBIT##=n

Invert flag for Bit ##, either (0 or 1)

ONTEXT##=string

State 1 name for Bit ##

OFFTEXT##=string

State 0 name for Bit ##

PULSE##=n

Enable pulse output for Bit ##

DELAY##=nnnn

Pulse delay in milliseconds for Bit ##

INIT##=n

Cold start value for Bit ##, either (0 or 1)

VTIME##=nnnnnnnn nnnnnnnn

Value time stamp for Bit ##

RENAME##=string

Individual name for value of Bit ## (this is a rename-able slotname)

DESCRIPTION##=string

Description for Bit ##

COLDSTART##=n

Enable cold start for Bit ##, either (0 or 1)
