Agent Header Information

Just like certain slots are header slots that are common to all agent types and instances, the first batch of .WGP file lines for each agent contain header information, as described in the following table:

For a detailed description of any of its slots, see Slot Details.

.WGP File Line Description

[name]

Name of agent, e.g. "AN-01"

DSC=description

description of agent, e.g. Analog No. 1

TYP=type

type of agent, e.g. "Analog"

VER=nnnnn

Major and Minor agent type version no.

DBG=n

Debug flag value

STS=nnnnn

Agent status word value

PRY=n

Agent priority value

FIL=n

Agent event filter group (Integer). For details, see Filter Group edit box in the Agent Header Dialog.

MSH=n

Agent membership count (i.e. no. of groups joined)

MEM=agent-1 name

name of group 1

MEM=agent-2 name

name of group 2

...

...

MEM=agent-n name

name of group n

PIC=name

[Path] and/or name of mimic currently associated with this agent. For details, see Associating Mimics with Agents.

ICO=

Not currently used, but can be used to record user-defined information or messages. For details on configuring this, see Editing the Header.

SST=n

Slot status word count

SST0=nnnn,nnnn

Slot 1 status word (raw and derived)

SST1=nnnn,nnnn

Slot 2 status word (raw and derived)

...

...

SSTn=nnnn,nnnn

Slot n status word (raw and derived)

EXT=0

Not used.

UID= Not used.
SVN=0 Not used.
AVN=0 Not used.
LVN=0 Not used.

 

The syntax and semantics of the remaining .WGP file lines for each agent are specific to the agent type. For details, see Database File Reference.
