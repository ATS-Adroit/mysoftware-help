DbAccess Agent - Slot Details

The DBAccess agent provides a link between Adroit and various external databases such as Access, SQL Server, FoxPro and Oracle using Microsoft's OLE DB technology.

This agent is located in the following file: T_DBACCESS.DLL

Slots:

Slot Name Type Function

badTransactions

INTEGER

Increments when an unsuccessful transaction is made, this slot is not saved and starts at 0 when the Agent Server restarts.

connectionString

VARSTRING

The OLE DB provider's database connection string.

dbRowCriteria

VARSTRING

This identifies the row in the table to transact on.

dbSQL

VARSTRING

SQL string

disableStandby

BOOLEAN

Disable logging, when this Agent Server is clustered and is in standby mode - to prevent duplicate logging.

eventlogErrors

BOOLEAN

Enable or disable the eventlogging of transaction errors.

goodTransactions

INTEGER

Increments when a successful transaction is made, this slot is not saved and starts at 0 when the Agent Server restarts.

information

VARSTRING

General information or error information. For instance, this contains the string "Transaction succeeded' after every successful transaction.

listOfDBFields

VARSTRING

A CSV string containing a list of database table fields.

listOfDBFormats

VARSTRING

A CSV string identifying the format of the data in the database.

listOfTags

VARSTRING

A CSV string containing a list of input tags.

listOfTriggerOpts

VARSTRING

A CSV string identifying the type of trigger.

listOfTriggers

VARSTRING

A CSV string identifying the tags that will trigger a transaction.

runNow

BOOLEAN

Do a transaction now.

runTime

INTEGER

The time in milliseconds taken to do the last transaction.

scheduleOption

INTEGER

0 = None

1 = Use any starting time

2 = Use given starting time

schedulePeriod

REAL

The time delay in seconds between scheduled transactions.

scheduleStartTime

TIME

Synchronise the scheduling of transactions at this point in time.

start

BOOLEAN

Enable or disable the connection to the database

tableFieldList

VARSTRING

The list of fields found in the table.

tableList

VARSTRING

The list of tables found in the database.

tableName

VARSTRING

The name of the table in the database to transact on.

transactionType

INTEGER

0 = Insert

1 = Update

2 = Delete

3 = Retrieve

triggerOption

INTEGER

0 = do the transaction when triggered,

1= do the transaction using schedulePeriod and only if triggered.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Disconnected

State is on if there is no connection to the database.

status bit 17

Connected

State is on if there is a connection to the database.

status bit 18

Transaction error

State is on if a transaction with the database fails.

status bit 19

Overrun error

Works only for scheduled transactions. State is on if the transaction time took longer than the scheduled delay period, i.e. runTime in seconds > schedulePeriod in seconds.

status bit 20

Connection error

State is on if there is a problem connecting to the database.

status bit 21

Transaction success

 

State is on if a transaction with the database succeeds.

Note: This status slot (and the "transaction error" status slot) is turned off prior to executing a new transaction but the user is free to turn it off manually before executing a transaction.

Methods of creation:

Manual

Agents created by default:

None
