SystemDataLog Agent - Slot Details

The SystemDataLog Agent manages the datalog catch-up process within a cluster.

IMPORTANT: .LGB files are used when backing up datalogs as these can have their stored historical data seamlessly retrieved for trending and reporting. For details, see Datalog backup and retrieval.

Note: For performance reasons, the SystemDatalog agent ONLY provides the Time datalog catchup method, of catching up the data between two specified date/times.

This agent is located in the following file: T_SYSTEMDATALOG.DLL

Slots:

Slot Name Type Function

backupAgent

STRING

This contains the name of the datalog agent that is currently being backed up, this is normally empty.

backupCompletion

REAL

Read only - this contains the percentage completion of the datalog backup process, which is normally 100% to denote finished.

backupDirectory

VARSTRING

This contains the full path of the directory where the backup CSV files are to be stored.

backupNow

BOOLEAN

This will execute the datalog backup, using either the previously configured period or the Monthly period by default., if set to TRUE (1). If set to FALSE (0) this will do nothing, this is the default state.

backupOnFull

BOOLEAN

For future use: Backups are disabled if disk is full (default) = 0; Oldest backup files are deleted if disk is full = 1

backupPeriod

INTEGER

Every day = 0; Monday = 1; Tuesday = 2; Wednesday = 3; Thursday = 4; Friday = 5; Saturday = 6; Sunday = 7; first day of Month = 8, the default; first day of year = 9

backupPeriodStr

VARSTRING

This describes the currently selected datalog backup period.

backupTriggerTag

STRING

This specifies the tagA fully qualified named value in Adroit (agentName.slotName). used to trigger the datalog backups, if triggering is used. (backup now tag)

backupType

INTEGER

None, the default, disables the backup facility = 0; Scheduled = 1; Triggered = 2; Scheduled & Triggered = 3

backupTypeStr

VARSTRING

This describes the currently selected datalog backup type.

catchupRate

INTEGER

The rate at which data points are being merged into the local datalogs from the cluster partner.

dataEndTime

TIME

End of data time

dataStartTime

TIME

Start of data time

information

STRING

This contains general information regarding the synchronization process including error messages.

mode

INTEGER

Mode of operation (0 or 1)

modeStr

STRING

Mode of operation description (automatic or manual)

options

INTEGER

Option (0, 1, 2 or 3)

optionsStr

STRING

Option description (Last, All, Everything or Time)

Note: For performance reasons, the SystemDatalog agent ONLY provides the Time datalog catchup method, of catching up the data between two specified date/times.

progress

REAL

This displays the progress of the current synchronization process as a percentage of datalog agents that have been synchronised on that Agent Server in the cluster.

qFree

INTEGER

This represents the percentage of the datalog buffer queue that is currently free.

realTimeRate

INTEGER

This indicates how many points were datalogged by all of the datalog agents in the last second (points/sec).

start

BOOLEAN

Start catchup manually

tagRestoring

STRING

This displays the datalog agent that is currently being synchronised by the systemDatalog agent.

totalRate

INTEGER

This is the sum of the realTimeRate and the catchupRate slots (points/sec).

totalRateLimit

INTEGER

Rate limit when the LowRate status bit is set

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Done

State is on when the datalog catchup is complete.

status bit 17

Busy

State is on when the datalog catchup is being carried out.

status bit 18

Failed

State is on when the datalog catchup has not completed.

status bit 19

LowRate

State is on when the total catchup rate in the last second (totalRate slot) is less than the value of the totalRateLimit slot.

status bit 20

BackupBusy

State is on when the datalog backup process is being carried out.

status bit 21

BackupError

State is on when an error occurs in the last datalog backup.

Methods of creation:

Automatic - do not add new instances manually.

Agents created by default:

systemDl
