ARec Agent - Slot Details

The ARec agent provides both user-configurable state operation functionality (being a truth table that can contain up to 32 elements, that it can obtain from a file that is imported) and sequence functionality similar to that provided by the Stringlist agent except that the ARec agent is also able to drive its private status bits.

This agent is located in the following file: T_AREC.DLL

Slots:

Slot Name Type Function

bit00 - bit31

BOOLEAN

The default slot names representing the I/O bits of the AREC agent. These default names are replaced by the IDs of each state definition.

coldStartEnable

BOOLEAN

Enables the cold start value.

coldStartValue

INTEGER

A 32 bit mask representing the initial status of the I/O points.

enable

BOOLEAN

Enables the state computer to set/clear the output bits.

numOutputs

INTEGER

A number (1-32) indicating how many I/O points, starting at tag1 are designated as outputs.

numSequences

INTEGER

Number of sequence steps to be defined, default 0.

numStates

INTEGER

The number of states (1-32) required for this AREC agent.

numTags

INTEGER

The number of I/O tags used in this AREC agent.

pulseWidth

INTEGER

Output pulse width, in ms, for ON outputs – 0 to disable pulsing. Not required if dereferencing I/O points to digital tags that have pulsing functionality.

seqIdx

INTEGER

Current sequence step. This slot is generally communicated to a Front End Device (PLC).

seqList

LIST

A list of sequence information.

seqText

VARSTRING

Current sequence step text – read-only.

stateIdx

INTEGER

Current state number – read-only.

stateList

LIST

A list of state information.

stateText

VARSTRING

Current state text – read-only.

tagList

LIST

A list of optional tags that map to the 32 I/O points of the AREC agent.

typeName

VARSTRING

The type of AREC.

value

INTEGER

A 32 bit mask representing the current state of the I/O points.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16
to 31

ARecStatus00 to ARecStatus15

These are controlled by configuration of the state and sequence operations and should not be driven by both unless different status bits are being used.

Methods of creation:

Manual

Agents created by default:
