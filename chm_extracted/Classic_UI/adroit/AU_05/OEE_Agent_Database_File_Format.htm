OEE Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description
AUR The autoReset Boolean slot that determines whether this agent automatically resets the calculated OEE and KPI data at the end of every shift.
TP1

Defines what type of signal is attached to input1, as follows:

1=Accumulator: The input1 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input1 type must be reset to 0 at the end of every shift using the agent’s ShiftEnd status bit as a trigger.

2=Totaliser: The input1 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input1 type is never reset to 0.

3=Rate per hour: The input1 slot is interpreted as a per hour production rate which will be integrated by the agent over time to produce a totalised value.

4=Rate per min: The input1 slot is interpreted as a per minute production rate which will be integrated by the agent over time to produce a totalised value.

5=Rate per sec: The input1 slot is interpreted as a per second production rate which will be integrated by the agent over time to produce a totalised value.
TP2

Defines what type of signal is attached to input2, as follows:

0=Unused: This means that input2 is not used.  The KPI is calculated using input1 against time.

1=Accumulator: The input2 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input2 type must be reset to 0 at the end of every shift using the agent’s ShiftEnd status bit as a trigger.

2=Totaliser: The input2 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input2 is never reset to 0.

3=Rate per hour: The input2 slot is interpreted as a per hour production rate which will be integrated by the agent over time to produce a totalised value

4=Rate per min: The input2 slot is interpreted as a per minute production rate which will be integrated by the agent over time to produce a totalised value.

5=Rate per sec: The input2 slot is interpreted as a per second production rate which will be integrated by the agent over time to produce a totalised value.

If type2 is not set to 0 (Unused), then the OEE agent is said to be in complex mode.
UN1 Specifies the units for the input1 slot e.g. tons/hr
UN2 Specifies the units for the input2 slot
AVA

The available Boolean slot that determines whether the machine/process is currently available for production.

The state of this slot affects the accumulation of availableCurrShift time.

RUN The running Boolean slot that determines whether the machine/process is currently running. 

The state of this input affects the accumulation of runtimeCurrShift and downtimeCurrShift times. 
ENA The enable Boolean slot that determines whether this agent is enabled for operation or not. 
CAP The designCapacity Real slot which is the designed rate/capacity of the process/machine, as a per hour value for use in OEE calculations.
INA

The inactivityPeriod Integer slot which is the period defined in seconds that determines an inactive input signal. 

If the measurement variable (input1 slot) remains static for this configurable time, the agent will interpret the process/machine as not running. 
QUA The qualityFactor Real slot, which is an external quality percentage factor used against the internally calculated quality component for OEE calculations.  
SHF

The shiftAgent Tagname slot, which is the Shift agent that specifies the current shift information. 

If no Shift agent is specified, then it is assumed that the agent is running in a “batch mode” where the onus remains on the user to trigger an OEE data snapshot followed by a reset at the end of every batch. 
AVATAG The availableTag Tagname slot, which is the optional tag reference for the available slot. 
RUNTAG The runningTag Tagname slot, which is the optional tag reference for the running slot. 
IN1TAG The input1Tag Tagname slot, which is the optional tag reference for the input1 slot. 
IN2TAG The input2Tag Tagname slot, which is the optional tag reference for the input2 slot. 
REJTAG The rejectCountTag Tagname slot, which is the optional tag reference for the rejectCount slot.
PROTAG The productTag Tagname slot,which is the optional tag reference for the product slot. 
BADTAG The batchIDTag Tagname slot, which is the optional tag reference for the batchID slot. 
KPIT The kpiTarget Real slot, which is the target KPI value.  This value is used simply used for calculation of the kpiPercent slot value as a percentage.
KPILO The kpiLo Real slot, which is the Low alarm value for the KPI value as a percentage.
KPILL The kpiLoLo Real slot, which is the Low-Low alarm value for the KPI value as a percentage.
QUAT The qualityFactor Real slot, which is the external quality percentage factor used against the internally calculated quality component for OEE calculations.
QUAL The qualityLo Real slot, which is the Low alarm value for the quality component of OEE as a percentage.
QUALL The qualityLoLo Real slot, which is the Low-Low alarm value for the quality component of OEE as a percentage.
PERT The performanceTarget Real slot, which is the target for the Performance component of OEE as a percentage.
PERL The performanceLo Real slot, which is the Low alarm value for the performance component of OEE as a percentage.
PERLL The performanceLoLo Real slot, which is the Low-Low alarm value for the performance component of OEE as a percentage.
AVAT The availabilityTarget Real slot, which is the target for the value for the Availability component of OEE as a percentage.
AVAL The availabilityLo Real slot, which is the Low alarm value for the Availability component of OEE as a percentage.
AVALL The availabilityLoLo Real slot, which is the Low-Low alarm value for the Availability component of OEE as a percentage.
OEET The oeeTarget Real slot, which is the target for the OEE value for the oeeCurrShift slot.
OEEL The oeeLo Real slot, which is the Low alarm value for the OEE value as a percentage.
OEELL The oeeLoLo Real slot, which is the Low-Low alarm value for the OEE value as a percentage.
CONN The connection Varstring slot, which is the optional OLE DB connection string for logging of KPI and OEE data.
SRAT The sampleRate Integer slot, which is the rate at which samples are sent to the database, in minutes (1-60) or 0 to disable this.
SBY Disable on standby – this disables writing to SQL on the standby server to avoid double entries.
PROD The product String slot, which is an optional product name that is recorded with database entries.
BID The batchID String slot, which is an optional batch ID that is recorded with database entries.
LST0= The historicalData List slot, which is a list of historical OEE and KPI shift values for up to 30 days.
...
LSTn-1=
LSTn=<EOL>
