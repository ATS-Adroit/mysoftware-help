Recipe Agent - Slot Details

The Recipe Agent holds information to control batching operations.

This agent is located in the following file: T_RECIPE.DLL

Slots:

Note1 All slots marked with a superscript R are read only slots.

Note2 All slots marked with a superscript X should be left untouched.

Slot Name Type Function

active R

INTEGER

Master Recipe: equal to the currentRecipeId of the currently active control recipe. If no control recipe is active then this slot is equal to minus one.

activeName

STRING

Master Recipe: the name of the control recipe that is currently executing or that has just executed.

addRecipe

BOOLEAN

Master Recipe: used to add an empty control recipe.

batchCounter

INTEGER

Control Recipe: the number to be appended to batchPrefix to make up the batch name. This counter is incremented after a control recipe has completed execution.

batchPrefix

STRING

Control Recipe: batch prefix

controlRecipe X

VARSTRING

Control Recipe: stores the control recipe

currentBatchName R

STRING

Master Recipe: the batch name of the control recipe that was last active or is currently active. This slot is simply the control recipe slot batchCounter appended to the control recipe slot batchPrefix. This slot is updated when a control recipe is active.

currentPhaseTrigger X

STRING

Master Recipe: the agent.slot to trigger the start of a new phase. This slot is updated during control recipe execution.

currentRecipeId

INTEGER

Master Recipe: the numerical identity of the current selected control recipe. Numerical identities start at 0. Set this slot to access a control recipe with equivalent identity. This slot can be set while a recipe is active. When changed, the slots currentRecipeName and currentBatchName are updated.

currentRecipeName

STRING

Master Recipe: the name of the current selected control recipe. Set this slot to access the slots of a control recipe with the equivalent name. This slot can be set while a recipe is active. When changed, the slots currentRecipeId and currentBatchName are updated.

currentStepMessage R

STRING

Master Recipe: status message during Control Recipe execution. A descriptive message of what is happening during control recipe execution. This message includes a step number.

currentStepNumber R

INTEGER

Master Recipe: the last executed step of an active control recipe. This value is zero if no control recipe is active. This slot is automatically updated during control recipe execution.

deleteRecipe

BOOLEAN

Master Recipe: used to delete the control recipe identified by currentRecipeId and currentRecipeName.

eventLoggingActive

BOOLEAN

Master Recipe: if equal to zero, then no event logging will take place. If equal to one, then all events will be logged. If equal to two, then all events except those regarding phases will be logged.

exportName

STRING 

Complete Recipe agent: the full path and filename of the CSV file where the complete Recipe agent (both the master recipe and its control recipes) will be exported. When this slot is set, the complete Recipe agent will be exported immediately. See note below "importName" slot.

importName

STRING

Complete Recipe agent: the full path and filename of the CSV file where the complete Recipe agent (both the master recipe and its control recipes) will be imported. When this slot is set, the complete Recipe agent will be imported immediately.

Note: If this is used in conjunction with the " exportName" slot, it is now possible to redefine the contents of the master and control recipes completely. But if control recipe names are changed then their respective batch numbers will be reset to zero.

lock

BOOLEAN

Master Recipe: used to lock access to a control recipe.

masterExportName

STRING

Master Recipe: the name of the CSV file where the master recipe will be exported. When this slot is set, the master recipe will be exported immediately.

masterImportName

STRING

Master Recipe: stores the name of a CSV file to import the master recipe from when the slot masterImportTrigger is set to 1.

masterImportTrigger

BOOLEAN

Master Recipe: if set to 1, the master recipe will be imported from the CSV file named in masterImportName.

masterRecipe X

VARSTRING

Master Recipe: stores the master recipe.

private X

RAWBYTES

Master Recipe: this slot is used internally and should not be accessed.

recipeExportName

STRING

Control Recipe: the name of the CSV file where the control recipe will be exported. When this slot is set, the control recipe will be exported immediately.

recipeImportName

STRING

Control Recipe: stores the name of a CSV file to import the control recipe from when the slot recipeImportTrigger is set to 1.

recipeImportTrigger

BOOLEAN

Control Recipe: if set to 1, the control recipe will be imported from the CSV file named in recipeImportName.

recipeList R

VARSTRING

Master Recipe: stores a list of all control recipe names.

recipeListChanged X

INTEGER

Master Recipe: indicates that a name in the control recipe list has changed.

recipeName

STRING

Control Recipe: the name of the control recipe.

rollbackActive

BOOLEAN

Control Recipe: if TRUE then when a verification failure occurs, one of the three actions defined in rollbackSelection will be taken.

rollbackRecipeName

STRING

Control Recipe: the name of the recipe to rollback to.

rollbackSelection

INTEGER

Control Recipe: indicates which of the following rollback actions to take.

rollbackStepNumber

INTEGER

Control Recipe: the step number to rollback to.

routeIndex

INTEGER

Master Recipe: route index for event logging.

runRecipe

STRING

Master Recipe: the name of a control recipe to execute. Set this slot to activate a control recipe.

start

BOOLEAN

Master Recipe: set to activate the recipe identified by currentRecipeName and currentRecipeId.

stop

BOOLEAN

Master Recipe: can be used to stop the execution of a control

totalRecipes R

INTEGER

Master Recipe: equals the total number of control recipes.

totalSteps R

INTEGER

Master Recipe: the total number of steps in the master recipe.

verificationTime

INTEGER

Control Recipe: the delay time in milli-seconds to wait at the end of a phase before doing a verification check.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Ready

On when Recipe has finished

status bit 17

Activated

On when Recipe is running

status bit 18

Verification Failure

On when Recipe has failed verification check

status bit 19

Execution Failure

On when Recipe has failed in execution

Methods of creation:

Manual

Agents created by default:

None
