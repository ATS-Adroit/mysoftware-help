Notify Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

SUN=string

The name of the user that is to be notified.

Slot name = user-name

SUC=string

The code that is usually used to identify the pager.

Slot name = user-code

FLDS=varstring

 

Fields to be sent.

Slot name = alm-fields

i.e. <Field Name>:<#characters>,<Field Name>:<#characters>,…

e.g. Source:7,Date:10,Time:8,Agent:15,Description:20,Alarm Type:10,Reported Data:8,Computer:10,Sub-Source:10

BFTS=boolean

If TRUE then spaces will be trimmed off the end of the fields.

Slot name = alm-field-trim-spaces

BF=boolean

If TRUE then the field name will be included in the message to be transmitted.

Slot name = alm-field-in-msg

SFD=string

String that separates the field name from the data if field-in-msg is TRUE.

Default value is ": ".

Slot name = alm-field-data-str

SF=string

String that separates each field to be sent. Default value is " ".

Slot name = alm-field-str

BSET=boolean

If TRUE then transmit information when an alarm is set.

Slot name = alm-send-if-raised

ILMX=integer

Only this number of recent alarms will be sent. Zero implies option disabled.

Slot name = alm-list-send-length

BTLP=boolean

If TRUE the send the alarm list periodically.

Slot name = alm-list-send-periodically

TLP=integer

List will be sent every alm-list-period minutes after the start of period time.

Slot name = alm-list-period

TLSP=time

List will be sent periodically starting from this time.

Slot name = alm-list-period-start
