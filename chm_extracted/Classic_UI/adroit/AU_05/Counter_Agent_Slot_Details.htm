Counter Agent - Slot Details

The Counter Agent takes data from any Input Tag’s BOOLEAN slot and calculates the time spent On (1) and the time spent Off (0), counts the number of On and Off events, and totalises the On and Off time.

This agent is located in the following file: T_COUNTER.DLL

Slots:

Slot Name Type Function

catchupData

RAWBYTES

Internal use only (used for datalog and real-time data catch-up).

contPause

BOOLEAN

True if agent is operational, otherwise false.

STRING

The tag name (agent.slot) of the input signal.

inputValue

offTime

BOOLEAN

Use this to manually trigger the agent to cause it to update.

BOOLEAN

Resets the computation if set to 1, then the slot returns to a value of 0.

ssButTextValue

Contains the string start or stop depending on value of startStop slot.

BOOLEAN

BOOLEAN
