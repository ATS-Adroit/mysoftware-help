Device Agent - Slot Details

The Device Agent facilitates the configuration and control of front end device (PLC) communications.

This agent is located in the following file: T_DEVICE.DLL

Slots:

Slot Name Type Function

browserInfo

RAWBYTES

Internal use only (Browser information).

commsFail

BOOLEAN

Communications failed indicator, either 0 or 1.
config VARSTRING Used internally by the Object Model to get or set the configuration of this device.

drvNextAddr

STRING

Next consecutive address in device.

drvOptions

RAWBYTES

Protocol driver options string.

drvType

STRING

Protocol driver DLL name.
hdaAll BOOLEAN If set, the OPC client will attempt to retrieve historical data for all the scanned tags between the specified hdaStart and hdaEnd times.
hdaEnd TIME Set by the user to denote the end time of subsequent OPC HDAOPC Historical Data Access (OPC HDA) is used to retrieve and analyse historical process data. retrievals.
hdaFile STRING If set to a valid file name, the OPC client will attempt to retrieve historical data for all the tags listed in this file between the specified hdaStart and hdaEnd times.
hdaGroup INTEGER If set to a scan job number (which represents an OPC group), the OPC client will attempt to retrieve historical data for all tags contained in that group between the specified hdaStart and hdaEnd times.
hdaItem STRING If set to a valid scanned tag, the OPC client will attempt to retrieve historical data for that tag between the specified hdaStart and hdaEnd times.
hdaStart TIME Set by the user to denote the start time of subsequent HDA retrievals.
isNASA BOOLEAN Set to True (1) when the device is a NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. device.
lastError STRING Displays the last communication error received from the front-end device. This contents of this error is unaffected by the current datascope mode of this device (ASCII or HEX).

recovPeriod

INTEGER

Communications recovery/cooldown period (milliseconds).
refresh BOOLEAN If set to 1, all the associated Scan agents do a read transaction.
resetConnection BOOLEAN If set to 1, the device closes and re-opens the connection to the remote device after the current transaction has completed.

start

BOOLEAN

Start/stop all the scanning for this device.

subsCount

INTEGER

Number of the @scanned tags configured for the device.
supportsDemandScan BOOLEAN Set to True (1) when a NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. device is configured to support demand scanning. For more details, see Demand Scanning.
supportsOutputInit BOOLEAN Set to False (0) if a NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. device does not support the output initializing of scanned values.
switchConnection BOOLEAN

If set to 1, the device agent is forced to switch from primary to secondary (if configured) or from secondary to primary.

Note: This has nothing to do with cluster switchovers.

tagCount

INTEGER

Count of the tags scanned in the device.

tagList

LIST

List of tags scanned in the device.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Started

Device Started

status bit 17

Healthy

Communications Healthy

status bit 18

Running

Running i.e. Started and Healthy

status bit 19

Stopped

Stopped i.e. NOT Running

status bit 20

Alarm

Alarm, i.e. Running and NOT Healthy.

status bit 21

Primary

On if the device is configured to use the Primary port.

status bit 22

Secondary

On if the device is configured to use the Secondary port.

status bit 23

DisableAtScanning

On if @scanning has been disabled for this device.

Note: This is set via the following device-specific registry setting: DisableAtScanning.
status bit 24

BadAttach

On if the Device agent did not attach to the device, which can occur if there is a bad serial port, missing 3rd party software etc.

Methods of creation:

Manual

Agents created by default:

None
