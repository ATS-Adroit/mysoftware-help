DumpConfig Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

ENA=0 or 1

BOOLEAN Enabled status (0 disabled, 1 enabled), when set to [1] this enables the agent to start saving agent configurations to the specified database.

SCH=number

If set to a number greater than [0].

  • This number specifies the hourly interval that will be used to trigger this agent to save the specified agent configurations to the database.

If set to [0].

  • Disables this method of triggering this agent.

TTAG=string

Tag name (agent.slot) used to trigger this agent to save the specified agent configurations when this value changes.

  • As selected in the configuration dialog.

DMPN=0 or 1

BOOLEAN status of the DumpNow setting.

  • When set to [1] this forces the agent to save all the currently configured agent configurations to the specified database.
  • As selected in the configuration dialog.

CONN=string

The OLE DB connection string for the database. 

  • As selected in the configuration dialog.

LST=list

The Agent type configuration list, which specifies the agent types, their slots, and the agent instances to save to the database.

  • As selected in the configuration dialog.
DPA=0 or 1

Interval mode.

  • As selected in the configuration dialog.
DPS=0 or 1

Interval tag.

  • As selected in the configuration dialog.
