Scan Agent - Slot Details

This agent is located in the following file: The Scan Agent carries out bi-directional communications with a front-end device by means of a protocol driver.

Each Scan agent has its own thread, and is responsible for scanning a dedicated block of addresses within the front-end device.

Since most devices will contain several such blocks of addresses, this multi-threaded design means that genuine parallel, or concurrent, front-end device I/O is possible.

This agent is located in the following file: T_SCAN.DLL

Slots:

WARNING! Since this is an internal agent, it is not advisable to manipulate its slots externally!
