Working with Adroit OPC Server Nodes

When typing in an OPC itema string, uniquely describing an individual data element residing in an OPC server. It may be up to 80 characters long, and structured hierarchically typically using a period "." to separate each level. name into the AdroitOPC Server extends the normal "dot-notation" referencing system of OPC to include "nodes", in other words: nodename.agenttype.agentname.slotname.

A node like an Agent Server, but transparently provides redundancy (especially for Agent Server clustering) by specifying a backup (standby) Agent Server, the backup server provides the values when the preferred server is unavailable.

In other words nodename, specifies the network location of either one or two Agent Servers, so that if the first Agent Server becomes unavailable or becomes the standby Agent Server in a cluster, then the other Agent Server, will be queried for the required values.

The Adroit OPC Server can run on any computer, from which it will connect to the Agent Server specified by the currently selected node.

Note1: It is recommended that the node name is the same as the network name of the computer, on which the OPC Server exists, or the name of the cluster.

Note2: When specifying or removing unwanted nodes, if a node is not selected in the Nodes list, then the FIRST node in the list is used by default.

To select and/or configure a node:

  1. Press the Windows key and start typing in the required application name and select it from the list, in this case:

    OPC Server

  2. Click on the Edit menu and select Properties.
  3. In the Adroit OPC Server Configuration dialog, select the required node in the Nodes list box.

Note: The default node is the name of the local computer network name, which refers to the local Agent Server.

Tip: If you want to configure another node, you can click the Add button to add a new node to the Nodes list first, which initially contains any preexisting node configuration.

  1. If required, in the Server 1 edit box, specify both the location and name of the Agent Server, that will be queried for the specified tags first, in the following format: AScomputername.AgentServerName, where:
  2. AScomputername, indicates the network name of the computer, on which the Agent Server exists
  3. AgentServerName, indicates the name of the Agent Server on this computer, as specified in the Adroit Setup.
  1. If required, also specify an alternate Agent Server in the Server 2 edit box.

Note: If Server 2 is specified, this Agent Server will only be referenced by the Adroit OPC Server if the Agent Server specified as Server 1 becomes unavailable e.g. it is no longer the master of a cluster or it has been switched off for maintenance etc.
