Adroit OPC Server

What is OPC?.

The Adroit OPC Server is OPCstands for OLE for Process Control, which is designed to alllow an I/O server developed by a 3rd party to communicate to any SCADA. 2.0 compliant and exposes each tagA fully qualified named value in Adroit (agentName.slotName). in an Agent Server as an I/O point to an OPC clientan application that uses the data provided by an OPC server. application.

Launching:

  1. Initially this AdroitOPC Server must be run manually for configuration purposes, but thereafter whenever an OPC client application connects, it launches itself automatically.

  2. Press the Windows key and start typing in the required application name and select it from the list, in this case:

    OPC Server

  3. When the OPC Server starts it is added to the system tray, in the bottom right of the screen.

Configuration:

  1. Double-click this icon to open the OPC Server item-address browser window. For details, see The OPC Server browser window.
  2. Click on the Edit menu and select Properties, to display the OPC Server Configuration dialog.
  3. The Adroit OPC itema string, uniquely describing an individual data element residing in an OPC server. It may be up to 80 characters long, and structured hierarchically typically using a period "." to separate each level. convention is: nodename.agenttype.agentname.slotname, where:
  4. nodename, specifies the node, which is like an Agent Server, but transparently provides redundancy (especially for Agent Server clustering).For details, see Working with Nodes.
  5. agenttype is the agent type (e.g. Analog or Digital),
  6. agentname is the name of the applicable agent (e.g. MYANALOG or AIRCON01_SP) and
  7. slotname is the slot of the value that is required (e.g. Value).

Licensing issues:

The Adroit OPC server will deduct a scan point, from your license, for every unique tag whose value is changed.

Note: Pure read-only values are no longer licensed, therefore populating the browser will no longer require scan points.

Security issues:

  1. To avoid any DCOM setup considerations when creating remote OPC connections, it is recommended to run the OPC server on the same computer as the client application.
  2. If you are connecting to the OPC server from a remote computer, read the security issues that need to be in effect. If difficulty is experienced in connection to the Adroit OPC Server, read the troubleshooting section.
