About the Adroit Security Manager

The Adroit Security Manager provides a single utility that contains all the Windows and Adroit security settings you require to fully secure your Adroit installation. This utility also allows you to save the security settings that you configure, so that these can be applied to other Adroit computers, as needed.

Note: Only users that are members of the Administrator user group of their computer and/or the network domain can use this application to configure these security settings.

Press the Windows key and start typing in Security Manager and select it from the list.

The left hand pane of this utility provides the following three expandable/collapsible branches:

Note: These branches are displayed in the order in which you will typically configure these security settings.

  • TheWorkgroup/Domain branch: specify the required Windows user groups and/or users for your Adroit installation. If necessary, the typical (default) Adroit groups and user can be created for you.
  • TheWindows Security Options branch: these settings apply to the Windows operating system.
  • The Adroit Security Options branch: these settings specifically apply to the Classic UI application.

Once you select an option from one of these branches, it can be configured in the right hand pane.

Tip: Each option provides a brief description of what you can configure by using the selected option, which is displayed in bold blue text at the top of the right hand pane.

Configuring Groups and Users: how to use the Adroit Security Manager to configure the necessary groups and their users.

Exporting and Importing Groups and Users: how to use the Adroit Security Manager to export and import configured users and groups.

 

Configuring Windows Security Policies: the policies provided by the Adroit Security Manager to secure the Windows operating system of a computer.

IMPORTANT: Simply enabling a policy (option) does NOT change this policy on this computer; you need to APPLY the policy to a specific computer in order to change the security settings of this computer.

Applying Security Policies: how to use the Adroit Security Manager to save and/or apply the specified security settings. 

 

For more details about using Windows security to secure Adroit, see Windows Security for Adroit.
