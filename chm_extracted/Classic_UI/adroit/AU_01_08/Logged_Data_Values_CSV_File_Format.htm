Logged Data Values CSV File Format

Note: Backup (LGB) files can be created when logging to the Adroit proprietary datalog (.LGD) files so that this historical data can be retrieved by the datalogging system when needed. This can also create CSV files too, to make this historical data available to third party applications such as Microsoft Excel and formatted to create reports. For details, see Datalog backup and retrieval.

After you have exported data logged values to a CSVComma Separated Value file containing data, which consists of a number of fields in one or more rows, in which the different fields (values) are typically separated by commas. file, this file provides the following columns:

date, time, value, comment

  1. The purpose of the comment field is to label each data log entry indicating how and when the value was derived.

  2. For every session, defined as the period between startup and shutdown of the Agent Server, Adroit always marks the first and last entries in the log as the post startup and last known values.

    Note1: To prevent logging the POST_STARTUP value after an Agent Server restart, configure the Disable first datalog entries on startup of agent serverglobal datalogging setting. See Advanced Datalog Configuration (global settings).

    Note2: Post startup values apply to all datalogs regardless of whether their input tag is scanned or not.

  3. All intermediate values will be marked as normal or bad.

  4. When retrieving data for viewing or analysis, the requested interval time may not coincide with the actual logging time.

    Therefore, Adroit calculates the values that occur between the recorded values either by estimation (if between sessions) or interpolation (if within the same session).

    The following symbols in the second column are used in the extracted .CSV file:

Symbol Represented Value Description

s

Post_Startup_Value

this is the first value logged after startup

l

Last_Known_Value

this is the last value known before shutdown

*

Estimated_Value

this estimated value lies between a last known value and a post startup value outside a session

 

Interpolated_Value

this interpolated value lies between two consecutive normal values within a session

 

Normal_Value

this value was logged normally by the DataLog agent

b

Bad_Value

this value should not be trusted as the Bad status bit was set when it was logged

?

Unknown_Value

extracted value is unknown

 

Note: When viewing this CSV file in a third party application program, such as Excel, ensure that the "Time" column format is set to the "hh:mm:ss" setting, so that the time value is not inadvertently truncated.
