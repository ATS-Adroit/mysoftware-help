The illustration below shows the effect on disk space after a period of 1 month.

The impact of these data compression effects, together with the fact that some values often remain constant for extended periods, indicate that much of the reserved buffer spaces within the data log file remain unused.

Note: Since each Datalog agent has a maximum of 53 million records, which can provide at least 30 days of logging at a log rate of 50 milliseconds!

Tip: If you use datalog backups, which create .LDB files, then you can extend the potential amount of logged data without creating larger log files. In this case, while the active log (LGD) file can remain small, the log backup (.LDB) files can store historical data for much longer time periods. For details, see Datalog backup and retrieval.
