The SystemDatalog Agent

The SystemDatalog agent manages the Datalog catch-up of all configured Datalog agents, which only applies to clustered Agent Servers and refers to the process of synchronizing, unsynchronised sections of logged data between the two Agent Server partners in the cluster. This involves fetching stored historical data from the datalog agents on the cluster partner and merging the data with the local datalog agents.

Note: For performance reasons, the SystemDatalog agent ONLY provides the Time datalog catchup method, of catching up the data between two specified date/times.
