Out of limit data logging

Out of limit monitoring enables Datalog agents to immediately log out of limit values (values that are not within their specified operating range), by ignoring the normal time deadband value and using the faster log rate specified by the out of limit time deadband instead.

In other words, as soon as the logged value that is being logged, enters or leaves its user-specified limit range it is logged unconditionally, and continues to be logged at the new time deadband as specified by the Out of limit logging time setting (Time...). This allows the Datalog agent to catch short spikes whose duration is less than the normal time deadband logging interval (Deadbands -> Time...)

Usage Example:

A customer wants to monitor his incoming voltage of 220 V.

Previously, without using out of limit monitoring: he would create a Datalog agent to log this voltage tag at a logging rate of 1 second for a period of 1 week. So, in this case, this Datalog agent is configured (Length = 7 days and Deadbands Time = 1 sec) to log all changes to the voltage at 1 second and always keep one week's worth of this data.

Using out of limit monitoring: since he is actually not that interested in logging this voltage, if it remains within its normal operating voltage range of 215-225 volts, as long as the voltage is within this value range he is happy to log it at a far slower rate - say 10 seconds.

But when the voltage breaches this range, then he wants this Datalog agent to log this value at 1 second intervals. So, in this case, this Datalog agent is configured (Length = 7 days and Deadbands Time = 10 sec and Out of limit monitoring Time = 1 sec and Upper limit = 225 and Lower limit = 215).

Note: In this case he will be able to catch short voltage spikes whose duration whose duration are less 10 seconds, the normal logging interval.

Configure the Out of limit monitoring section, at the bottom, of the Edit Datalog agent dialog, as follows:

  1. Set the Time... (limitLogInterval slot) to the required out-of-limit logging interval, which is typically much faster than the in-range logging interval.

IMPORTANT: Configure this log interval at the required sample rate while the value is out of limits to catch its short value spikes.

  1. Configure the Upper limit (upperLimit slot) and Lower limit (lowerLimit slot) fields to define the normal operating range for the value that is being logged.

Note: If both of these limit values are zero (default values) then NO limit checking is done and the Datalog agent operates normally.

 

To disable out of limit data logging: this disable any limit checking so the Datalog agent operates normally and ignores the "out of limits" log interval
