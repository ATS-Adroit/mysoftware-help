Enhanced Data Logging

The data logging sub-system of Adroit provides the following enhancements:

  1. Improved performance : using the datalog change queue to improve the data logging sub-system performance.
  2. Demand logging : configuring Adroit to only log data at specific times or events, such as at the end of a batch.
  3. Multiple log sets : instead of specifying only a single rate and period per datalog agent configuration, you can create multiple log sets within a single datalog agent.
  4. Improved Integrity : the Agent Server ALWAYS honors the data log settings as found in the agent database (WGP) file to prevent Datalog agent exceptions.
  5. Advanced Datalog Configuration (global settings): all the global settings that affect the operation of the data logging sub-system can be configured from a single dialog, whenever a user logs a tag.
