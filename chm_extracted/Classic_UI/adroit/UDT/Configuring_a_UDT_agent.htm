Configuring a UDT Agent

The UDT Agent Type Designer creates UDT agent types that emulate the structure of a UDT in a PLC. Once created you need to add one or more agents to these UDT agent types (templates). Then configure and scan these agents to their corresponding UDTs in the required PLCs.

PLEASE NOTE :Every instance (agent created) of an UDT agent type will consume (number of slots-1) scan points. The other scan point will be consumed if and when its rawValue slot is scanned.

To edit a UDT agent: how to display the edit dialog of a defined UDT agent.

  1. Ensure that your Agent Server is started.
  2. If the Adroit User Interface of your choice.
  3. Open the Agent configuration dialog.
  4. Select the name of the required UDT agent type from the Type list box.
  5. Type the name of the required agent in the Name edit field.
  6. Click the Add button.

PLEASE NOTE :Every instance (agent created) of an UDT agent type will consume (number of slots-1) scan points. The other scan point will be consumed if and when the rawvalue slot is scanned.

  1. Double click this agent in the Agents list box to display its edit dialog.

IMPORTANT When you edit UDT agents you must also remove all existing agent instances of this UDT agent type from the Adroit agent database (.WGP) file!

When you change the structure of a UDT agent (by using the UDT agent designer), then any UDT agents of that type that are already saved in a WGP file will prevent the WGP file from loading because their saved structures are now incorrect.

Therefore when you change the structure of a UDT agent, you must remove all instances of this UDT agent type from the WGP file.

For example if you have a UDT agent type called MOTORE, whose structure you have changed, then you need to:

EITHER manually delete all agents of this MOTORE agent type.

OR you can use the WGP Remove utility to do this for you and back up the original WGP file.

Note: This utility can be installed from the Additional Components install that provided on the Adroit 10 DVD or can be downloaded from the Adroit website.

In this case, open the Command prompt, in Administrator mode (in Windows 8.1, right click the Windows button and select the Command Prompt (Admin) item).

Type in: wgpremove motore

This removes all instance of the MOTORE agent type from the currently configured WGP file in Adroit Config (if using the SmartUI) or in the Classic Adroit Setup (if using Classic Adroit) and back up the original WGP file.

To configure a UDT agent: how to configure the edit dialog of a defined UDT agent.

  1. Check the Live checkbox, to immediately save changes made to the configuration of this agent, without needing to click the Update button first.
  1. Check the Auto-refresh checkbox, to immediately refresh the dialog to display the latest values of these properties, without needing to click the Refresh button first.

Tip: Only use this setting for monitoring the UDT property values; do NOT use this when you are changing UDT properties values from this dialog.

  1. For each of the properties that are defined for this UDT, you can configure the following:
  2. Value: This is ONLY editable if the Readonly checkbox for this property is cleared in the UDT Agent Type Designer utility.
  3. Tag reference: Specify a tagA fully qualified named value in Adroit (agentName.slotName). whose value will be mirrored with this property value. In other words the current value of this property will be copied into the specified tag. Clicking the browse button to select this tag using the tag browser. For details, see Selecting a tag.
  1. Click OK once you have configured this agent appropriately.

To scan this UDT agent: how to communicate the UDT this agent represents to its corresponding UDT in the required PLC.

  1. Right click this agent in the Agents list box.
  2. Select the Scan… menu item to display the Tag scanning configuration dialog.
  3. Select the device that communicates to this PLC from the Device list box.

Note : Currently you can only specify devices that communicate using theBeckhoff and Alan Bradley protocols.

This automatically selects both this Agent name and its required Slot, in this case rawValue.

  1. Specify the Address of the corresponding UDT in this PLC.
  2. If necessary, specify the required Scan Rate, in milliseconds and Deadband settings.

Note : These settings apply to ALL the properties specified within this UDT.

  1. You should NEVER check the Scan (input) inhibited checkbox.
  2. It is NOT recommended to check the Output Enabled checkbox when your UDT contains properties that are a mixture of read and write variables. Click for more details:when a control is done the ENTIRE UDT is written back to the PLC which may overwrite the values of readonly properties. 
  3. Click the Scan button.

Repeat this procedure for all the UDTs you need to configure.

Note: The value slots are saved and the agent edit dialog is resizable.
