Creating UDT Status Bit Expressions

When defining status bits for your UDT, it is necessary to create a conditional expression that describe a state of one of more of the slots of this UDT that need to be alarmed. Therefore the result of this expression must either be True (1) or False (0).

Note:  The result of this expression must either be True(1) or False(0).

To configure an expression for a status bit of a UDT:

  1. Launch the UDT Agent Type Designer and select the required status bit from the Status bits list in the Selected UDT - Status Bit section of this dialog.
  2. Specify the required expression for this status bit in the Status bit expression edit field.

Expression Conditions

Your expressions can contain one or more of your defined slots, such as:

Logical expressions Condition for success
Slot(value) > 95 SUCCESSFUL if the Value slot is greater than the value of 95
Slot(Open) & (Slot(value) > 95) SUCCESSFUL if the Open tag is On and the Value slot is greater than the value of 95

Expression Elements

Your expressions can use one or more of the following operator elements:

Tip:

  1. You need to enclose each slot name defined by this UDT within the Slot() specifier, e.g. Slot(Open)
  2. If a slot is NOT enclosed within a Slot() specifier then the status bit will NEVER be True
  3. Multiple items are separated by commas ','
  4. Where necessary, the description of an operator is displayed in brackets () after the operator
Element Types Operators / Example
Other logical operators ! (not), & (and), | (or)
Arithmetic operators +, -, *, /, % (modulus),^ (power)
Parentheses (), {}, []
Scientific notation 3E+10
Constants  2, 3, 50
Functions MIN(4,5), SQR(34)

Expression Function Usage

Your expressions can also use one or more of the following functions:

Note:  
These functions can take either constants or slot values as their parameters.
For simplicity, the slot specifiers have been omitted, where Slot1 = Slot(SlotName)

Functions Usage
MIN : returns the minimum value MIN(2, 3, 4, 5) is 2.
MAX : returns the maximum value MAX(2, 3, 1, 0) is 3.
IF(condition, valueIfTrue, valueIfFalse) IF(1, 2, 3) is 2
SUM : adds the values together SUM(1, 2, 3, 4) is 10
AVG :averages the values AVG(1, 2, 3, 4, 5) is 3
SQR: returns the square of the value SQR(Slot1)
SQRT: returns the square root of the value SQRT(Slot1)
EXP : Returns E raised to the power of the value EXP(Slot1)
INTPOW(Base, power): raises the Base to an integral power INTPOW(2, 3) = 8
POW(Base, power): raises the Base to any power

Note:  For fractional exponents or exponents greater than MaxInt, the Base must be greater than 0.

 POW(2,3) = 8
LN: returns the natural logarithm of the value LN(Slot1)
LOG: returns the base-10 logarithm of the value LOG(Slot1)
LOGN(Base, value): returns the log Base of the value LOGN(10, 100) = 2
ABS: returns the absolute value ABS(Slot1)
SIGN: returns the sign of the value SIGN(Slot1) returns -1 if Slot1<0; +1 if Slot1>0, 0 if Slot1=0
TRUNC: discards the fractional part of the value TRUNC(-3.2) is -3, TRUNC(3.2) is 3
CEIL: returns the value rounded up, away from zero CEIL(-3.2) = -3, CEIL(3.2) = 4
FLOOR: returns the value rounded down, toward zero FLOOR(-3.2) = -4, FLOOR(3.2) = 3
SIN: returns the sine of the value (an angle in radians) SIN(Slot1)
COS: returns the cosine the value (an angle in radians) COS(Slot1)
TAN: returns the tangent of the value (an angle in radians) TAN(Slot1)
ATAN: returns arctangent, or inverse tangent, of the value. The returned angle is specified in radians ATAN(Slot1)
SINH: returns the hyperbolic sine of the value SINH(Slot1)
COSH: returns the hyperbolic cosine of the value COSH(Slot1)
COTAN: returns the cotangent of the value COTAN(Slot1)
