ScanTag ActiveX Method

PLEASE NOTE: This method uses scan points because it uses putslot functionality internally, therefore ensure that the Agent Server computer either is licensed (i.e. has a HASP Software Protection Key attached) or that the Agent Server is run using the Limited Time License HASP.

SCADA Functionality.

 

Method ScanTag (AgentOrSlot:String, Slot:String, Device:string, Address:String, Rate:Long, DeadBand:Long, OutputEnable:Long):Boolean;

This method configures a tagA fully qualified named value in Adroit (agentName.slotName). for scanning.

 

Parameters:

  1. AgentOrSlot: the name of the agent or tag (agent.slot) that is to be scanned.
  2. Slot: the name of the slot to be scanned. This parameter is ignored if the Agent parameter contains a tag.
  3. Device: the name of the Device agent interfacing to the PLC or other front-end device, e.g. SIMPLC
  4. Address: the scan address of the point to be scanned, e.g. DB2:DW0
  5. Rate: the scan period in milliseconds at which point is to be polled.

Note: This parameter is ignored when this method is used to @scan.

  1. Deadband: the scanning deadband in scanned units.

Note: This parameter is ignored when this method is used to @scan.

  1. OutputEnable: set to true if you want the scanned point to be an output.

To UNSCAN a specified item, specify the Rate (at which this item was scanned) as a negative value, while keeping all the other parameters correct.

In this case, the AgentOrSlot, Slot and Address parameters are case sensitive. For instance, if the item was scanned at a rate of 1500 milliseconds, then it is necessary to specify its Rate as –1500, in order to unscan it.

Note: In order to create a Device agent and add scan points to it, first create the device agent, using CreateAgent, then perform a ‘dummy’ Fetch to initialise the Device agent, which does NOT initialise itself when it is created and then use this method to add the required scan points to it.
