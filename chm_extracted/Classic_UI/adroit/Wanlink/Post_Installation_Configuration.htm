Post Installation Configuration

Wanlink is installed into the Adroit installation folder as part of the complete Adroit installation, alternatively its WanClient and WanServer components can be selectively installed during a custom installation. For details of these components, see Wanlink Components or for details of launching these components, see Launching Wanlink Components.

The following post-installation configuration actions can be performed on each Wanlink components:

WanServer

If the shortcut used to launch the WanServer includes the " /p:nnn" command-line parameter, then it will be able to change the port that this WanServer uses to communicate to the necessary WanClients (default 51114). Where nnn specifies the required port.

The WanServer can also be installed to run as a Service within Windows. The advantage of this is that then the WanServer does not shutdown when the current user logs off.

The WanServer also generates a WanServer.ini file which can be used when troubleshooting its communicating.

WanClient

If the shortcut used to launch the WanClient the "/start" command-line parameter, then it will automatically start its communication process.

Although the location and name of its database folder is initially hard coded, an alternate location and / or name can be specified, if necessary. For details, see Database folder
