Installing WanServer as a Service

The WanServer can run either as a standard Application or as a Service within Windows. The advantage of running this as a Service is that then the WanServer does not shutdown when the current user logs off.

Tip: It is recommended that the WanServer is initially run as an Application, which provides more diagnostic information during the configuration period.

ONLY once Wanlink is configured and running properly, then run the WanServer Service Setup application and install the WanServer as a Service.

Note: For default use, this service must run as a Local System account, and the Allow service to interact with the desktop option should be disabled.

If this is needed then the WanServer application icon will continue to appear in task bar.

The Server Service Setup Wanlink component, launches the Wanlink Server Service Setup dialog. For details on launching this, see Launching Wanlink components.

This dialog can be configured as follows:

  1. If you wish to install the WanServer as a Service, then click on the Install WanServer Service button.
  2. If you wish to uninstall the WanServer as a Service, then click on the Uninstall WanServer Service button.
  3. The WanServer Path displays the path to the WanServer that is being or that has been installed as a service, for diagnostic purposes.
  4. Click the OK button to accept the changes made and to exit.

WARNING! If you have made changes to this configuration, the computer will need to be rebooted for these changes to be implemented.
