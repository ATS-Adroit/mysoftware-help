Tag Links

The WanClient application initiates communications to one or more WanServer applications to fetch or send values of Adroit tags that occur in the Agent Server that is also running on the WanClient computer.

A tag link or tag mapping, simply specifies the name of the local and the remote Adroit tag, whose values are to be ‘linked’.

These are added to a tag group within a server, which together provide the communication settings, required by the WanClient to connect to the necessary WanServers. For details, see Servers or Tag Groups.

Note: The data type of the local and the remote tag must be identical.

Tag Links can be configured, as follows:

  1. To configure a new tag link.
  2. To edit an existing tag link.
  3. To delete an existing tag link.

Note: Any link that is deleted is permanently removed from the database and cannot be recovered later.

  1. To manually edit tag links – this may be necessary when adding a large number of tag links to one or more groups at once.
