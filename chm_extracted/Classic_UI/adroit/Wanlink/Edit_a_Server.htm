Edit a Server

A Server simply stores the necessary communication settings for a specific remote WanServer and its computer, so that the WanClient can connect to this computer and communicate with this WanServer application. For further details, see Servers.

To edit a server:

  1. If necessary launch the WanClient and open the WanClient Configurator, by selecting the Open Configurator item from the File menu.
  2. Click the Edit Servers button to display the Edit Remote Servers dialog.

Note: This dialog can also be used to delete servers.

  1. In the List of servers list box, select the required server that is to be modified.
  2. In the Full server title edit box, specify a name for the server, not more than 90 characters in length.
  3. The Database name field ONLY displays the CSV filename that was specified for this server to store its tag groups and tag links.
  4. In the IP Address edit box, either specify the exact IP address of the WanClient computer or specify the network name of this computer instead.

Note: If the computer name is specified then the WAN requires a LMHOSTS file or a WINS server to resolve the computer name into its corresponding IP address.

  1. The Port field, displays the port address that is being used by WanLink, which can be modified, if necessary.
  2. The Connect timeout edit box is not currently used.
  3. In the Transaction timeout edit box, specify the time in seconds before a requested transaction made to the server fails.

The default value of 5 is required for fast networks and a value from 15 – 20 can be used for slower networks.

  1. In the Retries edit box, specify the number of reties to be automatically attempted when attempting to establish a connection to this WanServer computer.
  2. In the Ping timeout edit box, specify the period in seconds to wait after the communications fail before the client will retry to establish communications.
  3. Uncheck the Enabled checkbox, if this server is not to be communicated to for a period, but will be required in the future and so is not to be deleted.
  4. Click the Ok button to accept the changes made to the list of servers or the Cancel button to discard any configuration changes and return to the WanClient Configurator.
