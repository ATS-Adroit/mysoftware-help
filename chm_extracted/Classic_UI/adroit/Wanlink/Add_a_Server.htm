Add a Server

A Server simply stores the necessary communication settings for a specific remote WanServer and its computer, so that the WanClient can connect to this computer and communicate with this WanServer application. For further details, see Servers.

To add a server:

  1. If necessary launch the WanClient and open the WanClient Configurator, by selecting the Open Configurator item from the File menu.
  2. Click the Add Server button to display the New Remote Server dialog.
  3. In the Full server title edit box, specify a name for the server, not more than 90 characters in length.
  4. In the Database name edit box, specify the name to be used by this server to store its tag groups and tag links.

This will be saved as a CSV file in the database folder, which is created in the folder in which WanClient has been installed.

Tip: This file can also be edited manually for bulk configuration of tag groups and bulk configuration of tag links.

Note: This filename should be not more than 90 characters in length.

  1. In the IP Address (or PC name) edit box, either specify the exact IP address of the WanClient computer or specify the computer name of this computer instead.

Note: If the computer name is specified then the WAN requires a LMHOSTS file or a WINS server to resolve the computer name into its corresponding IP address.

  1. The Port field, displays the port address that is being used by WanLink and cannot be changed.
  2. The Connect timeout edit box, is not used currently by Wanlink.
  3. In the Transaction timeout edit box, specify the time in seconds before a requested transaction made to the server fails.

The default value of 5 is required for fast networks and a value from 15 – 20 can be used for slower networks.

  1. In the Retries edit box, specify the number of reties to be automatically attempted when attempting to establish a connection to this WanServer computer.
  2. In the Ping timeout edit box, specify the period in seconds to wait after the communications fail before the client will retry to establish communications.
  3. Click the Ok button to add the server or the Cancel button to discard the settings and return to the WanClient Configurator.

Note: If the OK button is pressed, without all the fields being completed, a message box appears requesting that all the fields are completed first.
