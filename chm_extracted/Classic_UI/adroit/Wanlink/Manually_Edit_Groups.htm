Manually Edit Groups

Tag groups are primarily added to manage the communication settings for the tags whose values need to be communicated to or from the remote Agent Servers via their associated WanServers. Groups are server-specific. For details, see Tag Groups.

If it is necessary to bulk configure a large number of groups at one time, they can be manually edited.

To manually edit groups:

Groups are stored in the user-specified database filename of their applicable Server, specified when adding a server.

This .CSV file is located within the database folder and contains all the specific configuration of the tag groups and their tag links that have been configured within the specific server.

The first 6 lines of the file are comment lines.

The first two lines show both the name and IP address of the server, to which these tag groups and tag links are associated.

The next four lines then provide configuration specific information.

The columns, required when configuring a tag group, in the order that they appear in the file:

  1. [GROUP]: This is used to identify that a tag group, as opposed to a tag link, is being specified.

Note: This must not be any spaces before the [GROUP]’ indication.

  1. Group Title: This stores the name that has been given to this tag group, which must not more than 90 characters in length.
  2. Group Enabled: This stores the enabled status of the group, if the group is enabled this is 1, otherwise if the group is disabled this is 0.
  3. Group Deleted: This stores the deleted status of the group, if the group is deleted this is 0, otherwise if the group is not deleted this is 1.

If the group is deleted then it will be added to the list of groups to be recovered, until the Pack Database file menu item is executed, after which it is permanently removed from this file.

  1. Poll Period: This stores the rate in seconds at which the WanClient should request this WanServer for changes to the tag links within this tag group.

The default value of 0 implies "as fast as possible" and the rate will depend on the total number of configured groups.

  1. Buffer size: This is not being used.
  2. Group Type: This stores the communication type required by the tag links within the group.
  1. A Normal group, indicated by a 0, only permits the values of the tags links within this group to be fetched from the WanServer so that the values on the WanClient are updated accordingly.
  2. A Control group, indicated by a 2, also permits the tags links within this group to also send changes from the WanClient to the WanServer.
