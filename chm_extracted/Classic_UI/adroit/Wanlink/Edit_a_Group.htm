Edit a Group

Tag groups are primarily added to manage the communication settings for the tags whose values need to be communicated to or from the remote Agent Servers via their associated WanServers.

Groups are server-specific. For details, see Tag Groups.

To edit a group:

  1. If necessary launch the WanClient and open the WanClient Configurator, by selecting the Open Configurator item from the File menu.
  2. Ensure that the required server is selected in the Select server list box. For details, see Servers.
  3. Click the Edit Groups button to display the Edit Groups dialog.

Note: This dialog can also be used to delete groups.

  1. In the List of Groups list box, select a tag group that is to be modified.
  2. In the Group Title edit box, specify a name for this tag group, which must not be more than 90 characters in length.
  3. The Group Type list box, ONLY specifies the communication type originally selected for this group, as follows:
  4. Normal: This should contain tag links, whose local values (located in the Agent Server, residing on the WanClient computer) should ONLY be fetched (read) from the specified remote tag values via the required WanServers.
  5. Control: This should contain tag links, whose local values (located in the Agent Server, residing on the WanClient computer) can be BOTH fetched (read) from AND sent (written) to the specified remote tag values via the required WanServers.
  1. In the Poll Period edit box, specify the rate in seconds at which the WanClient should request this WanServer for changes to the tag links within this tag group.
  2. The default value of 0 implies "as fast as possible" and specifies a 1 second polling rate.

Note: Poll periods can be specified from 1 to 2000 seconds.

  1. Uncheck the Enabled checkbox, if the tag links within the tag group is not to be communicated to for a period, but will be required in the future and so should not be deleted.
  2. Click the Ok button to accept the changes made to the list of tag groups or the Cancel button to discard any configuration changes and return to the WanClient Configurator.
