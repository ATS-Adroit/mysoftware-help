Available Agents

The most fundamental building blocks of Adroit are intelligent objects called agents, which in addition to being able to manipulate their own data can read and write to other agents and so influence them. For further details, see About Agents or How agents can be used.

An Adroit configuration is therefore made of many different agents, each of which is a unique instance of one of the supported agent types. For details about how to reference agents, see Agent Referencing Convention.

Each agent type provides externally accessible data attributes, or slots. For a description of the slots provided by each agent type, see Agent Type Slot Reference.

 

The following is an alphabetic list of all the available agent types:

  • "The Accumulator agent" on page 1 : to analyse an accumulating process value to calculate its difference in value (or delta) between successive events or over a specific time period.
  • The AgentGroup Agent : combines agents that have something in common into groups.
  • The Alarm Agent : manages how incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). are communicated to the necessary personnel and/or applications.
  • The AlarmList Agent : lists current or unacknowledged incidents to display in an Alarm List Viewer window.
  • The AlarmManagement Agent : configures and records your active incidents so you can improve your alarming configuration.
  • The Alias Agent : creates a reference to an existing agent to adopt its Behaviour and state information.
  • The Analog Agent : stores a real (floating point) value and provides engineering functionality such as scaling.
  • The ARec Agent : configures up to 256 states using truth table type logic on up to 32 bits.
  • The Audit agent : supplements the Agent Server auditing by monitoring one or more tags for ANY change in value.
  • The Beeper Agent : provides simple audio output using the built-in PC loudspeaker.
  • The Boolean Agent : stores a Booleana value that only has two discrete states, 0 (FALSE) or 1 (TRUE). value.
  • The Command agent : sends and receives SMSShort Message Service is a service (protocol) for sending short text messages to and from mobile phones. messages to remotely configure or report on your process.
  • The Counter Agent : a simple counter and averager.
  • The Custom Agent: a generic agent type used to create user-defined agent types.
    Since this agent CANNOT be used in its generic format, the Custom Agent Designer utility, facilitates the creation of these user-defined agent types. For details, see How to Use the Custom Agent Designer
  • The DataLog Agent : manages the historical logging of process values (tagA fully qualified named value in Adroit (agentName.slotName).).
  • The Date Agent : holds time and date information broken down into the date and time constituents.
  • The DBAccess agent : performs a transaction on a row in an OLE DB compatible database.
  • The DBLog Agent : is a bulk OLE DB logging agent for typically logging Analog and/or Digital values to a specific table in a database for later retrieval.
  • The Device Agent : transfers process values between Adroit and the FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..
  • The Digital Agent : stores a Boolean value and provides engineering functionality such as value inversion.
  • The DumpConfig Agent: stores the configuration of specific agents in an OLE DB database.
  • The EventLogging Agent : manages the logging of events by Adroit to Windows event logs and to a database.
  • The EventOutput Agent : directs event log messages to output devices (printers, files, databases).
  • The Expression Agent : performs user-defined calculations to calculate an output value.
  • The Frame Agent : stores up to 32 indexed strings.
  • The Hasp Agent: displays the current Adroit license information.
  • The ICMP (PING) Agent : determines the existence of a remote device on the network.
  • The Integer Agent : stores an integer number +/– 2147483647 (32 bits).
  • The IOT Agent: can represent any object containing multiple properties (or slots).
  • The Marshal Agent : provides the functionality of 16 Digital agents in a single agent.
  • The MaxDemand Agent : monitors your electricity usage so that you remain within your agreed usage limits.
  • The MultiMedia Agent : runs a variety of Windows compatible multi-media files such as .WAV, .AVI and .MID.
  • The MultiState Agent : defines up to 16 discrete states to create operating and/or control sequences.
  • The Notify Agent : directs alarms to pagers and also to cellular phones via SMS.
  • The OEE Agent : EITHER calculates the OEEstands for Overall Equipment Effectiveness, which typically identifies the productivity or utiltization of a machine or an entire plant, as a percentage. for the monitored equipment and/or plant or measures a specific KPIKey Performance Indicator, a quantifiable measurement that measures how well something is accomplishing its goals and objectives. for a measured production value.
  • The PerfMon Agent : monitors up to 16 Windows Performance counters to detect performance bottlenecks.
  • The PID Agent : provides the 25 signals and tuning parameters associated with an external PID controller.
  • The Proxy Agent : provides continuous updates of the value of an agent referenced from a remote Agent Server.
  • The Real Agent : stores a real (floating point) value.
  • The Recipe Agent : provides basic sequencing and batching and reporting capabilities.
  • The Scan Agent : communicates one or more tags to an FED, these agents are managed by Device agents.
  • The Scheduler Agent : defines one or more time periods of time to enable or disable other agents.
  • The Script Agent : performs one or more Visual basic or Java scripts to do complicated tasks.
  • The Shift Agent : to configure your required shift patterns globally, for use by any interested agents. 
  • The SNMPMgr Agent : monitors and/or manages network devices using SNMPSimple Network Management Protocol (SNMP) is used to monitor and manage a diverse range of devices on a computer network..
  • The Statistical Agent : provides the basic functionality to create a statistical process control strategy.
  • The String Agent : stores a "string" of text characters, only the first 79 of which can be used whenscanningthe process of communicating a value (slot), typically to and/or from a front-end device (FED)..
  • The StringList Agent : stores an unlimited number of indexed ASCII character strings of variable length.
  • The SystemDataLog Agent : administers the backing up of datalogs and synchronises datalogs in an Adroit cluster.
  • The SystemInformation Agent : acts as an information center containing data that is global to the Agent Server.
  • The Text Agent : stores a 79-character text string (this length excludes the mandatory zero terminator character).
  • The Timer Agent : performs several commonly used timing operations.
  • The UDT Agent: a generic agent type used to create user-defined agent types that typically duplicate the structure of your UDTs in your PLCs, by adding properties (basic data types) to them.
    Since this agent CANNOT be used in its generic format, the UDT Agent Type Designer utility, facilitates the creation of these user-defined agent types, see UDT Agent Type Designer.
