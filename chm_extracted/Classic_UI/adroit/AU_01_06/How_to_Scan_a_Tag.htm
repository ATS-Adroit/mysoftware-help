How to Scan a Tag

Adroit allows one or more tagA fully qualified named value in Adroit (agentName.slotName). (values) to be communicated or scanned to a device, which is typically a FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..

Note: You need to create a device of the required protocol driver for each FED that uses this protocol driver.

For an example of scanning tags, see Scanning Example.

Note: If you are scanning this tag from a remote UI, the following ADDITIONAL REQUIREMENTS apply: Remote Scanning Requirements.

To scan a process value:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Select the required agent in the Agent Configurator, as follows:

  1. Ensure that the Basic, Advanced and/or System checkbox is checked to display the required agent type in this list. These checkboxes use these default agent groups to help you select the required agent quickly.

Tip: If no checkboxes are selected, then all the available agent types will be displayed in the Type list box. This is useful if the required agent type has not been categorised.

  1. Click the down arrow in the Type drop down list
  2. Locate the required agent type, using the scroll bar and click on it.
  1. In the Agents list, click on the name of the required agent (if necessary scroll down to locate this).

Tip: Right-click to display a menu of commands to perform upon the selected agent(s).

  1. Click the Scan… button to display the Tag scanning configuration dialog.

Tip: You can also right-click the agent and select the Scan… menu item.

  1. Click on the Device list and select the name of the required device, from the list of devices configured in the Adroit Setup utility. Click here for more details about Devices:

    PLEASE NOTE: If a front-end device is off-line, un-available or disconnected, then its associated device should be stopped, since Adroit will continue to attempt to resume communications and this will impede the adding and removing of Adroit tags to or from its Device agent.

    Note1: If this selected device is used for the first time, then the "Device Agent does not exist" message box is displayed, click the Yes button.

    Note2: It is also possible to change the active device in this list by using the UP and DOWN arrow cursor keys.

  1. If you need to specify the required agent in the Agent field, then click the browse button to use the Agent and slot to scan dialog to specify the required agent and its required slot too, if necessary. For details, see Browsing for agents and their slots. Click here for more details about specifying Agents:

    Note1: This field will automatically be specified by the name of the agent selected when you click the Scan… button.

    Note2: If the Agent and slot to scan dialog is used to browse for another type of agent, then the required slot MUST be selected using the Slot field instead.

    WARNING: The same tag CANNOT be scanned TWICE i.e. it cannot be added to this or any other Device agent again. If necessary, click the Find button to the right of this field to locate this agent in the list of scanned tags for this device, to determine if the required tag (agent.slot) has already been added to this Device agent.

    Tip: Before locating this tag, it is recommended to sort the list of scanned tags using the Tag column, by clicking on its column heading.

  2. If necessary, click in the Slot field and select the required slot from the displayed list of available slots.

Note: If the required slot is a header slot then check the Header slots checkbox to display all the header slots for this agent in this list. Normally this option should remain unchecked so that this Slot list is not overly cluttered.

  1. Specify the address (location) within the FED (Device) that the specified Slot should be communicated to/from in the Address field, as follows:
    • Typically, this will be an address in a front-end device, in which case click the Details… button for a list of valid address ranges. This is also described in documentation installed with its driver. For details, see Displaying Driver Documentation.
    • If this is an OPC server, then click the browse button to the right of this field and use the OPC Item Browser for all OPC Servers to locate and specify the address of the required OPC item. For details, see Browsing for OPC Item Addresses.

    Note: This field can also be used to specify the slot of another agent. For details, see @scanning.

    WARNING: The same address CANNOT be scanned to the same Device agent. If necessary, click the Find button to the right of this field to locate this address in the list of scanned tags for this device, to determine if this specified address has already been added to this Device agent.

    Tip: Before locating this address, it is recommended to sort the list of scanned tags using the Address column, by clicking on its column heading.

  2. If necessary, specify the time, in milliseconds, which will elapse before this value is communicated to or from this device in the Scan rate (ms) field. The default is 4 seconds. For configuration details, see Scanning interval configuration tips.

Note: This field should ONLY be configured for POLLED devices, since event-based or telemetry devices do not use setting.

  1. If necessary, specify the deadband limit for this slot (value) in the Deadband field. Any CHANGE in value LESS than this deadband limit will NOT be communicated. By default, no deadband limit is applied. For configuration details, see Scanning Deadband Configuration Tips.

WARNING: Do not use a deadband when scanning tags that contain state information, as information will be lost when decoding to binary format.

  1. If you do NOT want this value from being changed (updated) by the Device (FED), then check the Input disabled checkbox. By default this is OFF (cleared).

    Note: This setting does not prevent this value from changing the value in the FED.

  2. If you want this value to be written to the Device to change the value in the FED, then check the Output enabled checkbox. By default this is OFF (cleared).

    Note: While this setting does not prevent this value from being updated by the FED it does prevent this value from being demand scanned. For more details, see Demand Scanning.

  3. If you want an initial value to be written to the Device to change the value in the FED, at startup, or after any communications failure and subsequent recovery, then check the Output initialise checkbox. By default this is OFF (cleared).

    Note: Some NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. devices, like OPCUA, do not support the output initializing of scanned values and so this checkbox will be disabled for these devices.

  4. If you want a NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. device to only communicate to this tag while it is being used then check the Demand scan checkbox. By default this is OFF (cleared).

    Note: This checkbox is ONLY available for NASAThis stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. devices when global setting Demand scanning enabled checkbox is checked in the Driver Configuration page of the Config Editor. For more details, see Demand Scanning.

  5. Click the Scan button, to add this configured scan point to the list for the selected Device.
  6. Ensure that the Started option at the top of this dialog, is currently selected and if not, then select it to start this device.

Click here for more details that describe how to work with the list of scanned items:

The list contains the IO flags column which displays the configuration of the scanning-related checkboxes (Input disabled, Output enabled and Output initialise) as a bit mask. For more details, see IO Flags.

Note1: Each of these columns of the list of scanned items can be used to sort this list alphanumerically, by clicking on the respective column heading to either display the sort ascending or sort descending icon to the right of this column heading (these icons ONLY appear when you click the column heading).

Note2: Remove scanned values from this list by selecting the unwanted tag(s) in the list and clicking the Unscan button. For details, see Unscanning Tags.

Tip1: By selecting a scanned tag from the list you can change the scanning-related checkboxes "live" for the currently selected item in the Currently scanned tags list i.e. there is no need to unscan the item, change these settings and then rescan it. Although the device needs to be stopped and restarted, for these changes to take effect.

Tip2: Although the increased size of this dialog allows more scanned tags to be displayed in the list, this dialog can also be manually resized to display even more tags, if required.

Tip3: Double clicking a scanned tag in the list opens the configuration dialog of this agent.

 

For more information on scanning values, the various methods and destinations and optimization tips, see Scanning Tags.
