Scanning Values

How to Scan a Tag : how to communicate a process value in Adroit to a FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..

Scanning values simply means communicating values, typically to and from front-end devices, such as a PLCa Programmable Logic Controller or programmable controller is a digital computer used for the automation of industrial processes. or RTUan Remote Terminal Unit is a device installed at a remote location that collects data and transmits this data back to a central station, or master..

Since in Adroit terminology a value (slot) is the same as a tag, ‘to communicate a value’ is the same as saying ‘to scan a tag’ or ‘adding a scanned point’, which typically requires a scan point license. For further details, see Scan Points.

In addition to communicating or scanning a single tag, it is also possible to:

  1. Scan multiple tags simultaneously i.e. to scan multiple agents of the same type, using the most recently specified scanning configuration. For details, see Template Scanning.
  2. Scan in bulk i.e. to import many scanned points to a Device agent. For details, see Bulk Scanning or Scanning Import.

Although the majority of tags will be scanned or communicated to front-end devices, it is also possible to communicate to the following destinations:

  1. To an OPC Server: This requires the use of the OPC client driver and will involve browsing for the required OPC Item Addresses.

Note: If you use the Adroit OPC client driver to connect to an OPC Historical Data Access (HDA) server, then you can retrieve historical information from this server. See OPC Historical Data Access.

  1. To the simulation driver: This is an emulation of a Siemens S5 PLC, mainly provided for testing and demonstration.
  2. To another tag: This simply copies the value of one agent’s slot into the value of another agent’s slot and is known as @scanning.

Note: To support drivers that use the @ character in scan addresses, @ scanning can be disabled for the required device, by adding the DisableAtScanning registry value. For details, see Registry settings affecting communications.

Tip: For details on how to optimizing your scanning configuration, see Scanning Optimization and Golden Rules for Scanning. Furthermore the Adroit Scanning Monitor utility can be used to provide pertinent scanning data, so that your scanning can be tuned to achieve optimal performance. For details, see Monitoring Scanning in Adroit.
