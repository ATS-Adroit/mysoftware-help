Common Device Configuration

Although the dialog displayed when adding or configuring a device is protocol driver specific, this dialog will generally contain the following groups of configuration parameters:

Note: This protocol driver configuration for each device is saved in the system registry; therefore it is necessary to reconfigure the devices if they are to be run on another computer. For further details, see About Protocol Drivers.

The rates at which the scanning or communication occurs can be defined for the individual I/O ports.

Primary and secondary parameters

Each device contains primary and secondary parameters that define the available connection channels (or routes) and parameters.

The secondary information is optional and is used in the event of a failure on the primary connection, or vice versa. How this secondary port works is simple, if the driver is using the primary configuration parameters and the communication fails, the driver will switch over to (and re-initialise) the secondary port and continue communicating via it if possible.

Once the primary port becomes available again, the driver may be forced into reverting to it by breaking the secondary port link, long enough to force the driver to do the switch back. This cycle may be repeated as often as fault conditions occur.

PLC Details

This group of details relates to how to address the FED (front-end device), and will contain details such as routing information or ID’s on a multi-drop that is specific to the FED’s protocol.

Necessary details such as the model in the range may appear here. Selecting the incorrect model will most often cause problems.

Local Details

Port configuration parameters are often required by a driver to allow it to decide which port to use on the Adroit computer.

Any additional parameters in this group will show default settings that may need to be changed. Only parameters that are configurable on the FED will be shown here. In other words, if the FED does not support different baud-rates, this setting will not be optional in our driver.
