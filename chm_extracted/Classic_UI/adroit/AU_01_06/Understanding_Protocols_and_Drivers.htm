Understanding Protocols and Drivers

Protocols are essentially languages that are strictly adhered to and which accurately transfer information between any two devices.

No one protocol works efficiently in every situation, since the following factors cause protocols to differ:

  • The medium along which they are being communicated, for instance, microwaves, fiber optic cable or Ethernet.
  • Which communication attribute has been optimised, for instance, speed, efficiency or timing.

Adroit Protocol Drivers ensure that these protocols are adhered to by Adroit and by the devices with which Adroit is communicating. You typically need to install each protocol driver that one or more of your front-end devices use.

Each Adroit protocol driver is supplied with documentation, which is installed to the Adroit system folder (typically: C:\Program Files\Adroit Technologies\Adroit) when the driver is installed and provides a summary of the protocol, so that this ‘language’ can be learnt and adhered to.

Having installed a protocol driver, you need to add a deviceadded to an installed protocol driver to communicate using this protocol to a specific front-end device - in other words a logical connection to this FED. for each FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU. through which the communication actually occurs.

An essential tool, that deciphers and analyses these protocols, is the Datascope.
