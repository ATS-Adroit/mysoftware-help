Configuring Device Agents

A device must first be added for an installed protocol driver before a Device agent of the same name can be added to the Agent Server when an Adroit tagA fully qualified named value in Adroit (agentName.slotName). is scanned to it. For further details, see Device Agents.

Each Device agent, is responsible for managing and configuring the following:

  1. The Scan agents, which it creates or removes when Adroit tags (agent.slot) are scanned to or unscanned from it. For details, see Scanning Tags.

Note1: Adroit automatically optimises the I/O points for the most efficient scanning and traffic loading, executing either block reads or single transactions to minimise scanning load and to maximise throughput.

Note2: It is recommended to stop the Device agent when adding and removing (and importing) more than one scan-point.

  1. The ‘device’ created in the Adroit Configuration Setup utility, through which the communication actually occurs to its front-end device.

This not only manages the communication (scanning) to and from this front-end device, but also its communication settings, which are specific to the protocol driver to which it has been added. For details, see About Protocol Drivers.

Note1: The rates at which the scanning or communication occurs can be defined for the individual I/O ports.

Note2: These changes only take effect when the device is first created automatically, or after the Agent Server starts up.

PLEASE NOTE: If a front-end device is off-line, un-available or disconnected, then its device should be stopped, since both Adroit and this device will continue to attempt to resume communications to the exclusion of most other functions of the scanning sub-system. Therefore any scanning or unscanning of Adroit tags to or from its Device agent will be impeded.
