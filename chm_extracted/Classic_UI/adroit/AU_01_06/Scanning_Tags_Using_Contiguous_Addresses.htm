Scanning Tags Using Contiguous Addresses

This method of scanning or communicating values is only effective when more than one agent of the same agent type need the same slot to be communicated by the same device using contiguous scan addresses.

For instance, if you need to scan the rawvalue slot of more than one Analog agent to the same device, using the same scanning configuration settings.

To scan a number of tags to continuous addresses in the same device:

  1. Create the required scanning template, by simply scanning the first tag, as normal to the first address of the required contiguous range of addresses. For details, see How to scan a tag.

This will specify the following: the agent type, the slot, the Device, the starting address and if necessary the Scan rate and/or Deadband.

If necessary, it is also possible to specify if the output enable and/or scan inhibit bits need to be set.

  1. Ensure that the Stopped option at the top of the scanning dialog, is currently selected and if not, then select it to stop this device.
  2. Close the Tag scanning configuration dialog.
  3. In the Agent Configuration dialog, either select a block of adjacent agents by keeping the left mouse button clicked and dragging the mouse down the Agent list or select non-consecutive tags by holding the CTRL key while clicking the left mouse button.

Note: Ensure that this first agent is excluded from this selection!

  1. Either click the Scan… button or right-click and select Scan….

This will immediately add the selected tags to the selected Device, using the scanning parameters pre-configured in step 1.

  1. Ensure that the Started option at the top of the scanning dialog is currently selected and if not, then select it to start this device.

Note: Since Adroit will allow more than one agent to use the same address–care must be taken to ensure that the assigned addresses correspond to the intended agent slots. Adroit, however, does not allow a slot to be configured for scanning more than once.
