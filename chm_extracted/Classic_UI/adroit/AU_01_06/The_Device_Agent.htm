The Device Agent

Device agents are used to manage the Adroit-specific communication settings of one or more tags (agent.slot) for a device that has already been added to an installed protocol driver.

This device is typically a logical connection to a front-end device, with which it communicates. For further details concerning the role this agent plays in communicating values, see the Scanning Overview.

For this reason, Device agents cannot simply be added to the Agent Server like other agents. Instead its associated ‘device’ must first be added to an installed protocol driver. For details, see About Protocol Drivers.

Then it is only when this device, which appears in the Device list in the Tag scanning configuration dialog, is selected when scanning a tag (agent.slot), for the first time, that a Device agent with the same name is added to the Agent Server. For details, see Scanning Adroit tags.

NASA, stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. For more details, see Demand Scanning.

The purpose of a Device agent is simply to manage the Adroit tags that have been scanned to it and their communication to and from its associated front-end device, as follows:

  1. The Device agent automatically creates Scan agents, which generally contain a manageable amount of tags that are scanned to contiguous addresses.

Each Scan agent manages the scanning configuration of their assigned Adroit tags, such as their poll rate, deadband, timestamps etc. For details, see Configuring Device Agents.

Note1: The Device agent also removes these Scan agents when Adroit tags are unscanned from it.

Note2: Since Scan agents are created dynamically, it is not recommended to use their slots in other agents, such as Expression agents, since their names are not fixed.

  1. The Device agent also exposes the ‘device’ created in the Adroit Configuration Setup utility, through which the communication actually occurs to its front-end device.

So it is able to stop and start the communication to and from this front-end device and configure its communication settings, if necessary. For details, see Configuring Device Agents.
