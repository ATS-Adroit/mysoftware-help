Working with the Datascope

The Datascope displays the data that is being sent to and from the specified device of a protocol driver.

Most drivers make use of following colors to make this diagnostic information easier to read, as follows:

  • Data going to the PLC is displayed in yellow,
  • Data coming from the PLC is displayed in cyan,
  • Important messages will be displayed in other colors etc.

Tip: The Datascope can also be displayed from within the driver and device configuration dialog for a specific device of a protocol driver, see Diagnosing installed Protocol Drivers or their configured Devices.

The data displayed by the Datascope can either be displayed in HEX or RTU(BINARY), the default or in ASCII, which is RECOMMENDED. The currently selected mode is indicated in the title bar of this window, as follows:

  • ASCII mode:

Type “A” to toggle the display between these two modes. Click for more details:

Tip: We recommend that you ALWAYS display the Datascope in ASCII format, even for known Binary(hex) type protocols, because the newer drivers provide extra information usually in a readable (English) format and also convert the hexadecimal display to ASCII to remain compatible.

Note1: If the following characters are displayed in ASCII mode: as displayed in the screenshot example above, then it may be useful to type in “A” again to toggle the display of the Datascope back into RTU(BINARY) mode.

Note2: Typing in “A” to toggle between the display modes is equivalent to using the command-line option "/A".

Press the SPACEBAR to PAUSE this display of data to allow the window to be scrolled up and down. Press any other key to CONTINUE the display of data. Click for more details:

Note: While the Datascope is ’paused’, the data is still being captured and will only wrap at 32 Kbytes.

Tip: If the Datascope becomes clogged with data, it may take hours to decipher, to avoid this either increase the device polling times and/or stop other Scan agents.

Create a Protocol Dump using the Datascope, as follows:press the “L” key, wait for the Datascope to fill with messages and then press the “L” key again.

This creates a Devicename.txt file in the folder in which this utility is launched your Adroit system folder, typically C:\Program Files\Adroit Technologies\Adroit, where Devicename is the name of the device specified in the title bar of this window.

Click for more details:

Tip: Press the “H” key instead to log the output to an HTM file, which also preserves the color of the Datascope to make the troubleshooting process easier. The extension of this file is .HTM

Note: If you are unfamiliar with communication protocols, then this log file or protocol dump can then be sent faxed or emailed to the support desk, to troubleshoot any communication problem experienced by this device.

WARNING! Both the L and H options will append to an existing log file, which has no size limitation and so can consume all the free disk space, unless these log files are properly managed.

Note: Typing in “L” or “H” to log the output to the Datascope is equivalent to using the command-line option "/L" or “/H”.

When the Datascope is being logged, this is indicated in the title bar of this window by appending the following to the title: "* LOG"
