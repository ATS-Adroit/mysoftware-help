Launching the Protocol Driver Monitor

How to use a mouse with PDRVMON running in an MSDOS or CONSOLE window.

As an alternative to using the Driver Monitor Launcher, you may set up a Protocol Driver Monitor icon for each driver type in your system, as follows:

  1. Find PDRVMON.EXE in the Adroit installation folder, typically: C:\Program Files\Adroit Technologies\Adroit.
  2. Right click on this file with the mouse and from the menu, select Create Shortcut then rename this shortcut appropriately and copy it to the desired location e.g. to the Desktop.
  3. Right click on this shortcut and from the menu, select Properties. In the Target field add the required device name to the end of the command line. e.g. "C:\Program Files\Adroit Technologies\Adroit\PDRVMON.EXE" BOILER1 i.e. this will run the monitor for the device type BOILER1.

Note: Device names must be pre-configured in Adroit and these names are case-sensitive.

  1. Then Double-click this shortcut icon to run the Driver Monitor for this device.

Note: This only enables the default usage of the Protocol Driver Monitor. Additional functionality can be added to these shortcuts by adding the available command-line options to the end of the Target field.
