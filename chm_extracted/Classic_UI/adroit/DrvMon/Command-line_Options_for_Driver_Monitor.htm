Command-line Options for the Driver Monitor

The following options can typically be either entered into the Command line options edit box in the Options menu of the Driver Monitor Launcher and allows you to further customise this application for your specific requirements:

  1. /A This option toggles the output display of the Datascope screen between the default hexadecimal (binary) format and ASCII format

Tip: We recommend that you ALWAYS display the Datascope in ASCII format, even for known Binary(hex) type protocols, because the newer drivers provide extra information usually in a readable (English) format and also convert the hexadecimal display to ASCII to remain compatible. For further details, see Datascope screen.

  1. /L This option will log the communication messages and errors as they occur between Adroit and the specified front-end device.
    The logged information is typically stored in a .TXT file with the same name as the device name. The following additional options can be used in conjunction with this /L option:
  1. /F<filename> This sub-option allows you to specify the name of the file that is used to log the Datascope screen e.g. /Ferrors.txt specifies a file called 'errors.txt' 
  2. /T This sub-option adds timestamps to the logged data, so that time at which the data is logged to file will also be recorded.
  3. /H This option logs the device-specific communication messages and errors to an HTML page to preserve the color of the datascope to make the troubleshooting process easier.
    The output file created by this option has the same name as the device name and a .HTM extension.

Note: The log files created by the /L and /H options are located in the folder in which this utility is launched. This is usually the Adroit system folder (typically C:\Program Files\Adroit Technologies\Adroit) otherwise open the properties of the shortcut used to launch this application to determine this folder.

WARNING! Both the /L and /H options will append to an existing log file, which has no size limitation and so can consume all the free disk space, unless these log files are properly managed.

  1. /N This will suppress the warning that usually appears when more than one Datascope window is opened on a computer.
  2. /G This only applies to GST drivers and is used to open up a specialised diagnostics screen.
  3. /SCREENn This will automatically open the specified screen.

Where:

  • /SCREEN1 = Datascope.
  • /SCREEN2 = Diagnostic Counters.
  • /SCREEN3 = Error Log.
  • /SCREEN4 = GST FEP scope – this is only available when the /G option is used for GST drivers.

A usage example of these options

/A /SCREEN1 /L /T /Ferrors.txt

This will automatically log the Datascope output in ACSII with times, to the file called errors.txt, without requiring any user interaction!
