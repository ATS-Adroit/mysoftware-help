How to create a graphic form navigational menu from a TGONavToolbar control

This document describes how to use the TGONavToolbar control to create a menu of graphic forms, so that your end- users (operators) can easily move between these graphic forms, which you can arrange in a logical manner and which can reside in any of your configured projects.

Prerequisites

Note: This document assumes that the reader has a basic working knowledge of creating and using projects and graphic forms.

  • You need to create all the projects and their graphic forms and that this menu should provide navigation for.
  • You need to have added the required TGONavToolbar control. For details, see Adding TemplateGONavToolbar controls.
  • This document ONLY describes how to create or design a menu of graphic forms displayed by the TGONavToolbar control. For details, on the other more advanced configuration options provided by this control, see TemplateGONavToolbar controls.

Click the TGONavToolbar control glyph or Smart Tag () and then click the Browse for Toolbar Graphic Forms… task, which displays the Graphic Form Toolbar Setup menu designing workspace or grid.

 

This document demonstrates the following tasks that you may need to perform when creating your graphic form navigational menu structure:

Overview of the menu designing grid and its buttons and right click options

The menu designing grid contains the following fields that can be configured as follows:

  • Graphic Form Name: this is the full name of the graphic form that has been selected for a menu item, which adheres to this naming format: Project Name[.Folder/s Names].Graphic Form Name – so check that this is the required graphic form. If it is not then double click this cell to launch the Graphic Form Selection dialog to browse for the required one.
  • Toolbar Item Text: this is the label or name displayed by this sub-menu or menu item, in which case it defaults to the name of the graphic form – but you can change it or abbreviate it as needed, by double clicking this cell and editing the text.
  • Toolbar Item Name: this is the internal name of this sub menu or menu item for this control, which is provided for reference purposes, since you can use this name in any Behaviours or scripts or spiders that you create to refer to and interact with this specific menu item and its associated graphic form.

This also provides the following row of buttons at the bottom, which you can use to define your required graphic form navigation:

Example:

Note: All the Add functions always add items to the row below the currently selected row of the grid.

  • Add GF: this adds a menu item that is linked to a specific graphic form, which is displayed when this menu item is clicked.
  • Add Menu: this adds a sub-menu that is not linked to a graphic form, but allows you to add structure to your navigation by containing and displaying sub-menu GF items. In this way, you can display the most important GFs and hide the less important ones within sub-menus. 

Note: You do not need to add menus, since you can make GFs sub items of other GFs if necessary.

  • Add Project: instead of adding GFs and menu items manually 1 by 1, you can create some or all of your graphic form navigation based on the structure of an entire or portion of a project.

In this case, any project folders are configured as menus and their graphic forms are configured as their menu items.

Tip: You can also right click the menu grid and use the Export to CSV and Import from CSV options to bulk configure the menu in an external editor instead of using this grid.

You can also use the following buttons to adjust the navigational order of the added items:

Note: If you select more than one row, then all the selected rows are configured by the button that is clicked.

  • Left: Changes the displayed hierarchy of the selected row, by moving it up one level, if possible, so if the row was a sub-item of a menu then it is now displayed on the same level as the menu.
  • Right: Changes the displayed hierarchy of the selected row, by moving it down one level, if possible, so that this row is displayed as a sub-item of the row immediately above it, whether this is a GF or sub menu.
  • Move up: Moves the selected row up in the grid.
  • Move down: Moves the selected row down in the grid.

Tip: If necessary, you can delete any unwanted sub menus or menu items from the grid by selecting them and then clicking the Remove button or pressing the DELETE key.

Adding a sub menu

Note: If you have not selected a row in the grid then any GF or sub menu is added to the top (first row) of the grid, by default.

For the purposes of this example, select the row containing the graphic form we have added first – to add a sub menu below this row.

Click the Add Menu button, which opens a dialog to specify the required name of this sub menu – type in the required name, in this case “System” and click OK.

This adds another row to the grid, which only provides two fields:

  • Toolbar Item Text: this is the label or name displayed by this sub menu, which you can change by double clicking this cell and editing the text.
  • Toolbar Item Name: this is the internal name of this sub menu for this control, which is provided for reference purposes, since you can use this name in any Behaviours or scripts or spiders that you create to refer to and interact with this specific sub menu.

Note: The Graphic Form Name field is empty since a sub menu does not have an associated GF.

Adding a Project to create GFs (menu items) and sub menus

In this case, we will be adding additional graphic form navigation based on the structure of an existing project, instead of adding its GFs and sub menus manually 1 by 1. In this case, any folders in the project are configured as sub menus and their graphic forms are configured as their menu items.

If necessary, open the Graphic Form Toolbar Setup dialog.

Click the Add Project button, which displays the Project Selection dialog with a drop down list box containing all the projects configured on this Server.

Select the required project, in the case MA Process Suite, and click OK.

This displays the Project Item Selection dialog, which displays a tree view showing the layout (hierarchy) of the selected project, which each folder and graphic form is represented by a checkbox.

Example:

Only select those folders (which will become menu items) and graphic forms that you want to add to your graphic form navigation, which adheres to the hierarchy of the project. By default all items will be selected and so by clicking OK the entire project is added, as in this case.

Adding portions of projects to the navigational structure

In this case, having removed the AI_A_v1_0 section from the navigation structure we decide that we actually need to re-add it.

Select the row where you want to ADD the AI_A_v1_0 section in on the grid.

Note: All the Add functions add items to the row below the currently selected row of the grid. In this case select the third row, containing the “Templates” menu item, since we want to add the AI_A_v1_0 section before the AI_A_v2_0 menu item.

Click the Add Project button and select the MA Process Suite project again from the Project Selection dialog.

In the Project Item Selection dialog, uncheck the topmost project checkbox, which is the name of the selected project, in this case "MA Process Suite" - this unchecks everything below it, and then just check the AI_A_v1_0 checkbox, which also checks all the other items below this section.

Testing your graphic form navigation
