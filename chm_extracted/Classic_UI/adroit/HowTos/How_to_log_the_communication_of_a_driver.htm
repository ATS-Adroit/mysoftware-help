How to log the communication of a driver

Introduction

When troubleshooting potential driver problems, it is essential to understand exactly how the specific device of an installed driver is communicating between Adroit and the specified front-end device.

Adroit provides a utility known as the Driver Monitor that is used for just this purpose and one of its functions allows it to display the Datascope window, which allows you to view and log the exact communication messages and errors as they occur between Adroit and the specified front-end device.

This procedure describes how to create an HTML log file of the communication messages and errors as they occur between Adroit and the specified front-end device. So that if you are not a driver expert, you can email this log file to Adroit support, who will then be able to assist you with your driver problem.

The advantage of an HTML log file over a text file is that this file format preserves the color of the Datascope window, which makes the troubleshooting process easier.

Prerequisites

  • Have Adroit 8.4 or later installed.

Note: If you are using a version earlier than this, then the method used to launch the Driver Monitor will differ.

  • Ensure that you have installed the required driver and created and named the necessary devices for them, each of which handle the communications to each of your front end device/s.
  • Ensure that the Agent Server is running.

  • Ensure that any previous log file for this device is deleted. This log file is located in C:\Program Files\Adroit Technologies\Adroit folder and have the same name as the device you created for this driver, with a .HTM extension.

    Otherwise this log file will be appended to, which will cause confusion.

Configuration Summary

The following steps summarise what we will be doing:

  1. Launch the Driver Monitor

  2. Monitor the required device of an installed driver

    Tip: You can also do this via the Adroit Config Editor, as follows:

    Launch the Adroit Config Editor utility: click Agent Server Configuration and then Driver Configuration in the right hand pane, then right click the required configured Device () of the installed Protocol Driver () in the Installed Drivers and Devices list and select its Diagnostics option.

  3. Display the Datascope screen for the device

  4. Log the contents of the Datascope screen

 

Detailed Configuration Steps

Launch the Driver Monitor

  1. Open the SmartUI Designer.
  2. Click the Diagnostics & Tools tab of the SmartUI Designer ribbon.
  3. In the Monitoring group on the far left, click the Driver Monitor utility.

 

Back to top

Monitor the required device of an installed driver

  1. Click the name of the required installed driver in the Driver list.
  2. Double click the name of the required device of this driver, in the Device name list.

Note: You can create a device for this driver by pressing the INSERT key and then provide a name for it and complete its driver-specific configuration dialog.

Typically this opens a window displaying a selection screen so that you can choose which monitoring screen you want to display for this device. Unless you have specified the /SCREENn command line option in the Options... dialog of the Driver Monitor, which explicitly launches a specific screen (/SCREEN1 always displays the Datascope, /SCREEN2 always displays the diagnostic counters etc).

Display the Datascope screen for the device

  1. In this case click the following option: 1 Datascope.

This opens the Datascope screen for this device, however the information that this screen displays depends upon the driver protocol and the operational status of the device that you are viewing. The status you can determine from the icon of the device as displayed in the Device name list, as follows:

Tip: One of the Options... of the Driver Monitor allow you to configure how fast these statuses are updated.

In this case the BATCHOPC device is idle, so the following information is displayed by the Datascope screen:

Since the ASCII checkbox of the Driver Monitor dialog is checked by default, your datascope will be displayed in ASCII mode by default, which is the recommended way to view the datascope, even for known Binary (hex) type protocols, because most drivers also provide extra information usually in a readable (English) format - you can press the A key to toggle between these viewing modes.

Tip: For ease of use, the first word of the titlebar of the datascope tells you whether it is being displayed in ASCII or HEX mode.

Log the contents of the Datascope screen

  1. Press the H key to start logging the contents of the Datascope screen to an HTML log file.

This HTML log file, has the same name as the device that you are currently monitoring, in this case BATCHOPC with a .HTM extension and is saved to the C:\Program Files\Adroit Technologies\Adroit folder.

  1. Wait for at least 3 minutes or until the particular error that you are trying to troubleshoot presents itself.
  2. Press the ESC key to stop logging.
  3. Close the Datascope window and if necessary the Driver Monitor utility.
  4. In Windows Explorer, browse to this folder: C:\Program Files\Adroit Technologies\Adroit.
  5. Open or save or email this log file as required.

Tip: If you email this file to support, please provide a full description of your driver problem so that they can resolve this issue as fast as possible.
