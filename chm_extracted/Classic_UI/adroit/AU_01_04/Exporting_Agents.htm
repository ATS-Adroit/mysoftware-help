Exporting Agents

To Export an Agent Type.

Configuration data can be converted from Agent Server (.WGP) load files into comma separated variable (.CSV) files by:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Either select the Export command from the Classic UI File menu or from the Configurator Edit dialog (see table below).

Third party applications can then be used for off-line editing and modification prior to re-Import into an Agent Server load file.

All agent types (except the Scan, Hasp and Proxy agents, which do not save themselves, and therefore do not exist in a .WGP file) can be exported for documentation purposes, but not all the resulting .CSV files may be re-imported.

Note1: The Adroit agent exporting utility cannot export numeric values when they are the type STRING.

Note2: Ensure that the path and file name of the exported CSV file is less than 65 characters, when exporting your agents, since Adroit is unable to import agents from CSV files, which have paths in excess of 65 characters.
