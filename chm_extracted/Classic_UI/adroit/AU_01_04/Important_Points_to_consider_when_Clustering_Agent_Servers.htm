Important Points to consider when Clustering Agent Servers

Clustering in Adroit, previously known as hot standby, consists of a pair of Agent Servers (known as the master and standby) running a replicated agent database (WGP file) on the same project. More details:

The master server services all the I/O and client tasks, while the standby server replicates the master server. If the master server or computer fails, the standby server takes over as master and its clients and scanning tasks take appropriate action.

The following issues are important when implementing an Adroit cluster:

  1. Ensure that both Agent Server computers (and their clients) have their system time synchronised, for clustering to work effectively. For details, see Time Synchronization of an Adroit Cluster.
  2. Ideally both Agent Servers, in the cluster, should be in the same Windows domain. If your Agent Server has a cluster partner that is on a DIFFERENT domain or on DIFFERENT sides of a router/switch, then ensure that you are using an explicit connection to connect to this remote Agent Server. See Agent Server Connection Methods.
  3. When naming the two Agent Servers that you want to be a clustered pair, if you have a preference for a specific Agent Server to act as master, then ensure that the name of this Agent Server is alphanumerically lower than the name of the Agent Server that will be the standby partner e.g. if the preferred master Agent Server is called AS1 then the standby Agent Server should be called AS2.
  4. Ensure that you configure both Agent Server processes, in an Adroit cluster, to have the same (identical) Windows security permissions.
  5. If using the Agent Server Service on one of both of your clustered Agent Servers, ensure that the user account under which the Agent Server Service is running has network access to the partner machine.

IMPORTANT: It is NOT sufficient that a user logged in on the Agent Server can access the remote machine through explorer since this applies to his / her user account.

  1. Ensure that you DISABLE simplified file sharing on your clustered Agent Server computer, because this interferes with the inter-communication of clustered Agent Servers. For details, see Disabling Simplified File Sharing.
  2. Ensure that your chosen method of providing communication from Adroit to/from your PLCs or RTUs can support your desired clustering-scanning method. For details, see the following chart: Communication Hardware and Cluster Server I/O Modes.
  3. Adroit Clustering does not support the run-time creation of agents on both Agent Servers.

Note: Certain agent types on a cluster server require synchronization of internal data structures with their master partner. For details, see Real-time Catch-up.

  1. It is recommended that identical copies of the agent database (.WGP) files are manually replicated on both clustered Agent Server computers. Click for more details:

Typically Agent Server configuration is not shadowed across to the Standby computer, unless the agent database (.WGP) file used by both Agent Servers in the cluster is browsed in using the UNC file notation i.e. \\ComputerName\Drive\pathName. In this case this shared WGP file should not reside on either of the clustered Agent Server computers.

But we do NOT RECOMMEND the use of a SHARED WGP file as this creates a potential single point of failure if the computer containing this WGP file fails OR if the network connection to this computer fails.

Therefore we recommend that identical copies of the WGP files are manually copied between the clustered Agent Server computers and that Auto-Load Filename field of the Adroit Configuration Setup utility (PSEXE) is configured to point to the local copy of this WGP file.

Tip: This provides the added benefit of being able to use the standby server for extending the WGP configuration, then once the user is happy that the extended configuration is working correctly, the standby WGP file can then be deployed on the master Agent Server computer.

  1. Ensure that you configure the following fundamental Agent Server settings for both of your clustered Agent Server partners, as follows:

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Agent Server Configuration again in the right hand pane.

  1. In the WGP (Auto-Load) File field, typically specify the local copy of the manually replicated agent database (.WGP) file [OTHERWISE specify the SHARED WGP file, specified using the UNC file notation i.e. \\ComputerName\Drive\pathName - which is NOT RECOMMENDED - see the relevant point above for details).
  2. In the Project Name field, specify the SAME name.
  3. In the Agent Server Name field, specify a DIFFERENT name.
  4. In the Agent Server Type field, select ‘Cluster Server’.
  5. Click the Options… button to the left of the Agent Server Type field (that is now selectable) to display the clustering-specific settings.
  6. In the Cluster Name field, specify the SAME cluster name
  7. Configure the desired Server master mode assignment strategy that is, either manual or automatic. If an automatic assignment strategy is selected, then optionally configure the post startup period after which the server will attempt to set it as master.
  8. If necessary, configure the other settings. For details, see Adroit Cluster Configuration Settings.
