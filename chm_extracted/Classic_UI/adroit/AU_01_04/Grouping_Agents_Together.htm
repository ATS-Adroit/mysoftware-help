Grouping Agents Together

An Agent Group is a logical grouping of agents, contained within an AgentGroup agent, either for user convenience or to identify a section or a function of a plant. For example, all the I/O agents associated with Boiler No. 1, or all DataLog agents needed to compile, say, a Production shift report could be placed in groups.

This has already been done for each of the agent types and for the three pre-defined agent groups of BASIC, ADVANCED and SYSTEM as determined by the postload Adroit database file.

An Agent Group can also be used to control several agents contained within a group. For example, the control bits of an Agent Group agent can be used as a way of setting or resetting the equivalent bits for all agents in the group.

An agent can belong to more than one Agent Group and these may be displayed by selecting the agent type from the Type list box and its specific name from the Tags list box and then clicking the Groups button. A list of current Groups to which the agent belongs is shown.

Note: Any agents that have been browsed into the agent, e.g. the agents used in an Expression agent, or the agent used to trigger the Counter agent, will appear in the Current groups list, prefaced by an asterisk (*) e.g. *TRIGGER. These ARE NOT group names.

Similarly, the membership list of a given Agent Group can be displayed by selecting the group from the Group drop down list box, whereupon the members will be listed in the Tags list box.
