To install or uninstall the Agent Server as a service

Typically the Agent Server is configured to run as a Service during the install, although you can do this after the install if necessary by using the following command line switches that the Agent Server process (as.exe) provides:

  • Press the Windows key + R shortcut to open the Run dialog.
  • Type in as.exe followed by following commands and press ENTER:

/install /u:"[Domain\]Username" /p:"Password" /quiet

This command will install the Agent Server as a service.

The /u: and /p: parameters specify the credentials of the user account that the Agent Server service will run as, ensure that you specify a user that has the rights / permissions to access the network resources (printers, SQL Express, network shares) that the Agent Server requires access to.

IMPORTANT: The username MUST NOT be "Administrator", the built-in Windows Administrator account, since UAC is automatically disabled whenever this built-in Administrator account is used, which causes a myriad of problems to occur.

Note: The [Domain\] portion of the username ONLY applies if the specified user is on a domain.

The /quiet parameter suppresses any feedback messages.

 

/uninstall

This command will remove the Agent Server as a service.
