Loading Agents

The Agent Server automatically loads the .WGP file defined in the Agent Server Configuration dialog of the Adroit Setup utility. If there is a POSTLOAD.WGP file this too will be loaded. Further agents can be loaded from other .WGP files whenever the user wishes.

If no agents are visible in the Configurator then examine the Agent Server window, and confirm that the correct .WGP file has been loaded or if there were errors in loading this file.

If new agents need to be added to the Agent Server from a .WGP file, for example after importing agents, then:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Select Load Agents from the Classic UIFile menu.

File path names up to a maximum of 1023 characters are supported.

If an agent of the same name already exists, then it will NOT be imported i.e. existing agents cannot be overwritten or modified by loading over them.
