Editing the Header of an Agent

All agents types, regardless of their function, have common header attributes or values that are assigned and managed by the Agent Server. These can be edited in the Agent Header configuration dialog, as follows:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Select the required agent in the Agent Configurator, as follows:

  1. Ensure that the Basic, Advanced and/or System checkbox is checked to display the required agent type in this list. These checkboxes use these default agent groups to help you select the required agent quickly.

Tip: If no checkboxes are selected, then all the available agent types will be displayed in the Type list box. This is useful if the required agent type has not been categorised.

  1. Click the down arrow in the Type drop down list
  2. Locate the required agent type, using the scroll bar and click on it.
  1. In the Agents list, click on the name of the required agent (if necessary scroll down to locate this).

Tip: Right-click to display a menu of commands to perform upon the selected agent(s).

  1. In the Agent Configuration dialog, select the Header button in the Configurator dialog box, or from within the edit agent dialog box or simply select the required agent and right-click and select Header… from the menu. For details, see Right-click Configurator Menu.
  2. Edit the Description of the agent, if it was not done when the agent was first added.
  1. The User edit box can record user-defined information by using the agentIcon slot of the agent. For instance, this slot can be placed on a mimic so that operators could communicate and leave messages with regard to this agent. Click for more details:add a Text picture element and assign a Display Value Behaviour and an Operator Action Behaviour - set to Data Entry, for the agentIcon slot of the applicable agent).
  2. This dialog then displays the 32 bits of the Agent Status word that contains configuration and run-time status information about the agent. This status word is divided into the following two groups:
  1. The first 16 bits (0 to 15) are labeled Common Status bits, which are common to all agents, with each of these 16 bits having a fixed purpose. These have a unique slotname, which follows the naming convention of statusXxxxxxXxxxxx. e.g. statusScanBad.
  2. The second 16 bits (16 to 31) are labeled Specific Status bits and their purpose varies with each agent type. They are named statusBit16 up to statusBit31.
  1. The View derived agent status checkbox, affects how the Control status bits for the agent are displayed, as follows:
  2. Unchecked: This is the default view and displays the raw agent status. The Control status bits can be set or cleared for the ENTIRE agent i.e. once a Control bit is set or cleared, this setting will fan out and force this value of this Control bit for ALL the slots of this agent.
  3. Checked: This is a view-only display of all the agent slot Control bit statuses OR'd together. This allows one to determine which of these Control status bits have been set for one or more of the agent slots. The Control status bits CANNOT be set in this mode
  1. Specify the alarm priority filter group in which this agent is required, by specifying the required priority, in the Alarm priority edit box, as an integer from 0 to 4, as follows:

Note: The Alarm agent will discard any alarms that are triggered, if its own alarm Priority Filter is set to a priority greater than the alarm priority that is specified in this edit box.

  1. Specify the event filter group, to which this agent is assigned in the Filter Group edit box. Typically, a filter group denotes a plant area to which the agent belongs and is used to filter events and/or alarms per plant area. This number can be from 0 to 2 million (2,000,000).
  2. Clicking the Refresh button will refresh the dialog with any changes that have been made to the bits of the Agent Status word.
  3. Clicking the Advanced… button will display the Slot Status dialog, which allows the bits of the status word for each slot of this agent to be viewed and/or set. For details, see Slot Status Words.
  4. Clicking the OK button will return to the Configurator dialog box.
