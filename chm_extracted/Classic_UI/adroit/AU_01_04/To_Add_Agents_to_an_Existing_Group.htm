Adding Agents to an Existing Group

One reason for doing this would be to add together agents that you would like to start or stop together. For instance, to start three pumps at the same time, you could do the following:

  • Create the required AgentGroup agent
  • Add the necessary agent memberships to it e.g. three digitals that start the various motors – then by referring to the name of this agent group agent e.g. AgentName.value accesses all the member agents e.g. by using this in an operator action Behaviour you are able to start all pumps.
  • Edit this AgentGroup agent and enable the Bulk editing of agent type configuration option.

Note: You CANNOT enable this option if you have NOT added agents to it.

 

To add agents to an existing group:

Ensure that you have created the required group. For details, see To Create a New Agent Group.

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

  1. Click the down arrow in the Type drop down list, and select the required agent type (of the agent you want to add).
  2. From the Agents list box, select one or more agents e.g. ANA02 an instance of an Analog agent, to be allocated to the Agent Group.
  3. Click the Groups button in the Agent Configuration dialog box.

The Agent Groups dialog box is displayed.

Note: Any agents that have been browsed into the agent, e.g. the agents used in an Expression agent, or the agent used to trigger the Counter agent, will appear in the Current groups list, prefaced by an asterisk (*) e.g. *TRIGGER. These ARE NOT group names.

  1. Select the required existing group from the Available list.
  2. Click the Move to Left button (<<).

The selected group moves across from the Available to the Current Groups list.

  1. Click the OK button to return to the Agent Configuration dialog box.
