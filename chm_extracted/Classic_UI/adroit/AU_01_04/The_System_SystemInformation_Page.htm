The System SystemInformation Page

The System Information agent acts as an information center containing 5 tabbed pages of data slots that are global to the Agent Server. For details on how to access these pages of data, see Editing the SystemInformation Agent.

Note: The actual slot names and NOT their literal descriptions are specified, for ease of reference, since you most likely will need to display one or more of these slots on mimics.

Granularity or the Granularity period refers to the startGranularity slot of the SystemInformation agent, which is the time interval, in seconds, that this SystemInformation agent updates itself. By default, this is set to 1 second.

Changes

  1. getSlots: This indicates the total number of getSlot operations that have been performed by the Agent Server, since startup.
  2. putSlots: This indicates the total number of putSlot operations that have been performed by the Agent Server, since startup.
  3. getSlotAverage: This indicates the average number of getSlot operations that have been performed within the Granularity period, hence if Granularity was set to 60 this would be the average number of getSlot operations that have been performed per minute by the Agent Server.

Note: If this long integer, wraps, during this calculation this reported number will be inaccurate. Use the Performance Monitor counters if more accuracy is required.

  1. putSlotAverage: This indicates the average number of putSlot operations that have been performed within the Granularity period, hence if Granularity was set to 60 this would be the average number of putSlot operations that have been performed per minute by the Agent Server.

Note: If this long integer, wraps, during this calculation this reported number will be inaccurate. Use the Performance Monitor counters if more accuracy is required.

  1. recentGetSlots: This indicates the number of getSlot operations that have been performed by the Agent Server, in the last Granularity period.
  2. recentPutSlots: This indicates the number of putSlot operations that have been performed by the Agent Server, in the last Granularity period.
  3. updateFrequency: This displays the current specified Granularity period, which is the time in seconds that the systemInformation agent updates itself, and the period in which these averages are determined.
