About Backup Procedures

It is important to create a backup procedure to guarantee disaster avoidance rather than just disaster recovery and also to provide an easy way for transferring an Adroit project or system to another computer. Hence, this backup procedure should include all the files utilised during plant operation and include storage facilities as well as locations, since critical data should be stored in an alternative location, such as a drive or remote hard disk etc.

For these reasons it is recommended to use the System Backup and Restore facility provided by the Adroit Config Editorutility to execute and manage such a backup procedure. For details, see System Backup and Restore.

Note: This requires you to have installed SmartUI.

The backup process generates a single compressed file in the specified location, which contains the date and time of its creation, which contains all the relevant registry settings and all the files and folders containing the user-configuration of the currently specified Configuration.

When restoring, you can restore between x86 and x64 operating system architectures and across different operating system language sets. However, any file paths within the agent database (.wgp) file are not currently converted and still need to be manually edited after restoring the project.

This backup includes the following files and settings:

  • Adroit data files. This will backup up the files required by your Adroit projects, where multiple file locations can be specified.

WGP files, provide two features to assist with their regular backup. For details, see Backing Up Adroit Database (.WGP) Files.

WARNING! These features are merely intended to AUGMENT the existing backup system and NOT to REPLACE it i.e. it is still imperative that an efficient backup system is in place!

  • Event Logs. This will ONLY export the application; security and system event logs files. These event log files CANNOT be restored but can be viewed by using the Event Viewer.
  • Adroit registry. This will backup both the global Adroit registry settings and the Adroit registry settings specific to the current user. This will contain the Adroit configuration, workspaces and Adroit protocol driver configuration settings.
