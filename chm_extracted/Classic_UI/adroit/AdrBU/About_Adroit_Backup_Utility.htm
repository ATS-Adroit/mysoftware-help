About Adroit Backup Utility

How to Use this Adroit Backup Utility

The Adroit Backup Utility makes it possible to create a complete backup of your Adroit installation.

This should be used to protect your Adroit installation from corruption or possible accidental deletion and also provides an easy way for transferring an Adroit project or system to another computer.

This consists of the following 4 sections, which can be enabled or disabled according to your needs:

  1. Adroit installation files: backs up the files required by the Adroit application.
  2. Adroit data files: backs up the files required by your Adroit projects, where multiple file locations can be specified.
  3. Event Logs: ONLY exports the application; security and system event logs files. These event log files CANNOT be restored but can be viewed.
  4. Adroit registry: backs up both the global Adroit registry settings and the Adroit registry settings specific to the current user.

Once the back up has been appropriately configured, click the Backup now button to execute the back up.

The Backup path, allows you to specify where these Adroit backups are to be stored.

The Overwrite option determines if previous backups are preserved or overwritten, affecting the structure of the saved backup directory.

The Adroit Backup Utility makes use of profiles to store different backup configuration settings for later reuse and as these profiles can be executed from the command-line, Adroit backups are also able to be scheduled or run from a batch file.

The Set defaults button can be used to save the configured backup settings as the Default profile settings, this is recommended if the current settings are to be frequently used.

On exit the currently configured settings are saved to the currently selected profile.
