How to Use this Adroit Backup Utility

Use the Adroit Backup utility to create a complete backup of your Adroit projects and/or the Adroit installation files.

WARNING: All Custom agents and their files (*.DLL, *.VBS, *.CSV) need to be manually backed up.

Note: Ensure that the Adroit Agent Server and/or User Interface and any other Adroit programs, such as MISSRVR, are not running.

If necessary launch this utility:

Press the Windows key and start typing in the required application name and select it from the list, in this case:

Backup Utility

When the Adroit Backup Program is open:

  1. Specify the required location where these backups must be placed, this is c:\adroit.backup, by default.
  2. Backup your Adroit data files that you have created for every Adroit project. By default the Adroit data path/s is set to the Adroit projects folder, which should contain all your project data in the relevant sub-folders.

By default the global Include sub dirs. checkbox is checked, so that all the files contained in the sub directories of each of the specified Adroit data path/s are also be included in the backup.

  1. Backup the Adroit Registry settings.
  2. If required, export the event logs.
  3. If required, backup the Adroit installation files, currently installed on the machine.
  4. If these backup settings are to be re-used, then save these to a backup profile.
  5. Click the Backup now button, to backup the specified components.

Once the backup has been completed, a message box is displayed, indicating the specified location of this backup, this is placed in a sub-folder of the specified backup path, which is named by the current date and the current time.

Tip: Make a note of this backup location, so that you can locate this backed up data.
