Adroit Script Editor

This Script Editor is usually launched from the Script agent and the derived custom agents edit dialogs, so that their VB Script files can be edited.

This editor is also launched by the Custom Agent Designer, when adding VB Script functionality to a derived custom agent. This editor allows the concurrent editing of the following script file types:

  • Custom agent VB Script files (*.VBS)
  • Script agent VB Script files (*.BAS) See Also: List of all the Script Functions.
  • Custom agent Java Script files (*.JAV)

Press the Windows key and start typing in Script Editor and select it from the list.

Each file is displayed in the main editor window and is accessed by clicking on its tab at the below this window, which uses the full path and file name of this script file as its label. If long file names are used or many script files are being edited at once, it may be necessary to use these scroll buttons, which appear to the right of these tabs, to locate the required script file.

The Script Editor allows script files to be created, opened, compiled, saved or saved to another name or location or closed.

The Script Editor also provides the following editing functionality:

  1. Formatting colors are used in the Editor window.
  2. A List of the Available Keywords can be Displayed.
  3. Go to Pre-defined Procedures in the Script file.
  4. To Toggle between Spaces or Tabs.
  5. To Configure the Number of Spaces used per Tab character.
  6. Debugging Tools in the Status Bar.
  7. To Find Text in the Script file.
  8. To Find and Replace Text in the Script file.
  9. To Redo the Last Action made to the Script file.
  10. To Undo the Last Action made to the Script file.
