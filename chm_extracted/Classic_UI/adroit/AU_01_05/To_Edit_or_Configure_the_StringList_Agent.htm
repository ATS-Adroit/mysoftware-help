Configuring the StringList Agent

The StringList agent.

  1. Edit an agent of type: StringList.

The Edit StringList Agent dialog box is displayed.

  1. To insert a list or add to a list of indexed strings:

Note: These strings can contain commas "," and each string has a maximum length of 79 characters.

  1. Either import a comma delimited file, which contains the index numbers and their associated text values, as follows:

  • Use the Import file name edit box to type in the required file or use the button to browse for the file.

    Note: Once an import file name is specified, this file name is remembered for the remainder of the Agent Server sessioneach time an application is started and stopped on a computer constitutes a single session of this program..

  • Once the file is located, click the Import button, which sorts the list in imported list in descending order and remove all duplicate index entries.

When importing, the import is committed directly to the Agent Server, so the user no longer needs to click the Update button, after clicking the Import button.

  1. Or type the list in manually, as follows:
  2. Use the button to add an entry to the list by automatically incrementing the last index value of the list and placing this in the Edit index edit box and selecting the Edit String edit box for its value.
  3. Alternatively manually enter the required index value in the Edit index edit box and then selecting the Edit String edit box to add its value, this also requires the clicking the Update button to save this entry to the list.
  1. To remove an entry from a list of indexed strings, select the entry in the window, which is to be removed and click the button. If an entry is given the index value of an existing index, then the second entry will be deleted from the list on clicking the Update button.
  2. The Invalid index value edit box is used for specifying the error message to denote an invalid index.
  3. The Index list box allows the selection of the required index value and displays its associated string in the Value box along side it.

Note: When the Index selects an invalid value, then the StringList agent’s Invalid status slot will be enabled.
