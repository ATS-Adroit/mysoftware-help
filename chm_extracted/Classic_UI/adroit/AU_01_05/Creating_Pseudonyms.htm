Creating Pseudonyms

Pseudonyms can be created to simply the process of specifying commands, since a pseudonym is simply an abbreviation or alias for a tag (agent.slot), which once defined, can be used to represent this tag in commands that are sent to this Command agent.

Before pseudonyms can be used in messages, it is necessary to alert this Command agent to their possible existence in its received messages, so that it can correctly interpret them and so that any outgoing messages will have the pseudonyms replaced with the full tag. For details, see Enabling Pseudonyms and Macros.

Although pseudonyms can reduce the typing required to specify commands, they need to be defined for this Command agent before they can be used. For this reason, they can be used to to further restrict or limit the SET-table tags that can be performed by this Command agent. For details, see Limiting SET Commands.

Note1: Macros can be used as placeholders for entire commands, if required. For details, see Creating Macros.

Note2: Pseudonyms, like macros, are specific to the Command agent in which they are defined and are not global to all Command agents. However when a Command agent is copied, any defined macros and pseudonyms will also be duplicated. For details, see Copying Agents.

Note3: It is also possible to remove any pseudonyms that are no longer required. For details, see Removing Pseudonyms and Macros.

To define a pseudonym:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Pseudonyms and Macros tab.
  2. If necessary, click the Add pseudonym or macro button to add a new entry.
  3. If necessary, select the Pseudonym/Macro cell, in the required row and type in the name that will be used to represent the required tag.
  4. Select the Replacement cell and click the browse button to the left of this cell to browse for the required tag (agent.slot). For details, see Selecting the Agent and Slot Names.

Tip: Although it is also possible to type the name of this tag (agent.slot) directly, it is recommended to use the browser instead.

Note: Ensure that the Expand pseudonyms in messages checkbox, is checked, so that this pseudonym will be correctly recognised and interpreted by this Command agent.
