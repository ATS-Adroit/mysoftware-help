Specific Status Bits of the Accumulator Agent

The following specific status bits of this agent represents the agent-specific conditions that can be alarmed, displayed directly on a Graphic Form, if necessary, to indicate when the following conditions occur:

Note:  The Accumulator agent does not have any default status slots.

Status name Status description
statusBit16 - endofperiod Pulsed (set to ON [1] momentarily and then set back to OFF [0]) at the end of each period.
statusBit17 - sqlerror This bit is set ON if there is a problem connecting to the database when the connection to this SQL Server database has been specified.
statusBit18 - VHighHigh This bit is set ON when the differential value is GREATER THAN OR EQUAL to the valueHiHi alarm limit.
statusBit19 - VHigh This bit is set ON when the differential value is GREATER THAN OR EQUAL to the valueHi alarm limit.
statusBit20 - VLow This bit is set ON when the differential value is LESS THAN OR EQUAL to the valueLo alarm limit.
statusBit21 - VLowLow This bit is set ON when the differential value is LESS THAN OR EQUAL to the valueLoLo alarm limit.
statusBit22 - RHighHigh This bit is set ON when the differential rate of change is GREATER THAN OR EQUAL to the rateHiHi alarm limit.
statusBit23 - RHigh This bit is set ON when the differential rate of change is GREATER THAN OR EQUAL to the rateHi alarm limit.
statusBit24 - RLow This bit is set ON when the differential rate of change is LESS THAN OR EQUAL to the rateLo alarm limit.
statusBit25 - RLowLow This bit is set ON when the differential rate of change is LESS THAN OR EQUAL to the rateLoLo alarm limit.
