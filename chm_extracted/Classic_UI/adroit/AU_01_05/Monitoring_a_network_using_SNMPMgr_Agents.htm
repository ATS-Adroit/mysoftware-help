Monitoring a network using SNMPMgr Agents

Each SNMPMgr agent can manage a single device, by getting, setting and/or trapping its OID values.

PLEASE NOTE: It is very important to set up Windows firewall, or any other similar network security product, correctly to allow SNMP traffic. Failing to do this will result in the inoperability of the SNMPMgr agent. For further details on the requirements and guidelines regarding the use of this agent, see SNMPMgr Agent Usage Requirements.

To implement SNMPMgr agents to monitor a physical industrial network:

  1. Before setting up the SNMPMgr agent, decide which devices you need to monitor. In other words determine the (SNMP) network topology.

Tip: It is recommended to create a mimic to visualise the network, because this also assists in quickly detecting of the source of network bottlenecks too.

  1. In the case of the network described by this mimic, it would be necessary to configure seven SNMPMgr agents on the computer running the Agent Server.

In other words one SNMPMgr agent is required for each networked device that you need to manage.

  1. Configure each of these SNMPMgr agents to get and/or set the required OID values of their devices. For details, see Configuring SNMPMgr Agents.
  1. Once the monitoring process has begun, the SNMPMgr agent will start:
  2. Polling : to receive values from the device and copy them into the associated tags.

Which you can then trend, alarm or log in Adroit: For instance, it is possible to trend object information such as bandwidth; alarm certain conditions on the network, such a computer becoming unavailable and log information, which allows you to determine at which point in history an error or certain condition of the network has occurred, such as its degree of congestion etc.

  • Writing: to change values of the device when the value of their associated tags change.
  • Trapping: to receive events from the device, which are placed in a queue that you will typically interrogate by means of a script and respond to the important ones.
