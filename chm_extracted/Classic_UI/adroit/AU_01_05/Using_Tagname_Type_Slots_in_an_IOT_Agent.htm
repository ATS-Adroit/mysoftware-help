Using Tagname Type Slots in an IOT Agent

Tagname type slots are used in an IOT agent when the IoTThe Internet of Things (IoT) is the concept of connecting any device with an on and off switch to the Internet (and/or to each other). device needs to subscribe to external tags, such as systeminfo.second.

When using Tagname type slots, there is a rule that must be applied:

  • The Tagname slot must be immediately followed by the IOT agent slot that will ultimately contain the value of the specified tag.
  • If the Tagname slot contains a valid tag name, the IOT agent will automatically subscribe to the specified agent and will place any values received for this tag into the next slot.

For example, to subscribe to systeminfo.second then the XMLstands for Extensible Markup Language, which defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. slot value would look something like this:

<IOT Name="SecsInMinute" Description="The second time value">

<Slots>

<Slot Name="source" Description="Source of value" Type="Tagname">systeminfo.second</Slot>

<Slot Name="value" Description="Seconds" Type="Integer">0</Slot>

</Slots>

<HeaderSlots>

</HeaderSlots>

</IOT>

In the above sample,

  • the Slot Name “source” defines the tag to which we want to subscribe.
  • the Slot Name “value” defines the slot where the subscribed tag value will be stored.

Important:  The slot names "source" and "value" used in the example above are merely placeholders to make this example clearer, you may use any names you choose.
