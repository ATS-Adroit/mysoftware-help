Evaluation Options for Expressions

There are two options available to you in this group, whether the expression is to evaluate continuously or only when triggered by a change in the trigger input slot. If the continuous option is selected then a new result will be generated whenever any of the inputs change or even if the expression itself changes.

By design, a triggered Expression agent will always generate subscription updates for the value slot even if the value slot has not actually changed, which can lead to unnecessary Agent Server CPU loads and network traffic when remote UI clients have been deployed. These unnecessary subscription updates can be disabled, by adding the PropagateTrigger registry value.

Note: When selecting the Continuous option ensure that there are no cyclic relationships between outputs and inputs. If such cyclic dependencies exist for a continuously evaluating expression Adroit is likely to become unresponsive.
