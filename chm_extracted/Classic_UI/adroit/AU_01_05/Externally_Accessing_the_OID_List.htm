Externally Accessing the OID List

Typically you can view and/or modify the list of OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.s you select from the device from within the edit dialog of the SNMPMgr agent itself. However, you can also select and configure the records in this list outside of this agent by using certain slots of this agent that provide the following functionality:

These slots can be used to navigate the listed OIDs.

To select a record (row) from the OID list: to display and/or configure one or more fields of this record.

  1. Set the idx slot to the index of the required record in the list.

This populates the following slots with the following fields of this selected record:

idxEnabled: E field of the selected record;

idxWriteable: W field of the selected record;

idxOID: OID field of the selected record;

idxName: Name field of the selected record;

idxType slot = the Integer indicator of the return type of the selected record. For details, see OID Return Type Indicators;

idxValue: Current Value field of the selected record;

idxRate: Rate field of the selected record;

idxLastPollTime slot = the last time the value of the selected record was automatically polled;

For details of the fields that these slots represent, see the OID List.

To change the OID of the selected record: to monitor and/or control different SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device..

  1. If necessary, set the idx slot to the index of the required record in the OID list.
  2. Set the idxOID slot to the numeric format of a valid OID. 

This automatically changes the Name (idxName slot) of the selected record to “Unknown”, since this field is usually set by the OID browser, when the OID is selected.

Note: Please ensure that the OID you specify is correct and supported by the managed device.

To change the Name of the selected record: to change the OID description.

  1. If necessary, set the idx slot to the index of the required record in the OID list.
  2. Set the idxName slot to the required description.

Tip: This is usually required after manually changing the OID.

To change the polling configuration of the selected record: to enable or disable polling for this item.

  1. If necessary, set the idx slot to the index of the required record in the OID list.
  2. Set the idxEnabled slot to 0 or 1 to disable or enable the polling of the selected record.

Note: If you enable polling, this item will ALWAYS be polled EVEN if an tag is NOT specified to receive this value.

To change the writing configuration of the selected record: to enable or disable writing for this item.

  1. If necessary, set the idx slot to the index of the required record in the OID list.
  2. Set the idxWriteable slot to 0 or 1 to disable or enable the writing of the selected record.

Note: If you enable writing, the value of this item will ONLY be changed when the tag associated with this record changes in value.

To perform a manual write of the selected record: this ONLY applies to items that are enabled for writing.

  1. If necessary, set the idx slot to the index of the required record in the OID list.
  2. Set the idxValue slot to the required value.

This only changes the value of this OID if it is enabled to be written and the necessary connection settings are specified for this device.
