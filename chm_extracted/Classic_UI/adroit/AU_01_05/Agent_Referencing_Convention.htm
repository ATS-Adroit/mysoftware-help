Agent Referencing Convention

The following convention can be used when referring to agents:

[\\AgentServerName\]AgentName

This allows agents to be specified or referred to, as follows:

  1. Explicitly, by including the Agent Server name. For instance \\AS1\ANA001

This ensures that there is no ambiguity in specifying the required agent. In general, this format may be used in any Classic UI dialog except when adding or copying agents.

  1. Implicitly agent names, by omitting the Agent Server name. For instance ANA001

In this case Adroit will first search the Agent Server it is currently connected to for that agent, implicitly assuming it is on that server.

If it does not find the agent, it will look in all the other Agent Servers in the same project for agents of the same name. If only one agent is found on a remote Agent Server, it will use that one.

If more than one agent of that name is found on the remote Agent Servers, then the action taken depends on the mode of the local Agent Server (as specified in the Adroit Setup utility), as follows:

  1. If this is a Stand-alone / Distributed server then any duplicate agent names found on two or more remote Agent Servers will be ignored by the user interface.
  2. If this is a Cluster aware server or Cluster server then the duplicate tag name found on the first (alphabetically) remote Agent Server will be used. When that becomes unavailable, the tags on the next Agent Server will be used by the user interface, and so on.

Note: If a duplicate agent name is found on the local Agent Server (if running) and any remote Agent Servers, the local agent will always be used.
