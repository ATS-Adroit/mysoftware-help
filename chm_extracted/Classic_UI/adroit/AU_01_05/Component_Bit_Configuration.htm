Component Bit Configuration

Each row of the grid represents a component bit, which has the functionality of a digital agent. The following columns permit the configuration of the 16 component bits:

Note: It is possible to manually change the width of any column and to auto-size the width of any column, in the grid.

  1. Description: A General description of this bit e.g. HeaterNo. 7
  2. Name: The name of this bit. By default this name ranges from dig0 through dig15. However this name can be changed to switch0, switch15 etc. This will also change the name of the slot e.g. dig0.value then becomes switch0.value.

Note: The following characters CANNOT be used when specifying the Name of the bits:

Space

 

Percent

%

Dollar

$

Period

.

Back slash

\

  1. Value: The corresponding value of this bit as extracted from the value slot of the Marshal agent. This value can be manually toggled, select the ‘Value’ cell, to reveal the following:
  2. This value can be switched between the two states, using the left mouse click. The value of the value slot of the Marshal agent will change accordingly. The names of the two states are determined by values of State0 and State1
  3. Rawvalue: The corresponding value of this bit as extracted from the raw value slot of the Marshal agent. This value can be manually toggled, select the ‘Rawvalue’ cell, to reveal the following:
  4. This value can be switched between the two states, using the left mouse click. The value of the raw value slot of the Marshal agent will change accordingly. The names of the two states are determined by values of State0 and State1.
  5. Invert: The default, unchecked, action is to cause the value of this bit to always correspond to the rawvalue, e.g. if the rawvalue is State0, then value will be State0. If checked, then the value will correspond to the inverted rawvalue, e.g. if the rawvalue is State0, then value will be State1.
  6. State0: The text value that is used to describe the state of 0 for this bit.
  7. State1: The text value that is used to describe the state of 1 for this bit.
  8. Pulse: The default, unchecked, action does not pulse the value of the bit, so it will remain unchanged. If checked, then the value of the bit will be pulsed i.e. the period for which the digital is 1 is timed, when the timer expires then the bit is returned to 0. This is useful for emulating the action of a push button.
  9. Delay: The amount of time that a pulsed bit will remain in state 1, in milliseconds. The default value is 3 seconds. To alter this value, select the ‘Delay’ cell, to display: Either alter the value by using the left mouse button to click on the arrow buttons or modify the existing delay value using the keyboard, like any other edit box.
  10. Coldstart: The default, unchecked, action does not allow for a cold start value, so that no value is sent to a front-end device when the Agent Server is loaded. If checked, then the initial value of this bit will be stored for later use.
  11. Coldstart Value: The value of this bit is stored and will be sent to a front-end device when the Agent Server is first loaded.
