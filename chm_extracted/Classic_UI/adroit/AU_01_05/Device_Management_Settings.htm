Device Management Settings

Each SNMPMgr can manage a single device by getting and/or setting and/or trapping its SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. (values).

The Poll settings section of the Edit SNMP Mngr Agent dialog, either enables or disables this device management and can specify a rate at which values are retrieved from the managed device and how many values are included in each polling transaction, as follows:

PLEASE NOTE: If the Unlicensed checkbox (status bit indicator) is checked, then you need to correctly license your Agent Server before you can run 2 or more SNMPMgr agents.

To start managing the device: to start polling (monitoring) and/or writing (controlling) and/or trapping (enabling events) of the OID values of this device.

  1. Select the Enable polling option (BOOLEAN start slot).
  2. Click the Update button.

This sets the Started (status bit 18), which checks the Started checkbox.

Note: A scan point is consumed for every unique OID value that is polled, written to and/or trapped.

WARNING! If a SNMPMgr agent requires more than your available scan points then ALL these OID operations are DISABLED and its Error status bit is set.

IMPORTANT: If the InvalidConnection status bit is set (the Invalid connection checkbox is checked), then NONE of these OID operations will be performed as the agent cannot connect to this device

To stop managing the device: to stop polling and/or writing and/or trapping OID values of this device and to release the scan point licenses the agent was using for these OID operations.

  1. Select the Disable polling option (BOOLEAN start slot).
  2. Click the Update button.

The Stopped (status bit 17) is set, which checks the Stopped checkbox

The Started (status bit 18) is cleared, which clears the Started checkbox.

To configure the poll rate: the default rate, in milliseconds, that the agent fetches OID values (that are enabled for polling in the list) and copies these values into their associated tags.

  1. Specify the Poll rate (INTEGER scanRate slot) in milliseconds.

Note: The lowest rate is 5000 milliseconds (5 seconds).

To configure the number of OID values per polling transaction: the number of OID values to retrieve in a single polling transaction, which effectively determines how many transactions are required for each poll.

  1. In the Pdu edit box specify the number of OID items to include in a single polling transaction.

For instance if you have a list with 15 OIDs and you specify a Pdu of 5 then each poll will require 3 transactions.

Note: The device determines how many OID values that it is able to return in a single transaction.

To view the activity of this agent: to allow advanced users to use the Datascope window to monitor the state and current activity of this agent.

Note: Ensure that you Enable polling before you can monitor this agent.

  1. Click the Datascope button.
  2. In the Adroit Protocol Driver Monitor dialog, type 1 to select the Datascope option.
  3. In the Datascope window, type A to convert the Datascope from HEX to ASCII.

This window displays the current STATE of this agent, where [1] means running and [2] means stopped. 

The other messages indicate the current activity of the agent, such as tree building, reading writing polling general activity.

In general this facility allows you to know if the agent is working or not.
