Configuring On Delay Timers

This timing operation filters out specific events, so the BOOLEAN value slot is ONLY enabled (set to TRUE) AFTER the required delay period has elapsed. 

For example to configure a 3 second delay period, use the following settings:

Tip1: The value slot can be used to enable, disable or schedule other agents, its status is indicated by the Timer output checkbox in the edit dialog.

Tip2: The status bits of this agent indicate when the timer is running or has expired

The BOOLEAN start slot initiates and terminates this timing operation and can either be driven as follows:

  • Manually either by checking or clearing the Start timer checkbox in the edit dialog or via a mimic.
  • Automatically either via a script or by using the Input tag edit box in the edit dialog to subscribe to another tag in the Agent Server.

Note: When the start slot becomes disabled (set to FALSE), the value slot is also disabled and the timer expires. If necessary, this ‘on timer’ can be configured to automatically restart itself.

To configure an on delay timer

Note: When typing values into this edit dialog, click the Update button to register these changes.

  1. If necessary, open the Edit Timer Agent dialog, as follows:
    1. If necessary, add an Timer agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Timer Agent dialog.
  1. If this timer is to be started automatically from another tagA fully qualified named value in Adroit (agentName.slotName). in the Agent Server, then click the browse button to the right of the Input tag edit box to specify this tag. For details, see Selecting a Tag Using the Built-in Agent Explorer.

Note1: If this tag is numeric, then the start slot is enabled (set to TRUE) when the value is non-zero.

Note2: If this tag is a string, then the start slot is enabled when this string is not empty.

Note3: If necessary, the timer can also be started or stopped manually within this edit dialog, by checking or clearing the Start timer checkbox, which configures the start slot directly.

  1. Use the Delay time (ms) field to specify the required delay period, in milliseconds, after which the Boolean output (value slot) of this agent will be enabled (set to TRUE).

Note: The Timer output checkbox indicates the current status of the value slot of this agent.

  1. The Pulse width (ms) field must be set to zero for this timing operation.
  2. The Free running checkbox must be cleared for this timing operation.
  3. If necessary, set the Granularity (ms) field to specify the required period, in milliseconds, for monitoring the time during this timing operation.

When this period is less than the required duration of the timer, then the timeleft slot (Time left field) indicates the remaining time, in milliseconds.

WARNING! The smaller this Granularity value the greater the amount of work the Agent Server is required to perform in updating its clients with the timeleft slot value.

Note1: The default value of 0 forces this granularity period to equal the required timer duration, so that the timeleft slot (Time left field) is never calculated.

Note2: Although this setting has a minimum of 100 ms, a minimum of 1000 ms is recommended.

If this timer is required to be reset automatically, then check the Auto-reset checkbox, which resets the start slot’s value to 0 once the timer has expired, so that this Timer agent is ready for the next start.
