OID Return Type Integers

The Type field of the OID list uses the following Integer values to specify the type of data returned by an OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.:

Value OID Return Type

2

Integer or Integer32

3

Bits

4

Octet String

5

Null

6

Object Identifier

16

Sequence or Sequence Of

64

IP Address

65

32-bit counter

66

32-bit gauge

67

Time ticks

68

Opaque

70

64-bit counter

71

Unsigned 32-bit value
