Managing Message Queues

The Command agent uses a message queue because the sending and receiving of SMS messages are not instantaneous. This message queue provides temporarily storage, especially when a large number of SMS messages need to be sent at any one time or a large number of Command agents are using the same GSM SMS modem.

If necessary, the total number of messages that can be stored in this queue can be limited, although once the queue is filled, any further messages that arrive will not be sent. It is therefore recommended to keep the default setting, of 0, which does not limit this queue length, since a large message queue does not pose a performance issue.

It is also possible to purge all the messages from this queue, for instance, for testing purpose or when the message queue has been filled with unwanted or unnecessary messages.

Note: These settings are ONLY specific to this Command agent only and do not apply globally to all Command agents.

To specify the maximum number of queued messages:

  1. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. If necessary, select the General tab, the default selection.
  2. Under the Agent Settings group, specify the required maximum number of messages in the Queue size edit box.

Note: Any integer number from 0 to 1000 can be specified, the default being 0 i.e. an unlimited queue length.

Tip: It is recommended to keep the default of 0 i.e. unlimited queue length.

To remove all the messages that are currently in the queue:

  1. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. If necessary, select the General tab, the default selection.
  2. Under the Agent Settings group, click the Empty Queue button.

WARNING! All messages currently in the queue will be removed and will need to be re-sent.

Tip: This can also be performed through the direct manipulation of its Boolean emptyQueue slot.
