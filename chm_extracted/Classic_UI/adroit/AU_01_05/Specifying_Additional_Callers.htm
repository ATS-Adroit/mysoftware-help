Specifying Additional Callers

Once a Command agent has been linked to a device, it is possible to specify one or more additional cell phone numbers that are able to send SMS messages to it, in addition to the configured recipient phone number. For details, see Specifying the GSM_SMS Device or Specifying the Recipient Phone Number.

However it is ONLY when the Command agent has been enabled to perform commands that commands received from these phone numbers will be performed. For details, see Allowing Commands to be Performed.

WARNING! Once the Command agent is configured to receive commands, scan point licenses are consumed by each unique phone number that is able to send an SMS command to this Command agent i.e. by both the configured recipient phone number and these additional cell phone numbers that are specified or used to send SMS messages to it.

There are two methods by which these additional callers can be specified:

  1. Anonymous access: This requires the least configuration, although it provides unrestricted access in that anyone who phones the recipient will be able to send commands to this Command agent. For details, see Configuring Anonymous Caller Access.

PLEASE NOTE: In this case EVERY unique caller who phones the recipient and issues a command to the Command agent will consume a scan point license, which will not be released until the Agent Server is shutdown.

  1. Authorised access: This requires the cell phone numbers of all the callers who are allowed to issue commands to this Command agent to be added to the Cmd phone numbers list. However, only these additional callers are able to ‘command’ this agent and hence will consume scan licenses. For details, see Configuring Authorised Caller Access.

Note: This list can hold a maximum of 10 numbers.

Tip: Since these commands are able to obtain and/or control any process value or slot exposed by the Agent Server, it is recommended to BOTH specify the authorised phone numbers AND to limit these command-able phone numbers for security reasons.
