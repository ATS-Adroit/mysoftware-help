SNMP Managed Objects

Network devices that are managed by SNMPSimple Network Management Protocol (SNMP) is used to monitor and manage a diverse range of devices on a computer network. expose their management data as managed objects. These managed objects might be hardware, configuration parameters, performance statistics, and so on, that directly relate to the current operation of the device.

EVERY managed object (value) is uniquely described and organised hierarchically in an international database, known as the SNMP Management Information Base (MIB), by means of an associated Object Identifier (OID). This OID not only uniquely describes it in the MIB but also describes the exact location of this object within the tree-like structure of the MIBSNMP Management Information Base, this is a database that lists uniquely described and organises SNMP managed objects hierarchically. database too. For details on their naming convention, see SNMP Object Identifiers.

Each SNMP agentDO NOT confuse this with an Adroit agent, this is simply software running on a device that allows it to be managed by SNMP. is responsible for maintaining its own virtual MIB, which ONLY contains the managed objects supported by its device. This virtual MIB is read by an SNMP managera program that is responsible for managing and monitoring SNMP devices, such as the Adroit SNMPManager agent. to obtain a list of this device’s managed objects, so that it can know which values to get and/or to set.

Note1: SNMP allows the extension of these standard objects (as defined in the international MIB) with objects that are specific to a particular agent through the use of private MIBs.

Note2: SNMP also provides a limited security system, known as SNMP Community Strings, which control the access to these objects. For details, see SNMP Community Strings.
