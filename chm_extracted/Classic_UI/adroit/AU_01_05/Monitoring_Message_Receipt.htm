Monitoring Message Receipt

One of the methods in which SMS messages sent by a Command agent can be monitored, for auditing purposes, is to require a delivery report to be sent by the recipient as soon as the SMS messages arrives, which logged to the event log.

This audit method verifies that the message has been delivered to the recipient’s device.

Furthermore, a minimum time period can also be specified in which this delivery report must be received.

If this is exceeded then this SMS message can be sent via another Command agent to someone else. In this way it is possible to escalate this message either to a colleague or up the management chain, as is necessary.

Note1: It is also possible to ensure that the recipient receives and is aware of a message and, if necessary that this recipient responds within an appropriate time otherwise the message is escalated. For details, see Monitoring Message Response.

Note2: For details on specifying the recipient for a Command agent, see Specifying the Recipient Phone Number.

The lastMsgReceivedTime slot displays the time of the last message received.

The lastMsgReceivedTimeStr slot displays the time of the last message received, as a (var)string.

To log delivery reports for all the sent messages:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Phone tab.
  2. Under the SMS Delivery Confirmation group, ensure that the Require delivery report checkbox is checked.

Note: Once this checkbox is enabled, the delivery report of all messages that are sent from this Command agent are always logged i.e. this is independent on whether a timeout is configured.

To specify the maximum delivery delay and the required escalation Command agent:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Phone tab.
  2. Under the SMS Delivery Confirmation group, ensure that the Require delivery report checkbox is checked.
  3. Specify the maximum delay period, in minutes, in its Timeout (in minutes) edit box.

Note: This delay can only be specified in multiples of 10, however any number less than 10 but greater than 4 will rounded up to the next 10 automatically.

  1. Specify the Command agent, which is to be sent the SMS message when this timeout expires, in the Escalation tag edit box.

Tip: It is recommended to use the browse button to the right of this edit box, to select and/or add the required Command agent, as this only displays the Command agents currently configured for this Agent Server.
