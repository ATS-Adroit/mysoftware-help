Message Sending and Processing Slots

The Command agent provides the following slots that are responsible for processing commands and sending SMS messages, which can be externally manipulated if required:

  1. The lastMsgReceived slot: the most recent data received by this slot, even if identical to its previous contents, will cause it to BOTH process the data and then to send this processed data to the rawValue slot.

Note1: If this slot receives a command, which has been enabled for this Command agent, then this command will be performed before it is sent to the rawValue slot. For details on enabling commands, see Specifying Permitted Commands.

Note2: If pseudonyms and macros have been configured and enabled for this agent, then they can be also used when specifying this data. For details, see Using Pseudonyms and Macros.

  1. The value slot: the most recent data received by this slot will also be sent to the rawValue slot.

Since this is a standard 80-character String slot and NOT a VARSTRING slot, like these other lastMsgReceived and rawValue slots, other agents are able to be @ scanned to it, so that their STRING slots can be sent by the Command agent instead.

The lastMsgReceivedTime slot displays the time of the last message received.

The lastMsgReceivedTimeStr slot displays the time of the last message received, as a (var)string.

For instance, the value slot of the Command agent can be @scanned to the rawValue slot of a Notify agent, so that the Notify agent's alarm message can be sent to the recipient of the Command agent instead. For details, concerning @scanning, see Scanning from a Slot of Another Agent.

  1. The rawValue slot: this sends the most recent data received by this slot to its associated GSM_SMS device and as it leaves the Command agent, this data will also be placed in its lastMsgSent slot. For details on associating a GSM_SMS device with a Command agent, see Specifying the GSM_SMS Device.

Note1: This rawValue slot is also exposed as the Raw value edit box provided at the bottom of the Edit Command agent dialog. For details on displaying this dialog, see Editing Agents.

Note2: When the Resend message checkbox is cleared (its default setting) a message will ONLY be sent if the rawvalue of this agent HAS changed when dialog is either updated or closed. This effectively prevents the resending of identical messages.

Tip: The lastMsgSentTime slot displays the time of the last message sent.

These slots can either be modified programmatically, via scripting or manually, such as by exposing the required slot and sending messages to it directly by exposing it on a mimic and associating a Data Entry, Operator Action Behaviour to it. For details, see Adding an Operator Action Behaviour or its Data Entry action.
