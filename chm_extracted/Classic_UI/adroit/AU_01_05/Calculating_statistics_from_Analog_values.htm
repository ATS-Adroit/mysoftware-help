Calculating statistics from Analog values

The Analog agent can be enabled to calculate the following statistics from its value slot: sum (total), average, standard deviation, minimum, maximum and direction of change (trend).

These statistics are only calculated, when the Integer statsPeriod slot is set to the number of minutes that you want the value slot to be recorded for statistical evaluation. This is a "rolling" period, which specifies the maximum sampling time from "now" (the current time) into the past for the specified period. In this case the value slot is recorded every second over this timespan and the statistics are calculated from these recorded values.

IMPORTANT: Since the calculation of these statistics can affect performance if used excessively, please ensure that you ONLY calculate statistics for the Analog values you need them for. Setting the statsPeriod slot to 0 (the default value) disables the calculation of these statistics for an Analog agent.

Tip: You can use the Statistical period (mins), 0 to disable field of the configuration dialog to configure this statsPeriod slot for an Analog agent.

These statistics are saved into the following slots of the Analog agent, so that they can be separately reported, as needed:

Note: If necessary, you can reset these statistical calculations by setting the Boolean statsReset slot to 1 (True) which clears the recorded values.

  • statsAverage: The average of all the recorded values.
  • statsMax: The highest recorded value.
  • statsMin: The lowest recorded value.
  • statsStdDev : The standard deviation of all the recorded values.
  • statsSum: The total of all the recorded values.

  • statsDirection: This compares the newest recorded value (the current value slot) to the oldest recorded value and displays the results of this comparison, so that you can determine the general direction in which it is changing (its trend) as follows:

    • 0 typically means that the value has not changed.
    • 1 if the current value is higher, so that the trend of the value is moving up
    • -1 if the current value is lower, so that the trend of the value is moving down.

    However, you can also specify an optional minimum deviation or deadband to ensure that this trending direction only indicates significant changes in value. In this case set the statsDirDev slot, to the required decimal percentage value (a value from 0 to 1) so that deviations in value less than or equal to this specified percentage result in the statsDirection slot being set to 0 meaning “no change”.

    For instance, if you set the statsDirDev slot to 0.10, then only when the newest recorded value differs from the oldest recorded value by more than 10 % will the statsDirection slot display whether the current value is higher (1) or lower (-1).
