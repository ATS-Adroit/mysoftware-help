Configuring a Scheduled Period of Time

The grid of the Scheduler agent, is comprised of the following columns, which are used to define a specific period of time as follows:

Note1: This Edit Scheduler agent dialog can be resized, to view the entire width of this grid, if necessary.

  1. The first untitled field is the index of the periods of time in the grid.
  2. Start datetime: This column can specify the date and/or time at which this period of time is scheduled to commence. The default value is the current date and time. If this is left blank, then this cell is disabled and all date/times are valid.
  3. End datetime: This column can specify the date and/or time at which this period of time is scheduled to end. The default value is the current date and time. If this is left blank, then this cell is disabled and all date/times are valid.

Click the cell of the required column and configure it, as follows:

Note: To ONLY specify a time and NOT a date, then enter the following date: 1 /1 / 1970

  1. Either click the downward arrow of the list box and use the supplied calendar to select the required date; the current date is selected by default.

Note: Use the << and >> buttons to select the required year; use the < and > buttons to select the required month and then click on the required date.

  1. Or click in the list box, over the required date and time digits to select them, then either type in the required unit or use the spin control arrows to increase or decrease the value accordingly.

Note1: Only numbers can be typed in and if the number that is entered is too great for the specified unit it will be disregarded

Note2: The date and time is displayed as per the Regional Settings of the computer.

  1. Weekdays: This column can specify the days of the week, which need to be included during this scheduled period of time. By default all the days of the week are included.

Click the cell of this column and configure it, as follows:

  1. Click the downward arrow on the right of this cell.
  2. Ensure that the tick boxes of the days for which this period of time, is NOT applicable, are cleared.
  3. Click the downward arrow on the right of this cell, to close this weekday selection list.
  4. Click the Update button to save the change made to the configuration.

Note: If no Weekdays are selected then this entire scheduled period entry is disabled.

  1. Day of month: If necessary, type in the particular day of the month on which this scheduled period of time applies. The default value of 0, disables this cell, so that all the days of a month are valid.

Note: If this entry is enabled (non-zero), then all the Weekdays should be enabled for it to work properly.

  1. Lastday of month: If necessary, tick this checkbox to indicate that this scheduled period of time is only valid if it is the last day of the month. This is not ticked by default.

Note: If this entry is enabled (non-zero), then all the Weekdays should be enabled for it to work properly.

  1. Auto-delete: Enable this checkbox to indicate that this scheduled period entry must be removed from this grid as soon as the time, specified by its End datetime field, is exceeded. This is not ticked by default.
