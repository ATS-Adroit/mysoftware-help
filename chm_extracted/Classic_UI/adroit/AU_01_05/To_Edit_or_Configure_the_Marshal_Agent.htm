Configuring the Marshal Agent

The Marshal agent.

  1. Edit an agent of type: Marshal.

The Edit Marshal Agent dialog box is displayed.

  1. Configure each of the 16 component bits in the grid..
  1. When using the grid, select the initial row, by selecting the required cell with a left mouse click.
  2. Once a row has been selected then all the values in that row, e.g. the toggled and checkbox values are immediately accessible.
  3. When moving between rows the row must first be selected before the contents of the cell(s) can be altered.
  4. Once a cell has been selected, it is possible to move through the grid using the arrow keys on the keyboard. PageUp and PageDown move the highlighted cell to the top and bottom of the current column, respectively.
  5. Each row of the grid represents a component bit, which has the functionality of a digital agent.
  1. Click Update All to save all the changes made to the Marshal agent.
  2. Click Update Current to only save the changes made to the currently selected row.
  3. Click Refresh to display the current state of the Marshal agent.
  4. Check Reverse Mapping to reverse the direction in which the individual bits for the digital agents are stripped from the 16 bit raw value slot i.e. so that most significant bit e.g. dig0, before reverse mapping has been selected, becomes the least significant bit e.g. dig15.

Note: this option is applicable for the entire Marshal agent.

  1. The Value integer displays the value slot, which is the value of the raw value slot after the effects of the reversing of the individual bits have been determined. Manually editing this value will change the individual value states of the component bits and the value of the raw value slot accordingly.

Note: This value slot also has an associated Time slot, which records the time stamp of this slot and is used when this slot is being logged.

  1. The Rawvalue integer displays the value of the raw value slot. This integer would normally be scanned in from the PLC. The Marshal Agent splits this integer into the individual raw value states for each of the component bits. Manually editing this value will change the individual value states of the component bits and the value of the value slot accordingly.
