Configuring Pulse Generators

This timing operation generates free running square waves, so the BOOLEAN value slot is:

  • disabled (set to FALSE) for the required delay period and
  • enabled (set to TRUE) for the duration of the required pulse width.

Therefore the period of the generated pulse is the sum of configured delay and pulse width times.

For example to configure free running 3 second square waves, use the following settings:

Tip1: The value slot can be used to enable, disable or schedule other agents, its status is indicated by the Timer output checkbox in the edit dialog.

Tip2: The status bits of this agent indicate when the timer is running or has expired

The BOOLEAN start slot initiates and terminates this timing operation and can be driven as follows:

  • Manually either by checking or clearing the Start timer checkbox in the edit dialog or via a mimic.
  • Automatically via a script.

Note1: It is not possible to drive this slot automatically by subscribing to another tag.

Note2: When the start slot becomes disabled (set to FALSE), the value slot is also disabled and the timer expires.

Note3: The configured timer CANNOT be restarted.

To configure a pulse generator

Note: When typing values into this edit dialog, click the Update button to register these changes.

  1. If necessary, open the Edit Timer Agent dialog, as follows:
    1. If necessary, add an Timer agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Timer Agent dialog.
  1. If necessary, the timer can be started or stopped manually within this edit dialog, by checking or clearing the Start timer checkbox, which configures the start slot directly.

Note: The Input tag edit box is ignored, since this timer CANNOT be started automatically by subscribing to another tag in the Agent Server.

  1. Use the Delay time (ms) field to specify the period, in milliseconds, that this generated pulse is required to be OFF for i.e. after which the specified Pulse width (ms) period will begin. During this time the Boolean output (value slot) of this agent will be disabled (set to FALSE).
  2. Use the Pulse width (ms) field to specify the period, in milliseconds, that this generated pulse is required to be ON for i.e. the width of the required pulse. During this time the Boolean output (value slot) of this agent will be enabled (set to TRUE).
  3. The period of the generated pulse is the sum of the Delay time (ms) and Pulse width (ms) fields. For example: if Delay time (ms) = 59000 and Pulse width (ms) = 1000, then the Boolean output (value slot) of this agent will be enabled for 1 second every 60 seconds, until the Boolean start slot of this Timer agent is disabled (set to FALSE).

Note: The Timer output checkbox indicates the current status of the value slot of this agent.

  1. The Free running checkbox must be enabled (checked) for this timing operation.
  2. If necessary, set the Granularity (ms) field to specify the required period, in milliseconds, for monitoring the time during this timing operation.

When this period is less than the required duration of the timer, then the timeleft slot (Time left field) indicates the remaining time, in milliseconds.

WARNING! The smaller this Granularity value the greater the amount of work the Agent Server is required to perform in updating its clients with the timeleft slot value.

Note1: The default value of 0 forces this granularity period to equal the required timer duration, so that the timeleft slot (Time left field) is never calculated.

Note2: Although this setting has a minimum of 100 ms, a minimum of 1000 ms is recommended.

The Auto-reset checkbox is greyed out, since this timer cannot be restarted automatically.
