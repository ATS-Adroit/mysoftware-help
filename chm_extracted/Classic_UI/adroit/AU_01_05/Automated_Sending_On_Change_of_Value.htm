Automated Sending On Change of Value

The Command agent is able to send an automatic SMS message that contains the value of a tag (agent.slot) to remotely monitor the status of important process values.

One of the methods by which these messages can be automated, is by sending a message whenever the value of the specified tag changes. For details of the other methods, see Automatic Sending of Values.

To send an SMS message when the value of its tag changes:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Subscriptions tab.
  2. If necessary, click the Add subscription button to add a new entry.
  3. If necessary, select the Tag/Pseudonym cell, in the required row and specify the name of the required tag or its pseudonym, whose value is to be automatically sent to the designated recipient of this Command agent.

Tip: When specifying the name of the tag, use the browse button to the left of this cell to browse for the required tag (agent.slot). For details, see Selecting the Agent and Slot Names.

Note: When using a pseudonym, ensure that it has been created, that it is spelt correctly and that the use of pseudonyms have been enabled for this Command agent. For details, see Creating Pseudonyms or Enabling Pseudonyms and Macros.

  1. Ensure that the Trigger / Deadband cell is empty.

 

The designated recipient of this Command agent, will then receive automatic SMS message whenever this tag value changes, which adhere to the following format:

<SUB UPDATE> tagName = value

In this case, tagName is the name of the tag specified in step 5.

Note: If the default formatting of real numbers has been configured for this Command agent, this format will be used to display real or floating-point values. For details, see Default Real Number Formatting.
