Configuring Authorised Caller Access

Once a Command agent has been linked to a device, it is possible to specify one or more additional cell phone numbers that are able to send SMS messages to it. For details, see Specifying the GSM_SMS Device.

This method of specifying additional cell phone requires the cell phone numbers of all the callers who are allowed to issue commands to this Command agent to be added to the Cmd phone numbers list.

Furthermore, only these specified callers are able to ‘command’ this agent and hence will consume scan licenses. For details, see Allowing Commands to be Performed.

Note: This list can hold a maximum of 10 numbers.

Tip: Since these commands are able to obtain and/or control any process value or slot exposed by the Agent Server, it is recommended to limit these command-able phone numbers for security reasons.

To add an authorised transmitting phone number:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Phone tab.
  2. Under the Phone Settings group, click the plus button to the right of the Cmd phone numbers list heading.

This displays the New phone number… dialog, specify the required number in its Enter a phone number edit box and click OK.

When specifying this number, please observe the following formatting restrictions:

  1. Use a plus sign ‘+’ in front of the required number.
  2. ONLY specify the digits of the number.
  3. Do not use letters, spaces, hyphens to separate these numbers etc. +27830000000

 

To remove an authorised transmitting phone number:

  1. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Phone tab.
  2. Under the Phone Settings group, select the phone number in the Cmd phone numbers list that is no longer required and click the minus button next to the list heading.
