The Command Agent

The Command agent can send and receive SMS messages, by using a device of the GSM_SMS protocol driver to bypass the scanning subsystem with its imposed scanning limitation of 79 character strings, so that the full 160-character SMS message length can be used. Its name is derived from its ability to also receive commands within these textual messages, which can manage Adroit remotely.

Note: The sole function of this new GSM_SMS driver is to send and receive SMS messages to and from a SMS GSM modem. For details, see About the GSM_SMS driver.

For details, concerning the configuration and use of this agent, see Configuring Command Agents.

This agent, unlike the Notify agent, provides the following functionality:

Note: If necessary, this agent can be used to SMS alarms received by the Notify agent instead. For details, see Message Sending and Processing Slots.

  1. The ability to BOTH send and receive SMS messages of up to the full 160 character SMS message limit, instead of being restricted to only 79 characters.
  2. Send SMS messages to a single recipient, manually, programmatically or automatically to remotely monitor the status of important process values. For further details, see Sending SMS Messages.
  3. Sent SMS messages can also be monitored for auditing purposes.
    If they are not received and/or responded to within a specified period they can also be sent to another recipient via another Command agent, such as a colleague or even escalated up the management chain, if necessary.
  4. Receive SMS messages from the one or more cell phones and, if necessary, perform commands to remotely supervise and control your process and configure Adroit, for instance, by acknowledging alarms or fetching or setting process values etc.
    For details, see Allowing Commands to be Received or for details of the available commands that can be performed, see Available Commands.

PLEASE NOTE: Once the Command agent is configured to receive commands, scan point licenses are consumed by every unique phone number that is able to send an SMS command to this Command agent i.e. by both the configured recipient phone number and any additional cell phone numbers that are specified or used to send SMS messages to it. For details, see Specifying Additional Callers.

This is in accordance with the generally adopted Adroit policy, where information is provided freely, but where you are obliged to pay for the service of manipulating information.

  1. Pseudonyms can also be used when specifying commands, to simplify the process of specifying commands by providing shorter aliases for the names of commonly referenced tag (agent.slot) names.
    In addition to this macros can also be used to provide shortened aliases for commonly used commands. For details, see Using Pseudonyms and Macros.
