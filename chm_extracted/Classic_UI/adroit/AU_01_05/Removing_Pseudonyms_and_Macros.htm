Removing Pseudonyms and Macros

Pseudonyms and macros act as placeholders for part or all of a textual command that is sent to a Command agent. For details, see Using Pseudonyms and Macros.

It is also possible to remove any pseudonyms and/or macros that have been created and are no longer required.

To remove unnecessary pseudonyms and/or macros:

  1. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Pseudonyms and Macros tab.
  2. Select the required pseudonym and/or macro and click the Remove pseudonym or macro button to delete this entry.

WARNING! This will immediately remove the currently selected row.

Tip: It is possible to immediately undo this removal by clicking the Refresh button, although once the Update or OK buttons are clicked this row will be permanently removed.
