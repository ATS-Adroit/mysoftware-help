SNMP Object Value Return Types

The following list describes the typical type of data that are returned by SNMP object values and the recommended tag (agent.slot) that can be used to store this value and whether this data type can be written to:

Note: ONLY the specified return types are writable.

  1. Integer32: An integer variable, between -2^31 (-2147483648 decimal) and 2^31-1 (2147483647 decimal) inclusive. This should typically be stored in an Integer agent. This is writable.
  2. Unsigned 32-bit value: An integer variable, between 0 and 2^32-1 (4294967295 decimal) inclusive. This should typically be stored in a Real agent. This is writable.
  3. 32-bit counter: A counter variable that is a non-negative integer which increments until it reaches a maximum value of 2^32-1 (4294967295 decimal), when it wraps around and starts increasing again from zero. This should typically be stored in a Real agent. This is writable.
  4. 32-bit gauge: A gauge variable that represents a non-negative integer, which may increase or decrease, but shall never exceed a maximum value. This maximum value cannot be greater than 2^32-1 (4294967295 decimal). This should typically be stored in a Real agent. This is writable.
  5. Time ticks: A timeticks variable represents a non-negative integer which represents the time, modulo 2^32 (4294967296 decimal), in hundredths of a second for a specific timer event, which should be identified by the description of its object. This should typically be stored in a Real agent. This is writable.
  6. 64-bit counter: A counter variable that is a non-negative integer which increments until it reaches a maximum value of 2^64-1 (18446744073709551615 decimal), when it wraps around and starts increasing again from zero. This should typically be stored in a Real agent. This is writable.
  7. Real: A real variable that represents a double precision floating point number (64 bits). This should typically be stored in a Real agent.
  8. String: A string variable. This should typically be stored in a String agent.
  9. Bits: A variable that is an enumeration of named bits with non-negative, contiguous values, starting at zero. This should typically be stored in a String agent.
  10. Object Identifier: An object identifier variable that represents administratively assigned names, which may have at most 128 sub- identifiers. This should typically be stored in a String agent.
  11. Sequence: An ASN sequence variable. This should typically be stored in a String agent. This is writable.
  12. IP Address: An IP address variable that represents a 32-bit Internet address, in network byte-order. This should typically be stored in a String agent. This is writable.
  13. Opague variable: This should typically be stored in a String agent. This is writable.
  14. Octet String: This should typically be stored in a String agent. This is writable.
