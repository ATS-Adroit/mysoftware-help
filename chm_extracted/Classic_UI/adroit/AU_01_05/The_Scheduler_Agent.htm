The Scheduler Agent

The Scheduler agent can be used to define one or more periods of time during which its BOOLEAN output (value slot) will be enabled (set to slot to TRUE or 1); alternatively, it is also possible to manually set the output.

This output can be used as an enabling/disabling tag for other Agent Server configurations; scanned to a front-end device, and/or an application can be run as soon as the output becomes enabled i.e. at the start of each defined period of time.

Note: The Scheduler agent supports real-time catch-up.
