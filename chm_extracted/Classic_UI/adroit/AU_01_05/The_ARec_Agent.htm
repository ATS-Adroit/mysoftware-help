The ARec Agent

The ARec agent or "Associated digital Record" agent, is a fancy version of the Multistate agent that enables the configuration of up to 255 states using truth table type logic on up to 32 bits.

These 32 bits can be mapped to individual digital tags or the complete 32 bit value can be scanned from an external value.

Each state can be configured to test a mask of the bits for ON, OFF or DON'T CARE conditions and can also be tested for timeouts and can be used to set status bits. In addition, each state, or timed out state, can be configured to set or clear one or more of the 32 input bits, allowing this agent to be used as a sequence controller.

It is also possible to configure the AREC agent as a numerical sequence, to display text, similar to the StringList agent, except that the AREC supports up to 255 sequence steps and enables these steps to set its status bits.
