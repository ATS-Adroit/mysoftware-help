PID Alarm Limits

The PID agent type provides alarming capabilities for both the PV (process value) and the %Error or the percentage deviation of the PV from the SP (the required set-point).

As such it is possible to define L, LL, H and HH for the PV and an H and HH alarm for the %Error, for each instance of the PID agent.

  1. The L(low)and H (high) inner alarms are the first warning that a process value has moved outside its acceptable range, and implies that corrective action must be taken, by the control algorithm, as soon as possible.
  2. The LL (low low) and HH (high high) outer alarms are the second warning that the process value has moved further from its acceptable range and reached the second alarm limit. This implies that the first warning has been ignored and urgent and immediate corrective action, by the control algorithm, is now required.

Note: that whenever the LL alarm is on, the L alarm must by definition already be on. Similarly, whenever the HH alarm limit is reached, the H alarm limit will already have been passed. The alarm will not be cleared until the process value goes past the limit.

When the value of the PValue or Error slot of the agent reaches one or more of these configured limits, the agent will set the relevant specific status bit.

Any Alarm agent subscribing to the PID agent will detect these status bits.
