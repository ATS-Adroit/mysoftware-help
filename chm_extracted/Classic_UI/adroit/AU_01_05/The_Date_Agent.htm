The Date Agent

Date agents are particularly useful when used in conjunction with Extract, the historical log extraction utility, in which case slots of Date agents can be used to reference dates and times, instead of cumbersome command-line parameters.

The Date agent holds in its slots the localTime, universal UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI). time, the time since 00h00 1st Jan 1970 as an integer (cTime), and a breakdown of the local time into year, month, day, hour, minute, second and millisecond slots.

The format slot governs the way in which the date and time are displayed in the asciiTime slot. Triggering the setTime slot causes the agent local time to be updated by the system clock. Any change to a slot (except the asciiTime slot) will cause all the slot values to be updated to their relevant values.

Note: You should never externally manipulate the localtime slot of the Date agent from a mimic using an operator action. The localtime slot must be used for viewing the time and the ucttime slot MUST be used for manipulating the datetime value. This is by design of the Date agent only. All other time slots in Adroit can be viewed and edited directly.

The format argument consists of one or more codes, which are preceded by a percent sign (%).

Note: An additional flag (#) may prefix any formatting code after its % symbol.
