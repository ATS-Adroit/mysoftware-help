Sending SMS Messages

SMS messages will only be sent to the specified phone number of the recipient of this Command agent via the specified GSM_SMS device. For details, see Specifying the Recipient Phone Number and Specifying the GSM_SMS Device.

Note: If necessary, sent SMS messages can also be sent via another Command agent to another recipient, if they are not received and/or responded to within a specified period. For details, see Monitoring Message Receipt and Monitoring Message Response.

SMS messages can be sent by means of the following methods:

Note1: If the Require recipient response option is enabled, all sent messages will be prefixed by an asterisk "*" to indicate to the recipient that he/she needs to return the message to the Command agent. For details, see Monitoring Message Response.

Note2: When the Resend message checkbox is cleared (its default setting) a message will ONLY be sent if the rawvalue of this agent HAS changed when dialog is either updated or closed. This effectively prevents the resending of identical messages.

  1. Manually: By typing the required message in the Raw value edit box provided at the bottom of the Edit Command agent dialog. For details on displaying this dialog, see Editing Agents.

Tip1: It is also possible to expose the required message processing and/or sending slot and send messages to it directly by using a mimic, for instance, by associating a Data Entry Operator Action Behaviour to it. For details on these slots, see Message Sending and Processing Slots.

Tip2: In addition to simple text it is also possible to place commands into these slots so that they can be performed before the message is sent. For details of the available commands that can be performed, see Available Commands.

  1. Programmatically: By using another agent to create the message dynamically and then passing it into the required message processing and/or sending slot of the required Command agent.
  2. Automatically: The Command agent is able to send an automatic SMS message that contains the value of a tag (agent.slot) to remotely monitor the status of important process values.
    This message can either be sent when triggered by another Adroit tag or when the change in its value exceeds the specified deadband. For details, see Automatic Sending of Values.

Note: Pseudonyms and macros are generally used to simply the creation of SMS messages that are RECEIVED by the Command agent. For details, see Using Pseudonyms and Macros.

Tip: The lastMsgSentTime slot displays the time of the last message sent.
