Configuring Digital Agents

You can configure a Digital agent to provide change and/or value monitoring, value inversion, textual descriptions of its two states and other functionality to a Booleana value that only has two discrete states, 0 (FALSE) or 1 (TRUE). value, as follows:

If necessary, open the Edit Digital Agent dialog, as follows:

  1. If necessary, add an Digital agent. For details, see To Add a New Agent.
  2. Select the name of this agent. For details, see To Select an Agent.
  3. Right click and select the Edit... menu item to display the Edit Digital Agent dialog.

To edit or view or display the current value: to view or change this value manually.

  • The current state of the value slot is displayed and configured by the list box in the Value section that displays the textual description of the current state (the textValue slot ).
  • The Raw value field of the Value section displays the current value of the rawValue slot.
  • To edit the value (the value slot) of this Digital agent, select the required state from the list box in the Value section.

Note1: Click the Update or OK button to save the changes BEFORE clicking the Refresh button; otherwise this value change is lost.

Note2: This value will ONLY be changed to the specified value if it is NOT being scanned.

Note: Adroit uses positive logic, so that OFF = 0 and ON = 1.

Tip: Use the value slot to display this value, so the tag would be DigitalAgentName.value.

To invert the raw value:when you want to use and display the OPPOSITE state that is scanned in from the device.

  1. Check the Value Inverted checkbox (the invert slot) of the Value section.

Note: Click the Update or OK button to save the changes BEFORE clicking the Refresh button; otherwise this configuration change is lost.

This causes the value slot to always be opposite to the Raw value (the rawValue slot), which is typically this is the value that is scanned from the front-end device..

Note: The current state of the value slot is displayed and configured by the list box in the Value section that displays the textual description of the current state (the textValue slot).

Therefore if the rawValue slot is 0, the value slot is set to 1, then changing the value slot to 0, sets the rawValue slot is 1.

To change the textual description displayed when the value slot is 0: this is usually required if your process uses different terminology, from the default of OFF to refer to this state.

  1. Edit the OFF state field (the state0 slot) in the Text section appropriately.

Typical options for this field are: OFF, OUT, 0, DISABLED.

Note1: Click the Update or OK button to save the changes BEFORE clicking the Refresh button; otherwise this value change is lost.

Note2: This will change the value displayed for this state in the list box of the Value section and, if necessary, the value of the textValue slot too.

To change the textual description displayed when the value slot is 1: this is usually required if your process uses different terminology, from the default of ON to refer to this state.

  1. Edit the ON state field (the state1 slot) in the Text section appropriately.

Typical options for this field are: ON, IN, 1, ENABLED.

Note1: Click the Update or OK button to save the changes BEFORE clicking the Refresh button; otherwise this value change is lost.

Note2: This will change the value displayed for this state in the list box of the Value section and, if necessary, the value of the textValue slot too.

To monitor this value for changes: if enabled, any change in value instantaneously sets the Changed specific status bit of this agent and records the previous value.

To enable and specify a default (cold-start) value: to specify the default value to use when the Agent Server is started and it does not have a value specified for this agent. If enabled, this value is sent to the front-end device when the Agent Server starts up.

  1. Check the Enable checkbox in the Cold start section.
  2. Select the required state of this value from the State list box (the initValue slot).

This state is sent to the scanned front-end device for this Digital agent when the Agent Server is first loaded.

To enable and specify a pulsed output: to specify how long this digital should maintain its ON (1) state and can be used to emulate the action of a push button.

  1. Check the Enabled checkbox in the Pulsed output section.
  2. Specify the required Delay, in milliseconds, that the value slot should remain at 1 for.

Note slot, if this value is inverted value applies to the Delay: Since this(the invert slot set to 1) then the effect of the pulsed output is ALSO inverted. In other words the Delay specifies the length of time that the value slot remains at 0 for.
