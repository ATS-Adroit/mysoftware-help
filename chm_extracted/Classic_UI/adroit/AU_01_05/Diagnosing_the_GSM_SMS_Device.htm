Diagnosing the GSM_SMS Device

Once a GSM_SMS device has been specified for this Command agent, the following key communication diagnostic indicators are exposed to this Command agent:

Note: For details on specifying this device, see Specifying the GSM_SMS Device.

  1. Signal Strength: This signalStrength slot is displayed within the Edit Command agent dialog and indicates the strength, in percent, of the current signal of the GSM modem that is being used to transmit and receive the SMS messages.

According to the GSM specification, the signal strength must be greater than 29 % to reliably transmit data.

  1. Bit Error Rate: This bitErrorRate slot is not displayed within the Edit Command agent dialog and indicates the quality of the communications i.e. a high bit error rate indicates that there is a large amount of interference, in percent.

According to the GSM specification, the bit error rate must NOT be greater than 40 % signal strength to reliably transmit data.

The SignalError specific status bit monitors the values of BOTH of these slots of the command agent and if either the signalStrength slot is less than 29 % or the bitErrorRate slot is greater than 40 %, this specific status bit will be enabled. For details, see Specific Status Bits.

Note1: If this is checked, it does NOT mean that SMS messages will not be sent or received, it only indicates that the current conditions are unfavorable for their successful receipt or delivery i.e. this should be used for troubleshooting purposes only.

Note2: The MsgSendError specific status bit should also be monitored for troubleshooting purposes; this is checked whenever the last message could not be sent due to cell phone network-specific problems, such as signal problems etc.

To view the signal strength of the device used by a Command agent:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Phone tab.
  2. Under the ‘GSM_SMS’ Device Diagnostics group, the value to the right of the Signal Strength (in %) specifies the current percentage strength of the signal that is being received by this GSM SMS modem.

The progress bar below this represents this signal strength graphically.
