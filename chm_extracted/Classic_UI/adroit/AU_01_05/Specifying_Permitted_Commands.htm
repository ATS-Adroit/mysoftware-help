Specifying Permitted Commands

Once a Command agent has been allowed to perform commands, NONE of the available commands are selected by default, since certain commands pose a greater security and operational risk than others.

For this reason it is necessary to specify exactly which commands each Command agent are able to perform. For details on allowing a command agent to perform commands, see Allowing Commands to be Performed.

To select which commands a Command agent is able to perform:

  1. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. If necessary, select the General tab, the default selection.
  2. Under the Commands group, ensure that the Enable commands checkbox is checked.
  3. Check or clear, the checkboxes next to the available commands, listed beneath each of the following checkboxes, as required:

Note: For details of the available commands that can be performed, see Available Commands.

  • Allow ‘Get’ commands: If checked, this will allow this agent to retrieve the value of any tag (agent.slot) exposed by the Agent Server and the GetCommands specific status bit for this agent will also be checked, to indicate this. For details, see GET Commands or Specific Status Bits.

Note: This command does not pose a security risk since process values are only received.

  • Allow ‘Set’ commands: If checked, this will allow this agent to modify the value of any tag (agent.slot) exposed by the Agent Server and the SetCommands specific status bit for this agent will also be checked, to indicate this. For details, see SET Commands.

WARNING! Since this command can cause a serious security and operational risk, additional settings are provided to further restrict its usage. For details, see Additional SET Command Restrictions.

  • Allow ‘Ack’ commands: If checked, this will allow this agent to globally and/or locally acknowledge alarms that have been reported by an agent within the Agent Server. The AckCommands specific status bit for this agent will also be checked, to indicate this. For details, see ACK Commands.

Note: This command DOES pose a security risk since alarms can be acknowledged remotely.
