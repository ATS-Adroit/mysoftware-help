Enabling the Changing of OID Values

You can change (write to) OID values in the managed device, so that you can remotely control the device from Adroit.

Each OID value that you want to control requires an associated tagA fully qualified named value in Adroit (agentName.slotName)., since the OID value is only written to when the value of this tag changes.

To enable the writing of a selected OID value:

This assumes that the edit dialog is displayed and the required OID value has already been added to the list.

  1. Click the Name field of the required OID value to select this row in the list.
  2. Click the Browse tag button and use the built-in agent explorer to create and/or select the Tag that will contain this value. For details, see Select a Tag Using the Agent Explorer.

Note: Ensure that the return type of this OID value be saved in this agent type and can be written to. For help on this, see SNMP Object Value Return Types.

  1. Click the W field of this row to place a tick in this tick box.

This only indicates that you want to change this OID value when the value of the specified Tag changes.

  1. Ensure that you either click the Update or OK button BEFORE clicking the Refresh button; otherwise these configuration changes will be lost.

This value will only be written to the device, when:

  • you select the Enable polling option (BOOLEAN start slot) in the Poll settings section of this agent
  • you have specified connection settings that allow this device’s OID values to be written
  • the value of its specified Tag changes

At this point a single scan point license is consumed for this service. If the write fails, then the SNMPMgr agent polls the device for this OID value to obtain its original value and the Current Value field is updated accordingly.

Tip: The lastWriteStatus STRING slot, displays a text message that indicates whether the last value written to the device was successfully changed in the device or not.
