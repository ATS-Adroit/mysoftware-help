Using Pseudonyms and Macros

Pseudonyms and macros can be created to simply the process of specifying these commands by acting as placeholders for part or all of a textual command that is sent to a Command agent. Therefore they only need to be created for Command agents that have been enabled to receive commands. For details, see Allowing Commands to be Performed.

Before pseudonyms and macros can be used in messages, it is necessary to alert the Command agent to their possible existence in its received messages, so that they can be correctly interpreted. For details, see Enabling Pseudonyms and Macros.

Note1: Pseudonyms and macros are specific to the Command agent in which they are defined and are not global to all Command agents. However when a Command agent is copied, any defined macros and pseudonyms will also be duplicated. For details, see Copying Agents.

Note2: Pseudonyms and macros can also be used to further restrict or limit the SET-table tags / commands that can be performed by this Command agent. For details, see Limiting SET Commands.

A pseudonym is simply an abbreviation or alias for a tag (agent.slot), which once defined can be used to represent this tag in commands that are sent to this Command agent. For details, see Creating Pseudonyms.

Note: Although pseudonyms can reduce the typing required to specify commands, they need to be defined for this Command agent before they can be used.

A macro is simply an abbreviation or alias for an ENTIRE command, which once defined can be used when issuing this command to this Command agent. For details, see Creating Macros or for details of the available commands that can be performed, see Available Commands.

Note: Although macros can provide the most intuitive and the shortest command names, they are also the MOST restrictive, since this entire command must be pre-configured in this Command agent, before it can be used.

It is also possible to remove any pseudonyms and/or macros that are no longer required. For details, see Removing Pseudonyms and Macros.
