Specific Status Bits of the MaxDemand Agent

The following status bits of this agent can be used to indicate when the maximum demand limit is exceeded or to troubleshoot the monitoring process, as follows:

  • statusBit16
    MaxDemand

On if when the predicted block maximum demand exceeds maximum demand limit.

Note: This will ONLY be set if the Enable max demand alarm checkbox (the enableMDAlarm slot) is checked.

Tip: This can be used to control the maximum demand by turning off non-essential equipment via a script.
  • statusBit17
    Unlicensed

Not used.
  • statusBit18
    PulseError

On when an error occurs in the timing of external block pulses are compromised, in other words as soon as a pulse does not occur at the period specified by the Block period (mins) value (the blockPeriod slot).

Tip: Alarm the ‘PulseError’ alarm type for this agent to warn you when this occurs.
