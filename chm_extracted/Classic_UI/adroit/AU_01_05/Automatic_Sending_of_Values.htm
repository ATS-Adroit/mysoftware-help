Automatic Sending of Values

The Command agent is able to send an automatic SMS message that contains the value of a tag (agent.slot) to remotely monitor the status of important process values. For details of the other methods of sending SMS messages, see Sending SMS Messages.

The following mechanisms can be used to send these automatic messages:

  1. On change: In this case an SMS message is sent whenever the value of the specified tag changes. For details, see Automated Sending On Change of Value.
  2. On significant change: In this case an SMS message is ONLY sent when the change in the value of the specified tag exceeds a specified deadband. For details, see Automating Sending On Significant Change of Value.
  3. By triggering: In this case, an SMS message is ONLY sent when it is triggered by another tag i.e. when the value of this tag changes. For details, see Automating Sending By Triggering.

Tip: This last mechanism can be used to send or report values at pre-configured intervals, simply by configuring an Expression or Script agent to provide an appropriate trigger.

 

The received automatic SMS message, adheres to the following format:

<SUB UPDATE> tagName = value

In this case, tagName is the name of the tag whose value is to be displayed.

Note: If the default formatting of real numbers has been configured for this Command agent, this format will be used to display real or floating-point values. For details, see Default Real Number Formatting.
