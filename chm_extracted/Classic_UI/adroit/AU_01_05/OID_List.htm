OID List

The SNMPMgr agent can manage a device by getting and/or setting SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. (OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. values) from a single device on the network.

All the selected OIDs are added to the list in the Edit SNMPMgr Agent dialog. However, you can also select and/or configure the records in this list outside of this agent, for instance to allow a mimic to navigate the listed OIDs. In this case, see Externally Accessing the OID List.

Tip: You can use the Export button to save and/or bulk configure these OIDs within a .CSV file.  For details, see Exporting the OID List.

This OID list is NOT saved to WGP file but to the 'snmpmgr.wgx' file, which is stored in the Data folder of your Adroit configuration, which is typically: C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\Data. This file stores the OID lists of all your SNMPMgr agents, allowing you to create large lists of OIDs for each agent without substantially increasing the size of the WGP file.

IMPORTANT: Please ensure that you backup this 'snmpmgr.wgx' file in addition to the WGP file, which is stored in the same folder.

Each OID in this list contains the following columns:

  1. I (Index): The zero-based integer index of this SNMP object in this list.

Note: This index is used to select and/or configure OIDs in this list from outside of this agent. For details, see Externally Accessing the OID List.

  1. E (Enable): This checkbox determines whether the OID value will be copied into the specified Tag at the applicable rate, so that it can be monitored. For details, see Enabling the Monitoring of OID Values.
  1. W (Writable): This checkbox determines whether this OID value will be changed when the value of the specified Tag changes. For details, see Enabling the Changing of Values.

Note: Please ensure that the returned data type can be written to. For details, see: SNMP Object Value Return Types.

  1. OID (Object Identifier): The OID of this SNMP object, which specifies the unique numeric description of this OID. For further details, see Selecting SNMP Objects.
  1. Name: The textual description this OID, when available.
  1. Type (Return type): This field displays the following integer values that represents the type of data returned by this OID, which therefore determines which agent/s you can use to store this data:

  1. Current Value: This field displays the last value of the OID that is ENABLED for monitoring.

In other words, this field is ONLY updated when the corresponding E field is enabled and the Enable Polling option (BOOLEAN start slot) is selected and its value has changed within the last polling period.

  1. Tag (Agent.slot): The appropriate tagA fully qualified named value in Adroit (agentName.slotName). that either contains or writes to this OID value. Use the Browse tag button to specify the required tag. For details, see Select a Tag Using the Agent Explorer.

  1. Rate: If this OID value changes faster or slower than the default Poll rate for this agent, then specify the required rate, in milliseconds, in this field.

    By default this is 0 which uses the default Poll rate of this agent, specified in the Poll settings section.

Note: This rate cannot be less than 5 seconds, the minimum for the Poll rate for this agent.

The following buttons are also provided:

  1. Add OID manually button: Displays the Add OID entry dialog to add one or more SNMP objects to the list manually. For details, see Adding OIDs Manually.

Tip: Use this when the SNMP enabled device is not physically connected to the computer.

  1. Edit OID list button: Displays the Edit OID entry dialog to edit one or more SNMP objects in the list. For details, see Editing Listed SNMP Objects.
  2. Browse OID to add button: Displays the SNMP Objects Browser dialog to add one or more SNMP objects to the list. For details, see Selecting SNMP Objects.
  3. Remove selected row button: Deletes the currently selected row in the list of selected SNMP objects.

WARNING! This deletion is performed immediately - no confirmation dialog is displayed.

  1. Browse tag button: Displays the built-in agent explorer to specify the required tag (agent.slot) in the Tag field of the currently selected row in the list of selected SNMP objects.
  2. Auto-refresh values checkbox: If checked, this retrieved the values of all the OIDs in the list, at their configured poll rates, so they change as fast as they are being monitored. This disables the Refresh button.
  3. Refresh button: Queries the specified device for the latest values of all the OIDs in the list.
  4. Update button: Saves any configuration changes that have been made, such as when you select the Enable polling or Disable polling options for this agent.

Tip: Ensure this is clicked BEFORE clicking the Refresh button; otherwise the configuration changes may be lost.
