Protocol Driver Information

The following attributes are displayed in the information pane at the top of the right windowpane when an installed () or partially installed () Protocol Driver has been selected in the right Installed Drivers and Devices windowpane.

  • Description: This is the same as the name of the installed protocol driver.
  • Filename: The full path and name of the DLL file used by this installed protocol driver.
  • Revision: The current revision of this installed protocol driver.
  • Devices: The number of devices configured for this driver.
  • Comments: Usually not displayed, but used to note any driver-specific information that changes its functionality e.g. the Adroit Simulation Driver’s Comment is "Comms analyser not present".

Advanced troubleshooting information is also displayed when the Advanced View is configured.
