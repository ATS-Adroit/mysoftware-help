Scan Point Licensing Exceptions

Scan point licenses or 'scan points' are just one of the components of an Adroit license. These are consumed when information is being manipulated in some way. Their typical usage is when communicating (scanning) a value to a front-end device. However, there are a number of other consumers of scan point licenses, as follows:

Note: This is in accordance with the generally adopted Adroit policy, where information is provided freely, but where you are obliged to pay for the service of manipulating information.

  1. Each DbAccess and Script agent consumes a single scan point license to run. This license is checked before doing a DbAccess transaction for the first time (on a per agent basis) or running the Script for the first time (on a per agent basis) and is only returned when the agent is deleted.
  2. Any derived Custom agent, containing a Script engine, will consume a scan point license.
  3. Any pokes performed (i.e. an operation that changes the value of an agent.slot) using either the Adroit OLE Automation Interface (MISSRVR) or the Adroit ActiveX component will consume a scan point license for each unique tag (agent.slot) that is "poked".
    Also, as the AlarmTag, LogTag and ScanTag functions all use pokes internally, calls to these functions will also consume scan point licenses. Also the FetchChanges & FetchValues functions of the Adroit ActiveX component also consume scan point licenses for the same reason.
  4. Any tag (agent.slot) writes from the Adroit OPC Server will consume one scan point license per unique tag.
  1. Once a Command agent has been allowed to perform commands, scan point licenses are consumed by every unique phone number specified by this agent and/or used to send SMS messages to it. For details, see Specifying Additional Callers.
  1. The SNMPMgr agent consumes a scan point for each unique OID value that is monitored, written and/or trapped.
  2. Any agent created for a UDT agent type created by the UDT Agent Type Designer consumes (number of slots-1) scan points. The other scan point will be consumed if and when its rawValue slot is scanned.

For further details of what is licensed by an Adroit (Agent Server) licence, see Adroit Licensing.
