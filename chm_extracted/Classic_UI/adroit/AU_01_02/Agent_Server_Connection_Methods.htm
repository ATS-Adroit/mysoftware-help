Agent Server Connection Methods

Adroit provides three methods for allowing multiple distributed Agent Servers to seamlessly share their agents and the data that they contain. In other words, the ability to refer to agents within another Agent Server.

Note: Proxy agents are automatically created when an Agent Server accesses an agent that exists in a remote Agent Server.

Using the Project Name: This is the default method for connecting distributed Agent Servers, in which case you specify the SAME project name for ALL the Agent Servers that need to connect to each other, which adds them to this project. Network broadcasts are then made between ALL these Agent Servers to provide each other with two-way access to their agents. Click here for the limitations of this method and/or how to configure this method:

Disadvantages:

  • In practice each Agent Server within a project typically only connects to agents in SOME of the other specified Agent Servers, which results in unnecessary network traffic between the Agent Servers that are not actually communicating with one another.
  • This connection mechanism uses Agent Server broadcasts, which do not work across domains or routers/switches (a WAN). You need to use the explicit connection mechanism to connect Agent Servers that are in DIFFERENT domains or on OPPOSITE sides of a router or switch or any other network component that blocks network broadcasts.

Configuration:

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Agent Server Configuration again in the right hand pane.

  1. Specify the SAME Project Name.

Note1: Project names must not contain any embedded spaces.

Note2: When more than one project name is being used on the same network, ensure that the first 3 characters of each Project Name are UNIQUE.

Note3: When more than one Agent Server is being used within a project, ensure that the first 7 characters of each Agent Server Name are UNIQUE.

  1. If necessary, ensure that the remote Agent Server broadcasts are enabled, by clicking the Options… button to the right of the Project Name field and ensuring that the Enable remote servers to automatically detect this server checkbox is checked in the Project Options dialog (this is the default setting).

Creating Explicit Agent Server Connections: This is the ONLY way to connect Agent Servers that are in DIFFERENT domains or on OPPOSITE sides of a router or switch or any other network component that blocks network broadcasts.

In this case you specify exactly which Agent Servers you want your Agent Server to connect, however, these connections are not two-way. Click here for further details of this method, its limitations and/or how to configure this method:

In other words if Agent Server 1 has an explicit connection to Agent Server 2 then Agent Server 1 will be able to see data on Agent Server 2. If Agent Server 2 needs to see data on Agent Server 1 then an explicit connection to Agent Server 1 must be configured on Agent Server 2.

Disadvantages:

  • This method requires more administration overhead, in that you need to manually configure ALL the connections you require and if two-way connections are required, then you need to configure these explicit connections on BOTH computers.
  • The explicit connection mechanism can create unnecessary network traffic as it requires each Agent Server to continuously poll its explicit partners even if they are not up and running. 

Configuration:

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Agent Server Configuration again in the right hand pane.

  1. Ensure that an appropriate Project Name and Agent Server Name have been specified for BOTH of the computers that you want to connect.
  2. Click the Options button to the right of the Project Name field to display the project-specific settings.
  3. Check the Explicit connections checkbox. This is unchecked by default.
  4. Click the add button to add an entry to the end of the Agent Servers list, for which you need to provide the following details:
  5. The Machine Name that is used to identify this remote Agent Server computer on the network. Click for more details:this can be found by extracting all the words up to the first ‘.’ from in the Full computer name field of the Computer Name tab of the System applet in the Control Panel. For example if the Full computer name field is ‘bob.domain’, then simply specify ‘bob’.

Tip: You can either specify the textual computer name or the IP name of this computer e.g. 10.10.10.96

  • The Agent Server Name, which is the name of the remote Agent Server running on this computer, such as AS1.
  1. If necessary, specify the required Servers timeout (seconds), which specifies how often ALL the explicit connections are tested. If there is no response from the specified Agent Server, then it is assumed to be off-line until the next poll.

Note: To remove an Agent Server from the list, select a cell of the required Agent Server and click the delete button.

Tip: You should ONLY clear the Enable remote servers to automatically detect this server checkbox if you ONLY use this method of explicit connections to connect this Agent Server to other remote Agent Servers.

Note: If your computer network does not have a method of resolving computer names (such as WINSstands for Windows Internet Name Service, which predates DNS as the method used to resolve (translate) computer names and their IP addresses in a network. Unlike DNS which uses a hierarchical namespace, WINS uses a flat namespace. or DNSstands for Domain Name System and is one of the industry-standard suite of protocols that comprise TCP/IP, which is used to translates domain (computer) names to and from their IP addresses.), then you can use IP addresses in place of the PC name in explicit connections to connect to other Agent Servers.

Using the Projects / Servers list: In this case you can specify exactly which Agent Servers and/or projects an Agent Server can connect to. Since this connection mechanism works in tandem with the Using the Project Name method above, these connections are made IN ADDITION TO the Agent Server/s that are in the SAME project as this Agent Server.

IMPORTANT: In order for this connection mechanism to work, each Agent Server that is either uniquely specified or within a specified project of the Projects / Servers list of an Agent Server MUST enable this connection mechanism EVEN when their own Projects / Servers list is EMPTY. The safest rule to use is that if this mechanism is enabled on any one Agent Server, enable it on all your Agent Servers.

These specific connections also rely on Agent Server broadcasts but are NOT two-way in nature. Click here for further details of this method, its limitations and/or how to configure this method:

In other words Agent Server A’s Projects / Servers list allows it to access agents from any Agent Server or project configured in this list. If you require two-way access to these agents then Agent Server A’s project or server name must to be added to each remote Agent Server’s Projects / Servers list.

Disadvantages:

  • This connection mechanism requires more administration overhead than when using project names, in that you need to ensure that the Additional connections checkbox is enabled in the Project Options... dialogs of the Adroit Configuration Setup utilities that are associated with all the referenced Agent Servers.
  • To configure two-way connections, you need to configure this connection mechanism on BOTH Agent Servers.
  • This connection mechanism uses Agent Server broadcasts, which do not work across domains or routers/switches (a WAN). You need to use the explicit connection mechanism to connect Agent Servers that are in DIFFERENT domains or on OPPOSITE sides of a router or switch or any other network component that blocks network broadcasts.

Configuration:

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Agent Server Configuration again in the right hand pane.

  1. Ensure that an appropriate Project Name and Agent Server Name have been specified for BOTH of the computers that you want to connect.
  2. Click the Options button to the right of the Project Name field to display to display the project-specific settings.
  3. Check the Additional connections checkbox. This is unchecked by default.
  4. Click the add button to add an entry to the end of the Projects / Servers list, for which you need to provide the following details:

Note: You ONLY need to specify those Agent Server/s and/or projects that this Agent Server needs access to IN ADDITION TO the Agent Server/s that are within its project.

  • The required project name, as specified by the Project Name field of the Adroit Configuration Setup utility for the associated Agent Server/s.

Tip: The advantage of specifying a project name is that in ONE entry you immediately allow this Agent Server to access agents on all the Agent Servers within this project; otherwise you need to add individual entries for each of the Agent Servers within this project.

  • The required Agent Server name, as specified by the Agent Server Name field of the Adroit Configuration Setup utility for the associated Agent Server. In other words, do NOT also provide the computer name. For instance, specify AS1 and not BATCHPC.AS1. 

Note: Any entries that contain invalid characters (\ / . or space characters) will simply be ignored.

IMPORTANT: Please ensure that ALL the remote Agent Servers specified by this Projects / Servers list ALSO has their Additional connections checkbox checked in the Project Options dialog of their Adroit Configuration Setup utility – EVEN WHEN their own Projects / Servers list is EMPTY.

Note: To remove an entry from the list, select a cell of the required entry and click the delete button.

  1. Ensure that the Enable remote servers to automatically detect this server checkbox is checked.
