Adroit Drivers Install Dialog

Note: Installed Adroit protocol drivers are not removed when Adroit is uninstalled.

  1. The Show installed drivers only checkbox is unchecked by default and all the available drivers are shown as a result. If checked then only the installed drivers are visible in the Available protocol drivers list.
  2. If you need to specify another location from which to install Adroit protocol drivers, click the (…) browse button next to the Path edit box, to locate this disk or folder.
  3. Click the Refresh button, after manually changing the path in the Path edit box, to view the available drivers in this new path.

Note: The Upgrades button should only be used to update protocol drivers that have already been installed.

  1. Select the driver you wish to add from the Available protocol drivers list, using the scroll bar and clicking on the required entry.
  2. Use the Details button to view the component files of the selected driver and the path into which each of the files are to be installed on your system.
  3. Click the Copy button to copy the driver to your Adroit system folder, typically C:\Program Files\Adroit Technologies\Adroit.
  4. Click the Close button to exit the dialog, once all the necessary protocol drivers have been installed.

Note: If one or more of the Adroit protocol drivers that you installed, rely upon 3rd party hardware and/or software components that are not present, then for each driver a driver loading warning will be displayed and it will have the following icon: in the Installed Drivers and Devices list.

PLEASE NOTE: It is essential that the accompanying driver documentation be read carefully before continuing with the installation, since this specifies which devices are supported, how to configure the driver, how to scan using the driver, diagnostic tips and any relevant protocol information.
