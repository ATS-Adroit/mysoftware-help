Copy the Selected Device

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

  1. Click on the Drivers tab and right click on a configured Device (, , ) in the Installed Drivers and Devices list and select Copy Device ‘XXXXXXXX’ from the menu, where XXXXXXXX is the name of the selected configured device.

This will display the Drivername device dialog, where Drivername is the name of the protocol driver of the selected device.

  1. Specify a unique, 8-character name for the device e.g. you may not have a SIE3964R device 'BOILER1' as well as a MODBUSI device 'BOILER1'.

Note: The specified device name may not contain any illegal filename characters, such as .%\,$/*?<>:"’`=| etc. It is also recommended that this device name describe the function or location of the device being communicated to.

This dialog will also display the following beneath this edit field: This new device will be a copy of 'XXXXXXXX', when the setup dialog appears, change any necessary parameters and click OK, where 'XXXXXXXX' is the name of the selected configured Device (, , ) in the Installed Drivers and Devices list.

Click OK, to display the Drivername:DeviceName configuration dialog for the selected protocol driver, where Drivername is the name of the selected protocol driver and DeviceName is the name supplied in the previous dialog

Note1: A psexe warning may be displayed, if a configuration function does not exist for the selected driver.

Note2: If no changes are made when configuring a copied Device, the Device copy info message box is displayed; either click the Cancel button to remove this device or click Ok to keep this new identically configured device.

Note3: This protocol driver configuration is saved in the system registry; therefore it is necessary to reconfigure the devices if they are to be run on another computer.

Click Cancel to delete this newly created device.

Using the Adroit Config Editor:

This functionality is currently not provided.
