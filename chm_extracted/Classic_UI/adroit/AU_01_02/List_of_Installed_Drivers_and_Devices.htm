List of Installed Drivers and Devices

Press the Windows key and start typing in Classic Setup and select it from the list.

Click on the Drivers tab and the left windowpane of the Drivers tab in the Adroit Setup utility is entitled Installed Drivers and Devices.

This is a tree or explorer view, which allows selection and configuration of the protocol drivers and their devices installed on the computer and/or referenced in the current Adroit database (.WGP) file:

The first level primarily displays an alphabetical tree-view listing all the currently installed protocol drivers, indicated by this icon: .

Note1: Any problems experienced when installing a protocol driver, will cause this driver to have the following icon:.

Note2: If an installed protocol driver is double clicked this will immediately add a device.

Any of the installed protocol drivers, which have configured device(s) will have a collapsed icon: to the right of its icon. Click on this collapsed icon, to display an alphabetical listing of the configured device(s).

This icon indicates devices that are either not loaded or not connected to the Agent Server: .

Note: If a device is double clicked this will immediately open its Configuration dialog.

The following item may also appear at the top of the listing of protocol drivers, entitled ‘Used devices that are missing configuration’, which is distinguished from the installed protocol drivers by the following icon: . Clicking on its collapsed icon , will display an alphabetical listing of the devices that are have not yet been configured, which are distinguished from the configured devices by the following icon: .

Note: This listing of un-configured devices, will usually appear when the current Adroit database (.WGP) file, has been copied from another computer that includes devices that are not yet configured for this computer. Use the Advanced troubleshooting view to view the address of the first IO point scanned to this device.
