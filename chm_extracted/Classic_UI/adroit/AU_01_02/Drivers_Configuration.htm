Drivers Configuration

 

Press the Windows key and start typing in Classic Setup and select it from the list.

Click on the Drivers tab, to install the necessary protocol drivers and add, configure and remove their devices, so that the necessary scanning configuration can be performed via the Agent Configurator.

Tip: The Adroit Config Editor provides an alternate method of managing your protocol drivers and their devices. For details, see Drivers Configuration.

IMPORTANT: Due to a change in the Microsoft compiler used to produce the Adroit 10 drivers, ALL the protocol drivers from Adroit 7 onward are incompatible with protocol drivers in previous versions of Adroit.

Therefore you need to UPGRADE your existing drivers when upgrading from a prior version of Adroit to Adroit 10, since if you try to use your EXISTING Adroit 6, 5, 4x driver in Adroit 10, THEY WILL NOT WORK!!!. See How to upgrade your existing drivers.

 

For details on scanning in general, see the Scanning Overview.

Note: On opening this page any configured protocol drivers and their devices are loaded, any protocol drivers that are unable to be loaded will display a driver loading warning.

This dialog contains the following components:

  1. The left windowpane consists of the tree-view list of the installed drivers and their configured devices.

Note: If any entry in this left pane is truncated, by the width of its windowpane, a tool tip will display its entire text when selected by the mouse pointer.

  1. The right windowpane consists of the protocol driver and device information pane and buttons.

Note: Both windowpanes are separated by a splitter bar, which can be used to adjust their widths.
