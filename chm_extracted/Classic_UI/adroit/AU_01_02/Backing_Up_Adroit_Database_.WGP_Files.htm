Backing Up Adroit Database (.WGP) Files

The Adroit database or .WGP file stores almost all of the data and configuration of the Agent Server, including the added agents, their values and their alarming, logging and scanning configuration.

For this reason, it is essential that this file, along with the other Adroit project files, be frequently backed up to ensure that the integrity of this data is preserved. Since if this file is either deleted or becomes corrupted without having a recent backup, many man hours of effort will be lost.

Adroit WGP files, from Adroit 6 onwards, provide two additional features to assist with their regular back up, as follows:

WARNING! These features are merely intended to AUGMENT the existing backup system and NOT to REPLACE it i.e. it is still imperative that an efficient backup system is in place!

  1. Automatic backup of WGP file on each save: To further ensure that changes made to the WGP file are safeguarded between the regular backups, WGP files can now be automatically backed up each time they are saved. For details, see Configuring Automatic WGP File Backups.

Note1: If this is implemented, then at most only the changes made since the last save will be lost.

Note2: Restoring these saved WGP files is still a manual process, which requires: stopping the Agent Server, renaming the WGP file that is currently being used; locating and renaming the required backup file to this name and restarting the Agent Server.

  1. Version information saved in the WGP file: In addition to providing an audit trail of changes for debugging and troubleshooting purposes, this versioning information can also be used to assist in locating the required backup file when recovering lost changes. For details, see Versioning WGP Files.

 

For details on creating a backup procedure to guarantee disaster avoidance and to easily transfer a project to another system, see Creating Backup Procedures.
