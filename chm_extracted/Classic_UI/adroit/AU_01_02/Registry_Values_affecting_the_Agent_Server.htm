Registry Values affecting the Agent Server

This is an ALPHABETICAL list of the otherwise undocumented registry Values that affect the Agent Server and therefore its agents and their operation:

WARNING: Registry settings are recorded as ADVANCED information and should not be used unless you understand exactly how these will affect the operation of your Adroit  installation, IF YOU HAVE ANY DOUBTS, PLEASE CONTACT Adroit SUPPORT, BEFORE CHANGING THE REGISTRY.

PLEASE NOTE: When working on a 64 bit operating system, remember to add "\Wow6432Node" to the path of each registry setting after "\SOFTWARE", for instance: "HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\Adroit Technologies".

Note1: The Advanced Scanning Settings dialog can be used to configure the registry settings affecting the marshalling functionality of the Multistate agent and for enabling the 16 status bits of a Text agent to be set by the bit stream value of that text string e.g. "1110010011011000" (EnableTextBitStreams).

Note2: Many global datalogging settings can be set in the Advanced settings dialog of the DataLog agent, whenever you log a tag, see Advanced Datalog Configuration.

The StartupDelay setting to delay the start up of the Agent Server is configured in the Service tab of the Adroit Configuration Setup utility. For details, see Configuring Agent Server Startup Delay.

 

AcknowledgeAtStartup: To ensure that the Agent Server automatically acknowledges alarms at startup, either do NOT add this key or if you have added it, then set it to 1.

Active Link Monitoring: To remedy and troubleshoot slow (or unresponsive) Agent Servers and/or their clients.

AnalogRawComms: To ensure the correct operation of the Analog agent, when communicating alarm limits and to also provide reverse polarity for all Analog agents.

AutoCreate: To query the user as to whether a Datalog agent should be created when the Log button is clicked in the Configurator.

ConnectionProtocol: To specify the required mechanism that Adroit client software want to use when connecting to local and remote Agent Servers

CreateDumpFiles: To enable the creation of the Agent Server dump file (.DMP) when the agent database (.WGP) file is faulty.

DisableADOTableNamePrefix: To remove the "AdroitRawLog_" table name prefix when logging to an OLE DB database.

DisableEventOutputOnStandby: To prevent the EventOutput agent from outputting events when its clustered Agent Server is in standby mode.

DisableOnQualityChangeLogging: To disable DBLog agents from logging on quality change ONLY for the "Log on change" logging method.

DumpAgentDetailsEnabled: To prevent all DBLog agents from creating the Agent Details table.

EnableUnchangedValueWrites: To send an output to a PLC REGARDLESS of whether the scanned rawvalue slot of the Digital agent is changing or not. By default this only occurs when the rawvalue slot changes.

Extensions: To enable column header names to be added to fetch calls, which return a string array.

ExtractFloatResolution: To support decimal resolution for real logged values that are retrieved using the Extract utility.

ForceJet: To use the DbAccess agent with databases that require square brackets around the field names, otherwise their SQL transactions fail.

ForceSendIfDuplicate: To determine whether the same message can be resent or not from a Notify agent.

HousekeepingHour: To specify the hour of the day that the housekeeping of DBLog agents should occur.

IgnoreBadAlarms: To enable the alarming of agents that are currently in a bad status (ScanBad or Bad).

IPEnableHeartbeat: When using sockets as the communication mechanism between the Agent Server and its clients, this setting allows the Agent Server to monitor the status of these client connections and to close any unhealthy connections.

IsPostgress: To allow you to log to a postgress database.

LazyFlushing: To enable the log data to be immediately written to disk.

LMOperatorAction: To change the default Alarm route used for Operator Action Behaviours from route 1.

LogADODateTimes: To add an additional column containing readable timestamps to the database table, when datalogging to an ADO-compliant database.

LogCompressionFactor: To override the 20% data log capacity or the "divide by 5" storage factor applied to datalog files by default.

Managing Subscription Queue Length: To prevent the Subscription Manager queue length from overfilling.

MarshalAlarmMode: To specify the type of information reported in the description field for Marshal agent alarms.

MaxAgents: To specify the total number of expected agents on all the connected Agent Servers, which by default is set to 199000.

Note: ONLY when memory is a serious constraint, should you alter this default setting by adding and configuring this registry setting.

Memsize: To reduce the memory usage of the Alarm agent, when your very large alarming configuration spread over many Alarm agents is causing the virtual memory size of the Agent Server process to reach its upper 2 GB limit.

OutOfRangeEqualsAgentBad: To use the legacy method of marking your Analog agents are being bad when their rawvalue slot goes out of range

PropagateTrigger: To disable subscription updates for the value slot of a triggered Expression agent, if the value slot has not actually changed, to prevent unnecessary Agent Server CPU loads and network traffic when remote UI clients have been deployed.

RDAdminName: To allow Remote Desktop (RDP) clients to get a free node connection to obtain engineering access to the Agent Server.

RestartOnZeroChannels: To prevent the Agent Server from restarting when the number of free channels is zero.

ServiceCleanShutdown: To cause the Agent Server service to attempt a clean shutdown to ensure that the OPC client drivers disconnect from their OPC Servers so that these OPC Servers can clean up their resources and shutdown if necessary.

SmartInhibit: To define how the alarming subsystem treats current alarms if an agent’s statusalarmInhibit slot is set to one and the agent is currently in alarm and/or unacknowledged.

SubsWriteTimeout: To force the Agent Server to timeout once the network channel between it and a slow client has filled up.

SupportCompressionOnDemand: To enable the use of the Datalog compression algorithm when using Demand logging.

SuppressLogAtStartup: To suppress the log of the POST_STARTUP value after an Agent Server restart.
