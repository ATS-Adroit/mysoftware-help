Protocol Driver and Device Information Pane and Buttons

The right windowpane of the Drivers tab in the Adroit Setup utility, includes the following components from top to bottom:

  1. An information pane at the top, which displays troubleshooting information for the currently selected driver or device in the Installed Drivers and Devices list on the left of this dialog.

Note: When the Advanced view is enabled, this pane displays additional troubleshooting information for the selected protocol driver or device.

  • Information displayed when an installed () or partially installed () Protocol Driver is selected.
  • Information displayed when a configured (, , ) or un-configured () Device is selected.
  1. The following Device-specific function buttons:
  • Add () to add and configure a device (, , ) for the selected protocol driver ().  
  • Configure () to configure the selected device (, , ).
  • Remove () to delete the selected device (, , ). 
  • Diagnostics () to diagnose the selected device (, , ) or protocol driver ().
  1. The following Protocol Driver-specific function buttons:
  • Install () to install a new protocol driver (). 
  • Document () to display the documentation for the selected device (, , ) or protocol driver ().
