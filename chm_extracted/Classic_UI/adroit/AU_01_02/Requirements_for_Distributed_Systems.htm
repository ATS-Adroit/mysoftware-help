Requirements for Distributed Systems

If the installation is to form part of a distributed Adroit system with the ability to share data across the network within one project (i.e. it is not a simple standalone system) then it is essential that the following requirements are met:

  1. Check that all computers belong to the same Network Workgroup or Domain
  2. Using Adroit Configuration Setup, check that all Agent Servers are configured as part of the same project by ensuring the Agent Servers have the same Project Name.

Note: Project names must not be longer than 8 characters, nor contain any embedded spaces. When more than one project name is being used on the same network, ensure that the first 3 characters are unique.

  1. Click the Project Options button, and ensure that Enable remote servers to automatically detect this server is checked. The checkbox Explicit Additional Server Connections should remain unchecked initially.
  2. Ensure that each computer within the same project has a unique name for its local Agent Server.

Note: The name "Adroit" is given by default, and if more than one Agent Server with this name is started, the message "Cannot start duplicate AS" will be displayed. (This message is also displayed when more than one Agent Server is started on a computer.)

  1. If duplicate agent names exist in the Agent Servers, the one on the local Agent Server will be used. It is therefore advisable to ensure that agent names are unique over the whole project. For details, see Naming Agents.
  2. Check that each computer has a HASP software protection key fitted
  3. Check that each computer has every Adroit user set up identically by its local User Accounts applet , so that the same User Names and Passwords exist on all the computers in the project.
  4. Verify that the Number of Connections (go to the Options/Agent Information menu option) equals the number of computers on the project that have an Agent Server running.
  5. Check that all devices that are to be scanned have been installed using the Drivers dialog during the Configuration Setup procedure described earlier.
  6. Check that the physical memory is 25% more than the committed memory (see Total Commit Charge in the Performance tab of the Task Manager).
  7. Verify on each computer, using the Agent Server Configurator or Agent Browser that an AgentGroup tag exists for each Agent Server in the project.

For example, for a project name ‘Juice’ consisting of 3 Agent Servers called PLANT_A, PLANT_B and PLANT_X, you will see PLANT_A and PLANT_B as AgentGroup tags if you pull down the Group list box in PLANT_X’s Configurator.

For additional assistance, see Trouble-shooting.
