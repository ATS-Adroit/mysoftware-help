Administrative Tools - Configuring Event Logs

As Adroit utilises the Applications log of Windows, you need to configure this event log to set an appropriate size to contain and/or overwrite old events.

To configure the Windows event logs

  1. From the Start menu, click on the Control Panel link and double-click on the Administrative Tools applet.
  2. Double click on the Event Viewer icon.
  3. In the left pane, expand the Windows Logs item and do the following for each of the event logs i.e. Application, Security and System:
  4. Right-click on the event log and select Properties and in the General tab:
  1. Set the Maximum Log size to suit your requirements. A typical Adroit event record uses 500 bytes of disk space, therefore if the maximum log size is set at 512 Kilobytes, then it is possible to accumulate 1024 event records.

Note: It should NOT be necessary to perform the following configuration, as this is automatically configured by Adroit.

  1. Set the When maximum log size is reached option to Overwrite events as needed (oldest first)

To look at an event in greater detail, click on the required event log in the left pane and double click on the required entry in the middle pane.

Adroit provides an alternative Adroit Event Viewer, which:

  • allows these events to be filtered
  • allows you to export the filtered events to a .TXT file.
  • allows you to save windows with different filter view settings to .EFF files
  • allows you to archive the basic event log to .EVT files
