Agent Server Parameters

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab and click on the Advanced… button.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Advanced Agent Server Configuration in the right hand pane.

This displays a page of grouped advanced Agent Server settings.

The Agent Server Parameters group contains the following settings:

Note: By default the Agent Server reserves storage space for up to 199000 agents on all the connected Agent Servers and ONLY when memory is a serious constraint, should you alter this new default setting by adding and configuring the MaxAgents setting.

  1. Channels: this is the maximum number of possible Client-Server connections from the Agent Server to the outside world, such as to the User Interface, other Agent Servers, DDE links. The default setting is 20.
  1. Remote Timeout: this is the time the system waits before reporting a lost connection between any two Agent Servers, or an Agent Server and the user interface.
  2. Agent Path: this is typically the installation folder in which the Adroit executables and dynamic link libraries are stored.

  3. Save WGP file on exit: check to ensure changes are saved at Agent Server shutdown.

Tip: The Agent Server can also be saved using the saveNow and saveAsName slots of the SystemInformation agent.

Note1: Saving can take a long time for large installations. For quick shutdowns, leave unchecked and manually save at planned intervals.

Note2: This setting does not work if the Agent Server is installed as a service.
