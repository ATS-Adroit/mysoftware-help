Adroit Drivers Popup Menu

Press the Windows key and start typing in Classic Setup and select it from the list.

Click on the Drivers tab and then either click the browse button () in the upper right corner this Installed Drivers and Devices list or right click in this list to display this menu of available options:

Note: This menu is context-sensitive, so that certain menu items will not always be visible.

Add Device to add and configure a device (, , ) for the selected protocol driver ().

Configure Device to configure the selected device (, , ).

Remove Device to delete the selected device (, , ).

Diagnostics to diagnose the selected device (, , ) or protocol driver ().

Add New Driver... to install a new protocol driver ().

Documentation to display the documentation for the selected device (, , ) or protocol driver ().

Copy Device `XXXXXXXX', where XXXXXXXX is the name of the selected device (, , ) to be copied.

 

Advanced View to enable the advanced configuration and troubleshooting of protocol driver and device-related problems.

Refresh drivers(s) tree Advanced view only - to rebuild the list of installed drivers and devices.

Registry settings Advanced view only - to perform advanced scanning configuration via a dialog.

Scan for used devices / Re-scan for used devices to check the current WGP file to indicate devices that contain scanned points

Note: This function may take some time on larger databases.

Monitor Local Agent Server to enable this dialog to indicate the status of each device in the Agent Server.
