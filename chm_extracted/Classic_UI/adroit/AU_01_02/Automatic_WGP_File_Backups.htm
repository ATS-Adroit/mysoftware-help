Automatic WGP File Backups

Adroit WGP files can be automatically backed up when they are saved to ensure that at most only the changes made since the last save will be lost.

Both the number of days for which these files are to be saved for and the maximum number of backup files can be specified to avoid backup duplication and conserve disk space.

WARNING! This feature is merely intended to AUGMENT the existing backup system and NOT to REPLACE it i.e. it is still imperative that an efficient backup system is in place! For details, see Creating Backup Procedures.

Note1: These backup files will be created in the folder in which the WGP file resides, EACH time it is saved, regardless as to whether its contents have been changed or not.

Note2: Restoring these saved WGP files is still a manual process, which requires: stopping the Agent Server, renaming the WGP file that is currently being used; locating and renaming the required backup file to this name and restarting the Agent Server.

 

The names of these automatically created backup copies, adhere to the following format:

name.yyyymmdd_hhmmss_v_n.wgp

Where:

  1. name: is the normal name of the WGP file
  2. yymmdd: is the date of the save e.g. 20041101
  3. hhmmss: is the time of the save e.g. 163715
  4. v:  is an incremental version number

Note: This version number will increment when this WGP file is saved, even if nothing has been changed in the WGP file.

  1. n  is the number of agents stored in the WGP file

Note: This is still stored in the first line of the WGP file, as before.

 

Note: In addition to automatic backup, Adroit WGP files also contain version information. For details, see Versioning WGP Files.
