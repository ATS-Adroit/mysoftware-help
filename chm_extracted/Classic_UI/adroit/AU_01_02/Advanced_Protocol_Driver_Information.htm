Advanced Protocol Driver Information

The following advanced or troubleshooting attributes are only displayed for an installed () or partially installed () Protocol Driver when the Advanced view has been enabled. These attributes are solely intended to assist the support and troubleshooting of protocol driver problems:

  • size: The size of the file, designated by Filename, in bytes.
  • Adroit Version: The version of Adroit that the driver was created for.
  • Note: This must NEVER be less than the current Adroit version.
  • Creation: The date at which the file, designated by Filename, was created.
  • Status: This information is intended for future use only, typical values are Simulation and Real, if this field is blank then the driver may come from a 3rd party.
  • Features: A list of features specific to the operation of this driver i.e. whether it only supports polling or is telemetry or supports tag browsing etc.

Note: If this list of reported features ends with a …, it is necessary to expand the width of the Value column.
