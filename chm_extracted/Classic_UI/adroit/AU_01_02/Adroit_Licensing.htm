Adroit Licensing

The only component in Adroit that needs to be licensed is the Agent Server. For details on licensing the Agent Server, see Licensing the Agent Server.

Typically, the Agent Server is licensed via a HASP software protection key, which is inserted into either the parallel or USB port of the computer on which the Agent Server is running. This HASP is then programmed in accordance with your specific license agreement.

In situations where it is not possible to use a physical HASP, it is also possible to license Adroit via a software license, which is only available on request. For further details, contact the Adroit support department. For further details on how to get, view and/or update your product license, see "Working with the Adtech Licensing Utility" on page 1.

Note: It is also possible to evaluate Adroit freely, by using the limited time license HASP, which runs the Agent Server with a 58 minute operating license with 30000 scan points and 2 remote connections. For details, see Limited Time License HASP.

The Agent Server licence typically specifies the following components:

  1. The unique serial number that identifies this Adroit Agent Server.
  2. The version of the Adroit product that this licence applies to.
  1. The available number of scanned point licences these are also known as "scan points".

These are consumed when information is being manipulated in some way, typically when communicating (scanning) a value to a front-end device.

However, there are a number of other consumers of scan point licenses. For details, see Scan Point Licensing Exceptions.

Note: A Proxy Server (an Agent Server that is licensed for ZERO scan points) can proxy an unlimited number of agents, whereas a normal Agent Server is only able to create as many proxy agents as it has scan points and therefore must be licensed for AT LEAST the same number of scan points as the remote Agent Server.

IMPORTANT: The former Remote Nodes licenses that applied to all types of clients have been DISCONTINUED. These have now been replaced by the following client specific node licenses, each of which have different costs:

  • Clients: typically Operators and/or Designers and

  • Web Clients: typically Performance Anywhere clients.

Note: Agent Server to Agent Server connections do not require remote connection licenses.

  1. Whether any OEM licenses or component counts have been specified. These are programmatic components that require separate licensing before they can be used.
  2. Whether the Agent Server in being run in HMI mode or not. The HMI mode reduces the functionality of the Agent Server to provide a cost-effective, bulk implementation of HMI software.

  3. If necessary, the expiration date of the HASP, which can be used to safeguard the software.

    When a running Agent Server reaches the expiration date of the license (HASP), then the scanning is stopped but the clients are not disconnected. But when this Agent Server is restarted, both scanning and client connections will be prevented.

Note: Once the expiration date of the HASP has been exceeded, the HASP will no longer be detected until it has been re-licensed.

When the Agent Server starts up, this license information is displayed in its application window, as follows:

HASP SN : Serial Number, [PARTNER SN: Serial Number of clustered Agent Server,] ID: ID Number, Ver: Adroit version i.e. 1000 is Adroit version 10.0, Scan: Scan Points, Drivers=1 (if licensed for drivers), Designer:#, Operator:#, Web:# (number of licensed remote client connections), HMI: Status of HMI mode, Expiry: Expiry date of the HASP.

 

Licensing when using Terminal clients (Remote Desktop):

EACH Adroit client application launched using new terminal client (Remote Desktop) takes a (remote node) connection licence.

When Adroit clients are launched via a remote desktop using the session of the console user (either session 0 or 1 depending on the operating system), then these Agent Server connections are treated as legacy local connections which do NOT require connection licences. See Issues related to using Remote Desktop to Run Adroit.
