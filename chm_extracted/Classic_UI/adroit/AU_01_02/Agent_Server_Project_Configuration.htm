Agent Server Configuration

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

Click the Agent Server tab.

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Agent Server Configuration again in the right hand pane.

This displays the following fundamental Agent Server settings.

  1. Select Configuration: Allows the selection between pre-saved Agent Server project configurations.

    Note: The setup configuration name can be used as a parameter in the target command line (i.e. C:\Program Files\Adroit Technologies\Adroit\AS.EXE <setup_config_name>) when creating more than one Agent Server desktop shortcut item.

  • The Save As button: Enables the saving of the current Agent Server settings. This involves selecting the name for the configuration, by default this is set to the current Project Name. This will then become the selection in Select Configuration.
  • The Remove button, will delete the currently selected configuration.
  1. Agent Server Type, select the type of your Agent Server, as follows:

Note: In HMI mode, when the Agent Server is run, it is forced to run in stand-alone mode, regardless of its current setting.

  • Stand-alone / Distributed server : Proxy agents are NOT created if remote duplicate tags are found.

In other words, when an Adroit client is connected to an Agent Server that is configured as a “stand-alone server”, it cannot display or refer to agents that have the same name as other agents on other Agent Servers.

  • Cluster aware server : Proxy agents are created if remote duplicate tags are found.

In other words, if you need to display or refer to agents that have the same name as other agents on other Agent Servers, then change the Agent Server to be a “cluster aware server”, which allows this Agent Server to be aware that there are duplicate agents on the network, so that this Agent Server will display and use the agent that exists on the server with lowest alphabetical name i.e. AS1 before AS2.

  • Cluster Server : This Agent Server is part of a cluster (a redundant Agent Server pair, where each Agent Server is either a master or standby, both of which maintain duplicate agent databases). In this case the Options... button is enabled to display the Cluster Server Configuration Options.

For more details on addressing the important issues that affect the operation and configuration of clustered Adroit Agent Servers, see Important Points to consider when Clustering Agent Servers.

  1. Server Project Name : This is the default method for connecting distributed Agent Servers so that they can share their data. For further details about this method, its limitations and configuration and of the other mechanisms provided to overcome these limitations, see Agent Server Connection Methods.
  1. Agent Server Name : The name of this Agent Server, which must:
  2. be unique across the same network,
  3. not have spaces,
  4. not be longer than 20 characters and
  5. have the first 7 UNIQUE characters, when more than one Agent Server is being used within a project.

Note: The name 'Adroit' is provided by default for the Agent Server Name and we recommend that you change this to avoid duplicate Agent Server names in a distributed installation.

  1. WGP File : the path and name of the Adroit database (.WGP) file that is automatically loaded when the Agent Server is started.  

By default, this specifies an empty file called WG.WGP in the Data subfolder of your designated project folder, which is typically C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\Data. This is the recommended location for this file. Either type in another filename directly or use the browse button to search for the required file. 

Note: When this .WGP file is empty or nonexistent the POSTLOAD.WGP performs its default configuration. For details, see Postload Adroit Database File.

  1. Agent Server Service: this section allows you to install the Agent Server service or change the configuration of a pre-installed Agent Server service, as follows:

  2. Specify the Username and Password of the mandatory user that the Agent Server service will use to log onto this computer with.

    Ensure that this user account has the rights / permissions to access the network resources (printers, SQL Express, network shares) that the Agent Server requires access to.

    Use the following syntax when specifying the user name:

    For users on the local computer: UserName

    For users on a domain: domainName\UserName.

    IMPORTANT: Ensure that the specified password does not expire, otherwise you will need to reconfigure this each time the password changes.

    Note: The username and password of the specified user account are verified and the username cannot be "Adminstrator" (because this COULD be the built-in Windows Administrator account).

  3. Check or uncheck the Auto Start checkbox to specify whether this service (and the SmartUI Server) service should automatically start. If this is unchecked then you need to manually start these services via the Service Manager when you need them.
  4. Click the button to perform the indicated action which is either Install Service or Change Service (when the Agent Server service has already been installed).

The following items are only provided by the Adroit Configuration Setup:

  1. Time Granularity : the time period in seconds that the systemInformation agent updates itself.
  2. HMI Mode : when this checkbox is checked, the specified WGP (Auto-Load) File runs in HMI Mode, which is then subject to a number of restrictions. For details of these restrictions, see Working with HMI Mode.

Note: HMI Mode is typically configured on installation or in the Configuration dialog of the Adroit Config Editor utility.
