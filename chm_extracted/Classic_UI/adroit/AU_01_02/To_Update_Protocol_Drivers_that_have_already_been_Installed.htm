To Update Protocol Drivers that have already been Installed

Follow the following procedure, to determine if any of the Adroit protocol drivers that have been installed are older than the drivers on the Adroit DVD (or your current Adroit driver source folder) and to re-install the newer files.

PLEASE NOTE: Before re-installing Adroit protocol drivers, STOP the Agent Server application or service FIRST.

Press the Windows key and start typing in Classic Setup and select it from the list.

  1. Click on the Drivers tab and then click the Install () button, to display the Adroit protocol driver installation dialog.
  2. If you need to specify another location from which to install Adroit protocol drivers, click the (…) browse button next to the Path edit box, to locate this disk or folder.
  3. Click the Upgrades… button.

This will search your Adroit system folder, typically C:\Program Files\Adroit Technologies\Adroit for any installed protocol drivers and compare the versions of these located files with the versions of the driver files located in the specified Path.

  1. Any installed drivers, whose driver revisions are lower than the drivers in the specified Path are then displayed in the Available Protocol Drivers list.
  2. Select the driver you wish to add from the Available protocol drivers list, using the scroll bar and clicking on the required entry.
  3. Use the Details button to view the component files of the selected driver and the path into which each of the files are to be installed on your system.
  4. Click the Copy button to copy the driver to your Adroit system folder.
  5. Click the Close button to exit the dialog, once all the necessary protocol drivers have been installed.

Note: When Adroit is uninstalled the installed Adroit drivers are not uninstalled.
