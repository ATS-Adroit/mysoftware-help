Recommended System and/or Adroit Configuration Guide

The following is the recommended order in which to set up the system.

Note: When asked to reboot after installing anything or changing a setting, do so by selecting the "Reboot later" option, and then shutdown-&-restart the system manually.

  1. Install your Operating System, which should be NT-based from Windows XP onwards, verify that it has been installed correctly. Contact your network administrator if this is not the case.
  2. Install the network card and the required network protocol and verify that the computer is connected to the network. Contact your network administrator if this is not the case.
  3. Install all hardware drivers, including the required printer drivers and verify that the hardware devices are working and that it is possible to print to all the required printers (both those that are physically connected to the computer and those that are available over the network). Contact your network administrator if this is not the case.
  4. Configure the graphics card with at least a resolution of 800 x 600 with 65535 colors.
  5. Open the System applet in the Control Panel, optimise performance for background applications for the Agent Server computer and configure the virtual memory paging file, keep the Initial and the maximum size the same to avoid page file fragmentation. Recommended size is 300 MB or at least twice the physical RAM. Also set system recovery options to reboot automatically on a fault.
  6. Re-start the operating system at least once before installing Adroit.
  7. Ensure that the computer complies with the specified hardware and software requirements, before installing Adroit.

Best Practices.

Post-Adroit Installation Configuration

  1. Verify that the Adroit installation directory has been added to the path, by typing ‘path’ in the CMD window.

Note: If the installation is to form part of a distributed Adroit system with the ability to share data across the network within one project (i.e. it is not a simple standalone system) then it is essential that a number of additional requirements are met. For details, see Requirements for Distributed Systems.

  1. Run the Adroit setup (psexe.exe), make the necessary Agent Server and project settings and add the necessary drivers and their devices.
  2. Install the other required programs–if Microsoft Office is installed then disable the office FindFast re-indexing service as this tends to adversely affect the computer’s responsiveness.
  3. Reboot before re/installing your service pack now, for Windows 2000 this is SP2. The SP is always the last software to be installed.
  4. Configure security in Adroit, which makes use of Windows security and presupposes a group-based security model. For details, see Adroit Security Configuration.
  5. Configure the Event viewer, and set the Application event log to wrap, set the size for 1024k or more.
  6. Now run an empty Adroit Agent Server from the icon, verify that the HASP is present by opening the Agent Server Agent Server window and looking for the line that begins with "HASP SN:…". To further determine that status of the HASP, open a UI window and then edit the LICENSE Hasp agent in the Configurator, if the HASP is correctly configured then the I/O Status should be: "Read memo OK".
  7. Adroit provides the facility to allow operators to specify numerical and textual (alpha-numeric) values by means of the Adroit virtual keyboard. This is typically required when you are using touch screen user interfaces that do not provide keyboards. See Adroit Virtual Keyboard.
  8. If this computer is a cluster or a backup, copy all the datalog files across and any other duplicated files, such as mimics and scripts, before you start up to speed up things. Run the intended Adroit database normally.
  9. Verify that the front-end devices (PLCs) communications are established and that all the tags on the mimics are visible (that none of the tags are greyed out) and that the mimics work correctly and can be navigated between correctly. Ensure that the datalogs and hence the trends are working correctly.
  10. Set up the Agent Server service if required, once you have verified that the project and the Agent Sever are working as required.
  11. Ensure that the Data Execution Prevention (DEP) is correctly configured, since this can cause the Agent Server to be unable to read the HASP, at start up causing the Agent Server to hang or fail and/or to display HASP exceptions in the Agent Server window. For further details, see Data Execution Prevention (DEP) Configuration.
  12. Do a full Re-boot to test the system.
  13. If your current Agent Server process is approaching the 1.6GB virtual memory limit, as measured by Performance Monitor (NOT Task Manager!), then increase the amount of virtual memory available to this process. For further details, see Increasing the virtual memory available to the Agent Server.
