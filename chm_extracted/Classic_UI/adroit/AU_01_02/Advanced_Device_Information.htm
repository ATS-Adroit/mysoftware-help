Advanced Device Information

The following advanced or troubleshooting attributes are only displayed for a configured (, , ) or un-configured () Device when the Advanced view has been enabled. These attributes are solely intended to assist the support and troubleshooting of communication (device-related) problems:

  1. The performance counters, for the protocol driver of this configured device are displayed. These are identical to those displayed in the Diagnostic Counters Screen of the Protocol Driver Monitor, with the exception of:
  1. Trans/sec: This represents the number of successful transactions performed per second over a 5 second interval.
  2. If an un-configured device (), has been selected then the following four attributes will also be displayed below the others:
  1. WGP : name: This displays the name of this device as specified in the current Adroit database (.WGP) file.
  2. WGP : @-scans: This displays the number of tags that are ‘at’ or @ scanned to other tags, using this device as specified in the current Adroit database (.WGP) file.
  3. WGP : I/O: This displays the number of tags that are scanned to I/O addresses, using this device as specified in the current Adroit database (.WGP) file.
  4. WGP : 1st I/O: This displays the address of the first IO point scanned to this device as specified in the current Adroit database (.WGP) file.
