Installing a Protocol Driver

Using the Adroit Configuration Setup:

Press the Windows key and start typing in Classic Setup and select it from the list.

  1. Click on the Drivers tab.
  2. Click the Install () button, which is always enabled.

This will display the Adroit Driver Install dialog to allow new protocol drivers to be installed, by creating a list of available Adroit drivers from the installation path or the previously specified path.

If the Adroit driver setup files cannot be found in the installation or previously specified path, another Adroit driver install dialog is displayed, with the following three buttons:

  1. Retry: This will attempt to reopen the installation or previously specified path for installing drivers.
  2. Cancel: This will abort the driver installation process.
  3. Browse…: This will display a dialog, to manually locate the disk or folder containing the Adroit protocol drivers.

 

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

  1. Click Agent Server Configuration in the right hand pane.
  2. Click Driver Configuration in the right hand pane.
  3. Click the Install new driver button.

This displays the DriverInstallList dialog to allow new protocol drivers to be installed, by creating a list of available Adroit drivers from the installation path or the previously specified path.

If the Adroit driver setup files cannot be found in the installation or previously specified path, then click the browse button to manually locate the disk or folder containing the protocol drivers.

  1. Click the name of the driver () to install.

This copies the associated driver files into the Adroit system folder and opens the associated driver documentation.

PLEASE NOTE: Read this driver documentation carefully, as it specifies which devices are supported, how to configure the driver, how to scan using the driver, diagnostic tips and any relevant protocol information.
