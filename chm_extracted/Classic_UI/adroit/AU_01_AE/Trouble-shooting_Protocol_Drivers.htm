Please take note of the following before phoning for support for any driver communication problems:

  1. Launch the Driver Monitor Launcher, by selecting the Start menu, Programs, Adroit 10 and then the Driver Monitor Launcher item.
  2. Select the driver that is causing the communication problems from the Driver list box.
  3. Write down both the description and revision of this installed driver, which are displayed below this list box.
  4. In the Device name list box, double-click on the name of the device that is causing the communication problem, to open its Driver Monitor.
  5. Select this Driver Monitor and press the "3" key to display the "Error Log" screen and try to determine the nature of the problem from the live detailed reports for all problems in a driver, that are displayed in this screen.
  6. If the nature of the problem cannot be detected, then press the "ESC" key, to return to the main menu and press the "1" key to display the "Datascope" screen.
  1. If you are familiar with communication protocols, use the "Datascope" screen to try and analyse the problem.

Note: By default this screen opens in ASCII mode, which is indicated in the title bar of the window, to toggle the mode to HEX and vice verse (depending on protocol), type in "A".

  1. If you are unfamiliar with communication protocols, create a log-file of the messages in the "Datascope" screen, which you can FAX/e-mail it to the Support desk. Create this log file by pressing the "L" key, waiting for the screen to fill with messages and pressing the "L" key. This will create a Devicename.txt file in your Adroit system folder e.g. C:\Program Files\Adroit Technologies\Adroit, where Devicename is the name of the device selected in step 4.

Note: Having an Internet e-mail address available ensures that the Support desk can forward patches to your computer and/or that you can send your database (the .WGP file) and other relevant information to the Support desk, when using the Support program, by selecting the Start menu, Programs, Adroit 10, Utilities and then the Support Program item (if this has been installed).

 

Before phoning for support if Adroit is not scanning:

  1. Is a HASP attached to your Agent Server computer?
  1. If yes, ensure that the correct licence information appears in the Agent Server window? If not then check that both the port (use the port testing utility supplied in the utilities folder on the Adroit installationDVD in the ‘Utilities\comm port tester’ folder) also ensure that the HASP is not faulty.
  2. If no, open the Agent Server window and ensure that the following message was not reported over three minutes ago: "Server shutting down scanning in 180 seconds", if so then the hour of free scanning has elapsed and the Agent Server must be restarted in demo mode for scanning to continue.
  1. Open the Adroit Setup utility, by selecting the Start menu, Programs, Adroit 10 and then the Setup item. Select the Agent Server tab, is the Agent Server Type set to "Cluster server". If yes, take note of your Project Name and Agent Server Name fields and then open the Adroit Classic UI, open the Options menu, click Preferences and open the Connection tab and determine if your Agent Server is in Standby mode. If yes, ensure that Parallel scanning has been configured for the cluster, to do this open the Adroit Classic Setup utility (psexe.exe) and click the Options. . . button next to the Agent Server Type in the Agent Server tab.
  2. Is the required device started? If not, start it.
  3. Verify that you are physically connected to the device you are trying to communicate to.
  4. Open the Adroit Setup utility, as in step 2, and select the Drivers tab, select the required device in the Installed devices list box, click on the Configure button and verify that all the driver setup configuration parameters (comm. port etc.) make sense to you, and that any two drivers do not use the same resource/port.
  5. Verify that your hardware is working, check that the cables are not damaged, and test continuity if applicable.
  6. Launch the Driver Monitor Launcher, by selecting the Start menu, Programs, Adroit 10 and then the Driver Monitor Launcher item. Select the driver that is causing the communication problems from the Driver list box and write down both the description and revision of this installed driver, which are displayed below this list box.
