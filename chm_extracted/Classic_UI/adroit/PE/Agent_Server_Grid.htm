Agent Server Grid

The Agent Server grid, consists of the following fields, each of which displays relevant runtime information about the current Agent Server session, as follows:

Note: The grid provides the following standard configuration options.

  1. The first untitled field numbers the information items in the grid.
  2. Item: This field specifies the configuration item, which is being displayed.
  3. Value: This field specifies the current configuration of the specified item, which cannot be edited.

The following list describes what the listed Items of the selected Agent Server object refer to:

  1. Server mode: This indicates the current mode of this Agent Server i.e. Master or Standby, if it is part of a cluster or Normal if it is a standalone Agent Server.
  2. Previously stopped at: This indicates the time at which the previous Agent Server session was stopped.
  3. Started at: This indicates the time at which the current Agent Server session was started.
  4. Running time (hours): This indicates the current duration of the current Agent Server session in hours.
  5. Licenced scanpoints: This indicates the number of points that are currently scanned out of the total licensed number of scanned points that are allowed by current Agent Server session.
  6. Licenced Clients: This indicates the number of Client licenses that are currently being made to this Agent Server out of the total licensed number of Client licenses that are allowed to the current Agent Server session.
  7. Licenced Web Clients: This indicates the number of Web Client licenses that are currently being made to this Agent Server out of the total licensed number of Web Client licenses that are allowed to the current Agent Server session.
  8. Licenced for Adroit drivers: This indicates whether the current Agent Server session is licensed to use Adroit drivers, a 1 indicates that this license is in effect.
  9. Licenced for HMI mode only: This indicates whether the current Agent Server session is licensed to only operate in HMI mode, a 1 indicates that this license is in effect.
  10. Licence expiry: This indicates the expiry date of the HASP being used by the current Agent Server session
  11. Total putslots: This indicates the total number of putslots made within the current Agent Server session.
  12. Total subscriptions: This indicates the total number of subscriptions made within the current Agent Server session. Agent Server clients can subscribe to particular values within the agents, and they are only notified when these values change.
  13. Total active agents: This indicates the total number of configured agents in the current Agent Server session.
  14. Total system agents: This indicates the number of agents that have been created by Adroit in the current Agent Server session.
  15. Total user agents: This indicates the number of agents that have been created by the user in the current Agent Server session.
  16. A list of the currently filtered agent types, in alphabetic order, indicating the number of configured agents for each agent type.
