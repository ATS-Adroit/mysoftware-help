To Send a Message to a Remote Computer

This will send a text message to the Project Explorer window, running on the selected remote computer in the tree view windowpane. 

Note: This command is only applicable for computers that have an operational Project Explorer window i.e. that are represented by the following computer icon: .

  1. Select the Computer object to which the message is required to be sent.
  2. Right-click or press F4 and click on the Send message to PC menu item.

Tip: Alternatively press F7, the shortcut key for this command.

In the Send message dialog, type in the required message in the edit box.

Note: A blank message will not be sent.

When a message is received:

A dialog box entitled: Message from ComputerName appears on the screen of this computer, where ComputerName is the network name of the sending computer, as it appears in the Project Explorer tree view windowpane.

In addition to displaying the message, it is also possible for this computer to type in a reply to the sending computer in this Message from ComputerName dialog, in which case a similar dialog will appear on the screen on the computer from which the message was originally sent.
