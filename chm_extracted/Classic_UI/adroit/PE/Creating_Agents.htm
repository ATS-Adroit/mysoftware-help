Creating Agents

This command allows you to create agents in bulk or singly, as follows:

Note: This command does not apply to system agent types (those agents created by Adroit).

If necessary launch the Project Explorer. For details, see Launching options from within Adroit.

When the tree view windowpane of the Project Explorer is selected:

  1. Click the required agent type/group, beneath the expanded Agent Server object.
  2. Right-click and select the Create agent/s menu item.

Tip: Alternatively press INS, the shortcut key for this command.

The Create AgentTypeName Agent dialog is displayed, where AgentTypeName is the name of the selected agent type.

A few options exist at this point:

  1. To create a single agent type in the name as required
  2. To create agents FT123 to FT150 – type in FT%d,123,150
  3. To create agents FT1 to FT19 –type in FT%d,1,19
  4. To create agents FT001 to FT019 – type in FT%03d,1,19
  5. To create agents TANK01LEVEL to TANK16LEVEL – type TANK%02dLEVEL,1,16

Type in the required name for this agent and press Enter or OK to close this dialog and add the agent.

Note: The name that is typed into this dialog is remembered, making this easier to add more than one agent of the same name with differing numbers.
