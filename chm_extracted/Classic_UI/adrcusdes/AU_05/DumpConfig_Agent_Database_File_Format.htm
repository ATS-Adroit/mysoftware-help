DumpConfig Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

ENA=n

BOOLEAN Enabled status (0 disabled, 1 enabled), when set to TRUE (1) this enables the agent to start dumping agent configurations to the specified database.

SCH=n

If set to a number greater than 0, then this number specifies the hourly interval that will be used to trigger this agent to dump the specified agent configurations to the database but if set to 0 this disables this method of triggering this agent.

TTAG

Tag name (agent.slot) used to trigger this agent to dump the specified agent configurations when this value changes.

DMPN=n

BOOLEAN status of the DumpNow setting, when set to TRUE (1) this forces the agent to dump all the currently configured agent configurations to the specified database.

CONN

The OLE DB connection string for the database. 

LSTn

The Agent type configuration list, which specifies the agent types and/or their slots and/or the agent instances to dump to the database.
