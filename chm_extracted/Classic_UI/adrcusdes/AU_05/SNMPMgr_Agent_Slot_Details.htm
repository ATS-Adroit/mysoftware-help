SNMPMgr Agent - Slot Details

The SNMPMgr Agent can both monitor and manage devices on a network, by using SNMPSimple Network Management Protocol (SNMP) is used to monitor and manage a diverse range of devices on a computer network..

Each SNMPMgr agent is able to retrieve and/or write to any number of SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. from a single device. This is also able to receive SNMP trapsunsolicited SNMP messages sent by a device to notify an SNMP manager of significant events. from this device.

This OID list is saved to WGP file.

This agent is located in the following file: T_SNMPMgr.DLL

Slots:

Slot Name Type Function

authPassword

STRING

SNMP version 3 ONLY: the required password for authentication on this device.

catchupData

RAWBYTES

Internal use only (used with datalog catchup).

datascope

BOOLEAN

Launches the Adroit Protocol Driver Monitor application so that you can open the Datascope window to view the activity of this agent - like clicking the Datascope button in the edit agent dialog.

encrPassword

STRING

SNMP version 3 ONLY: the required encryption password for this device.

errorMsg

STRING

This slot displays the reason why the Error status bit of this agent is currently set. For details, see the description for status bit 21 of this agent below.

filename

STRING

The name of the global SNMP configuration file, which is called 'snmp.wgx' by default.

This file contains the common OID configuration of all your SNMPMgr agents and allows them to store an unlimited number of OIDs. Ensure that this file is backed up.

Note: This file name can also be specified using the Advanced button in the edit dialog. 

idx

INTEGER

To select a record (row) from the list of selected OIDs (records slot). This can be used to display and/or configure one or more fields of this record.

Set this slot to the index of the required record in the list, to populate the following slots with the fields of this selected record: idxEnabled, idxWriteable, idxOID, idxName, idxType, idxValue and idxLastPollTime slot.

idxEnabled

BOOLEAN

Indicates whether the value, specified by the idx slot, is enabled to be polled (retrieved from the device) or not. This can be configured as required.

idxLastPollTime

TIME

Indicates the last time the value, specified by the idx slot, was automatically polled.

idxName

VARSTRING

The textual description of the OID, specified by the idx slot. This can be configured as required, for instance after manually changing the OID, see the idxOID slot description.

idxOID

VARSTRING

The OID, in numeric format, of the SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. specified by the idx slot. This can be changed to another OID. If so this automatically changes the Name (idxName slot) of the selected record to “Unknown”.

idxRate

INTEGER

The rate, in milliseconds, that the OID value, specified by the idx slot, is polled (retrieved from the device). If this is 0 then the default poll rate (pollrate slot) is used instead. This can be configured as required.

idxTag

STRING

The name of the agent used to store this OID value, if one has been specified.

idxTimestamp

TIME

The time stamp of the current OID value.

idxType

INTEGER

An Integer indicator of the return type of the value, specified by the idx slot. For details, see OID Return Type Indicators.

idxValue

VARSTRING

The current value of the OID, specified by the objectListIndex slot.

idxWriteable

BOOLEAN

Indicates whether the OID value, specified by the idx slot, is enabled to be written to the device or not. This can be configured as required.

ipAddress

STRING

The IP Address of the SNMP managed device to be monitored.

Note: It is NOT possible to specify an IP address that has ALREADY been configured for another SNMPMgr agent!

ipPort

INTEGER

The IP port of the SNMP managed device to be monitored - used when monitoring a device through a gateway.

lastWriteStatus

 

STRING

Displays a text message that informs the user whether the last value written to the device was successfully changed in the device or not.

pollAllNow

BOOLEAN

If set to 1, this will cause all OIDs in the list to be manually polled now (ASAP), see Manually Polling OID Values.

pollIdx

INTEGER

To manually poll any OID (receive its value from the device) that you added to the list (records slot), set this slot to the index of this OID in the list.

readCommunity

STRING

The SNMP Community String required that ONLY provides READ access to the SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. of the network device. For further details, see SNMP Community Strings.

records

VARSTRING

The list of the selected OIDs (SNMP objects).

Each list entry is enclosed in #’s and adheres to the following format: *Index*Enable*Writable*Object Identifier*SNMP name*Return type*Current Value*Adroit tag*PollRate

retries

INTEGER

The number of times this agent will attempt to connect to the device, before deeming this device to be unavailable.

scanRate

INTEGER

The default or global rate, in milliseconds, at which the polling-enabled OIDs are retrieved from the device.

start

BOOLEAN

Determines whether the device is to be managed (1) or not (0).

When enabled (1) the selected OID values will be polled and/or written to and SNMP traps will be received, if the trapEnabled slot is enabled (1).

Note: A scan point is consumed for every unique OID value that is polled, written to and/or trapped.

timeout

INTEGER

The maximum time (in milliseconds) for this agent to establish a connection to the specified SNMP managed device.

trapCount

INTEGER

The number of SNMP traps (and their sub-traps) received from the managed device in the main trap queue (for simple traps this is 1, for complex traps this is the number of OIDs [sub-traps] in this trap).

trapEnabled

BOOLEAN

This enables the receipt of SNMP traps from the managed device. (This only occurs once the start slot is set to 1 and consumes a scan pointa scan point licence that is consumed from your Adroit license when information is being manipulated. for each unique OID that is trapped.)

trapGeneric

INTEGER

An Integer value of the generic code or identification of this trap OID.

trapOID

VARSTRING

The OID, in numeric format, which identifies the SNMP managed object for this event.

trapPop

BOOLEAN

Set this slot to 1 (via a script or button etc.) to read the first trap off the main trap queue, which reduces the trapCount slot by the number of OIDs in this trap (for simple traps this is 1, for complex traps this is more than 1). This populates the trapTime, trapType, trapValue, trapGeneric, trapSpecific and trapOID slots with the information pertaining to trap that is first in the queue.

This reduces the trapCount slot by 1.

WARNING! Once a trap has been read off a queue it is discarded and cannot be accessed again.

Note: The queue of traps is processed from the oldest to the newest trap.

For more details concerning the handling of traps and the related queues, see About SNMP Traps.

trapSpecific

INTEGER

An Integer value of the specific code or identification of this trap OID.

trapTime

TIME

The time that the value, specified by the trapValue slot, occurred.

trapType

INTEGER

An Integer indicator of the return type of the value, specified by the trapValue slot. For details, see OID Return Type Indicators.

trapValue

VARSTRING

The value of the OID specified by the trapOID slot.

trapValueIsBinary

BOOLEAN

This is enabled set to 1 when the trap value reports as ascii and will need conversion to hex/binary.

trapWorkCount

INTEGER

For the current complex trap that is popped off the main trap queue, this contains all the OIDs [sub-traps] in this trap, except for the first OID that is transferred to the trap... slots.

This work queue is provided to prevent the possible corruption of the main queue by popping off the incorrect number of sub-traps.

userName

STRING

SNMP version 3 ONLY: the required user name for this device.

version

INTEGER

An Integer value of the SNMP version that is supported by the network device.

writeCommunity

STRING

The SNMP Community String that provides read AND WRITE access to the SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. of the network device. For further details, see SNMP Community Strings.

This must be specified in order to change the values of OIDs in the device.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

InvalidConnection

On if the agent is UNABLE to access the specified device and its SNMP objects. To troubleshoot this, see Connecting to the Managed Device.

Note1: This will ALWAYS be On if the agent is loaded in the Stopped state and is only validated when the agent is Started or Updated.

Note2: When an invalid connection is specified this will cause a delay when closing and opening the Edit dialog of this agent, as the agent attempts to establish this connection.

Note 3: This is set to On, by default, for new agents.

status bit 17

Stopped

On if the agent is ABLE to connect to the device BUT not getting, setting and/or trapping OID values.

status bit 18

Started

On if the agent is ABLE to connect to the device AND getting, setting and/or trapping OID values. For details on stopping or starting the managing of the device, see Device Management Settings.

status bit 19

Unlicensed

On if:

  • the Started (statusBit18) is set
  • Agent Server license does NOT contain the required OEM license and
  • it is NOT the first SNMPMgr agent that was added.

For details regarding the licensing and use of this agent, see Usage Requirements.

status bit 21

Error

On when a non connection-related error has occurred, while the errorMsg slot can be used to determine the reason why this status bit is being set. This specifies that one of the following errors have occurred:

Note: If this Error status bit is alarmed, using the default Error alarm type, then the contents of the errorMsg slot appears in the "Reported data" field of the alarm entry.

  1. If the Started (statusBit18) is set and any agent assigned to an OID is not found. For instance, when an agent is removed from the Agent Server after it was assigned.

Note: In this case the errorMsg slot contains the name of the missing agent. However, if multiple agents are not found, usually only the last agent that is "not found" will be displayed by this slot.

  1. If the Started (statusBit18) is set and one or more of the polled, written and/or trapped OIDs cause the number of licensed scan points for this Agent Server to be exceeded.

Note: In this case the errorMsg slot contains 'Not enough scan points'.

WARNING! This immediate disables the polling, writing and/or trapping of ALL the OIDs, even if this agent only attempts to consume one scan point more than the total number of licensed scan points for this Agent Server. For details, see Adroit Licensing.

status bit 22

Traps

On when this agent receives 1 or more SNMP traps from the device and the trapCount slot is >= 1.

These traps are stored in the trap queue for this agent, so that you can process them, typically by means of a script. For more details, see About SNMP Traps.

status bit 23

Healthy

 On if the agent is UNABLE to connect to the specified device.
