ICMP Agent - Slot Details

The ICMP or PING agent uses the Internet Control Message Protocol to determine the existence of a remote device on the network.

By continuously polling the specified remote IP address, this agent is therefore able to identify potential network problems as they occur by generating alarms when errors are obtained when attempting to contact the specified remote IP address and/or when the round trip timeThe time to send an ICMP message to the network device and receive a reply. exceeds specified High and High-high times.

This agent is located in the following file: T_ICMP.DLL

Slots:

Slot Name Type Function
active BOOLEAN This is set to True when an ICMP message is being sent and/or received from the network device.

catchupData

RAWBYTES

Internal use only (used for datalog and real-time data catch-up).
disableStandby BOOLEAN Disable this agent on the standby Agent Server, when the Agent Server is being clustered.

failure_Count

INTEGER

The number of ICMP messages that were not received from the specified ipAddress.

hi

INTEGER

The time, in milliseconds, that indicates that the time to send a message to the network device and receive a reply has moved outside its acceptable range and therefore implies that corrective action must be taken as soon as possible.

hiHi

INTEGER

The time, in milliseconds, that indicates that the time to send and receive a message and from the network device has moved further from its acceptable range and reached the second alarm limit.

This implies that the first warning has been ignored and that urgent and immediate corrective action is now required.
interval INTEGER How often you want to check the availability of this device on the network, in seconds, also known as the required poll rate.

ipAddress

STRING

The IP address of the network device.

Note: ONLY IP addresses can be specified, so if you need to contact a web address, you need to resolve this to an IP address first.

last_Execution_Time

TIME

Specifies when the last attempt to contact the device occurred.
pingNow BOOLEAN Performs an immediate ping.

pingStatus

STRING

Provides a textual description of the status of the last ICMP message used to contact the device, as follows:

  • OK from [IP Address] if it succeeded;
  • Retries exhausted when retrying to contact the device (a timeout failure) and
  • Host unreachable from [IP Address] if it is not possible to contact the device.

retries

INTEGER

Specify how many times you want to query the availability of the network device before determining that it is unavailable.

roundTripTime

INTEGER

The time taken, in milliseconds, to send the last ICMP message to the network device and receive a reply.

start

BOOLEAN

This is used to enable/disable the sending of ICMP messages to the specified ipAddress.

timeout

INTEGER

Specify how long you want to wait, in milliseconds, to receive a response from the device before you determine that this device is unavailable.

Note: If the specified timeout is too short then you will never get a "host unreachable" error because the network will not have the necessary time to respond.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Healthy

 On when the last ICMP message was sent to and received from the network device successfully.

status bit 17

General_Failure

On when there is any failure preventing the network device from being accessed. This value is cleared when the device becomes accessible (Healthy).

status bit 18

Destination_Unreachable

On when the failure is caused because the destination IP address is not reachable on the current network, for instance when no routing is available to reach this IP address range. This value is cleared when the device becomes accessible (Healthy) or when a timeout failure occurs.

status bit 19

Destination_Timeout

On when the failure is caused because no response has been received from the remote device within the configured timeout value. This value is cleared when the device becomes accessible (Healthy) or when the remote device becomes unreachable.

status bit 20

High

On when the last round trip timeThe time to send an ICMP message to the network device and receive a reply. (INTEGER roundTripTime slot) is GREATER THAN OR EQUAL to the Round trip time: high alarm value (ms) (INTEGER hi slot).

status bit 21

High-high

On when the last round trip time is GREATER THAN OR EQUAL to theRound trip time: high-high alarm value (ms) (INTEGER hiHi slot).

status bit 22

Busy

On when an ICMP message is in the process of being sent and/or received from the network device.
