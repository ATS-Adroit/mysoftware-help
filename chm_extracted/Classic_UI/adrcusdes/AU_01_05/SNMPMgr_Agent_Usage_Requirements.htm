SNMPMgr Agent Usage Requirements

The following usage requirements must be met before the SNMPMgr agent can monitor and/or manage your network devices:

  1. Typically the device must have a SINGLE (FIXED) IP address or at least a unique port address so that this SNMP devices can be uniquely addressed via a gateway.

Note1: ONE SNMPMgr agent CANNOT connect to MULTIPLE devices (IP addresses).

Note2: You CANNOT specify an IP address that is ALREADY configured for another SNMPMgr agent!

  1. The device (computer) must be ACCESSIBLE on the network (able to be PINGed).
  2. You need to know which SNMP version the device supports and you also need to know all of its connection settings. Since the SNMPMgr agent supports up to SNMP version 3 and SNMP version 3 supports additional connection settings.
  1. ONLY WHEN MONITORING A COMPUTER: you need to run the SNMP service on this computer.

IMPORTANT: NEVER run the Windows SNMP Trap (listener) service because it conflicts with the Adroit SNMP trap functionality!

Note: This agent does NOT require the Windows SNMP Service to function, this service is ONLY required on each computer that this agent monitors.

So to monitor a computer, you will typically need to install the SNMP service - because this component is NOT included in the STANDARD installation of Windows (and/or Server) operating systems and you need to you need to configure the security settings to browse its SNMP values. For details, see Installing the Windows SNMP Service and SNMP Service Security Configuration.

  1. The security settings, of the SNMP managed devices and the Agent Server computer, on the network must ALLOW SNMP traffic.

Therefore, ensure that the port used for SNMP communications is unblocked (enabled) in any firewalls that may exist, which is typically UDP port 161 for a fixed IP address or the unique port address for the device, when addressed via a gateway.

  1. To monitor/manage TWO OR MORE DEVICES, then your Agent Server license must include the necessary OEM a component in Adroit that requires a SEPARATE license BEFORE it can be used, which is added to the Agent Server license by means of an appropriate textual description of this component. license. In other words, WITHOUT this OEM license you can ONLY monitor and/or manage a SINGLE device.

Tip: To check if you have the correct OEM license, simply create a second SNMPMgr agent and ensure that its Unlicensed checkbox (status bit) is not enabled.

  1. Ensure that your Agent Server license has enough available scan licenses, since a scan pointa scan point licence that is consumed from your Adroit license when information is being manipulated. is consumed for every unique OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. value that is polled, written to and/or trapped.

WARNING! If an SNMPMgr agent requires more than your available scan points then ALL these OID value operations are DISABLED and its Error status bit is set.

  1. To monitor this device you require its community string that has READ ONLY rights. For details of community strings, see SNMP Community Strings.
  2. To control this device you require its community string that has READ WRITE rights.
  3. To receive SNMP events (traps) from the device you need to create a script that processes the received traps. For further details, see About SNMP Traps.

Note: Ensure that you backup the GLOBAL SNMP configuration file, which is called 'snmp.wgx' by default, as this file contains the common OID configuration of ALL your SNMPMgr agents!
