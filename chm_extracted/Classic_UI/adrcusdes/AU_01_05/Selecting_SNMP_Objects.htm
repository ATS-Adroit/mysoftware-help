Selecting SNMP Objects

The SNMPMgr agent is able to get and/or set SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. (each of which is an OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.) from a single device on the network. The SNMP Objects Browser can specify the required OIDs. Click for more details:

Note1: You need to connect to the device to use this SNMP Objects Browser.

Note2: You need to Enable polling before you can use this SNMP Objects Browser.

Note3: If you cannot connect to the device then you can add OIDs manually. For details, see Adding OIDs Manually.

Note4: Not all devices allow you to browse their OIDs.

Launch the SNMP Objects Browser:click the Browse OID to add button in the Edit SNMPMgr Agent dialog.

Note: A message box is displayed if the agent cannot connect to the device, indicating that the connection is invalid.

Tip: If this dialog is displayed then the specified connection settings are correct.

The MIB Browser dialog contains the following methods of obtaining the device's MIBSNMP Management Information Base, this is a database that lists uniquely described and organizes SNMP managed objects hierarchically. hierarchy (tree of OID values):

  1. Either click the Walk device button, which then build the tree of the available OID values supported by this device. In this case the retrieved nodes of this tree are only indicated by their numbers.

    Note: If the monitored device is a computer and you receive an error when trying to walk this device, then ensure that you have installed the SNMP service on this computer AND configured its security settings appropriately. For details, see Installing the Windows SNMP Service and SNMP Service Security Configuration.

  2. Or click the Load MIB file... button to browse in a MIB file for this device, which provides the available OID values supported by this device. In this case the nodes of this tree display their textual descriptions, making it easier to select the required values.

To select an OID from the OID tree:

  1. Expand the branches in the tree to expose the required OID.

Tip: Double-clicking a branch will expand its sub-branches, if any.

  1. Click on the required object to display its details, in the Selected OID details pane, which provides the following information:
    • Object-identifier (OID): This specifies the name of the selected OID in numeric format. For further details, see OID Naming Formats.
    • Name: Typically this should correspond to the literal name of the OID, however due to the latest standard in displaying OIDs, this may only be a partial description of the international MIB database tree.
    • Return type: The type of data that is returned by the value of this SNMP object. If you intend writing to this value, please ensure that this return type CAN be written to. For details, see: SNMP Object Value Return Types.
    • Description: This is identical to the Name field, except that its text is wrapped, so that the full textual description of this object can be viewed.
    • Value: This obtains the value of this SNMP object within the specified SNMP device.

Tip: Use the information displayed in these fields to determine if the selected OID is correct.

  1. Click the Add to List button to add the highlighted OID to the selected OID list of this SNMPMgr agent.

Tip: Double-clicking an SNMP object immediately adds it to the selected OID lists.
