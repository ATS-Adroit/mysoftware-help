The DumpConfig agent

A DumpConfig agent simply stores the configuration of specific agents in an OLE DB database.

One example for its use is when you need to report on agents in the context of their configuration at the time of the report, alternatively this could be used as an extensive method of auditing changes made to specific agents.

 

For details on how to specify which agents' configurations you want to save to the OLE DB database and at what time or events their configurations should be saved, see Configuring DumpConfig Agents.

Note: For those of you running a clustered Agent Server, this agent supports real-time catch-up so even if the master Agent Server fails, the standby will seamlessly continue with dumping the specified agent configurations.

For details of the specific status bits of this agent can be used for diagnosing the status of its connection to the database and/or monitoring the process of dumping agent configurations to this database, see Specific Status Bits of the DumpConfig Agent.

Note: You can only add ONE DumpConfig agent.

For a description of all the slots (values) contained in this agent, see DumpConfig Agent - Slot Details.

For a description of how this agent is saved in the Adroit database (.WGP) file, see DumpConfig Agent - Database File Format.
