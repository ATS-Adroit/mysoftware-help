Specific Status Bits of the ICMP Agent

The ICMP or PING agent uses the Internet Control Message Protocol to determine the existence of a remote device on the network. Any IP network device is able to send, receive and process ICMP messages. These messages are only used for troubleshooting network problems and not to transfer data. The most common use of the ICMP protocol is by the PING diagnostic utility.

The following status bits of this agent can be used for diagnosing the existence of the specified remote device on the network, as follows:

  • statusBit16
    Healthy

On when the last ICMP message was sent to and received from the network device successfully.
  • statusBit17
    General_Failure

On when there is any failure preventing the network device from being accessed. This value is cleared when the device becomes accessible (Healthy).
  • statusBit18
    Destination_Unreachable

On when the failure is caused because the destination IP address is not reachable on the current network, for instance when no routing is available to reach this IP address range. This value is cleared when the device becomes accessible (Healthy) or when a timeout failure occurs.
  • statusBit19
    Destination_Timeout

On when the failure is caused because no response has been received from the remote device within the configured timeout value. This value is cleared when the device becomes accessible (Healthy) or when the remote device becomes unreachable.
  • statusBit20
    High

On when the last round trip timeThe time to send an ICMP message to the network device and receive a reply. (INTEGER roundTripTime slot) is GREATER THAN OR EQUAL to the Round trip time: high alarm value (ms) (INTEGER hi slot).
  • statusBit21
    high-High

On when the last round trip time is GREATER THAN OR EQUAL to theRound trip time: high-high alarm value (ms) (INTEGER hiHi slot).
  • statusBit22
    Busy

On when an ICMP message is in the process of being sent and/or received from the network device.
