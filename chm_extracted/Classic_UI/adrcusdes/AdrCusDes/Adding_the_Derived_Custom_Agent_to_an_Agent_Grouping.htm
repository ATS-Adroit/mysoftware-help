Adding the Derived Custom Agent to an Agent Grouping

In order for this derived agent to be displayed in the Type list box, in the agent Configurator and to allow the Adroit Project Explorer to display this agent type, it must be configured as either a Basic, Advanced or System agent. As follows:

  1. Open the Agent Configurator in the User Interface
  2. Select the AgentGroup agent from the Type list
  3. Select this derived custom agent type from the list box
  4. Click the Groups button
  5. In the Agent Groups dialog, double click on the applicable agent grouping from the Available list. It is recommended to follow the following guidelines, when selecting this applicable agent grouping:
  6. A Basic agent: The most commonly used agent types.
  7. An Advanced agent: Those agent types most likely to be created and manipulated by advanced Adroit users.
  8. A System agent: System agents are ordinarily created automatically by Adroit to provide certain SCADA or other system functions.
  1. Click OK.
  2. With the agent Configurator window still open, click the Save toolbar button, to save the WGP file.

For the DriveXYZ type, add this custom derived agent to the Basic agent grouping.
