Script Methods

The Custom object, can be used when creating the script code that will provide additional functionality for this agent, to provide communication with the Agent Server, via the following methods:

AgentName

GetSlot

LogEvent

SetStatus

Sound

CDateTime

GetTag

SetSlot

SetTag

 

Note: To implement these methods simply type: Custom.RequiredMethodName and its parameters, if any.
