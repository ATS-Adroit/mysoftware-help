Slot Configuration Grid

This grid, consists of the following columns, which define each slot of the derived agent, as follows:

Note: The grid provides standard configuration options, use the horizontal and vertical scroll bars, when visible, to navigate to the required fields.

  1. The first untitled column, numbers the defined slots in the grid.
  2. Replace or edit the cell in the Slot name column, to define a name for each slot required by the derived agent.

Note: The order in which the slots are defined, defines the order of the slots, in which they will be displayed in the configuration agent dialog. It is good practice to keep slots with the same data type together.

For the DriveXYZ agent, type in the following slots: Start, Stop, Tripped, Speed and Temperature.

We will also add a Value slot that will denote the running status of the drive and a slot called HighTemp that will be used to store the high alarm value of the temperature variable.

  1. Replace or edit the cell in the Slot type column, for each defined slot, to select its applicable data type, from the following selections in the list box:

    2. Boolean

    If the slot is to contain a 1 (TRUE) or 0 (FALSE).

    Integer

    If the slot is to contain a valid 32 bit value.

    Real

    If the slot is to contain a valid 64 bit (8 byte) floating number.

    String

    If the slot is to contain a variable length string (i.e. a VarString slot).

    WARNING! This slot CANNOT be scanned.

    String80

    If the slot is to contain a 79 character text string (i.e. a String slot).

    Note: ONLY String80 slots can be scanned.

    Datetime

    If the slot is to contain a valid datetime variable.

    Tagname

    If the slot is to contain the name of any valid tag (agent.slot), which will be automatically subscribed to.

 

For the DriveXYZ agent, add the following descriptions to the configured slots: Start=Boolean, Stop=Boolean, Value=Boolean, Tripped=Boolean, Speed=Real, Temperature=Real and HighTemp=Real.

  1. Replace or edit the cell in the Slot description column, for each defined slot, to specify a suitable slot description.

For the DriveXYZ agent, add the following data types to the configured slots: Start=Start drive pulse, Stop=Stop drive pulse, Value=Drive is running, Tripped=Drive has tripped, Speed=Drive Speed (rpm), Temperature=Temperature (degC) and HighTemp=Temperature high alarm value.

  1. Replace or edit the cell in the WGP prefix column, for each defined slot that needs to be saved in the WGP file, to specify a suitable 3 to 5 character prefix for this slot.

For the DriveXYZ agent, in practice only the HighTemp slot would need to be saved, since this is probably the only slot that is not scanned from a front-end device and is manually changed by an engineer/operator from a mimic.

But for this example, all the slots will be saved so that the WGP file will always contains the slot values as at the last save.

  1. Tick the tick box in the Disable editing column, to prevent this defined slot from being edited within this derived agent’s configuration dialog.

A slot that is disabled for editing, prevents its simulation from within the configuration dialog, but will still allow it to be manipulated by others means e.g. from a mimic. This is not ticked by default.

For the DriveXYZ agent, only the following slots: Start, Stop and HighTemp will be edited from the configuration dialog, therefore tick this tick box for the following slots: Value, Tripped, Speed, Temperature, so that these slots will only reflect the values existing in the PLC or the last saved value.

  1. Tick the tick box in the Disable view column, to prevent this defined slot from being viewed in this derived agent’s configuration dialog.

This should typically be used by an intelligent agent type to hide its internal working slots from view, although these slots can still be manipulated by others means e.g. from a mimic. This is not ticked by default.

The DriveXYZ agent, does not use any internal working slots, therefore none of this column’s cells need to be ticked.
