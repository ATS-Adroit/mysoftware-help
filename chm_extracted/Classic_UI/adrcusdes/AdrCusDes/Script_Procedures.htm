Script Procedures

When a Has script engine Custom agent is derived the following empty procedures are created, which can either be left empty– to not provide a script engine or they can be coded to provide any additional functionality for this agent:

OnCompiled()

Code that is executed every time the Agent Server detects a change in the script code. This procedure can be used to initialize any global variables.

OnLoadComplete()

Code that is executed once an agent has been loaded from the WGP file. This procedure can contain code to initialize slot values.

OnChange(slotid, value)

Code that is executed every time a slot value is changed. This procedure should contain code that requires execution depending on the slot and value thereof being changed, e.g. setting status bit slots.

OnUpdate(slotid, value)

Code that is executed every time a Tagname type slot receives a subscription update. This procedure should contain code that requires execution depending on the subscription received.

OnBackground()

Code that is executed every second in the background. This procedure should contain time-dependant and/or simulation code.
