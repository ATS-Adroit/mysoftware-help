How to Use the Online Help

Comprehensive online help documentation is provided, in the Microsoft HTML Help (.CHM) format, which has the following functionality:

IMPORTANT: Due to Microsoft security restrictions, CHM help files can ONLY be used on your local computer and cannot be launched over the network.

How to launch the help: ways in which the help can be displayed.

  • Open the Help menu and click on the Help Contents menu item.
  • Press the F1 key, to display the context-specific help topic.
  • Click the Help button of the relevant dialog.

Using help

  1. Help file topic links: the following methods are provided to display additional or related information concerning the current help topic:

  2. Popup and topic links: these links appear as sampleText in topics. Click on the following hyperlinks to see the differences between these types of links popup and topic links (click on these).

    Note: If a popup link closes and you reopen it, it opens at the same place before it closed and/or with same selected text.

    Tip: If you click anywhere in a popup the popup closes, so use the provided scroll bar to navigate down.

How to copy text from a popup link:

    1. Click on the popup link to display the popup window.
    2. Select the required text manually or right click and select Select All.

    1. If the popup link closes, click on the popup link again.

      Tip: You can also press the CTRL+C shortcut.

The popup window appears again with the required text selected.

    1. Right click and select the Copy menu item

Paste this text into the required application.

  • Drop down text: these links appear as sampleText in topics. If clicked this display its contents, and if clicked again will hide its contents. This can show or hide parts of a help topic. Click on these links in this topic below, to see how they work.

    Contents displayed by the sample drop-down text link - if clicked again this content will again be hidden. Note the direction of the link icon has changed too!

    Tip: If a topic is printed ONLY those drop down text links that are expanded will be displayed.

  1. Navigation Pane:

This contains a number of navigational tools to help you locate the required help topic.

Access the following tools by clicking their named tab:

  1. The Contents tab, provides a hierarchical view of help topics, organized by subject, as follows:
    • When you click a closed book, it opens to display its content (sub-books and pages).
    • When you click an open book, it closes.
    • When you click pages, you select topics to view in the right-hand pane of the HTML Help viewer.

    Tip: Use this if you know the approximate location of the help topic they are looking for, but not its exact name.

    Note: The root of the Table of contents provides the Glossary or list of words that you may not understand, simply click on the required word to view its corresponding definition.

  1. The Index tab, provides a list of keywords each linked to one or more topic, as follows:

    Select the keyword and then click Display.

    Tip: Its also possible to double-click the keyword.

    If the keyword is used with more than one topic, a Topics Found dialog opens so you can select a specific topic to view.

    Tip: Once the topic is displayed you can click the Locate toolbar button to find this topic in the Contents tab. This will also open the Contents tab.

    Tip: Use this if you know what they are looking for, but may not know its exact term and do not want to use the table of contents.

  1. The Search tab, to locate EVERY topic containing the EXACT word or phrase that you specify. To specify a phrase, put the words into double quotes ("). For further details, see Searching the help for topics.

    Tip: Use this if you know the exact phrase you are looking for. Otherwise this may return a long list of irrelevant topics.

    Note: The search options can also be used to limit the topics that are returned.

  1. The Favorites tab, to create your own list of help topics that you frequently use, as follows:
    • Select a help topic that you frequently use.
    • Open the Favorites tab.
    • If necessary, type in your own label for this help topic.
    • Click the Add button.

    Then when you next open the Favorites tab, use this label to open this help topic.

    Tip: Open or close this navigational pane, as needed, by using the Show or Hide toggle button of the help toolbar.

 

  1. Viewed Topic Navigation: Use the Back and Forward toolbar buttons to navigating between previously viewed topics.
  2. Printing topics: While using the online help system, you can print topics and information, by using the Print toolbar button from within the help viewer.

    To print a single topic:

    1. Ensure the required topic is displayed in the help viewer.

    2. Click the Print toolbar button.

      Note: If you are within the Contents tab, select the Print the selected topic option from the Print Topics dialog and click OK.

    The Print dialog is displayed.

    1. Use the General page to select the required printer, the range of pages and number of copies.
    2. Use the Options page to specify the required printing options:
    3. Print all linked documents: This will also print all the topics that are linked to the currently displayed topic.
    4. Print table of links: This will print a table at the end of this topic, which lists all the links found within this topic.

     

    To print all topics in a selected book:

    Note: This can only be performed when the Contents tab is selected.

    1. Ensure the required topic is displayed in the help viewer.
    2. Click the Print toolbar button.

    The Print Topics dialog is displayed

    1. Select Print the selected heading and all subtopics and click OK.

    The Print dialog is displayed.

    1. Use the General page to select the required printer, the range of pages and number of copies.
    2. Use the Options page to specify the required printing options:
    3. Print all linked documents: This will also print all the topics that are linked to the currently displayed topic.
    4. Print table of links: This will print a table at the end of this topic, which lists all the links found within this topic.

    Tip: If topics include Drop down text, ONLY those that are currently expanded will be printed.

  1. Options menu: The Options toolbar button opens a menu, which provides items that duplicate many of these functions and provide additional options too.

    This menu contains the following items:

    • Hide/Show Tabs: To close or open the left hand help tabs.
    • Locate: To find out where a topic located within the Index occurs in the table of contents i.e. the Contents tab. This will also open the Contents tab.
    • Back: To display the previously viewed help topic.
    • Forward: To display the prior help topic.
    • Home: To display the home page of the Designer.
    • Stop: To stop a help topic or Web page from loading.
    • Refresh: To update the information displayed in the window.
    • Internet Options...: To display the Internet Options dialog.
    • Print: To print the selected topic.
    • Search Highlight Off/On: To turn search highlighting on or off. If search highlighting is on then the word(s) that are being searched for will be highlighted in the displayed topics.
