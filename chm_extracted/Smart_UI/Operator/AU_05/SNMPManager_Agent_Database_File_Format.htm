SNMPManager Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

IPA=nnn.nnn.nnn.nnn

The IP Address of the device to be monitored.

COM=string

The SNMP Community String required to access the SNMP objects and their values, for this device.

MON=#…##… #$

The list of the selected SNMP objects, where each list entry (…) adheres to the following format: *Index*Enable*Object Identifier*SNMP name*Return type*Current Value*Adroit tag.

RAT=nnnnn

Scan rate in milliseconds for retrieving the values of the scanned and enabled SNMP objects in the selected objects list.

STT=n

A Boolean value indicating whether the monitoring (scanning) process of this agent is either started or stopped.
