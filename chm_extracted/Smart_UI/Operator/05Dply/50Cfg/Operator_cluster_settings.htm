Operator cluster settings

This page of the Setting up the Operator component of the Adroit Config Editor configuration dialog, provides the following settings that required to make the Smart UI Operator aware of one or more of the available clusters:

Click for more details:

Servers can be clustered to handle their combined workload evenly and to provide continued operation in the event that one or more fail. An Operator can only connect to a clustered Server, if it is aware of this Servers's cluster.

Note: An Operator can be aware of more than one cluster.

 

To display this page of settings:

When the Smart UI Operator is launched, it needs to log into a Smart UI Server computer, which stores the data configured within the Smart UI Operator.

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Operator option.

Note: If this option does not appear then the Smart UI Operator may not be installed.

  1. Select the Cluster Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Enable Clustering: determine whether this Operator will connect to clustered Servers or not.

To specify cluster-awareness: Either select Yes to enable or No to disable this setting.

 

Cluster Names: specify the names of all the clusters that this Operator will connect to.

To specify the required cluster name: : Type the required name into the edit box and press theAdd button.

Note: The correct capitalization is not required as long as the name is correctly spelt.

To remove a cluster name: : Select the required name in the list, below the edit box and press theRemove button.

Simply specify the names of all the clustered Smart UI Servers that this Smart UI Operator should connect to, since the Smart UI Server name is the cluster name for a clustered Smart UI Server.

Cluster Server connections: configure the connection between this Smart UI Operator and each of the Smart UI Servers within the specified clusters.

Each connection, consists of the following parameters:

  1. Clustername: The name of one of the specified clusters - simply select the required cluster name from the list.
  2. Comms Type: Select the method of connecting to the Server, by selecting one of the following options:
  3. MAINDATAPROVIDER: To directly connect to the Server computer via the local network (LAN).
  4. WEBSERVICEDATAPROVIDER: To connect to the Server computer via the Internet.

Note: This option requires the Smart UI Server to have the Smart UI Web Service installed and configured.

  1. MachineName: Depending upon the selected connection type, specify the location of the Server, as follows:
  2. LAN: This should either be the network name of the computer on which this Server is running or its IP address.
  3. Internet: The Internet location of the Smart UI Web Service, which adheres to the following format: http://webservice/folder, which by default is http://machineName/Smart UI
  1. Port: This is address of the port used to communicate with this Smart UI Server and this address depends upon the selected connection type, as follows:
  2. LAN: Usually port 9000 is used to communicate with this Smart UI Server via the network.
  3. Internet: Usually port 80 is used to communicate with this Server via the Internet.
  1. Comms Mode: Select the appropriate method of communicating data to and from the Smart UI Server, from the provided list box, as follows:
  2. LAN: SUBSCRIBE is recommended which provides the fastest response time and therefore requires the highest bandwidth.
  3. Internet: SUBSCRIBE_POLL is recommended when using a high bandwidth Internet connection, otherwise POLL should be used when using a low bandwidth Internet connection.

Note: Please ensure that the first Smart UI Server in this list is the Smart UI Server that this Smart UI Operator will log into and that the SAME settings are specified for this connection, as those in the Operator connection settings page.

 

This page only configures the part of the essential Smart UI Operator settings. For details, see Setting up the Operator.

For details on displaying all the related Smart UI Operator settings, see the Advanced Operator settings page.
