Configuring AdroitHistoricalAlarmViewer columns

The AdroitHistoricalAlarmViewer control allows you to choose which columns are displayed, their order and their specific properties via the Columns tab of the Initial Configurationand the Columns Configuration and General Configuration Settings dialogs, as follows:

  • To display or hide a column: check or uncheck the checkbox in the Columns list on the left.
  • To change the order of the displayed columns: select the required column in the Columns list on the left and then click the or arrow to move it up or down as required.
  • To edit the properties of a column: select the required column in the Columns list on the left and then modify the required property in the Column Properties section on the right.
  • The Best Fit Columns checkbox is checked by default to force all the displayed columns in the grid to automatically resize their widths so that their contents fit in the control without requiring any horizontal scrolling.

Available column properties:

Property Configuration

DisplayName

 changes the name of the column heading in the grid.

BestFit

determines whether the column auto-sizes (if True) or not, in other words if it changes its width to accommodate the largest entry.

Width

 configures how wide the column is, in pixels, which is 100 by default.

FormatString

a string of data type specific format specifiers in {} braces that specify how the entries of this column are formatted. The default is column-specific. For details, see the Value formatting syntax.

GroupIndex

this determines whether this column is automatically used to group the data of the other columns and if so what its relative order is, if more than one column is configured to automatically group data, as follows: -1 the default, which means do not initially group data using this column; 0 = 1st level grouping; 1 = 2nd level grouping; 2 = 3rd level grouping etc.

Note: These grouping settings only affect the initial grouping of the data, but users can choose to remove all grouping columns and/or group data using any column.

GroupInterval

when this column initially groups the data, this allows you to select how the data within this column is used to group the other data. Hence these settings are data specific so the data time settings only apply to date time data etc.

SortIndex

when multiple columns are initially sorting the data, this defines the order in which these columns are used, as follows: -1, this is the default, which means do not initially use this column to sort the data; 0 = primary sorting column; 1 = secondary sorting column; 2 = tertiary sorting column etc.

Note: These sorting settings only affect the initial sorting of the data, but users can choose to remove all sorting and/or sort data using any column.

SortOrder

when this column initially sorts the data, this defines how the data in the column is sorted, as follows:

  • None (the default): this does not sort the data
  • Ascending: from smallest to biggest (a to z).
  • Descending: from biggest to smallest (z to a)

By default the control is sorted in Descending order of the Date Time column, so that the latest alarm is displayed at the top.

SummaryType

this allows you to perform a calculation on all the entries in this column and display the result of this calculation in the summary row, which the last row at the bottom of the grid. The default is column-specific.

  • Sum: the summary row displays the total of all the values in this column;
  • Min: the summary row displays the minimum (lowest) value for this column;
  • Max: the summary row displays the maximum (highest) value for this column;
  • Count: the summary row displays the number of items in this column - which is the default setting of the DateTime (DT) column
  • Average : the summary row displays the average value for this column;
  • None (the default): no summary calculation is performed on this column's entries

SummaryDisplayFormat

when a column is calculating a summary, this allows you to specify the required format specifier string for the summary value in {} braces and any descriptive text that should also be displayed. For instance the default summary format for the DateTime (DT) column is: {0:n0} rows. For details about formatting the calculated value, see the Value formatting syntax.

Fixed

determines whether the column is frozen like in Excel so that this column is always visible when scrolling left and right, as follows:

  • None (the default) - the column takes part in left and right scrolling
  • Left: the column is anchored to the left edge of the grid and is always visible when scrolling left and right.
  • Right: the column is anchored to the right edge of the grid and always visible when scrolling left and right.
