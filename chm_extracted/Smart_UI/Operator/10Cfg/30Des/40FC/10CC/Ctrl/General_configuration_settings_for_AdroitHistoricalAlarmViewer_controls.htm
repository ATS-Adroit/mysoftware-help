General configuration settings for AdroitHistoricalAlarmViewer controls

This dialog allows the generally applicable settings of the AdroitHistoricalAlarmViewer control to be specified, namely:

  • select how you want this control to refresh itself with more recent alarms. For details, see Configuring how to update AdroitHistoricalAlarmViewer controls, which ALSO describes the TWO methods of linking the Alarm Management database table to this control.
  • choose which columns are displayed, their displayed names, their order and their specific properties, such as their widths; whether they autosize; whether the alarms will be sorted by their contents and how; whether they display a summary and what type and/or whether they should be frozen. For details, see Configuring AdroitHistoricalAlarmViewer columns.
  • you can further refine the displayed alarms to eliminate unnecessary alarms; in other words you can configure this control to only return a specific number of the topmost alarms and/or how you want to specify the time period of applicable alarms that will be retrieved. For details, see Configuring AdroitHistoricalAlarmViewer constraints.
  • you can change the colors the following components within this control: the background and foreground color of the odd and even rows; the background color of the toolbar and the color theme used for the grid. For details, see Configuring AdroitHistoricalAlarmViewer appearance.

Tip: The Tasks menu provides additional configuration settings ONLY applicable when designing AdroitHistoricalAlarmViewer controls. For details, see AdroitHistoricalAlarmViewer controls task menu.
