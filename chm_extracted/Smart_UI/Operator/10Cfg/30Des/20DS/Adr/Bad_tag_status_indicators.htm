Bad tag status indicators

When displaying Adroit tags in your graphic forms, to assist in their troubleshooting, by default, both the Smart UI Designer in Run (runtime) mode and the Smart UI Operator display bad-tag status indicators.

Note: The (Misc)ShowStatusBadIndicators Boolean value in Smart UI Designer and Operator CONFIG files, controls the display of these bad status indicators, which is True, by default.

Tip: The Show (All) Information right click option provided by the Smart UI Operator, lists the good tags in green and the bad tags in red. For details, see Working with Show (All) Information.

The following indicator icons are displayed, in the bottom right corner of the controls (or vectors) that have the applicable bad tags connected to them:

Note: While each tag only displays the most relevant bad status indicator, if there is more than one bad tag linked to the control or vector, then the bad status indicator of the tag that changed last is displayed.

  1. general bad: , which usually means the value of the tag is outside of its minimum or maximum range.
  2. scan bad: , which usually means either the tag not been scanned correctly or the device has not started.
  3. invalid tag: , which usually mean that the tag does not exist.

Example:

Clicking the displayed indicator, possibly displays the name of the tag and displays the name of the property that this tag is linked to.

This only displays the name of the tag if it has been directly linked to this control or vector.

Example:

Therefore, if an intermediary method of linking has been used, such as a spider, then the tag name is not be displayed. In the case of using a spider, all you see is the name of the spider output that is linked to this property.

Example:

Clicking on the displayed text, displays the following options:

  1. Status : this indicates the status or reason of why the specified (first detected) tag directly linked to this item is problematic (BAD, SCANBAD, NONEXISTING).
  1. Copy : to copy the specified tag name (when this has been directly linked) to the clipboard, for reference purposes.

Note: When an indirect method of linking has been used, such as a spider, this will only copy the name of the spider output to the clipboard.

  1. Copy all : to copy all the tag names (when multiple problematic tags are directly linked to this item) to the clipboard, for reference purposes.
  1. Edit: to open the Adroit Agent Configurator with this tag (agent) selected (if it can be found), so that it can be edited.

Note: Since the editing of tags in the Smart UI Operator poses a security risk, the display of this option is controlled via the AllowEditTags Boolean setting of the Operator Settings page of the profile dialog, which is False (hidden) by default.
