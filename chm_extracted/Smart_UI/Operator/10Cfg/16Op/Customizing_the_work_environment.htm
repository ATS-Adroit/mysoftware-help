Customizing the work environment

The Smart UI Operator displays configured graphic forms, so they can be operated or interacted with and allows you to customize the working environment, as follows:

The display and the amount of interaction that a user has with the Smart UI Operator window, is determined by:

  • the user profile configured for this user in the Smart UI Designer. For details, see Operator customization.
  • and/or the command line argument options used to launch the Smart UI Operator. For details, see Operator command line arguments.

Note: The INITIAL display of the Smart UI Operator and configuration of the work environment can be configured by Smart UI Operator settings. For details, see Operator user interface settings.

The work environment of the Smart UI Operator consists the workspace and tool windows. For details, see Operator workspace.

Note: The tool windows can be hidden to increase the viewing space. For details, see Available tool windows.

The work environment can be further customized by right-clicking the Smart UI Operator window and selecting one of the following menu items:

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. To display or hide the tool windows and document tabs, press CTRL+O or right-click and select Toggle Operator Mode.

Note: The default setting can also be configured using the Boolean InitialOperatorMode Smart UI Operator setting of the user profile configured in the Smart UI Designer.

  1. To display or hide document tabs within the Operator window, press CTRL+T or right-click and select Toggle Graphic Form Tabs. For details on the use of these tabs, see Operator workspace.

  2. To enable or disable the running or "live" state of the currently displayed graphic form, either press F5 or right-click and select Running.

    This may be necessary if a running graphic form consumes excessive bandwidth ( for instance when using an Internet connection).

  3. To print the currently displayed graphic form, press CTRL+P or right-click and select Print.
  4. To assist in troubleshooting your graphic forms you can allow all or a single control or vector to display the list of all the data elements connected to its properties. For more information, see Working with Show (All) Information.

Note: When using Adroit tags you can also display bad-tag status indicators on relevant controls and/or vectors. For details, see Bad tag status indicators.

  1. To enable or disable the display of the Smart UI Operator window above all other applications, right-click and select Always On Top.
  1. To enable or disable the full screen display of the Smart UIOperator window (filling the entire screen without a title bar), press F11 or right-click and select Full Screen.
  2. To display the current bandwidth speeds for sending and retrieving data from the Smart UI Server and the amount of data that is being sent and received, press F6 or right-click and select Transfer Statistics.
  3. To log off the Smart UI Operator, either press CTRL+N or right-click and select Disconnect.
  4. To close the Smart UI Operator window, either press ALT+F4 or right-click and select Exit.
