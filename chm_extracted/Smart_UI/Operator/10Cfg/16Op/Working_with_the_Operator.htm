Working with the Smart UI Operator

The Smart UI Operator allows you to operate graphic forms (view and manipulate their data, using the user-interface provided by each graphic form) and customize the display of these graphic forms within the Smart UI Operator window at the same time.

The display and the amount of interaction that a user has with the Smart UI Operator window, is determined by:

  • the user profile configured for this user in the Smart UI Designer. For details, see Operator customization.
  • and/or the command line argument options used to launch the Smart UI Operator. For details, see Operator command line arguments.

Note: The INITIAL display of the Smart UI Operator and configuration of the work environment can be configured by Smart UI Operator settings. For details, see Operator user interface settings.

This work environment of the Smart UI Operator provides the following main features:

  1. Windows: The work environment of the Operator consists of two types of windows, the Operator workspace and tool windows. 

Note: This typically provides the Context View tool window to view the defined contexts in the Operator, to display all the graphic forms and/or object instances that have been added to your defined contexts, such as the graphic forms associated to the nodes of your Default context.

In addition to searching for your object, you can also right click them to view the defined attributes of each object instance and/or show the children (sub-components) of any item in your contexts. For details, see Context View tool window.

Tip: The start page allows you to navigate between open graphic forms and also shows when these graphic forms were last refreshed.

  1. Right-click menu: Extensive right-click menus provide support for doing the most common tasks.

    Place the cursor in the window that you want to work with, press the right-mouse button, and select an option from the menu. For details, of these options, see Customizing the work environment.

  1. Getting help: See Working with the online help.
