Context View tool window

The Context View tool window, logically groups or organises your deployed objects according to their defined attributes, so that they can be easily located and/or searched. In other words all the objects that have the SAME attribute are added a separate group or 'context'.

Furthermore this grouping is hierarchical so that the objects are further classified or grouped according to their specified values of this attribute. This allows you to see which objects have the same values and/or view all the values that have been specified for a particular attribute.

This also displays the Default context which you can use to specify your own logical organisation of your objects and/or other data by creating the necessary hierarchy of nodes , which you can assign graphic forms that can be opened when the node is selected.

Actions supported by all contexts:

  • Select the required context from the list of contexts to the left of the bottom tool bar of this window.

  • Search the Context View, by typing the text that you want to search for into the search box to the right of the top tool bar of this window. More details:

    Any results that match the specified text are displayed in the results pane that expands below the top tool bar of this window.

    By default you only search for matching text within the currently loaded context.

    However, if you click the filter button at the right of the search box, then you can specify which defined object attributes you want to include in this search, by checking their relevant checkboxes.

    So if you have specified text that does not occur in the current context but does appear in another defined context that you select , then the applicable object name appears in the search results pane along with the full name of the attribute containing the searched text.

    By default the Include item name in the filter checkbox is checked, which also searches the defined items in the context tree for the specified text, such as the node names and any added data elements or object instance names etc. If this is unchecked then these item names in the context hierarchy are excluded from the search.

  • Items displayed in the Context View, provide the following right click options when applicable:
  • Show attributes - this is only displayed when the selected item is an object instance, which lists all the attributes and their values that are defined for this object.
  • Show children - this displays all the children of this item: for instance if this is an agent, then its slots are displayed as sub-items in the tree; if this is an object instance, then all the defined child instances are displayed as sub-items in the tree etc.

To access the Context View tool window

Click the Context View tab, which should be on the left side of the Smart UI Operator.

Note: If only the Smart UI Operator workspace is currently displayed, then right-click and select Toggle Operator Mode.

Tip1: When a component is open in this tool window you will see a minus box  at the left side of its icon. When you close a component, you collapseclick the minus box to the left of the current icon the hierarchy so you do not see its contents.

Tip2: If you right-click on any item in this tool window a menu will open with the available options, if any, for working with that item.
