Operator workspace

The Operator workspace is the main work area, that contains all the graphic forms, which are currently open in the Smart UI Operator.

The workspace either fills the entire Smart UI Operator application window or opens to the right of the tool windows, when displayed.

Note1: You can increase the viewing space by hiding the tool windows (right-click and select ToggleOperatorMode).

Note2: Scrollbars provide easy navigation when viewing large graphic forms. For details, see Working with scrollbars.

Each opened graphic form is identified by means of a tab, which is displayed at the top of this window. Click for more details:

Use the tabs to selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the required graphic form.

Tabs for newly opened graphic forms are added to the right of the any existing tabs.

Note1: Only one graphic form can be displayed within this window at a time.

Note2: Hide or display these tabs by right-clicking and selecting Toggle Graphic Form Tabs.

Note3: If the tabs are not displayed then you CANNOT select other graphic forms.

Depending upon the graphic form that is displayed in the Operator workspace, various buttons are also displayed to the right of the tabs at the top of this window, as follows:

  • By default, the following button  is displayed, which when clicked automatically selects the most recently opened graphic form i.e. the rightmost tab.
  • When a graphic form is displayed, this  button appears in the top-right corner, which if pressed closes the graphic form.

To display an opened graphic form in the Operator workspace: click on the tab, associated with the graphic form you require.
