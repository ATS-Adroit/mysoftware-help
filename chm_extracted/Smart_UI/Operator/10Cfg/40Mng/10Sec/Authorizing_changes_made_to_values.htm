Authorizing changes made to values

This is only needed when you have configured one or more data elements to require authorization via the data element security dialog in the Smart UI Designer.

When a value (data element) requiring authorization is changed then this change in value (write) must be authorized (before it is effected) as follows:

  • If the currently logged on user does NOT have write access to at least one of the data elements that are being written to, then the User Rights Elevation dialog is displayed by the Smart UI Operator or Designer, to provide the Username and Password of a user with write access to the specified data element, along with Comments, if required.

Then the Authorize Data Element Writes dialog is displayed so that this or any other unauthorized changes (writes) made to the values (data elements) can immediately be authorized, as described by the next point.

  • If the currently logged on user has write access to at least one of the data elements that are being written, then the Authorize Data Element Writes dialog is displayed by the Smart UI Operator or Designer,so that this or any other unauthorized changes (writes) made to the values (data elements) can immediately be authorized.

Note:This dialog does NOT display any data elements whose write authorizations have been deferred.

Specify the Usernameand Password of the authorizing user, if required Comments , which typically provides the justification for granting the requested change/s.

Note: The user who initiates the write cannot be the user that authorizes this write .

A successfully authenticated authorizing user requires write access to a data element in order to authorize its change in value.

If you are unable to obtain immediate authorization for this change in value, then click the Defer button, which adds this write to the list of deferred writes, so that it can be authorized later. For more details, see Authorizing deferred writes to data elements.

If you want to stop or abandon this write (change in value), then click the Cancel button.
