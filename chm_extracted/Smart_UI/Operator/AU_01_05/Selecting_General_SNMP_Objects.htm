Selecting General SNMP Objects

The General tab of this SNMP Objects Browser contains a collection of commonly used statistics for device management.

Note: You CANNOT write to the items you select from this General tab.

To select an item from the General tab:

  1. Ensure that the General tab of the SNMP Objects Browser dialog is selected.
  2. Check the checkbox next to the required item.

This immediately adds this item to the OID list of this SNMPManager agent, which is differentiated from browsed objects (those selected from the Browse tab), as follows:

  • their OID field is simply "General Object",
  • their Name field is prefaced by [G#], where # typically specifies the order of this object in this General tab.

 

The statistics provided by this tab are divided into the following two groups:

  • General objects for computers only:SNMP managed objects that are computer-specific and can only be used when monitoring computers. In this case a number of specific usage requirements need to be met first. For details, see Usage Requirements.

The statistics provided by this group is further classified into the following sub-groups:

  1. Incoming network traffic: these statistics are generally used to determine the status of the network received by the specified computer.

    Note: These calculated statistics ONLY use the SNMP objects that refer to the FIRST network card on the monitored computer, so if there are more than one network cards these statistics will not present the full picture.

    1. Bandwidth (kbit per second): This statistic measures the currently utilised networking bandwidth that is being received by the computer, in kilobits per second.

    Note: If the monitored computer has more than one network card, it may be necessary to perform this bandwidth calculation manually for the other network cards. For details, see Manual Network Bandwidth Calculation.

    1. Unicast packets per second: This statistic measures the number of packets received by the computer per second, which are ONLY intended for this computer.

    Note: Unicast packets are packets that ONLY have a SINGLE device as their destination

    1. Non-unicast packets per second: This statistic measures the number of broadcast packets received by the computer per second.

    Note: Non-unicast packets are broadcast packets meant for all devices or a group of devices on a network.

    1. Errors per minute: This statistic measures the number of packet errors received by the computer per minute.
  2. Outgoing network traffic: these statistics are generally used to determine the status of the network away from the specified computer.

    Note: These calculated statistics ONLY use the SNMP objects that refer to the FIRST network card on the monitored computer, so if there are more than one network cards these statistics will not present the full picture.

    1. Bandwidth (kbit per second): This statistic measures the currently utilised networking bandwidth, which is being sent out of the computer, in kilobits per second.

    Note: If the monitored computer has more than one network card, it may be necessary to perform this bandwidth calculation manually for the other network cards. For details, see Manual Network Bandwidth Calculation.

    1. Unicast packets per second: This statistic measures the number of unicast packets sent out of the computer per second.

    Note: Unicast packets are packets that ONLY have a SINGLE device as their destination.

    1. Non-unicast packets per second: This statistic measures the number of broadcast packets sent out of the computer per second.

    Note: Non-unicast packets are broadcast packets meant for all devices or a group of devices on a network.

    1. Errors per minute:This statistic measures the number of packet errors sent out of the computer per minute.
  3. System information: these are generally applicable computer management statistics.
    1. System available memory: This statistic measures the available RAM, on the computer being monitored, in Megabytes.

    For instance, this can determine whether this computer is under-performing or in other words is currently over-utilising its resources or not.

    1. Available hard drive space (C:\): This statistic measures the available hard drive space on the <C:\> drive, on the computer being monitored, in Megabytes.

    Since the majority of Adroit-related information is stored on the <C:\> drive, this statistic can be used to determine when a computer is running out of storage space.

  4. Adroit processes: these are commonly used Adroit applications that may be running on the specified computer.
    1. Agent Server (as.exe): This Boolean value can be used to determine the current status of the Agent Server process on the device being monitored.

    For instance, when used to monitor a computer that is designated to run the Agent Server, this value can be used to trigger an alarm when the Agent Server is shut down.

    1. Classic User Interface (adroit.exe): This Boolean value can be used to determine the current status of the Classic User Interface process on the device being monitored.

    For instance, when used to monitor a computer that is designated to run the Classic User Interface, this value could also trigger an alarm when this is shut down.

  1. General objects for most devices: SNMP managed objects that are generally provided by all devices.
    1. Host name:This statistic displays the textual (network) name of the device being monitored.
    2. Host description:This statistic displays the textual system description of the device being monitored, which includes the processor type and operating system employed on this device.
    3. System uptime:This statistic measures the time (in hundredths of a second) since the network management portion of the device was last re-initialized, in other words, since its SNMP service has been restarted.

While some of these items are individual OIDs, others are calculations using the values of one or more OIDs. It is also possible to perform these calculations yourself within Adroit. For details, see Manual Network Bandwidth Calculation.
