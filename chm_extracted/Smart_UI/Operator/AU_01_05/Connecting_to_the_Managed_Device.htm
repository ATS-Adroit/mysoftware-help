Connecting to the Managed Device

The SNMPManager agent must connect to the required device and specify the required level of access to its values (SNMP managed objects) before you can monitor and/or manage this device.

To connect to a SNMP device:

Specify the following settings in the Connection settings section of the Edit SNMP Manager Agent dialog:

  1. IP address (STRING ipAddress slot): Specify the IP address of the device that is to be monitored and/or managed by this SNMPManager agent. For details on the requirements and guidelines regarding the use of this agent to monitor and/or manage devices, see Usage Requirements.

Tip1: Use the arrow keys to navigate between the digits separated by periods.

Tip2: When monitoring the local computer, the following IP address always returns the local address: 127.0.0.1.

  1. Port address: this allows SNMP devices to be addressed via a gateway where the IP addresses are not unique and so a unique port address is required. 
  2. Read comm. (STRING readCommunity slot): If you ONLY want to retrieve (poll) values from this device then specify its read-only SNMP Community String. For further details, see SNMP Community Strings.

Tip: Since most equipment ships from the factory with a read-only community string that is set to "public", this is its default value.

  1. Write comm. (STRING writeCommunity slot): If you want to write (set) values for this device then specify its read-write SNMP Community String.
  1. Timeout (ms) (INTEGER timeout slot): If necessary, specify the maximum time (in milliseconds) to establish a connection to this device. This is 2.5 seconds, by default.
  2. Retries (INTEGER retries slot): If necessary, specify the number of attempts to connect to the device, before deeming this device to be unavailable. This is 2 times, by default.
  3. Only check the Enable traps checkbox (BOOLEAN trapEnabled slot): if you want to receive SNMP traps from this device. For more details, see About SNMP Traps.

Note: If the Update button is clicked after modifying the IP address or Read comm. or WriteRead comm. settings, the agent will attempt to reconnect to the device using these new settings.

The Invalid connection checkbox (InvalidConnection status bit) indicates if this agent CAN (if empty) or CANNOT (if checked) connect to the specified device. BUT this checkbox is ONLY validated when you press the Update button or select the Enable polling option for this agent, so it will ALWAYS be CHECKED when the Disable polling option is selected.

Note1: If you are monitoring a computer and have NOT installed the SNMP service, then the InvalidConnection status bit will be set.

Note2: An invalid connection will delay the closing and opening the Edit dialog, as the agent attempts to establish this connection.
