SNMPManager Agent Usage Requirements

The following usage requirements must be met before the SNMPManager agent can monitor and/or manage your network devices:

  1. The device must have a SINGLE (FIXED) IP address.

Note1: ONE SNMPManager agent CANNOT connect to MULTIPLE devices (IP addresses).

Note2: You CANNOT specify an IP address that is ALREADY configured for another SNMPManager agent!

  1. The device (computer) must be ACCESSIBLE on the network (able to be PINGed).
  1. You ONLY need to run the SNMP service on a computer that you want to monitor using the SNMPManager agent.

IMPORTANT: NEVER run the Windows SNMP Trap (listener) service because it conflicts with the Adroit SNMP trap functionality!

Note: This agent does NOT require the Windows SNMP Service to function, this service is ONLY required on each computer that this agent monitors.

So to monitor a computer, you will typically need to install the SNMP service - because this component is NOT included in the STANDARD installation of Windows (and/or Server) operating systems. For details, see Installing the Windows SNMP Service.

Note: You may need to configure the installed SNMP Service on Windows 7 before you can use the SNMPManager agent. For details, see Additional SNMP Service Configuration for Windows 7.

  1. The security settings, of the SNMP managed devices and the Agent Server computer, on the network must ALLOW SNMP traffic.

Therefore, ensure that the port used for SNMP communications, namely UDP port 161 is unblocked (enabled) in any firewalls that may exist, such as the Windows Firewall installed by Windows XP Service Pack 2.

  1. To monitor/manage TWO OR MORE DEVICES, then your Agent Server license must include the necessary OEM license, WITHOUT which you can ONLY monitor and/or manage a SINGLE device.

Tip: To check if you have the correct OEM  license, simply create a second SNMPManager agent and ensure that its Unlicensed checkbox (status bit) is not enabled.

  1. Ensure that your Agent Server license has enough available scan licenses, since a scan point is consumed for every unique OID value that is polled, written to and/or trapped.

WARNING! If an SNMPManager agent requires more than your available scan points then ALL these OID value operations are DISABLED and its Error status bit is set.

  1. To monitor this device you require its community string that has READ ONLY rights. For details of community strings, see SNMP Community Strings.
  2. To control this device you require its community string that has READ WRITE rights.
  3. To receive SNMP events (traps) from the device you need to create a script that processes the received traps. For further details, see About SNMP Traps.

Note: Ensure that you backup the GLOBAL SNMP configuration file, which is called 'snmp.wgx' by default, as this file contains the OID configuration of ALL your SNMPManager agents!
