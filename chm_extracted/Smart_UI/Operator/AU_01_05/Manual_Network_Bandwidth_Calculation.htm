Manual Network Bandwidth Calculation

In the General tab of the SNMP Objects Browser, the Incoming network traffic and the Outgoing network traffic groups contains a collection of commonly used statistics for monitoring and managing computers, which are all calculated from the values of one or more of the OIDs.

However, these calculations ONLY use the OID values that refer to the FIRST network card on the monitored computer, so if there is more than one network cards these statistics will not present the full picture.

Note: The Microsoft Loopback Adaptor will be included in this list, if it has been enabled.

Therefore, it may be necessary to perform these calculations manually for the other network cards.

Note: The following calculation can calculate the incoming (or outgoing) bandwidth for each network card of the monitored computer in kilobits per second.

If necessary, locate the required agent, as follows:

 

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit Analog Agent dialog:

  1. In the Device Span (raw) group, set the Maximum value to 10000000000000.
  2. In the Engineering Span (eng) group, set the Maximum value to 78125000000 and click the OK button.

Add and/or Edit a Statistical Agent and in the Edit Statistical Agent dialog:

  1. In the Input Tag edit box, click the browse button to the right of this and select the VALUE slot of the Analog agent that was added in step 1. For details, see Selecting a Tag Using the Agent Explorer.
  2. Click the Start button and then click the OK button.

Add and/or Edit an SNMPManager agent and in the Edit SNMPManager Agent dialog:

  1. Ensure that this agent can connect to the required computer. For details, see Connecting to the Managed Device or see SNMPManager Agent Usage Requirements for potential issues when monitoring computers.
  2. Click the Browse OID to add  button to display the SNMP Objects Browser dialog, if the connection settings are correct.
  3. Select the Browser tab and browse for the OIDs (values) of the required network bandwidth that you want to monitor. For details, see Browsing for SNMP Objects.

To monitor the incoming bandwidth, expand the tree to expose this OID: interfaces.ifTable.ifEntry.ifInOctets.

To monitor the output bandwidth, expand the tree to expose this OID: interfaces.ifTable.ifEntry.ifOutOctets

  1. Once this branch has been expanded, select the node number that corresponds to required network card and click the Add to list button.

Note: Node 1 is not a network card and should not be selected.

Tip: To establish which network card corresponds to a node number, examine the values that are exposed by the following OID: interfaces.ifTable.ifEntry.ifPhysAddress, which displays the MAC addresses of the cards associated with each node number.

To verify the MAC address of a card, enter 'ipconfig /all' in a command prompt (DOS window), on the required computer, and look at its specified 'Physical Address' value.

  2. Select the Enable Polling option (BOOLEAN start slot) to start managing this device, by polling (getting), writing (setting) and/or trapping (enabling events) of its OIDs. For further details, see Global Device Management Settings.
  3. Display the rate slot of the edited Statistical agent, to display the selected network bandwidth in kbits/s for the specified network card.

Tip: The first few values displayed by this rate slot will not be accurate, as the Statistical agent needs to obtain a number of samples first, before it can calculate the correct value.

  1. Repeat this procedure, as necessary.

Note: If any network card (or Microsoft Loopback Adaptor) is disabled, while the computer is being monitored, this will remove its associated node from the SNMP tree, which will prevent the monitoring of the network bandwidth for this node and possibly the others too.

Technical explanation of this calculation:

  1. The network bandwidth is an accumulative value of the number of bits that are either received (incoming) or sent (output) from the specified network card.

Therefore, its current value must be calculated by subtracting it from the previous value, which is performed by the rate slot of the Statistical agent.

  1. These bits are recorded as octets and so need to be multiplied by 8 before this value displays the number of bits, then the value needs to be divided by 1024 so that it is displayed as kilobits.

The Analog agent performs this conversion, since its Device Span (raw) Maximum value of the Analog agent is set to 10000000000000, to ensure that this value will not be exceeded.

Its Engineering Span (eng) Maximum value is set to 78125000000, because this is the Device Span Maximum value multiplied by 8 and divided by 1024.

  1. This value must then be calculated over time to give you the value per second. This is why the rate slot of the Statistical agent needs to be displayed
