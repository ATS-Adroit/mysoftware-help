Selecting SNMP Objects

The SNMPManager agent is able to get and/or set SNMP managed objects (each of which is an OID) from a single device on the network. The SNMP Objects Browser can specify the required OIDs. Click for more details:

Note1: You need to connect to the device to use this SNMP Objects Browser.

Note2: You need to Enable polling before you can use this SNMP Objects Browser.

Note3: If you cannot connect to the device then you can add OIDs manually. For details, see Adding OIDs Manually.

Note4: Not all devices allow you to browse their OIDs.

Launch the SNMP Objects Browser:click the Browse OID to add button in the Edit SNMP Manager Agent dialog.

Note: A message box is displayed if the agent cannot connect to the device, indicating that the connection is invalid.

The SNMP Objects Browser contains 2 tabs, each of which provide a different view of the values contained within this device, as follows:

  • General: This tab provides a collection of commonly used statistics for device management. Although some of these items are individual OIDs, others are calculations using the values of one or more OIDs. For more details, see Selecting General SNMP Objects.

Note: You CANNOT write to items you select from the General tab.

  • Browser: This tab can browse for device-specific OIDs from the device's MIB hierarchy. For more details, see Selecting Browsed SNMP Objects.

Note: You can read/write to OID values that you select from the Browser tab.
