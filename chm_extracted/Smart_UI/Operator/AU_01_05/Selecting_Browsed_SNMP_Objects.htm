Selecting Browsed SNMP Objects

The Browser tab of this SNMP Objects Browser selects device-specific OIDs.

Note: You CAN read and/or write OIDs that you select from this tab.

This retrieves the MIB of this device and displays "Tree build in progress ..." at the top of the tree view while this occurs. When the MIB has been retrieved this text is replaced by the title: Available Objects.

To select an OID from the Browser tab:

  1. Ensure that the Browser tab of the SNMP Objects Browser dialog is selected.
  1. Expand the branches in the Available Objects tree to expose the required OID.

Tip: Double-clicking a branch will expand its sub-branches, if any.

If "Tree build in progress ..." is displayed at the top of the tree view and the tree does not display the required object, then click the Refresh Tree button to manually refresh this tree view until it is displayed.

  1. Click on the required object to display its details, in the following fields:
    • Object-identifier (OID): This specifies the name of the selected OID in numeric format. For further details, see OID Naming Formats.
    • Name: Typically this should correspond to the literal name of the OID, however due to the latest standard in displaying OIDs, this may only be a partial description of the international MIB database tree.
    • Return type: The type of data that is returned by the value of this SNMP object. If you intend writing to this value, please ensure that this return type CAN be written to. For details, see: SNMP Object Value Return Types.
    • Description: This is identical to the Name field, except that its text is wrapped, so that the full textual description of this object can be viewed.
    • Value: This obtains the value of this SNMP object within the specified SNMP device.

    Tip: Click the Update Object button to view the most recent value of the selected OID.

     

Tip: Use the information displayed in these fields to determine if the selected OID is correct.

  1. Click the Add to List button to add the highlighted OID to the selected OID list of this SNMPManager agent.

Tip: Double-clicking an SNMP object immediately adds it to the selected OID lists.

If the device is upgraded after the tree was last built, then click the Rebuild Tree button. For instance, when monitoring a computer then rebuild this tree when additional hardware is added to this computer, such as a loop-back adapter.
