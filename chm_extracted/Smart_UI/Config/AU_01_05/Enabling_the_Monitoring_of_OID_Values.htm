Enabling the Monitoring of OID Values

The SNMPMgr agent can poll (monitor) OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. values from the managed device.

Each OID value that you want to monitor is retrieved from the device at the required poll rate and copied into the selected tag, so that this tag can be alarmed, trended (reported), logged and/or manipulated etc. within Adroit.

Note: You can also manually poll (obtain the value of) ANY OID value in the device. For details, see Manually Polling OID Values.

To enable the polling of a selected OID value:

This assumes that the Edit SNMPMgr Agent dialog is displayed and the required OID is in the list.

  1. Click the Name field of the required OID to select this row in the list.
  2. Click the Browse tag button and use the built-in agent explorer to create and/or select the Tag that will contain this value. For details, see Select a Tag Using the Built-in Agent Explorer.

Note: Ensure that the selected agent type can store the data of this OID value. For help on this, see SNMP Object Value Return Types.

  1. Click the E field of this row to place a tick in this tick box.

This only indicates that you want to enable automatic polling for this value.

  1. By default, this value is polled at the global Poll rate for this agent. If this value changes faster or slower than the global rate then use the Rate field of this row to specify this specific rate in milliseconds (you may need to enlarge this dialog to see this field or use the horizontal scroll bar to do this).

Note: The specific poll rate allows you to specify a rate faster than 5 seconds (the limitation of the global rate) and is ONLY used if it is greater than 0.

  1. Ensure that you either click the Update or OK button BEFORE clicking the Refresh button; otherwise these configuration changes will be lost.

This value will only be retrieved from the device, once you select the Enable polling option (BOOLEAN start slot) in the Poll settings section of this agent, at which point a single scan point license is consumed for this service and the Current Value field is updated when you refresh this dialog at the applicable poll rate.
