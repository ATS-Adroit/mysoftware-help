Disabling Simplified File Sharing

By default Windows XP, VISTA and Windows 7 enables simplified file sharing. This setting must be DISABLED on clustered Agent Server computers because it interferes with the inter-communication between the clustered Agent Servers by making incorrect assumptions regarding this communication.

If this setting is ENABLED on a clustered Agent Server computer then under certain conditions one of the cluster partners does not see/detect the presence of its cluster partner. 

In other words, one cluster partner detects both Agent Servers, while the other detects only itself. This causes the master-standby switchover to fail, resulting in an unstable cluster configuration.

How to disable this simplified file sharing setting:

  1. Open Windows Explorer. (Click the Start menu, Programs, Accessories and Windows Explorer item.)
  2. Open the Tools menu.
  3. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Folder Options…

Example:

  1. In the Folder Options dialog, select the View tab.
  2. Scroll to the bottom of the Advanced settings list.
  • For Windows XP:

Ensure that check box next to the Use simple file sharing (Recommended) setting is empty.

Example:

If this is not empty, then click it to clear the tick.

  • For VISTA and Windows 7:

Ensure that check box next to the Use Sharing Wizard (Recommended) setting is empty.

Example:

If this is not empty, then click it to clear the tick.

  1. Click the OK button.
