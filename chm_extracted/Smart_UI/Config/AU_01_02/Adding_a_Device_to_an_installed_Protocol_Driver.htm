Adding a Device to an installed Protocol Driver

Using the Adroit SmartUI Config:

Launch the Adroit SmartUI Config.

  1. Click Agent Server Configuration in the right hand pane.
  2. Click Driver Configuration in the right hand pane.
  3. Double click the required Protocol Driver () in the Installed Drivers and Devices list.

This displays a dialog to specify the required name for this device, as follows:

Specify a unique, 8-character legal name for the device e.g. you may not have a SIE3964R device 'BOILER1' as well as a MODBUSI device 'BOILER1'.

Note1: The specified device name may not contain any illegal filename characters, such as .%\,$/*?<>:"’`=| etc. It is also recommended that this device name describe the function or location of the device being communicated to.

Note2: A total of 65534 devices may be added and used for any one installed protocol driver.

This device is a logical connection for an installed protocol driver and is not only configured here in the Adroit Setup utility, but also as a Device agent in the Agent Server.

On clicking OK, either the Drivername:DeviceName configuration dialog for the selected protocol driver is displayed, where Drivername is the name of the selected protocol driver and DeviceName is the name supplied in the previous dialog or a warning is displayed, informing the user that a configuration function does not exist for the selected driver.

Note1: Apart from the generic help concerning this configuration dialog, click the Document button, if enabled, to open the installed documentation for the selected protocol driver, which describes the configuration of this dialog in detail.

Note2: This protocol driver configuration is saved in the system registry; therefore it is necessary to reconfigure the devices if they are to be run on another computer.
