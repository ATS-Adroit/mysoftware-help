Configuring Automatic WGP File Backups

Adroit WGP files can be automatically backed up when they are saved to ensure that at most only the changes made since the last save will be lost.

WARNING! This feature is merely intended to AUGMENT the existing backup system and NOT to REPLACE it i.e. it is still imperative that an efficient backup system is in place! For details, see Creating Backup Procedures.

Note: These backup files will be created in the folder in which the WGP file resides, EACH time it is saved, regardless as to whether its contents have been changed or not.

To configure automatic WGP file backups

Using the Adroit SmartUI Config:

Launch the Adroit SmartUI Config.

Click Agent Server Configuration in the right hand pane.

Click Advanced Agent Server Configuration in the right hand pane.

This displays a page of grouped advanced Agent Server settings.

The following settings are contained within the WGP Versioning group:

  1. These files are created when the WGP file is saved for the period of time specified by the Delete WGP backup files older than # days edit box, where # is the required number of days.
    The default period is 90 days and any backup WGP file older than this time will be deleted every time the WGP file is saved.

Tip: It is recommended to set this value to the period of your existing Adroit backups, so as to avoid backup duplication.

Note: A value of 0 will disable this feature and remove all the backup files on the next save.

  1. The minimum number of backup files that will always remain can be specified using the … but keep a minimum of # backup files edit box, where # is the required number of files.
    This should be used as a failsafe to prevent ALL the previous backups from being deleted if the WGP file is saved after the period specified by the Delete WGP backup files older than # days edit box has elapsed.
    The default minimum number of files is 3, which ensures that the folder will always contain the 3 most recent backups.
  2. The total number of backup file that are created can be limited, by specifying the required number in the … and a maximum limit of # files edit box, where # is the required number of files.
    In this way it is possible to regulate the amount of disk space that is used for these backups. The default number of files is 10, after which the oldest backup file will be deleted each time the WGP file is saved.

Note: A value of 0 will remove this limitation, so that a separate backup file will be created each time the WGP file is saved for the specified number of days.

 

For further details, such as the naming format of these automatically created backup copies, see Automatic WGP File Backups.
