Standards used throughout the Help make it easy for you to recognize references and text used for emphasis or functionality.

The way in which information appears in the text can indicate something about the information itself. The style of the text and the font used lets you know the type of information being displayed.

bold text

Indicates any named item in the user interface and may also be used to add emphasis to important words within a sentence.

For instance the names of dialog boxes and their controls (edit fields, buttons and list boxes and their items); menus and their options etc.

CAPITALIZED TEXT

Indicates the names of keys and is also used to add emphasis to important words within a sentence.

Press CTRL + Z to undo the last action

Indicates hotkeys and combinations of keys you press at the same time.

This example tells you to hold down the CTRL key and press Z.

C:\MyPath\MyFile.ext

Indicates paths and file names.

Note:

A note draws attention to pieces of information that should stand out.

Tip:

A tip provides useful, additional information—such as a time-saving suggestion.

WARNING!

A warning provides information that might help you avoid problems, such as loss of data.

maroon text

Indicates and calls attention to the text of notes, tips and warnings.
