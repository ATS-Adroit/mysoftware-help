Smart UI Operator customization

User profiles can customize the default display and permitted user interaction within the Smart UI Operator window.

Note: You can also specify default Smart UI Operator settings are applied before a user logs on. For details, see Default Operator user interface settings or Operator command line arguments.

To customize the Smart UI Operator display and user interaction:

  1. In the Smart UI Designer, create a profile or edit the profile that applies to the current user.

Tip: Any user not associated with a profile has the Default profile applied to them.

  1. In the Profile Configuration dialog, select the Operator Settings dialog, from the left pane.
  1. Select the required setting to highlight the row and then configure this setting.

Tip: It is also possible to double-click either the setting name or its value cell to expand or highlight numerical values selections or select the next value within the lists.

    Edit: for Adroit datasources ONLY, this option opens the Adroit Agent Configurator with this tag (agent) selected (if it can be found), so that it can be edited.

Note: Since this option ONLY applies to Adroit datasources and even then the editing of tags in the Smart UI Operator poses a security risk, so the display of this option is controlled via the AllowEditTags Boolean setting of the Operator Settings page of the profile dialog, which is False (hidden) by default.

Customizable Smart UI Operator settings and their required configuration

  1. AllowEditTags: this setting applies, when linking tags from Adroit datasources to controls and vectors of graphic forms. In this case, this option determines whether your Operator users have the ability to edit the exposed Adroit tags, which are displayed either through the use of Show (All) Information or the Bad tag status indicators. For details on these tag exposing mechanisms, see Working with Show (All) Information and Bad tag status indicators.

    IMPORTANT: This option is disabled (False) by default, due to the security risk posed by allowing your operators to edit tags on the fly.

  2. AlwaysOnTop: to enable or disable the initial display of the Smart UI Operator window to be above all other applications. By default this is disabled (False).
  3. CanClose: to allow users to close the Smart UI Operator window (True) or not (False).

Configuration:

Click the drop-down list box button at the right of this field and select the required value.

Note: If the user CANNOT close the Smart UI Operator window, the close button will still appear in the top left hand corner but will not work.

  1. DefaultGraphicFormLevel: to select which level is initially displayed by the graphic form, specified by the DefaultGraphicFormPath setting.

Configuration:

Type in or paste (right click and select Paste) the required level name or leave this field blank to select the first level, as usual.

Note: If the specified level does not exist in this graphic form, then the first level is selected.

  1. DefaultGraphicFormPath:to select the default graphic form that is displayed when the Smart UI Operator window opens.

Configuration:

Click the browse button at the right of this field to launch the Graphic Form Selection configuration dialog to locate this graphic form from its required project within the correct Server or leave this field blank.

  1. DefaultGraphicFormTemplateSet: to select which template set is initially activated in the graphic form, specified by the DefaultGraphicFormPath setting.

Configuration:

Type in or paste (right click and select Paste) the required template set name or leave this field blank to select the "Default" template set, as usual.

Note: If the specified template set does not exist in this graphic form, then the "Default" template set is selected.

  1. FullScreen: to display the title bar at the top of the Smart UI Operator window (False) or not (True).

Configuration:

Click the drop-down list box button at the right of this field and select the required value.

  1. ShowContextMenu: to allow users to display the right-click menu in the Smart UI Operator window (True) or not (False).

    Note: This menu can close the Smart UI Operator window, configure its always-on-top property and toggle the Operator mode i.e. to hide or display the Levels and Layers window.

Configuration:

Click the drop-down list box button at the right of this field and select the required value.

Note: If this setting is disabled, this ALSO disables the Ctrl+0 and Ctrl+T shortcuts to entirely prevent this menu from being displayed in the Smart UI Operator.

  1. ShowMaximize: to allow users to maximize the Smart UI Operator window (True) or not (False).

Configuration:

Click the drop-down list box button at the right of this field and select the required value.

  1. ShowMinimize: to allow users to minimize the Smart UI Operator window (True) or not (False).

Configuration:

Click the drop-down list box button at the right of this field and select the required value.

  1. StartupBorderStyle: to specify the window type used for the graphic forms, which determine how users can interact with each graphic form window.

Configuration:

Click the drop-down list box button at the right of this field and select one of the following styles:

Note: Each style has its own pre-set properties, experiment with these styles as necessary.

  • FixedSingle: This has a title bar and frame, therefore you are able to close, move, minimize or maximize this window, although you are unable to resize it.
  • Fixed3D: Similar to FixedSingle, except that it has a 3D frame, which makes its contents seem sunken.
  • FixedDialog: Similar to FixedSingle, except that its a dialog.
  • Sizable: Similar to FixedSingle, except that you are also able to resize this window.
  • FixedToolWindow: Similar to FixedSingle, except its a dockable window that you are unable to resize.
  • SizableToolWindow: Similar to Sizable, except that its a dockable window.

  1. StartupLocation: to MANUALLY set the location of the Smart UI Operator window on the screen, by specifying the required position of the top left corner of the window in pixels.

    Tip: The StartupWindowPosition setting provides preset system-dependent startup positions.

Configuration:

These pixel measurements are measured relative to the top left corner of the screen.

The first digit specifies the leftmost (X) position and the second the topmost (Y) position.

Either specify both positions separated by a comma or expand this setting and specify these positions separately.

Note1: Only integer values can be used when specifying these positions.

Note2: This setting is overridden if the StartupWindowPosition setting is NOT set to Manual.

  1. StartupSize: to set the maximum dimensions of the Smart UI Operator window on the screen, by specifying the required window size in pixels.

Configuration:

These pixel measurements are relative to the size of the screen.

The first digit specifies the width of the window and the second digit specifies its height.

Either specify both dimensions separated by a comma or expand this setting and specify these dimensions separately.

Note: Only integer values can be used when specifying these positions.

  1. StartupWindowPosition: to set the location of the Smart UI Operator window on the screen, by selecting one of the preset system-dependent startup positions.

Configuration:

Click the drop-down list box button at the right of this field and select one of the following preset system-dependent startup positions:

  • Manual: This is the default option, which uses the StartupLocation setting to determine the location of the Smart UI Operator window on the screen at startup.
  • CenterScreen: This option overrides the StartupLocation setting and positions the Smart UI Operator window in the centre of the screen.
  • WindowsDefaultLocation: This option overrides the StartupLocation setting and cascades the Smart UI Operator window at the Windows default location on the screen.
  • WindowsDefaultBounds: This option overrides the StartupLocation setting and positions the Smart UI Operator window at the Windows default location on the screen and has its bounds determined by the Windows default.
  • CenterParent: This option overrides the StartupLocation setting and positions the Smart UI Operator window in the centre of its parent form, which is not applicable in this case.

Note: These startup positions, with the exception of Manual, typically use the currently selected active monitor (monitor with the mouse cursor) when dual monitors are being used, which is determined by the windows video driver.

Tip: It is recommended that this setting either be set to Manual (default) or CenterScreen.

  1. StartupWindowState: to select the initial state of the Smart UI Operator window - in other words should this window be maximized, normal or minimized.

Configuration:

Click the drop-down list box button at the right of this field and select the required state.
