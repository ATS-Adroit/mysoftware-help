Launcher connection settings

This page of the Setting up the Launcher component of the Adroit SmartUI Config configuration dialog, creates the customized or pre-configured Smart UI Launcher package that provides the necessary connection details to connect to your Smart UI Distribution service:

To display this page of settings:

  1. Launch the Adroit SmartUI Config.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Launcher option.
  1. Select the Connection Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit SmartUI Config configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

This page is divided into the following three sections:

  1. The type of network used to connect the Distribution computer to your clients.
  2. The network identification and login to the Distribution computer.
  3. Additional configuration options and the Apply button that creates the customized Launcher executable.

 

You can either connect to the Web Service using:

  • LAN or WAN
  • Internet, if this is selected then you can specify the required proxy server settings, as follows:
  1. Check the Enable Proxy checkbox.
  2. Then either specify the Machine Name or IP address and Port used by your proxy server.
  3. If necessary, provide the required User and Password for your Proxy Authentication Details.

 

Specify the name of the required Computer name or the URL required to connect to the Web Service:

If necessary, provide the required User and Password for your Authentication Detailsfor this computer.

Tip: Click the Test Connection button to check that you are able to connect to this computer using the specified information.

 

  1. If necessary, the Launcher installation can prompt for its required extraction path, by default this is: C:\Program Files\Adroit Technologies\Adroit\SmartUI
  2. If necessary, you can automatically run the Launcher after extraction - by default this option is checked.
  3. Click the Apply button to create your customized Smart UI Launcher executable, which is called VIP Launcher Setup.exe and is created in the Smart UI Web Service installation folder (C:\Program Files\Adroit Technologies\Adroit\SmartUI\Webservice).
