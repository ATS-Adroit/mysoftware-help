Server security settings

The Smart UI security system is user-centric and operates on top of the traditional Windows operating system security.

This uses a configurable sub-set of the existing users and groups that are "allowed" on each Smart UI Server computer and are hence known as the Allowed users and groups.

For details, see Working with security.

This page of the Setting up the Server component of the Adroit SmartUI Config configuration dialog, provides the following settings that configure which Windows users and groups are given default access to the Smart UI Server and the services it provides:

Click for more information:

WARNING! Careful consideration should be given to which users and groups are specified. For further details, see Assigning global security to groups and users. 

Note: When the Server is deployed on a domain with a large number of users and/or groups, this page will take a long time to be displayed while the user and group lists are populated. For details on reducing or eliminating this delay, see Specifying user and group subsets.

 

To display this page of settings:

  1. Launch the Adroit SmartUI Config.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Server option.

Note: If this option does not appear then the Smart UI Server may not be installed.

  1. Select the Security Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit SmartUI Config configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

To enable 21 CFR 11 mode:

When engineering and commissioning a system, the system is not required to comply with 21 CFR 11, it is only once the system is deployed that 21 CFR 11 compliance is required.

Therefore, you should ideally engineer your project, with 21 CFR 11 mode disabled, due to the design-restrictions that it imposes and then just before you start commissioning the project you can enable and configure the 21 CFR 11 mode. For more details of the controls and requirements required by 21 CFR 11, see 21 CFR 11 controls and requirements.

Select the Yes option for the Title 21 CFR Part 11 Compliance option at the top of this page and provide the required password.

This password secures the connection to the Adroit Agent Server and also prevents the unauthorized disabling of this 21 CFR 11 setting itself.

IMPORTANT: If you forget your password then you MUST DELETE ALL your config files and project files and start again from scratch.

Note: When running an Adroit Agent Server and a Smart UI Server on two separate computers, BOTH computers must be configured for 21 CFR 11 mode using the SAME password.

This password is encrypted and stored in the configuration (.config) files on the Smart UI Server computer.

Since 21 CFR 11 requires that system access be limited to authorized individuals, access to these configuration files need to be limited through the use of directory and file level security.

Note: You can only change or disable this setting by providing the specified password.

To use an optional SQL Server database to store the audited entries: you can specify a (remote) database in addition to the mandatory, local SQL Server Compact database that stores the auditing locally on the relevant Smart UI Server computer.

Select the Yes option for the Auditing question at the top of the Server Security Settings page of Adroit SmartUI Config.

This displays the Connection String field in which you specify the connection string to this optional SQL Server database.

Either type/paste this in directly or by click the browse button to the right of this field and use the Connection Properties dialog to specify the required connection string to the SQL Server database.

Typically do NOT change the Data source from the default of .NET Framework Data Provider for OLE DB, unless you are connecting to a SQL Compact database. More details: in which case, click the Change... button and choose the datasource that corresponds to the correct version of SQL Compact and then the dialog will change so that you only need to browse in the required database file and specify the required password, if any.

Network location of users and groups: if the Smart UI Server computer is part of a domain then this setting must specify the name of this network domain.

Note: When a domain is specified - all users logging into this Smart UI Server must use their domain passwords and not their local user names and passwords (if these exist).

However, if the Server computer is a member of a Workgroup, then this setting must be left empty.

To specify the network location of the users and groups for the Server computer: Type in the required domain name or leave this empty if the Server is not part of a domain.

This setting determines which users and groups are displayed by the user and group selectors for the other settings, as follows:

  • If this setting is empty then the selector will display the local groups or users that have been created on this Server computer.
  • If this setting specifies a domain, then the selector will display the groups or users that are available in this domain.

Note: Click the Refresh button after changing this setting, so that the correct users and groups will be displayed in these selectors.

Groups with global Server access: select which groups automatically become allowed groups for this Smart UI Server, which means the following: that their users can always log in and have unrestricted access to this Smart UI Server and its data.

To add global security groups:

  1. Select the name of the required group from the Available Groups list.
  2. Click the << button to add this group to the Selected Groups list.

Tip: You can also add groups by double-clicking the required entry in the Available Groups list to immediately add it to the Selected Groups list.

Note: Only the groups listed in the Selected Groups list have global Server access.

  1. Repeat this for all the groups that you want to add.

To remove global security groups:

  1. Select the name of the required group from the Selected Groups list.
  2. Click the >> button to add this group to the Available Groups list.

Tip: You can also remove groups by double-clicking the required entry in the Selected Groups list to immediately add it to the Available Groups list.

  1. Repeat this for all the groups that you want to remove.

Users with global Server access: select which users automatically become allowed users for this Smart UI Server, which means the following: that they can always log in and have unrestricted access to this Server and its data.

 

To add global security users:

  1. Select the name of the required user from the Available Users list.
  2. Click the << button to add this user to the Selected Users list.

Tip: You can also add users by double-clicking the required entry in the Available Users list to immediately add it to the Selected Users list.

Note: Only the users listed in the Selected Users list, will have global Server access.

  1. Repeat this for all the users that you want to add.

To remove global security users:

  1. Select the name of the required user from the Selected Users list.
  2. Click the >> button to add this user to the Available Users list.

Tip: You can also remove users by double-clicking the required entry in the Selected Users list to immediately add it to the Available Users list.

  1. Repeat this for all the users that you want to remove.

One aspect of Smart UI Server security are policies, which provide high-level control to safeguard the services and data that the Smart UI Server provides.

Only the users and groups associated with a specific policy or Smart UI Server service can use this service. For further details, see Working with policies.

Groups initially able to use Server services: if necessary specify one or more ADDITIONAL groups that can use every policy (service) of this Smart UI Server, by default.

Note The groups and users that have GLOBAL Server access are ALREADY able to use all the Server services (policies) and should NOT be specified again.

To add initial service usage groups:

  1. Select the name of the required group from the Available Groups list.
  2. Click the << button to add this group to the Selected Groups list.

Tip: You can also add groups by double-clicking the required entry in the Available Groups list to immediately add it to the Selected Groups list.

Note: Only the groups listed in the Selected Groups list, will have global Server access.

  1. Repeat this for all the groups that you want to add.

To remove initial service usage groups:

  1. Select the name of the required group from the Selected Groups list.
  2. Click the >> button to add this group to the Available Groups list.

Tip: You can also remove groups by double-clicking the required entry in the Selected Groups list to immediately add it to the Available Groups list.

  1. Repeat this for all the groups that you want to remove.
