Designer scripting settings

This page of the Setting up the Designer component of the Adroit SmartUI Config configuration dialog, provides the following settings that determine the default scripting environment for this Smart UI Designer :

To display this page of settings:

  1. Launch the Adroit SmartUI Config.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Designer option.

Note: If this option does not appear then the Smart UI Designer may not be installed.

  1. Select the Scripting Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit SmartUI Config configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

Default script references: specify the list of external assemblies or dynamic linked library (.DLL) files that are automatically added to each script.

Note: The longer the list of references, the longer it takes to load and compile every script.

Tip: This setting allows 3rd party users to expose their product-specific assemblies (DLLs) to all their scripts.

To add a default script reference: Click the Add button and browse for the required assembly.

Note: Ensure that the paths of all of these files are added to the Script references paths setting so they will be located.

To remove a default script reference: Select the assembly that is no longer required and press the Remove button.

WARNING! The reference to the selected assembly is immediately removed, so ensure that you select the required assembly.

Graphic form scripting: to enable or disable the ability to script event handlers to programmatically achieve a more interactive user experience for graphic forms. For further details, see Graphic form scripting.

Note: If this functionality is not required then disable it to increase the speed of loading graphic forms.

To configure graphic form scripting: Either select Yes to enable or No to disable this setting.

Visual Studio debugging: if you have Visual Studio 2010 or later installed, then you can use this application to edit and debug your scripts instead of the generic script editor, which only provides limited debugging functionality.

To debug your scripts using Visual Studio: Either select Yes to debug your scripts using Visual Studio or No to use the generic script editor.

Note: When debugging your scripts in Visual Studio, the scripts are exported to the ScriptsExport subfolder of the Smart UI ProgramData folder (typically C:\ProgramData\Adroit Technologies\Adroit\SmartUI\ScriptsExport) in a Visual Studio-compatible format.

Search paths for script references: specify additional paths that contain the assemblies (.DLL files) that are referenced by your scripts. For further details regarding script references, see Managing references.

WARNING! Only specify the locations to assemblies (.DLL files) that you use frequently, since an extensive list will delay the loading and compilation times of all scripts.

To add a path that is to be searched: Click the Add button and browse for the required folder.

To remove a path from the list: Select the path that is no longer required and press the Remove button.

WARNING! The selected path will immediately be deleted, therefore ensure that the required path is selected.

Note1: The installation folder and its subfolders are searched by default and so do NOT need to be added to this list.

Note2: It is NOT recommended that these locations exist on different computers due to many hindrances, such as security problems and time delays.

 

This page only configures the part of the essential Smart UI Designer settings. For details, see Setting up the Designer.

For details on displaying all the related Smart UI Designer settings, see the Advanced Designer settings page.
