Designer login settings

This page of the Setting up the Designer component of the Adroit SmartUI Config configuration dialog, provides the following settings that specify the login credentials and configuration for the default user of this Smart UI Designer:

To display this page of settings:

When the Smart UI Designer is launched, it needs to log into a Smart UI Server computer, which stores the data configured within the Smart UI Designer.

  1. Launch the Adroit SmartUI Config.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Designer option.

Note: If this option does not appear then the Smart UI Designer may not be installed.

  1. Select the Login Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit SmartUI Config configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Default login user name: specify the name of the most prevalent user of this Smart UI Designer, which the login dialog always displays.

To specify the default login username: If necessary, type the required name into the provided edit box.

Note: Ensure this user name is correctly spelt, otherwise it needs to be manually corrected before this, user can login.

Automatic login of the default user: in a single-user or non-secure environment, you can save time launching the Smart UIDesigner, by having the necessary login details automatically specified.

To configure automatic login: Either select Yes to enable or No to disable this setting.

WARNING! Since this setting bypasses Smart UI security, this setting is only recommended when security is not important, such as when one user uses this Smart UI Designer exclusively.

However, this facility can prevent users of the Smart UI Designer from knowing the password of their login user account on the Smart UI Server.

Tip: You can also specify login profiles that store different sets of login settings.

Default user password: if automatic login is enabled then specify the password of the selected user account.

Note: This password is stored in an encrypted format; so specifying this password should not pose a security threat.

To specify the password of the default user: Type in the required password in both the edit boxes and then press the Set Password button, which encrypts the specified password.

Note: Please ensure that both the case and spelling of this password is correct.

Display of automatic login checkbox: in a security-conscious environment, you can completely hide the automatic login option from your users, so it cannot be configured.

To configure the display of the automatic login option: Either select Yes to enable or No to disable this setting.

Note: Hide (disable) this setting when the Designer has more than one user to ensure the security of Smart UI.

 

This page only configures the part of the essential Smart UI Designer settings. For details, see Setting up the Designer.

For details on displaying all the related Smart UI Designer settings, see the Advanced Designer settings page.
