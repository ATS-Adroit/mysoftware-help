Setting up the Server

This part of the Welcome section of the Adroit SmartUI Config configuration dialog simplifies the essential configuration of the Smart UI Server.

These fundamental Smart UI Server settings are grouped according to their purpose and are presented as a series of questions on the following pages:

  1. General Settings: important miscellaneous Smart UI Server settings.
  2. Directory Settings: specify where the various Smart UI Server constituents are located.
  3. Backup Settings: manage the saving and backup of the Smart UI Server data.
  4. Security Settings: determine which Windows users and groups are given immediate access to this Smart UI Server.

Note: This page only configures the essential Smart UI Server settings. For details on displaying all the related Server settings, see the Advanced Smart UI Server settings page.

To display this page of settings:

  1. Launch the Adroit SmartUI Config.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Server option from this page.

Note: If this option does not appear then the Smart UI Server may not be installed.
