Advanced settings page features

The Advanced setting pages of the Adroit SmartUI Config configuration dialog provide the following features to display and configure their settings:

  1. A toolbar at the top, which can be used to alter how these settings are displayed, as follows:

Note: These are global viewing settings that apply to ALL the Advanced setting pages.

  1. Categorized: the default selection, which groups the settings into a number of expandable and collapsible categories.

    Each category representing a component of the selected application. The available categories depend upon the selected application or service. Click for more details:

These categories are listed alphabetically and can be expanded or collapsed to display or hide the associated settings, by clicking the gray plus box or minus box to the left of the category name respectively. 

Note: Any setting that does not have a default category, will be placed into the Misc (miscellaneous) category.

Tip: This display mode makes it easier for you to know which settings affect or belong to the required component of the selected item.

It is therefore recommended if you are unfamiliar with the application, whose settings you are configuring.se categories.

  1. Alphabetic: displays the settings in an alphabetical list.

Tip: This display mode is recommended if you are familiar with the application, whose settings you are configuring, as this makes it easier to locate the required settings by name.

  1. Beneath the list of settings is an information pane that displays the name and may also display a brief description of the setting that is currently selected.

Note: This information pane is separated from the settings by a splitter bar that can be used to adjust its relative size.
