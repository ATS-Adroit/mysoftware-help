Advanced Server service settings

This page within the Advanced section of the Adroit SmartUI Config configuration dialog allows the more advanced user to fully configure the Smart UI Server, when it is being run as a service within Windows, to ensure that it will not shutdown when you log off.

Click for more information:

Note: It is recommended to run the Server as an application, especially during the initial designing phase, to make use of the diagnostic features provided by the Activity Monitor. For details, see Working with the Activity Monitor.

Tip: It is recommended to use the Setting up the Server pages of settings, in the Welcome section, which simplifies the configuration of the essential Smart UI Server settings. For details, see Setting up the Server.

To display this page of settings

  1. Launch the Adroit SmartUI Config.
  2. Select the Service heading, which is beneath the Advanced heading in the tree view pane on the left. For details on navigating within configuration dialogs, see Working with configuration dialogs.

Note: If this heading does not appear then the component may not have been installed.

When this page is viewed in Categorized mode, these settings are displayed within a number of categories, some of which are:

  1. ConnectionSettings: settings that affect how the Smart UI Clients (Designers and Operators) connect to this Smart UI Server. 
  2. DataSources: settings that affect the datasources used by the Smart UI Server.
  3. Licensing: settings that affect how this Smart UI Server is licensed.
  4. Misc: unclassified settings.
  5. Profiles: settings that affect the profiles created upon this Smart UI Server.
  6. Projects: settings that affect the projects created upon this Smart UI Server.
  7. Scripting: settings that affect the scripts that run on this Smart UI Server.
  8. Security: settings that affect the security settings for this Smart UI Server.
  9. Server: settings that specific to this Smart UI Server.

Note1: For details on configuring these viewing modes and the other features provided by this page, see Advanced settings page features.

Note2: The onus rests upon the user to provide the correct values when modifying settings, therefore if you are unsure about a setting, use the existing default value instead.
