Working with the Adroit SmartUI Config

The Adroit SmartUI Config can customize the installed applications and/or services by modifying their default settings, some of which are contained in each .CONFIG fileThis .NET file is similar to an .INI file, in a single .CONFIG file is used per application to contain its user-configurable settings. This text file is located in the installation folder and has the same name as its application.. Click for more details:

These files are named according to their application or service and located in the installation folder (typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI). Although these text files can be manually edited, it is recommended to use this application for the following reasons:

  • It makes it easier to view, identify and configure these settings and prevents one from mistakenly modifying anything except their values.
  • It exposes the settings of all the .CONFIG files located within the installation folder, so that it is possible to configure one or more of these applications at a time. Instead of manually navigating to the installation folder and opening each file individually.
  • It also provides a concise description of each setting and can provide comprehensive help too, if necessary.

WARNING! Users who do not use this editor and who modify these .CONFIG files directly, do so at their own risk, since renaming or removing a setting may render an application inoperable and/or cause its functioning to be impaired.

Launch the Adroit SmartUI Config.

The configurable settings provided by the Adroit SmartUI Config are arranged as follows:

The following settings that affect all Smart UI applications are displayed in the lower left hand corner of the application alongside the version and the various buttons:

  • Language being used in applications: Select the required language from the list of available languages and click the Update button.
  • Theme: Select the theme from this list box, which determines how the user interfaces of all the Smart UI applications are displayed.

The other settings are classified into the following pages of related settings:

Note: Since this is a configuration dialog it provides the standard navigation and layout features common to all configuration dialogs. For details, see Working with configuration dialogs.

  1. The Configuration page, which can specify the currently active configuration that all the application settings pertain to. For details, see Working with Configurations.

    This contains the Welcome section, which simplifies the essential configuration of the main Smart UI components, namely the Server, Designer and/or Operator, depending on which components are installed. For details, see the Welcome section.

    1. Agent Server Configuration: this section configures the fundamental and advanced settings of the Adroit Agent Server and/or its protocol drivers.

      Note: This option ONLY appears when Adroit is installed.

    2. Setting up the Server: this section configures the fundamental general, directory, backup and security settings of the Smart UI Server.
    3. Setting up the Designer: this section configures the fundamental login, connections, user interface and scripting settings of the Smart UI Designer.
    4. Setting up the Operator: this section configures the fundamental login, connections, user interface and scripting settings of the Smart UI Operator.
    5. Setting up the Launcher: this section creates a custom Smart UI Launcher installation that is pre-configured to connect to your Smart UI Web service and Smart UI Distribution service.
    6. Setting up ClickOnce: this section creates a custom Smart UI ClickOnce installation (deployment) of your Smart UI Operator.

    7. System Backup and Restore: this section configures the settings required to backup and restore your Smart UI and/or Adroit user-configuration.

      WARNING: This should NOT be used to transfer project files to and from an engineering workstation.

  2. The Advanced section, in contrast, allows the more advanced user to configure all the settings of all the installed applications and/or services and so limited assistance is provided. For details, see the Advanced section.

The Adroit SmartUI Config also provides a number of command line settings, when launching this utility manually. For more details, see Config editor command line settings.
