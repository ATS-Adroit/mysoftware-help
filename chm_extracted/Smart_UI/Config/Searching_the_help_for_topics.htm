Searching the Help for Topics

The Search tab, on the left hand side of the help viewer, is a good way to find a topic title if you know it, as this looks through the online help to find topics that match the specified word(s) and/or phrase(s).

Tip: Use this if you know the EXACT PHRASE you are looking for. Otherwise this may return a long list of irrelevant topics, in which case use the Index tab instead.

To search the help for topics:

  1. Click the Search tab.
  2. Type the search query that you want to locate in one or more help topics into the edit box or click the list button and select a previously entered search query from this list box.

Basic searches: Guidelines or tips for creating the search query.

  1. Searches are not case-sensitive, so you can type your search in either uppercase or lowercase characters.
  2. You may search for any combination of letters (a-z) and/or numbers (0-9).
  3. Punctuation marks such as the period ("."), colon (":"), semicolon (";"), comma (","), and hyphen ("-") are ignored during a search.
  4. Group the elements of your search using double quotes or parentheses into phrases, where necessary e.g. (TermA TermB) or “TermA TermB”.

Note1: The default operation between terms is AND, so unless you specifically group terms into phrases then all instances of each individual word will be searched for.

Note2: You cannot search for quotation marks.

Note3: If you are searching for a file name with an extension, you should group the entire string in double quotes, ("file name.ext").

Advanced searches: Additional items that can be added to your search query to help you narrow your searches for more precise results.

  • Wildcard expressions: These can be used as placeholders for one or more characters, within your search query.
    1. Use a question mark (“?”) as a single-character placeholder e.g. 90?10, will return 90a10, 90610 etc.
    2. Use an asterisk (“*”) as a multiple character placeholder e.g. water*, will return "WATER", "waterfall", "waterproof" etc.

    Note: These wildcard operators cannot be the only character in a term.

  • Boolean operators: These can be used to create specific relationships between the phrases or words in your search query.
    1. TermA AND TermB: This will return topics that both contain TermA and TermB.
    2. TermA OR TermB: This will return topics that either contain TermA or TermB.
    3. TermA NOT TermB: This will return topics that contain TermA but not TermB.
    4. TermA NEAR TermB: This will return topics that contain TermA within eight words of TermB.

    Note1: If no Boolean operator is specified, AND is used i.e. TermA TermB = TermA AND TermB.

    Note2: The |, &, and ! characters do not work as Boolean operators (you must use OR, AND, and NOT).

  • Nested expressions: These allow you to create complex search queries.
    1. Use parentheses to nest expressions within a query. The expressions in parentheses are evaluated before the rest of the query.
    2. If a query does not contain a nested expression, it is evaluated from left to right.

    Examples:

    TermA NOT TermB OR TermC will locate topics, which contain TermA without TermB or topics containing TermC.

    TermA NOT (TermB OR TermC) will locate topics, which contain TermA without either TermB or TermC.

    Note: You cannot nest expressions more than five levels deep.

Note: If you are performing an advanced search and using one or more Boolean operators, click the button to select the required operators from the list.

  1. If necessary, ensure that the required search settings have been set before the search is performed:
  • To only search topic titles and not their contents, ensure the Search titles only checkbox at the bottom of the Search tab is ticked.
  • To find words similar to your search term, ensure the Match similar words checkbox at the bottom of the Search tab is ticked.
  • To narrow your search, ensure the Search previous results checkbox at the bottom of the Search tab is ticked.
  • To highlight all instances of search terms that are found in topic files, click the Options toolbar button and select Search Highlight On.

Note: To turn off this highlighting of words, select this menu item again and then perform the search again.

  1. Click List Topics, select the topic you want, and then click Display.
  2. To sort the list of topics, alphanumerically that have been found by this search, click the required column heading:
  • Title: The names of the located help topics.
  • Location: The name of the help file in which these topics have been located.
  •  Rank: The lower the number, the greater the number of occurrences of the required words and/or phrases.
