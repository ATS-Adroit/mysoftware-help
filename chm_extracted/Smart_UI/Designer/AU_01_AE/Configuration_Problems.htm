Configuration Problems

The most commonly experienced fault in the first-time use of any communications link is incorrect configuration. In many cases, a single resource is used to communicate to multiple devices.

Serial communications

When configuring serial communications of any type, be sure to specify the correct data and stop-bit settings if available for selection. If these settings are unknown, then the documentation for the remote device should be examined to find out the following information:

  • whether the settings are fixed and unchangeable
  • whether they exist as dipswitch settings
  • whether the devices are software configurable

In the case of dipswitches or software configuration, it may be necessary to re-start the device for the settings to take effect.

Because some of our older serial protocol drivers do not interpret error codes and translate them to English, I include a brief listing of serial communications error codes. These codes are separate from the Win32 codes. They can also be OR'ed together, and for that reason we supply the hex values here.

0x0001 = Receive Queue overflow

0x0002 = Receive Overrun Error

0x0004 = Receive Parity Error

0x0008 = Receive Framing error

0x0010 = Break Detected

0x0100 = TX Queue is full

0x0200 = LPTx Timeout

0x0400 = LPTx I/O Error

0x0800 = LPTx Device not selected

0x1000 = LPTx Out-Of-Paper

0x8000 = Requested mode unsupported

(e.g. An error value of 12 is equal to 8 + 4 which means "Receive parity" and "Receive framing" error.)

Networks

If the communications are via a protocol such as TCP/IP, NetBIOS or other LAN protocol, the resource may be connected to the existing office LAN. To eliminate the possibility of interference, a "private" network should be created to reduce the chances of poor network termination or excessive traffic causing problems.

Networking programs and Adroit protocol drivers rely on certain network drivers being operational before they can run. If this is the case, you will have to install any networking protocols required in the documentation. If the front-end computer is using one protocol, the Adroit scanning station must be running similar or compatible network layers before communication can be established.

To see which network software you have loaded in Windows, you must open the Network Connections in the Control Panel, select the existing network connection, right-click and select Properties, select the software component and network card in question in this dialog, and click on the Configure button. Also check that there are no disabled networking software components.
