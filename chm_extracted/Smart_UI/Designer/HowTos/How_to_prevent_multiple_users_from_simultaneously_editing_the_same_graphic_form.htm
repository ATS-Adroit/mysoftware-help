How to prevent multiple users from simultaneously editing the same graphic form

If multiple users or engineers develop graphic forms in project datasources, it is necessary to ensure that they cannot overwrite each others work by both accidentally editing the same graphic form at the same time.

To this end, it is necessary to use the data element security infrastructure, provide by SmartUI, to ensure that there is only one person who can write to a project at a time. The following configuration is required:

Initial Windows Security Setup

You need to ensure that each engineer logs in with his/her own unique user onto the SmartUI Designer. Furthermore, each of these users must have the necessary rights to modify the security settings on data elements for the project datasource.

In this case:

  1. Create windows users for each person who needs to edit graphic forms in the windows user management system tool.
  2. Create a new user group called ‘designer users’ and assign all the users you created in the previous step to this group.

For further details, see How to configure user security. [Click the Back button to return to this how to topic]

SmartUI Security Setup

Security data source configuration

  1. Open the Enterprise Manager window of the Designer.
  2. If necessary, expand the Management category and the Security item.
  3. Expand the Users and Groups branch and finally the Groups node.
  4. Drag the ‘designer users’ group containing all the users who will need access to edit the graphic forms from the All Groups node to the Allowed Groups node.
  5. Expand the Users tree node, which is also under the Users and Groups branch.
  6. Drag each user that will need to edit graphic forms from All Users to Allowed Users.

Figure 1 : SmartUI Security configuration

Project data source configuration

  1. Right click on the required Project datasource and select Security from the drop down menu.
  2. In the displayed dialog, select the ‘designer users’ group under the Available Groups list and click on the << button to add it to the Selected Groups list.
  3. With the ‘designer users’ item selected in the Selected Groups list, uncheck the Write Data and Remove Data checkboxes.
  4. Make sure the Apply to Children checkbox is checked. (This will result in these security settings being applied to all of the data elements belonging to this Project datasource).

Note: This will overwrite any security settings already defined on the graphic forms belonging to this project – if you don’t want this to happen, then apply this step to each graphic form individually.

  1. Make sure that there are no users or groups that have write access to the graphic forms of this project.
  2. Click on the Finish button to apply the security.

Figure 2 : Ensuring that users in the 'designer users' group cannot write to this project's graphic forms

  1. When a user needs to edit a graphic form, he will first need to give himself write access by adding his user to the Selected Users list and check the Write Data checkbox to obtain write privileges for the graphic form he needs to modify.
  2. When the user has finished editing and saved his changes, he can then remove his user from the security section (which will result in him getting normal read access security as part of the group security applied to the project)
  1. If all of the users designing graphic forms follow the same practice, they will see when someone else has write permissions to a graphic form, thereby preventing accidental overwriting of the graphic form.

Note: The user can still obtain write access to the form and make changes, but he will do so knowing that there is another user who also has write access to that form thereby reducing accidental overwriting of forms.
