How to connect to the Server over the Web

This describes the recommended procedure to connect Operators to a Server over the Internet, as follows:

  1. The SmartUI Web Service must be installed on a web server or ‘Internet PC, which provides Internet connectivity between the Server and its clients.
    Installing the SmartUI Web Service    .
  2. Since SmartUI Operators are typically deployed using the SmartUI Launcher application, the VIP Distributor service must be started on the SmartUI Server computer.
    Starting the SmartUI Distributor service    .

This is used together with the SmartUI Launcher application, as follows: 

Note: This also provides a good way of testing whether the Internet connectivity is working.

  • The VIP Distributor service identifies a "distribution" folder on its computer.
  • The SmartUI Launcher then connects to the computer that is running the VIP Distributor service and is able to download all files and folders that have been placed in the "distribution" folder and allows any downloaded executables to be launched.

Note: The SmartUI Launcher also ensures that these downloaded files are kept up-to-date with the files located in the “distribution” folder on the computer that it connects to.

  1. Test that the SmartUI Web Service is working locally, via the Intranet.
    Testing the Intranet connection to the SmartUI Server    .
  2. Test that the SmartUI Web Service is working externally, via the Internet.
    Testing Internet connection to the SmartUI Server    .
  3. A troubleshooting section is also provided to correct common issues preventing communication. Troubleshooting communication issues.

Installing the SmartUI Web Service

Install the SmartUI Web Service, either on the Server computer itself or on any other machine that is able to communicate to the Server computer. Provided this machine has BOTH the .NET framework (necessary for SmartUI to install) and Microsoft Internet Information Services (IIS) installed.

For the purposes of this scenario, this will be installed on a computer called “pserver”, which is running the firewall for the company. This is recommended so as to provide secure connectivity to the SmartUI Server.

  1. Insert the SmartUI installation media and wait for the autorun Setup menu to appear.
  1. Click the Install option.
  2. Accept the license agreement and click Next and Next again.
  3. Select the Custom installation option and click Next.
  4. Then ONLY select the Web Service component from the list of available components and click Next.

Note: You are unable to continue if you do not have IIS installed on this computer, then an error message is displayed and a valid installation option is selected instead.

The SmartUI Web Service ALSO requires the ASP.NET sub-component of Internet Information Services (IIS), which is NOT installed by default, when adding the IIS feature to Windows, please ensure that this component is installed, as follows:

If you have Windows 7 / Windows Server 2008 R2 installed:

  1. Launch Control Panel -> All Control Panel Items -> Programs and Features -> click the "Turn Windows features on or off" link on the left hand side:
  2. In the displayed "Windows Features" dialog, scroll down to:
  3. Internet Information Services -> World Wide Web Services -> Application Development Features -> ASP.NET (ensure that this check box is checked)
  4. Click the OK button.

If you have Windows 8/8.1 / Windows Server 2012/R2 installed:

  1. Launch Control Panel -> All Control Panel Items -> Programs and Features -> click the "Turn Windows features on or off" link on the left hand side:
  2. In the displayed "Windows Features" dialog, scroll down to:
  3. Internet Information Services -> World Wide Web Services -> Application Development Features -> ASP.NET 4.5 (ensure that this check box is checked)
  4. Click the OK button.

If you have Windows 10 installed:

  1. Launch Control Panel -> All Control Panel Items -> Programs and Features -> click the "Turn Windows features on or off" link on the left hand side:
  2. In the displayed "Windows Features" dialog, scroll down to:
  3. Internet Information Services -> World Wide Web Services -> Application Development Features -> ASP.NET 4.6 (ensure that this check box is checked)
  4. Click the OK button.

 

  1. Click the Install button and if necessary, specify the Name of the required Virtual Directory and the Web Site in which this Virtual Directory will be created.

For this scenario these have been left as their defaults i.e. SmartUI and Default Web Site respectively.

  1. Click Next to install the necessary files.
  2. Once installed, it is recommended to ensure that both the web service itself and the virtual directory that is created during this installation is fully operational, as follows:
  1. Launch your web browsing application.
  2. Type in the required path of your newly created virtual folder, as follows: http://WebSiteName/VirtualDirectoryName, since the ‘Default Web Site’ is selected, this will simply be: http://ComputerName/VirtualDirectoryName i.e. http://pserver/VIP.
  3. If everything has been successfully installed and configured, this should immediately display the default web page, which explains how you can use the Web Service.
  1. By default the SmartUI Web Service assumes that the Server is on the local computer. Since, the Server is on a remote computer, in this scenario, the following additional configuration after successfully installing the SmartUI Web Service:
  1. Launch the Windows Explorer (Windows Key + E).
  2. Navigate to the SmartUI Web Services installation folder, typically this is: C:\Program Files\Adroit Technologies\Adroit\SmartUI\Webservice.
  3. Locate the “Web.config” file in this folder.
  1. Open this “Web.config” file in a text editor, such as Notepad.

Its first four lines should appear as follows:

<?xml version="1.0" encoding="utf-8" ?>

<configuration>

   <appSettings>

      <add key="server" value="localhost" />

  1. Modify the “localhost”, so that the value refers to either the network name of the remote Server computer or its IP address. In this case: 192.168.0.53

Starting the VIP Distributor Service

On the SmartUI Server machine, start the VIP Distributor service (eventually this will be automatically started), as follows:

  1. Open the Services applet (Start menu, Settings, Control Panel, Administrative Tools and select the Services applet).
  2. Navigate to the VIP Distributor service, right click and select Start.

ThisVIP Distributor service specifies the folder that will contain the files and folders that the SmartUI Launcher will download; always ensuring that it contains the latest files. Typically, this folder is C:\Program Files\Adroit Technologies\Adroit\SmartUI\Distribution.

Note: If necessary it can be changed by editing the ‘VIP Distribution.exe.config’ file in the SmartUI installation folder, as required. However, in this scenario this will not be changed.

  1. Ensure that this “distribution” folder contains the necessary files:
  1. Using Windows Explorer, navigate to the SmartUI Server installation folder, typically this is: C:\Program Files\Adroit Technologies\Adroit\SmartUI.
  2. Locate the “Distribution” sub-directory. This contains an empty “plugins” folder; typically, this will be C:\Program Files\Adroit Technologies\Adroit\SmartUI\Distribution\plugins.

Note: This folder MUST contain all the plugins that are currently being used.

For this scenario, all the files in the C:\Program Files\Adroit Technologies\Adroit\SmartUI\plugins folder were copied to this folder.

  Testing Intranet Connection to SmartUI Server

On the computer on which the SmartUI Web Service has been installed, copy the SmartUI Launcher from the SmartUI Server computer and place this into a temporary folder, for instance, on the Desktop.

Note: The SmartUI Launcher is typically used to download the files required for the Operator application, either over a LAN or the Internet. To do this, the Launcher needs to connect to a computer that has the VIP Distributor service installed and configured, which in this case is the SmartUI Server computer.

Start the SmartUI Launcher from this temporary folder and complete its Connection dialog, as follows:

  1. Specify the Internet address of the WebService, which makes this Internet connection possible, which is typically: http://ComputerName/VirtualDirectory/wsdistributor.asmx. Where:
  2. ComputerName is the name of the IIS server on which the SmartUI Web Service has been installed.
  3. VirtualDirectory is the name of the virtual directory that contains the wsdistributor.asmx file, which was specified when installing the SmartUI Web Service.

In this scenario, this will be: http://pserver/VIP/wsdistributor.asmx

Tip: The 'http://' prefix and '/wsdistributor.asmx' suffix will be added to this URL on connection, if they have not been specified.

  1. Ensure that the Internet selection is selected.
  2. In the Authenticate group, specify the required User and Password, which are required when connecting to this computer.
  3. If a proxy server is required for this Internet connection, check the Enable Proxy checkbox and click the Proxy Settings button.
  1. Then press the Connect button.

If everything has been correctly specified, the Download dialog should be displayed.

If this is displayed, you can stop testing, since this proves that the SmartUI Web Service is working over http in your internal network (Intranet).

Testing Internet Connection to SmartUI Server

  1. Launch your web browsing application.
  2. Type in the required URL, as follows: http://WebSiteName/VirtualDirectoryName, which in this case is : http://213.49.35.19/VIP/
  3. This should immediately display the default web page, in which case, click on the ‘SmartUI Launcher Setup Download link’ link to download and install the SmartUI Launcher onto your computer.

Note: In order for this installation to succeed, the .NET framework MUST be installed on this computer first.

  1. Once the download has completed, click the Launcher shortcut that is installed on your Desktop.
  1. This will display its Connection dialog, which should be completed as follows:
  1. Ensure that the Internet selection is selected.
  2. If a proxy server is required for this Internet connection, check the Enable Proxy checkbox and click the Proxy Settings button. Specify the Machine Name or IP address of the proxy server and its designated Port number.
  3. In the Computer/URL field, specify the Internet address of the WebService, which makes this Internet connection possible, which is typically: http://ComputerName/VirtualDirectory. Where:
  4. ComputerName is the IP address of the web server (IIS computer) on which the SmartUI Web Service has been installed.
  5. VirtualDirectory is the name of the virtual directory specified when installing the SmartUI Web Service. In this scenario, this will be http://213.49.35.19/vip

Tip: The 'http://' prefix will be added to this URL on connection, if it is not been specified.

  1. In the Authentication Details, specify the required User and Password, which are required when connecting to this computer that is running the VIP Distributor, which is typically the SmartUI Server computer.
  1. Then press the Connect button.

If everything has been correctly specified, the Download dialog should be displayed.

  1. Click the Download button to download the files specified by the VIP Distributor service. For details, see Starting_the_VIP_Distributor_service. This will download these files into the SmartUI Launcher installation folder.

Once all the required files have been downloaded the SmartUI Launcher will display all the executable programs that have been downloaded. Typically the SmartUIConfig Editor and Operator.

  1. Double-click on the SmartUI Operator to launch it.
  1. The next time you run the SmartUI Launcher program it should automatically display these executables.

If however, any of the file(s) and folder(s) are newer on this remote computer or which do not exist on the local computer, they will be displayed for downloading.

In this way the SmartUI Launcher ensures that the files within its installation folder are kept up-to-date with the files located in the distribution folder on the computer that the SmartUI Launcher connects to.

Note: If you want to specify other connection settings instead, then simply open the File menu and select the Connection item, which will display the Connection dialog instead.

Tip: To automatically execute a downloaded executable after the SmartUI launcher has finished processing, simply edit the shortcut used to launch the SmartUI launcher and add the name of this executable (its extension is not required) as its command-line parameter to the Target field e.g. add "VIP Operator" to launch the Operator.

Troubleshooting Communication Issues

Note: While default port numbers have been used, it is possible to change the port number that either application uses via the SmartUI Config Editor but ONLY advanced users should attempt this.

The SmartUI Launcher is unable to connect to the remote distributor computer (i.e. the computer that is running the VIP Distributor service) if port 9010 is being blocked by the firewall.

This port is used by the VIP Distributor service to communicate to and from other computers and must be unblocked in order for it to communicate freely.

PLEASE NOTE: The SmartUI Server will also be unable to connect to a remote client (Operator or Designer) computer if port 9000 is being blocked by the firewall.

This port is used by the SmartUI Server service to communicate to and from other remote (Operator and Designer) computers and must be unblocked in order for it to communicate freely.
