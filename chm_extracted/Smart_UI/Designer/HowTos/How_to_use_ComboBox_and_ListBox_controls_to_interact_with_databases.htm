How to use ComboBox (and ListBox) controls to interact with databases

The value of being able to use graphic forms in the Designer to interact with databases cannot be underestimated. For example a user may wish to select a batch number from a field in a table and get the index returned for use in a query, or select a name and have the users ID number returned for use in some application.

IMPORTANT: The screenshots and specified configuration settings relate to an OLD version of the SmartUI product and so your specific settings and screens may differ.

The biggest challenge with using any controls in graphic forms is understanding which properties of each control return what data, and what property you need to populate to display the required information.

Important properties of the ComboBox (and ListBox) control

Also, should you wish to operate or manipulate a control via a spider or a script, it is also important to know which event to use in order to achieve the correct result.

Important events of the ComboBox (and ListBox) control

 

The following usage scenarios are provided:

Populating a ComboBox control from a fixed list and displaying the selected value in a TextBox control

Populating a ComboBox control from a database field and displaying the selected value in a Label

Associating a key to an item displayed in a ComboBox or ListBox control

Important ComboBox (and ListBox) Control Properties

Figure 1: Displaying the properties of the ComboBox control

The most important properties of the Combobox control are grouped within the Data property grouping:

  1. DataSource – this should be used if you if need to bind this control to a Dataset in order to set the DisplayMember and ValueMember properties. In SmartUI terms we only get the Dataset at runtime so nothing will be displayed in this view.

Note: To configure this property, simply dragged the Table onto the control and bind it to its DataSource property.

  1. DisplayMember – is the property that should specify the name of the column (field) of the Dataset data that is bound to the DataSource property of this control. This is the first column from the table of this Dataset data, by default. To display another field of the table then you must manually type in this field name.

Tip: If this graphic form is being Run, then the required field can simply be selected from the DisplayMember property’s value list box. To do this right-click the Graphic Form name in the Enterprise Manager and select Run.

Note: The DisplayMember value that is selected from the control at runtime is returned in the Text property of the control.

  1. Items – this is used to either type your own list from which the user can select an Item by adding a list manually in the property grid, or you can drag a database table onto the combo box and using the configuration dialog bind a field from that table automatically. Bare in mind that if you select more than on field in the configuration dialog it will concatenate the fields in the list box. If you use this method the value returned is contained in the Text property of the combo box.
  2. Tag – this is a very important property in that you can use this to return any value to SmartUI. It is a freely configurable property that can be very useful in building a system. It will be dealt with in more detail later on in the document.
  3. ValueMember – is the property that should specify the name of the column (field) of this Dataset data, whose value you want to be retrieved, when its associated DisplayMember value is selected at runtime. So the returned ValueMember will be based on what record/item you select as a DisplayMember from the list in the control. Typically, ValueMember will specify the field of this Dataset data that is more descriptive.

This parameter is configured in exactly the same way as DisplayMember above, you can manually type it in or you can Run the form and then select it from the list displayed. (See The third usage scenario as to its usage)

Note 1: The ValueMember value that is associated with the DisplayMember value that is selected from the control at runtime, is returned in the SelectedValue property, of the control. SelectedValue is listed within the Hidden Properties list of this control, in the property tree in the Spider Configuration window.

Note 2: If you don’t set the ValueMember it will be set the same as the DisplayMember and visa-versa.

Important ComboBox (and ListBox) Control Events

These are important should you wish to should you wish to operate or manipulate a control via a spider or a script.

  1. TextChanged – Whenever text changes in combo box this event gets raised, so if for example you are typing something every letter will raise this event, so be aware of this.
  2. ValueMemberChanged – whenever you change the ValueMember property is changed usually this is set at design and won’t be raised in runtime. This is not the event to use if you want to trigger something on selection change from the list in the combo box (the would be the SelectedValueChanged event)
  3. DataSourceChanged – only gets raised when the DataSource property gets changed, usually at design time only
  4. DataMemberChanged – only gets raised when the DataMember property gets changed, usually at design time only
  5. SelectedIndexChanged – gets raised whenever a selection is made in the combo box. This is a good event to use to trigger some desired result whenever you make a selection change.
  6. SelectedValueChanged – will get raised providing you have defined the ValueMember property and it gets raised whenever the selected record in the DisplayMember property changes.

Populating a ComboBox Control from a Fixed List and Displaying the Selected Value in a Label Control

In this example a fixed list is defined in a ComboBox control and then the item (record) that the user selects from this control is used to populate a text box.

  1. Add a ComboBox control to the graphic form, which is listed in the Windows Forms category of the Toolbox window.
  2. Select the ComboBox, go to the “Data” portion of the properties window, and click on the small button next the Items property.

Figure 2: Displaying the Items property of the ComboBox control

This displays the following dialog in which you can simply type in a list if Items you would like to display to the user:

Figure 3: Specifying the items the ComboBox control should contain

  1. Type in the list that you would like to display to the User. In this case we have typed a list North Plant, East Plant etc
  2. Put the form into Run Mode (by pressing the Run button) and select the pull down on the Combo Box control and you will notice that you get the list you have typed in the box.

Note: The text property combobox1 is displayed by this ComboBox control by default. If you want that to be blank simply delete the text in the Text property of this control. You can type anything in here, remembering that if it is selected it will become the value effectively passed onto the next transaction via the Text property.

  1. Display the selection of this ComboBox control, as follows:
  1. Add a Label control to the graphic form
  2. In the Spider Configuration window, connect the Text property of the combo box to the Text property of the label by firstly selecting the two controls on the form and then dragging and dropping from the Combobox.Text  property to the Label.Text property.
  3. The event you should use to trigger the spider is the SelectedIndexChanged of the ComboBox control, so that whenever a new item is selected the text of this item will be updated, as follows:
  1. To expose the property spider right click on the Combobox.Text  property and click on “Show Property Spider” or simply select the Combobox.Text  property in the tree view hold your right button of your mouse down, move the mouse a little and then double-click.
  2. In the Event Trigger section of this property spider ensure that the Event Object is comboBox1 and the Event Name is SelectedIndexChanged.

Figure 4: Configuring the event used to trigger the Text property of the ComboBox

Note: This Text could also be sent back to a SCADA system or be used to drive a parameter within a user defined query on a database.

Associating a Key to an Item Displayed in a ComboBox or ListBox Control

A common usage of the ComboBox control (or ListBox control) is to select the index or key column of a database, however these values are usually not descriptive enough to be very user-friendly. However, there is usually another column in the database that contains descriptive values.

It is now possible to BOTH select the required index or key column value using the ComboBox control and to obtain the associated, more descriptive value, from the other column of this database too. This descriptive value can then either be displayed or used, for instance, by being passed as a parameter to a parameterised query.

This is possible due to its DisplayMember and ValueMember data properties that both the ComboBox and ListBox

controls have. For details. see Important properties of the ComboBox (and ListBox) control.

This example assumes that there is a database called Northwind, which has a table called Employees with some fields. In this case it is required to select from a list containing the EmployeeID records and return the name of the Employee from the FirstName field.

Figure 8: Fully configured graphic form

Perform this configuration, as follows:

  1. Add a ComboBox control to the graphic form, which is listed in the Windows Forms category of the Toolbox window.
  2. From enterprise manager drag and drop the Employee Table and bind it to the combo box’s DataSource property and select the column to be displayed in the ComboBox from the Filter DataSet configuration dialog.

Note: If the Datasource property doesn’t appear in the list when you drop the table onto the combo box control then simply expand the list by selecting “Customise” and the highlight and check the Datasource check box in the list.

  1. Select the ComboBox, go to the “Data” portion of the properties window, and set the DisplayMember property to the displayed column name by typing it in manually, in this instance it will be “EmployeeID”. Do the same with the ValueMember property but set it to the column name that you want to associate with the DisplayMember, in this case select “FirstName”.

Figure 9 : Configuring the DisplayMember and ValueMember properties of the ComboBox control

  1. Add a Label control to the graphic form.

Note: This will only be used to display the selected displayed member’s associated value.

  1. Select the ComboBox and in the PropertyTree expand the hidden properties tree node in the spider configuration window.
  2. Right click on the SelectedValue property node and select “Show Property Spider”.

Figure 10 : Displaying the SelectedValue Property spider

  1. Right click the spider heading and select “Trigger Spider from Event”.
  2. Select the Event Object to be the Combobox, and the Event to be the SelectedValueChanged event.

 

Figure 11 : Configuring the event used to trigger the SelectedValue Property spider

  1. Select the Label control on the form.
  2. Expand the controls properties in the PropertyTree to the Text property under the Appearance category.
  3. Drag and drop the SelectedValue output from the comboBox1.SelectedValue property spider onto the expanded label’s Text property.

Figure 12 : Connecting the SelectedValue property of the ComboBox control to the Text property of the Label control

  1. Select the Run button of this graphic form. Select an Employee Id, in the Combo Box on the graphic form, the associated value member should appear in the label.

Note: The selected value member can be passed as a parameter to a parameterised query, if necessary.
