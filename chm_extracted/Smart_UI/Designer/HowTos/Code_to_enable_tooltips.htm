Code to implement tooltips in a graphic form

The ToolTip component is a graphic form component that can be added to a graphic form from the Windows Forms category of the Toolbox window. This component enables a tooltip (a text string) to be displayed when the mouse pointer hovers over a control, in this graphic form, that has been associated with this component.

Note: One or more controls can be associated to this component, as required.

This association between the ToolTip component and the required control(s) must be performed programmatically, by adding code to the Form_Load event of a graphic form. It is during this association that the content of each tooltip text message is specified.

For instance, in the example code below a ToolTip component (called “toolTip”) is associated to a Button control (called “button”) and the tooltip “test tooltip message” is specified, which will be displayed when the mouse pointer hovers over this Button control:

 ((ToolTip)MyController["toolTip"]).SetToolTip((Button)MyController["button"],"test tooltip message");
