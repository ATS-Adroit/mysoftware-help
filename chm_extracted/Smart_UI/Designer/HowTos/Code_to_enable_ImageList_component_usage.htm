Code to implement the ImageList component

The Imagelist component is a graphic form component that can be added to a graphic form from the Windows Forms category of the Toolbox window. This component maintains a developer-provided list of images typically for use with controls that need to display more than one image. For instance, this can be used to provide images for the different states of a button.

Before the Imagelist component can be used, however, it needs to be associated with the control(s) on this graphic form that will use it. This association can be performed programmatically, by adding code to the Form_Load event of a graphic form.

For instance, in the example code below an ImageList component (called “imageList”) is associated to a Button control (called “button”):

ImageList __img = (System.Windows.Forms.ImageList)MyController["imageList"];

Button __btn = (System.Windows.Forms.Button)MyController["button"];

__btn.ImageList = __img

Note: The ImageIndex property of the associated control (in this case called “button”) must also be set in this Form_Load event, if it is not set at design time.
