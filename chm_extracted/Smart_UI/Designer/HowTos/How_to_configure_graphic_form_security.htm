How to configure graphic form security

Typically graphic forms are secured (access to them is controlled) by the projects in which they are created. However, when designing graphic forms in the Designer, it is also possible to limit the interaction and viewing capabilities of particular users within the graphic forms too. This is achieved by specifying which users have access to which properties exposed by the controls that have been added to the graphic form.

In other words, this allows the configuration of graphic form templates based on user login name, which can provide an alternate set of properties from the default standard properties based on user or group membership.

PLEASE NOTE: Securing graphic form interaction should be one of the last configuration items performed when designing graphic forms.

This example assumes that the following configuration has already been performed:

  1. The following two user accounts have been created on the SmartUI Server computer and have been added to its allowed users:
  2. Administrator (which belongs to the group “Administrators”)
  3. Operator (which belongs to the group “Users”). 

For further details, see How to configure user security. [Press the Back button to return to this how to topic]

  1. That a graphic form has been added to a project and contains the following two button controls:
  2. btnAlarms, whose Text property has been set to “View Alarms”
  3. btnStopPlant, whose Text property has been set to “Stop Plant”

This example assumes that the Administrator user is required to be able to press both buttons, while the Operator user is NOT allowed access the button that is used to stop the plant (btnStopPlant). In other words btnStopPlant must be Enabled for Administrator but Disabled for Operator.

The following procedure is recommended to implement this graphic form user-interaction security:

  1. Launch the SmartUI Designer and log into the SmartUI Server using the user name and password of Administrator.
  2. Open the required graphic form.

Figure 1 : The default view of the graphic form in the Designer

  1. Select the Stop Plant button control (btnStopPlant) and set its (Security on Form) property to True.

Figure 2 : Enabling interaction security for this button control

 

  1. Select the Graphic Form itself, click on its Security property in the property grid to display the Security configuration dialog.

Figure 3 : Configuring the Security property of the graphic form

  1. In the Security configuration dialog, select the operator row from the Users section to change the following properties for this Operator user:

    Set the Enabled property of the Stop Plant button control (btnStopPlant) to False and its Backcolor property to Red.

Figure 4 : Configuring interaction security for the Operator user

  1. Click Finish and Save the graphic form.
  2. Launch the SmartUI Operator and log into the SmartUI Server using the user name and password of Operator. When this graphic form is displayed, the Stop Plant button is now Red and disabled.

Figure 5 : The Operator user’s view of the graphic form

  1. Launch another SmartUI Operator and log into the SmartUI Server using the user name and password of Administrator. When this graphic form is displayed, the Backcolor of the Stop Plant button is default and the button is enabled, as follows:

Figure 6 : The Administrator user’s view of the graphic form
