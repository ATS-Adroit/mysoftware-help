How to configure a TrendConfigurator control whose tags come from a database

The TrendConfigurator control provides users the ability to configure and save trended values (pens) in a set, which they can then reload when they next logon. In this way, each user can customise the values trended using an associated LineChart control, according to their requirements.

Note: The TrendConfigurator is a SEPARATE control from the LineChart control and requires an associated LineChart control to trend its configured sets of series.

Since this control is intended for use in a SCADA environment, it provides support for the physical structure of automation projects as described by the ISA S95 and S88 standards, so when specifying which values (tags) need to be trended, the following drop-down lists are available for use:

Note: Of these levels only the Pen is mandatory, both the Area and Device levels can be hidden if needed.

  1. Area: this is the Area level of physical structure of automation projects described by the ISA S95 and S88 standards. The level above this is the Site level. The Area contains one or more Process Cells or PLCs, which in Adroit-speak are communicated to via Devices, hence the next tag-locating drop-down list is:
  2. Device: this is the Process Cell level of physical structure of automation projects described by the ISA S95 and S88 standards. Which in SCADA projects equate to the PLCs of each defined plant Area. This is called Device, since Adroit uses a Device to communicate to each PLC, within a Plant Area. Each Device contains one or more values, hence the final tag-locating drop-down list is:
  3. Pen: this is the Unit and Equipment module and the Control module levels of the physical structure of automation projects described by the ISA S95 and S88 standards. This contains all the values (tags) within the specified Device.

Prerequisites

Have Adroit 8 (MAPS 3) or later installed.

Note: If you are using a version later than this then this how to will probably also apply to your version too, although some dialogs and/or commands may have changed slightly.

 

This document describes how to connect a TrendConfigurator control to a LineChart control for runtime chart configuration, when the physical structure of its tags (adhering to the ISA S95 and S88 standards) are sourced from a database.

Note: This document assumes that the reader has a basic working knowledge of using SQL databases and using databases in SmartUI.

This document describes the following steps that are required:

  1. Add an Adroit Datasource that connects to the Agent Server containing the tags to trend.
  2. Add an OleDB datasource and connect it to the database where the structured list of the areas, devices and their tags are stored.
  3. Create the following three Select queries for this OleDB datasource:
  • Areas Select query
  • DevicesPerArea Select query
  • TagsPerDevice Select query
  1. Add a LineChart control to trend the tags.
  2. Add a TrendConfigurator control to perform the runtime configuration of the LineChart.
  3. Link the three TrendConfigurator combo boxes to their respective Select queries:
  • Add and configure a Query spider for the Areas Select query
  • Troubleshoot query and link the Return Object output to the AreaList property
  • Add and configure a Query spider for the DevicesPerArea Select query
  • Link the CurrentArea property to supply the value of its area (parameter) input
  • Troubleshoot query and link the Return Object output to the DevicesList property
  • Add and configure a Query spider for the TagsPerDevice Select query
  • Link the CurrentArea property to supply the value of its area (parameter) input
  • Link the CurrentDevice property to supply the value of the device (parameter) input
  • Troubleshoot query and link the Return Object output to the PenList property
  1. Operate the TrendConfigurator control at runtime.

Add three Select queries to this OleDB datasource

The TrendConfigurator provides three drop-down list fields, per configured series or tag, namely Area, Device and Pen which can be driven by using their respective properties AreaList, DeviceList and PenList - either via Select queries on an OleDB datasource or via direct links.

Note: Driving both the Area and Device drop-down lists are optional, if you do not wish to select a list of tags per device per area and just want to drive the Pen column drop-down list with a list of all tags instead.

Tip: You can hide both the Area and/or Device columns by setting the AreaColumnVisible and/or DeviceColumnVisible property to False.

If ONLY driving the Pen combo box, then the required syntax of the Select Query that populates this combo box, is as follows:

SELECT DISTINCT [Table].[Tags] FROM [Table], assuming that the field of Table containing the tags is called Tags.

 

In this example, we will create three Select queries namely Areas, DevicesPerArea and TagsPerDevice to populate each combo box, as follows:

Areas Select query

  1. Add a Select Query to this TrendTags OleDB datasource, called Areas, which returns a unique list of areas from the Area field of the Tagsdatabase table. For details, see Select queries.

  2. Ensure that the resultant query adheres to the following syntax:

    SELECT DISTINCT [Tags].[Area] FROM [Tags]

  3. Click Preview to test that this query works as intended.
  4. Click Finish to add this query to the Select Queries queries category of this TrendTags OleDB datasource.

Back to top

DevicesPerArea Select query

  1. Add a Select Query to this TrendTags OleDB datasource, called DevicesPerArea, which returns a unique list of devices from the Device field of the Tagsdatabase table for a specific area.

    Since this query is more complex than the previous one, as it requires a constraint that uses a String parameter, use the query builder option instead of the Custom query option, in this case after selecting the Device field of the Tagsdatabase table:

  2. Click Next until you get to the Constraints section of the configuration dialog.
  3. Select [Tags].[Area] as the Field.
  4. Select = as the Constraint operator.
  5. Right click the Value/Expression and select Add String Parameter.
  6. Type in the name "area" for this parameter, to add this to the Parameters list.

Example:

  1. Ensure that the resultant query adheres to the following syntax:

    SELECT DISTINCT [Tags].[Device] FROM [Tags] WHERE  [Tags].[Area] = '<!!area!!>'

    Note: You can simply copy and paste this query as-is into the Custom Query dialog, you do not need to specifically add parameters and/or constraints by using the Select Query Builder dialogs. The required parameter data type is specified by its specific formatting in the query string, whether this is typed in manually or selected from the right click menu.

  2. Click Preview to test that this query works as intended and then click Finish.

TagsPerDevice Select query

  1. Add a Select Query to this TrendTags OleDB datasource, called TagsPerDevice, which returns a unique list of tags from the Tag field of the Tagsdatabase table for a specific device in a specific area.

    Since this query is more complex than the previous one, as it requires a constraint that uses a String parameter, use the query builder option instead of the Custom query option, in this case after selecting the Tag field of the Tagsdatabase table:

  2. Click Next until you get to the Constraints section of the configuration dialog.
  3. Select [Tags].[Area] as the Field.
  4. Select = as the Constraint operator.
  5. Right click the Value/Expression and select Add String Parameter.
  6. Type in the name "area" for this parameter, to add this to the Parameters list.
  7. Click the Add Constraint button to add another constraint to this list of constraints.
  8. Select [Tags].[Device] as the Field.
  9. Select = as the Constraint operator.
  10. Right click the Value/Expression and select Add String Parameter.
  11. Type in the name "device" for this parameter, to add this to the Parameters list.

Example:

  1. Ensure that the resultant query adheres to the following syntax:

    SELECT DISTINCT [Tags].[Tag] FROM [Tags] WHERE  [Tags].[Area] = '<!!area!!>' AND [Tags].[Device] = '<!!device!!>'

    Note: You can simply copy and paste this query as-is into the Custom Query dialog, you do not need to specifically add parameters and/or constraints by using the Select Query Builder dialogs. The required parameter data type is specified by its specific formatting in the query string, whether this is typed in manually or selected from the right click menu.

  2. Click Preview to test that this query works as intended and then click Finish.

All three queries should be listed in the Select Queries category of the OleDB datasource.

Add and configure a Query spider for the Areas Select query

Note: Query spiders can perform queries and execute statements provided by any OLE DB datasource.

  1. Right click the spider workspace and select Create New Spider and select the Query spider from the Databasing category.
  2. Double click the spider icon to display its spider configuration dialog.
  3. Double click the default name, for instance Query1 and type in the new name: Areas.
  4. Configure the Inputs section of this spider to specify the Select Query created for the TrendTags OleDB datasource, which is called Areas , as follows:
  5. Set the Server input to Default Server; the OLEDB Data Source input to TrendTags; and the Query Type input to Select Queryand the Query Name input to Areas
  6. Configure this Query spider to perform this query when the graphic form is opened, by configuring the Event Trigger section, to select Form as the Event Object and Load as the Event Name.

Troubleshoot query and link the Return Object output to the AreaList property

  1. Right click the Spider header (bar at the top of this Areas spider) and select Trigger Now! to get the initial dataset for this Query spider.

Note: Ensure that the Success output is True (i.e. the query ran successfully), if this is False then there is either a problem with the query syntax or another problem preventing this query from running.

Tip: The Rows Exist output is only True when the query returns data and is False if an empty dataset is returned.

  1. In the graphic form, click the trendConfigurator control to display this control's properties in the Objects tree on the right of the spider workspace.
  2. In the Outputs section of the Areas Query spider, drag the Return Object output onto the Hidden Properties property group (to expand it) and then onto the AreaList property of the trendConfigurator control to connect them with a Silk.
  3. Click Finish, when the Filter DataSet configuration dialog is displayed.

Operate the TrendConfigurator control at runtime

Typical runtime configuration:

Note: By default, the run-time configuration of all TrendConfigurator controls are stored in a user profile variable called TrendConfigurator. Therefore if you want to maintain separate lists of sets for your TrendConfigurator controls, then rename this variable of each TrendConfigurator control in the The Setting Name to use to load and save the Set configuration to the Users Profile field of the General Settings tab of the TrendConfigurator Setup dialog (the UserProfileSetting property).

For each Pen (tag or value) that you select to be trended as part of a set, you can specify the following:

IMPORTANT: You need to click the Save Set button (on the right of the TrendConfigurator control ) after adding or configuring one or more series to this list, to save these changes to the current set (as specified by the Set Name drop-down list on the right of the TrendConfigurator control). Otherwise when you close this graphic form, the new series and/or configuration changes will be lost.

Note: You may need to click the Refresh Chart button to view with any series that you add to the current set.

  1. color: Use the color box to choose the required color for this series or value (and its axis color if it has its own custom axis) in the associated LineChart control.
  2. If displayed, the Area column typically allows the specific plant area to be specified, in which this tag is physically situated (unless the PresetArea property has been specified).
  3. If displayed, the Device column typically allows the specific FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU. device to be specified, in which this tag is being communicated (unless the PresetDevice property has been specified).

  4. Pen: The name of the tag of this series.

    When using the Adroit mode:

    A browse (...) button appears to the right of this field so that users can also browse in additional tags to the Pen drop-down list at runtime.

    Note: These additional tags can be removed from the Pen drop-down list at runtime, by selecting the required tag in the list and clicking the button on the right.

  5. Title: Edit the name of the series or value that is displayed in the legend of the associated LineChart (if you choose this value to be visible in the legend by checking its Leg checkbox).

Note: By default this column displays the description of the tag as this is usually more descriptive than the tag name itself. However, if you want the series to display the tag name [AgentName.Property(Slot)Name] instead then uncheck the Use Pen (Tag) Description for Series Names instead of Tag Names checkbox in the General Settings tab (the UsePenDescForSeriesName property).

  1. Value: The current value of the tag being used for this series when it was selected.
  2. Unit: If necessary, specify the required unit to specify on the custom axis of the series on the LineChart for the trended value or series. If you are using the MAPS or Adroit modes, then this is retrieved for you, for Analog tags.
  3. Vis: This checkbox toggles the series or value visibility on the associated LineChart. In other words this series is displayed in the LineChart when checked (the default setting) and it is hidden when unchecked.
  4. Leg: This checkbox toggles the series or value visibility in the legend of the associated LineChart. In other words this series is displayed in the legend when checked (the default setting) and it is hidden when unchecked.
  5. Axes: This checkbox determines whether this series or value will be charted using the default Y (or value) axis when unchecked OR whether a custom Y axis will be used, when this is checked (the default setting). When using custom Y axis then, the following fields are used to configure the display of this axis in the associated LineChart:
  1. X-Pos: Specify the horizontal position of this custom Y axis, relative to the position of the default Y axis, as a percentage of the total horizontal width (size) of the default X axis. In other words, a value of a 100 moves the custom Y axis to the other side of the LineChart.

Note: A positive value shifts this custom Y axis to the right of the default Y axis, by the specified amount; while a negative value shifts this custom Y axis to the left of the default Y axis, by the specified amount.

  1. Y-Pos: Specify the vertical position or topmost end of this custom Y axis, relative to the top of the default Y axis, as a percentage of the total vertical height (size) of the default Y axis. In other words, a value of a 100 hides this custom Y axis and therefore this series too.

Note: A positive value decreases the height of this custom Y axis below that of the default Y axis, by the specified height; while a negative value increases the height of this custom Y axis above that of the default Y axis, by the specified height.

  1. size: Specify the size of this custom Y axis, from the specified Y-Pos location in the direction of the X axis (lower-left corner), as a percentage of the total vertical height (size) of the default Y axis. In other words, a value of 100 is the size of the actual Y axis.
  1. Min: The minimum value of this Custom Y axis, which depends upon the value being charted. By default this is set to 0, although, if possible, this control will obtain this value from the applicable Adroit datasource for the selected agent.

Note: Any series value below the specified Min value will be hidden from view.

  1. Max: The maximum value of this Custom Y axis, which depends upon the value being charted. By default this is set to 100, although, if possible, this control will obtain this value from the applicable Adroit datasource for the selected agent.

Note: Any series value above the specified Max value will be hidden from view.

  1. Adv: This column provides a browse (...) button that launched the tabbed Advanced Pen Configuration dialog, that allows the following advanced settings to be configured per pen:

Note: You typically need to click the Refresh Chart button after making changes to these settings to view them on the associated LineChart.

Series settings: These settings affect how the series of this pen will be charted, as follows:

  • You can select one of the following series styles from the Type drop-down list: Line, FastLine, Area and XYPlot.
  • You can specify the width of the line representing this series, in pixels, from the Width spin control.
  • You can check the Stairs/Steps checkbox to change the series to be charted in stairs/step mode (when unchecked, the default setting, the series uses a smoothly interpolated line between successive data points).
  • You can check the Pointers checkbox to display rectangular data points representing this series (when unchecked, the default setting, these data points are hidden).

Custom Axis settings: These settings affect the display of the vertical Y-Axis of the LineChart for the pen, as follows:

Note: The bottom chart axis for each set can now be configured via the Advanced Set Configuration dialog.

  • You can check the Automatic Scales checkbox to turn on automatic scaling for the entire axis or for only the minimum (by checking the Minimum Auto checkbox) or maximum (by checking the Maximum Auto checkbox) of the scale.
  • You can specify the required frequency or number of the axis ticks and labels, by specifying the required Increment interval.
  • You can change the Axis color.
  • You can display the axis on the right-hand side by checking the Other side checkbox (when unchecked, the default setting, this axis is displayed on the left side).

 

Using buttons, on the right of the TrendConfigurator control, you can change how the values of the current set are trended in the associated LineChart, as follows:

To view added series for the current set that are not yet displayed: click the Refresh Chart button.

To set the time interval of the X-axis for all series:

Click the Range button, on the lower right of the TrendConfigurator control.

This displays the Time Details Settings dialog so you can configure the starting and ending times that apply to all the values that you are trending.

Note: This affects the time interval for all series of all the sets that you display on this LineChart until you close the SmartUI Operator, at which time this configuration will be lost.

The following axes-stacking actions change both the Custom and default Y axes parameters, which you can edit if you want to change their resultant settings:

Note: These Axes stacking actions only apply if you have configured one or more custom Y axis for this set of trended values. In other words, you have at least one Axes checkbox checked.

To view each custom Y axis on its own axis: This is particularly useful when you are trending values, whose custom Y axes have differing scales (differing maximum values), since this separates each custom Y axis for easier readability.

Click the Stack Axes Horizontally button, on the lower right of the TrendConfigurator control.

Note: This automatically configures the horizontal positioning (X-Pos) of the Custom Y axes for the best fit.

To trend each series using their own Y (value) axis: This allows you to compare the trend of each series (value) without confusing or hiding the trends of the other series.

Click the Stack Axes Vertically button, on the lower right of the TrendConfigurator control.

Note: This automatically configures the vertical positioning (Y-Pos) and size of the Custom and default Y axes of each trended series, so that each series has their own Y axis that is the same size, one above the other.

To configure the chart axes at runtime: This allows you to configure the scaling, position and/or axis ticks of one or all the axes of the associated LineChart in the Operator.

Click the Axes button, on the lower right of the TrendConfigurator control.

In the displayed Axis Configuration dialog, configure the axes of the associated LineChartconfigured, as follows:

If necessary, Select an Axis to configure from this drop-down list box.

To customise the scaling of this axis: determine whether to manually or automatically scale this axis and/or invert the scaling and/or hide the scaling and/or to improve the readability of the axis.

Click the Axis Scales tab to do one or more of the following:

Note: You may need to select the Advanced view in the Edit Chart dialog to display these settings.

To automatically configure the scaling of this axis: ensure that the Automatic checkbox is checked, this also checks the Auto checkboxes for the Minimum and Maximum values.

Tip: It is recommended to use automatic scaling (the default setting) when trending data with the Line or XYPlot chart.

To manually configure the scaling of this axis:

Tip: This is typically required when you are using Bar or Column charts so that you can see the differences in values between two series.

  1. Ensure that the Automatic checkbox is cleared, this also clears the Auto checkboxes for the Minimum and Maximum values.
  2. Manually specify the Minimum and Maximum values, by using the Value spin control to specify the required value.

To scale the axis logarithmically:

Note: You need to select the Advanced view in the Edit Chart dialog to edit these settings.

  1. Check the Logarithmic checkbox to scale the selected axis logarithmically settings include:

Note: The Minimum and Maximum values of this axis should be greater than zero, and the Axis cannot be of type DateTime .

  1. Then specify the required Logarithmic Base for this logarithmic scaling.

To specify a margin or offset above and/or below the axis scaling for improved readability: specify the required Offset (blank space) below the Minimum value and/or above the Maximum value, in pixels (this is an Advanced feature).

To invert the scaling of this axis: ensure that the Inverted checkbox is checked (this is an Advanced feature).

To hide the scaling of this axis: ensure that the Visible checkbox is cleared.

To customise the positioning of this axis: determine the relative position and the actual size of this axis relative to the total dimension of the charting area.

Click the Axis Position tab to specify one or more of the following axis positions:

Relative Position: the position of this axis, as percentage (0-100%) of the length or width of the charting area, as follows:

For a horizontal (X) axis: 0 is the Bottom border and 100 is the Top.

For a vertical (Y) axis: 0 is the Left border and 100 is the Right.

Start Position: at the specified Relative Position, this determines the starting position of this axes, as percentage (0-100%) of the total size of the charting area, as follows:

For a horizontal (X) axis: 0 is the leftmost point and 100 is the rightmost point of the horizontal size of the charting area.

For a vertical (Y) axis: 0 is the topmost point and 100 is the bottommost point of the length of the vertical size of the charting area.

End Position: at the specified Relative Position, this determines the ending position of this axes, as percentage (0-100%) of the total size of the charting area, as follows:

For a horizontal (X) axis: 0 is the leftmost point and 100 is the rightmost point of the horizontal size of the charting area.

For a vertical (Y) axis: 0 is the topmost point and 100 is the bottommost point of the length of the vertical size of the charting area.

To customise the display of the axis and its scaling demarcations or ticks: determine to display the axis, its major demarcations or ticks and their grid lines and to configure the colors of these items.

Click the Axis Ticks tab to specify the visibility and/or the displayed color of the following axis components:

Axis Pen Visible: This checkbox displays/hides this axis.

Axis color: Configure the required color of this axis. For details, see Using the color edit box to select a color.

Ticks Visible: This checkbox displays/hides the major ticks (demarcations) of this axis.

Ticks color: Configure the required color of these major ticks.

Grid Visible: This checkbox displays/hides the grid lines, displayed within the charting area, from each major tick (demarcation) of this axis.

Grid color: Configure the required color of these grid lines.

 

Using buttons, on the right of the TrendConfigurator control, you can manage and configure sets of your values that are trended in the associated LineChart, as follows:

To create a new set:

  1. Open the Set Name drop-down list, on the lower right of the TrendConfigurator control, and select the New Set entry.
  2. Add and configure the series (values) that you want to trend in this set in the list on the left of the TrendConfigurator control.
  3. Click the Save Set button to name this set and add it to the Set Name drop-down list.

To save and name a new set:

Click the Save Set button, on the lower right of the TrendConfigurator control, which prompts you for the required name for this set of trended values, which is then added to the Set Name drop-down list.

Tip: Ensure that you provide a descriptive or unique enough name so that you will remember exactly which trend values this set contains.

To configure and/or trend the series (values) that you have added to a set:

Open the Set Name drop-down list, on the lower right of the TrendConfigurator control, and select the name of the required set.

This loads the series (values) and their configured properties in the list on the left of the TrendConfigurator control and then updates the associated LineChart to trend these series.

To configure the display of the bottom chart axis for each set: to specify the minimum datetime interval between the axis labels and the required DateTime format of these labels.

Note: This configuration is stored per set in the currently logged on user’s profile.

Click the Advanced Set Configuration button, on the lower right of the TrendConfigurator control, to the right of the Set Name drop-down list to configure the bottom chart axis for the currently selected set.

In the displayed Advanced Set Configuration dialog:

  • Specify the minimum datetime interval between the axis labels i.e. 1 minute, 1 hour etc. by selecting and configuring the required Scaling Increment options, as follows:
  • Check the Exact Date Time checkbox to enable Standard and to calculate the Axis Labels in exact 1 hour intervals. Unchecking this checkbox, the default setting, selects the Custom option.
  • Select the Standard option and specify the required datetime interval e.g. 1 hour, 1 minute etc. from the drop-down list.
  • Select the Custom option, if the Standard datetime intervals do not specify the interval that you require and then specify this required time interval in hours:minutes.
  • Specify the required DateTime Format of the Labels of this axis by specifying the required standard DateTime formatting string specifier i.e. yyy-MM-dd etc. from the list and then clicking the Set button.

To update the current set with newly added and recently configured series:

Click the Save Set button, on the lower right of the TrendConfigurator control.

This updates the set that is currently displayed by the Set Name drop-down list, with all the newly added series (values) and any changes that have been made to the properties of the other series in this list.

WARNING! If you forget to do this and then close this graphic form or exit the SmartUI Operator, then ALL the newly added series and/or configuration changes will be lost.

To export and import the configuration of all the sets in the currently logged on user’s profile to and from an XML file: This allows you to open this exported file in MS Excel or any XML editor and do bulk configuration or any other external editing and then import the edited file.

To use this, click the Export and Import buttons, on the lower right of the TrendConfigurator control.

To delete the current set:

Click the Delete Set button, on the lower right of the TrendConfigurator control.

This removes the set that is currently displayed by the Set Name drop-down list, from this list of sets, which therefore removes all of its added series (values) and their configuration.

 

 To remove all the series or values from the left list: click the Clear All button.

Note: This action does not automatically stop these values from being trended by the associated LineChart.

WARNING! After clearing all the series or values, ONLY click the Refresh Chart button if you want to remove all the series or values from the set that is currently displayed by the Set Name drop-down list.

To programmatically select a specific set from the Set Name combo box:

Specify the name of the required set to load in the Specify the Set Name to load if TriggerLoadSet is set to true through SpiderEngine field of the General Settings tab of the Advanced View of the TrendConfigurator Setup dialog (or use the TriggerLoadSetName property)

Then trigger the Boolean TriggerLoadSet property via a spider, for instance by using a Constant spider, whose output is set to True.

This loads the series (values) and their configured properties in the list on the left of the TrendConfigurator control and then updates the associated LineChart to trend these series.
