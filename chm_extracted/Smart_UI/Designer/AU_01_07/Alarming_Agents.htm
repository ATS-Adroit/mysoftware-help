Alarming Agents

How to Alarm Process Values: how to alarm agents (process values) in Adroit.

In principle, you can alarmthe process of monitoring an agent for the occurrence of a specific abnormal condition or state (alarm type). any agent in Adroit and this process is managed by an Alarm agent. For a general overview of alarming, see Alarming in Adroit.

Once an Alarm agent has been selected to manage the alarming of an agent, the following items need to be configured, as required:

  1. Its Alarm Type(s) specify the alarming condition/s that must be met for an alarm to be generated.
  2. Its Alarm Route(s) specify how this alarm, once generated, will be reported to the operators.

As the alarming system in Adroit is very flexible a number of additional capabilities are provided. For details, see Additional Alarming Configuration.

BEFORE any agent is alarmed it is RECOMMENDED to create and use of an Alarming strategy. This is simply a set of guidelines or a plan to optimise the configuration of the alarming of agents. For further details, see Alarming strategy.

Alarms are typically viewed using Alarm List Viewer windows. For more details about displaying alarms, see Displaying Alarms.
