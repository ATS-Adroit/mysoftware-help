Creating Alarm Types

You can either create alarm types from the Alarm agent for ALL agent types or from the Alarming dialog for the agent type of the specific agent that you are alarming.

To create an alarm typea named (abnormal) condition or state of an agent that is defined by which of its status bits are simultaneously ON or OFF, which can also list the slots of this agent to report when this condition occurs. for an agent, you must provide two of the following three components:

  • a descriptive name for the specified condition, this usually takes the form of a descriptive abbreviation. For instance "Overheating" for an Analog agent type or "Tripped" for a Digital agent type.
  • specify which of these status bits must be simultaneously enabled or disabled in order for this condition to occur and
  • if necessary, specify which slots of the agent should be reported (and their order) when the specified condition occurs.

To create an alarm type:

  1. Open the Edit Alarm Type dialog, using one of the following methods:

When editing the Alarm agent: this allows you to configure agent types for all your agents from one dialog.

  1. Edit the required Alarm agent, as follows:
    1. If necessary, add an Alarm agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Edit... menu item to display the Edit Alarm Agent dialog.
  2. Select the Types tab from the Edit Alarm Agent dialog.
  3. Select the required agent type from the Agent Type drop down list box.
  4. Click the Add an entry button.

When alarming a specific agent: this allows you to add specific or unique alarm types, when the need arises to the applicable agent (type).

  1. Display the Alarming dialog for the required agent, as follows:
    1. If necessary, add the required agent. For details, see To Add a New Agent.
    2. Select the name of this agent. For details, see To Select an Agent.
    3. Right click and select the Alarm... menu item to display the Alarming dialog.
  2. Select the required Alarm agent.
  3. Click the button above the Available alarm types list.
  1. Type the required name for this alarm type in the Alarm Type edit field.

Tip: Provide a descriptive name for this condition, so that it is easy for engineers and operators to recognise.

  1. Select the status bits (check their checkboxes) from the Alarm Trigger section that must be simultaneously ENABLED (set) enabled in order for this condition to occur.

Note1: ALL the status bits that should not be used for alarm type definitions are disabled.

Note2: ONLY if you need to specify a condition in which specific status bits are DISABLED (off) then ensure that the Alarm Off States checkbox is checked.

  1. If necessary, specify which values of this agent (and their order) should be reported when this condition occurs.

    These slots and their order are specified in the Reported Data section of this dialog, as follows:

To add a reported slot:

  1. Double-click the required slot/s from the Available list box.

This adds them to the Current list box, which displays the slots in the order in which they will be reported.

Tip: You can also select the required slot in the Available list box and click the << button.

To change the order of a reported slot:

  1. If necessary, remove this slot from the Current list, by double-clicking it.

Tip: You can also select the required slot in the Current list box and click the >> button.

  1. Click the slot in the Current list that the required slot should be ABOVE.
  2. Select the required slot in the Available list box
  3. Click the << Insert button

This adds the selected slot ABOVE the slot that was selected in the Current list.

 

To insert a new slot into an existing list of reported slots:

  1. Click the slot in the Current list that the required slot should be ABOVE.
  2. Select the required slot in the Available list box
  3. Click the << Insert button

This adds the selected slot ABOVE the slot that was selected in the Current list.

  1. Click on the OK buttons to close the open dialogs.

 

For further details about alarm types and their purpose in alarming, see About alarm types.
