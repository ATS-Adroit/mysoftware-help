To Add or Edit an Alarm Type

  1. From the Edit Alarm Agent dialog, select the Types tab.

The Types page is displayed.

  1. From the Agent Type drop down list box, select the Agent Type for which the Alarm Types will be defined.
  2. To add a new alarm type, click the Add button and enter the name, remembering that Alarm Types are case sensitive.
  3. To edit an existing alarm type, select it and click the Edit button to get a further dialog box.
  4. To allow the status bits to be alarmed in their off states, check the Alarm Off States checkbox, this is off by default.
  5. Select the Alarm Trigger status mask bits that will be used to monitor the agents using that particular Alarm Type.
  6. Choose the agent slots to be reported using the changeover buttons e.g. for an analog type, you may wish to report the data held in the value and unit slots.

The Available list box displays all slots relevant to the selected agent type.

The Current list box displays the slots in the order in which they will be reported.

The Insert button is available to rearrange the order of the slots.

  1. Click on the OK button to return to the Edit Alarm Agent dialog.
