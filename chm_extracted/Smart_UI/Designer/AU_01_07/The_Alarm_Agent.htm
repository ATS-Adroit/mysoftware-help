The Alarm Agent

The role of an Alarm agent is to monitor the status bits of as many agents you choose to alarm.

It will also route any of their significant events to one or more alarm lists, printers or event logs.

Each Agent Server has one instance of the Alarm agent already created called defaultAlarmAgent. However, additional Alarm agents may be created to provide easier management of alarm filtering and messaging loading.

Tip: If necessary, bulk-alarming configuration can be performed. For details, see Importing Alarm Agents.

Each Alarm agent (whether the defaultAlarmAgent or a user defined agent e.g. ALM02) contains three distinct groups of information, which are reached using the Agent Configuration Edit button:

  • Alarm routing options to a variety of output and display devices
  • Alarm types and the associated status bit mask for each agent type being monitored
  • Global settings and switches to set alarm priority level and globally enable or disable alarming

Note: You cannot copy an Alarm agent as this corrupts its alarming configuration.
