The Notify Agent

The Notify agent provides another alarm route destination, which provides the following methods of reporting alarms that are intended to keep off site personal informed of unacknowledged alarms, process values and operator messages:

Methods of remotely sending messages to the Notify agent

  • alarms can be transmitted via cellular phone Short Message Service (SMS) or paging service direct to a designated person.

Tip: The Command agent can SMS alarms that have been sent to a Notify agent, by @ scanning the valueEx (VARSTRING) slot of this agent to the value slot of the required Command agent, since this supported extended strings. For details, see Message Sending and Processing Slots or for details on the Command agent in general, see Command agents.

Drivers are provided which support Zetron encoder paging, MTN cell phone paging and Vodacom cell phone paging, Autopage and Telstra paging services amongst others.

IMPORTANT: When scanning Notify agent slots that are displayed on mimics, set their scan rates to zero. If this is not done then Adroit will attempt to poll these tags and the driver (which cannot read SMSs) has no data to return, and thus fails to read, resulting in scan-bad tags when displayed on a mimic.

  • alarms can also be sent as email messages to the necessary recipients, by using the Email driver. For details, see Configuring the Notify Agent to send Email messages.

In addition to automatically sending alarms as email message, the Notify agent can also send email messages manually.

Note: Multiple email addresses in the To, Cc and Bcc fields of the email message need to be separated by the COMMA (“,”) character and not the semi-colon (“;”)

The Body and/or Subject line of the AUTOMATICALLY sent email messages may contain text macros that are parsed to before the message is sent, if required. For details, see Adding Macros to Notify agent email messages.

Note: Currently these macros are only parsed when automatically sending email messages via the Notify agent, NOT when it sending email messages manually.

Each email message can include an optional file attachment.

Note: You can enable the ForceSendIfDuplicate registry setting to determine whether the same message can be resent or not from a Notify agent.
