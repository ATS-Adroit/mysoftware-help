Configuring the Notify Agent to send Email messages

There are two ways in which to send an email message from the Notify agent.

BOTH require scanning (not @scanning) the Email-rawValue slot (as output enabled and scan inhibited) of the applicable Notify agent to the applicable Email driver device address i.e. EMAIL.x where { x = 0, x <= 250 }

The number of Email driver devices a system requires is determined, as follows:

  • the required number of FROM email addresses, since each Email driver device uses a single FROM address, from which all the email messages scanned to this device are sent from.
  • the number of Notify agents that send email messages, since each Email driver device can service up to 251 Notify agents.

Note: Since multiple Email driver devices can use the SAME FROM address, the system can technically serve an unlimited number of Notify agents.

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit Notify agent dialog:

  1. Leave the default Notify agent edit dialog unchanged and click the Advanced… button.

In the e-Mail section of the Advanced options dialog:

  1. Check the Enable checkbox.
  1. Specify the required email recipients for the email messages sent using this Notify agent in the To, CC and/or Bcc fields, as follows:

IMPORTANT: Use a comma (,) NOT a semi-colon (;) to separate multiple email addresses.

  • The To field is for people that the message directly affects, in other words those people that need to do something about this message.
  • The Cc field is for people that need to know about the message, but are not directly involved - to keep them informed.
  • The Bcc field is used when you want other people to receive the message, but you don't want the other recipients to know they got it. When an e-mail is received, the recipients see all the email addresses in the To, CC and From fields - but not the Bcc field.

Tip: Only use the Bcc field when sending an e-mail to more than 50 recipients to prevent them from seeing the e-mail addresses of the other recipients.

  1. Specify the generic Subject of these Notify agent email messages, which is the title of the email that appears in the InBox of the recipients.
  2. Specify the generic Body of these Notify agent email messages.
  3. If necessary, you can specify any file as the attachment of this email message in the Attachment field. Either type in or browse in the full path of this file including its extension.

Note: Only 1 file can be attached to the email message.

Manually sending email messages

In this case, create a mimic that allows your operators to send email messages, as follows:

IMPORTANT: Please ensure that this Notify agent is NOT on an alarm route. Otherwise manually sent email messages may cause automatic alarm email messages not to be sent, if BOTH are sent simultaneously!

  1. Specify the values of the following VARSTRING Notify agent slots to define the email message:

IMPORTANT: Use a comma (,) NOT a semi-colon (;) to separate multiple email addresses.

Note: Macros are NOT SUPPORTED in manually-created email messages, so any specified macros in the Subject or Body fields are sent as-is (undecoded).

Slot Description
Email-To The To field is for people that the message directly affects, in other words those people that need to do something about this message.
Email-CC The Cc field is for people that need to know about the message, but are not directly involved - to keep them informed.
Email-BC The Bcc field is used when you want other people to receive the message, but you don't want the other recipients to know they got it. When an e-mail is received, the recipients see all the email addresses in the To, CC and From fields - but not the Bcc field.
Email-Subject The Subject line of the email message, which is the title of the email that appears in the InBox of the recipients.
Email-Body The Body (actual message) of this email.
Email-Attachment

The OPTIONAL full path and filename of the file attachment of this email message.

Note: Only 1 file can be attached to an email message.

  1. Add a mechanism, typically a button to send a 1 to the BOOLEAN Email-Send-Now slot.

    Sending a 1 to the BOOLEAN Email-Send-Now slot, encapsulates the other VARSTRING Email- slots into the RAWBYTES Email-rawValue slot, which is then scanned to applicable device of the Email driver that sends this message.
