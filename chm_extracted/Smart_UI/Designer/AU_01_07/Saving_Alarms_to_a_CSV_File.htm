Saving Alarms to a CSV File

Note1: It is also possible to prevent the EventOutput agent from outputting events when its clustered Agent Server is in standby mode, so that the output destination does not receive duplicate entries, by adding the DisableEventOutputOnStandby value to the registry.

Note2: The Time column of the EventOutput agent now supports MILLISECONDS.

Note3: For this to work a TEMP folder, e.g. C:\Temp, must exist, which Win2k and WinXP no longer have by default.

From the Agent Configurator, do the following:

  1. Create a new EventOutput agent. For the purposes of this example, we will assume that you have used the name EO_FILE as the name of this new agent.
  2. Double-click on the newly created agent.

In the Event Output Agent configuration dialog box, do the following:

  1. From the Printer Type list, select the FILE entry to cause the Printer Name field to default to the name of the EventOuput agent .CSV e.g. EO_FILE.CSV and the Setup Data field to default to "Fixed width = /p else CSV format is used" respectively.
  2. The Printer Name field, in this case, is used to specify the path and filename of the file that you wish to send the events to. As long as the path is a valid one, Adroit will create the file if it does not exist.

Note1: It is also possible to use the drive letters of mapped remote network shares.

Note2: To re-activate the default file name, delete this field, exit the dialog box and re-edit this agent.

  1. The Setup Data field, in this case, will only accept ‘/p’ (without the quotes), which creates a fixed width text file, by forcing the width of the file entries to be padded with spaces as per the configured settings in the Format dialog.

Any other entry in this field will use comma delimiters between the columns creating a CSV file format.

Note: In the case of CSV files, column widths are honored as maximum width settings, but not the column starting positions.

  1. Disable (select No) for both the Demand Printing and Time Printing otherwise it will create duplicate, out of sequence entries in your file.
  2. Enable size Printing (select Yes) and type a 1 in the size drop-down list box i.e. size = 1.
  3. Lastly, add this EventOutput agent e.g. EO_FILE as a printer routing option to the required Alarm agent.

While the Agent Server is running, the file being written to is available to other software packages as shared, read-only.
