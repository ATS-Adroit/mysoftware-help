About Alarm Types

An alarm type is simply the required condition or state of an agent that you need to alarm. This can also contain a list of slots of this agent, which are reported when the alarm occurs.

In Adroit, each agent drives the following status bits:

These status bits are divided into the following categories:

  • Common Status Bits, which indicate their internal status (or integrity) and are common to all agents. For instance, these can indicate failures within the Adroit system itself.
  • Specific Status Bits, which indicate the status of the values driven by or contained in the agent and are specific to each agent type. For instance, these can indicate plant upsets or process variable excursions.

Each alarm type requires two of the following three components:

  • specify which of these status bits must be simultaneously enabled or disabled and
  • provide a descriptive name for the specified condition, this usually takes the form of a descriptive abbreviation. For instance "Overheating" for an Analog agent type or "Tripped" for a Digital agent type.
  • if necessary, specify which slots of the agent should be reported when the specified condition occurs, in other words ONLY select those slots that will help clarify or troubleshoot this state of the agent.

To create an alarm type: You can either create alarm types from the Alarm agent for ALL agent types or from the Alarming dialog for the agent type of the specific agent that you are alarming.

To edit an alarm type:You can either edit alarm types from the Alarm agent for ALL agent types or from the Alarming dialog for the agent type of the specific agent that you are alarming.

To remove an alarm type: You can ONLY remove alarm types from the Alarm agent for ALL agent types.

When you ‘alarm’ an agent, you simply select the required alarm type/s that the specified Alarm agent should monitor for this agent. Then when the necessary status bit/s are set in this agent that match one of the selected Agent Types, the Alarm agent communicates incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). via the selected alarm route.

Example:

By default each agent type provides one or more pre-configured alarm types. This means that one set of alarm types will be created for Analog agents and another set for Digital agents. If necessary, you can create your own agent types. Although it is NOT recommended that you modify the predefined alarm types.

Note: Alarm types are specified per agent type; therefore once you have created the required agent type for one agent it is available for ALL agents of this type.

The default alarm types are pre-configured in the postload Adroit database file. For further details of this file, see About the Postload Database File.
