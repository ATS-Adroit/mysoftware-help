To Configure an Alarm Route

All alarms are routed to the following destination agents that are designed to announce, record, organise and display the alarm state of the alarmed agent. For further details of alarm routes, see About Alarm Routes.

  1. From the Edit Alarm Agent dialog, select the Routes tab.

The Routes dialog displays the following information:

  • Route Numbers – specify as many routes as you require.

However, the defaultAlarmAgent reserves Routes 0 and 1 for system alarms such as software faults and communication errors.

Therefore, when configuring route destinations in the defaultAlarmAgent, the route number must begin at Route 2. When more alarm agents are created, Routes 0 and 1 are not reserved.

  • Route Destinations – this is divided into:

Alarm Route Destinations, which select the required Alarm Lists and Audio Devices for the selected route number, that only applies to this Alarm agent.

Eventlog Route Destinations, which select the required Output Destination (EventOutput or Notify agents) and Event Logs for the selected route number.

Note:Eventlog Route Destinations are GLOBAL settings that apply to ALL alarm agents. Hence, Route 2 of the defaultAlarmAgent routes to the same EventOutput(s) and EventLog(s) as will Route 2 of another alarm agent etc.

  1. Select an existing route number, by using the Select route number list box. If necessary:
  1. Click the Add Route button to create a new route number for this Alarm agent
  2. Click the Remove Route button to remove the route currently selected in the Select route number list box.
  3. Configure the Route Destinations for the selected Route Number.
