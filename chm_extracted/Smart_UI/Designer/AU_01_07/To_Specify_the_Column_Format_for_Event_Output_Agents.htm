To Specify the Column Format for Event Output Agents

From the Event Output Agent dialog, select the Format button.

The Columns Format dialog box is configured as follows:

  1. Transfer the required fields between the Available list and Current list by:
  2. Double left clicking the item.
  3. Using the appropriate move to, << and >> button.
  1. The Insert button will place a selected field in the Available list above the selection in the Current list.
  2. The Start and Width boxes identify the starting point and width of each field. Initially the default settings are specified. Adjust the widths to suit your report and then click the Compress button to reset the column widths.
