Historical Alarm mode

Historical alarm mode allows an unlicensed AlarmManagement agent to save your historical alarms to a SQL Server database. Up to now, an unlicensed AlarmManagement agent only allowed the fully fledged AlarmManagement system to be used for one hour.

The main advantage of using this Historical alarm mode is that previously the life-cycle of an alarm, such as when it was initiated, when viewed, when acknowledged and when cleared (removed) could only be determined by looking at several lines from the relevant AlarmList, but now this Historical Alarm mode you allows you to see the full life-cycle of each alarm in a single row in the Adr_AM_HistoricalIncidents table of the Adroit Historical Alarms database that is created for you in the specified SQL Server that you need to specify.

IMPORTANT: But this Historical alarm mode does not give you access to the other functionality provided by a licensed AlarmManagement agent, which allows you to fine-tune and optimise your alarming system.

Note: This table only contains those historical alarms whose conditions for complete acknowledgment have been fulfilled, in other words if reasons and/or notes are mandatory for them that these have been specified in addition to acknowledging the alarm.

Therefore, ONLY when your Agent Server license is not licensed for AlarmManagement does the AlarmManagement dialog contain a Historical Alarm mode check box. When you check this check box, then the next time that you start the Agent Server, the existing AlarmManagement database tables, if any, are removed and replaced with a minimal set of tables.

IMPORTANT: You cannot run the AlarmManagement agent in both alarm management mode and this Historical Alarm mode at the same time and therefore after enabling Historical Alarm mode the AlarmManagement reports will not work!

Note1: As usual, you need to have installed Microsoft SQL Server (Express) in order to use this Historical Alarm mode.

Note2: If you do not check this checkbox then you can freely use (demo) the fully fledged AlarmManagement system for one hour. However, after enabling this checkbox you no longer have access to the fully fledged AlarmManagement system, unless you uncheck the Historical Alarm mode check box and restart the Agent Server.

You can use the AdroitHistoricalAlarmViewer control in the SmartUI to connect to the AlarmManagement database and allow your users to locate and/or filter and/or print and/or export the historical Adroit alarms.
