Temporarily Suspending Alarming (Alarm Shelving or Alarm Inhibiting)

Usually you need to suspend (shelvealarm shelving is the process of removing an alarm from the entire alarm system for a specific time period. This also known as inhibiting an alarm.) alarming temporarily when you are performing maintenance on a plant section or a particular item of equipment or when an alarm indicator is not functioning correctly or is being tested.

Depending upon the scope of the required shutdown and the configuration of your alarming, you are able to temporarily suspend alarming in the following two ways:

  • Globally per Alarm agent: this option should only be used when an Alarm agent ONLY manages all the alarming of the plant section that is being shutdown or the plant item/s that are being shutdown for maintenance or repair.

WARNING! If you do not have an alarming strategy and do not know which areas of the plant are controlled by which Alarm agents then DO NOT USE this method.

To disable the alarming of an Alarm agent:

  1. Edit the required Alarm agent.
  2. Select the General tab from the Edit Alarm Agent dialog.
  3. Click the No option in the Enable Alarming section of the General dialog.
  4. Click the OK button.

To enable the alarming of an Alarm agent:

  1. Edit the required Alarm agent.
  2. Select the General tab from the Edit Alarm Agent dialog.
  3. Click the Yes option in the Enable Alarming section of the General dialog.
  4. Click the OK button.

 

  • Individually per incident: this option should be used when an alarm indicator may be malfunctioning or may need to be repaired or replaced or in situations when you need to disable ALL the alarms of a particular item of equipment and you cannot disable the alarming of an Alarm agent.

To temporarily inhibit incidents: this method requires you to specify the future time at which this incident will be re-enabled, in other words the time at which this temporary stoppage will end.

  1. Select the required agent, in other words the agent containing the alarmed alarm type/s. For details, see To Select an Agent.
  2. Right click this agent and select the Alarm… menu item.
  3. Click on the required alarm type in the Current list of the Alarming dialog.
  4. Check the Inhibited until checkbox at the bottom of this dialog.
  5. Specify the future time at which this incident will be re-enabled, in other words the time at which this temporary stoppage will end, as follows:

To specify a future date:

  1. Click the  button of the list box
  2. Specify the required date using the supplied calendar.

The current date is selected by default.

To specify a future time:

Use the spin control to specify this time, as follows:

The spin control displays the time in 12 hour format as HH:MM:SS AM/PM

To change the hour:

  1. Click the hour digits to the far left of the time control.
  2. Either type in the required hour
  3. Or use the spin control buttons to increment/decrement the current hour to select this.

To change the minutes:

  1. Click the hour digits to the far left of the time control.
  2. Either type in the required hour
  3. Or use the spin control buttons to increment/decrement the current hour to select this.

To change the seconds:

  1. Click the hour digits to the far left of the time control.
  2. Either type in the required hour
  3. Or use the spin control buttons to increment/decrement the current hour to select this.

To change AM/PM:

  1. Click the hour digits to the far left of the time control.
  2. Either type in the required hour
  3. Or use the spin control buttons to increment/decrement the current hour to select this.

Advantage: ONLY the affected incidents are disabled for a predefined period of time, after which they are automatically enabled.

Limitation: This requires prior planning and you need to know WHEN the stoppage will cease.

To temporarily inhibit active and/or unacknowledged incidents: this method allows you to immediately inhibit current incidents that are active and/or unacknowledged.

IMPORTANT: You must REVERSE the following change MANUALLY, when you need this agent to produce alarms again.

  1. Select the required agent, in other words the agent containing the alarmed alarm type/s. For details, see To Select an Agent.
  2. Right click this agent and select the Header… menu item.
  3. If necessary, clear (uncheck) the View derived agent status checkbox.

This should enable the Control bits section.

  1. Check the Alarm inhibit checkbox in the Control bits section.
  2. Click the OK button.

 

Now ALL incidents for this agent that are:

  • activethe monitored condition of this incident (alarm/event) is still in effect and has not yet returned to its normal operating state. will be cleared and an event log entry is added, whose “Reported Data” event log column is set to “Inhibited” and “Sub-source” event log column provides the name of the alarm agent as opposed to the name of the operator.
  • unacknowledged will be acknowledged and an event log entry is added, whose “Reported Data” event log column is set to “Inhibited” and “Sub-source” event log column provides the name of the alarm agent as opposed to the name of the operator.

Advantage: This can be implemented as and when this is required and is ideally suited to stoppages that cannot be clearly defined.

Limitation: This requires greater management as you need to REMOVE the SUSPENSION of the alarms of this agent MANUALLY.
