Printing Alarms

Before a new printer may be used, you must ensure that the host computer has the correct BIOS setting.

The Parallel Port Mode must indicate Normal or Standard (SPP), NOT Enhanced (EPP). For further details see To set up a new printer.

Note1: Typically, in order to perform line-by-line printing, no Windows driver should be installed at all, since the Windows spooler will internally cache printing until it has an entire page, so as to reduce CPU load while printing. However, specific printer drivers may be able to disable this spooling or page-caching method, and can thus work too.

Note2: It is also possible to prevent the EventOutput agent from outputting events when its clustered Agent Server is in standby mode, so that the output destination does not receive duplicate entries, by adding the DisableEventOutputOnStandby value to the registry.

Note3: The Time column of the EventOutput agent now supports MILLISECONDS.

  1. In the Configurator dialog box, select EventOutput from the Agent Type drop down list.

A list of agents is displayed in the Agent Tag list box.

  1. Select an agent and click on the Edit button.

 The EventOutput Agent dialog box is displayed.

  1. Ensure that the Activate option is set to No.
  2. Select the type of printer connection from the Printer Type list box: PARALLEL, PRINT or SERIAL, where:
  3. The PARALLEL and SERIAL options are for printers connected to local PC where the Agent Server is running. Such printers must NOT be configured in Print Manager as it creates a conflict in resource usage and hence will not work.
  4. The PRINT option is for printers that are configured in Windows' Printer manager and are usually page based and shared by other users. WHEN USING THIS OPTION, DO NOT SELECT LINE BY LINE PRINTING or you will waste paper.
  1. In the Printer Name list box, select the printer (\\<shared-directory>\<shared-printer>), or the local serial port number (COM1, COM2 etc), or the local parallel port number (LPT1, LPT2 etc).

Note: If any of the serial or parallel ports have already been assigned by Windows Printer Settings or for the mouse, they will not appear in the Printer Type List box. When setting up networked printers, avoid allocating the printer to an LPT# or COM# port.

  1. For a serial printer, specify the following setup configuration in the Setup Data dialog:

<baud-rate>, <nos-of-bits>, <parity>, <nos-of-stop-bits>, <flow-control>

For instance: 9600, 8, none, 1, Xon/Xoff

  1. Decide whether the printing will be based on Demand, size or Time, by selecting the necessary Yes radio button as follows:
  1. Demand Printing: this prints all the events that have accumulated.

As this option is represented internally by the demandPrint slot (of type Boolean) this can be externally triggered if necessary. For instance, a Button picture element with an Operator Action Behaviour attached using its Control Action option of Digital On can be used to do this.

  1. size printing: this prints events when they reach the specified size of the printed page. Two sizes can be selected from the size list box, for all printer types, namely: File Full and Page Full.

Note: A third option applies only to PARALLEL and SERIAL printers, which allows one to specify the Number of Lines by directly typing in an integer number, e.g. 1 for single line printing.

  1. Time printing: this prints events at the specified time, which can either be a specific date and Time for printing the Event Log or a recurring Interval, e.g. 1 day, when the Event Log will be printed. Simply click the required Set... button to configure this.

Note: If the Demand Printing and/or the size Printing options are selected together with Time Printing (using a recurring Interval) and a report is later activated on the Demand or on the size criterion, then the timer will reset to zero.

  1. Format the output by specifying which columns will be printed, together with their position and width, by clicking the Format button.
  2. When you are satisfied with the configuration, make the EventOutput agent ACTIVE by clicking the Activate radio button.

Note: It is also possible to configure this agent to send events to a SQL database or to a file. For details, see Method for Sending Events to SQL or Method for Sending Events to a CSV File.
