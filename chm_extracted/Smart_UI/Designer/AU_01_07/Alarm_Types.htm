Alarm Types

An alarm is triggered when one or more of the status mask bits in an alarm type of an Alarm agent matches any status bits in the agent being monitored.

For an agent to be monitored, you have to apply one or more alarm types to the agent (see Alarming an Agent). The creation of alarm types is discussed here.

Alarm Types are defined on a per Agent Type basis, which are pre-configured in the postload Adroit database file. This means that one set of Alarm types will be created for Analog agents and another set for Digital agents.

Agent Types may take the form of a descriptive abbreviation, e.g. "Overheating" for Analog agent types, or "Tripped" for Digital agent types.

Each Alarm Type must be edited to define the alarm triggers that take the form of a descriptive abbreviation, e.g. "Overheating" for Analog agent types, or "Tripped" for Digital agent types.

Each Alarm type must be edited to define the alarm triggers that take the form of a status word mask wherein specific bits are set.
