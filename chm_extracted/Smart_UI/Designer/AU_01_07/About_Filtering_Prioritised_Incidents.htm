About Filtering Prioritised Incidents

One way to ensure that your operators ONLY receive IMPORTANT alarms is to prioritise your alarms into categories of importance. Since some alarms are critical, whereas others are more informational in nature.

Once you have prioritised your incidents, Adroit provides the following ways to filter your incidents, based on their priority:

  • You can configure the priority level of each Alarm agent to discard any alarm that has a LOWER priority level. In this way you can to filter out the alarms of less important or less critical agents.

WARNING! This method REMOVES the lower prioritised alarms so that they are NOT REPORTED.

This method should ONLY be used during times of process upheaval or when alarm flooding occurs (this is indicative of a badly configured alarm configuration). 

To set the alarm priority filter of an Alarm Agent:Any incident that has a LOWER priority is DISCARDED by the Alarm agent and is as if this alarm did not exist at all.

  1. Edit the required Alarm agent.
  2. Select the General tab from the Edit Alarm Agent dialog.
  3. Specify the LOWEST incident priority level in the Priority Filter edit box of the General dialogas follows:

    0: lowest

    1: low

    2: normal

    3: high

    4: highest

    The default is 0, which means that ALL alarms are dealt with.

  4. Click the OK button.

Note: The EventLogging agent can also EXCLUDE events from agents based on their configured Alarm Priority.

  • You can let your Alarm agents process ALL the active incidents (their default setting) and then use the priorities of the incidents to filter out the unnecessary incidents.

For instance the Alarm List Viewer windows are able to filter incidents by specifying the required range of priorities. For details, see Row Filtering Configuration for Alarm Windows.

Note:Adroit also provides the Filter Group setting, which is specified in the header of each agent and is typically used to denote different plant areas, so that the alarms can be filtered per plant area.

For details on how to prioritise your alarms into categories of importance, see Configuring Incident (Alarm) Priorities.
