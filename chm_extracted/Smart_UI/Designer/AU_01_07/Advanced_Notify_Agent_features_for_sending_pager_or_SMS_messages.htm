Advanced Notify Agent features for sending pager or SMS messages

This dialog is displayed by clicking the Advanced… button in the main edit window of the Notify agent. This allows a user-defined message to be configured and sent:

  1. Use the Enter a message, edit box or edit the value slot of the Notify agent directly, to define the text that is to be sent, in this message, ether use plain text in the message or also send process values as part of the message.

Note: Messages, which exceed 79 characters (this length excludes the mandatory zero terminator character), will be truncated. When calculating the total message length, remember to include the number of characters of the required telephone number (user code) and the additional separator character.

  • Either click the Send button, to manually send this message.
  • Or in the Enter a tag to trigger the sending of a message the message, type in or use the browse button to browse in an tagA fully qualified named value in Adroit (agentName.slotName). (digital or analog) which will trigger the message transmission.

Typically, a trigger is used to send process values at a specific time or when a specific plant event occurs.

Sending process values via pager or SMS messages:

When editing the value slot of the Notify agent to define text that is to be sent, specify <tag.slot> in the message to send a process value.

For instance, by setting the value slot of the Notify agent to the following: 

The dam is: <DAM_LEVEL.value> percent full.

The device could receive the following message: "The dam is: 57.23001 percent full."

 

However, an optional format specifier, e.g. %.0f and %H:%M:%S:%L, can be used to format the output.

For instance the following message could also be specified:

The dam is: <%.0f, DAM_LEVEL.value> at <%H:%M:%S:%L, DAM_LEVEL.time>

The device could receive the following message: "The dam is: 57 percent full at 09:51:06:263"
