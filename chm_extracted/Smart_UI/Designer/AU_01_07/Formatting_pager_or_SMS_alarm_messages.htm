Formatting pager or SMS alarm messages

This dialog is displayed by clicking the Format… button in the main edit window of the Notify agent. This dialog allows the selection and format of the relevant information fields that are to be sent to the off site personal:

  1. Use the Information to send table to select the information that is to be sent.

The table has the following columns:

  1. Field: Use this column to select or unselect the various information fields, by using the clearing or checking the checkbox, in each of the following rows:

Source, Date, Time, Agent, Description, Alarm Type, Reported Data, Computer, Sub-Source, Category, Action, Event ID, Extra Data, Filter Group and Priority. For a description of each of these rows, see To Specify the Column Format for Event Output Agents.

  1. Width: This column displays the configured width of the Fields.
  2. Sample: This is a hard-coded sample of the typical information to be found in each of the Fields.
  1. Use the buttons to organise the Fields in the Information to send table, by moving the highlighted Field up or down.
  2. Enter the desired width of the currently selected Field, in the Width, edit box, which is automatically selected as soon as a Field is specified.
  3. Check the Trim spaces option, so that all empty spaces are removed from the Fields that are sent.
  4. Check the Include field name in message with separation text option, so that field names are also included, separated from the field value by the specified separator.
  5. Enter the desired Field by field separation text.
  6. Sample, using the existing sample values, this displays how an alarm will appear when it is received.

Note1: The most frequently used configuration of the Fields is the following: Date (Width=5); Time (Width=5); Description (Width=20); Alarm Type (Width=10); Reported Data (Width=8).

Note2: The message length is limited to 70 characters.
