Sample VBA Code

For details, see Steps required to Monitor Real-time Data or List of all the OLE Functions

 

The following VBA subroutine illustrates the steps involved in monitoring real-time Adroit data:

'--------------------------------------------------------

' Subroutine Subscribe: establishes ongoing realtime

' subscription for a group of tags

'--------------------------------------------------------

Sub Subscribe()

 

' Step1 - Create an OLE Server Data Object 

Set dataObj = CreateObject("AdroitServer") 

 

' Step2 - Get the Requests collection 

Set reqs = dataObj.Requests 

 

' Step3 - Add each slot we’re interested in as a 

' property in a property set 

Set p = reqs.CreateProperties() 

colNo = 0 

For Each col In Selection.Columns 

If colNo <> 0 Then 

Set pr = p.Add(col.Cells(1).Value) 

End If 

colNo = colNo + 1 

Next 

 

rowNo = 0 

For Each rw In Selection.Rows 

If rowNo <> 0 Then 

Set r = reqs.Add(rw.Cells(1).Value, p) 

End If 

rowNo = rowNo + 1 

Next 

 

' Step4 - Save the Data Object 

fileName = ActiveSheet.Name + ".MIS" 

dataObj.SaveAs (fileName) 

 

' Step5 - Copy and Paste links 

dataObj.IncludeNamesOnClipboard = FALSE 

dataObj.Copy 

ActiveSheet.PasteSpecial Format:="Text", link:=True 

 

' Step6 - Set update frequency and start the updates 

dataObj.UpdateFrequency = 1000 

dataObj.Active = TRUE 

 

End Sub
