Agent Server Window

This window contains a list of events, along with the date and time at which they were logged to this window, detailing the loading of the Agent Server e.g. the component Adroit agents, it also contains the following troubleshooting tools and aids.

  1. The Agent Server window title bar, displays both the current status of the Agent Server and the current Adroit configuration.
  2. The status bar displays the percentage of physical memory being used by the system. When this is greater than 100 % then all physical memory is occupied, requiring the use of the virtual memory (the paging file), which will slow down the performance of the system and of the Agent Server. Ideally, this figure should not exceed 75%.
  3. The File menu, contains the following commands:
  1. The Save Messages command, allows a text file and path to be selected, into which the current logged events in this Agent Server window can be saved, by default, a "message.txt" file will be saved to the "My Documents" folder.
  2. The Exit command closes the Agent Server window.
  1. The View menu, contains the following commands:
  1. The Explorer command, which launches the Adroit Project Explorer once the Agent Server has loaded. For details, see The Project Explorer .
  2. The Status Bar command, displays or hides the status bar at the bottom of this window. A tick symbol indicates the status bar is visible.
  1. The Options menu, contains the following commands:
  1. The Spacer command inserts a line into the Agent Server window with the current date and time, containing the following text "====SPACER===="
  2. The Jotting command provides you with a dialog box, so that related details or comments can be entered into this Agent Server window, along with the date and time at which the entry is made.
  3. The Pause command suspends the loading process, a tick symbol alongside this command, indicates that the loading process is currently being suspended. To resume loading click this command again, removing this tick.
  4. The Debug sub-menu which contains the following commands:
  5. Debug Flags… containing all the debug flags that were originally located in the Adroit setup program. These are off by default and are only intended to be used by the Adroit support engineers, for diagnosing system problems. (see Adroit Support Debug Flags for a description of these flags)
  6. Note: When these debug flags are enabled, the performance of the Agent Server will decrease.
  7. Log thread creation events, this logs an event to the Agent Server window, whenever a thread is created. A tick symbol alongside this command indicates that it has been selected.
  8. Log thread destruction events, this logs an event to the Agent Server window, whenever a thread is destroyed. A tick symbol alongside this command indicates that it has been selected.
  9. Log system events, this enables all internal events in the Agent Server to be logged to the event log. A tick symbol alongside this command indicates that it has been selected.

Note: the Debug Flags… and Log system events items are not saved when they are set from the Agent Server window. To save these items, they must be configured from the Adroit Setup program.

  1. The Minimise to tray command, affects where and how the Agent Server window appears when it is minimised. Normally, when minimised this window appears in the task bar along with any other currently open program. When this command is selected, however, the Agent Server window appears as the following icon , which is placed into the tray in the bottom right of the screen. A tick symbol alongside this command indicates that the Agent Server window will become a tray icon when it is minimised.

The Agent Server window Tray Icon.

Note: If this Minimise to tray command is selected, then on the next startup the Agent Server window will immediately startup as a tray icon; similarly if this is disabled then on the next startup the Agent Server will startup as an Agent Server window.

  1. The Help menu, contains the About… command, which displays the Adroit version information dialog.
