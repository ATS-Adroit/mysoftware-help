Agent Server Window Title Bar

The title bar, of the Agent Server window, displays both the current status of the Agent Server and the current Adroit configuration.

  1. The first text in the title bar, indicates the status of the Agent Server, as follows:
  2. <STARTING> i.e. the Agent Server is busy loading.
  3. <READY> i.e. the Agent Server has started.
  4. <SHUTTING DOWN> i.e. the Agent Server is closing.

Note: The status of the Agent Server is also indicated by the Agent Server tray icon, if the Minimise to tray setting is enabled (ticked) in the Options menu, as follows: flashing yellow light (STARTING), green light (READY), red light (SHUTTING DOWN).

  1. The following title bar text, indicates the current Adroit configuration, as follows: AgentServerName (ProjectName), where:
  2. AgentServerName is the name of the Agent Server that is being opened, which is configured in the Adroit Setup.
  3. ProjectName is the name of the Adroit project, that is also configured in the Adroit Setup.
  1. The standard Agent Server window title "Adroit Agent Server", follows this.
