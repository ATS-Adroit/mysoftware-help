Versioning WGP Files

Adroit WGP files from version 6, contain versioning information to provide an audit trail of changes for debugging and troubleshooting purposes and to assist in locating the required backup file when recovering lost changes.

Note: In addition to this version information, Adroit WGP files can ensure that changes made to the WGP file are safeguarded between the regular backups. For details, see Configuring Automatic WGP File Backups.

WARNING! This feature is merely intended to AUGMENT the existing backup system and NOT to REPLACE it i.e. it is still imperative that an efficient backup system is in place! For details, see Creating Backup Procedures.

Adroit WGP file structure has been modified to contain this versioning information, as follows:

  1. Line 1: This remains unchanged and contains the number of agents stored in the WGP file: SYS=#, where # is the number of agents currently added to this Agent Server.
  2. Line 2: From Adroit 6 onwards, this contains the version of Adroit: AVER=XYZ, where X is the major version number, Y is the minor version number and Z is the update number, therefore for Adroit 7.0.0, this number will be 700.

Note: This is especially important for forward compatibility.

  1. Line 3: From Adroit 6 onwards, this contains a sequential version number: FVER=1

Note: This version number will increment EACH time the WGP file is saved, regardless as to whether its contents have been changed or not.

  1. Line 4: From Adroit 6 onwards, this contains an optional version description for the WGP file, describing the changes made to it since its previous save: DVER=Adroit default configuration.

The manner in which this description is specified, depends upon how this WGP file is being saved, as follows:

  • The WGP file is being automatically saved: In this case, the new wgpdescription String slot of the System Information agent, can be used to programmatically provide the required version description instead.
  • The WGP file is being manually saved: In this case, the Save WGP file pop-up dialog can be displayed to specify this version description or reason for changing the WGP file can be specified.

This pop-up dialog only appears when the Enable WGP version description entries checkbox is checked, when configuring the WGP Versioning group of advanced Agent Server settings, which is displayed as follows:

Using the Adroit Config Editor:

Launch the Adroit Config Editor.

Click Agent Server Configuration in the right hand pane.

Click Advanced Agent Server Configuration in the right hand pane.

This displays a page of grouped advanced Agent Server settings.
