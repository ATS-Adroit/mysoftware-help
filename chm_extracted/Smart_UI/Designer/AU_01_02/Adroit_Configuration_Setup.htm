Classic Configuration Setup

This Setup utility is used to configure your Classic Adroit installation, after it has been installed.

To run Setup you must be logged on with Administrator privileges.

Press the Windows key and start typing in Classic Setup and select it from the list.

Note: You can also configure the Agent Server and protocol drivers by using the Agent Server Configuration section of Adroit Config Editor.

This Adroit Configuration Setup program, only displays the Adroit component installation and its relevant configuration pages, as follows:

  • If the Agent Server is installed then this program is entitled "Adroit Configuration Setup – FULL" and all the configuration pages are displayed, as follows:

Note: This can be launched using the /smartui command line parameter to HIDE the UI Connection and UI Preferences tabs.

Agent Server Configuration : to configure default settings of the Agent Server

Advanced Agent Server Configuration : advanced configuration options for the Agent Server, such as enabling auditing and/or versioning.

Typically the Agent Server is configured to run as a Service during install, although you can do this after the install if necessary by using specific command line options. For details, see To install or uninstall the Agent Server as a service.

Drivers Configuration : to install the necessary protocol drivers and add, configure and remove their device

Event Log Configuration : to specify these event-specific settings

Note: This can be launched using the /smartui command line parameter to HIDE the UI Connection and UI Preferences tabs.

  • If ONLY the Agent Server API (MISSRVR) Interfaces are installed then the Adroit Configuration Setup program is not installed.
