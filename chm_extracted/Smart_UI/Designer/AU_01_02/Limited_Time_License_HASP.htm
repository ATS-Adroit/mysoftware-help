Limited Time License HASP

IMPORTANT: When a HASP is not detected when the Agent Server is started and the Agent Server is not being otherwise licensed, then the Agent Server will automatically run in limited time license mode.

Use the limited time license HASP if the Agent Server is not currently licensed.

This runs the Agent Server with a 120 minute operating license with 20000 scan points and 2 remote connections.

When this period of time ends, the scanning of devices will stop and any remote server connections will be lost and not reconnected.

Typically this can be launched from the Adroit Start menu by clicking on the Start menu, Programs, Adroit 10, and clicking the Adroit Agent Server (timed license) item.

Although it is also possible to launch the Agent Server with the following command line parameter: –demo e.g. C:\Program Files\Adroit Technologies\Adroit\as.exe –demo

There are message boxes and event log entries explaining these important events. Also the HASP agent provides the following status bits that indicate events relating to the use of this mode of licensing the Agent Server:

  • TimedLicence: ON when the Agent Server is running in time license mode, which automatically occurs when the Agent Server is started and the HASP cannot be found.
  • TimedLicenceExpired: ON when the Agent Server is running in time license mode and the timed license period has expired, so the Agent Server needs to be restarted to re-enable scanning.

Note: To run the Agent Server Service in timed license mode, use the /-demo startup option, which is specified AFTER installing the Agent Server service, as follows:

EITHER open CMD.exe and type in the following command: "net start agentserver /-demo"

OR open the Services applet (in Administrative Tools), right click the AgentServer service, select Properties and specify –demo in the Start parameters edit field, then click the Start button and the Ok button.

IMPORTANT: If using the Services applet, this ONLY starts this service in demo mode for a single session only. The demo mode is not applied to all instances of the service thereafter.
