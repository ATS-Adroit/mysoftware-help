Starting and Stopping a Control Recipe from Another Recipe

Example:

A Master Recipe with two Control Recipes, Run_Cool and Run_Heat, that run batches of control recipes Cool and Heat of the recipe agent SET_TEMPERATURE.

When the control recipe Run_Cool is active, the following will happen:

  1. Set SET_TEMPERATURE.currentRecipeName = "Cool"; i.e. select control recipe Cool.
  2. Initiate the verification check for phase 1 (Step 1). That is, wait for the preconfigured verification time before continuing.
  3. If SET_TEMPERATURE.currentRecipeName = "Cool", then verification passed; i.e. the selection of control recipe Cool was successful.
  4. End of phase 1 (Step 1), go to next step.
  5. Set SET_TEMPERATURE.batchPrefix = "Cool#".
  6. Set SET_TEMPERATURE.batchCounter = 1. Hence, the batch name for control recipe Cool becomes "Cool#1".
  7. Set SET_TEMPERATURE.runRecipe = "Cool"; i.e. activate control recipe Cool.
  8. End of phase 2 (Step 2-4). If SET_TEMPERATURE.statusBit17 = 0, wait until it becomes equal to 1 and move on to the next step. That is, wait for SET_TEMPERATURE to become Active and then continue.
  9. End of phase 3 (Step 5). If SET_TEMPERATURE.statusBit16 = 0, wait until it becomes equal to 1 and move on to the next step. That is, wait for control recipe Cool to finish and then continue.
  10. End of phase 4 (Step 6). Go to step 4. Hence, batches of control recipe Cool will be activated continuously until control recipe Run_Cool is stopped.
