Usage Guidelines for Script Agents

Note: All Script Agents require a scan point license to run. This license is checked prior to actually running the Script for the first time (on a per agent basis) and is only returned when the agent is deleted.

The Script agent should only be used by those very familiar with the VBScript or the Jscript languages and is familiar with the pitfalls of bad programming.

Badly written scripts can cause the Agent Server to operate erratically, for instance, if the Scripts are written in such a way that they "hog" CPU time.

Note: If you need to install language references for both JScript and VBScript - ask Adroit support for more information.

Adroit Technologies is proud of its reputation for superior service and support and wish to maintain this reputation in the marketplace. In order to do this we are implementing a scripting service policy.

This policy is designed to give users access to relevant skills as well as confidence about taking advantage of this technology in realizing sound Adroit solutions. Contact the Adroit Support Desk for further information.

Note:Adroit Technologies does not offer free support for debugging scripts.

These agents require careful consideration in terms of both the number of agents to be used and the amount of work that they are to do, as they are resource "hungry".

Hence, both the Agent Server memory and overall memory usage should be monitored during configuration to avoid the excessive usage of these resources. The CPU usage should be monitored while during operation to ensure that the computer is able to handle the additional load.
