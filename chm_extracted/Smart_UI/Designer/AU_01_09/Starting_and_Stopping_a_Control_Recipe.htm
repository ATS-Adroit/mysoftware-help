Starting and Stopping a Control Recipe

A control recipe can be started (or stopped) through a recipe monitor window, while editing the control recipe list or by directly accessing its slots.

From a recipe monitor window:

  1. Open a new or existing Recipe Monitor window.
  2. Operate this Recipe Monitor window.

From the Configurator:

  1. Select a recipe agent from the list of recipe tags.
  2. Click Edit and wait for the Edit Master Recipe window to show.
  3. Click Recipes... and wait for the Control Recipe List window to show.
  4. Select a control recipe from the list.
  5. Click the Start button.
  6. If necessary, click the Stop button to stop the active control recipe.
