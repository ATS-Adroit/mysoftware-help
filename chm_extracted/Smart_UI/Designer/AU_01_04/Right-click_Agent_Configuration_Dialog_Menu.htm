Right-click Agent Configuration Dialog Menu

The Agent Configuration dialog provides a right-click menu as an alternate means of accessing much of the existing functionality provided by this dialog.

Simply select the required agent(s) in the Agents list box and right-click to display the following commands:

  1. Edit… an existing agent or to bulk edit agents of the same type.
  2. Scan… (communicate) the values of one or more slots of an agent to / from a Device or to contiguously scan agents of the same type.
  3. Alarm… one or more status bit combinations of an agent.
  4. Log… (record) the values of one or more slots of an agent to a database.
  5. Groups… displays the group membership(s) of this agent for configuration, if required.
  6. Used by… displays which agents, if any, are using (subscribing to) this agent.
  7. Header… displays the bits within the status word of an agent and to configure the other common header slots for configuration.
  8. Remove (delete) an agent.

For details on the Configurator dialog, see The Agent Configuration Dialog.
