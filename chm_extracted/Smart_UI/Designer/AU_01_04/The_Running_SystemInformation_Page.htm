The Running SystemInformation Page

The System Information agent acts as an information center containing 5 tabbed pages of data slots that are global to the Agent Server. For details on how to access these pages of data, see Editing the SystemInformation Agent.

Note: The actual slot names and NOT their literal descriptions are specified, for ease of reference, since you most likely will need to display one or more of these slots on mimics.

Run Statistics

  1. activeAgents: This indicates the total number of configured agents in the current Agent Server session.
  2. systemAgents: This indicates the number of agents that have been created by Adroit in the current Agent Server session.
  3. userAgents: This indicates the number of agents that have been created by the user in the current Agent Server session.
  4. numAgentTypes: This shows the number of different agents types that have been used in the current Agent Server session.
  5. connections: This shows the number of remote connections that have been made in the current Agent Server session.
  6. subscriptions: This shows the current number of subscriptions made within the current Agent Server session. Agent Server clients can subscribe to particular values within the agents, and they are only notified when these values change.
  7. channels: This shows the current number of client-server connection from the Agent Server to the outside world, such as to the User Interface, other Agent Servers, DDE links.
  8. proxiesCreated: This shows the number of proxy agents that have been created in the current Agent Server session.

 

Current date & Time

  1. CurrentTime: This displays the current date and time in the default Adroit time format.
  2. Year: This displays the current year.
  3. Month: This displays the current month as a number.
  4. Day: This displays the current day of the month.
  5. Hour: This displays the current hour.
  6. Minute: This displays the current minute.
  7. Second: This displays the current second.
