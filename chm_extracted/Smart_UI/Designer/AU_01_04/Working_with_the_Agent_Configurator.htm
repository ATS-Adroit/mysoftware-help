Working with the Agent Configuration dialog

This resizable dialog is the central point from which you can configure agents in a local or remote Agent Server. This allows agents to be creating and configured from Adroit.

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

The Agent Configuration dialog provides the following functionality:

  • an Agent section that allows you to add agents of the selected agent type in the Type list (if possible) or displays the name of the currently selected agent in the Agents list that will be configured.
  • an Agent filter section that allows you to limit the display of:
  • the available agent types displayed in the Type list when designing your system, by checking the checkboxes of the default agent groups. For details, see Default agent groups.
  • the available agents displayed in the Agents list to those having specific name/s, by specifying an optional agent filter string in the Filter edit box. For details, see Filtering Agents.
  • a list of buttons down the right side of the dialog that allows you to perform the following agent-specific functions:

    Find and select an existing agent.

    Add a new agent.

    Copy (duplicate) an existing agent configuration.

    Edit… an existing agent or to bulk edit agents of the same type.

    Header… displays the bits within the status word of an agent and to configure the other common header slots for configuration.

    Groups… displays the group membership(s) of this agent for configuration, if required.

    Used by… displays which agents, if any, are using (subscribing to) this agent.

    Scan… (communicate) the values of one or more slots of an agent to / from a Device or to contiguously scan agents of the same type.

    Alarm… one or more status bit combinations of an agent.

    Log… (record) the values of one or more slots of an agent to a database.

    Remove (delete) an agent.

  • a right-click menu as an alternate means of accessing many of the existing agent Configurator functions. For details, see Right-click Menu.

Only when these changes made to agents are saved, will they be written to the Adroit database file (.WGP) file of the Agent Server. For details, see Saving agents or Backing Up WGP Files.

 

For further details, see Configuring the Agent Server or the list of available agent types and their slots (values).
