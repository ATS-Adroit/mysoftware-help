The Other Slots SystemInformation Page

The System Information agent acts as an information center containing 5 tabbed pages of data slots that are global to the Agent Server. For details on how to access these pages of data, see Editing the SystemInformation Agent.

Note: The actual slot names and NOT their literal descriptions are specified, for ease of reference, since you most likely will need to display one or more of these slots on mimics.

  1. startPoolId: This displays the internal ID of the current Agent Server session.
  2. typeLst: Double click on typeLst to display the list of agent types used within the Agent Server.
  3. connections: This displays the number of remote connections made to the Agent Server, there will always be at least one i.e. the connection made to itself.
  4. connectionLst: Double click on connectionLst to display the list of remote connections made to the Agent Server.
  5. shutdown: If set to 1, this will force the Agent Server to cleanly shut itself down.
  6. saveShutdown: If set to 1, this will save and then cleanly shutdown the Agent Server.
  7. dayOfWeek: This specifies the day of the week as a number from 0 (Sunday) to 6 (Saturday).
  8. serverType: This indicates the current Server configuration of this Agent Server: (0) Cluster, (1) Cluster aware, (2) Standalone/Distributed.
  9. serverMode: This indicates the current mode of this Agent Server, if it is part of a cluster: (0) Master, (1) Standby, (2) Normal.
  10. serverState: This indicates the current state of this Agent Server, if it is part of a cluster: (0) Unhealthy, (1) Healthy.
  11. internalState: This specifies The internal state of the server.
  12. internalStateStr: This specifies The internal state as a string.
  13. serverModeStr: This specifies Master/Standby/Normal.
  14. clusterName: This specifies the name of the cluster, if this Agent Server is part of a cluster.
  15. clusterPartner: This specifies the server name of the cluster partner, if this Agent Server is part of a cluster.
