The SystemInformation Agent

The System Information agent acts as an information center containing data that is global to the Agent Server. There is only one System Information Agent in an Agent Server (identified as systemInfo) and it is created automatically at start up. When this agent is edited, 5 pages of data slots are accessible.

Note: The actual slot names and NOT their literal descriptions are specified, for ease of reference, since you most likely will need to display one or more of these slots on mimics.

It can also be used to configure the Agent Server start-up parameters and it is possible to display some of the System Information agent data in a picture at runtime, for instance the Current date & Time.
