Configuring the Agent Server

The Agent Server is the storage facility for all real time and historical data. For further details, see About Agent Servers.

The real time data resides within intelligent objects, known as agents, which exchange messages with other agents or picture objects either from their local host computer or from remote computer nodes elsewhere on the network. For details, see About Agents.

Historical data is written to disk where it is available for rapid retrieval and on-line analysis. For details, see Logging Values.

 

The Adroit database (.WGP) file or load file stores almost all of the data and configuration of the Agent Server, including the added agents, their values and their alarming, logging and scanning configuration. For details, see About Adroit Database Files.

The Agent Server Configurator creates, manages and stores the configured agents and their slots (values) in the Agent Server. For further details, see the list of available agent types and their slots (values).

Note: The Project Explorer can also be used to configure the Agent Server. For details, see The Project Explorer.

Before you can create or edit any agents you must be connected to an Agent Server.

If necessary, you can manually specify which Agent Server the Configurator should connect to and configure. For details, see Connecting to an Agent Server via the Classic UI.

Note1: Only when these changes made to agents are saved, will they be written to the Adroit database file (.WGP) file of the Agent Server. For details, see Saving agents.

Note2: These agents can also be exported to CSV files for editing by 3rd party applications and then imported into the Agent Server. For details, see Exporting and Importing Agents.

Related topics

Agent Server Connection Methods: Adroit provides three methods for allowing multiple distributed Agent Servers to seamlessly share their agents and the data that they contain.

Proxy servers : An Agent Server that creates proxy agents for agents that exist on remote Agent Servers on the same project because it itself does not contain any configured agents.

Note: A Proxy Server (an Agent Server that is licensed for ZERO scan points) can proxy an unlimited number of agents, whereas a normal Agent Server is only able to create as many proxy agents as it has scan points and therefore must be licensed for AT LEAST the same number of scan points as the remote Agent Server.

Clustering Agent Servers : A mechanism for providing client and server redundancy, previously known as hot standby.

For more details on addressing the important issues that affect the operation and configuration of clustered Adroit Agent Servers, see Important Points to consider when Clustering Agent Servers.

For more details on detecting and solving issues that most frequently prevent clustered Adroit Agent Servers from working, see Troubleshooting Clustered Agent Servers.
