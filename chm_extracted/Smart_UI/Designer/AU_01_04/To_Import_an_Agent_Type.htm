Importing an Agent Type

Configuration data can be exported from Adroit and edited off-line in third party applications, like Microsoft Excel, as comma separated variable data (.CSV) and then converted into an Adroit .WGP load file format.

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Select the Import item of the Classic UIFile menu.

Note1: Agents that already exist are not imported at all. Therefore, ensure that the agents that are to be re-imported are deleted first, before importing the modified agents. Remember, agents cannot be deleted before they have been un-alarmed, unscanned and "undatalogged".

Note2:DO NOT use commas in the agent descriptions – if a comma is required use a ‘~’ instead.

Note3: Adroit is unable to import agents from CSV files, which have paths in excess of 65 characters, even though Adroit is able to export to these long paths. Therefore ensure that the path and file name of the exported CSV file is less than 65 characters, when exporting your agents.

Alarm agents CAN be imported into Adroit, making bulk-alarming configuration possible. For details, see Importing Alarm Agents.

Each agent type has its own .CSV format

If agents need to be imported from a .CSV file, then open the Agent Configurator, and select Import from the File menu and the Choose file to convert dialog will appear:

Choose the .CSV file to convert, and then the data will be converted to the .WGP configuration file given in the Save As dialog. This file will be called Import.WGP by default, but the user may choose any filename he or she desires.

The file can then be loaded on-line into the current Agent Server using the Load Agents... Classic UI menu item.

Note1: When importing scanning information into a Device agent, use the Import button within the Device Agent’s configuration edit dialog

Note2: When importing the Master recipe (and its associated Control recipes) into a Recipe agent, use the Import button within the Recipe agent’s Master recipe configuration edit dialog.
