To Edit or Configure the MultiState Agent

The MultiState agent.

  1. Edit an agent of type: Multistate.

The Edit Multistate Agent dialog box is displayed.

  1. The bottom half of the dialog contains the Inputs group box. In this box is a slot for each input, labeled v01 through v16.

    To source the input from any other agent, the engineer simply types in the agent.slot string, or pastes it in by using the agent Browser to make an ongoing real-time connection to the agent and slot referenced.

    To see the value rather than the name of the data source, all the engineer needs to do is select the Values as opposed to the Names radio button at the bottom right hand corner of the dialog.

  2. The v01-v16 input slots can be dynamically renamed for each MultiState agent.

    If the Names radio button is selected and a character string is typed into one of the v01 to v16 fields that is NOT recognised as an agent.slot name, it will be treated as a replacement slot name in place of the default slot name.

  3. The top half of the dialog contains the States group box, and it is here that the engineer modifies the agent’s state configuration. Clicking either the Add... or Edit... buttons opens the MultiState State Configuration dialog, which allows you to:
  1. Page sequentially forwards and backwards through the different states by using the Next and Previous buttons
  2. Go directly to any one of the sixteen possible agent’s states by choosing it from the State No. list box
  3. Enter or modify the state description text for the selected state.

Note: In order to add a new state, a description of the new state must be entered into the Description box.

  1. Remove a state by deleting a state’s description text
  2. Specify the input-true and input-false masks that effectively define the state being configured. Select inputs from the list of available inputs into either the True or False list to ensure that this new state is not duplicated.
  3. Specify two lists of outputs that will be automatically carried out on attainment of this state. Outputs in the True-List will be set TRUE and outputs in the False list will be set FALSE.

Note: this output should not be fed back to the MultiState agent itself, either directly or indirectly. A circular reference error will be given, since agents are generally not recursive.

Although this agent has the facility to be used as a marshalling agent this has been replaced by the Marshal agent, which is specifically designed to do this task and is more powerful and easier to use. For details, see The Marshal Agent.
