Specific Status Bits of the Command Agent

The Command agent can both send SMS messages either manually or automatically and can escalate messages to another Command agent, if necessary. However, it is in receiving textual commands in SMS messages that it is able to remotely configure Adroit.

The following status bits of this agent can be used for diagnosing the sending and receiving of SMS messages and to determine which commands this Command agent can receive and their additional configuration, as follows:

  • statusBit16
    MsgSendError

On if the last message could not be sent due to cell phone network-specific problems, such as signal problems etc.
  • statusBit17
    AllCommands

On when the Enable commands checkbox is checked, to indicate that this Command agent is able to perform commands that it receives. For details, see Allowing Commands to be Performed.
  • statusBit18
    SetCommands

On when the Allow ‘Set’ commands checkbox is checked, to indicate that this Command agent is able to perform SET commands that it receives. For details, see Specifying Permitted Commands or SET Commands.
  • statusBit19
    GetCommands

On when the Allow ‘Get’ commands checkbox is checked, to indicate that this Command agent is able to perform GET commands that it receives. For details, see GET Commands.
  • statusBit20
    AckCommands

On when the Allow ‘Ack’ commands checkbox is checked, to indicate that this Command agent is able to perform ACK and LACK commands that it receives. For details, see ACK Commands.
  • statusBit21
    RepCommands

Currently not in use.
  • statusBit22
    SubCommands

Currently not in use.
  • statusBit23
    ExpandPseudos

On when the Expand pseudonyms in messages checkbox is checked, to indicate that any pseudonyms and macros specified in an incoming message received by this Command agent will be correctly interpreted and any outgoing messages will have the pseudonyms replaced with the full tag.

For details, see Enabling Pseudonyms and Macros or for details on pseudonyms and macros, see Using Pseudonyms and Macros.
  • statusBit24
    SignalError

On if either the signalStrength slot is less than 29 % or the bitErrorRate slot is greater than 40 %. For details, see Diagnosing the GSM_SMS Device.
  • statusBit25
    SetByPseudos

On when the Only ‘Set’ by pseudonym checkbox is checked, to indicate that SET commands can ONLY use pseudonyms and macros. For details, see Additional SET Command Restrictions.
  • statusBit26
    AllowAnonymous

On when the Allow anonymous callers checkbox is checked, to indicate that this Command agent is a potential security risk as it is able to receive messages and potential commands from any caller. For details, see Configuring Anonymous Caller Access.
