The Digital Agent

A Digital agent stores a Booleana value that only has two discrete states, 0 (FALSE) or 1 (TRUE). value that provides the following functionality:

  • Monitoring the current state of this value and setting its On or Off status bits accordingly, which can be alarmed.
  • User-configurable textual descriptions of its two states.
  • Monitoring its value for changes, where any change in value causes the agent to log an event and set a Changed status bit, which can be alarmed.
  • Recording the time this value changes, which is saved to the time slot of this agent.
  • Inverting the Raw value (typically this is the value that is scanned from the front-end device).
  • A cold start value initialization option when starting the Agent Server.
  • A pulsed output option to specify a user-configurable delay to maintain its ON state.

For details on how to configure some or all of this functionality for a Digital agent, see Configuring Digital Agents.

Typically Digital agents should be used for Boolean process values stored in a front-end device that may need to be inverted first and/or which needs its states to be closely monitored and/or alarmed.

If you ONLY want to store a Boolean value then use the Boolean agent instead.

Note: For those of you running a clustered Agent Server, this agent supports real-time catch-up so even if the master Agent Server fails, the standby will seamlessly continue with the current configuration settings.

For details of the specific status bits of this agent that indicate the current state of this value and other agent-specific conditions that can be alarmed or directly displayed on a mimic to indicate when these conditions occur, see Specific Status Bits of the Digital Agent.

 

For a description of how this agent can be used to create a half hour average of a process input, see To Create a Half Hour Average of a Process Input .

 

For a description of all the slots (values) contained in this agent, see Digital Agent Slots.

For a description of how this agent is saved in the Adroit database (.WGP) file, see Digital Agent Database File Format.
