Editing an OID in the list

You can edit one or more of the fields of the SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. (OIDs) that are already in the OID list.

Note: You need to Disable polling before you can edit listed OIDs.

To edit an OID in the list:

  1. Select the row of the required OID in the list.
  2. Click the Edit OID list button to display the Edit OID entry dialog.

Tip: Double-clicking the row of the required OID also displays this dialog.

  1. If necessary, modify the numeric description of the required OID.

Tip: Since it is ESSENTIAL to specify this address correctly, we recommend that you copy this address from the relevant MIBSNMP Management Information Base, this is a database that lists uniquely described and organises SNMP managed objects hierarchically. file and then use the button to paste it into this cell.

  1. If necessary, modify the Name used to identify this OID in the list.

Note: This name does NOT have to be the textual description of the OID.

  1. If necessary, select the modify the Type of data returned by this OID value.
  2. If necessary, change the Tag that either stores or changes this OID value.

Tip: Use the Browse tag button to add and/or select this tag. For details, see Selecting a Tag Using the Agent Explorer.

  1. If necessary, modify the Rate, in milliseconds, at which this OID value should be polled (monitored) or specify 0 to use the default Poll rate of this agent, specified in the Poll settings section.

    Note: This rate cannot be less than 5 seconds, the minimum for the Poll rate for this agent.

  2. If necessary, specify whether this OID value should be Enabled for automatic polling.
  3. If checked its value will be copied into the specified Tag whenever it changes.
  4. If unchecked (empty), you must manually poll this entry when it is required.
  1. If necessary, specify whether this OID value will be Writable.
  2. If checked then when value of the specified Tag changes it is written to this device, provided the necessary connection details are specified.
  3. If unchecked (empty) then this value will ONLY be monitored by this agent, depending upon the configuration of the Enabled for automatic polling checkbox. 

Note1: The and buttons can select the OID entries above and below in the list

Note2: If more than one OID entry is edited then these changes will ONLY be made once the OK button is clicked.
