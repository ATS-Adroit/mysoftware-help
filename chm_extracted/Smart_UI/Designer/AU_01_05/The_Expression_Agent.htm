The Expression Agent

The Expression agent can create powerful user-defined calculations.

It functions by gathering data from other agents, or from the plant directly by scanning into slots V01 to V20, and performs a user defined mathematical transformation to calculate an output value.

This result can be fed into a front-end device on the plant, or to a picture in the Classic User Interface for display, or sent to another agent.

Note1: The Expression agent supports real-time catch-up.

Note2: It is not advisable to use the slots of scan agents in expressions, since the names of these agents are not fixed, but are changed by Adroit according to the scanning configuration.

By design, a triggered Expression agent will always generate subscription updates for the value slot even if the value slot has not actually changed, which can lead to unnecessary Agent Server CPU loads and network traffic when remote UI clients have been deployed. These unnecessary subscription updates can be disabled, by adding the PropagateTrigger registry value.

The Expression agent can be combined and connected to several other Expression agents, so encouraging the use of standard expression building blocks and the reduction of complexity.

The Expression agent contains:

  • Value slot that displays the result of the calculation (value).
  • Units slot that displays the units of measurement of the value.
  • Variables containing 20 input slots (V01-V20).
  • Expression slot containing terms and mathematical operators.
  • Display options for selecting whether values or names are shown.
  • Evaluation options that determine whether the calculation is on a continuous basis or triggered.
  • Trigger slot with a Calculate command button, which performs a calculation on demand irrespective of the state of the expression trigger. This would normally be used to verify calculations when configuring the Expression agent.
  • Specific Status Bits to reflect whether the value is equal to zero, greater than zero, less than zero, greater than or equal to zero, or less than or equal to zero.
