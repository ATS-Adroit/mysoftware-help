Advanced OEE agent configuration options

When editing an OEE agent, click the Advanced button to display the Advanced OEE options dialog, which allows you to configure the following:

  • Optional tag references: instead of manually specifying them or scanning the relevant slots directly, you can browse in tag values to specify the following values:
  • Available tag : a BOOLEAN value used to determine when to calculate OEE. Typically you will browse in the BOOLEAN value slot of the pre-configured Scheduler agent

Note: This value should only be ON when the machine/process is supposed to be running.

  • Running tag: a BOOLEAN value used to determine when to calculate a KPI.

Note: Running time is typically automatically incremented by the agent while this BOOLEAN value is ON.

  • Input1 tag: a REAL value that is either the measurement variable used to calculate the OEE for the monitored equipment or plant or the FIRST variable of the KPI. Typically the REAL input1 slot is scanned directly.
  • Input2 tag : a REAL value that is the SECOND variable of the KPI. Typically the REAL input2 slot is scanned directly.
  • Reject count tag: a REAL value used to determine the Quality factor of the OEE calculation.

If you are logging the data to an OLE DB database, then you can specify:

  • Product tag: a STRING value that specifies an optional product name that will be recorded with the database entries.
  • Batch ID tag: a STRING value that specifies the optional batch ID that is recorded with the database entries.
  • The Setpoints section:
  • When calculating the OEE you can define the Target value, the Low alarm and/or Low-low alarm values for the three separate calculated production factor percentages for the current shift, namely Quality%, Performance% and Availability% and/or the overall OEE% calculation.
  • When calculating a KPI you can define the Target value, the Low alarm and/or Low-low alarm values for this KPI.

Note: These alarms are calculated in real time.

  • If necessary, specify an OLE DB connection to a SQL database, using the SQL connection string field to save the OEE or KPI data for later analysis, as follows:

Note:

If you specify global, the Global OLE DB connection string of the Agent Server is used, which is specified in the Adroit Config Editor.

  • Typically, you can launch this tool from the Desktop shortcut.
  • Select the Agent Server Configuration Welcome menu item.
  • Select the Advanced Agent Server Configuration option.
  • At the bottom of the dialog, the Global OLE DB connection field is available for you to specify this connection string.

If the connection string is specified then this agent logs shift data, manually triggered snapshots and 1 minute sample data to a table called ADR_OEE. 

IMPORTANT: The current version of the OEE agent does NOT support housekeeping operations on this table.

It is up to the user to ensure that “obsolete” records are deleted as required. For instance by running SQL queries in SQL Server Management Studio.

Housekeeping SQL query example: DELETE FROM ADR_OEE WHERE [dt]<’2010/01/01’

The Disable SQL on standby checkbox (the BOOLEAN disableStandby slot), prevents this agent from logging to the database, when its Agent Server is part of a cluster and is in standby node - to prevent the logging of DUPLICATE information.

Alternatively, the OEE agent can support database transactions to a table for the purposes of data warehousing. This requires specifying the required Data warehouse sample rate from 1-60 minutes. By default this is 0 = DISABLED.
