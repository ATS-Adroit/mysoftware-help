SET Commands

Function: To modify the value of any tag (agent.slot) exposed by the Agent Server.

Note1: This command must be enabled by the Command agent, which it is sent to, before it can be performed, because it can create a serious security and operational risk through the remote modification of process and control values. For details, see Specifying Permitted Commands.

Note2: Due to the seriousness of the potential security and operational risk, additional settings are provided to further restrict the usage of this command. For details, see Additional SET Command Restrictions.

Note3: Both the command and its parameters are NOT case-sensitive; commands have only been capitalised for ease of reference.

The decision of which of the following command formats to use, is usually a tradeoff between the prior configuration in the Command agent and the required amount of typing, when specifying the SMS command itself:

Note1: Both the command and its parameters are NOT case-sensitive; commands have only been capitalised for ease of reference.

Note2: When using this command, it is the responsibility of the user to specify a value of the correct slot type for the tag (agent.slot) that is being modified.

 

Basic command syntax: SET, tagName, value

In this case, tagName is the name of the tag whose value is to be displayed and value is the required value for this tag. For instance: set,dig_01.value,1

This is the simplest format of this command, which requires the least prior configuration in the Command agent, it is able to modify the value of any tag, however it does require the most typing when specifying the command.

Note: If the Only ‘Set’ by pseudonym setting has been enabled, then this command can ONLY be performed using pseudonyms or macros and NOT by typing in the name of required tag directly. For details, see SET Command Usage Restriction.

 

Pseudonym usage: SET, pseudonym, value

In this case, a pseudonym or alias needs to be created, beforehand, for the required tag (agent.slot) and value is the required value for this referenced tag. For instance, assuming that a pseudonym called ‘dig01v’ is created to represent ‘DIG_01.value’, this command can be specified as: set,dig01v,1 

Although pseudonyms save on the typing when specifying the command, ONLY the tags that have defined pseudonyms for this Command agent can be used. For details on creating and using pseudonyms, see Creating Pseudonyms.

 

Macro usage: macro

In this case, a macro or alias needs to be created, beforehand, for the entire SET command. For instance, assuming that a macro called ‘Pump1ON’ is created to represent ‘set,dig_01.value,1’, then this command can simply be specified as: "Pump1ON". 

Although macros provide short yet intuitive command names, they require the most pre-configuration in this Command agent and are therefore most restrictive. For details on creating and using macros, see Creating Macros.
