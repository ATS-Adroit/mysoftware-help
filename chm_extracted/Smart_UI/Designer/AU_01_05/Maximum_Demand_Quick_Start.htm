Maximum Demand Quick Start

This explains the recommended method of configuring your Adroit system to monitor your maximum demand.

Before you can monitor your maximum demand, you need the following:

  • To know when your electricity provider monitors your maximum demand.
  • To know the maximum kVA demand limit imposed by your electricity provider, above which you are required to pay penalties.
  • To know the block period duration used by your electricity provider to monitor your maximum demand.
  • A front-end device (PLC) that monitors the pulse sent from your electricity provider to signal the start of each block period. [Otherwise, you can disable block pulses and allow to agent to determine block periods automatically based on current time instead.]
  • A front-end device (PLC) that monitors the total kVA that your process uses.

To monitor your maximum demand:

Only enable this agent when maximum demand is being monitored

  1. Create a Scheduler agent, for instance called MDPERIODS, to specify the periods of high power use during which your electricity provider monitors your maximum demand. Contact your electricity provider for this information. For details, see Configuring the Scheduler agent.
  2. Edit an agent of type: MaxDemand.

If necessary, add an agent of the required type, as follows:

  5. Specify the required Tag Name or agent name.

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit MaxDemand Agent dialog:

  1. Check the Enable OR use tag checkbox (the enable slot)
  2. Click the browse button to the left of the Enable OR use tag checkbox and select the Scheduler agent you created and its value slot (MDPERIODS.value) to only enable this agent when your electricity provider monitors your maximum demand. For details, see Selecting a tag from the Agent Explorer.

Configure the other maximum demand-specific settings

  1. Specify the duration of the block period that your electrical provider uses, in minutes, in the Block period (mins) edit box (the blockPeriod slot). For instance, 30 minutes.
  2. Check the Enable block pulses checkbox (the blockPulseEnable slot)
  3. Specify the maximum kVA demand limit for this agent, in the Max demand limit (the mdLimit slot) edit box.

Tip: If may be useful to specify a value slightly LESS THAN the actual maximum demand limit imposed by your electricity provider, so that there is time for counteractive measures to be taken when this is exceeded.

  1. Check the Enable max demand alarm checkbox (the enableMDAlarm slot) to enable the MaxDemand status bit when the predicted maximum demand exceeds this specified maximum demand limit.
  2. Leave the default Reset configuration, unless you do NOT want to reset the current month’s calculations at midnight on the last day of the month.
  3. Click OK and close the configuration dialog of the MaxDemand agent.

Configure the maximum demand-specific alarms for this agent

  1. Alarm the ‘PulseError’ alarm type for this agent, so that you will know if the timing of these external block pulses are compromised i.e. as soon as a pulse does not occur at the period specified by the Block period (mins) value.
  2. Alarm the ‘MaxDemand’ alarm type for this agent, so that you will know when the maximum demand limit is exceeded.

Scan the relevant values of this agent to the appropriate front-end device

  1. Scan the BOOLEAN blockPulse slot of this agent to a value in a PLC that monitors the pulse sent from your electricity provider to signal the start of each block period.
  2. Scan the REAL kVA slot of this agent to a value in a PLC that measures the total instantaneous kVA usage.
  3. If you ALSO want to calculate the instantaneous power factor and reactive power component then also scan the REAL kW slot of this agent to a PLC that measures the total instantaneous kW usage.

Display important values

  1. You could display some or all of the following MaxDemand agent slots:

    mdLimit: the maximum kVA demand limit for this agent.

    mdActual: the highest recorded maximum demand for any block period of the current month.

    demand: the actual power that has been used (kVA demand) for this block period.

    mdPredict : estimates the total power use (kVA demand) for this block period, by using the demand slot against the remaining time for this block period.

    mdOverUnder : displays the difference between the Predicted max demand (the mdPredict slot) and the Max demand limit(the mdLimit slot) for this block period.

    timeToMD : indicates how long, in minutes, before the Max demand limit(the mdLimit slot) will be reached before the end of the block metered period, at the current demand.

    Note: If you are running safely, this will ALWAYS indicate the end of the current block period.

    kVAOptimal : the recommended kVA consumption to meet (and NOT EXCEED) the Max demand limit(the mdLimit slot) for this block period.

    kVASpare : the spare kVA capacity for current period, which is the difference between the Current demand(the demand slot) and the Optimal KVA(the kVAOptimal slot).

    This specifies a positive or negative amount of kVA that needs to be removed or added to meet (and NOT EXCEED) the Max demand limit(the mdLimit slot) for this block period.

    Example:

    For instance, you can create a mimic that allows a manager to know that at the current consumption (demand slot) that:

    • the configured maximum demand (the mdLimit slot) will be reached in 12 minutes (timeToMD slot) which is 3 minutes before the end of the period (the blockTimeLeft slot - timeToMD slot) and
    • 30kW of load needs to shed (the kVASpare slot is a negative number) to not exceed the maximum demand OR if the process is running safely that 45kW of load can be added (the kVASpare slot is a positive number) to meet the maximum demand) for this block.

If necessary, use this agent to control your maximum demand

  1. If you want to control the maximum demand by using this agent, then use the MaxDemand status bit of this agent to turn off non-essential equipment via a script. Since this status bit is ONLY set when the Enable max demand alarm checkbox is enabled and the predicted maximum demand exceeds this specified maximum demand limit.
