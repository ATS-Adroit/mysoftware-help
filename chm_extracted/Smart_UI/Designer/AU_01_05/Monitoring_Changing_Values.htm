Monitoring Changing Values

The Analog and Digital agents provide a change monitoring feature, which is disabled by default, in which a Changed status bit is pulsed when the value (slot) of the agent changes.

ONLY use this feature when your operators need to IMMEDIATELY be made aware of ANY change to an Analog or Digital value. In this case you need to:

  1. Enable change monitoring for the Analog or Digital agent, as follows:Either edit the agent and check its Enable change monitoring for this agent checkbox or set its BOOLEAN enableChange slot to 1.

When enabled, this feature will instantaneously pulse (set and then immediately reset) the Changed specific status bit of this agent.

Note1: The valuePrev slot contains the previous value (the value slot) of this agent.

Note2: The timePrev slot that provides the timestamp of this previous value (valuePrev slot) and is only affected by putslots to the

value slot NOT the time slot. This slot is not currently supported in realtime catch-up.

  1. Alarm the Changed alarm type of this agent, so that you can report incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). via the various alarm routing destinations, such as by viewing it using an Alarm List Viewer window or logging it to a printer or database or sending it to an operator via SMS etc.

Otherwise, if you want to know when the value of an agent changes, but your operators do not necessarily need to know about this change immediately, then audit the Agent Server and specify the required tagA fully qualified named value in Adroit (agentName.slotName). in an Audit agent.

This logs a record to the Agent Server audit database when this tag changes in value. This record also contains the previous and current values of this tag and the name of the currently logged on user at the time of the change.

This method also allows you to keep track of important process values, which can reside in agent types other than Analog or Digital.

 

For more details about auditing the Agent Server entails and how this can be used, see Agent Server Auditing.

For more details about how the audit agent supplements the auditing of the Agent Server, see The Audit agent.
