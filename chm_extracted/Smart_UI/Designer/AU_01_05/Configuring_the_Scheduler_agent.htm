Configuring a Scheduler Agent

Configure a Scheduler agent to do ONE of the following:

  1. to define one or more periods of time during which its BOOLEAN output (value slot) is enabled (set to slot to TRUE or 1)
  2. to manually set the output.
  1. Edit an agent of type: Scheduler.

If necessary, add an agent of the required type, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. Right click the required agent type , which are listed alphabetically, and select Create Tag.
  5. Specify the required Tag Name or agent name.

The following rules apply when naming agents:

  1. Agent names have a maximum of 27 characters.
  2. Agent names cannot be the same as the names used for Agent Types or for Agent Groups.
  3. Agent names cannot use the following characters:

Space

 

Percent

%

Comma

,

Period

.

back slash

\

Dollar

$

  1. If necessary, provide an optional Description that describes the purpose or describes the value of this tag (agent) for ease of reference.
  2. Click the Finish button.

 

If necessary, locate the required agent, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. If necessary, expand the required agent type , which are listed alphabetically.
  5. Locate the required agent , which is also listed alphabetically beneath their applicable agent type.

 

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit Scheduler Agent dialog box:

Note: This Edit Scheduler agent dialog can be resized, to view the entire width of this grid, if necessary.

  1. Tick the Enabled checkbox if the output of the Scheduler agent is to be determined by the defined periods of time.
  2. Clear the Enabled checkbox, if the output of the Scheduler agent is to be manually controlled, for instance, from this configuration dialog, from a mimic, the scanning subsystem or any other legal method of changing an agent’s slot. More details:

When the Enabled checkbox is cleared, the Value checkbox is enabled, and it determines the status of the Scheduler agent’s output, ignoring the configured Dates to exclude and any scheduled periods of time.

To Manually Enable the Value Tickbox.

  1. If required, tick the UCT Times checkbox, to specify the times using the UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI). time format instead of using local time. This is required if you intend to create schedules of times from around the world.
  1. The Scheduler agent also provides a global method for automatically configuring the schedule lists of multiple Scheduler agents, via the configuration of a "master" Scheduler agent. More details:

Note: When specifying a master Scheduler agent the schedule list of the slave agent is replaced with that of the master and the list of excluded dates of the master is ADDED to that of the slave. Click for more details: This by design, to ensure that any excluded dates specified in a slave Scheduler agent will not be overwritten by someone updating the master. However, this means that if you remove an excluded date from the Master Scheduler agent, then in order to remove this excluded date from your slave Scheduler agent/s, that you need to explicitly remove this date from each of the slave Scheduler agent’s "Dates to exclude" field.

This "master" Scheduler agent acts as the repository of the schedule lists. Then when configuring a "slave" Scheduler agent, specify the name of this "master" Scheduler agent in the Master agent edit box.

Either type this master agent name in directly or click on the browse button (...) on the right of this edit box, so that this agent can be selected using the agent browser.

Note: A "slave" Scheduler agent, is a Scheduler agent that will receive any schedule list changes implemented on the "master" Scheduler agent.

  1. The Dates to exclude edit box, this field is optional and only needs to be configured if there are specific dates, which must be excluded from the scheduled periods of time. More details:

Either type these dates in manually or use the browse button (...) on the right of this edit box, which opens the Select date to exclude dialog. Multiple dates are separated by semi-colons.

Note1: The date format used is determined by the Regional Settings of the computer. If unsure, use the Select date to exclude dialog to select these dates instead.

Note2: The Dates to exclude field is NOT copied from the "master" Scheduler agent.

  1. The Command to run edit box, this field is optional and only needs to be configured if an application is required to be launched as soon as this agent’s output changes into a TRUE state. More details:

This must contain the full path and name of the application, which can either be typed in manually or browsed in, by using browse button (...), which opens the file browser. If necessary, any command-line parameters can also be added.

Note: Paths containing spaces need to be enclosed in double quotation marks ("").

  1. Use the grid to add, configure and remove the scheduled periods of time, during which the output of the Enabled Scheduler agent will be TRUE. For details, see Configuring a Scheduled Period of Time.

Note: The grid provides standard configuration options.

  1. Click the Update button to save the change(s) made to the configuration of the agent.
  2. Click the Refresh button to determine the current configuration of the agent.
