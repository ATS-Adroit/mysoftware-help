Configuring a PerfMon Agent

The Perfmon agent.

Since Adroit is a 32 bit application, if you have installed a 64 bit operating system then when you run the default Performance Monitor (PERFMON.EXE) all the counters for Adroit will be missing, because the 64 bit version of PERFMON is being run which can only load 64bit counter dlls! Therefore, in order to force Windows to load the 32 bit version of PERFMON, open the Command Prompt and specify the following statement: mmc /32 perfmon.msc

  1. Edit an agent of type: PerfMon.

The Edit PerfMon Agent dialog box is displayed.

Note: Due to the long names of these performance counters, it is possible to resize this edit dialog appropriately. This edit dialog will remember these settings when it is next opened.

  1. Use the grid to add, configure and remove the Performance counters. This grid is comprised of the following columns, which are used to configure the Performance counters, as follows:

Note: The grid provides standard configuration options.

  1. Counter: Use this field to specify a Performance counter, either type in this counter directly or click the Browse button, to launch the Browse Performance Counters dialog.
  2. Tag: If necessary, use this field specify an external Adroit tag, to which the value of this Performance counter will be sent. Either type in this tag directly or click the Browse button, to launch the agent browser.

For instance the total memory used i.e. \\Memory\\Committed Bytes could be sent to the value slot of an Analog agent, which could be alarmed if this value exceeded the physical memory of the computer.

  1. Value: This column, which cannot be edited, only displays the value of the selected Performance counter, which is updated at one second intervals.
  2. Click the Update button to save the change(s) made to the configuration of the agent.
  3. Click the Refresh button to determine the current configuration of the agent.
  4. The Browse button is used for browsing for Counters or Tags, depending upon which cell is currently selected in the grid.
