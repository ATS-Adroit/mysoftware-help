Configuring SNMPMgr Agents

Each SNMPMgr agent can manage a single SNMP managed device by monitoring (polling) selected OID values and, if necessary, changing (writing to) them. Furthermore, you can also retrieve SNMP trapsunsolicited SNMP messages sent by a device to notify an SNMP manager of significant events. from this device. 

This describes all the configuration options provided by this agent to connect to and manage a network device:

PLEASE NOTE: Read the list of usage requirements and guidelines BEFORE using this agent, see Usage Requirements.

IMPORTANT: NEVER run the Windows SNMP Trap (listener) service because it conflicts with the Adroit SNMP trap functionality!

Note: This agent does NOT require the Windows SNMP Service to function, this service is ONLY required on each computer that this agent monitors.

To manage an SNMP device:

Edit an agent of type: SNMPMgr.

If necessary, add an agent of the required type, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. Right click the required agent type , which are listed alphabetically, and select Create Tag.
  5. Specify the required Tag Name or agent name.

The following rules apply when naming agents:

  1. Agent names have a maximum of 27 characters.
  2. Agent names cannot be the same as the names used for Agent Types or for Agent Groups.
  3. Agent names cannot use the following characters:

  2. Click the Finish button.

 

If necessary, locate the required agent, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. If necessary, expand the required agent type , which are listed alphabetically.
  5. Locate the required agent , which is also listed alphabetically beneath their applicable agent type.

 

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit SNMP Manager Agent dialog:

  1. Specify the details (information required) to connect to the device you want to monitor and specify the required level of access to its values. For details, see Connecting to the SNMP Device.
  2. If you want to receive SNMP trapsunsolicited SNMP messages sent by a device to notify an SNMP manager of significant events. from this device then check the Enable traps checkbox (BOOLEAN trapEnabled slot), in the Connection settings section. For more details, see About SNMP Traps.
  1. Select the SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. (OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. values) that you want to get and/or set by using the SNMP Objects Browser. For details, see Selecting OIDs.

Note: You need to select the Enable polling option in the Poll settings section before you can use this SNMP Objects Browser.

This adds the selected OID values to the list maintained by this agent. For details of the available fields in this list, see OID List.

  1. Specify which of these values you want to poll (monitor) and/or write to (control). For details, see Enabling the Monitoring of OID Values or Enabling the Changing of Values.
  1. Select the Enable polling option (BOOLEAN start slot) in the Poll settings section, to start managing this device, by polling (getting), writing (setting) and/or trapping (enabling events) its OID values. For further details, see Device Management Settings.

Note: The SNMPMgr agent consumes a scan pointa scan point licence that is consumed from your Adroit license when information is being manipulated. for every unique OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. that is polled, written to and/or trapped.

The Error status bit is set when non connection-related errors occur. For details of the errors that this bit can indicate and how they affect the management of the device, see Specific Status Bits.
