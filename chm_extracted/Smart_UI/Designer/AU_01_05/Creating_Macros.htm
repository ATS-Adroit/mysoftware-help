Creating Macros

Macro can be created to simply the process of specifying commands, since a macro is simply an abbreviation or alias for an ENTIRE command, which once defined, can be used when issuing this command to this Command agent.

Before macros can be used in messages, it is necessary to alert this Command agent to their possible existence in its received messages, so that it can correctly interpret them. For details, see Enabling Pseudonyms and Macros.

Although macros can provide the most intuitive and the shortest command names, they are also the MOST restrictive, since this entire command must be pre-configured in this Command agent, before it can be used.

For this reason, they can be used to further restrict or limit the SET-table commands that can be performed by this Command agent. For details, see Limiting SET Commands.

Note1: Pseudonyms can be used as placeholders for individual tags (agent.slot), if required. For details, see Creating Pseudonyms.

Note2: Macros, like pseudonyms, are specific to the Command agent in which they are defined and are not global to all Command agents. However when a Command agent is copied, any defined macros and pseudonyms will also be duplicated. For details, see Copying Agents.

Note3: It is also possible to remove any macros that are no longer required. For details, see Removing Pseudonyms and Macros.

To define a macro:

  1. If necessary, add a Command agent. For details, see Adding Agents.
  2. Edit the required Command agent. For details, see Editing Agents.

This will display the Edit Command agent dialog.

  1. Select the Pseudonyms and Macros tab.
  2. If necessary, click the Add pseudonym or macro button to add a new entry.
  3. If necessary, select the Pseudonym/Macro cell, in the required row and type in the name that will be used to represent the required command.
  4. Select the Replacement cell and specify the required command. For details of the available commands that can be performed, see Available Commands.

Tip: When specifying this command use the browse button to the left of this cell to browse for the required tag (agent.slot). For details, see Selecting the Agent and Slot Names.

Note: Ensure that the Expand pseudonyms in messages checkbox, is checked, so that this macro will be correctly recognised and interpreted by this Command agent.
