Configuration of an ARec Truth Table

  1. Edit an agent of type: ARec.

The Edit AREC Agent dialog box is displayed.

  1. Ensure the State I/O configuration tabbed page is displayed.
  1. In the No of tags edit box, enter the number of I/O bits that are to be used to define the truth table, from 1 to 32. press the TAB key to create the required number of rows in the State I/O configuration grid below.
  2. In the No of outputs edit box, enter the number of low order I/O bits that are to be used as outputs e.g. if No of tags = 9 and No of outputs = 5, then bits 0 to 4 will be outputs and bits 5 to 8 will be the inputs. press the TAB key to configure the required number of outputs in the State I/O configuration grid below, these will have a yellow background.

Note: There can never be more outputs than the specified No of tags.

  1. Tick the Cold Start Value checkbox, in order to specify a binary cold start value for the 32 bits, e.g. a value of 10 will set bits 3 and 1 and all the others will be set to 0. The default value is 0 i.e. no bits are set.
  2. Use the State I/O configuration grid to add, configure and remove up to 32 I/O bits, slots of the ARec agent.

Note: The grid provides standard configuration options.

  1. Click the Update button to save the change(s) made to the configuration of the agent.
  2. Click the Refresh button to determine the current configuration of the agent.
  1. Click on the State configuration tab.
  1. In the No of states edit box, enter the number of states that need to be configured, from 1 to 255. press the TAB key to create the required number of rows in the State configuration grid below.

Note: State 0 is reserved as the Undefined state, hence only 255 states can be configured.

  1. In the Output pulse width edit box, enter the time in milliseconds that the outputs, if used, are to be pulsed for.
  2. Tick the Enable outputs checkbox, so that any configured output bits can be Set or Cleared.
  3. The Current value indicates which of the configured I/O bits are currently set.
  4. The Current state indicates which the index number and the description of the state, which is associated with the Current value. If no such state has been defined, the Undefined state of index 0 is displayed.
  5. Tick the Binary mode checkbox, to display the bit masks in binary format, instead of displaying its equivalent value.

Note: In binary mode, bit 0 is on the right.

  1. Use the State configuration grid to add, configure and remove up to 255 states that define the truth table of the ARec agent and to set or clear any output bits that have been configured.

Note: The grid provides standard configuration options.

  1. Click the Update button to save the change(s) made to the configuration of the agent.
  2. Click the Refresh button to determine the current configuration of the agent.
