Configuring Command Agents

The Command agent can receive textual commands in SMS messages that it is able to remotely configure or "command" Adroit. SMS messages can also be sent either manually or automatically and, if necessary, be sent via another Command agent to another recipient, such as a colleague or escalated up the management chain.

This agent requires a device of the GSM_SMS protocol driver, to be added and correctly configured, in order to send and receive SMS messages. For details, see Specifying the GSM_SMS Device.

Each Command agent is able to send SMS messages to a single recipient. For details see, Sending SMS Messages or for details on specifying this required phone number, see Specifying the Recipient Phone Number.

Note: When the Resend message checkbox is cleared (its default setting) a message will ONLY be sent if the rawvalue of this agent HAS changed when dialog is either updated or closed. This effectively prevents the resending of identical messages.

Sent SMS messages can be monitored for auditing purposes and if they are not received and/or responded to within a specified period can also be sent to another recipient via another Command agent, which can be used to escalate this message up the management chain, if necessary. For details, see Monitoring Message Receipt and Monitoring Message Response.

Note: Although Command agents can also receive SMS messages from their recipient, one or more additional cell phone numbers can also be specified that are able to send SMS messages to it. For details, see Specifying Additional Callers.

If a Command agent is required to receive COMMANDS within these received messages, this must be MANUALLY ENABLED. Since once enabled, these commands can be used to obtain and/or control any process value or slot exposed by the Agent Server.
For details, see Allowing Commands to be Performed or for details of the available commands that can be performed, see Available Commands.

PLEASE NOTE: Once a Command agent is configured to receive commands, scan point licenses are consumed by every unique phone number specified by this agent and/or used to send SMS messages to it.

Note: Pseudonyms and macros can also be created to simply the process of specifying these commands by acting as placeholders for part or all of a textual command that is sent to a Command agent. For details, see Using Pseudonyms and Macros.

If necessary, it is also possible to configure the following Command agent–specific settings:

To specify default format used for displaying real numbers in sent messages.

To manage the message queue that is maintained by this agent.
