To Configure the States of the ARec agent

The State configuration grid, consists of the following fields, which configures each state, as follows:

Note1: The grid provides standard configuration options.

Note2: Use the horizontal scroll bar beneath this grid (and the vertical scroll bar when visible) to navigate to the required fields.

  1. The first untitled field, numbers the states in the grid.
  2. Description: Use this field to type in a description of the condition that defines this state.
  3. Mask:Configure this bit-mask field to specify which of the configured I/O bits (ARec slots) need to be considered, when testing for this state.

Note: Any bit not set in this Mask field, effectively becomes a DON’T CARE condition for this state.

  1. Test:Configure this bit-mask field to determine, which of the I/O bits specified by the Mask field, need to be set (ON) or cleared (OFF) for this state to be achieved.

Note: This Test field effectively determines the ON and OFF conditions for this state.

  1. Set:Configure this bit-mask field to specify which of the output bits, must be set when this state is achieved.
  2. Clear:Configure this bit-mask field to specify which of the output bits, must be cleared when this state is achieved.
  3. Timeout: Use this field to type in a timeout value, in milliseconds, for the state. If the ARec agent remains in this state for the specified time, then the Timeout set and Timeout clear functionality will then be implemented. A value of 0 disables this timeout functionality.
  4. Timeout set:Configure this bit-mask field to specify which of the output bits must be set if the timeout value is reached.
  5. Timeout clear:Configure this bit-mask field to specify which the output bits must be cleared if the timeout value is reached.
  6. Status bits:Configure this bit-mask field to specify which of the 16 private status bits, if any, are to be set when this state is achieved so as to be able to alarm the agent.

Note: Clear the Enable outputs checkbox, to prevent any configured output bits from being Set or Cleared.
