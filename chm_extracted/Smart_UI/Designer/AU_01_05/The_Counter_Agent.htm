The Counter Agent

The Counter agent takes data from any Input Tag’s BOOLEAN slot and calculates the time spent On (1) and the time spent Off (0), counts the number of On and Off events, and totalises the On and Off time.

There is a Counter Wizard to demonstrate its operation, which can be found in the Samples\Wizards folder under the Adroit system folder, typically C:\Program Files\Adroit Technologies\Adroit\Samples\Wizards.

The alarm limits associated with these times, are indicated by its specific status bits.

Note1: The Counter agent supports real-time catch-up.

Note2: Use agent persistence files to prevent Counter agents from losing their statistical data, instead of saving the Agent database (.WGP) file frequently. For further details, see Agent Persistence Files.
