Configuring a PID Agent

The PID agent is a simply a faceplate agent for external PID controllers, encapsulating the 25 signals and tuning parameters associated with a PID within a single agent. For details, see The PID agent.

  1. Edit an agent of type: PID.

The Edit PID Agent dialog box is displayed.

  1. The PID agent’s data values can be broken down into 5 distinct groups with the following names and associated meanings:

  1. PID Signals: this contains the input to and the output from the PID and its desired SP (set-point).

    For both the PV (process value) and the CV (control variable) this defines their minimum and maximum engineering values and their corresponding minimum and maximum values that the raw value can attain in the front-end device in order to scale the raw values into engineering values using meaningful units of measurement. Since this may vary between device types, the user should ascertain the correct front-end device span is used for each value.

The value of these PID signals, including the SP (the required set-point) can also be specified in engineering units, with their raw value equivalents being displayed. Both SP and PV will always share the SAME minimum and maximum Engineering and Raw values. The SP and CV values provide a Max limit and Min limit which specify their effective operation range.

Note: Once these limits are set these values cannot be manually set above and below these limits.

The inner (H or L) and outer (HH or LL) High and Low alarm limits for the PV can also be specified in engineering units, with their raw value equivalents being displayed.

Note: When the Cascade checkbox is ticked, the SP is controlled by the output (PV) of another PID agent, therefore the SP edit box is greyed out. Also when the Automatic checkbox is ticked, the CV is calculated by the PID controller, therefore the CV edit box is greyed out.

  1. Tuning parameters: this contains the parameters for all the different control methods that can be used by the external PID controller i.e. the Proportional gainand Integral time and Derivative time.

This defines their minimum and maximum engineering values and their corresponding minimum and maximum values that the raw value can attain in the front-end device in order to scale the raw values into engineering values using meaningful units of measurement. Since this may vary between device types, the user should ascertain the correct front-end device span is used for each value.

The value of these tuning parameters can also be specified in engineering units, with their raw value equivalents being displayed.

  1. %Error: this determines the Value of the %Error (the deviation of the PV from the SP), expressed as a positive or negative percentage, with a positive value indicating that the PV is above the desired SP and a negative value indicating that the PV is below the desired SP.

The inner (H) and outer (HH) High alarm limits for %Error, also expressed as a negative or positive percentage, can also be specified.

  1. General: this specifies general settings that apply to the entire PID agent.
  2. A Units text field is provided to record the chosen measurement unit for the PID Signals.
  3. The Cascade checkbox is provided to enable or disable the Cascade status of the external PID controller.
  4. The Automatic checkbox is provided to enable the Automatic (if ticked) or Manual (if unticked) status of the external PID controller. The Local checkbox is for future use.
  1. Control: currently this group is not used, although the PID agent may support its own PID algorithm for control, in the future.
  1. This Edit PID dialog also contains the following buttons:
  1. The Update button, this can be used after any of the configurable fields have been edited to update the display of the dialog, without closing and reopening this dialog.
  2. The Refresh button, this can be used to update the display of the dialog with the most current values fetched from the field.
  3. The Auto refresh button, this disables the Update button and effectively preventing any user-configuration of the dialog as the display of the dialog is constantly updated with the most current values fetched from the field, to be able to monitor the control by the external PID controller.

Note: Do not try to edit values while this mode is on.
