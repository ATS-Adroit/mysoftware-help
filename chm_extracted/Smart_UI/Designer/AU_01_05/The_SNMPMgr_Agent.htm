The SNMPMgr Agent

This agent can both monitor and manage devices on a network, by using the Simple Network Management Protocol (SNMP). Examples of devices that can be monitored using SNMP include routers, switches, hubs, UPSs, printers, modems and computers.

How to use the SNMPMgr agent to Manage a Device : details the most common configuration and method needed to monitor and/or manage a network device.

Each SNMPMgr agent can access the data relating to the operation of a single device, in order to:

PLEASE NOTE: For a comprehensive list of requirements regarding the use of this agent, see SNMPMgr Agent Usage Requirements.

  • monitor this device: by writing the values of SNMP managed objectsmanagement data exposed by SNMP managed devices that might be hardware, configuration parameters, performance statistics, and any other data that directly relates to the operation of this device. to one or more tagA fully qualified named value in Adroit (agentName.slotName)..

This allows you to trend this data, such as bandwidth; alarm this data, such as when particular conditions arise like a device becoming unavailable and log this data, so you can analyse it for troubleshooting purposes.

  • control this device: by using tags to set the values of this data.

This allows you to change set-points within the managed device that control its operational functionality. 

  • receive SNMP traps (events) from this device, so that you can react to those that are important.

This allows you to reduce the number of values that you need to monitor (poll) for each device. In other words, instead of monitoring every value on every device, by using SNMP traps, a device can simply inform its SNMPMgr agent of the important values without solicitation. 

This agent supports up to SNMP version 3 and allows an MIBSNMP Management Information Base, this is a database that lists uniquely described and organises SNMP managed objects hierarchically. file to be browsed in, in order to select which OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device. values you need to monitor and/or control and/or trap.

Each SNMPMgr agent can manage a single SNMP managed device by monitoring (polling) selected OID values and, if necessary, changing (writing to) them. For details of how to configure all the configurable options provided by this agent, see Configuring SNMPMgr Agents.

Furthermore, you can also retrieve SNMP trapsunsolicited SNMP messages sent by a device to notify an SNMP manager of significant events. from this device. For details, see About SNMP Traps.

For the suggested procedure of using SNMPMgr agents to monitor and manage a network, see Monitoring a network using SNMPMgr Agents.

For further details about SNMP, see About SNMP.
