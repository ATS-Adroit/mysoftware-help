Installing the Windows SNMP Service

The SNMP service must be running on a computer, before it can be monitored using the SNMPMgr Agent.

IMPORTANT: NEVER run the Windows SNMP Trap (listener) service because it conflicts with the Adroit SNMP trap functionality!

Note: This agent does NOT require the Windows SNMP Service to function, this service is ONLY required on each computer that this agent monitors.

This usually requires installing this service as it is not included in the standard installation of Windows (and/or Server) operating systems.

To install the Windows SNMP service on Windows 10:

  1. Right click the Start menu and select Programs and Features.
  2. Click the Turn Windows features on or off link on the right hand side of the applet.

This will display the Windows Features dialog.

  1. Scroll down until you see the Simple Network Management Protocol (SNMP) option and check this checkbox.
  1. OK all the open dialogs.

This will install this service, provided that the installation media or its files can be located on the computer.

The SNMP Service will be started by default.

To install the Windows SNMP service on Windows 7:

  1. Select the Start menu, Control Panel and the Programs and Features applet.
  2. Click the Turn Windows features on or off link on the right hand side of the applet.

This will display the Windows Features dialog.

  1. Scroll down until you see the Simple Network Management Protocol (SNMP) option and check this checkbox.
  1. OK all the open dialogs.

This will install this service, provided that the installation media or its files can be located on the computer.

The SNMP Service will be started by default.

Note: You also need to configure the security settings of this installed SNMP Service before you can browse its OIDSNMP managed Object IDentifier, which describes the exact location of this value in the SNMP structure for its device.s. For details, see Additional SNMP Service Security Configuration.
