The Primitive Agents

The primitive agent types Boolean, Integer, Real and String are the simplest building blocks. Instances of these primitive agent types are used simply to hold a single value in the value slot.

They do not contain any other slots or additional functionality such as inversion, pulsing, linearisation, etc, as found in the Digital, Analog and other agent types.

PLEASE NOTE: These legacy agents do not support Alarming and other SCADA functionality, use Analog/Digital agents instead!

These agents should ONLY be used where efficient use of memory is required.

  1. A Boolean agent will hold a Boolean value (0 or 1)
  2. An Integer agent will hold an integer number -2147483648 to +2147483647 (32 bits)

Note: The specific status bits of the Integer agent will be set if its value is between 0 and 15.

  1. A Real agent will hold a double precision floating point number (64 bits)
  2. A String agent will hold a 79 character text string (this length excludes the mandatory zero terminator character).

Due to the increasing need of customers for the Agent Server to support strings longer than 79 characters, the String agent now has a new slot called valueex that is able to contain these longer strings.

Usage examples for these longer strings include queries that are created dynamically and long descriptions.

WARNING! This new "valueex" slot is NOT supported by the scanning subsystem because the scanning subsystem cannot handle strings larger than 80 characters in length.

Note: This new valueex slot is now identical to the String slot type of Custom agents, which have always supported strings that are greater than 79 characters.

The legacy "value" slot of the String agent will still remain and contain the first 79 characters of the "valueex" slot.

Therefore the "valueex" slot will always be equal to the "value" slot its string length is less than 79 characters (excluding the zero terminator).

Note: When editing the String agent, only the "valueex" slot can be configured, although the content of the "value" slot is also displayed.
