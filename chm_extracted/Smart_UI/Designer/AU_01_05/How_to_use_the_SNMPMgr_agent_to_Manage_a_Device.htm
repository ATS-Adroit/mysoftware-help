How to use the SNMPMgr agent to Manage a Device

This agent can both monitor and manage devices on a network, by using the Simple Network Management Protocol (SNMP). Examples of devices that can be monitored using SNMP include routers, switches, hubs, UPSs, printers, modems and computers.

Things you need to know or do before you can manage a device:

  • ensure that you know which SNMP version the device supports and that you know all of its connection settings. Since the SNMPMgr agent supports up to SNMP version 3 and SNMP version 3 supports additional connection settings.
  • ONLY if this device is a computer, ensure that you have installed and configured the SNMP service on this computer. For details, see Installing the Windows SNMP Service or SNMP Service Security Configuration.

IMPORTANT: NEVER run the Windows SNMP Trap (listener) service because it conflicts with the Adroit SNMP trap functionality!

Note: This agent does NOT require the Windows SNMP Service to function, this service is ONLY required on each computer that this agent monitors.

  • please ensure that the device and your Agent Server license, complies with the specified SNMPMgr Agent Usage Requirements.
  • if you want to monitor this device, then you need the read community string of this device. For details of community strings, see SNMP Community Strings.
  • if you want to control this device, then you need the read/write community string of this device.
  • if you want to control (write) OID values in the device, ensure that their return types CAN be written to by the SNMPMgr agent. For details, see SNMP Object Value Return Types.
  • if you want to receive SNMP events (traps) from the device then you need to create a script that processes the received traps. For further details, see About SNMP Traps.

To monitor a device:

Edit an agent of type: SNMPMgr.

If necessary, add an agent of the required type, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. Right click the required agent type , which are listed alphabetically, and select Create Tag.
  5. Specify the required Tag Name or agent name.

The following rules apply when naming agents:

  1. Agent names have a maximum of 27 characters.
  2. Agent names cannot be the same as the names used for Agent Types or for Agent Groups.

  1. If necessary, provide an optional Description that describes the purpose or describes the value of this tag (agent) for ease of reference.
  2. Click the Finish button.

 

If necessary, locate the required agent, as follows:

In the SmartUI Designer:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required Adroit datasource or its icon .
  3. If necessary, expand the AgentGroup tree.
  4. If necessary, expand the required agent type , which are listed alphabetically.
  5. Locate the required agent , which is also listed alphabetically beneath their applicable agent type.

 

In the Enterprise Manager window: right click this agent and select Configure.

In the Edit SNMP Manager Agent dialog:

  1. Specify the IP address of the device, in the IP address edit box (STRING ipAddress slot), in the Connection settings section or when a device does not have a unique IP address then specify the unique port address (INTEGER ipPort slot) that allows this SNMP devices to be uniquely addressed via a gateway.

    Note: ensure that the port used for SNMP communications is unblocked (enabled) in any firewalls that may exist, which is typically UDP port 161 for a fixed IP address or the unique port address for the device, when addressed via a gateway.

  1. Select the required SNMP Version for this device supports, if this is version 3 then the following 3 additional connection settings are required:
  • Username (STRING userName slot): SNMP version 3 ONLY: the required user name.
  • Authentication (STRING authPassword slot): SNMP version 3 ONLY: the required password for authentication on this device.
  • Encryption (STRING encrPassword slot): SNMP version 3 ONLY: the required encryption password for this device.
  1. If you ONLY want to retrieve (poll) values from this device then specify its read-only SNMP Community String in the Read comm. edit box (STRING readCommunity slot).
  2. If you want to retrieve and/or write (get and/or set) values for this device then specify its read-write SNMP Community String in the WriteRead comm. edit box (STRING writeCommunity slot).
  3. If you want to receive SNMP trapsunsolicited SNMP messages sent by a device to notify an SNMP manager of significant events. from this device then check the Enable traps checkbox.
  4. Click the Browse OID to add button to open the MIB Browser dialog.

Tip: If this dialog is displayed then the specified connection settings are correct.

  1. Select the values of this device that you want to monitor (retrieve) and control (change), as follows:

  2. Either click the Walk device button, which then build the tree of the available OID values supported by this device. In this case the retrieved nodes of this tree are only indicated by their numbers.

    Note: If the monitored device is a computer and you receive an error when trying to walk this device, then ensure that you have installed the SNMP service on this computer AND configured its security settings appropriately. For details, see Installing the Windows SNMP Service and SNMP Service Security Configuration.

  3. Or click the Load MIB file... button to browse in a MIB file for this device, which provides the available OID values supported by this device. In this case the nodes of this tree display their textual descriptions, making it easier to select the required values.

Browse the resultant tree and select the required OID value and click the Add to list button to add it to the OID list maintained by this agent.

  2. Click the Name field of the required OID to select this row in the list.

  4. Click the Browse tag button and use the built-in agent explorer to create and/or select the Tag that will contain and/or change this OID value. For details, see Selecting a Tag Using the Agent Explorer.

Note: Ensure that the selected agent type can store the data of this OID value and, if necessary, that the return type of this OID value is writable. For help on this, see SNMP Object Value Return Types.

  • To poll (retrieve) this OID value: click the E field of this row to check (tick) this checkbox.

Note: By default, this value is polled at the global Poll rate for this agent. If this value changes faster or slower than the global rate then use the Rate field of this row to specify this specific rate in milliseconds.

Tip: You may need to enlarge this dialog or use the horizontal scroll bar to see this Rate field.

  • To change this OID value (when the value of the specified Tag changes): click the W field of this row to check (tick) this checkbox.

Tip: The lastWriteStatus STRING slot, displays a text message that indicates whether the last value written to the device was successfully changed in the device or not.

Note: Ensure that you either click the Update or OK button BEFORE clicking the Refresh button; otherwise these configuration changes will be lost.

In the Poll settings section of this dialog:

  1. If necessary, specify the default rate at which values are retrieved from the managed device, in milliseconds, in the Poll rate edit box (INTEGER scanRate slot).

    Tip: You can also specify the number of OID items in each polling transaction in the Pdu edit box. The maximum number is device dependant.

  2. Select the Enable polling option (BOOLEAN start slot) to start managing this device, by polling (getting), writing (setting) and/or trapping (enabling events) its OID values. 

If necessary display, manipulate, log, trend, chart and or alarm the OID values that are returned from the device.

Tip: Check the Auto-refresh values checkbox to immediately obtain the latest values of all the listed OIDs at their specified polling rates, without having to Refresh this dialog manually.

Ensure that you backup the GLOBAL SNMP configuration file.
