Date Formats

The format slot may consist of one or more codes, which are preceded by a percent sign (%).

Characters that do not begin with % are copied unchanged to string.

e.g. %Y-%m-%d %H:%M:%S will yield 1996-02-23 13:45:25

Note: An additional flag # may prefix any formatting code character after its % symbol.

%Code Meaning Example

%a

Abbreviated weekday name

Fri

%A

Full weekday name

Friday

%b

Abbreviated month name

Feb

%B

Full month name

February

%c

Date and time representation appropriate for locale (U.S.style)

02/23/96 13:45:25

%d

Day of month as decimal number (01 - 31)

23

%H

Hour in 24-hour format (00 - 23)

13

%I

Hour in 12-hour format (01 - 12)

01

%m

Month as decimal number (01 - 12)

02

%M

Minute as decimal number (00 - 59)

45

%p

Current locale's A.M./P.M. indicator for 12-hour clock

PM

%S

Second as decimal number (00 - 59)

25

%U

Week of year as decimal number (00 - 51)

07

%w

Weekday as decimal number (0 - 6; Sunday is 0)

5

%W

Week of year as decimal number (01 - 52)

08

%x

Date representation for current locale (U.S.style)

02/23/96

%X

Time representation for current locale

13:45:25

%y

Year without century, as decimal number (00 - 99)

96

%Y

Year with century, as decimal number

1996

%z, %Z

Time-zone name; no characters if time zone is unknown

 

%%

Percent sign

%
