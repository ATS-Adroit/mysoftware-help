IOT Agent Slot Details

The IOT agent can represent any object containing multiple properties (or slots), which are defined AFTER adding the IOT agent.

Therefore when this agent is created it only contains the slots used to remotely define these properties, namely its xml slot, which defines the structure of this agent in XMLstands for Extensible Markup Language, which defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. format, which is saved in the Agent database (.WGP) file. Hence this agent does not have any default status slots.

This agent is located in the following file: T_IOT.DLL

Slots:

Slot Name Type Function

catchupData

RAWBYTES

Internal use only. The IOT agent does not support realtime catchup at this time.
expression VARSTRING An optional multi-line expression for calculating the defined slot values and/or status bit conditions. See more info at Creating IOT Expressions.

xmlSlots

VARSTRING

Defines the structure of this agent in XMLstands for Extensible Markup Language, which defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. format, which is saved in the Agent database (.WGP) file. See How to use the IOT agent to define an object
rawValue VARSTRING XML representation of the agent slot values. This slot is typically scanned and expects an XML representation of the slot values.

Specific status bits: 

None.

Methods of creation:

Manual

Agents created by default:

None
