Marshal Agent - Slot Details

The Marshal Agent "marshals" an integer input value into 16 discrete digital values dig00-15, where each bit has the full functionality of a digital agent.

This agent is located in the following file: T_MARSHAL.DLL

Slots:

Note: For the 16 discreet digital agents the ## represents 00 to 15.

Slot Name Type Function

byteSwap

BOOLEAN

If enabled (set to 1), this will swap the high and low bytes when splitting input into digitals, as required for S7 PLC compatibility.

dig##.coldstartEnable

BOOLEAN

Enable cold start for Bit ##

INTEGER

Description for Bit ##

BOOLEAN

dig##.invert

Invert flag for Bit ##

STRING

dig##.value

BOOLEAN
