Expression Agent - Slot Details

The Expression Agent allows for the configuration and execution of user-defined mathematical and logical expressions.

This agent is located in the following file: T_EXPRESSION.DLL

Slots:

catchupData

RAWBYTES

Internal use only (used for datalog and real-time data catch-up).

The user-defined expression string including comments.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Equal to zero

On when the result is equal to zero.

status bit 17

Greater than zero

On when the result is greater than zero.

status bit 18

Less than zero

On when the result is less than to zero.

status bit 19

Greater than or equal to zero

On when the result is greater than or equal to zero.

status bit 20

Less than or equal to zero

On when the result is less than or equal to zero.

status bit 21

Contains bad data

On when there is an error in the expression.
