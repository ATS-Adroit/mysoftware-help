OEE Agent - Slot Details

The OEE Agent allows you to

  • EITHER calculate the OEE for the monitored equipment and/or plant. Since targeting the three key OEE factors simultaneously, can effect significant improvements in production.
  • OR measure a specific KPIKey Performance Indicator, a quantifiable measurement that measures how well something is accomplishing its goals and objectives.. In other words, individual OEE agents can be applied to any component or part of a process for which a variable denoting a measurement of output is available.
    KPIs are typically the measurement of some production value over time OR one production value against (divided by) another production value. 

This agent is located in the following file: T_OEE.DLL

Slots:

Slot Name Type Function

autoReset

BOOLEAN

Allows the agent to automatically reset calculated OEE and KPI data at the end of every shift.  Default is ON. 

To use the agent in “batch mode”, set this slot value to zero (or OFF). 

Note: The action of resetting automatically performs a trigger.

Denotes that the machine/process is available for production. 

The state of this slot affects the accumulation of availableCurrShift time.

Tip: You could drive this using a Scheduler agent.

Select the Agent Server Configuration Welcome menu item.Select the Advanced Agent Server Configuration option.At the bottom of the dialog, the Global OLE DB connection field is available for you to specify this connection string.

enable

BOOLEAN

Enables the agent for operation. 

Can either be permanently set to ON for 100% production facilities or be driven by a Scheduler agent that is configured with times for maintenance, tea, lunch etc.

historicalData

LIST

A list of historical OEE and KPI shift values for up to 30 days.

inactivityPeriod

INTEGER

A period defined in seconds to determine an inactive input signal. 

If the measurement variable (input1 slot) remains static for this configurable time, the agent will interpret the process/machine as not running. 

Note: A value of 0 (default) disables this feature. 

Should the input1 slot be detected as inactive, the Downtime status bit is activated.

input1

REAL

The measurement variable for which KPIs and OEEs are calculated. 

If this value goes to zero (rate mode) or remains static (Accumulator mode) for a configurable amount of time, it will affect actual run time. 

The OEE agent expects that this input will be static if the available and/or running slot is OFF.  If not, production totals will continue to increment even though running/availability is OFF.

input1Tag

TAGNAME

An optional tag reference for the input1 slot.

input2

REAL

An optional, second measurement variable against which the 1st input value (input1)is measured for KPIs i.e. KPI = input1/input2 e.g. kWh/ton. 

If this value is not required (input2 is unused), KPIs are calculated over time.

input2Tag

TAGNAME

An optional tag reference for the input2 slot.

The Shift agent that specifies the current shift information.

Note: This agent can still be operated in a “batch mode” with a Shift agent specified so that OEE data is recorded with a shift number.

RAWBYTES

The data of the current shift that is received from the Shift agent, specified by the shiftAgent slot.
shiftEndTime TIME Stores the ending time of the current shift.
shiftStartTime TIME Stores the starting time of the current shift.
shiftTargetDataSet LIST

Target dataset for the current shift, which provides the following two records that each contain a Datetime and double value:

  • Record1 contains: the start time of the current shift and a value of 0.
  • Record2 contains the end time of the current shift and a value equal to the kpiTarget slot.

BOOLEAN

Triggers a record of the current KPI and OEE values to the database (snapshot). 

This is typically used immediately prior to a reset on completion of a batch.

type1

INTEGER

Defines what type of signal is attached to input1, as follows:

1=Accumulator: The input1 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input1 type must be reset to 0 at the end of every shift using the agent’s ShiftEnd status bit as a trigger.

2=Totaliser: The input1 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input1 type is never reset to 0.

3=Rate per hour: The input1 slot is interpreted as a per hour production rate which will be integrated by the agent over time to produce a totalised value.

4=Rate per min: The input1 slot is interpreted as a per minute production rate which will be integrated by the agent over time to produce a totalised value.

5=Rate per sec: The input1 slot is interpreted as a per second production rate which will be integrated by the agent over time to produce a totalised value.

type2

INTEGER

Defines what type of signal is attached to input2, as follows:

0=Unused: This means that input2 is not used.  The KPI is calculated using input1 against time.

1=Accumulator: The input2 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input2 type must be reset to 0 at the end of every shift using the agent’s ShiftEnd status bit as a trigger.

2=Totaliser: The input2 slot is interpreted as an accumulated production count over time e.g. 123 bags.

This input2 is never reset to 0.

3=Rate per hour: The input2 slot is interpreted as a per hour production rate which will be integrated by the agent over time to produce a totalised value

4=Rate per min: The input2 slot is interpreted as a per minute production rate which will be integrated by the agent over time to produce a totalised value.

5=Rate per sec: The input2 slot is interpreted as a per second production rate which will be integrated by the agent over time to produce a totalised value.

If type2 is not set to 0 (Unused), then the OEE agent is said to be in complex mode.

units1

units2

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

ShiftEnd

 

Pulsed on at the end of every shift to allow interested parties to perform shift end operations.
status bit 17 Downtime On when the process/machine is available but not running or the input1 slot is detected as being inactive (exceeded the configured inactivityPeriod slot without changing).
status bit 18 KPILow On when the kpiPercent slot is equal to or below the low alarm (kpiLo slot).
status bit 19 KPILowLow On when the kpiPercent slot is equal to or below the low-low alarm (kpiLoLo slot).
status bit 20 QualityLow On when the qualityPercent slot is equal to or below the low alarm (qualityLo slot).
status bit 21 QualityLowLow On when the qualityPercent slot is equal to or below the low-low alarm (qualityLoLo slot).
status bit 22 PerformanceLow On when the perfomancePercent slot is equal to or below the low alarm (perfomanceLo slot).
status bit 23 PerformanceLowLow On when the perfomancePercent slot is equal to or below the low-low alarm (perfomanceLoLo slot).
status bit 24 AvailabilityLow On when the availabilityPercent slot is equal to or below the low alarm (availabilityLo slot).
status bit 25 AvailabilityLowLow On when the availabilityPercent slot is equal to or below the low-low alarm (availabilityLoLo slot).
status bit 26 OEELow On when the oeeCurrShift slot is equal to or below the low alarm (oeeLo slot).
status bit 27 OEELowLow On when the oeeCurrShift slot is equal to or below the low-low alarm (oeeLoLo slot).
status bit 29 Unlicenced On when the required OEE Count (which specifies the maximum allowable instances) as specified by the Agent Server license is either missing or has been exceeded.
status bit 30 InvalidShift On when the Shift number is equal to zero … not necessarily an error as this can, for example, occur due to no shifts being defined on weekends.
status bit 31 ConnectionError On when either connection string is invalid OR  a transaction error has occurred.
