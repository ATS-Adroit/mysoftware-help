Notify Agent - Slot Details

The Notify Agent handles alarms by sending text:

  • to pagers and cellphones (SMSs) and also
  • as email messages, when using the Email driver.

This agent is located in the following file: T_NOTIFY.DLL

Slots:

Slot Name Type Function

alm-field-data-str

STRING

String that separates the field name from the data if field-in-msg is TRUE.

alm-field-in-msg

BOOLEAN

If TRUE then the field name will be included in the message to be transmitted.

alm-fields

VARSTRING

Fields that will be sent. Format will be
<Field Name>:<#characters>,<Field Name>:<#characters>,…

alm-field-str

STRING

String that separates each field to be sent. Default value is " ".

alm-field-trim-spaces

BOOLEAN

If TRUE then spaces will be trimmed off the end of the fields.

alm-list-length

INTEGER

The number of alarms in the alarm list.

alm-list-period

INTEGER

List will be sent every alm-list-period minutes after the start of period time.

alm-list-period-start

TIME

List will be sent periodically starting from this time.

alm-list-send

BOOLEAN

When set to TRUE the alarm list will be sent.

alm-list-send-length

INTEGER

Only this number of recent alarms will be sent. Zero implies option disabled.

alm-list-send-periodically

BOOLEAN

If TRUE then send the alarm list periodically.

alm-send-if-raised

BOOLEAN

If TRUE then transmit information when an alarm is set.
Email-Attachment VARSTRING The OPTIONAL full path and filename of the file attachment of this email message. Note: Only 1 file can be attached to an email message.
Email-BC VARSTRING The Bcc field is used when you want other people to receive the message, but you don't want the other recipients to know they got it. When an e-mail is received, the recipients see all the email addresses in the To, CC and From fields - but not the Bcc field.
Email-Body VARSTRING The Body (actual message) of this email.
Email-CC VARSTRING The Cc field is for people that need to know about the message, but are not directly involved - to keep them informed.
Email-Enabled BOOLEAN When set to 1, this enables the configuration of and the sending of AUTOMATIC emails by the Notify agent.
Email-Include-Macro-Def BOOLEAN When set to 1, this enables the use of macro definitions in the Subject and Body fields of the automatic email messages.
Email-rawValue RAWBYTES

This slot is scanned to the applicable device of the Email driver. It encapsulates the other Email- slots of the Notify agent except the Email-Send-Now slot, when AUTOMATICALLY sending email messages.

Note: When scanning from the Notify agent – ensure that you specify this RAWBYTES Email-rawValue slot and NOT the default STRING rawValue slot.
Email-Send-Now BOOLEAN When MANUALLY sending email messages from a Notify agent, set this slot to 1 to encapsulate the VARSTRING Email- slots into the RAWBYTES Email-rawValue slot.
Email-Subject VARSTRING The Subject line of the email message, which is the title of the email that appears in the InBox of the recipients.
Email-To VARSTRING The To field is for people that the message directly affects, in other words those people that need to do something about this message.

flush-send-queue

INTEGER

When set to TRUE, all messages in the send queue will be erased.

outputData

No Type

Alarm agent passes an AdroitRecord to the Notify agent through this slot.

rawValue

STRING

Structured string to be transmitted to device. The string will be comma delimited with the first field being the code identifying the pager and the second field being the text to display on the pager.

user-code

STRING

The code that is usually used to identify the pager.

user-name

STRING

The name of the user that is to be notified.

value

STRING

Any text put into this slot will be queued for transmission through the rawValue slot.
valueEx VARSTRING This slot that is now SMS’d or emailed to subsystems that can handle long strings. It is also the slot that is saved to the WGP file.

valueSend

BOOLEAN

If non-zero then send the message in the value slot.

valueTrigger

STRING

The tag that can be used to send a message.

Specific status bits: 

None - transmit (status bit 16) is currently NOT being used.

Methods of creation:

Manual

Agents created by default:

None
