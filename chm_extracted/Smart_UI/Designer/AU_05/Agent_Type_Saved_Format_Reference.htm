Agent Type Saved Format Reference

The Adroit database (.WGP) file or load file stores almost all of the data and configuration of the Agent Server.

This includes every agent that has been added to the current project of this Agent Server, with the exception of the agents that are automatically created or dynamic agents like Proxy and Scan agents. For details, see About Adroit Database Files.

Note: If it becomes necessary to edit this file manually, you must ensure that a Carriage Return terminates the last line of the .WGP file.
