Date Agent - Slot Details

The Date Agent stores a date and time value. It has the capability of returning the value in a number of ways as depicted by the slots. If TRUE is put into setTime, the date agent will set itself to the current time.

The user may change the time stored in the date agent by writing to any slot, except the asciiTime slot. The user may format the way the date and time stored by the agent is displayed in the asciiTime slot, by setting the format slot in a specific way.

Note: You should never externally manipulate the localtime slot of the Date agent from a mimic using an operator action. 

The localtime slot must be used for viewing the time and the ucttime slot MUST be used for manipulating the datetime value. This is by design of the Date agent only. All other time slots in Adroit can be viewed and edited directly.

It is generally a bad idea to store an alphanumeric or broken down time in the Agent Server, because clients may exist in different time zones. This is why all times native to the Agent Server are stored in UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI). time.

If clients in different time zones read the same time slot, their time displays should differ. If the conversion to local time is done on the Agent Server level, as it is done in this agent, the user should take care to be totally aware that the time conversion to local time is done in the time zone of that Agent Server, and not in the time zone of the client the user is using.

This agent is located in the following file: T_DATE.DLL

dayOfWeek INTEGER The number representing the current day in the week, from 0 to 6 - where Sunday is 0 and Saturday is 6.

format

TAGNAME

ASCII time display format. The way to set this up is as follows:

The format argument consists of one or more codes; as in printf, the formatting codes are preceded by a percent sign (%).

Characters that do not begin with % are copied unchanged to string. The time category of the current locale as set in the Control Panel affects the output formatting. The formatting codes are listed below:

%a - Abbreviated weekday name

%A - Full weekday name

%b - Abbreviated month name

%B - Full month name

%c - Date and time representation appropriate for locale

%d - Day of month as decimal number (01 - 31)

%H - Hour in 24-hour format (00 - 23)

%I - Hour in 12-hour format (01 - 12)

%j - Day of year as decimal number (001 - 366)

%m - Month as decimal number (01 - 12)

%M - Minute as decimal number (00 - 59)

%p - Local AM / PM indicator for 12-hr clock

%S - Second as decimal number (00 - 59)

%U - Week of year as decimal number, with Sunday as first day of week (00 - 51)

%w - Weekday as decimal number (0-6; Sunday is 0)

%W - Week of year as decimal number, with Monday as first day of week (00 - 51)

%x - Date representation for current locale

%X - Time representation for current locale

%y - Year without century, as decimal no. (00 - 99)

%Y - Year with century, as decimal number

%z, %Z - Time-zone name or abbreviation; no characters if time zone is unknown

%% - Percent sign

As in the printf function, the # flag may prefix any formatting code. In that case, the meaning of the format code is changed as follows:

%#c Long date and time representation, appropriate for current locale. For example: "Tuesday, March 16, 1993, 12:41:29".

%#x Long date representation, appropriate to current locale. For example: "Tuesday, March 16, 1993".

%#d,

%#H,

%#I,

%#j,

%#m,

%#M,

%#S,

%#U,

%#w,

%#W,

%#y,

%#Y Remove any leading zeros

localTime

TIME

The local time. This is the local time for the UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI). time in the time zone where the Agent Server is running.

The breakdown of minutes etc. in the integer slots are local time.

Note: It is not possible to externally manipulate the localtime slot of the Date agent, for instance via a mimic EXCEPT by using the "Set to now" button of the date agent dialog or by using the "settime" slot of the date agent which also "sets the date and time to now".

uctTime

TIME

The time in Coordinated Universal Time (UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI).). This is the native form for all times in the Agent Server.

The native form for Client applications is Local Time. Therefore, what a Client application should do when getting a Time, is always convert it to local time before displaying it. Also convert a local time to UTC time before putting it into the Agent Server.

Note: It is not possible to externally manipulate the ucttime slot of the Date agent, for instance via a mimic EXCEPT by using the "Set to now" button of the date agent dialog or by using the "settime" slot of the date agent which also "sets the date and time to now".
