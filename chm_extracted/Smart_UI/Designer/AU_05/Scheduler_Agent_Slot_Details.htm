Scheduler Agent - Slot Details

The Scheduler Agent is used to define one or more periods during which it’s output (value slot) will be enabled and a valid application can be configured to execute at the beginning of these scheduled period(s). This agent also supports real-time catch-up.

This agent is located in the following file: T_SCHEDULER.DLL

Slots:

Slot Name Type Function

catchupData

RAWBYTES

Internal use only (used for datalog and real-time data catch-up)

command

VARSTRING

The executable program (including parameters) to run when a scheduled time arrives.

datesToExclude

VARSTRING

A list of specific dates, which must be excluded from the scheduled periods.

enabled

BOOLEAN

If this is set to TRUE (1) then the "value" slot of the Scheduler agent is determined by the scheduled periods. If this is set to FALSE (0) then the "value" slot of the Scheduler agent can be manually controlled.

masterAgent

TAGNAME

The master scheduler agent i.e. any changes made to its schedule slot is automatically transferred to all those Scheduler agents who refer to it as Master.

Note: the datestoexclude slot is NOT transferred.

recDaysOfMonth

INTEGER

This contains the value of the ‘Day of month’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify the required day, as a number, that this record is valid for.

recDaysOfWeek

INTEGER

This contains the value of the ‘Weekdays’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify the decimal value of the 7 digit binary number that specifies which days of the week this record is valid for e.g. if all seven days are required (1111111), specify 127 or if only Tuesdays and Wednesdays are required (0110000), specify 48.

recEndDate

TIME

This contains the value of the ‘End datetime’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify the date and time at which this record should terminate.

recIndex

INTEGER

This is an index for the list of schedule records, with 0 representing the first record. Once a valid index is selected, the following slots, representing the individual parameters of the record, can be updated e.g. via a mimic or script: recStartDate, recEndDate, recDaysOfWeek, recDaysOfMonth, recLastDayOfMonth and recSpecial.

recLastDayOfMonth 

BOOLEAN

This contains the value of the ‘Last day of month’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify a 1 or 0 to turn this option on or off respectively.

recSpecial

BOOLEAN

This contains the value of the ‘Special’ or ‘Auto delete’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify a 1 or 0 to turn this option on or off respectively.

recStartDate

TIME

This contains the value of the ‘Start datetime’ parameter for the schedule record specified by the recIndex slot. To alter this value, specify the date and time at which this record should commence.

schedule

LIST

A list of time schedules where each entry contains the following parameters:

  1. Start datetime – The start date/time of an entry. If left blank, the parameter is disabled and all date/times are valid
  2. End datetime – The end date/time or time of an entry. If left blank, the parameter is disabled and all date/times are valid
  3. Weekdays – The days of the week for which this entry is valid. If no weekdays are selected the entry is disabled.
  4. Day of month – The day of the month on which this entry is valid. A value of zero disables the parameter. All weekdays should be enabled for a non-zero value to work properly.
  5. Last day of month – If enabled, the entry is only valid if it is the last day of the month.
  6. Special – If enabled, the entry will be deleted as soon as the end datetime is exceeded.

uct

BOOLEAN

If this is set to TRUE (1) then any times specified in the schedule are specified using the UTCstands for Coordinated Universal Time, which is a time standard that couples Greenwich Mean Time (GMT), which is based solely on the Earth's inconsistent rotation rate, with the highly accurate International Atomic Time (TAI). time format instead of using local time. If this is set to FALSE (0), the default setting then local time is used instead.

Note: The slot name is uct even though it refers to setting UTC time.

value

BOOLEAN

If this is set to TRUE (1) then the current time is within a scheduled time. If this is set to FALSE (0) then the current time is NOT scheduled.

Note: If the "Enabled" slot is set to FALSE then this can be manually controlled.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Active

State is On if the value slot is TRUE.

Methods of creation:

Manual

Agents created by default:

None
