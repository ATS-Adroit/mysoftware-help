EventLogging Agent - Slot Details

The EventLogging Agent logs events to the Windows event logs.

This agent is located in the following file: T_EVENTLOG.DLL

Specific status bits: 

Note: These are of type BOOLEAN.

None

Methods of creation:

eventLog
