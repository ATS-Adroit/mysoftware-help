Agent Type Slot Reference

Most agents are designed to contain multiple items of data, most of which are accessible to clients of the Agent Server, each of which is known as a slota value (attribute) or field within an agent that can be retrieved and/or set. of the agent. A tagA fully qualified named value in Adroit (agentName.slotName). is simply a de-referenced slot. For further details, see About Agents or About Agent Data (Slots).

This describes the slots that are available for each agent type, as follows:

  • Slots that are COMMON to all agent types: Header Slots.
  • Slots that are SPECIFIC to each defined agent type:

Accumulator Agent Slots : this agent requires an input a value that accumulates over time to calculate the difference in value between successive events or periods.

AgentGroup Agent Slots : this agent combines agents that have something in common into groups.

Alarm Agent Slots : this agent manages how incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). are communicated to the necessary personnel and/or applications.

AlarmList Agent Slots : this agent lists current or unacknowledged incidents to display in an Alarm List Viewer window.

AlarmManagement Agent Slots : this agent configures and records your active incidents so you can improve your alarming configuration.

Alias Agent Slots : this agent creates a reference to an existing agent to adopt its Behaviour and state information.

Analog Agent Slots : this agent stores a real (floating point) value and provides engineering functionality such as scaling.

ARec Agent Slots : this agent configures up to 256 states using truth table type logic on up to 32 bits.

Audit Agent Slots: this agent supplements the auditing of the Agent Server by selecting tags to monitor for any change in value.

Beeper Agent Slots : this agent provides simple audio output using the built-in PC loudspeaker.

Boolean Agent Slots : this agent stores a Booleana value that only has two discrete states, 0 (FALSE) or 1 (TRUE). value.

Command Agent Slots : this agent sends and receives SMSShort Message Service is a service (protocol) for sending short text messages to and from mobile phones. messages to remotely configure or report on your process.

Coordinate Agent Slots : this agent stores the GPS coordinates of assets on the GIS platform.

Counter Agent Slots : this agent is a simple counter and averager.

DataLog Agent Slots : this agent manages the historical logging of a process value (tagA fully qualified named value in Adroit (agentName.slotName).).

Date Agent Slots : this agent holds time and date information broken down into the date and time constituents.

DBAccess Agent Slots : this agent performs a transaction on a row in an OLE DB compatible database.

DBLog Agent Slots : this agent is a bulk OLE DB logging agent.

DBQuery Agent Slots : this agent provides a methodology for asynchronously executing OLE DB transactions.

Device Agent Slots : this agent transfers process values between Adroit and FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..

Digital Agent Slots : this agent stores a Boolean value and provides engineering functionality such as value inversion.

DumpConfig Agent Slots: this agent simply stores the configuration of specific agents in an OLE DB database.

EventLogging Agent Slots : this agent manages the logging of events by Adroit to Windows event logs and to a database.

EventOutput Agent Slots : this agent directs event log messages to output devices (printers, files, databases).

Expression Agent Slots : this agent performs user-defined calculations to calculate an output value.

Frame Agent Slots : this agent stores up to 32 indexed strings.

ICMP Agent Slots : this agent uses the Internet Control Message Protocol to determine the existence of a remote device on the network.

Integer Agent Slots : this agent stores an integer number +/– 2147483647 (32 bits).

IOT Agent Slots : this agent can represent any object containing multiple properties (or slots), which are defined AFTER adding the IOT agent.

Marshal Agent Slots : this agent provides the functionality of 16 digital agents in a single agent.

MaxDemand Agent Slots : this agent monitors your electricity usage so that you remain within your agreed usage limits.

MultiMedia Agent Slots : this agent runs a variety of Windows compatible multi-media files such as .WAV, .AVI and .MID.

MultiState Agent Slots : this agent defines up to 16 discrete states to create operating and/or control sequences.

Notify Agent Slots : this agent directs alarms to pagers and also to cellular phones via SMS.

OEE Agent Slots: this agent either calculates the OEEstands for Overall Equipment Effectiveness, which typically identifies the productivity or utiltization of a machine or an entire plant, as a percentage. for the monitored equipment and/or plant or measures a specific KPIKey Performance Indicator, a quantifiable measurement that measures how well something is accomplishing its goals and objectives..

PerfMon Agent Slots : this agent monitors up to 16 Windows Performance counters to detect performance bottlenecks.

PID Agent Slots : this agent provides the 25 signals and tuning parameters associated with an external PID controller.

Proxy Agent Slots : this agent provides continuous updates of the value of an agent referenced from a remote Agent Server.

Real Agent Slots : this agent stores a real (floating point) value.

Recipe Agent Slots : this agent provides basic sequencing and batching and reporting capabilities.

Scan Agent Slots : this agent communicates one or more tags to an FED, these agents are managed by Device agents.

Scheduler Agent Slots : this agent defines one or more time periods of time to enable or disable other agents.

Script Agent Slots : this agent performs one or more Visual basic or Java scripts to do complicated tasks.

Shift Agent Slots : this agent determines the current shift number as defined by a configurable shift pattern.

SNMPMgr Agent Slots : this agent monitors and/or manages network devices using SNMPSimple Network Management Protocol (SNMP) is used to monitor and manage a diverse range of devices on a computer network..

Statistical Agent Slots : this agent provides the basic functionality to create a statistical process control strategy.

String Agent Slots : this agent stores a "string" of text characters, only the first 79 of which can be used for scanningthe process of communicating a value (slot), typically to and/or from a front-end device (FED)..

StringList Agent Slots : this agent stores an unlimited number of indexed ASCII character strings of variable length.

SystemDataLog Agent Slots : this agent administers the backing up of datalogs and synchronises datalogs in an Adroit cluster.

SystemInformation Agent Slots : this agent acts as an information center containing data that is global to the Agent Server.

Text Agent Slots : this agent stores a 79-character text string (this length excludes the mandatory zero terminator character).

Timer Agent Slots : this agent performs several commonly used timing operations.

 

For the slots that are saved to the Adroit database (.WGP) file for each agent type and the format of these saved values, see: Agent Type Saved Format Reference.
