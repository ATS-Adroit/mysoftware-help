Script Agent - Slot Details

The Script Agent provides a basic scripting language to automate complex or repetitive tasks. End users can define their own subroutines and functions and pass data to other applications using OLE automation.

This agent is located in the following file: T_SCRIPT.DLL

Slots:

Note: All slots marked with a superscript R are read only slots.

Slot Name Type Function

compile

BOOLEAN

Forces all modules to be reloaded and compiled

disableRun

BOOLEAN

Enable or disable the ability to run the script

eventlogErrors

BOOLEAN

Enable or disable eventlogging of runtime and compilation errors

informationR

VARSTRING

Compilation and execution information

moduleList

VARSTRING

CSV string containing a list of module names

runCleanup

BOOLEAN

Run the clean up subroutine

runInitialise

BOOLEAN

Run the initialization subroutine

runNow

BOOLEAN

Run the main subroutine

runTime

INTEGER

Time in milliseconds taken to do the last execution

scheduleEnabled

BOOLEAN

Enable or disable script scheduling

schedulePeriod

REAL

Time period in seconds between scheduled executions

scheduleStartTime

TIME

Start scheduling execution of the main subroutine from this point in time.

scriptEngineId R

INTEGER

VBScript = 1; JScript = 2

scriptEngineName

VARSTRING

Name of the selected scripting engine

subroutineCleanup

VARSTRING

Perform any final script cleanup in this subroutine

subroutineInitialise

VARSTRING

Perform any script initialization in this subroutine

subroutineMain

VARSTRING

Name of main subroutine to be run

triggerEnabled

INTEGER

No Triggering = 0; Default triggering = 1; Trigger with deadband = 2.

triggerList

VARSTRING

CSV string containing a list of triggers

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Idle

State is on if nothing is executing.

Note: The agent has to be in this state before it will execute a script.

status bit 17

Running

State is on if a script is currently executing.

status bit 18

Compilation error

State is on if a syntax error is found in the module file.

status bit 19

Runtime error

State is on if the execution terminated due to a fatal error.

status bit 20

Overrun error

Works only for scheduled scripts.

State is on if the execution took longer than the schedule period, i.e. runTime in seconds > schedulePeriod in seconds.

Methods of creation:

Manual

Agents created by default:

None
