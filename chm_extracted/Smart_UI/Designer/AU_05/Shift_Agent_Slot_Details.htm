Shift Agent - Slot Details

The Shift agent determines the current shift number as defined by a configurable shift pattern, which can then be used by other agents.

Instead of configuring the shift pattern information into each instance of these agents.

This agent is located in the following file: T_SHIFT.DLL

Slots:

Slot Name Type Function

catchupData

RAWBYTES

For internal use

connection

VARSTRING

If specified, the shifts are added to the Adr_Grouping_Details table as the shifts occur in real time, which is used by Adroit SCADA Intelligence. 

Note:

If you specify global, the Global OLE DB connection string of the Agent Server is used, which is specified in the Adroit Config Editor.

  • Typically, you can launch this tool from the Desktop shortcut.
  • Select the Agent Server Configuration Welcome menu item.
  • Select the Advanced Agent Server Configuration option.
  • At the bottom of the dialog, the Global OLE DB connection field is available for you to specify this connection string.

data

RAWBYTES

Encoded data about the current shift for internal use by Adroit agents.

day

REAL

The day value for the current shift – overnight shifts will have previous day’s number from midnight until end of shift

info

STRING

Current shift information string in the format e.g.

2010/03/17 Shift 2, 08:00 hours from 10:00 to 18:00

number

INTEGER

The current shift number

pattern

LIST

A list of time shift patterns where each entry contains the following parameters:

  1. SpecialDate – a string value in the format yyyy/mm/dd that denotes a specific unique date.  Empty string denotes not used
  2. DayOfMonth – an integer value in the format mmdd that determines a special recurring holiday e.g. 1225 for 25 December. Value of 0 denotes not used
  3. DaysOfWeek – an integer bit mask representing Monday to Sunday
  4. Shift1StartTime … Shift6StartTime– a real value that denotes the hour of the day for the start of shift 1 … 6.
shiftEndTime TIME Stores the ending time of the current shift.
shiftStartTime TIME Stores the starting time of the current shift.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

ShiftEnd

Pulsed on at the end of every shift to allow interested parties to perform shift end operations.

status bit 17

InvalidShift

On when the shift pattern entry for the current time is not found.

status bit 18

ConnectionError

On when the OPTIONAL OLEDB connection string, if specified, is invalid.

Methods of creation:

Manual

Agents created by default:

None
