Analog Agent - Slot Details

The Analog Agent stores a floating point engineering value, and associated scaling parameters.

It has the capability of comparing this value against 4 alarm limit values, monitoring rate of change, and raw value scaling. If the alarm inhibit bit is set, alarm limits and rate of change are not checked.

This agent is located in the following file: T_ANALOG.DLL

sqRoot

BOOLEAN

SQRT input conditioning flag
statsAverage REAL The average of all the recorded values.
statsBuffer VARSTRING For INTERNAL USE: this stores all the value slot values recorded for the current period from which the statistics are calculated.
statsDirection INTEGER

This compares the newest recorded value (the current value slot) to the oldest recorded value and displays the results of this comparison, so that you can determine the general direction in which it is changing (its trend) as follows:

  • 0 typically means that the value has not changed.
  • 1 if the current value is higher, so that the trend of the value is moving up
  • -1 if the current value is lower, so that the trend of the value is moving down.
statsDirDev REAL

An optional minimum deviation or deadband to ensure that this trending direction specified by the statsDirection slot only indicates significant changes in value. In this case set the statsDirDev slot, to the required decimal percentage value (a value from 0 to 1) so that deviations in value less than or equal to this specified percentage result in the statsDirection slot being set to 0 meaning “no change”.

For instance, if you set the statsDirDev slot to 0.10, then only when the newest recorded value differs from the oldest recorded value by more than 10 % will the statsDirection slot display whether the current value is higher (1) or lower (-1).
statsMax REAL

The highest recorded value.
statsMin REAL

The lowest recorded value.
statsPeriod INTEGER

The statistics are only calculated, when this slot is set to the number of minutes that you want the value slot to be recorded for statistical evaluation. In this case the value slot is recorded every second over this timespan and the statistics are calculated from these recorded values.

IMPORTANT: Since the calculation of these statistics can affect performance if used excessively, please ensure that you ONLY calculate statistics for the Analog values you need them for. Setting the statsPeriod slot to 0 (the default value) disables the calculation of these statistics for an Analog agent.
statsStdDev REAL The standard deviation of all the recorded values.
statsReset BOOLEAN This clears the statsBuffer slot of all of its recorded values to restart calculating the statistics.
statsSum REAL The total of all the recorded values.
statsUpdate BOOLEAN For INTERNAL USE ONLY.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Low

Value is <= lo alarm level.

status bit 17

Low-low

Value is <= loLo alarm level.

status bit 18

High

Value is >= hi alarm level.

status bit 19

High-high

Value is >= hiHi alarm level.

status bit 20

Rate-of-change

Value rate of change is >= ROC alarm level.

status bit 21

Normal

ON when no alarm values have been trespassed.

status bit 22

Changed

When change monitoring is enabled (the enableChange slot is set to 1) AND the Engineering value (the value slot) CHANGES then this status bit will (be set to 1 and then immediately be set back to 0).
status bit 23 OutOfRange

ON, when the rawValue slot exceeds the rawMax value or is lower than the rawMin value.

Note: When the OutOfRangeEqualsAgentBad registry setting is added and set to 1, this also sets the statusAgentBad condition bit, which was the legacy response, so that all the instances of this value will be greyed out on the mimics which display them.
