SNMPMgr Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

.WGP File Line Description

IPA=nnn.nnn.nnn.nnn

The IP Address of the device to be monitored.

COM=string

The SNMP Community String required to access the SNMP objects and their values, for this device.

WCOM=string

The SNMP Community String required to write (set) values for this device.

MON=string

The name of the .WGX file that stores the OID list of this agent, which is typically saved in the following folder: C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\Data and is called snmpmgr.wgx.

IMPORTANT: Please ensure that you backup this 'snmpmgr.wgx' file in addition to the WGP file, which is stored in the same folder.

RAT=nnnnn

Scan rate in milliseconds for retrieving the values of the scanned and enabled SNMP objects in the selected objects list.

STT=n

A Boolean value indicating whether the monitoring (scanning) process of this agent is either started or stopped.

TMT=n

The Integer timeout value i.e. the maximum time (in seconds) to establish a connection to this device.

RET=n

The Integer retries i.e. the number of attempts to connect to the device, before deeming this device to be unavailable.

TRAP=n

A Boolean value indicating whether the traps are enabled for this agent or not.

IPP=nnn

The Integer IP port used for SNMP communication to this device.

PDU=nnn

The Integer number of OID values to include in each polling transaction.

VER=n

The Integer SNMP version the device supports.

USER=string

SNMP version 3 ONLY: the required user name.
AUTH=string SNMP version 3 ONLY: the required password for authentication on this device.
ENCR=string SNMP version 3 ONLY: the required encryption password for this device.
MIB=string the name of the MIB file if this was used to specify the OID tree, instead of walking the device.
