Command Agent - Slot Details

The Command agent can both send SMS messages either manually or automatically and can escalate messages to another Command agent, if necessary. However, it is in receiving textual commands in SMS messages that it is able to remotely configure Adroit.

This agent is located in the following file: T_COMMAND.DLL

Slots:

Slot Name Type Function

allowAckCommand

BOOLEAN

If enabled (set to TRUE) this allows this Command agent to perform ACK commands that it receives. For details, see Specifying Permitted Commands or ACK Commands.

allowAllCommands

BOOLEAN

If enabled (set to TRUE) this allows this Command agent to perform textual commands that it receives, provided they have been enabled. For details, see Allowing Commands to be Performed.

allowAnonymous

BOOLEAN

If enabled (set to TRUE) this allows Command agent to receive messages and potential commands from any caller. For details, see Configuring Anonymous Caller Access.

allowGetCommand

BOOLEAN

If enabled (set to TRUE) this allows Command agent to perform GET commands that it receives. For details, see GET Commands.

allowRepCommand

BOOLEAN

NOT IN USE

allowSetCommand

BOOLEAN

If enabled (set to TRUE) this allows this Command agent to perform SET commands that it receives. For details, see SET Commands.

allowSubCommand

INTEGER

NOT IN USE

bitErrorRate

REAL

This displays the bit error rate of the SMS GSM modem, measured in percent, which should not exceed 40% for effective data transmission. For details, see Diagnosing the GSM_SMS Device.

defaultAnalogueFormat

STRING

This can specify the default format that is used to display any real or floating point numbers in messages that are sent from this Command agent. For details, see Default Real Number Formatting.

delReportTime

INTEGER

Timeout period for monitoring network delivery reports, if this is exceeded then the SMS message can be sent via another Command agent to someone else. Although the reqDelReport slot must be enabled before this is used. For details, see Monitoring Message Receipt.

device

STRING

The name of the GSM_SMS device used by this Command agent to send and, if necessary, receive SMS messages. This specified device must also be configured for sole use by Command agents and therefore cannot be used by the scanning subsystem for the scanning of other agents. For details on the necessary configuration, see Configuring GSM_SMS devices.
disableSendingInStandby BOOLEAN When using this agent in a clustered Agent Server, set this slot to 1 to disable the sending of SMS’s when the Agent Server is in Standby mode to AVOID sending duplicate messages.

emptyQueue

BOOLEAN

Empty the queue of current messages to be sent, for instance, for testing purpose or when the message queue has been filled with unwanted or unnecessary messages. For details, see Managing Message Queues.
enableCmdInStandby BOOLEAN NOT IN USE

enableSmsSending

BOOLEAN

In order for the Command agent to send and/or receive SMS messages, it needs to specify a GSM_SMS protocol driver device that will be used to send and, if necessary, receive SMS messages. If true, this Command agent will attempt to connect to the GSM_SMS device, specified by the device slot. For details, see Specifying the GSM_SMS Device.

enforcePassword

BOOLEAN

NOT IN USE

escalationTag

TAGNAME

The name of another Command agent to which SMS messages are to be sent when the timeout specified by either the delReportTime or recipResponseTime slots have expired. Although, this will only be used if either the reqDelReport or reqRecipResponse slots is enabled (set to TRUE). For details, see Monitoring Message Receipt and Monitoring Message Response.

expandPsuedos

BOOLEAN

When enabled (set to TRUE), pseudonyms and macros specified in a received message will be correctly interpreted and any outgoing messages will have the pseudonyms replaced with the full tag. For details, see Enabling Pseudonyms and Macros.
globalAck VARSTRING To globally acknowledge alarms via Putslot, use the following syntax:

tag[.alarm type]

Note: This method does NOT use SMS to acknowledge alarms, nor are you limited to only using the Putslot utility, any method can be used that sets the value of this slot.

Where ‘tag’ is the name of the agent a user wants to acknowledge, ‘[.alarm type]’ is optional, this is used if a used wants to acknowledge a specific alarm for the specified agent. For instance “ANA_1.High” only acknowledges ANA_1.High, whereas “ANA_1” acknowledges ALL the alarms relating to the agent ANA_1.

To globally acknowledge more than one alarm at a time, use the following format in this globalAck slot: tag[.alarm type],…, tag[.alarm type]

ignoreTime

INTEGER

If the Command agent is able to process SET commands, then it is possible to specify the period, in minutes, for which these commands are of valid for, which is calculated from the time the message is originally sent. For details, see Ignoring Delayed SET Commands.

lastMsgReceived

VARSTRING

Contains the last message that was received by this Command agent. For details, see Message Sending and Processing Slots.
lastMsgReceivedTime TIME Displays the time of the last message received.
lastMsgReceivedTimeStr VARSTRING Displays the time of the last message received, as a (var)string.

lastMsgSent

VARSTRING

Contains the last message that was sent from this Command agent to the designated GSM_SMS driver. For details, see Message Sending and Processing Slots or Specifying the GSM_SMS Device.
lastMsgSentTime TIME Displays the time of the last message sent.
lastNumberReceived STRING Stores the cellphone number of the last message received by this agent.

password

STRING

NOT IN USE

phoneNumber

STRING

The recipient phone number for sending of alarms, subscriptions, and commands. The Command agent has been designed to only send SMS messages to this phone number. For details, see Specifying the Recipient Phone Number.

pseudoData

VARSTRING

Contains the list of configured pseudonyms and macros. For details, see Using Pseudonyms and Macros.
queueCount INTEGER Number of messages currently in the queue, which you can compare to the queuesize slot to determine how full the current queue is.

queuesize

INTEGER

The maximum queue size, once this maximum has been reached, any further messages that arrive will be discarded and will not be sent. For details, see Managing Message Queues.

rawValue

VARSTRING

The most recent data received by this slot is sent by the Command agent to its associated GSM_SMS device. For details, see Sending SMS Messages or Message Sending and Processing Slots.

recipientList

VARSTRING

The list of phone numbers allowed to issue commands to this Command agent. For details, see Configuring Authorised Caller Access.

recipResponseTime

INTEGER

Timeout period for monitoring recipient responses in which the SMS message must be returned to the Command agent, if this is exceeded then the SMS message can be sent via another Command agent to someone else. Although the reqRecipResponse slot must be enabled before this is used. For details, see Monitoring Message Response.

reportData

VARSTRING

NOT IN USE

reqDelReport

BOOLEAN

If enabled (set to TRUE) this monitors when the recipient receives a sent SMS message by requiring a delivery report to be sent as soon as the SMS messages arrives, which is then logged to the event log for auditing purposes. For details, see Monitoring Message Receipt.

reqRecipResponse

BOOLEAN

If enabled (set to TRUE) this monitors when the recipient acknowledges a sent SMS message by requiring each message to be sent back to the Command agent on arrival, in which case all incoming messages (to its configured GSM_SMS device) are logged to the event log for auditing purposes. For details, see Monitoring Message Response.

setByPseudos

BOOLEAN

If enabled (set to TRUE) this forces the Command agent to only perform SET commands that use pseudonyms or macros. For details, see SET Command Usage Restriction.

signalStrength

INTEGER

This displays the signal strength of the SMS GSM modem, measured in percent, which should not be less than 29% for effective data transmission. For details, see Diagnosing the GSM_SMS Device.

subsData

VARSTRING

Contains a list of configured subscriptions or automatic SMS messages that contains the value of a tag (agent.slot), which makes it possible to remotely monitor the status of important process values. For details, see Automatic Sending of Values.

templateData

VARSTRING

NOT IN USE

value

STRING

The most recent data received by this slot will also be sent to the rawValue slot. Being a standard 80-character String slot, other agents can be @ scanned to it, so that their STRING slots can be sent by the Command agent instead. For details, see Message Sending and Processing Slots.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

MsgSendError

On if the last message could not be sent due to cell phone network-specific problems, such as signal problems etc.

status bit 17

AllCommands

On when Command agent is able to perform commands that it receives. For details, see Allowing Commands to be Performed.

status bit 18

SetCommands

On when Command agent is able to perform SET commands that it receives. For details, see Specifying Permitted Commands or SET Commands.

status bit 19

GetCommands

On when Command agent is able to perform GET commands that it receives. For details, see GET Commands.

status bit 20

AckCommands

On when Command agent is able to to perform ACK and LACK commands that it receives. For details, see ACK Commands.

status bit 21

RepCommands

Currently not in use.

status bit 22

SubCommands

Currently not in use.

status bit 23

ExpandPseudos

On when pseudonyms and macros specified in an incoming message received by this Command agent will be correctly interpreted and any outgoing messages will have the pseudonyms replaced with the full tag. For details, see Using Pseudonyms and Macros.

status bit 24

SignalError

On if either the signalStrength slot is less than 29 % or the bitErrorRate slot is greater than 40 %. For details, see Diagnosing the GSM_SMS Device.

status bit 25

SetByPseudos

On when SET commands can ONLY use pseudonyms and macros. For details, see Additional SET Command Restrictions.

status bit 26

AllowAnonymous

On when the Command agent is able to receive messages and potential commands from any caller. For details, see Configuring Anonymous Caller Access.
status bit 27

RawValueChanged

 NOT IN USE
status bit 28 MsgReceived NOT IN USE
