DataLog Agent - Slot Details

The DataLog Agent performs historical data logging to disk of successive values of an agent slot, and subsequently allows retrieval of the logged information.

Note: The contents of the slots marked with an * are dependant on the cfgSet slot value.

This agent is located in the following file: T_DATALOG.DLL

Slots:

Slot Name Type Function

algorithm*

INTEGER

Specify the required logging method, as follows:

  • 0 = latest value
  • 1 = time weighted average of all values
  • 2 = maximum of all values
  • 3 = minimum of all values
backupCSV BOOLEAN Enable CSV backups, since in addition to creating .LGB files for Adroit to retrieve historical data, you can also create .CSV files to enable third party applications to trend or report this data too
backupPeriod INTEGER

Backup period code, which determines how much data each .LGB file contains. This is automatically set to 4 for a period of a month of data.

Note: To disable datalog backups from being created for a particular Datalog, set this backupPeriod slot to 0.

cfgSet

INTEGER

The log set being configured - for internal use only.

clientSet

INTEGER

The log set from which the last data retrieval was made.

dataHoles

LIST

A list of holes in the datalog file, which are the periods in which the Agent Server was not running.

deadband*

REAL

Value deadband

disableStandby

BOOLEAN

Disable logging, when this Agent Server is clustered and is in standby mode - to prevent duplicate logging.

doubleEntries*

BOOLEAN

For backward compatibility only - this creates double log item entries if the log period exceeds the configured log period by a factor of 2. Should normally be OFF.

flushLazily*

BOOLEAN

For internal use only.
housekeepPeriod INTEGER Housekeeping period in days, which ensures that the created .LGB (and .CSV) files older than a specified number of days (default 90 days) are deleted from the backup folder.

integrityFlag

INTEGER

Integrity indicator

internal

BOOLEAN

For internal use only.

interpolate*

BOOLEAN

For backward compatibility - Enables data interpolation between samples on retrieve. Should normally be OFF.

lastError

STRING

Last internal error
limitLogInterval TIME

Specifies the Time required for Out of limit logging.

lock

BOOLEAN

Locks the agent

logFilename*

VARSTRING

Full path name of the data log file. If empty, this defaults to an .LGD file with the same name as the WGP file.

loggedSlotType

INTEGER

Logged slot type code

logNow

BOOLEAN

Instructs the Datalog agent to log a reading.

logPeriod*

TIME

The period for which data will be retained.
lowerLimit REAL Lower limit for Out of limit logging

minLogInterval*

TIME

Minimum logging interval (loggging rate)

mode

INTEGER

Logging mode (continuous, demand or both)
period REAL Log period in days, which is easier to set externally than using the legacy logperiod TIME slot.
rate INTEGER Log rate in milliseconds, which is easier to set externally than using the legacy minloginterval TIME slot.

reset

BOOLEAN

Clears all data

retrieveData

RAWBYTES

Internal use only (used with datalog catchup)

retrieveEndTime

TIME

Internal use only (used with datalog catchup)

retrieveOptions

INTEGER

Internal use only (used with datalog catchup)

retrieveStartTime

TIME

Internal use only (used with datalog catchup)

serverMode

INTEGER

Used to receive server mode subscription

sets

INTEGER

The configured number of log sets.

start

BOOLEAN

Start/stop

timeCursor

TIME

Time index

trigger

STRING

Tag to be used for demand logging.
upperLimit REAL Upper limit for Out of limit logging

value

REAL

Output value

windowData

RAWBYTES

Retrieved data

windowParams

RAWBYTES

Retrieval parameters (start, end, etc)

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

BackupEnabled

 

State is on, if the Enable backups option has been selected for this datalog agent so that it will be included in the global datalog backup.

Methods of creation:

Automatic. Do not add new instances manually.

Agents created by default:

None
