DbAccess Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

 

The DBQuery agent configuration is saved to the WGP file as follows:

.WGP File Line Description
MTD=number Trigger method
INT=number Interval
TRG=string Trigger tag
SBY=0 or 1 Disable on standby
CON=string Database connection string
TBL= string Database table name
WC= string Where clause
CQ=string Custom query
AGS=0 or 1 Enable agent
TAGS=list List of tags
RRN=0 or 1 Auto-reset runNow
