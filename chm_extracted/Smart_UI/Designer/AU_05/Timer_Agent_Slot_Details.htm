Timer Agent - Slot Details

The Timer Agent performs several commonly used timing operations, which previously could only be inefficiently accomplished by using expressions, recipes and scripts.

This agent is located in the following file: T_TIMER.DLL

Slots:

Slot Name Type Function

autoReset

BOOLEAN

If enabled (set to True) this will automatically reset the start slot, 100 milliseconds after the timer has expired. Not used if the freeRun slot is enabled.

delayTime

INTEGER

The delay time (in ms) i.e. the time before the pulse (value slot) is switched on (set to TRUE). This must be left at zero if an "on timer" is configured. For details, see Configuring On Timers.

freeRun

BOOLEAN

If enabled (set to True) this enables the "pulse generator" mode of operation. For details, see Configuring Pulse Generators.

granularity

INTEGER

The granularity (in ms) determines how often the Timer agent monitors the time after the timer has started.

If less than the duration of the timer, then the timeleft slot indicates the remaining time, in milliseconds, before this timer expires.

The default value of 0, forces the granularity period to equal the required duration of the timer, so that this timeleft slot is never calculated.

WARNING! The smaller the specified granularity, the greater the amount of work the Agent Server is required to perform in updating its clients with the timeleft slot value.

Note: Although this granularity value is has a minimum of 100 ms, a minimum of 1000 ms is recommended as a "safe" value.

inputTag

TAGNAME

This can automatically start the timer by subscribing to another tag in the Agent Server.

Note1: If this tag is numeric, then the start slot is enabled (set to TRUE) when it’s value is non-zero.

Note2: If this tag is a string, then the start slot is enabled when this string is not empty.

pulseWidth

INTEGER

The pulse width (in ms) OR the time at which the pulse (value slot) is switched on (set to TRUE).

This must be left at zero if an "on delay timer" is configured. For details, see Configuring On Delay Timers.

start

BOOLEAN

Starts and stops the timer.

Note: When this slot is set to FALSE, the value slot is also set to FALSE and the currently configured timer expires.

timeLeft

INTEGER

If the granularity slot is set at 100 milliseconds or greater and is less than the required duration of the timer, then this slot displays the amount of time left in the timing cycle in milliseconds.

value

BOOLEAN

The output of the timer.

Note: This slot can be used to enable, disable or schedule other agents.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Running

On if the timer is enabled i.e. the timer is operating.

status bit 17

Expired

On when the timer has terminated, the event which causes this to occur is timing operation-specific, as follows:

  1. The pulse width time expires, when configured as an on timer. For details, see Configuring On Timers.
  2. The delay time expires, when configured as an on delay timer. For details, see Configuring On Delay Timers.
  3. The timer is not running, when configured as a pulse generator. For details, see Configuring Pulse Generators.

Methods of creation:

Manual

Agents created by default:

None
