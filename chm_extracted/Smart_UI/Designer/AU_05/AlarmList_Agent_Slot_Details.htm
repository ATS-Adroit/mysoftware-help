AlarmList Agent - Slot Details

The AlarmList agent performs alarm list management.

This agent is located in the following file: T_ALARMLIST.DLL

Slots:

Slot Name Type Function

alarmList

LIST

The current alarm list.

cleanASPlease

STRING

Used by system for garbage collecting alarms.

dataPersist

BOOLEAN

Saves the alarm list on shutdown.

globalAck

RAWBYTES

Globally acknowledge alarms in the alarm list.

globalAckLastX

INTEGER

Acknowledge the last 'n' unacknowledged alarms. If n is zero, all the alarms will be acknowledged.

localAck

RAWBYTES

Locally acknowledge alarms in the alarm list.

localAckLastX

INTEGER

Acknowledge the last 'n' unacknowledged alarms. If n is zero, all the alarms will be acknowledged.

numAlarmsActive

INTEGER

The number of active alarms in the list.

numAlarmsUnacked

INTEGER

The number of unacknowledged alarms in the list.

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Alarms Active

One or more alarms are active.

status bit 17

Alarms Unacked

One or more alarms are unacknowledged.

Methods of creation:

Automatic/Postload/Manual

Agents created by default:

defaultAlarmAgent
