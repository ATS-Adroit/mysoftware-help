AlarmManagement Agent - Slot Details

The AlarmManagement agent logs all incidentssignified by AgentName.AlarmType, which indicate that this agent has gone into the condition or state specified by this alarm type. Each incident can either be an alarm (requiring action) or an event (not requiring action). and their details, including their time of occurrence, their time of acknowledgement and the time at which they were cleared to a database.

This agent is located in the following file: T_ALARMMANAGEMENT.DLL

Slots:

Slot Name Type Function
alarmListRequest STRING

Requests a list of alarms by using one of the following methods of determining which alarms should be retrieved:

  • all : this displays all the configured alarms in the Alarm Management agent.
  • alarmagent=defaultalarmagent : in this case all the alarms of the defaultalarmagent Alarm agent will be displayed.
  • agent=tanklevel : in this case all the alarms for the agent that is called 'tanklevel' will be displayed.
  • incident = tanklevel.high : in this case all the alarms generated for this specific 'tanklevel.high' incident will be displayed.
  • context=3 : in this case, you can specify the unique number of the category, whose incidents you want to retrieve - in this case all the incidents added to the category = 3 are retrieved.
  • inhibitedincidents : this displays all the incidents that are currently inhibited in ALL the Alarm agents.

IMPORTANT: After setting this slot, immediately read the AlarmListXml slot to retrieve the list of retrieved alarms in XML format.
alarmListXml VARSTRING Contains the XML recordset of the retrieved list of alarms once the alarmListRequest slot is set.

For internal use by VIZNET only.

connection

VARSTRING

The connection string to the specified OLE DB database (preferably MS SQL).

Note: You CANNOT connect to an MS Access database because of its known performance issues
contextXml VARSTRING An XML recordset of the Adr_AM_Categories table to allow the solution to display a unique context so that it can customise the categorization of its incidents.

debug

BOOLEAN

For support use only: if the “Log system events” setting is enabled and this is set to 1, then debugging events for the AlarmManagement agent are logged to the event log.

debugStr

VARSTRING

For support use only: when debug mode is enabled for this agent, this slot displays the last debug message string.

disableStandby

BOOLEAN

When set to TRUE (1) this will disable the logging of incidents to the database on standby cluster nodes.
documentName STRING

The document name for the incident as specified in the documentRequest slot.

This document name may be a UNC name or local name. If it is a local (unqualified) name, it is up to the user to ensure that local copies of the relevant documents exist.
documentRequest STRING Specifies the incident for which the associated document name is required.

enable

BOOLEAN

When set to TRUE (1) this enables the agent to start logging records.

engineQueuesize

INTEGER

Displays the number of incidents that the AlarmManagement agent still needs to log to the database. This should always remain at 0.

engineState

INTEGER 

For support use only.

housekeepCount

INTEGER

The number of days to use for housekeepingthe removal of unnecessary records from a database, the length of time specified depends on:

  • the storage capacity you have available for your database and
  • how useful this data becomes to you the older it gets.

Note: This value cannot be less than 30.

housekeepEnable

BOOLEAN

Enables housekeepingthe removal of unnecessary records from a database. The default value is FALSE, which specifies that housekeeping must be performed by the customer.
inhibitChange STRING

Allows the user to modify the inhibit configuration of an incident, as follows:

TANKLEVEL=1 to globally inhibit the TANKLEVEL agent

TANKLEVEL=0 to remove global inhibit on the TANKLEVEL agent

TANKLEVEL.High=0 to switch off inhibit for the incident

TANKLEVEL.High=10 to inhibit the incident for 10 minutes

TANKLEVEL.High=2014/07/30 23:24:25 to inhibit the incident until the specified time

kpi[x]

REAL

The value returned by the KPI query, specified by the kpi[x]Query slot.

Note1: [x] is a number from 1 to 6.

Note2: If the KPI[x]Query returns multiple columns and/or rows, this slot is set to 0.0.

 

kpi[x]Description

VARSTRING

The description of the KPI[x], which is saved in the WGP file.

Note: [x] is a number from 1 to 6.

kpi[x]Query

VARSTRING

The KPI query, which is saved in the WGP file. This must be a SELECT query that only returns a SINGLE value.

Note: [x] is a number from 1 to 6.

kpi24Hrs

REAL

The automatically calculated number of alarms per hour for the current 24 hour period.
kpiCalcNow BOOLEAN

This Boolean slot pulses to allow users to perform a KPI calculation at any time, especially when they have set the kpiCalcRate slot to 0.
kpiCalcRate INTEGER 

Specifies the maximum rate at which the KPIs should be calculated, in minutes, to improve the performance of this agent, which by default is set to 1.

If this slot is set to 0 then KPI calculations are NEVER executed on new or changed alarm occurrences and so also added the Boolean kpiCalcNow slot that pulses to allow users to perform a KPI calculation at any time, especially when they have set the kpiCalcRate slot to 0.

kpiTotal

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

ConnectionError

Set to TRUE (1) when the connection with OLE DB source cannot be established.

status bit 17

QueryError

Set to TRUE (1) when a query error has occurred.

status bit 18

ReasonsRequired

Set to TRUE (1) when there are incidents that require reasons and/or notes.

Note: Indication can take up to 30 seconds to reflect the current status.

status bit 19

Unlicensed

Set to TRUE (1) when the required OEM license is missing from the Agent Server license.
