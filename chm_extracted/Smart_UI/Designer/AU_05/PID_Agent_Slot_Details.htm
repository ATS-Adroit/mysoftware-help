PID Agent - Slot Details

The PID Agent is simply a faceplate container for all the commonly found signals and tuning parameters associated with a PID. This agent simply encapsulates these signals and tuning parameters as tags within a single agent. These values can then be scanned to the outside world, via their raw slots.

This agent is located in the following file: T_PID.DLL

Slots:

Specific status bits: 

Note: These are of type BOOLEAN.

Bit Number Name Function

status bit 16

Low

PV is lower than its configured Lo alarm value

status bit 17

Low-Low

PV is lower than its configured LoLo alarm value

status bit 18

High

PV is higher than its configured Hi alarm value

status bit 19

High-High

PV is higher than its configured HiHi alarm value

status bit 20

EHigh

Error value is higher than its EHi alarm value

status bit 21

EHigh-High

Error value is higher than its EHiHi alarm value
