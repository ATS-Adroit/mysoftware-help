Alarm Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

 

.WGP File Line Description

DPER=n

Data Persistence

ENAB=n

Enabled or Globally Inhibited

PRTY=n

Alarm Priority Filter

RDB=nnnn

Routing Time deadband (ms)

TYPLST0='name','agent type','bitmask','description'

First Alarm Type

TYPLST1='name','agent type','bitmask','description'

Second Alarm Type

End of Type List Indicator

n'th Alarm Route

End of Route List Indicator
