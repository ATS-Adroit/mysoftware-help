Slot Types

Slot types define the type of data that can be stored within a slot, which is an externally accessible attribute of an agent. For further details, see About Agent Data (Slots).

The supported slot types are:

Type Description

BOOLEAN

Boolean TRUE/FALSE Indication

INTEGER

32-bit signed integer

REAL

IEEE double precision floating point value

STRING

80-byte ASCII string

TIME

Win32 64-bit FILETIME

TAGNAME

68-byte ASCII string

AGENTID

Adroit AgentId struct.

RAWBYTES

A sequence of bytes whose contents are known to the agent only. (Agent specific data)

LIST

Adroit List Slot

AGENT

For future use.

VARSTRING

An unlimited-length ASCII string (first 4 bytes contain the length)

HEADER

Agent header structure

NOTYPE

Undefined type.

Note: The RAWBYTES slot is ONLY for internal use of the agent and does NOT provide any other functionality.
