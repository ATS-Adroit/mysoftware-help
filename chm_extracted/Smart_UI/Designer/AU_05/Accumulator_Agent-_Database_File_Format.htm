Accumulator Agent - Database File Format

For a detailed description of any of its slots, see Slot Details.

See the agent header slots for the information that is common to all agent types.

 

The Accumulator agent configuration is saved to the WGP file as follows:

.WGP File Line Description
ENA=0 or 1 XML representation of slot structure for the current agent
DOS=0 or 1 Expression used for the agent
CONN=string Database connection string
TABLE=string Database table name
HKP=number Housekeeping period
INT=number Interval
INTM=number Interval mode
IAG=string Interval tag
VTAG=real number Input tag
VHH=real number Value hihi alarm
VHI=real number Value hi alarm
VLO=real number Value lo alarm
VLL=real number Value lolo alarm
RHH=real number Raw value hihi alarm
RHI=real number Raw value hi alarm
RLO=real number Raw value lolo alarm
RLL=real number Raw value lo alarm
DBD=real number Deadband value
