Putting Values into Agents

Adroit provides a utility that performs a putslot operation. The putslot utility enables a specific value to be written to the target agent’s slot. Alternatively, a value obtained from another agent’s slot, by dereferencing it with an asterisk (*) prefix, can be used in the putslot expression both for the target agent’s name and the put value.

It can be scheduled to start a process, allowing the scheduler to trigger commands (e.g. print, scan etc.) and to drive mimics and dynamic pictures.

The syntax of a Putslot command is as follows:

putslot [-ccomputer.server],[*]agent.slot,[*]value[,time]

Note1: DO NOT insert spaces between arguments [ ] means optional.

Note2: By default a connection to a local Agent Server is assumed, but if a computer.server is specified, prefix it with –c.

Symbol Description Example

computer

computer name

-cMSP-1

server

Agent Server

West-Plant

agent

target agent

ANALOG01 or *OTHER (asterisk dereferences tag)

slot

target slot

RawValue

value

value to put or ~ to toggle value if Boolean slot

90.0 or "a string" or *ANOTHER.VALUE (asterisk dereferences tag) or ~ (~ absent = set value of slot)

time

time of change

04/10/1998 14:00:00 (dd/mm/yyyy hh:mm:ss)

Note: The command line input is now case-sensitive when changing the values of STRING slots.

Examples:

putslot boo01.value,1

putslot boo01.value,~

putslot int01.value,123,04/10/1998 14:00:00

putslot -cMSP-1.West-Plant,int01.value,123,04/10/1998 14:00:00

putslot str01.value,"hello"

putslot ana01.value,*ana02.value

Configuring the same slot of multiple agents

  1. If necessary, create the required Agentgroup or simply use the pre-defined Agentgroups for the defined Agent types.
  2. Configure this agentgroup as a bulk-editing group, as follows:
  1. Open the Agent Configurator window.
  2. Ensure that the Advanced checkbox is checked, in the Agent type section.
  3. Select the AgentGroup agent type from the Type list box.
  4. Double click the name of the required agentgroup e.g. Datalog.
  5. Select the Bulk editing of agent type : XXX option (where XXX refers to this agent type).

Note: This option is ONLY enabled if this agentgroup has one or more agents in it of the SAME agent type.

  1. Click the OK button.
  1. Specify the name of this agentgroup in the putslot command (instead of the required agent name). For example, to start all the Datalog agents at once (by setting their start slot to 1), you can specify the following putslot command: putslot datalog.start,1
