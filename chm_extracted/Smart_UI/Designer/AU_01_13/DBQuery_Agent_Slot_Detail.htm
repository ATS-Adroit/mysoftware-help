DBQuery Agent Slot Detail

The DBQuery agent contains various slot categories. Select the options below to view more information on each category.

DBQuery Configuration slots

The following slots are used for configuration and are saved to the WGP file.

Slot name Slot type Slot description
connection VARSTRING The OLE DB connection string | “global” can be selected to use the Agent Server’s audit connection string.
customQuery VARSTRING An option for a valid SQL query statement to be performed on the database connection.
  • If a custom query is specified, this will always be executed instead of the built-in SELECT query statement.
disableOnStandby BOOLEAN When set to [1], the slot indicates that the transaction should not be executed on the standby server.
enable BOOLEAN When set to [1] the slot is enabled to Start or alternatively, when set to [0] to disable the agent.
interval INTEGER An optional number of seconds may be entered that will determine the execution interval of the transaction.
  • A value of [0] (default) disables this feature.
method INTEGER Sets a trigger tag check value. You can set method value to one of the following:

0 – Execute the query when the trigger tag value goes to zero.

1 – Execute the query when the trigger tag value leaves zero.

2 – Execute the query when the trigger tag value changes.

The default value is [1].
tableName STRING The name of the table that the built-in SELECT statement should use.
  • This is available only if the custom query is not used.
tagList LIST Sets the list of tag values to be retrieved by the built-in SELECT statement.
  • This is available only if the custom query is not used.
triggerTag TAGNAME The trigger tag to be used.
  • Indicates the trigger tag used in conjunction with the trigger method.
  • This is available for trigger methods only.
pulseWidth INTEGER Edit this slot to set the pulse length of the Status slot: SuccessPulse [StatusBit18].
  • The pulse length is set in milliseconds (ms).
  • A value of [0] will disable the pulse.
  • Note:  Any value less than 5 ms will always cause a minimum pulse width of around 5 ms.
  • The default value is [100] ms.
whereClause VARSTRING Sets the WHERE clause that will be applied to the built-in SELECT statement.
DBQuery Information slots

The following slots are used for information only and are NOT saved to the WGP file.

Slot name Slot type Slot description
badTransactions INTEGER A slot value that is incremented after every unsuccessful transaction and denotes the number of bad transactions since starting the agent server.
goodTransactions INTEGER A slot value that is incremented after every successful transaction and denotes the number of good transactions since starting the agent server.
lastDuration INTEGER A slot value that represents the duration of time in milliseconds that the query took to execute the last transaction.
lastError VARSTRING This slot captures the last OLE DB transaction error.
  • Successful transactions will display “None”.
lastErrorQuery VARSTRING This slot captures the SQL Query that caused the last OLE DB transaction error.
  • This value is never cleared and is only valid if the FAILED status bit (StatusBit21 ) is currently set to on [1].
lastQuery VARSTRING This slot captures the last SQL Query that was executed.
lastTime TIME This slot captures the last time a transaction was executed.
resetRunNow BOOLEAN When set to ‘1’ this slot will cause the agent to automatically reset the runNow slot value to ‘0’ after a transaction has completed.
  • The default value is set to enabled.
  • This should be disabled when the agent communicates the runNow slot value directly to the PLC.
runNow BOOLEAN When set to ‘1’ the agent will execute a transaction ONLY if the agent is enabled AND connected to the database.
totalTransactions INTEGER This slot tallies the total number of transactions executed since the agent server was last started.

 

DBQuery Runtime slots

The following slots are used for runtime operations and are NOT saved to the WGP file.

Slot name Slot type Slot description
catchupData RAWBYTES For internal use during real-time catch-up.
DBQuery Status slots

The following slots indicate the status of certain DBQuery agent functions.

Status name Status description

Connected

Also known as StatusBit16

 This slot is set to on [1], if the Agent is connected to the database as of the last transaction.
  • If the agent is not enabled, the slot will always be set off [0].
  • The slot will be also be set to off [0] should the agent become disconnected from the database. However, this slot will automatically be set on [1] if the agent is enabled and the agent is able to reconnect to the database.
  • Important:  It is important to note that some transactions may take up to one minute to transact, if there is a problem with the connection.

Disconnected

Also known as StatusBit17

 This slot is set to on [0], if the Agent is not connected to the database possibly due to a last transaction error or that the database is not available.
  • Note:  Be aware that if the agent is not enabled, this slot will always be set on [1].

Failed

Also known as StatusBit21

 This slot will be set on [1] if the last transaction failed.
  • Will be reset immediately prior to a transaction being executed.

FailPulse

Also known as StatusBit19

 A short pulse is generated on a transaction failure.
  • This slot will be set on [1] for a very short period (approximately 100 ms), if the last transaction failed.

Succeeded

Also known as StatusBit20

 This slot will be set on [1] if the last transaction succeeded.
  • Will be reset immediately prior to a transaction being executed.

SuccessPulse

Also known as StatusBit18

 A short pulse is generated on a successful transaction.
  • The default length of this pulse can configured using the pulseWidth configuration slot.
  • This slot will be set on [1] for a very short period (approximately 100 ms or as set in the pulseWidth slot), if the last transaction succeeded.
