Scheduling Commands and Utilities

Commands and utilities can be scheduled to run today, tomorrow, or on a particular day of the week or month at a specified time using the Scheduler.

Typical examples of its use would be executing a batch file, starting a backup procedure, printing a report, archiving a file, extracting logged data or doing a putslot operation.

The Scheduler utility also provides dialog boxes to assist in specifying the required details for the Adroit putslot, extract (datalogs) and merge (datalogs) operations. For details, see Specifying the Scheduled Command or Utility.

Tip: This utility provides extensive use of tooltips to provide context sensitive help. If unsure about the function of a checkbox or list box hold the mouse pointer over it until the tooltip is displayed.

To schedule a command or utility:

  1. Launch the Scheduler.
  2. Specify the command or utility that should be scheduled.
  3. Specify when this command or utility should be executed.
  4. Add these specified details to the list of scheduled entries (this also describes how to manage this list of scheduled entries).
  5. Write the details of this scheduled command or utility to the registry.

Note: Since this information is written to the registry, it is not necessary for the Scheduler to remain running in order to schedule the specified entries.
