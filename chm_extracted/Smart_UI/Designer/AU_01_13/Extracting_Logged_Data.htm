Extracting Logged Data

Adroit uses a data extraction facility called Extract which retrieves information from an AgentGroup consisting only of DataLog agents (see Grouping Agents Together), or from a single DataLog agent, for a specified time period.

Tip: To provide decimal resolution for real logged values that are retrieved using this Extract utility, use the ExtractFloatResolution registry value.

The data is then converted into a CSV (comma separated value) file format, which can be opened by a third, party application such as Microsoft Excel and formatted to create reports.

When using the Extract utility to transfer logged data from Adroit to an external system for further processing, you can reorder and/or remove some of the default CSV columns, as follows:

Use the command line parameter: -COL to define the required subset and/or ordering of these default columns in the CSV file.

Simply append the lowercase letters that represent each default columns to the end of this -COL command line parameter, in their required order.

The following lowercase letters: d, t, n, c, v, u, q represent the following respective default columns: Date, Time, (tag)Name, DesCription, Value, Units, Quality.

Usage example: -COLctv will produce an output CSV file that ONLY contains the Description, Time, Value columns in this order.

Note: The existing keywords -TERSE, -UCT, -UNIT still work as they did before.

The syntax of the command is as follows:

extract mc.as,ag[,start[,end[,intl[,csvfile]]]]

When this CSV file is generated, the first row indicates the headings of the columns i.e. date, time, agent.slot (agent description).

The other rows indicate the date, time, value and ‘quality flag’ for each of the values recorded in the datalog for this tag.

The quality flag, is ignored by the MERGE utility, and indicates how the value of this tagA fully qualified named value in Adroit (agentName.slotName). was generated, as follows:

  • (an empty field) = NORMAL_VALUE and/or INTERPOLATED_VALUE
  • "s" = POST_STARTUP_VALUE
  • "l" = LAST_KNOWN_VALUE
  • "*" = ESTIMATED_VALUE
  • "b" = BAD_VALUE
  • "?" = UNKNOWN_VALUE

Note: A column in the .CSV file also specifies the agent description(s) and the times also display milliseconds.

The start, end, period and interval parameters of the extract command can use the Date agent slot "asciiTime" to get a text string in the format required by extract. E.g. 1995-06-02:15:10:00 for start and end time, 8:00:00 for an 8 hour period, and 2:00 for a 2-minute interval.

The actual values could be scanned in from a PLC to the relevant Date agent slots (year, month, day, hour, minute, second) where they are combined into the ascii string in the "asciiTime" slot.

A Frame agent could then be used to store up to 32 different "asciiTime" values. For instance the following command, will extract the last 744 hours (31 days) from the groupname of datalogs "EXTRACT_GROUP", using the Date agent "DATA_MONTHLY", on the computer "USER", with the Agent Server name "agl":

extract USER.agl,EXTRACT_GROUP,744:0:0:0,0,0,DATA_MONTHLY.asciiTime

The latest file retrieved will be saved with the .CSV file extension, and the previous file will become the backup file, and saved as a .BAK.
