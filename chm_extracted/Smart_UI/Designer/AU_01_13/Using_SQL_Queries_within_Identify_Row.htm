Using SQL Queries within Identify Row

For each of the update, delete and retrieve transactions; a row in a table has to be identified, by entering the required identification text into the edit box of Identify row.

In most cases, specifying the cell in the required field can uniquely identify the row. The required identification text in Identify row for this case is:

FieldName = ‘CellInFieldName’

If more than one field is required to identify a row uniquely, then the row is identified using the "OR" or "AND" SQL keywords. The required identification text in Identify row for this case is:

FieldName = ‘CellInField1Name’ AND Field2Name = ‘CellInField2Name’ OR

Field3Name = ‘CellInField3Name’

In order to reduce the number of DbAccess Agents required to select each row in the selected table, it is possible to substitute the value of the cell in the field with a StringList agent.

This StringList agent will then hold various strings, so that a different row can be selected, by manipulating its index value. The required identification text in Identify row for this case is:

FieldName = <StringListAgent.value>

Note1: Ensure that the value of the tagA fully qualified named value in Adroit (agentName.slotName). matches the data type of the database field, for instance, this example assumes that the field of the database requires strings, but had this field accepted numbers, then a numerical value should have been used instead e.g. real, integer etc.

Note2: The identification text must comply with the WHERE clause of a SQL statement.

Note3: It is assumed that the user is familiar with the SQL querying language and is able to perform SQL queries unassisted.
