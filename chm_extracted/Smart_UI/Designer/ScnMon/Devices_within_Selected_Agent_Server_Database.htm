Devices within Selected Agent Server Database

The Scanning Monitor utility provides information on the scanning (communications) configuration for a particular Agent Server, so this information can be used to manually fine-tune the scanning subsystem to achieve optimal performance. For details, see Monitoring Scanning in Adroit.

The list at the top of this utility, displays a list of the devices, which have been used to scan tags within the current project (.WGP file or Agent Server database file) that is running on the Agent Server.

Therefore any device that is not used within the current database file will NOT be displayed even if it has been added and configured on the computer.

Note: Once an Agent Server has been connected to, reselecting the same Agent Server within the utility will refresh this list of devices. For details, see Connecting to the required Agent Server.

This list, consists of the following columns:

  1. Device name: This identifies the name of each device (Device agent) used to scan one or more tags within the currently connected Agent Server. The other columns indicate the started, healthy and running status for each listed device.
  2. Started: This is 1 when the device has started.

Note: It is also possible to start or stop a listed device, by right-clicking it and selecting Start device or Stop device from the displayed menu.

  1. Healthy: This is 1 when all scan jobs are healthy and there are not bad tags being scanned.
  2. Running: This is 1 when all scan jobs for the device have been started.
  3. Primary: This is 1 when the device is configured to use the Primary port.
  4. Secondary: This is 1 when the device is configured to use the Secondary port.

Supported commands:

When a device is right-clicked in this list, the following commands may be enabled:

  1. Start device: to start the selected device.
  2. Stop device: to slop the selected device.
