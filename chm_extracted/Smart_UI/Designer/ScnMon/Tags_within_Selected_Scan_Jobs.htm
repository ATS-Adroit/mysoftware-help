Tags within Selected Scan Jobs

The Scanning Monitor utility provides information on the scanning (communications) configuration for a particular Agent Server, so this information can be used to manually fine-tune the scanning subsystem to achieve optimal performance. For details, see Monitoring Scanning in Adroit.

The list at the bottom of this utility, displays the tags (scan points) grouped within the selected scan job or jobs within the scan job list, directly above this list. For details, see Scan Jobs within Selected Devices.

Note: Scan jobs are automatically created by Adroit to group the scanned tags together in such a way as to minimise scanning load and to maximise throughput. For details on how to assist with this process, see Scanning Optimization Tips.

This list, consists of the following columns:

  1. Tag: This identifies the name of tag (agent.slot) or scan point contained within the selected scan job(s) in the scan job list. The other columns indicate the following attributes of this scan point:
  2. Device address: This is the address of the front-end device to which or from which the value of this tag will be written or read. This address is device-specific.
  3. Job offset: This indicates the offset of the item within its scan job.
  4. Bit offset: This is a legacy value, which generally shows a value of zero.
  5. Deadband: This indicates the specified deadband value for the tag
  6. Output enabled: This is 1 when the tag is output enabled, which allows this tag to write new values to the front-end device.

Note: A value of Global!, indicates that the entire agent has been output enabled instead of just the slot that is being scanned.
This can cause a problem when more than one slot of the same agent is being scanned, for when ANY of the scanned slot values change, a write message will be sent to the scanning subsystem, which can lead to scan degradation.

  1. Scan inhibited: This is 1 when the tag is scan inhibited, which prevents the front-end device from changing the value of this tag. This is normally used in conjunction with 'output enabled' to configure a write only tag.

Note: A value of Global!, indicates that the entire agent has been scan inhibited instead of just the slot that is being scanned.
This can cause also lead to scan degradation when more than one slot of the same agent is being scanned. Scan bad: This is 1 when a problem has occurred with the scan point. In polled drivers, scan bad is generally true for all tags in the job and/or device. If so, check the configuration and cabling.

Supported commands:

When this list is right-clicked, the following option is displayed:

  1. Refresh: this will update ALL the lists with the latest scanning configuration.

Note: This can also be performed by pressing F5.
