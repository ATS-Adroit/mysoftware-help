Logging Agents

For an overview of logging values, see Logging Values.

 

The following agents are used to manage the logging of values and for other logging functionality:

  1. The DataLog agent is used to manage the logging of other tags (agent.slot) in Adroit.
  2. The DBLog agent is a bulk OLE DB logging agent for typically logging Analog and/or Digital values to a specific table in a database for later retrieval.
  3. The SystemDatalog agent it is responsible for:
  4. Performing datalog catch-up, in an Active Cluster.
  5. Global administers the datalog backup facility, enabling the long-term storage of datalogged data in multiple CSV files.

How to Log a Tag (agent.slot) : describes the procedure for logging process values in Adroit.
