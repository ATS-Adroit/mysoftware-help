Configuring Multiple Log Sets

Create a SEPARATE log set for ALL the different log settings required for the SAME tagA fully qualified named value in Adroit (agentName.slotName).. Therefore you need to configure ALL of the following settings for EACH log set:

  • Each log set must specify the following items:
    1. Destination: the location of the logs of this value as determined by the method you are log this value with i.e. proprietary Adroit log files:specify the full path and file name of the required log (.LGD) file or OLE DB-compliant database:specify the connection string to the required database.  
    2. Log Period: the required length or time period for logging this value e.g. 48 hours
    3. Log Interval: the time deadband for this logged value e.g. 1 second
    4. Compression method: the method used to determine the logged value, if using a log Interval i.e. actual, minimum, maximum or average.
    5. Value deadband: specify the MINIMUM amount which the value must EXCEED in order for it to be logged e.g. 0
    6. The Clear data at start option.
    7. The Interpolate option.
    8. The Double entries option.

     

  • The following items are global settings (for all sets of a DataLog agent):
    1. Start/Stop
    2. Logging mode i.e. continuous/demand/both
    3. Demand trigger tag
    4. Log now

     

  • The Datalog agent includes the following three read only set-specific slots:
    SlotTypeDescription

    CfgSet

    INTEGER

    This slot is for the sole use of the data log dialog to select the current set being configured.

    ClientSet

    INTEGER

    This slot is updated by the datalog agent to contain the set number from which the data was retrieved after a client data retrieval request.

    Sets

    INTEGER

    The total number of configured log sets.

    It is possible to view the ClientSet slot on a picture and verify that the trend retrieved its data from the correct set as illustrated in the above example.

    Each time the trend is positioned to each of the three history positions, the ClientSet slot should display the log set that was used for the last retrieve operation.
