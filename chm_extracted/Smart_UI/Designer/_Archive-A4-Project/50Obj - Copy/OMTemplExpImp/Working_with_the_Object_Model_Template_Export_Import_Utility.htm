Working with the Object Model Template Export Import Utility

The Object Model Template Export and Import utility allows you to export one or more of your existing Object Model Templates to a proprietary .TEF (Template Export File) file and also to import Object Model Templates from a .TEF file.

You can typically launch the Object Model Template Export and Import utility via the Adroit Utilities on the Desktop and then select this utility from this menu.

Export one or more of your existing Object Model Templates

For instance this allows you to easily move your Object Model Templates from one computer or Configuration to another or for backup purposes.

Note: Since these templates are obtained directly from your hard drive, you do NOT need the SmartUI Server to be running to do this.

Import Object Model Templates from a .TEF (Template Export File) file

IMPORTANT: You need to shut down your SmartUI Server first, before you can import templates.

Note: These templates will be imported into a unique folder, which also specifies the date and time of the import, so they will not overwrite existing templates.

Export one or more of your existing Object Model Templates

For instance this allows you to easily move your Object Model Templates from one computer or Configuration to another or for backup purposes.

  1. If necessary, click the Export tab.
  2. Click the Get Templates button, which obtains the list of both user and system templates directly from your hard drive, so you do NOT need the SmartUI Server to be running to do this.

Note: This only lists the Object Model Templates of the currently Active Configuration, which you can check via the Configuration page of your SmartUI Config Editor.

  • On the left hand side, the Templates tree, by default, selects all the available templates and their folder structure in the System and User folders .

Note: The icons of all the folders that contain templates that have configuration issues and the problematic templates themselves display a red cross to assist you in locating these problematic templates.

  • If you select a template then the Templates Details section appears on the right hand side, which displays a summary of its configuration and displays any detected errors.

Note: If you hover over the Template name then you can preview the Primary wizard.

  • On the right hand side, the Export Details, displays the Number of templates, that have been selected to be exported, as follows:
  • If one of the selected templates has a configuration issue, then the Number of templates displays this icon and specifies the number of Good (error-free templates) and Bad (templates with problems) templates that are currently selected for export.

Note: In this case you are UNABLE to specify a Description and export any templates until the problematic templates are unchecked or you close this utility and fix the issues before exporting them.

  • If all the selected templates are configured correctly, then the Number of templates displays this icon and then specify the Description for these exported templates, that is displayed when a user tries to import the exported templates, so provide a useful description.

Note: This Description is NOT displayed in the name of the exported .TEF (Template Export File) file.

  1. Click the Export button (once all the problematic templates have been unchecked).

Note: If you click the Export button and problematic templates are still selected then a message box is displayed that details the errors that have been encountered and the exporting process is prevented from occurring.

  1. When the exporting process is successful, this automatically creates the following unique file name: TEF [# templates] date time.tef, where # is the number of templates that are being exported, and data and time specify the date and time of the export.

By default this file will be saved in the same folder that the Object Model Template Export and Import utility is launched from, however you can select any folder that you want.

Import Object Model Templates from a .TEF (Template Export File) file

IMPORTANT: You need to shut down your SmartUI Server first, before you can import templates.

  1. If necessary, click the Import tab.
  2. Click the Browse for export file button and browse for the required .TEF file.
  • On the left hand side, the Template list contains the names of the templates within the selected export file.

Tip: You can view the source path of an exported template by hovering over its name in the list.

  • If you select an exported template then the Templates Details section appears on the right hand side, which displays a summary of its configuration and displays any detected warnings or errors.

Note: If you hover over the Template name then you can preview the Primary wizard.

By analysing the contained templates also allows you to determine that you are importing the required wizards.

  • On the right hand side, the Import details section displays:
  • the Number of templates contained within this export file and lists the import status of them, as follows:
  • Good: all is OK with importing these templates - for instance no configured elements already exists.
  • Warning: a non-critical issue has been found with importing these templates - for instance a configured element already exists, such as the primary wizard

Note: In the case of an existing configured element, this element will NOT be replaced!

  • Bad: when one of more of these templates cannot be correctly referenced within this export file, typically due to file corruption, then these templates CANNOT be imported at all.
  • the Description that provides the detailed description of these exported templates, so you can determine if you have selected the correct templates to import.
  • when an incompatible SmartUI Server version is detected, which PREVENTS these exported templates from being imported, then the Source and Destination Server section is displayed by default, otherwise you need to click the Show more button to view this information.
  1. Click the Import button and click Yes to the confirmation dialog that you are certain that these are the templates that you want to import .

Note1: These templates will be imported into your Active Configuration, which you can check via the Configuration page of your SmartUI Config Editor.

Note2: These templates will be imported into a unique folder, which also specifies the date and time of the import, so they will not overwrite any existing templates that have the same name.

At the end of this process the Import results are displayed, listing all the events pertaining to this importing process.

Note: Although you should not see any errors in these results but if you do: then you attempt to fix them and depending upon their severity, delete this import folder and attempt to reimport these templates.

  1. If necessary, click the Open the Templates folder in Windows Explorer button in the top right corner of the utility to view the folder of these newly imported templates, which uses this name format:

    IMPORT_# templates_date_time.tef, where # is the number of templates that are being exported, and data and time specify the date and time of the import.
