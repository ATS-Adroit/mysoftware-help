Working with the SmartUI Launcher

Although the Launcher does not perform any client or server functionality, itself, it can install the SmartUI Operator remotely (either over a LAN or the Internet) and / or ensure that this component remains up to date with the latest files, if required.

Tip: For a detailed step-by-step procedure of connecting Operators to a Server over the Internet, see How to Connect to the Server over the Web.

The SmartUI Launcher connects to a pre-configured distribution computer over a LAN or the Internet and synchronises the contents of its installation folder with a specific folder on the distribution computer. Click for more details:

For details on connecting to a pre-configured distribution computer, see Connecting to the distribution computer.

This "distribution" computer is simply a computer that has the VIP Distributor service installed and running. This service specifies the required "distribution" folder that a Launcher application can connect to and synchronise its contents with, which is typically the C:\Program Files\Adroit Technologies\Adroit\SmartUI\Distribution folder of the SmartUIServer computer.

For further details of the procedure whereby contents of the Launcher's installation folder are synchronised with a specific folder on the distribution computer:

In other words, once the SmartUILauncher has connected to the specified distribution computer, the files and sub-folders within its installation folder are compared to those in the specified distribution folder.

Only the file(s) and folder(s) which are newer on this remote computer or which do not exist on the local computer will be displayed for downloading.

Any executables that are downloaded from the distribution computer can then be run or launched from this application, if necessary, hence the name of this application.

Therefore the files placed in the user-configurable distribution folder on the distribution computer, will be the files that are distributed whenever a Launcher is connected to it.

Tip: The Welcome section of the Config Editor provides a Setting up the Launcher page to specify the settings required to connect to the distribution computer. For details, see Setting up the Launcher.

Note: If the distribution computer uses firewall software ensure that the Distributor service has access to the necessary communication port. For details, see Firewall configuration.

To run the Launcher: 

  1. Either double-click the Launcher shortcut that is placed on the Desktop
  2. Or click the Start menu, Programs, VIP Launcher and the SmartUILauncher item.

WARNING! When the required files are downloaded they are currently not streamed and so if the connection is slow or breaks the application will not respond until after a timeout, which could take up to 30 seconds.

Note1: The Launcher can only connect to a computer that has the Distributor service installed, which specifies the required folder that will be distributed.

Note2: Newer files located in sub-folders can be optionally downloaded, however, newer files located in the root directory will always be copied.

Command-line options when running the Launcher:

  1. To create a log file, execute the Launcher with the "log" parameter in its command-line.
  2. To automatically execute a downloaded executable after the Launcher has finished processing, add the name of this executable (its extension is not required) as its command-line parameter e.g. add Operator to launch the Operator.

Note: These command-line options can be added permanently, by simply editing the shortcut used to launch the SmartUI Launcher and adding the required command-line parameter to the Target field.

The VIP Distributor service is installed with the SmartUI Server installation and the “Distribution” sub-folder contains the files required for the Operator. For this reason the Operator can be downloaded from a SmartUI Server by using the Launcher.

Note: As the SmartUILauncher is downloading the Operator, ensure that the computer complies with its software and hardware requirements. For details, see System requirements for the Operator. Also ensure that the necessary configuration is performed before the Operator is launched. For details, see Configuration after installation.

Note: If necessary, an entirely different folder can be specified by manually editing the path specified by the RedistPath setting. For details on accessing this setting, see Advanced Distributor service settings.
