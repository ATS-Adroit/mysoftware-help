Installing the SmartUI Launcher

You typically only install the SmartUI Launcher application to download the files required for the Operator, either over a LAN or the Internet.  For details on using this application, see Working with the SmartUI Launcher.

By default, this installation does not require the user to have Administrative rights.

WARNING! This installation does NOT install the files required for the SmartUIOperator itself.

Note1:Ensure that the computer complies with the software and hardware requirements for the Operator. For details, see System requirements for the SmartUI Operator.

Note2:The SmartUILauncher application does not require any further configuration once it has been installed.

Note3:When uninstalling this application, any files and folders that have been downloaded into its installation folder must be removed manually.

To install the Launcher:

Note: Ensure that the necessary .NET framework has been installed on this computer.

  1. Close all programs.
  2. Open the required web browsing application and type in the required address that specifies the SmartUI Web Service of the required Server. For details, see Installing the SmartUI Web Service.

If supported, this displays the default web page that provides a link to download the

Launcher installation file.

  1. Download the specified file and then execute this file on your computer.

Note: If the .NET framework is NOT installed on this computer, the installation will fail although it does provide a link from which this can be downloaded from the Internet and installed.

  1. Follow the instructions on the screen to complete the installation.

Note: It is not necessary to restart the computer after this installation.

  1. By default:
  1. The programs are installed in the SmartUI Launcher installation folder, which is typically: C:\Program Files\Adroit Technologies\VIP Launcher.
  2. The program can be launched from the Launcher shortcut that is placed on the Desktop by the installation or from within the SmartUILauncher program group, which is: VIP Launcher. For details on using this application to obtain the Operator application, see Working with the SmartUILauncher.
