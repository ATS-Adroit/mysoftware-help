Installing the SmartUI Server and Clients

This is the full SmartUI installation that installs the Server along with the Designer and Operator components on the computer.

This installation will also install and configure the Distributor service, so that the Operator can also be remotely installed on a computer by means of the Launcher. For details, see Working with the Launcher.

Note1:It is possible use the SmartUI Server freely, with four Client connections, for an evaluation period of 14 days, after which you need to either apply for a demo or commercial license. For more information on licensing the SmartUI Server, see Licensing the Server.

Note2:The SmartUI Server can be licensed by a HASP software protection key, a software license, an Adroit license or a demo license. For details of these licensing methods and their respective advantages, see Available licensing methods.

Note3:Before beginning this installation, ensure that the computer complies with the software and hardware requirements for the Server. For details, see System requirements for the Server.

Note4:Once these applications have been installed, ensure that they are satisfactorily configured before they are launched. For details, see Configuration after installation.

If the SmartUIServer is installed and licensed, each SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. can connect to it over the LAN, however, the SmartUIWeb service must also be installed in order for Clients to connect over the Internet. For details, see Installing the SmartUI Web Service.

Note: The number of Clients that can connect to a Server are dependent upon the operating system of the Server computer and its licensing.
