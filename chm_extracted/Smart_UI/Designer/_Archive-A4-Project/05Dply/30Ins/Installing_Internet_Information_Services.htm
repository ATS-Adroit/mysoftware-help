Installing Internet Information Services

The SmartUI Web Service and Click Once requires Microsoft Internet Information Services (IIS) to be installed. For details, see Installing the SmartUI Web Service or Working with Click Once.

When using a Windows desktop operating systems, such as Windows 7, it may be necessary to install IIS as it is not part of the default installation. However, when using a Server operating system IIS is installed by default.

To install IIS on Windows 7:

IMPORTANT: Simply selecting IIS is NOT enough on Windows 7 - you need to manually check ALL the ALL of the sub-components of its Application Development Features component.

Note: Ensure that the Windows system files are located in the same location as when the operating system was installed, for instance, if having installed from the local drive ensure that the Windows installation media is in this drive.

  1. Select the Start menu, Control Panel and Programs and Features item.
  1. Select the Turn Windows features on or off link, on the left side of this applet.

This will display the Windows Features dialog.

  1. Click the checkbox to the left of the Internet Information Services component.

    This only selects some of its components by default - indicated by a filled checkbox.

  2. Double click the Internet Information Services component to expand its options.
  3. Expand the World Wide Web Services option.
  4. Expand its Application Development Features option.
  5. Ensure that there is a tick box next to ALL of the sub-components of this Application Development Features component.

Tip: Once all the sub-components are ticked, a tick appears next to the Application Development Features component.

Example

  1. Click the OK button to install this component.
  2. Close the open dialog boxes.

To install IIS on Windows XP:

Note: Ensure that the Windows system files are located in the same location as when the operating system was installed, for instance, if having installed from the local drive ensure that the Windows installation media is in this drive.

  1. Select the Start menu, Settings, Control Panel and Add or Remove Programs item.

This will display the Add or Remove Programs applet.

  1. Select the Add or Remove Windows Components button, on the left side of this applet.

This will display the Windows Components Wizard dialog.

  1. In the Windows Components Wizard dialog, scroll down until the Internet Information Service (IIS) component is visible.
  2. Click the tick box next to the Internet Information Service (IIS) component.

Note: Ensure that there is a tick in this tick box.

Example

  1. Click the Next button to install this component.
  2. Click the Finish button to close the Windows Components Wizard dialog and also close the Add or Remove Programs applet.
