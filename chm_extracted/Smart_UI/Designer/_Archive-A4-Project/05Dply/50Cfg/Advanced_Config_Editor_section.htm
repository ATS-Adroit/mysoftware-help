Advanced Config section

The Advanced section of the Adroit Config Editor configuration dialog is intended to allow the more advanced user to configure all the settings of the applications and/or services, some of the more common ones are:

  1. Designer: displays the settings for the SmartUI Designer.
  2. Distribution: displays the settings for the SmartUI Distributor service, which typically runs on a SmartUI Server computer.
  3. Operator: displays the settings for the SmartUI Operator.
  4. Service: displays the settings for the SmartUI Server when it is being run as a service within Windows. 
  5. Server: displays the settings for the SmartUI Server when it is being run as an application.

To display the Advanced section:

Launch the Adroit Config Editor.

Select the Advanced heading in the tree view pane on the left. For details on navigating within configuration dialogs, see Working with configuration dialogs.

Note1: The number of options displayed by this section depends on which of these components have been installed.

Note2: These pages provide limited features that assist with the display and configuration of their settings. For details, see Advanced settings page features.

Tip: The Welcome section makes it easier to configure the essential application settings. For details, see the Welcome section.

To navigate within this Advanced section:

  • Either one can simply click on the required option, to display a list of all the settings for this component.
  • Or, since the Adroit Config Editor is a configuration dialog, this section also provides the standard navigation and layout features that are common to all configuration dialogs. For details, see Working with configuration dialogs.
