Operator connection settings

This page of the Setting up the Operator component of the Adroit Config Editor configuration dialog, provides the following settings that specify the default data connection that is established between this SmartUI Operator and the specified SmartUI Server at login:

To display this page of settings:

When the SmartUI Operator is launched, it needs to log into a SmartUI Server computer, which stores the data configured within the SmartUI Operator.

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Operator option.

Note: If this option does not appear then the SmartUI Operator may not be installed.

  1. Select the Connection Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Login Server: this specifies the default SmartUI Server computer that this SmartUI Operator connects to during the login process.

Note: ONLY the user profiles configured on this specified SmartUI Server can be applied to the users of this SmartUI Operator.

To specify the login Server computer name: If necessary, type the required name into the provided edit box.

Note: Please ensure that the name of this computer is correctly spelt; otherwise the login process will not succeed.

The following are typical login errors that occur when this name is incorrectly specified:

  • “Requested service not found” -> The Server has not completed loading yet
  • “No connection could be made because the target machine actively refused it” -> There is no running server

Data communication method: select the required method that data is transferred within the established connection between this SmartUI Server and SmartUI Operator.

To specify the required communication method: Select the required option.

The optimal method depends upon the network (bandwidth) connecting this SmartUI Server and SmartUI Operator, as follows:

  1. Subscribe: recommended when using a Local Area Network as this provides the fastest response time by requiring the highest bandwidth.
  1. Poll(send all values): recommended when using a high bandwidth Internet connection.
  2. Poll(send most recent values): recommended when using a low bandwidth Internet connection.

For further details concerning these methods, see About connection communication methods. 

The bandwidth requirements for this connection depends upon a number of factors, such as the update requirements and the size of the graphic forms.

However, you can ensure that the selected communication method provides sufficient bandwidth for the needs of your project, by adopting the following recommendations:

  1. Keep the graphic form sizes small; for example use JPG files instead of BMP files.
  2. Plan the graphic forms beforehand with the end-user in mind, including the bandwidth that will be available. 
  3. Develop an end-to-end prototype to test in a production environment in order to satisfy all requirements (including the communication requirements). 
  4. Only once this prototype has been successfully tested should the project be completely engineered.

Connection status check frequency: specify how often the SmartUI Operator should test that the SmartUI Server connection is still healthy and is not disconnected.

To specify the required interval between checking the connection, in seconds: Either type in the required value directly or use the arrows of this spin control to obtain the required value.

Tip:There is little reason to change this default value, as this connection monitoring process only consumes a small amount of bandwidth and CPU usage.

 

This page only configures the part of the essential SmartUI Operator settings. For details, see Setting up the Operator.

For details on displaying all the related SmartUI Operator settings, see the Advanced Operator settings page.
