Driver Configuration

This page of the Agent Server Configuration component of the Adroit Config Editor configuration dialog, allows you to manage your protocol drivers and their devices.

In other words, this allows you to install the necessary protocol drivers and add, configure and remove their devices, so that the necessary scanning configuration can be performed in Adroit.

To display this page of settings:

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Agent Server Configuration option.

Note: If this option does not appear then Adroit may not be installed.

  1. Select the Driver Configuration option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Note: On opening this page any configured protocol drivers and their devices are loaded, any protocol drivers that are unable to be loaded will display a warning.

This dialog allows you to manage your protocol drivers and their devices via the Installed Drivers and Devices list, as follows:

Install a Protocol Driver

Display Protocol Driver Documentation

To select an installed protocol driver: click on the name of the required protocol driver () in the list.

Installed protocol driver details: the attributes displayed in the information pane at the top right corner when an installed protocol driver () or its device () is selected.

  • Description: The literal name of the installed protocol driver.
  • File Name: The full path and name of the DLL file used by this installed protocol driver.

  • File Version: The Adroit version of this installed protocol driver.

    Note: The last number of this File Version: specifies the current revision of this installed protocol driver.

  • Devices: The number of devices configured for this driver.

Adding and Configuring a Device

To select a configured device: if necessary, click on the collapsed icon: to the right of required installed protocol driver () icon and click on the name of the required configured device () in the list.

 

Device details: the attributes displayed in the information pane at the top right corner when a device () of an installed protocol driver () is selected.

  1. Status: This indicates the status of the device itself and will either be: not loaded, no Agent Server connection, stopped or started.
  2. Healthy: This indicates status of the communications or scan-tasks assigned to this device, as follows:
  3. healthy, indicates that all of its all of its scan-tasks have started successfully.
  4. not healthy, indicates that either the selected device has stopped or a problem has occurred when starting this device or there may be a license/HASP problem (to test, run the Agent Server in demo mode). For details, see Limited Time License HASP.
  1. I/O Count: This specifies the number of I/O points that have been scanned using this device; this number excludes any 'at' or @ scanned items.

Click the Refresh Driver List button to refresh the status of the devices of the installed drivers.
