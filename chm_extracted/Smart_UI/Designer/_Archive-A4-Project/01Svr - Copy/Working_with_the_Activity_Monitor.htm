Working with the Activity Monitor

The Activity Monitor is available when the SmartUI Server runs an application.

Tip: It is recommended to run the SmartUI Server as an application, during the initial designing phase, to make use of the diagnostic features provided by the Activity Monitor.

Then once the configuration is over to run it as a service, if necessary, which will ensure that it will not shutdown when you log off.

Note: The System Information datasource of the SmartUI Server, extends the troubleshooting functionality provided by the Activity monitor. For details, see System Information.

To run the Server as an application:

Click the Start menu, Programs, Adroit 10 and the SmartUI Server item.

This can be used to display the operational status of the SmartUI Server and also provides a number of SmartUI Server-specific features.

Open the Activity Monitor
  1. Launch the Server as an application by clicking the Start menu, Programs, Adroit 10, and the SmartUI Server item.
    • Click the Launch Activity Monitor to open the Activity Monitor.
  1. Note:  The Activity Monitor is only displayed if the ActivityMonitorFormEnabled setting for this Server is enabled. For more information on this setting, see Advanced Server settings.

    The ActivityMonitorFormTitle setting specifies the title of this application.  
  1. Warning:  The Server window is not displayed if the SmartUI Server is running as a service.
  1. If the server is already running, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  • Tip:  When the SmartUI Server is running as an application, you may also press the ALT+TAB KEYS repeatedly until the task switcher displays the Server window, then select Launch Activity Monitor.
  1. If the server is already running as a service, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  2. The Activity Monitor opens and displays information on the Local Machine tab.

 

The Activity Monitor window consists of the following features:

The Tasks panel on the left of the window, which provides the following functions that can be performed by the Server, simply by clicking on the provided links:

Note: This Tasks panel also displays the operational status of the Server below these function links.

  1. Display Server Events: This can be used to troubleshoot the setting up and licensing the Server and establishing the required security, profiles, datasources and projects.
  2. Clear Server Events: This will remove the old and existing events and can be used to pinpoint a current problem by only displaying the most current events.

WARNING! This will immediately remove all the events from the Server's event log, without displaying a confirmation dialog first.

  1. Display Licence Information: This indicates how the Server is currently being licensed.
  2. Save Server Data: This will manually save the Server and its data and is required if the Server is not being saved automatically on shut down.
  3. Disconnected All Users: This can be used to free up Client connection licenses when it is not possible or inconvenient to visit each Client to disconnect them individually.
  4. Force Memory Cleanup: Typically this option should not be needed, as it is only used for advanced diagnostic purposes.
  5. Shutdown Server: This is the same as pressing the close button in the title bar and will display a confirmation dialog, which if accepted will close the Activity Monitor and terminate the Server.
  6. Restart Server: This will first shut the Server down and then start it up again.

  7. Restart With Rollback: This will first shut the Server down and then start it up again using the previous saved state (the previous data files).

    IMPORTANT: There is no guarantee as to the stability of this previous saved state.

 

For details on running the Server as an application or service, see Launching the Server.
