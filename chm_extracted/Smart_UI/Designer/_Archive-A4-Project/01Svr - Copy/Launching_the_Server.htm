Launching the SmartUI Server

After installing the SmartUI Server, it can either be run as:

Note: Ensure that this SmartUI Server has been licensed; otherwise the Server will not run as an application or service. For more information on licensing the SmartUI Server, see Licensing the Server.

  • An application, in which case the Activity Monitor provides additional Server-related functionality. For details, see Working with the Activity Monitor.

    To run the Server as an application:

    Click the Start menu, Programs, Adroit 10 and the SmartUI Server item.

  • A service within Windows, in which case the Service Manager can manage (start/stop) this service. For details, see Working with the SmartUI Service Manager.

    To run the Server as a service:

    Typically use the SmartUI Service Manager to start and/or stop this service, which can be launched as follows:

    Click the Start menu, Programs, Adroit 10 and the SmartUI Service Manager item.

    To manually start/stop and/or configure the VIP Server service:

    Open the Services applet, as follows: click the Start menu, Control Panel, Administrative Tools and the Services item.

    Locate the VIP Server entry in the list.

    Right-click this item and select Start/ Stop.

    Tip: Select Properties…to configure this service to your liking within the Services environment i.e. to determine the Startup type or the Log on account that should be used for this service.

Note1:The SmartUI Server, despite its method of launching, is able to log events for diagnostic purposes. For details, see Diagnosing the Server.

Note2:The SmartUI Server is installed into the SmartUI installation, typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI.

Tip: It is recommended to run the SmartUI Server as an application, during the initial designing phase, to make use of the diagnostic features provided by the Activity Monitor.

Then once the configuration is over to run it as a service, if necessary, which will ensure that it will not shutdown when you log off.
