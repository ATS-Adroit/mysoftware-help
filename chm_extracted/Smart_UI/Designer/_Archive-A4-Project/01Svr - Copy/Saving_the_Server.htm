Saving the SmartUI Server

The SmartUIServer is a "data portal" which exposes data from a number of disparate sources that are both external and internal to it.

Save the Server for the following reasons:

  1. To save all the datasources connected to it.

Note1: Each datasource specifies which of its items are required to be saved.

Note2: The SmartUIServer saves the complete datasource, including any Server configuration options, which have been performed via the SmartUI Designer.

  1. To save any changes that have been made to internal sources of data, which consist of Client-specific data that is managed by the Server. This includes the security and profile configuration and any projects that have been created.

Note1: For details on where these and any other data files that are saved by SmartUI can be located, see Locating saved data.

Note2: For details on how to automate backing up the Server data, see Backing up Server data.

Methods of saving the Server’s data:

  1. Automatically: Typically the SmartUI Server will be automatically saved when it is closed (or when the service is stopped), however this can increase the time taken for the Server to shutdown. This automatic saving can either be enabled or disabled by configuring the SaveServerOnShutdown Server setting. For details on accessing this setting, see Advanced Server settings.

Note: It is usually NOT recommended to disable this automatic saving when the Server is running as a service. For details, see Launching the SmartUI Server.

In addition the SmartUI Server is also able to save its data continually, according to a user-configurable frequency, which by default saves this data every 2 hours. For details, see Server saving settings.

  1. Manually: You can save the SmartUI Server manually, from within the SmartUI Designer, which configures the SmartUI Server, as follows:

    1. Open the Enterprise Manager. For details, see Accessing tool windows.
    2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
    1. Right-click the name or icon of the required Server connection and select Save Server Data.

    In addition to making remote configuration of the SmartUI Server possible, this also allows the SmartUI Server to be configured when it is being run as a service.

It is also possible to save the SmartUI Server manually when it is run as an application, as follows:

Open the Activity Monitor
  1. Launch the Server as an application by clicking the Start menu, Programs, Adroit 10, and the SmartUI Server item.
    • Click the Launch Activity Monitor to open the Activity Monitor.
  1. Note:  The Activity Monitor is only displayed if the ActivityMonitorFormEnabled setting for this Server is enabled. For more information on this setting, see Advanced Server settings.

    The ActivityMonitorFormTitle setting specifies the title of this application.  
  1. Warning:  The Server window is not displayed if the SmartUI Server is running as a service.
  1. If the server is already running, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  • Tip:  When the SmartUI Server is running as an application, you may also press the ALT+TAB KEYS repeatedly until the task switcher displays the Server window, then select Launch Activity Monitor.
  1. If the server is already running as a service, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  2. The Activity Monitor opens and displays information on the Local Machine tab.
