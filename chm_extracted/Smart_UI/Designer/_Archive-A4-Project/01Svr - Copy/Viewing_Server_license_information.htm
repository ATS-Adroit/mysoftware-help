Viewing SmartUI Server license information

The only component of the SmartUI that requires a licence is the Server, all the other applications, such as the Designer, Operator, Launcher and Distribution service do not.

To view the current Server license information:

To open the License Information dialog from the Activity Monitor: this is displayed when the Server is running as an application.

Open the Activity Monitor
  1. Launch the Server as an application by clicking the Start menu, Programs, Adroit 10, and the SmartUI Server item.
    • Click the Launch Activity Monitor to open the Activity Monitor.
  1. Note:  The Activity Monitor is only displayed if the ActivityMonitorFormEnabled setting for this Server is enabled. For more information on this setting, see Advanced Server settings.

    The ActivityMonitorFormTitle setting specifies the title of this application.  
  1. Warning:  The Server window is not displayed if the SmartUI Server is running as a service.
  1. If the server is already running, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  • Tip:  When the SmartUI Server is running as an application, you may also press the ALT+TAB KEYS repeatedly until the task switcher displays the Server window, then select Launch Activity Monitor.
  1. If the server is already running as a service, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  2. The Activity Monitor opens and displays information on the Local Machine tab.

 

Click the Display Licence Information link from the Tasks panel.

To open the License Information dialog from the Service Manager: this is displayed when the Server is running as a service.

  1. If necessary, launch the Service Manager, by clicking the Start menu, Programs, Adroit 10 and the SmartUI Service Manager item.

    2. This displays a tray icon in the tray bar, located in the bottom right corner of the screen.

  2. Right click the tray icon in the tray bar and select the Licence Information menu item.
 

The License Information dialog is displayed, which provides a summary of the most important licensing details.

Note: This Licence Information window remains open until you click the Close button at the top right of this dialog.

 

For more information on licensing the SmartUI Server, see Licensing the Server.
