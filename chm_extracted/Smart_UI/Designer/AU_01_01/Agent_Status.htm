Agent Status

The overall status of an agent can be determined from its status slot, which is a header or generic slot and so is common to all agent types, and shows the status as determined by the status of the individual slot, for instance if one of the agent slots is scan bad, then the agent status slot will show scan bad.

In contrast, the statusRaw header slot the agent shows the status of the agent, without any regard for the status of the individual slots. For instance, if one of the agent slots is scan bad, the agent status slot will not necessarily show scan bad unless the agent itself has been marked as scan bad. For details on the structure of data in an agent, see Data Structure of an Agent.

This status slot is a 32 bit word containing configuration and run-time status information about the agent. Each bit of this 32 bit word is also exposed as a slot, allowing up to 32 status flags to be accessed at any time.

Note1: In addition to this overall agent status word, there is also a status word for each slot of an agent, which can provide better monitoring and control of the agent. For details, see Slot Status Words.

Note2:The first bit in the status word, statusBad, is the only bit an application needs to monitor to determine the integrity of an agent or slot. For details, see Agent or Slot Integrity Monitoring (Bad Handling).

Note3: These bits can be viewed and/or set via the Agent Header configuration dialog. For details, see Editing the Header of an Agent.

This status slot is divided into two portions:

  1. The first 16 bits (0 to 15) are known as the Common Status bits as they are common across all agent types, each having a fixed purpose.

Their equivalent slots each have unique slotname, which follows the naming convention of statusXxxxxxXxxxxx. e.g. statusScanBad.

These status bits are further classified into control, condition and configuration bits. For details, see Common Status bits.

  1. The second 16 bits (16 to 31) are known as the Specific Status bits and they are agent type-specific.

Their equivalent slots are called statusBit16 up to statusBit31. For details of these slots, see the Agent Types and their Slots Reference.

For instance an Analog agent uses the first type-specific bit to indicate a Low Alarm condition, whereas an Expression agent uses this bit to indicate a result value Equal to Zero.

Write access is restricted to the control bits (agentStatusBitxx), where xx is: 01,02,03,05,08,09, or 11.
