What you can do with agents

Adroit is a SCADASupervisory Control And Data Acquisition, used to monitor and control an industrial plant or process and its related equipment. product and as such is primarily concerned with process values, since these are essentially used to supervise and control processes.

Like all programs, Adroit has its own terminology or jargon and in this case its jargon applies to how it refers to these process values. For details, see Agents, Slots, Tags and their relation to Values.

Adroit is built on a client-server architecture, where the server or Agent Server, is the database that contains the values and the client or User Interface (that is only one of many possible clients) provides the capability of configuring, displaying and manipulating the values. For further details, see About Agent Servers.

Adroit provides the following process value (agent-specific) operations:

  • Create the necessary agents to both store your process variables and perform more advanced calculations and manipulations of this data. For details, see About Agents or Adding Agents.

Note: For details about which agent types are in the default agent groups, see About Agent Types.

  • Communication of process values, this is the primary function of any SCADA, in that it allows you to bring in values from your process, via front-end devices in the field. This allows the process to be supervised, by reading the values and controlled, by writing them back to the field. For details, see Communicating Values.
  • Alarming of values, when values transgress configurable operational limits, an alarm can be created to notify the operator or engineer of this transgression using a variety of methods. For details, see Alarming Values.
  • Logging or recording of values, this allows the values of the process to be saved to proprietary historical files and/or to databases, so that they can be retrieved for long term analysis and reporting purposes. For details, see How to effectively log your data.
