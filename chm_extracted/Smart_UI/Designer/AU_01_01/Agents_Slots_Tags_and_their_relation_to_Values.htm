Agents, Slots, Tags and their relation to Values

Agents are the fundamental building blocks of Adroit. They are called agents because, in addition to containing data, like simple database records, they also usually contain the ability to operate or act on their own data. For further details, see About Agents.

Note: In Adroit, the data or values contained within agents are called slots. For further details, see About Agent Data.

Therefore the following method is used when referring to values within Adroit: agentName.slotName, which specifies both the name of the value and its associated agent.

Note: In Adroit, this fully qualified named value (or agentName.slotName reference) is known as a tag.

For example, a tag containing the value of the rawValue slot of an Analog agent called ANA1, would be written as: ANA1.rawValue
