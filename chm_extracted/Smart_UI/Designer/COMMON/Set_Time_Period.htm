Set Time Period

The Set Time Period is a generic dialog box that is used to specify time ranges.

 

Under Period Type, one or more of the following options may be available:

  • Start + Interval displays a period from a fixed start time forward in time at a specified interval.
  • End - Interval displays a period from a fixed end time backwards in time at a specified interval.
  • Start to End displays a period from a fixed start time to a fixed end time with a specified interval, and can be used to filter out alarms.
  • Current - Interval displays a real time period with the specified interval.

Note: If used for a trend, Adroit will attempt to fetch historical trend data if it exists to fill in the trend window.

  • Datum +/- Interval - displays a period from a fixed datum forwards or backwards in time at a specified interval.
  • Datum - Interval - displays a period from a fixed datum backwards in time at a specified interval.
  • Interval - for DataLog agent Length and Time configuration.
  • Time - for EventOutput agent Time Printing setting.

 

Under Period Details, one or more of the following options may be available:

For the Start and End, Date and Time fields, click in the appropriate field, and select the required date and time digits.
