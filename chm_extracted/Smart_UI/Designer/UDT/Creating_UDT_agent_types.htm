Creating UDT Agent Types

The UDT Agent Type Designer creates separate Adroit agent types for each UDT (complex data type) that you require. Duplicate the EXACT structure of each UDT by adding properties (basic data types) and, if necessary, configure status slots for the purposes of alarming. 

IMPORTANT: UDT agent types must exist on all Adroit computers that require access to the UDT agents from the Configurator. Once you have created one or more UDT agent types, you can import them to other computers. For details, see Importing UDT Agent Types.

PLEASE NOTE: Every instance (agent created) of an UDT agent type will consume (number of slots-1) scan points. The other scan point will be consumed if and when its rawValue slot is scanned.

Note: You can only create UDTs that are composed of data types that can be represented by Boolean, Integer, Real, Datetime, String (80 characters or less) and VarString values. Array data types are NOT supported.

To create a new UDT agent type

  1. Press the Windows key and start typing in UDT Agent Type Designer and select it from the list.

The UDT Agent Type Designer utility is displayed.

  1. Click the Add new UDT agent type... button in the UDT Agent Types section.
  2. Specify the required name for this UDT agent type in the Create new UDT type dialog.

Tip: Use a short yet suitably descriptive name as this name appears in the list of agent types in Adroit.

Note : Once you have added a name you CANNOT rename it later.

  1. Click the OK button.

Specifying the Properties for your UDT

  1. Specify the first property (component data type) of this UDT in the Add new UDT property dialog.

Note: A property of a UDT is equivalent to a slot of an agent.

  1. Type in the required name of this data type.

Note: If necessary, you CAN rename a property later, by selecting the required property and clicking the Rename selected UDT property... button.

WARNING! Renaming properties invalidate any configurations using the older slot (property) name.

  1. Click the OK button.
  2. Open the Type list box and specify the required data type for this property.

Tip:Ensure that the Selected UDT Properties section indicates the correct basic Adroit data types to represent this property.

Note: If you cannot find the required data type then contact support so that we can add it for you.

  1. Only clear the Readonly checkbox, if you want to prevent the user from editing the value of this property in the agent edit dialog.
  2. Only clear the Public checkbox,  if you want to hide this property from the agent edit dialog.
  1. Click the Add new UDT property... button in the Selected UDT - Properties section and repeat steps 5 to 10 for each of the component data types within this UDT.

Note: Please ensure that you add these data types in the EXACT order as they appear in the UDT of the PLC.

If necessary, edit the property descriptions.

The UDT Agent Type Designer dialog increments the Scan size of the resultant UDT after each property is added or modified.

Specifying the Status Bits for your UDT

In the Selected UDT - Status Bit section:

  1. Select the required status bit/s from the Status bits list, do the following for each, as required:
  1. Rename this status bit, by typing in the required name in the Status bit name edit field - you can use a maximum of 18 characters for this name.

Note1: The “Status bit xx” naming convention is ONLY used for display purposes in this dialog. Therefore any status bit that is NOT renamed will not be added as a status bit name within the UDT agent instances.

Note2: If a customised status bit name is cleared, the “Status bit xx” naming convention will be re-applied.

  1. Specify the required expression to calculate the value of this status bit, in the Status bit expression edit field, which define the state of this UDT that needs to be alarmed. For details, see Creating UDT Status Bit Expressions.

Therefore the expected expression result should be True (1) or False (0), Examples of such expressions are:

  • Slot(value) > 95
  • Slot(Open) & (Slot(value) > 95)

The following expression language used for this feature is exactly the same as the expression language used in conditional alarming.

  1. If necessary, configure another UDT agent by repeating steps 2 to 12.

IMPORTANT: Ensure that the Agent Server is stopped.

  1. Click the Close button of the UDT Agent Type Designer to save the UDT configuration to the registry and create the udt.reg file. Click for more details:

    The udt.reg file is in the created in the Data subfolder of the designated project folder, which is typically C:\ProgramData\Adroit Technologies\Adroit\Configurations\Default\Data. This file can be copied to remote computers then simply open this utility and click the Import button to import it.

Note: If you are using an Adroit cluster ensure that you import your UDT configuration into the UDT Agent Type Designer of the cluster partner.

Your UDT agent type DLLs are created EVERY time the Agent Server is started. Click for more details:

These DLLs are created in the Adroit installation folder, typically C:\Program Files\Adroit Technologies\Adroit and adhere to the following naming convention: t_TypeName.dll, where TypeName is the name you specified.
