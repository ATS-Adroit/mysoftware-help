Configuration after installation

Once installed, some or all of the following configuration items may be required depending upon which application has been installed and how the system itself has been setup.

Note: It is possible use the SmartUI Server freely, with a Designer and an Operator connections for 2 hours, after which the Server must be restarted. For more information on licensing the SmartUI Server, see Licensing the Server.

  • Multiple network cards: If your SmartUI Server computer has multiple network cards then you can specify which one the Server will use to communicate to each Clientrefers to either the Designer or the Operator, both of which are client applications of the Server..
  • Firewall configuration: This is required the computer on which the SmartUI Server, Designer or Operator is installed is using firewall software.
  • Non-english operating system security configuration: This needs to be performed when installing the Server on a non-english operating system is installed and trying to use the built in Windows Administrator user to log onto the SmartUI Server, by default.
  • Security configuration: This needs to be performed after the SmartUI Server is installed, so that your users can log onto the Server via the Designer or Operator.
  • Disable Simple File Sharing: This may need to be performed on Windows XP Professional computers so that the SmartUIDesigner and Operator are able to connect to remote Server computers.
  • Server clustering: SmartUI Servers can be clustered to provide both load balancing and redundancy.
  • Datasource-specific Server settings: The SmartUI Server provides a number of settings that apply to specific datasources.
  • The SmartUI Config Editor configuration dialog is provided to customise the installed SmartUI applications and/or services by modifying their default settings to conform to your requirements. For details, see Working with the SmartUI Config editor.

Note1:These settings are initialised to default values on installation.

Note2:The onus rests upon the user to provide the correct values when modifying settings, therefore if you are unsure about a setting, use the existing default value instead.

  1. If necessary, you can enforce your SmartUIOperators to only retrieve their graphic forms from their local cache to increase the speed at which graphic forms are loaded. For details, see Updating cached graphic forms.
  2. If necessary, you can perform a “one-touch deployment” of the SmartUI Operator, to install and run the SmartUI Operator over the Internet. This is usually necessary in scenarios where software may not be installed on the client machine, such as on corporate networks. For details, see How to Install and Run the Operator over the Internet.
