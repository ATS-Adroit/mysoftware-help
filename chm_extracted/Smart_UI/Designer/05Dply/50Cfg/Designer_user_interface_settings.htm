Designer user interface settings

This page of the Setting up the Designer component of the Adroit Config Editor configuration dialog, provides the following settings that govern the initial display and configuration of the work environment of this SmartUI Designer :

To display this page of settings:

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Designer option.

Note: If this option does not appear then the SmartUI Designer may not be installed.

  1. Select the User Interface Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Graphic form default dimensions: specify the default graphic form size, in pixels, that conforms to the requirements of your end-users.

Specify the default graphic form Width in pixels: Either type in the required value directly or use the arrows of this spin control to obtain the required value.

Specify the default graphic form Height in pixels: Either type in the required value directly or use the arrows of this spin control to obtain the required value.

Note1:These settings only affect the initial dimensions of newly created graphic forms and can be changed once the graphic form is created.

Note2:Specifying large dimensions may require the use of scrollbars to access the entire height and width of the graphic form.

 

This page only configures the part of the essential SmartUI Designer settings. For details, see Setting up the Designer.

For details on displaying all the related SmartUI Designer settings, see the Advanced Designer settings page.
