Firewall configuration

If you are using firewall software then ensure that the following configuration is performed, in order for the SmartUI Server and Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. applications to be able to communicate with one another.

Note:If you are running Windows XP SP2, then Microsoft Firewall has been installed on your system and will need to be configured.

  1. When the SmartUI Server is required to communicate over the LAN to Clients:
  1. Server computer configuration: ensure that port 9000 is unblocked for communication i.e. allowed to communicate to and from other computers.
  2. Client computer configuration: ensure that the Designer and/or Operator applications are unblocked for communication i.e. allowed to communicate to and from other computers on any port.

WARNING! Unblocking applications does require more maintenance than ports, for instance, they need to be re-enabled if their installation folders are changed.

  1. When the SmartUI Server is required to communicate over the Internet via IIS to Clients:
  1. Server computer configuration: ensure that port 80 is unblocked for communication i.e. allowed to communicate to and from other computers.
  2. Client computer configuration: ensure that port 80 is unblocked for communication i.e. allowed to communicate to and from other computers.

Note: If the Server is required to communicate to Clients over the LAN and the Internet, ensure that both of these ports have been unblocked i.e. allowed to communicate to other computers. 

  1. When using the VIP Distributor service, ensure that port 9010 is unblocked for communication i.e. allowed to communicate to and from other computers. For details on using this service, see Using the Launcher.

To unblock an application using Microsoft Firewall:

  1. Either:

Choose to unblock the required application, when it is first run, from the dialog that is displayed.

  1. Or:
  1. Open the Microsoft Windows Firewall application.

This will display the Windows Firewall dialog.

  1. Select its Exceptions tab.
  2. Select the Add Program… button and then browse for the required .EXE file.

To unblock a port using Microsoft Firewall:

  1. Open the Microsoft Windows Firewall application:
    1. Select the Start menu, Settings and Network Connections item.
    2. In the Network Connections dialog, right-click the required LAN connection and select Properties.
    3. In the Local Area Connection Properties dialog, select the Advanced tab and the Settings... button in the Windows Firewall group.

     

  1. In the Windows Firewall dialog, select its Exceptions tab.
  2. Select the Add Port… button.
  3. In the Add a Port dialog, in the Name edit box, specify the name of the service or application that requires this port to be unblocked and then specify the required port number in the Port number edit box. Also ensure that the TCP selection is selected and click OK.

 

To open the Microsoft Windows Firewall application:

  1. Select the Start menu, Settings and Network Connections.

This will display the Network Connections dialog.

  1. Right-click the required Local Area Connection and select Properties.

This will display the Local Area Connection Properties dialog.

  1. Select the Advanced tab and the Settings... button within the Windows Firewall group.
