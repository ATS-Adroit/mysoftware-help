General Server settings

This page of the Setting up the Server component of the Adroit Config Editor configuration dialog, provides the following generally applicable SmartUI Server settings:

To display this page of settings:

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Server option.

Note: If this option does not appear then the SmartUI Server may not be installed.

  1. Select the General Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Server name: specify the name to identify this SmartUI Server and differentiate it from others SmartUI Servers in the same network.

To specify the Server name: If necessary, type the required name into the provided edit box.

Note: The only naming limitation is that the Server name may not contain the separator character, which is typically the “.” character.

Tip: It is recommended to use a descriptive name, which is as concise as possible.

Server event log: specify the computer and Windows event log name where the events generated by the SmartUI Server are stored.

These events are typically generated by each task that is performed by the SmartUI Server and can provide detailed information if a problem arises. For more details, see Logging diagnostic events to the event log.  

Note: Each SmartUI application provide an EventLogSource property that defines which application name is specified when logging an event to this event log.

To specify the computer on which these events are logged: Either type in the name of the required computer directly in the edit box or use the browse button to browse for the required computer.

Tip: It is recommended to use the browse button to avoid the possibility of typing the name of this computer incorrectly.

To specify the name of the event log in which these events are logged: If necessary, type the required name into the provided edit box.

Note: If this name is not specified, then this uses the following default event log name: Application.

Server licensing method: select how you want to license this SmartUI Server. For details, see Licensing methods.

To specify the normal licensing method: Ensure that No is selected.

To specify the Agent Server licensing method: Ensure that Yes is selected.

If the Agent Server is running on this Server computer no further configuration is necessary.

However if the Agent Server is running on a remote computer, then specify both the network name of the relevant computer and the name of its Agent Server, in the following format: ComputerName.AgentServerName

 

This page only configures the part of the essential SmartUI Server settings. For details, see Setting up the Server.

For details on displaying all the related SmartUI Server settings, see the Advanced Server settings page.
