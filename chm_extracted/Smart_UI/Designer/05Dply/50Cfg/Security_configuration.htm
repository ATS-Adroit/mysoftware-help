Security configuration

The SmartUI security system is user-centric and operates on top of the traditional Windows operating system security.

This is made possible by using a configurable sub-set of the existing users and groups on each Server computer, known as the "allowed" users and groups, which provide the first or foundational level of ALL security and user management within the SmartUI; hence their creation is mandatory for every Server. For further details on configuring roaming profiles to manage user management, see Working with profiles.

Note: On each Server, it is also possible to give specific users and groups total or global security access to the Server and it is recommended to use these group(s) and/or user(s) to administer its security. For details, see Assigning global security to groups and users or Configuring SmartUI Server security.

Tip: As a further security precaution, it is possible to prevent users from using a domain user name and password, by configuring impersonated user names and passwords, which do not natively exist on the domain itself.

In other words, unless a user is either an allowed user or a member of an allowed group he/she will be unable to login to the Server and use the SmartUI. For this reason, the necessary user accounts and/or groups need to be created within Windows first. For details, see Working with user accounts and groups.

Tip: To save time when launching a Client, it is possible to specify automatic login settings that will be used whenever the Client is launched. For details, see Automatically logging into SmartUI Servers.
