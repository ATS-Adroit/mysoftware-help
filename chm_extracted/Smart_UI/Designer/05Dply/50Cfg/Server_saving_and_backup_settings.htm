Server saving and backup settings

This page of the Setting up the Server component of the Adroit Config Editor configuration dialog, provides the following settings that manage both the saving and backup of the SmartUI Server data:

Tip: The Adroit Config Editor provides a System Backup and Restore feature that can backup and restore your SmartUI and/or Adroit user-configuration. For details, see System Backup and Restore.

To display this page of settings:

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Server option.

Note: If this option does not appear then the SmartUI Server may not be installed.

  1. Select the Backup Settings option.

Tip1: You can navigate directly to this page using the left pane of the Adroit Config Editor configuration dialog. For details, see Working with configuration dialogs.

Tip2: Press the Next or Previous buttons to display the other pages of settings.

 

Saving frequency: specify how often the Server saves its data. For further details relating to the saving Server data, see Saving the SmartUI Server.

To specify the required interval between saves, in seconds:Either type in the required value directly or use the arrows of this spin control to obtain the required value.

The recommended setting depends on the lifecycle stage of the project, as follows:

  • frequently during the designing phase, such as every 2 hours or less, since changes are being made frequently.
  • reduce this frequency during the implementation phase, such as to once a day, since the number of changes decrease.

Backing up the Server data: the SmartUI Server can backup its saved data, which includes the profiles, projects and other data - to guard against the possible corruption of this data, accidental deletion and other eventualities. For details, see Backing up SmartUI Server data.

To configure the backing up of the Server data: Either select Yes to enable or No to disable this setting..

Normally backing up Server data will not affect the performance of the Server, since this operation only briefly affects the CPU usage and the backup does not consume a large amount of the hard drive space.

However the larger the data files become, the more carefully one should configure the frequency of these backups.

Backup storage duration: specify how long to store the backed up data, before it is deleted.

To specify the number of days before backup files are deleted:: Either type in the required value directly or use the arrows of this spin control to obtain the required value.

The recommended setting depends on the lifecycle stage of the project, as follows:

  • not be more than one or two days during the designing phase as the number of backups during this period can become quite sizable.
  • during the implementation phase as the changes decrease, this backup period should be increased, such as to once a week.

 

This page only configures the part of the essential SmartUI Server settings. For details, see Setting up the Server.

For details on displaying all the related SmartUI Server settings, see the Advanced Server settings page.
