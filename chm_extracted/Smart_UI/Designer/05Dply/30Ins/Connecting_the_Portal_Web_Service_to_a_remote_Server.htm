Connecting the SmartUI Web Service to a remote Server

The SmartUI Web Service must be installed before a Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. can connect to this Server via the Internet, since this provides a gateway between the Client and Server. For details, see Installing the SmartUI Web Service.

Tip: For a detailed step-by-step procedure of connecting Operators to a Server over the Internet, see How to Connect to the Server over the Web.

By default this SmartUI Web Service assumes that the Server is on the local computer. If however, the Server is on a remote computer then the following further configuration is required, after installation:

To connect the Web service to a remote Server computer:

  1. Navigate to the SmartUI Web Service installation folder, which is typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI\Webservice.
  2. Locate the “Web.config” file in this folder and open it in a text editor, such as Notepad.

Its first four lines should appear as follows:

<?xml version="1.0" encoding="utf-8" ?>

<configuration>

   <appSettings>

      <add key="server" value="localhost" />

  1. Modify the “localhost”, so that the value refers to either the network name of the remote Server computer or its IP address.
  1. Save this file and close it.
