Available SmartUI Licensing methods

The SmartUI Server can be licensed by one of the following methods, which are listed in the ORDER that the Server LOOKS for its license:

Note1: The license for the FIRST licensing method that is detected is used to license the SmartUI Server

Note2: ONLY when NONE of these licensing methods are found, does the SmartUI Server considers itself NOT to be licensed.

  • HASP license: In this case, the SmartUI Server is licensed by a HASP software protection key, which is inserted into the USB port of the computer on which the Server is running. This HASP is programmed in accordance with your specific license agreement. Click for more details:

    The Server continuously checks that the HASP key is present. If the HASP key cannot be found after 3 retries (which are logged to the Application event log) the Server shuts down displaying a 'HASP cannot be found' message.

    WARNING! If this HASP key is lost, the cost of replacement is the current full value of the corresponding license fee. We recommend, therefore, that you consider insuring this item against loss or theft.

    Note1:If the licence is updated or modified then the HASP key must be reprogrammed to reflect the changes.

    Note2:You can use the SAME HASP to license BOTH Adroit and SmartUI, however, this requires a 4K “green” USB HASP.

Advantage: The MAIN advantage of this licensing method is PORTABILITY, as unlike a soft license which is bound to a specific computer, you can install and use the Server ANY computer provided that you plug your HASP into one of its USB ports.

  1. Soft license: In this case, the SmartUI Server is licensed by a software license to a SINGLE computer and only remains valid while certain hardware and software or system characteristics of this computer remain unchanged. Click for more details:

    Note1:If ANY of the hardware and/or software items that the soft license monitors are modified, then the license will stop working and you will need to obtain a new license file.

    Note2:If the Server computer has more than one network card, the licence will only monitor ONE of the cards - should this card become disabled, then the Server will no longer be licensed.

Advantage: The MAIN advantage of this licensing method is SECURITY, as unlike a HASP license which can be removed from a computer without your knowledge, this license is bound intrinsically to a specific computer.

  1. Adroit license: In this case, the SmartUI Server is licensed by consuming a single connection license from the license of an Adroit Agent Server.
    This license provides LIMITED ACCESS to the datasources of the Server, by ONLY entitling the user to the Adroit datasources and the proprietary or unlicensed datasources, such as the Event Log, Simulation, Virtual and Project datasources. Click for more details:

    Typically the Server runs on this Adroit Agent Server computer and consuming the single connection license from this local Agent Server. However, you can specify a remote Agent Server from which this connection license should be taken.

    For details on configuring this alternative Server licensing method, see General Server settings.

    Note1:This licensing method applies whether the specified Adroit Agent Server is being run in licensed or in timed-license mode.

    Note2:The LICENSED datasources, such as OLEDB (databases), OPC and Server Scripts are ONLY AVAILABLE when the Server is licensed using the methods described above.

Advantage: The MAIN advantage of this licensing method is REDUCED COST and EASE OF USE as you do not need to specifically apply for this license.

  1. Demo license: You can use the SmartUI Server freely, for 2 hours, which you can restart as many times as you like.
    This license ONLY allows 1 local SmartUI Operator and 1 local SmartUI Designer to connect and does NOT restrict access to the datasources of the Server.

Note: 5 Minutes before the demo license expires, CONNECTED CLIENTS receive a warning that they must save their work.

Once the demo license expires the Server will shut down. The Server can then be restarted and any existing clients will automatically reconnect.
