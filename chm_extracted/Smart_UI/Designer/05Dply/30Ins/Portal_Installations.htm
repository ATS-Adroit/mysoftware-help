SmartUI Installations

Since SmartUI has been created using the .NET framework, its installations are both easier to deploy and maintain, when compared to conventional software in the past. For details, see About .NET installations.

SmartUI typically provides the following installation options; which may be named differently but will contain the same SmartUIcomponents, as follows:

Click for general SmartUIinstallation advice:

Note1:Add-on components that are separately licensed may need to be separately installed, such as datasources and spiders. For more information on licensing the SmartUI Server, see Licensing the Server.

Note2:Before beginning an installation ensure that the computer complies with both the software and hardware requirements for the required SmartUI application(s). For details, see System requirements.

Note3:After installation, ensure that the necessary configuration is performed before launching the application(s). For details, see Configuration after installation.

Note4:All of these installations except SmartUI Web Service also install the Launcher, which can be used to update their relevant files. For details, see Working with the Launcher.

  1. Server: This installation option installs the SmartUI Server along with the SmartUI Designer and SmartUI Operator onto a computer. For details, see Installing SmartUI.

Click for SmartUI-specific installation advice: this lists notices that apply specifically to the SmartUI Server installation, such as licensing the Server.

Note1:It is possible use the Server freely, with a Designer and an Operator connections for 2 hours, after which the Server must be restarted. For more information on licensing the SmartUI Server, see Licensing the Server.

Note2:The Server can be licensed by a HASP software protection key, a software license, an Adroit license or a demo license. For details of these licensing methods and their respective advantages, see Available licensing methods.

Note3:The Server does NOT need to be licensed or run if the Designer and/or Operator connects to another Server.

Note4:The number of Clients that can connect to a Server are dependent upon its operating system and licensing. For details, see System requirements for the Server.

  1. Operator: This will only install the Operator on a computer.  For details, see Installing the Operator.
  2. Click Once: The Click Once install allows a user to use a fully fledged Operator, which is downloaded via Internet Explorer and runs normally, as a separate application. For details, see Working with Click Once.
  3. Web Service: This additional installation is required if a Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. needs to connect to this Server via the Internet. For details, see Installing the SmartUI Web Service.

Tip: For a detailed step-by-step procedure of connecting Operators to a Server over the Internet, see How to Connect to the Server over the Web.

  1. Custom: This installation option is recommended for advanced users only, as it permits the selection of VIP components and their sub-components. Such as installing one or more unsupported components.
