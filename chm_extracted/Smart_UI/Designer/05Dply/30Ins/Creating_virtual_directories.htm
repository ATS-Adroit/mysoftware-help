Creating virtual directories

Note: This should NOT be required since the installation of both the SmartUI Web Service and Web Operator create their required virtual directories.

However, if a virtual directory, has NOT been created, this can also be manually performed, as follows:

To create a virtual directory:

Note: This procedure assumes that the user has Administrator privileges and that Internet Information Services (IIS) has already been installed.

  1. Select the Start menu, Settings, Control Panel, Administrative Tools and Internet Information Services.

This will display the Internet Information Services applet.

 

In the left hand windowpane of this applet:

  1. Select the required computer, to display its contents.

Note: This should usually be the local computer, which is specified in parentheses to the right of the computer name.

  1. Expand the Web Sites folder and select the required web site in which the virtual directory is to be created.

Note: This will usually be the ‘Default Web Site’, however computers with Server operating systems may have more than one web site to choose from.

  1. Right-click the required web site and select the New sub-menu and its Virtual Directory… item.

This will display the Virtual Directory Creation dialog.

  1. Click Next.
  2. Type in the name or alias, into the Alias edit box, that will be used to display the contents of this web site in a web browser. Typically the specified name will be accessed, as follows: http://WebSiteName/AliasName, although if the ‘Default Web Site’ is selected, this will simply be: http://ComputerName/AliasName.
  3. Click Next.
  4. Specify the folder in which the SmartUI Web Service has been installed, in the Directory edit box, which is usually the default SmartUI Web Service installation path: C:\Program Files\Adroit Technologies\Adroit\SmartUI\Webservice.
  5. Click Next.
  6. It is not necessary to modify the default Access Permissions.
  7. Click Next and then Finish.
