Connecting to the distribution computer

The SmartUI Launcher is used to download the files required for the SmartUIOperator application, either over a LAN or the Internet.

Tip: For a detailed step-by-step procedure of connecting Operators to a Server over the Internet, see How to Connect to the Server over the Web.

To do this, the Launcher needs to connect to a computer that has the SmartUI Distributor service installed and configured, which is typically the SmartUI Server computer. The VIP Distributor service specifies the folder that the Launcher uses to synchronises its installation folder with. For details, see Working with the SmartUI Launcher.

Note1: If the distribution computer uses firewall software ensure that the Distributor service has access to the necessary communication port. For details, see Firewall configuration.

Note2: Once the Launcher has successfully connected to a distribution computer, these connections settings will automatically be used whenever it is run.

Note3: This connection dialog can also be displayed, for instance to connect to another computer, by opening the launcher, selecting File menu and its Connection item.

The following procedure describes how to create a new connection.

  1. First ensure that the VIP Distributor service is running on the required computer.

To manually start or configure the SmartUIDistributor service:

  1. Open the Services applet on the required computer, as follows: click the Start menu, Control Panel, Administrative Tools and the Services item.
  2. Locate the VIP Distributor entry in the list.
  3. Right-click this item and select Start.

Tip: Select Properties…to configure this service to your liking within the Services environment i.e. to determine the Startup type or the Log on account that should be used for this service.

To connect to the distribution computer:

  1. Run the SmartUI Launcher, as follows:
  2. If you have installed the SmartUI Launcher: use the Launcher shortcut on the Desktop by the installation or from within the VIP Launcherr program group.
  3. If SmartUI supports the use of the Launcher and you have the Operator or Designer components already installed, then double click the SmartUI Launcher executable in the installation folder, which is typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI.

The SmartUI Launcher is displayed.

  1. If necessary, selecting File menu and its Connection item to display the Connection dialog.
  2. If necessary, select how this distribution computer is to be reached i.e. over the LAN or over the Internet.

Note: By default, this dialog displays the fields required when connecting to a distribution computer over the LAN.

If this connection is required over the LAN:

  1. Specify the network name of this required computer that has the SmartUI Distributor service installed and configured in the Computer/URL edit box.
  2. Ensure that the LAN or WAN selection is selected.
  3. In the Authenticate group, specify the required User and Password, which are required when connecting to this computer.

Note: At least the User field needs to be completed, in order for a connection to be created; a Password does not need to be specified.

  1. Click the Connect button, once the necessary details, have been correctly specified.

If this connection is required over the Internet:

Note: Before a connection can be made over the Internet to the Server, the Web service needs to be installed. For details, see Installing the SmartUI Web Service.

  1. Specify the Internet address (URL) of the Web service, which makes this Internet connection possible, in the Computer/URL edit box, which is typically: http://ComputerName/VirtualDirectory/wsdistributor.asmx. Where:
  1. ComputerName is the name of the IIS server hosting the distribution service (on which the Web service has been installed)
  2. VirtualDirectory is the name of the virtual directory containing the wsdistributor.asmx file, which was specified when installing the SmartUI Web Service, which is typically: SmartUI

Tip: The 'http://' prefix and '/wsdistributor.asmx' suffix will be added to this URL on connection, if they have not been specified.

For further details, open this web page: http://ComputerName/VirtualDirectory e.g. http://localhost/SmartUI, which can be used to download the Launcher application and also contains instructions on how to connect and download the distribution files too.

Note: The SmartUI Web Service does not need to be installed on the same computer as the Distributor service, as long as these two computers can communicate over the LAN.

  1. Ensure that the Internet selection is selected.
  2. In the Authenticate group, specify the required User and Password, which are required when connecting to this computer.
  3. If a proxy server is required for this Internet connection, check the Enable Proxy checkbox and click the Proxy Settings button.

This displays the Proxy Settings dialog, so that the necessary connection settings for this Proxy server can be specified, as follows:

  1. Specify the network name of this Proxy server or its IP address in the Machine Name or IP edit box.
  2. Specify the port that this Proxy Server uses in the Port edit box, this is typically port 8080.

Tip: If necessary, the required port for this proxy server can also be determined from Internet Options (typically launched from the Tools menu in Internet Explorer), by selecting the Connections tab and its LAN Settings… button.

  1. If user authentication is required when connecting to this proxy server, then check the Authenticate checkbox and supply the necessary User and Password.
  2. Click OK.
  1. Click the Connect button, once the necessary details, have been correctly specified.
