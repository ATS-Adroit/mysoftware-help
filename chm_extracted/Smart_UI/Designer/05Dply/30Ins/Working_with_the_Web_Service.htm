Working with the SmartUI Web Service

The SmartUI Web Service provides an internet gateway between the SmartUI Server and its various client applications.

Practically this means that the SmartUI Web Service is typically used to do the following:

  • To typically allow a SmartUI Operator client to connect to the SmartUI Server over the internet or intranet.

    This method uses the VIP Distributor service that is installed by the SmartUI Server install and the SmartUI Launcher that needs to be installed on the user's computer. These two are then linked by the SmartUI Web Service, so that the necessary files are downloaded via the web.

  • To allow a Performance Anywhere client to connect to the SmartUI Server over the internet or intranet.

    In this case, you ALSO need to install the SEPARATE SmartUI Performance Anywhere component, typically on this web server.

    Then users can use the provided URL to launch the Performance Anywhere dashboard in their Internet browser, as explained by the installed document.

Note: To this end you need to pair the version of SmartUI Performance Anywhere to the same product version of this SmartUI Web Service, otherwise your users will not be able to log in.

IMPORTANT: Performance Anywhere is NOT a replacement for a fully-fledged Operator but does allow for the limited viewing and configuration of typically SCADA data over the web.

However, you can also install the SEPARATE SmartUI Click Once component on this web server, via the Custom installation option.

This component allows users to use a fully fledged SmartUI Operator, which is downloaded via Internet Explorer and runs normally, as a separate application, which essentially performs a “one-click deployment” of the SmartUI Operator.

Troubleshooting the Web Service

  • Tweaking the default Web Service configuration settings: The Web Service Config file contains a number of settings that pertain to the operation of the SmartUI Web Service.

Typically these default settings are adequate, although you may need to adjust some of these settings, by editing this file yourself, to resolve connection and performance issues that arise.

  • Resetting ASP.Net with Internet Information Services (IIS): Sometimes the Microsoft .NET Framework will require a reset in order to update its files so that they are recognised by the web server and run the client side scripts.

In such cases, exceptions can be encountered when using the SmartUI Web Service, which can be resolved by manually re-registering ASP.NET

To typically connect an Operator to a Server over the web

This method uses the VIP Distributor service that is installed by the SmartUI Server install and the SmartUI Launcher that needs to be installed on the user's computer. These two are then linked by the SmartUI Web Service, so that the necessary files are be downloaded via the web.

  • The VIP Distributor service identifies a "distribution" folder on the SmartUI Server computer, which is typically the \Distribution sub folder of the SmartUI Server installation folder: C:\Program Files\Adroit Technologies\Adroit\SmartUI, which by default contains the files required by the SmartUI Operator.

Note: The SmartUI Server install ensures that this service automatically starts.

  • The SmartUI Launcher connects to the computer running the VIP Distributor service, via the SmartUI Web Service and downloads all files and folders that have been placed in the "distribution" folder and allows any downloaded executables to be launched.

Note: The SmartUI Launcher also ensures that these downloaded files are kept up-to-date with the files located in the “distribution” folder on the computer that it connects to.

  1. Launch your web browsing application.

  2. Type in the required URL for the Web Server, as follows: http://WebSiteName/VirtualDirectoryName, such as http://213.49.35.19/VIP/

    This should immediately display this default web page.

  3. Click on the SmartUI Launcher Setup Download link to download and install the SmartUI Launcher on your computer.

Note: In order for this installation to succeed, the .NET framework MUST be installed on this computer first.

  1. Once the download has completed, click the Launcher shortcut that is installed on your Desktop.

    This will display its Connection dialog, which should be completed as follows:

  1. Ensure that the Internet radio button is selected.
  2. If a proxy server is required for this Internet connection, check the Enable Proxy checkbox and click the Proxy Settings button. Specify the Machine Name or IP address of the proxy server and its designated Port number.
  3. In the Computer/URL field, specify the Internet address of the WebService, which makes this Internet connection possible, which is typically: http://ComputerName/VirtualDirectory. Where:
  4. ComputerName is the IP address of the web server (IIS computer) on which the SmartUI Web Service has been installed.
  5. VirtualDirectory is the name of the virtual directory specified when installing the SmartUI Web Service, such as http://213.49.35.19/VIP

Tip: The 'http://' prefix will be added to this URL on connection, if it is not been specified.

  1. In the Authentication Details, specify the required User and Password, which are required when connecting to this computer that is running the VIP Distributor, which is typically the SmartUI Server computer.
  1. Click the Connect button.

If everything has been correctly specified, the Download dialog should be displayed.

  1. Click the Download button to download the files specified by the VIP Distributor service into the SmartUI Launcher installation folder.

Once all the required files have been downloaded the SmartUI Launcher will display all the executable programs that have been downloaded. Typically the SmartUI Config Editor and Operator.

  1. Double-click on the SmartUI Operator to launch it.
  1. The next time you run the SmartUI Launcher program it should automatically display these executables.

If however, any of the file(s) and folder(s) are newer on this remote computer or which do not exist on the local computer, they will be displayed for downloading.

In this way the SmartUI Launcher ensures that the files within its installation folder are kept up-to-date with the files located in the distribution folder on the computer that the SmartUI Launcher connects to.

Note: If you want to specify other connection settings instead, then simply open the File menu and select the Connection item, which will display the Connection dialog instead.

Tip: To automatically execute a downloaded executable after the SmartUI launcher has finished processing, simply edit the shortcut used to launch the SmartUI launcher and add the name of this executable (its extension is not required) as its command-line parameter to the Target field.

Tweaking the Web Service Config file settings

The Web Service Config file contains a number of settings that pertain to the operation of the Web Service.

Typically the default values of these settings should be adequate, although you may need to adjust the following settings by editing this file yourself to resolve the following connection and performance issues:

Note: Be VERY careful when editing this file; since if you corrupt the file structure nothing will work. Please ask support for help if you need it and BACKUP the existing file before you start editing it.

File location: This file is called Web.config and is located in the root folder of the SmartUI Web Service component, which is typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI\Webservice

IMPORTANT: After editing the Web.config file, you need to restart IIS, which you can do by opening the Command Prompt (Admin) and entering the following command: iisreset

  • If the SmartUI Server is on another computer than the SmartUI Web Service.

    Then edit the <add key="server" value="localhost"/> to specify the computer name or IP address of the SmartUI Server computer.

  • If the SmartUI Server is running on a port other than 9010.

    Then uncomment the <add key="serverPort" value="9500"/> and change the port value to the port value that the SmartUI Server is running on.

  • If the Performance Anywhere clients are experiencing problems where the Charting widgets are taking too long update or do not have any data; or images take too long to load or the Data Element Browser either does not display any tags or takes to long to load etc.

    Then edit the <add key="ServiceRequestTimeout" value="60"/> and increase this timeout which specifies the timeout in seconds for any requests made by the Web Service or Performance Anywhere to the SmartUI Server.

How to Reset ASP.Net with Internet Information Services (IIS)

Sometimes the Microsoft .NET Framework will require a reset in order to update its files so that they are recognised by the web server and run the client side scripts. In such cases, exceptions can be encountered when using the SmartUI Web Service or logging in to the Performance Anywhere Dashboard.

These issues can be solved by re-registering ASP.NET, running the IIS Registration tool – aspnet_regiis.exe, which is installed in the Microsoft.NET Framework directory.

For 64-bit operating systems:

  1. Open the command prompt as Administrator
  2. Enter the following command (provided the system directory is C:\Windows) to open your Microsoft .NET Framework folder: CD C:\Windows\Microsoft.NET\Framework64\v4.0.30319 1.
  3. Enter this command to reset ASP.NET: aspnet_regiis –i
  4. Close the command prompt window.

For 32-bit operating systems:

  1. Open the command prompt as Administrator
  2. Enter the following command (provided the system directory is C:\Windows) to open your Microsoft .NET Framework folder: CD C:\Windows\Microsoft.NET\Framework\v4.0.30319 1.
  3. Enter this command to reset ASP.NET: aspnet_regiis –i
  4. Close the command prompt window.
