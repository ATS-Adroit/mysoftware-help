Adroit Server ActiveX Control

IMPORTANT: This utility is NOT included in the Adroit installation and must be separately installed from the Additional Adroit Components installation.

The Adroit Server ActiveX Control (adroitx.ocx) is provided as an alternative to the current Adroit Server OLE interface (MISSRVR) provided by the AdroitServer OLE automation object.

While it honors the current AdroitServer interface, its prime feature is that of supporting subscriptions via an event interface.

The ActiveX object provides for 3 different areas of functionality:

Connection.

Agent handling.

SCADA functionality.

Its main features are:

  • Provides subscription support.
  • Provides a base class from which to derive Adroit-aware ActiveX controls.

Note: Any pokes performed, using this Adroit ActiveX component will require a scan point license for each unique tag that is "poked". Also, as their AlarmTag, FetchChanges, FetchValues, LogTag and ScanTag methods all use pokes internally, calls to these methods will require scan point licenses.

 

The adroitx.htm sample file provides an example of how to use the Adroit ActiveX control in a web page. If installed, this is located in C:\Program Files\Adroit Technologies\Adroit\Samples\Web folder.
