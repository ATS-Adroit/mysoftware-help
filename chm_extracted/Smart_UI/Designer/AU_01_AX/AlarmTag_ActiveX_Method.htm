AlarmTag ActiveX Method

PLEASE NOTE: This method uses scan points because it uses putslot functionality internally, therefore ensure that the Agent Server computer either is licensed (i.e. has a HASP Software Protection Key attached) or that the Agent Server is run using the Limited Time License HASP.

SCADA Functionality.

 

Method AlarmTag (Agent:String, AlarmAgent:String, AlarmType:string, AlarmRoute:Long, AlarmAck:Long, AlarmTypeEnum:Long):Boolean;

This method configures an Adroit agent for alarming.

 

Parameters:

  1. Agent: the agent to alarmed, e.g. ANA-01
  2. AlarmAgent: the alarm agent to use, e.g. defaultAlarmAgent
  3. AlarmType: the alarm type to use, e.g. High
  4. AlarmRoute: the alarm route number, e.g. 1

Note: If a AlarmRoute of –1 is specified then the specified alarm will be deleted.

  1. AlarmAck: true, if alarm to be acknowledgeable.
  2. AlarmTypeEnum: the alarm type enumeration, instead of specifying the AlarmType parameter, -1 otherwise.

Note: The use of this parameter is intended for advanced users only, who know what the required type index is. This allows for faster transactions since the legality of the AlarmType parameter does not need to be checked.
