The Configuration grid

The Configuration grid, consists of the following fields, which displays information about the Adroit configuration of the selected computer, as follows:

Note: The grid provides the following standard configuration options. For instance any cell entries that are displayed in blue, in the grid, can be both edited or replaced.

  1. The first untitled field numbers the information items in the grid.
  2. Item: This field specifies the configuration item, which is being displayed.
  3. Setting: This field specifies the current configuration of the specified item.

The following list describes what the listed Configuration Items refer to:

  1. Server type: This field, specifies the current type of Agent Server that is running on the selected computer, as follows:
  • Type 0 - Cluster Server: In this case master or standby mode assignment is necessary and duplicate databases need to maintained on each.
  • Type 1 - Cluster aware server: In this case Proxy agents are created if remote duplicate tags are found.
  • Type 2 - Stand-alone server: In this case Proxy agents are not created if remote duplicate tags are found.
  1. Server name: This field specifies the configuration of the Agent Server name to be used when it starts up. This must be unique across the same network and when more than one Agent Server is being used within a project, ensure that the first 7 characters are unique.
  2. Project name: This field specifies the configuration of the project name to be used by the Agent Server when it starts up. This project name must not be longer than 8 characters, nor contain any embedded spaces. When more than one project name is being used on the same network, ensure that the first 3 characters are unique.
  3. WGP file: This field specifies the path and name that the WGP or Agent Server database file will be saved to.
  4. Adroit directory: This field specifies the path where the Adroit system files, executables and dynamic link libraries, are stored, which is typically: C:\Program Files\Adroit Technologies\Adroit.
  5. Channels: This field specifies the maximum number channels used by the Agent Server when it starts up. A channel is a Client-Server connection from the Agent Server to the outside world, such as to the User Interface, other Agent Servers, the Adroit OPC Server etc. The default setting is 20.
  6. Max agents: This field specifies the maximum number of agents used by the Agent Server when it starts up. This number accounts for both the number of agents in the project and additional Agent Servers explicitly connected to the project. Hence determine the number of expected agents on all the connected Agent Servers and multiply this by two.
  7. Save on exit: Change this Setting field to 1, to force the saving of the WGP file when the Agent Server is shut down.  This is valid for the current session only. The default value is 0.
  8. Installed devices: This field lists the currently configured devices to which tags can be scanned. Additional devices can be added using the Adroit Setup on this computer. For details, see Add Device.
  9. Log system events enabled: Change this Setting field to 1, to enable the logging of such events e.g.  when time-stamped data is rejected by a mimic for being to old. The default value is 0.
