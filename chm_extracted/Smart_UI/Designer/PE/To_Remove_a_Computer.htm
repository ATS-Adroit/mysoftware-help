To Remove a Computer

This will remove the selected computer name from the tree view windowpane. 

When the tree view windowpane of the Project Explorer is selected:

  1. Select the Computer object that is to be removed.
  2. Right-click or press F4 and click on the Delete PC menu item.

Tip: Alternatively press CTRL and - keys, the shortcut key for this command.

Note1: If the currently selected object was one of the children objects of a computer object, this computer will be removed from the tree view windowpane.

Note2: If the incorrect computer was removed, use Add PC... to add it to the tree view windowpane.
