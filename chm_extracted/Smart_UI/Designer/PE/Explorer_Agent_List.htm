Explorer Agent List

The Explorer Agent List grid displays a list of configured agents of the selected agent group. This consists of the following fields by default:

Note: The grid provides the following standard configuration options. For instance any cell entries that are displayed in blue, in the grid, can be both edited or replaced.

  1. The first untitled field numbers the agents in the grid.
  2. Name: This field, specifies the name of the configured agent, of the selected agent type.
  3. AgentDescription: This field, displays the default AgentDescription slot of the configured agents, this cannot be moved.

Note1: If necessary slots (columns) can be added to this grid. For details, see Adding slots to the Explorer Agent List.

Note2: Any column added to this grid can be selected and moved, however the positions of the Name and AgentDescription columns are fixed.

Right-click this grid to display the Explorer Agent List context sensitive menu, which provides the following functionality:

  1. To Select an Agent and Slot in the Explorer Agent List.
  2. To Add Header Slots for the displayed agents: to add one or more columns of Header slots for the displayed agents.
  3. To Edit the Currently Selected Agent.
  4. To Edit Multiple Cells Simultaneously.
  5. To Display the Header Dialog of the Currently Selected Agent: to view and edit the bits within the status word of an agent and its global slots, if required.
  6. To Scan the Currently Selected Agent and Slot.
  7. To Modify the Scanning Configuration of Scanned Tags.
  8. To Remove Scanned agents from a Device.
  9. To Log the Currently Selected Agent and Slot.
  10. To Alarm the Currently Selected Agent.
  11. To Display and Modify the Memberships of the Selected.
  12. To Display a List of Agents that Use the Selected.
  13. To Copy the Currently Selected Agent.
  14. To Remove the Currently Selected Agent(s).
  15. To Refresh the Display of the Explorer Agent List.
