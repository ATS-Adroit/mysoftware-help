The Hierarchical Tree view

The Adroit Project Explorer configures and manages both local and distributed Adroit projects. For details, see Project Explorer.

The tree view windowpane, on the left of the Project Explorer window, displays a collection of objects, which are hierarchically arranged, so that some of the objects are “parents” to their “children” and “grandchildren” objects. The following listing displays the order in which these objects are arranged:

Computers represent the first or “parent” level of accessible objects in the tree windowpane.

Agent Server.

Agent groups.

Agents.

List slots.

Configuration.

Note1: Computers that do not have Adroit installed will not display ANY objects beneath its Computer icon.

Note2: Any Computer found running an Agent Server, that does not allow read/write access of its registry, will ONLY display the Agent Server object, when its Computer icon is expanded.
