Scanning Slots in the Project Explorer

Expand the required agent type object in the tree view windowpane

  1. Either select the required agent so that its slots are displayed in the Explorer Agent List grid windowpane on the left, then right click the required slot and select the Scan slot… menu item.
  2. Or right click the required agent, in the tree view, and select the Scan… menu item.

This displays the Adroit Tag Scanning Dashboard dialog.

Note: This dialog can be resized, to view lengthy scanning configuration, if necessary.

  1. Select the required pre-configured device in the Device list box, from the list of available device drivers.

Note: If there is a driver that was not setup during installation, it can be added later by running Adroit Setup and adding a new driver. The Agent Server will NOT need to be restarted.

  1. Start or stop scanning from this selected Device by either selecting the Started (the default selection) or the Stopped options.

The Add tag edit box, contain the currently selected agent and slot combination, when launched from the Explorer Agent List grid windowpane e.g. AgentName.AgentDescription.

  1. In the Device address edit box, specify the protocol driver specific address in this Device to which the value of this tag will be stored.
  2. In the Scan rate (ms) edit box, define the scanning interval or period in milliseconds between attempts to poll this item.

Note: This will only apply to polled devices; telemetry devices will ignore this parameter.

  1. In the Deadband edit box, specify the limit that the change in the scanned value must exceed before the agent’s slot is updated.

This Deadband is in the same units as the tag that is being scanned. For performance reasons, it is advisable to give a non-zero Deadband for Analog or Integer values in order to filter out noise or minor variations in value, since applying a Deadband reduces the number of changes to the database thus improving performance.

Note1: It is NOT advisable to use a Deadband when scanning tags that contain state information, as you may lose significant bits of information when decoding to binary form.

Note2: The scan inhibit and/or output enable bits can be set “live” for the currently selected item i.e. it is no longer necessary to unscan the item, change its setting(s) and rescan the item. However, the device needs to be stopped and restarted before these settings can take effect.

  1. If required, tick the Scan (input) inhibited checkbox, to stop this scanned tag from being updated by the PLC (front-end device).

Note: This does not affect this scanned tag from updating the PLC (front-end device).

  1. If required, tick the Output enabled checkbox, to enable this scanned tag to update the PLC (front-end device).

Note: This does not affect this scanned tag from being updated by the PLC (front-end device).

  1. If you want an initial value to be written to the Device to change the value in the FED, at startup, or after any communications failure and subsequent recovery, then check the Output initialise checkbox. By default this is OFF (cleared).
  2. Click the Add button to add this slot-scanning configuration to the scanned tag list for this selected Device.

Note1: The Update button makes it possible to modify the scanning settings for an item, with a single update, instead of having to unscan the item, change its details and then rescan it.

Note2: Each of these columns of the list of scanned items can be used to sort this list alphanumerically, by clicking on the respective column heading to either display the sort ascending  or sort descending  icon to the right of this column heading.

Tip: This dialog can also be manually resized to display even more tags, if required.
