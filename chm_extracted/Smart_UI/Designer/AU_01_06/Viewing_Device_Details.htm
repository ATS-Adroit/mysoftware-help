Viewing Device Details

The Device agent exposes the ‘device’ created in the Adroit Configuration Setup utility, through which the communication actually occurs to its front-end device.

It is able to stop and start the communication to and from this front-end device and configure its communication settings, if necessary. For details on Device agents in general, see Device Agents.

To View the Details of a Device

Display the Tag scanning configuration dialog, as follows:

 

Open the Agent Configuration dialog, as follows:

Tip: This also opens the Adroit Classic UI in the SmartUI Designer, which provides agent-specific menu functions, such as importing and exporting agents.

In the SmartUI Designer:

Click the Open Configurator tool in the Agent Server group of the Home tab of the SmartUI Designer ribbon.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.

The Agent Configuration dialog is displayed within the Classic UI.

Click on any agent and click the Scan... button.

  1. If necessary, select the name of the required device in the Device list box.
  2. Click the Details… button.

This will display the Device: DeviceName dialog, where DeviceName is the same of the selected device.

  1. The Device dialog box typically provides the following information:
  2. the name of the protocol driver used to create this device.
  3. the list of valid address ranges for this protocol driver.
  4. the number of points (Adroit tags) currently scanned to this device.
  5. the communication status of the device i.e. whether it is stopped or started.

You can also reset (close and re-open) and switch the device’s connection, by using the Reset and Switch buttons, which will only work if the associated protocol driver supports this functionality. For further details, see Resetting or Switching Devices.

Note1: Although it is also possible to start and stop this device from this dialog, by clicking the Start and Stop button, its easier to use the Started and Stopped selection from the main Tag scanning configuration dialog instead. For details, see Starting or Stopping Devices.

Note2: It is also possible to configure the communication settings that are used to communicate to and from its associated front-end device, by clicking the Setup… button. For further details, see Configuring Protocol Driver Settings.

Note3: The Refresh button, simply updates the information displayed by this dialog.
