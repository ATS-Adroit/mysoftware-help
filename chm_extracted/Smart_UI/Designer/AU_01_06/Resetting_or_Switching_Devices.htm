Resetting or Switching Devices

The Device agent exposes the ‘device’, of a specific protocol driver that is created in the Adroit Configuration Setup utility, through which the communication actually occurs to its front-end device. For details on Device agents in general, see Device Agents.

Devices of certain protocol drivers also provide the following functionality (as specified in their protocol driver documentation):

  • Reset the device, so that it will close and re-open its connection to the connected front-end.

Note: This will only work for the current device, if its protocol driver supports this functionality.

  • Switch the device, which causes the device to switch the connection from the primary to the secondary connection

Note: This will only work for the current device, if this secondary connection has been configured and if its protocol driver supports this functionality..

To reset or switch a device:

  1. If necessary, display the Tag scanning configuration dialog, either by editing the required Device agent or when scanning an agent.
  2. If necessary, select the name of the required device in the Device list box.
  3. Click the Details… button.

This will display the Device: DeviceName dialog, where DeviceName is the same of the selected device.

  • To Reset the Device: click the Reset button.
  • To Switch the Device: click the Switch button.
