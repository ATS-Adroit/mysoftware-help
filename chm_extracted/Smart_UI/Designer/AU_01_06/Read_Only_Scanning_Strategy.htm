Read Only Scanning Strategy

This scanningthe process of communicating a value (slot), typically to and/or from a front-end device (FED). configuration is the normal mode of operation for read only scanning.

Where users should not modify the values of tags within the Agent Server manually otherwise the value of these tags in the Agent Server will be out of sync with their process values i.e. their values in the front end device (PLC).

For details of all the scanning strategies offered, see Scanning Strategies or for further details on the effect of combining the available global and tag-specific scanning settings, see The Effect of Combining Scanning Settings.

Required global scanning settings:

MonitorStatus can be set, in which case any values which have been manually modified in the Agent Server, will be overwritten with the process value, on the next read.

This setting can be configured within the Advanced Scanning Settings dialog, by checking the Allow changes in scan-inhibit and output-enable to affect the tag immediately checkbox.

Note: For this strategy, the settings of both ForceOutputs and SyncProcessToServerOnFirstScan are immaterial.

Required tag-specific scanning settings:

  1. Output Enable = 0
  2. Scan Inhibit = 0

Operation of strategy:

  1. When the Agent Server is started, the Agent Server receives the values of these scanned tags from the front-end devices (PLCs).
  2. When a device stops or starts, the Agent Server receives the values of these scanned tags from the front-end devices (PLCs).
  3. When the communications have been restored after a device has failed, the Agent Server receives the values of these scanned tags from the front-end devices (PLCs).
  4. If a value of one of these scanned tags is changed in the Agent Server, this value is overwritten by the value in the front-end device (PLC)

Note: Depending on the driver being used, MonitorStatus may need to be set, for this to be the case.

  1. If a value of one of these scanned tags is changed externally, the Agent Server receives this value from the front-end device (PLC).
