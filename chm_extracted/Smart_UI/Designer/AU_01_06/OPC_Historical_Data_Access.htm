OPC Historical Data Access

If you use the Adroit OPC client driver to connect to an OPC Historical Data Access (HDA) server, then you can retrieve historical information from this server. Typically this can be used to retrieve missing data, when you have lost connection to a remote OPC HDA server.

How to perform an HDA operation to recover missing data:

  • You need to have scanned at least one tagA fully qualified named value in Adroit (agentName.slotName). to an OPC server that supports Historical Data Access (HDA).
  • You need to know the extent of the missing data. In other words, the Adroit tags, scanned to this OPC HDA server, that are missing data and the start and end dates and times of this data loss.
  • You need to add the following Execute Command Behaviour to a picture element on a mimic, so that you can launch the OPC Historical Data Access (HDA) dialog that is used to retrieve the missing data, as follows:
    1. Add/edit the required mimic and/or picture element.

    Tip: Right click the picture element to display its Associated Behaviours dialog.

    1. Double click the Execute Command Behaviour in the Possible Behaviours list.
    2. Select the Execute DLL function option from the Commands list.
    3. Type the following into the File name edit field: adrhdacl.dll,OpenHDA,0
    4. Click the Finish button to close the open dialogs.
    5. Click the Toggle view toolbar button to toggle this mimic into operating mode (and save the changes).
  1. HDA operations can only be performed while the Agent Server is running.
  1. Click the picture element that has the assigned Execute DLL function to launch the OPC Historical Data Access (HDA) dialog.
  2. Specify the extent that the missing data, by providing the requisite dates and times in the From and To edit fields.
  3. Choose one of the following methods to retrieve the missing data for the affected Adroit tags from the OPC HDA server, starting from the From date and time and ending at the To date and time:
  4. Poll file: This method retrieves the data values for all the tags specified by a text file that you create, as follows:
    1. Create a text file that contains a list of the affected tags, with each tag on its own line and use the following file extension, when saving this file: .hda.tags.txt – for instance myHDAtaglist.hda.tags.txt.
    2. Click the Poll file… button to browse for and open this file.

    Tip: Use the Agent Browser utility to paste the required tags (agent.slot) names into this text file to ensure that there are no spelling errors when creating your list of tags.

This method is recommended when the affected tags are spread across numerous OPC Client devices, making the other methods cumbersome to use.

  • Poll device: This method retrieves the data values for all the tags within this OPC Client device, as follows:
    1. Select the name of the device, from the OPC Client Devices tree on the left hand side.
    2. Click the Poll device button.

This method is recommended when the majority of the scanned tags in this device are missing data and you want to fill in these data gaps for all the affected scanned tags.

  • Poll group: This method retrieves the data values for all the tags within one or more Scan agents (scan jobs) of a specific OPC Client device, as follows:
    1. Select the name of the device, from the OPC Client Devices tree on the left hand side.
    2. Select the required Scan agent, which contains some or all of the scanned OPC items that are missing their data.
    3. Click the Poll group button.

This method is recommended when you want to fill the data gaps for a subset of the scanned tags that are contained within specific Scan agents.

Tip: Both the tags and the OPC items that they are scanned to are displayed in the right hand Items pane, when you click on a Scan agent (scan job) in the Devices tree, so that you can identify the affected tags.

  • Poll item: This method retrieves the data values of one or more specific tags that are scanned within a Scan agents (scan job) of a specific OPC Client device, as follows:
    1. Select the name of the device, from the OPC Client Devices tree on the left hand side.
    2. Select the required Scan agent, from this tree, which contains scanned OPC items that are missing their data.

    The tags (and the OPC items that they are scanned to) are displayed in the right hand Items pane.

    1. Select all the tags, whose data values are missing.

    Tip: Hold down the CTRL key and click on all the required rows to highlight them.

    1. Click the Poll item button.

This method is recommended when want to fill the data gaps for particular scanned tags.

The dialog can be closed, while the realtime catch-up of the specified tags occurs in the background on the Agent Server computer.

This dialog does not display any visible activity while this realtime catch-up of data occurs. However, a text based log file called ‘opc_cl.hda.log.txt’ is created in the Adroit installation folder of the Agent Server computer, which you can monitor for this HDA activity. The full path of this file is typically: C:\Program Files\Adroit Technologies\Adroit\opc_cl.hda.log.txt
