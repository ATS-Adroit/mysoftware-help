IO Flags

In an effort to simplify the scanning configuration, the following legacy status slots that used to affect how a slot (value) was scanned: Scan Inhibit, Output Enable and Output Initialise are no longer stored in the header of the each agent for each of its slots.

Note: The advanced header dialog no longer displays these statuses and putslots to these status bits are also disabled.

Instead these settings are now stored in the scanning configuration of the Device agent in the Agent Database (.wgp) file along with the other scanning related settings, such as the scan address, scan rate etc, as an IO flags setting. Hence the Tag Scanning Configuration dialog contains an IO flags column in the list of scanned tags.

Note: There is no slot that contains these IO flags, since they are now stored in the tag list of scanned values of a Device agent.

When loading a Agent Database (.wgp) file from a previous version of Adroit, Adroit 10 uses the saved status bit information to configure the IO flags setting of all the Device agents and when the Agent Database (.wgp) file is saved then these status bits are switched OFF in the Agent Database (.wgp) file. Therefore Adroit 10 Agent Database (.wgp) file are NOT backwardly compatible!

IMPORTANT: When starting the Adroit 10 Agent Server for the first time and loading a Agent Database (.wgp) file from a previous version, devices will most likely NEVER show healthy once all the devices are started. You need to save the Agent Database (.wgp) file FIRST and then restart the Agent Server and then you should see all the devices going healthy.

The IO flags setting is a bit mask as follows:

Value Bit Description Default  
1 0 Input disabled ON

supercedes the legacy statusScanInhibit flag at the agent and slot level.

Any legacy WGP file that has the statusScanInhibit flag set, will force Bit 0 OFF.

Note1: This setting is the INVERSE of the Input disabled (Scan inhibited) checkbox, when scanning a tag.

Note2: You can still use the statusScanInhibit header slot of an agent to prevent any configured scanning of the agent from occurring.

2 1 Output enabled OFF

supercedes the legacy statusOutputEnable flag at the agent and slot level.

Any legacy WGP file that has the statusOutputEnable flag set, will force Bit 1 ON.

Note: This setting is enabled by checking the Output enabled checkbox, when scanning a tag.
4 2 Output initialise OFF

supercedes the legacy statusScanInitialise flag at the agent and slot level.

Any legacy WGP file that has the statusScanInitialise flag set, will force Bit 2 ON.

If this bit is set, an initial value will be scanned out from the agent at startup, or after any communications failure and subsequent recovery.

Note: This setting is enabled by checking the Output initialise checkbox, when scanning a tag.
8 3 Demand scan OFF New functionality – requires that the global configuration for demand scanning is enabled and that the currently selected device driver type supports demand scanning.

The IO flags setting is a sum of the values whose associated bit is ON. So for a newly scanned tag, the default of bit 0 (enable reads) applies, in which case IO flags is 1. If bit 0 (enable reads) and 2 (output initialise) are ON then the IO flags is 5 (1 + 4).

For more details on demand scanning, see Demand Scanning.
