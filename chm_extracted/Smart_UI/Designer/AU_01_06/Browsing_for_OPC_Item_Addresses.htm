Browsing for OPC Item Addresses

Typically, when using the OPC clientan application that uses the data provided by an OPC server. driver, the browse button next to the Address field in the scanning dialog is enabled and when clicked, the OPC Browser is automatically launched. This utility allows you to browse for and select the required address of an OPC item in an OPC server.

Example:

This application does not inherently support a connection to a remote OPC server. Click for more details:

This ONLY occurs if the remote OPC server has been configured as a valid Adroit device, in which case you can launch this program as follows: OPCBROWSER.EXE /d:devicename.

This allows you to keep the browser open after browsing in a scan-tag, avoiding the time needed for the browser to open each time.

Note: The speed of browsing is a function of the OPC tag database size and the OPC server itself, not the browser.

How to use this OPC Browser to obtain an OPC Item Address:

  1. Before the OPC Item Browser for all OPC Servers is displayed, it connects to all the local OPC Servers, and any remote OPC Servers specified in the device’s configuration, that are running

Note: If no OPC Servers are running then the OPC Item Browser will not open

  1. Once the OPC Item Browser for all OPC Servers is displayed, the required OPC Server can be opened in the left pane and the configured tree structure can be browsed.

Tip: Use the Esc key to abort the current browse operation.

The right windowpane displays all the configured items that exist for the currently selected branch of the tree in the left windowpane.

Tip: When browsing OPC Servers with large lists, use the Filter list box to limit the displayed items and easily locate the required item.

  1. When an OPC itema string, uniquely describing an individual data element residing in an OPC server. It may be up to 80 characters long, and structured hierarchically typically using a period "." to separate each level. is selected (highlighted), the status bar is filled with the data pertaining to it.

Note: The Detail mode in the browser has been enhanced for use with certain OPC Servers.

Tip: Check the Persistent checkbox to save and restore the last selected OPC item between browser sessions. So that it is no longer necessary to re-browse for it, when the OPC Browser is displayed again.

  1. To select an item in the right windowpane, double click on the required item.

This places the selected item into the third windowpane and copies this fully qualified path of this item to the clipboard.

  1. If necessary, paste this item address into the required field of the dialog.

Tip: Use the CTRL+V keyboard shortcut to paste this item address.

  1. Continue the scan procedure as usual. For details, see How to Scan a Tag.

WARNING: Registry settings are recorded as ADVANCED information and should not be used unless you understand exactly how these will affect the operation of your Adroit  installation, IF YOU HAVE ANY DOUBTS, PLEASE CONTACT Adroit SUPPORT, BEFORE CHANGING THE REGISTRY.

PLEASE NOTE: When working on a 64 bit operating system, remember to add "\Wow6432Node" to the path of each registry setting after "\SOFTWARE", for instance: "HKEY_LOCAL_MACHINE\SOFTWARE\Wow6432Node\Adroit Technologies".

Add the following DWORD registry key to improve the speed of retrieving information from certain slow OPC servers: HKEY_LOCAL_MACHINE \Software\Adroit Technologies\Adroit\OPC Browser\DisableItemProperties and set its value to 1.
