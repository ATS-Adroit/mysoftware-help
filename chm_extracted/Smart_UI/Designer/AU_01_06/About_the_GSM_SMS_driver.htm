About the GSM_SMS driver

The sole function of the GSM_SMS driver is the sending and receiving of SMS messages to and from SMS GSM modems. This driver has been specifically designed to simply its use with any cellular SMS protocol. For this reason, Windows drivers for the modem are NOT required, since this driver provides its own interface to the modem via the serial port assigned to it.

Note: This driver is ONLY designed to work with SMS GSM modems and, in particular, has been designed and tested using the WAVECOM WMOD2 GSM modem.

The devices configured for this driver, can be used in one of following two modes, depending upon the configuration of its Use with Command Agent checkbox setting:

Note: For details, concerning the configuration of devices, see Configuring Devices.

  • If checked, the default setting, this device can only be used by a Command agent, which bypasses the scanning sub-system, so that the full SMS message of up to 160 characters can be utilised.

In addition, the Command agent provides extensive functionality for both sending and receiving SMS messages. For further details, see Command Agents.

  • If unchecked, this device uses the scanning sub-system, as normal, replacing the former User-driver functionality, which was also difficult to configure, of sending 79 character SMS messages, configured in the Text, String or Notifier agents.

Therefore the Notifier agent can still be used to automatically route alarms from Adroit by SMS to the relevant personnel. For details, see Notifier Agents.

Note: The driver only handles the transmission of the intended message, which can originate as an alarm, a message entered by an operator or via programming performed in Adroit.
