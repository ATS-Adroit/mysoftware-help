Scanning Overview

Scanning in Adroit refers to the sending of or the communication of values between Adroit tags (agent.slot) and the front-end devices in the field, such as a PLCa Programmable Logic Controller or programmable controller is a digital computer used for the automation of industrial processes., RTUan Remote Terminal Unit is a device installed at a remote location that collects data and transmits this data back to a central station, or master. etc.

Since each front-end device can use a different protocola set of rules or conventions governing the exchange of information between a computer and a front-end device. or language for communication, Adroit has developed a drivera DLL that interfaces Adroit to front end devices, these are the only Adroit components that are device specific. for each of these different protocols, which allow Adroit to communicate to these front-end devices by adding and configuring a for each. For further details, see Understanding Protocols and Protocol Drivers.

Once installed, a protocol driver provides the protocol or language to communicate to front-end devices that use this protocol. However, it is necessary to add a deviceadded to an installed protocol driver to communicate using this protocol to a specific front-end device - in other words a logical connection to this FED. for each front-end device through which the communication actually occurs. Each device is essentially a logical connection to the front-end device that it is communicating to. For further details, see About Protocol Drivers.

NASA, stands for New Adroit Scanning Architecture and describes a sub-class of protocol drivers that are specifically written to take advantage of the scanning improvements and enhancements provided by NASA, such as demand scanning and highly optimised scan tasks. For more details, see Demand Scanning.

In other words, while the installed protocol driver is the language that needs to be communicated, the devices are the actual translators that use this language to communicate between the front-end devices and Adroit.

As any translator needs to be able to communicate to and speak the language of each party in order to correctly translate, the device needs to be configured in the following TWO locations, to ensure this:

  1. Front-end device communication, this is performed by the ‘device’ that is added to the required installed protocol driver in the Adroit Configuration Setup utility. For details, see Adding Devices.

This ‘device’ is then configured to communicate to the required front-end device, according to the protocol-specific requirements laid out in the documentation installed with this Adroit protocol driver. For details, on displaying this documentation, see Display Protocol Driver Documentation.

  1. Adroit communication, this is performed using an associated Device agent, which is ONLY added to the Agent Server, when a ‘device’ (see step 1) is selected to communicate or scan a value within Adroit. For details, see Device agents.

This Device agent configures the communication settings of the required values (agent.slot), through the use of Scan agents which it dynamically creates, configures and deletes, as needed. It is also able to stop, start and configure the communication settings of its associated ‘device’ too.

PLEASE NOTE: If a front-end device is off-line, un-available or disconnected, then its associated device should be stopped, since Adroit will continue to attempt to resume communications and this will impede the adding and removing of Adroit tags to or from its Device agent.

It is also recommended to stop the Device agent when adding, importing and removing more than one scan-point. For details, see Starting or Stopping Devices.

Note1: If the agent is being scanned from a remote UI, ensure that the necessary additional requirements have been met. For details, see Remote Scanning Configuration.

Note2: You may use as many different protocol drivers and devices as you wish, until the sum of their scanned points exceeds your licensed number of scan points. For details, see Scan Points.
