Scanning Deadband Configuration Tips

A significant change or noise filter can be specified in the Deadband field when a tagA fully qualified named value in Adroit (agentName.slotName). is being scanned to a FEDfront-end device, which is a device that is accessed directly by the user, such as a PLC or RTU..

Any change in value less than this deadband limit will not be used to update this tag’s value. For details on scanning tags, see How to scan a tag or Scanning tags for general scanning information.

The purpose of applying a deadband is to reduce the amount of internal updating of this value within the Adroit database (such as its related alarming, client UI updates and datalogging) in order to conserve PC resources.

Note: This does not affect the usage of the commmunication channel itself, since it is performed after the data has arrived.

Please consider the following recommendations when configuring this deadband:

  1. Ensure that the deadband is specified in the same units as the slot of the agent being communicated.
  2. The deadband operates best when used to filter out noise or minor variations in value from an integer or analog value that you do not need to see in Adroit.

For instance, when using a 12 bit A/D input with 1 bit noise, then use a dead-band of 2.

Also when measuring a level on a vessel or item that changes due to vibration, waves or instability, then specify a deadband only slightly greater than the amount of variance.

  1. Do not use a deadband when scanning slots containing state information, as you may lose significant bits of information when decoding to binary format.
