Bulk Scanning or Scanning Import

Instead of using the Tag scanning configuration dialog to configure the scanning of a large number of tags (agent.slot) for the same device, it is also possible to scan a single tag, export the scanning configuration to a spreadsheet application, perform the required bulk configuration and import this configuration.

Note1: This method is ONLY recommended when adding more than 100 scan points to the same device:

Note2: Check that your communications are working before and after the importing of the scan points.

  1. Backup your Adroit database file (.WGP). For details, see Backing Up Adroit Database Files.
  2. Scan at least one tag (agent.slot) to the required device.
  3. Export the Device agent type, i.e. click the No button for all the other preceding agent type message boxes.
  4. In the Choose file to contain conversion dialog, select the location to save the Device agent files, it is recommended to leave this as the default location of the Adroit system folder, typically C:\Program Files\Adroit Technologies\Adroit and save the ‘Device.CSV’ file, then save the scan files for each of the device agents, of the name format DeviceName-SCAN.CSV, where DeviceName is the name of the Device agent.
  5. When the next agent type message box is displayed, click Cancel, to stop the exporting process.
  6. In either a CSV or text editor, open the DeviceName-SCAN.CSV, where DeviceName is the name of the Device agent that the tags have been scanned to. This file will contain four columns or comma-separated values, from left to right as follows:

Address, agent.slot, Scanning Interval (period), Deadband

Note: These fields are identical to those displayed in the Currently scanned tags list, when adding a scanning a tag. For details, see Scanning Example.

  1. Add the agents and their slots that are to be scanned, their required scan addresses and if necessary the required periods and deadbands.
  2. Save and close this CSV file.
  3. Edit the required Device agent.
  4. Stop this device agent.

Note: If the DeviceName-SCAN.CSV contains only new scan points, skip the following step.

  1. Remove all the scan points from this device.
  2. Click Import… button and browse in the required Devicename-SCAN.CSV file, where DeviceName is the name of the selected Device agent.

Note: If messages are displayed during the importing of this scanning configuration, see Common Reasons for Scanning Import Failure for the possible reasons.

  1. Start this device agent.
  2. Verify that the communications are still fine and all I/O tags work as expected.
  3. Save your Adroit database file (.WGP) again and finally perform a full test by restarting the Agent Server to verify proper loading etc.
