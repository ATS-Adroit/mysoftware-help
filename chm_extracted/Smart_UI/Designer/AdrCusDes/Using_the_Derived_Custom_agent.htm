Using the Derived Custom agent

Once the derived custom agent has been configured and published.

Start the Agent Server.

If the agent has been configured and published correctly, this Agent Server window should include this derived custom agent in the list of loaded agents.

Example:

For the DriveXYZ agent, this Agent Server window, should appear as follows:

  1. Start the Adroit user Interface and open the Configurator, add this derived custom agent to either the Basic, Advanced or System agent group.
  2. Select the new agent type, add a new instance of this agent and edit this derived custom agent type.
  3. Test that this derived custom agent works correctly.
  4. Having confirmed that this derived custom agent works correctly, save the WGP file, restart the Agent Server, reopen this configuration dialog to ensure that the values for the configured slots have been saved correctly.
