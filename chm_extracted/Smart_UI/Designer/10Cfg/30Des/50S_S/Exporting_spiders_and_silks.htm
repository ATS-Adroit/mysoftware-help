Exporting spiders and silks

Instead of manually configuring spiders, silks and their template sets in the spider workspace, you can also bulk configure them - by using the export and import configuration menu commands. Click for more details:

The Export Configuration spider workspace option can export the current spiders and/or silks configured within a spider workspace to a Microsoft Excel XML file.

This exported configuration can be viewed and/or edited in a compatible XML Spreadsheet program such as Microsoft Excel and re-imported later into this or another spider workspace. For details, see Importing spiders and silks.

WARNING! All NAMES are CASE-SENSITIVE. Therefore ENSURE that the CORRECT case is used when editing the exported file, otherwise they may NOT be recognised when IMPORTED.

Note: It is not necessary to save the spider workspace before exporting its spiders and/or silk configuration.

Tip1: This exported Microsoft Excel XML file can be used to quickly add a large number of silks on different template sets to different spiders and to quickly view and edit all the spiders’ configurations in a single spreadsheet.

Tip2: To add an imported silk to more than one template set, , separate the different template set names with semi colons ";".

To export the spider and/or silk configuration from a spider workspace:

  1. If necessary, open the required spider workspace.
  1. either press the Export Configuration toolbar button, from the spider workspace toolbar.
  1. or right-click the spider workspace and select the Export Configuration menu item.
 

This displays the Export Configuration dialog of the Export Wizard.

  1. Specify the full path and name of the exported XML file, as follows:
  1. EITHER type this in manually, in which case, ensure that the specified path, file name and (.XML) extension is correctly specified.

Note: Failure to specify the .XML extension will not affect the import functionality, although may require this file to be manually opened.

  1. OR select the browse button to the right of the edit box and browse for the required folder and either type in a new file name or select an existing XML file to overwrite it.

Note: If the specified file already exists, it will be overwritten.

  1. Select the configuration that should be exported from this spider configuration, by checking or clearing the following checkboxes:
  1. Export Silk configuration: If checked, this will export all the silks that have been configured within this spider workspace to link all data elements, spiders and properties. This also exports the template sets that have been configured too.

Note: If the spiders do not exist when re-importing the silk configuration, then the import utility will attempt to re-create them and will also provide further notification of any manual configuration required with regard to their inputs and outputs and of any spiders that could not be imported.

  1. Export Spider configuration: If checked, this will export all the spiders that have been added to this spider workspace, both manually and automatically. 
  1. Click the Next button to export the selected configuration to the specified .XML file.

Note: Microsoft Excel locks spreadsheet files that are currently open, which prevents them from being exported to. Therefore ensure that the specified file is closed in Microsoft Excel before exporting this spider and/or silk configuration to it.

This will display the Export Results dialog of the Export Wizard.

  1. If the specified file was successfully exported, this displays a hyperlink of the specified full path and name of the .XML file containing the exported silk and/or spider configuration.

Note: Selecting this hyperlink will open the program currently associated with the .XML file extension, provided this extension was specified. If you have a newer version of Microsoft Excel installed, then Microsoft Excel will open this file.

If the specified file could not be exported, the error(s) that occurred during the export process will be displayed, such as: an invalid or nonexistent path; the file is read-only; the file was locked by another application or the file denied writing to it etc.

  1. Either select Previous, to change the name and/or path of the .XML file or to modify the required configuration that should be exported or select Finish to exit the Export Wizard.
