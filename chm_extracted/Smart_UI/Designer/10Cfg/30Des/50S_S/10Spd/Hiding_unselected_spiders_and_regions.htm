Hiding unselected spiders and regions

Use the Hide Unselected Spiders/Regions spider workspace display option to simplify an otherwise cluttered spider workspace.

Click here for more information:

In addition to hiding ALL the unselected spiders and regions directly associated with the currently selected spider or region or form component, there are 3 other selective hiding filters.

For instance, consider a scenario when Alias spiders are in conjunction with Variable Data Element spiders to connect the required data elements, so most of the spiders would be connected.

Note1: When a spider is located or manually selected in the spider workspace, with this option enabled, then only it and the spiders that it is connected to will be displayed, in accordance with the currently specified hiding filter. For details, see Finding spiders.

Note2: If the graphic form itself, is selected, then all the spiders which are connected by silks to properties of this graphic form and its form components will be displayed. But any standalone spiders or spiders which are not connected to any form components will not be displayed, such as Script Engine spiders.

Note3: This does NOT display spiders that are triggered by the events of the selected form components.

Note4: All the selective hiding filters, add a watermark to the right hand bottom corner of the spider workspace indicating which selective hiding filter is being applied.

Tip: Click the Hide Unselected Spiders/Regions toolbar button to apply the currently selected hiding filter to the spider workspace.

 

To hide all spiders/regions not directly associated with the selected item: In other words this shows all the upstream and downstream spiders/regions that are linked to the inputs and outputs of the currently selected control/spider/region.

  1. If necessary, open the required spider workspace.
  1. If necessary, select the required form component, spider or region.
  1. Right-click the spider workspace and open the Hide Unselected Spiders/Regions menu and ensure that there is a tick mark to the left of the All item.

To also hide all spiders/regions connected to the outputs of the selected item: In other words this shows all the spiders/regions that are linked to the inputs of the currently selected control/spider/region and all the spiders/regions that these spiders/regions are connected to (all the upstream spiders/regions).

  1. If necessary, open the required spider workspace.
  1. If necessary, select the required form component, spider or region.

Tip: If you want to select more than one spider or region, hold down the CTRL key to multi-select.

  1. Right-click the spider workspace and open the Hide Unselected Spiders/Regions menu and ensure that there is a tick mark to the left of the Show Incoming item.

Tip: Hold down the CTRL key to select spiders or regions without applying this hiding filter.

To apply a hiding filter to more than one spider/region at a time: This allows you to view the spiders/regions associated with more than one spider/region at a time.

  1. Hold down the CTRL key and select the spiders/regions that you want to view.
  2. Then apply the currently selected hiding filter (by clicking the Hide Unselected Spiders/Regions toolbar button).

To select a spider/region without applying the currently configured hiding filter: This allows you to configure one or more of the displayed spiders/regions without hiding the others.

  1. Hold down the CTRL key and select the required spider/region.

 

To turn off the Hide Unselected Spiders/Regions filtering: In other words this shows all the spiders/regions that are currently configured in this spider workspace.

  • Either: click the Hide Unselected Spiders/Regions toolbar button to disable this option.
  • Or: Right-click the spider workspace and open the Hide Unselected Spiders/Regions menu and ensure that there is a tick mark to the left of the None item.
