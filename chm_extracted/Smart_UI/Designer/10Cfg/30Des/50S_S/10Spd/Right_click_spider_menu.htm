Right click spider menu

Right click the spider title bar to display the following configuration items and spider-specific items too:

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: To display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: You can also double-click the title bar.

  1. Trigger Spider From Event: A spider should triggerthe action of causing a spider to perform its specific operation, which usually involves communicating and / or manipulating data from its set of inputs to its set of outputs. See spider. from an event if it is required to perform its function based on user input e.g. if the button is clicked or when an action of another spider is performed e.g. if an input of a spider changes. For details, see Triggering a spider from an event.

  1. Enable Silk Triggering: This is the default method of triggering spiders, which occurs when one of the input values change this spider.

    This can disable this method for all the inputs of this spider, which is typically required if this spider is ONLY required to use some other form of triggering. For details, see Triggering spiders. 

Note: It is recommended to use silk triggering when transferring data between spiders instead of event triggering.

  1. Propagate Outputs At Startup: This property is only intended for spiders that do not have any inputs to improve the speed of starting up the spiders in this workspace. For details, see Sending spider outputs at startup. 

Note: All spiders that need to first calculate their initial output values would typically have this option turned off.

  1. Trigger Now!: A design-specific facility to immediately trigger this spider, instead of waiting for it to be triggered normally.

Note: Triggering only occurs when the spider workspace is running.

  1. Copy/Paste: This can be used to duplicate an existing spider, which includes copying its configuration. For details, see Copying and pasting spiders.

Tip: Instead of using the Delete Spider option to delete this spider, simply select the required spider and press the DELETE key.

Note: The spider workspace provides visual indicators for the following three options. For details, see Spider property indicators.
