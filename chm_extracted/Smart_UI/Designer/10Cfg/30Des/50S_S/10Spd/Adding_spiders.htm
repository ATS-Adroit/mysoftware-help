Adding spiders

You typically need to add a spider to the spider workspace so that you can connect it to other spiders and then trigger it so that it can perform its function. Click for more information:

To make it easier to select the required spider, spiders are organised into a number of categories. For details, see Available spiders

Data spiders (data elements and/or properties) are typically added automatically. For details, see Data spiders.

Note1: You can also duplicate an existing spider, which includes copying its configuration. For details, see Copying and pasting spiders.

Note2: In addition to manually configuring spiders and silks, it is also possible to perform bulk configuration, by exporting and importing this configuration. For details, see Importing spiders and silks.

To add a spider to the spider workspace:

  1. If necessary, open the required spider workspace.
  2. Add the required spider(s) using one of the following methods:

The toolbar: this can add more than one spider at a time.

By default, the spider workspace toolbar is located at the top of the spider workspace, although it can also be docked alongside the other toolbars below the menus of the Designer.

  1. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the New Spider toolbar button to display the tabbed spider selection pane at the top of the spider workspace.

The tabs represent the various spider categories, which are listed in alphabetical order.

  1. Select the spider category tab that contains the required spider(s).

Tip: Select a spider to display a brief description, at the bottom of this spider selection pane, regarding its usage. 

  1. Drag the required spider(s) onto the spider workspace.

An instance of each spider will be added to the spider workspace, displaying its distinctive icon beneath its title bar.

Tip1: The title bar is generally used when interacting with and configuring the spider.

Tip2: You can add a spider to the top left corner of the spider workspace by double-clicking it.
If more than one spider is added in this way only the last spider that is added will be visible, unless the spiders are rearranged.

  1. If necessary, select another spider category tab and also drag the spider(s) onto the spider workspace.

Note: This spider selection pane can be closed by pressing the New Spider toolbar button again.

The right-click menu: this can only add one spider at a time.

  1. Right-click the spider workspace and select the Create New Spider menu.

This displays a menu listing the available categories and their spiders.

  1. Navigate this menu and select the required spider.

An instance of this spider will be added to the spider workspace, displaying its distinctive icon beneath its title bar.

Tip: The title bar is generally used when interacting with and configuring the spider.

Added spiders are given default names, created by appending a unique number to the end of the name of the selected spider.

For instance "Constant3", if two Constant spiders called “Constant1” and “Constant2” already exist or have been removed from the spider workspace after it was last saved. For details, see Saving spider workspaces.
