Working with spider configuration views

Once a spider has been added to a spider workspace, it can be further configured through the use of its right-click menu and configuration view.

The configuration view of a spider can perform the following functions:

  • To add a description of its function and/or to rename the spider
  • To configure the required input(s) and output(s) of the spider.
  • To create silks to and from this spider.
  • If necessary, to configure the event used to trigger this spider.

This configuration view of a spider can be displayed or hidden, either individually or for all the added spiders, as required.

Note: When configuring this view a tool tip describing each of the configured inputs and/or outputs is displayed when you point over them.

This configuration view always contains the following fields:

  1. The first field, below the title bar of the spider, displays the name of the spider, which can usually be changed. For details, see Renaming spiders.

Note: The name of a Data spider cannot be changed.

  1. The second field is the description field, where you are able to add additional comments or reminders for future reference.

    This description is also displayed, along with the spider’s name, by the tool-tip text whenever the mouse pointer hovers over the title bar of a spider. For details, see Annotating spiders.

This configuration view, will contain at least one of the following sections:

Note: The type of spider that is selected, and the function that it performs, will determine which of these sections will appear. For details, see Available spiders.

  1. The Inputs section: this contains a list of inputs that have been configured for the spider.

Note1: If no inputs are configured for the spider, this section will not appear.

Note2: These inputs can either be configured within the spider itself and/or may require their values to be supplied by other spiders or Data spiders (e.g. properties or data elements).

  1. The New Input section: this contains a list of input types, which can be used to create custom inputs for the spider. For details, see Creating customised spider inputs.

Note: If this functionality is not supported for the current spider, this section will not appear.

Tip: When creating a silk, it is also possible to simply drag directly onto an input type, in the New Input section, to add an input to the Inputs section and connect it to the silk in one easy step. For details, see Creating silks.

  1. The Outputs section: this contains a list of outputs that have been configured for the spider.

Note1: If no outputs are configured for the spider, this section will not appear.

Note2: A silk can be connected from each configured output to supply the inputs of other spiders or Data spiders (e.g. properties or data elements), although this is not always desired.

Tip: If an output of a spider does not provide the necessary data type, you can convert it to the required data type and use this converted value instead. For details, see Converting output data types.

  1. The New Output section: this contains a list of output types, which can be used to create custom outputs for the spider. For details, see Creating customised spider outputs.

Note1: If this functionality is not supported for the current spider, this section will not appear.

Note2: The output name of a spider is case sensitive.
