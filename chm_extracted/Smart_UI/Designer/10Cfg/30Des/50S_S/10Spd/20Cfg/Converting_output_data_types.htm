Converting output data types

If an output of a spider does not provide the necessary data type, you can convert it to the required data type and use this converted value instead. 

For instance if the spider produces a numerical output which you want to display this as a string, you can now convert it to a string and apply string formatting too and then use this converted value instead.

The following type conversions are possible, depending on the data type of the selected output:

  • Double: Typically used to convert integer into a floating point value in order to perform number formatting. This does not provide any further configuration options.
  • Drawing point: Typically used to configure any property that accepts X and Y coordinates, such as the Location property of a control. This does not provide any further configuration options.

Note: Your output must have the same format as a point, by providing both X and Y coordinates e.g. {x=0,y=5}.

  • Boolean: Typically used to convert floating, integer or String values when a Boolean value is required. This does not provide any further configuration options.
  • String: Typically used for displaying numerical or date time values in Text properties, such as in TextBox controls. This provides optional string formatting. See below for procedure.
  • Integer: Typically used to convert floating point values into integers. This does not provide any further configuration options.

To add a type conversion for an output

  1. Open the required spider workspace.
  2. If necessary, display the configuration view of this spider by double clicking its title bar.
  3. In the Outputs section, right click the required output and select the required conversion from the ConvertOutput menu.

Note: The available conversions depend upon the data type of the selected output.

This adds the selected conversion in the line immediately below this output.

  1. If this conversion type supports additional configuration options these can be displayed by double clicking the conversion.

String formatting configuration: to format this string value accordingly. For instance to specify how the decimal digits should appear or how what elements of a date time should be displayed and how.

  1. Double click the required String conversion.
  2. Check the Add String Formatting checkbox in the Conversion configuration dialog.
  3. Add the required format string to the Format edit box, as follows:
  • Double click one of the provided formatting options in the Format dialog to add this automatically.
  • Manually specify or edit this format string.
  1. If necessary, press the Test button to see how the specified test Value appears when using the specified Format string.

For further details and examples of creating format strings, see String formatting syntax.

  1. Click the Finish button once you have the required format string.
  1. If necessary, connect the output as required.

Note: Once a conversion is created for an output this converted value is used and not the raw output value.
