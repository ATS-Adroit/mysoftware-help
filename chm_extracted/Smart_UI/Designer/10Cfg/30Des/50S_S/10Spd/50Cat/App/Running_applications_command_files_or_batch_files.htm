Running applications, command files or batch files

Specify the required application (.EXE), command file (.CMD) or a batch file (.BAT) and/or any command-line parameters that need to be specified, if required.

To run an application, command file or batch file:

  1. If necessary, add and/or select the required Execute Command spider and/or open its configuration view. For details, see Adding Execute Command spiders. 

In the Inputs section:

  1. Click the browse button to the right of the Browser input.

This will display the Select Application... dialog, to assist in locating the required file that will be executed when this spider is triggered, as follows:

Note1: Use the Files of type list box to specify which file type you are browsing for (*.EXE, *.CMD or *.BAT).

Note2: If necessary, use the provided help for assistance in navigating to the required file.

  1. Once the required file has been located, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Open button to close this dialog.

The Output output, of this spider, will now specify the full path and name of this browsed in file, which will be executed when the spider is triggered.

Note: Instead of manually browsing in a file, it is also possible to drag a text or string value, which contains the full path and name of the required file, to the Browser input via a silk.

In this way it is possible to change the application that is being executed remotely. For details, see Creating silks.

  1. If required, specify the required command-line parameters in their required format, that need to be specified in the Parameters input e.g. if using MS Word to open a document include "" around document names with spaces etc.

Note: These parameters can either be typed in manually or it can be specified by another spider or Data spider (e.g. property or data element) via a silk.

Tip: When typing the parameters manually, double-click the value column to the right of the Parameters input name in the Inputs section and type in the required parameters.
