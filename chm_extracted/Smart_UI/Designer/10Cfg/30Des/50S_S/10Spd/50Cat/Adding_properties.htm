Adding properties

The Property spider allows you to connect a data element or another property to the required property of the selected graphic forma document that belongs to a project, which can be designed to graphically display data to the user and to accept input from the user when it is being operated. or form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form..

Sometimes you can also expose one or more of the sub-properties of a property as additional inputs (readable properties) and/or outputs (writable properties) for this spider.

To expose additional properties:

  1. Select the required Property spider. For details, see Selecting spiders.
  2. Right-click its title bar and select Add Properties.

The Properties configuration dialog is displayed to expose one or more of the properties.

Note: For details concerning the navigation and use of configuration dialogs, see Working with configuration dialogs.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the checkboxes of the required properties, so that they are ticked .

Note: Do not click on the names of the properties themselves.

  1. Click the Finish button to add these selected properties to the spider.
