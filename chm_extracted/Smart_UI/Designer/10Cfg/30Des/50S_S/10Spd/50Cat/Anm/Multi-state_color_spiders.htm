Multi-state spiders

The Multi-state spider defines colors that provide a visual indication of the current value/s of either String, Double or Integer value/s. Click for more details:

This is achieved by creating more than one “state”, which simply associates a particular color with either a specific string or value or a range of numeric values or a logical result when comparing one or more input values.

When the monitored String, Double or Integer input value/s corresponds to the criteria of a defined state, the spider returns the associated color; thereby providing a visual indication of the value/s.

This spider can configure color properties of graphic forms and their form components.

Note1: These states are processed in order from top to bottom, until the first match is found, after which the remaining states are ignored.

Note2: The Boolean Operator SetOutputcolorEvenIfNotChangedconfig setting is disabled (set to FALSE) by default to ensure that Multi-state color spiders ONLY set their output colors when this output color has changed from the last time that this spider was triggered.

This is required to prevent high CPU loads for graphic forms using a large number of Multi-state color spiders and/or color behaviours using the Multi-state\Blink mode.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Value

String, Double or Integer

This value of this String, Double or Integer is monitored and it determines the color of the color output.
  1. New Input, this section contains the input types configured for this spider.
New Input Function

New State

This will open the Enter a State dialog, to either specify the required String value or the required range of Integer or Double values. For details, see Creating states.

Note: These states can also be removed from this spider. For details, see Removing states.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

color

color

The color of this output is determined by the current value of the Value input, as follows:

  • For String values: if the current value matches any of the specified states then this output is set to its associated color.
  • For Double or Integer values: if the current value falls within the range of a defined state then this output is set to its associated color.
  • If the current value cannot be matched to any of the defined states, then the output displays the default "Control" color instead.

Note1: These states are processed in order from top to bottom, until the first match is found, after which the remaining states are ignored.

Note2: The name of currently displayed color is also displayed in square brackets ("[]") to the right of the Output color output.
