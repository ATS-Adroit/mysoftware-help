Using special functions

To use a special function via the Special Function spider. Click for more information:

Note: Special function security determine which special functions are available for use, for each user. For details, see Working with special function security.

Tip: In addition to the datasource-specific special functions, this spider can also be used to: Execute queries and stored procedures added to OLE DB datasources or execute functions exposed by an XML Web Service.

To use a special function

  1. If necessary, add and/or select the required Special Function spider and/or open its configuration view. For details, see Adding Special Function spiders.

In the Inputs section:

Note: This spider will not triggered in design time when its input values are changed. 

  1. Open the Servers list box, to display the list of available SmartUI Servers.

Tip: Use the Default Server selection, where possible, when referring to datasources on the login SmartUI Server to simplify the importing of this spider. Otherwise this Server input will need to be reconnected after this spider has been imported.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the SmartUI Server, which contains the required datasource.
  2. Open the Data Source list box, to display the list of available datasources on this SmartUI Server.
  1. Select the datasource, whose special function you would like to use.

Note: When a datasource is selected that populates the Function list box, the Outputs section will appear.

  1. Open the Function list box, to display the list of the names of all the special functions provided by the datasource that has been selected in the Data Source list box.

Note: The security permissions assigned to the currently logged on user will determine which special functions, if any, he/she is able to view and to use. 

  1. Select the specific special function that you require.

If this selected special function requires parameters to be provided by the user, these will be added as additional inputs to the Inputs section.

If this selected special function produces an output, then connect the Return Object output to the required destination, via a silk. For details, see Creating silks. 

Note: The Outputs section also contains the Boolean Success output, which displays the result of the execution of this special function. 

This spider will perform this selected special function, whenever it is triggered. For details on triggering spiders, see Triggering spiders.
