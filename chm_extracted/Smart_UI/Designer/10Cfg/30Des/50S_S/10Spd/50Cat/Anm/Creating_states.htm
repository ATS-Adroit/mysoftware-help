Creating states

Define the required “states” , each of which associate a particular color with either a specific string or value or a range of numeric values or a logical result when comparing one or more input values.

When the monitored String, Double or Integer input value/s corresponds to the criteria of a defined state, the spider returns the associated color; thereby providing a visual indication of the value/s.

To create a state:

  1. If necessary, add and/or select the required Multi-state color spider and/or open its configuration view. For details, see Adding Multi-state color spiders .
  2. Double-click the New State entry, in the New Input section.
  1. Specify the criteria that must be met for this state in the Enter a State dialog, as follows:
    1. For String values, specify the required text value that the default Value input or additional input (i1 etc.) must match exactly, for instance "True" or "False" for boolean values.

    Note: Do not specify the required name of this state within quotes.

    1. For Integer or Double values, specify the range of values that the default Value or additional input (i1 etc.) must lie within, as follows:
    2. To specify a specific range:

    connect the minimum and maximum values with ":" character, for instance: 5.5:6.5 or -20:-10.

    1. To create infinite ranges, you can use one of the following operators:

    >   for instance: >5.5.

    >= for instance: >=6.5

    <   for instance: <-20

    <= for instance: <=-10

    <> for instance: <>7

    Note: Ensure that there are NO spaces between the specified numbers and the operator characters.

    • To compare the values of one or more inputs, create a logical expression using the following Boolean operators:

    Example of a logical expression that compares more than one input values: (Value>3)||(i1<34)

    Note: If a state uses multiple inputs, these need to be added and the correct values need to be assigned to them before the state can be evaluated.

    Although these boolean operators are typically used to compare the values of more than one input, you can also use them to define states for the single default Value input, for instance: (Value>23)&&(Value!=25)

    IMPORTANT: When adding multiple “&&” , “||” and other expressions, each expression MUST be enclosed in parentheses “()” (see the examples above). If these parentheses are left out, these expressions do not evaluate correctly.

    Boolean Operator & UsageName or MeaningExamples

    “2!=3” returns true (1)

    Greater than

    “2>3” returns false (0)

    Less than or Equal

    “2<=3” returns true (1)

    “3<=3” returns true (1)

    Greater than or Equal

    “2>=3” returns false (0)

    “3>=3” returns true (1)

    ! term

     Not – Boolean inverse

    “!1” returns false (0)

    “!0” returns true (1)

    “!n” returns 0, where n is not equal to 0

    term && term

    Boolean AND

    l“1&&1” returns true (1)

    “1&&0” returns false (0)

    x&&y returns true (1) where x and y are non-zero

    term || term

    Boolean OR

    “1||1” returns true (1)

    “1||0” returns true (1)

    “0||0” returns false (0)

    x||y returns true (1) where either x and/or y are non-zero

WARNING! Ensure that the state definition is correct because you CANNOT edit it after you add it. If the state is incorrectly defined then you need to remove and then add it again. For details, see Removing states.

This adds this defined state to the Inputs section and associates it with the color White, by default.
