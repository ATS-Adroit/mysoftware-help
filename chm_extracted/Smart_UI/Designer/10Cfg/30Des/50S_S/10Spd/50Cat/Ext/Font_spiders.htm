Font spiders

The Font spider either selects a new font using the standard font dialog or modifies an existing font by independently adjusting certain font attributes. Click for more details:

For instance, by driving one or more font attributes remotely, you can create a constantly varying font to configure a font property of a graphic form or one of its form components.

Note1: The font attributes that can be individually manipulated are: Regular, Bold, Italic, Font size, Underline and Strikethrough.

Note2: The Font size can be specified by a Double, whereas only Boolean values can be used to specify the values of the Regular, Bold, Italic, Underline and Strikethrough font attributes.

  • To add this spider to the spider workspace.
  • To select a font using the font dialog.
  • To modify a font by adjusting certain attributes.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.
  1. Add Font Properties: This adds six additional inputs to the Inputs section, which can be used to modify an existing font. For details, see Modifying fonts.

Note: Once you have add these properties you cannot remove them from this spider.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Font

Font

The Font dialog box can be displayed to manually select a font by clicking the list button to the right of this input field. For details, see Selecting fonts. Once a font has been selected from this dialog, this also displays the values of the following font properties:

Name: The name of the typeface selected for the font.

size: The point size of the specified font.

Units: The index number of the unit of measure used to specify the size.

GdiCharSet: A byte value that specifies the GDI character set of the specified font.

GdiVerticalFont: A Boolean value that indicates whether this font is derived from a GDI vertical font.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

Font

Font

This contains the font that has been selected and/or the values of the added font properties. This also displays the values of the following font properties:

Name: The name of the typeface selected for the font.

size: The point size of the specified font.

Note: If the Font size attribute is remotely driven this displays the most current value, when the associated graphic form is in runtime modee.g. being previewed in the SmartUI Designer.

Units: The index number of the unit of measure used to specify the size.

GdiCharSet: A byte value that specifies the GDI character set of the specified font.

GdiVerticalFont: A Boolean value that indicates whether this font is derived from a GDI vertical font.
