Scaling spiders

The Scaling spider can specify a scaling factor to convert raw (unscaled) values into engineering (scaled) values.

If necessary you can saturatethe scaled (output) value is forced to remain within the required minimum and maximum operational range. the scaled values.

Note: This spider is only able to scale numerical values.

 

  • To add this spider to the spider workspace.
  • To add one or more raw (unscaled) values.
  • To configure the scaling factor.
  • To remove unnecessary values.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.
  1. Configure Scaling: This displays the Scaling configuration dialog to configure the scaling factor that is applied to this spider. For details, see Configuring scaling.
  2. RawMin: This adds the RawMin variable to the Inputs section, so that it can be dynamically specified, when configuring the required scaling factor.
  3. RawMax: This adds the RawMax variable to the Inputs section, so that it can be dynamically specified, when configuring the required scaling factor.
  4. EngMin: This adds the EngMin variable to the Inputs section, so that it can be dynamically specified, when configuring the required scaling factor.
  5. EngMax: This adds the EngMax variable to the Inputs section, so that it can be dynamically specified, when configuring the required scaling factor.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. New Input, this section contains the input types configured for this spider.
New Input Function

RawValue

This will add a numerical input called RawValue#  to the Inputs section and a numerical output called Engineering Value# to the Outputs section, where # is a unique number starting from 1. For details, see Adding values to be scaled.

Note1: Both this input and output accept data of type Double.

Note2: By default a scaling factor of 1 is used, although this can be changed if necessary. For details, see Configuring scaling.

Note3: These inputs and their outputs can also be removed from this spider. For details, see Removing scaled values.
