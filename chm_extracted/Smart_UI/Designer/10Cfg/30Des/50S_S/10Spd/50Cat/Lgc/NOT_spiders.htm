NOT spiders

Logic spiders can construct simple or complex logic expressions that perform tasks when TRUE. Click for more information:

The NOT spider inverses the Boolean value of its Logical Result input, which it assigns to its Logical Result output.

These logical expressions are performed by using the Logic Trigger spider to trigger one or more of the Logic spiders that are added to the spider workspace. For details, see Logic Trigger spiders or for details of the other Logic spiders, see AND spiders, IF spiders or OR spiders.

Note: These Logic spiders are provided as an alternative to writing script to perform the same functionality.

  1. To add this spider to the spider workspace.
  2. To NOT a logical expression.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is disabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.

Boolean

If this input is specified, then this Boolean value is NOTed and this result is assigned to the Logical Result output. For details, see NOTing logical expressions.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

Logical Result

Boolean

This has the inverse value of the Logical Result input.
