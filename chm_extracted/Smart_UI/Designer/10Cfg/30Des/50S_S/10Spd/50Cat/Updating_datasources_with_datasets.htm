Updating datasources with datasets

Whenever a control displays a dataset and allows its data to be modified by the end-user, it is possible to update the associated data element with these changes, if necessary. Click for more information:

Note1: This is only possible if the datasource, to which this data element belongs, is able to be updated by means of a dataset.

Note2: Since a DataGrid control both displays a dataset and allows its data to be modified by the end-user, it has been used to demonstrate this functionality. For details, see DataGrid controls.

To update the datasource with changes made to the dataset:

  1. If necessary, connect a DataGrid control to the required data element of type dataset. For details, see Connecting datasets to DataGrid controls.

Note: Ensure that this graphic form is opened and currently displayed within the Design workspace and that the DataGrid control is visible.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. this DataGrid control in the graphic form.
  2. If necessary, display the property tree by using the pane display bar on the right border of the central spider workspace pane.

In this property tree:

  1. If necessary, expand the Objects and the name of this DataGrid control.
  2. If necessary, expand the Data category beneath this DataGrid control too.
  3. Double-click the blue line to the right of the DataSource property.

This will display the configuration view of this DataSource property spider.

  1. In the Inputs section, locate the silk that is connected to the DataSource input.
  2. Navigate back along the silk until you reach its associated node in the explorer tree pane (at the left edge of this central spider workspace), if its datasource is collapsed, expand it until the required data element is in line with the beginning of this silk.
  3. Drag the DataSource output of this DataSource property spider onto this exposed data element.
  1. Save the graphic form.

Note1: This data element will only be updated, if this datasource can be updated by a dataset.

Note2: It is also possible to see if this dataset is being modified correctly, by connecting this DataSource output to the StaticDataSet within a Simulation datasource. Then add another DataGrid control to the graphic form and connect the StaticDataSet to its DataSource property too. For details, see Adding Simulation datasources or Connecting datasets to DataGrid controls.
