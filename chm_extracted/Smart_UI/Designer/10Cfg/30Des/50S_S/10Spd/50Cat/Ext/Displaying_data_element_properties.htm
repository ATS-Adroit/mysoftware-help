Displaying data element properties

To use the Extended Data Element spider to display the properties of an existing data element.

Note: This is the only way to obtain the name of a data element.

To display the properties of an existing data element

  1. If necessary, add and/or select the required Extended Data Element spider and/or open its configuration view. For details, see Adding Extended Data Element spiders.
  2. In the Inputs section, drag the required data element into the DataElement input. For details, see Creating silks.
  3. Ensure that spider workspace is running (e.g. that the associated graphic form is in preview mode in the SmartUI Designer) and trigger the spider.

This populates the other inputs and outputs with the properties of this data element, which are described as follows:

Input / Output Data Function

DataElement

DE

The data element that contains the value specified in the Value input.

Name

String

The fully qualified namespace of the data element.

Separator

Character

The character(s) used to separate the sub-names within the namespace of this data element specified by the Name input.

SeparatorCount

Integer

The number of the occurrences of the separator character in the Name.

ShortName

String

The last of the sub-names within the Name input i.e. the leaf node.

ServerName

String

The first of the sub-names within the Name input i.e. the root node.

Formatter

String

This may specify the default format for the Value, which is recommended by its datasource.

Value

variant type:Object

The latest data provided in the data element.

Timestamp

DateTime

The date and time at which the value of this data element was last updated.

Status

VIZNET Status Enumeration

This specifies whether the value of this data element was able to be successfully read or not i.e. either GOOD or BAD, which could also indicate that the connection was lost.

Dirty

Boolean

This essentially specifies whether the value of this data element has changed, either True or False. If Dirty is True, then the value of the data element has changed and, when applicable, the SmartUI Server has also not yet saved this value.

Error

Object

The error object, detailing the last error experienced by this data element.

Note: This is not immediately accessible, if necessary use the Reflection spider to expose its properties. For details, see Reflection spiders.

CheckSerializable

Boolean

This specifies whether this data element can be communicated or not i.e. either Yes or No.

Save

Boolean

This value is either Yes or No is used as a flag by the SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. or Server to instruct its components (e.g. a Server datasource or UI control) as to whether they must save this value or not.

It is the responsibility of the user of the data element to set or use this flag.
