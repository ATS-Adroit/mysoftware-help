Summation spiders

The Summation spider can add and/or subtract numerical values. Click for more details:

The spider adds the amounts to be added and the amounts to be subtracted to create totals of each. The final total is calculated by subtracting the added total from the subtracted total.

This spider can ONLY add and subtract NUMERICAL values.

If a string value is supplied then the spider will try to convert the string value to a number before using it. If it cannot be converted, the input is meaningless and will not be used.

  • To add this spider to the spider workspace.
  • To add one or more values that are to be added to the total.
  • To add one or more values that are to be subtracted from the total.
  • To remove unnecessary adding or subtracting values.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. New Input, this section contains the input types configured for this spider.
New Input Function

Add Value

This will add an input called Add value# to the Inputs and section, where # is a unique number starting from 1. For details, see Adding added values.

Subtract Value

This will add an input called Subtract value# to the Inputs and section, where # is a unique number starting from 1. For details, see Adding subtracted values.

Note: These inputs can also be removed from this spider. For details, see Removing added and subtracted values.

  1. Outputs, this section contains the outputs from this spider.
Output Data Function

Added Values Total

Double

Adds together all of the values of the Add value# inputs, where # is a unique number starting from 1.

Subtracted Values Total

Double

Adds together all of the values of the Subtract value# inputs, where # is a unique number starting from 1.

Total

Double

Subtracts the Subtracted Values Total from the Added Values Total.

Note: These calculations are only performed if all the inputs are numeric values. If a string value is supplied then the spider will attempt to convert the string value to a number before attempting the calculation.
