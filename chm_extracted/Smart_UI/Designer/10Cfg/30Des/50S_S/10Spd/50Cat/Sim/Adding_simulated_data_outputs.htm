Adding simulated data outputs

Add the required number of simulated data, which can be further configured, if necessary.

To add one or more simulated data outputs

  1. If necessary, add and/or select the required Simulation spider and/or open its configuration view. For details, see Adding Simulation spiders.
  2. In the New Output section, double-click the New Output entry.

This adds a simulated data output called Sin or Sin# to the Outputs section, where # is a unique number starting from 1.

Note: By default this output generates a sine output between + and - 100.

This output can be renamed and/or its generated values can be further configured. For details, see see Configuring simulated data outputs.

Note: This output can also be removed, if necessary.For details, see Removing simulated data outputs.

  1. Repeat this until all the required simulated data outputs have been added.
