Modifying fonts

To use the Font spider to modify an existing font by independently adjusting certain of its attributes.

By driving one or more of these font attributes remotely, you can create a constantly varying font, when configuring a font property of a graphic form or one of its form components.

Note: The font attributes that can be individually manipulated are: Regular, Bold, Italic, Font size, Underline and Strikethrough.

To modify a font by adjusting certain attributes

  1. If necessary, add and/or select the required Font spider and/or open its configuration view. For details, see Adding Font spiders. 
  1. Right-click its title bar and select Add ARGB Properties.

Note: Once you add these properties you cannot remove them from this spider.

This adds the following six additional Integer inputs to the Inputs section:

  1. Regular: This Boolean attribute, if set to True, removes any Bold or Italic formatting specified for the font.

Note: For this reason, you cannot set both the Regular and Bold or Italic properties at the same time.

  1. Bold: This Boolean attribute, if set to True, displays the font in Bold.
  2. Italic: This Boolean attribute, if set to True, displays the font in Italic.
  3. Font size: This Double attribute, specifies the point size of the specified font.
  4. Underline: This Boolean attribute, if set to True, will cause the font to appear with underlines.
  5. Strikethrough: This Boolean attribute, if set to True, will cause the font to appear with a horizontal line through it.

Note: You are unable to set both the Underline and Strikethough properties at the same time.

  1. The value of these inputs can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or it can be typed in manually. For details, see Creating silks.

Note: The Font size can be specified by a Double, whereas only Boolean values can be used to specify the values of the Regular, Bold, Italic, Underline and Strikethrough font attributes. If other values are typed in, the cell will not accept this input until either this value is removed or the required value is entered instead.

Tip: When typing in a value manually, double-click the value column to the right of the Regular, Bold, Italic, Underline, Font size or Strikethrough input name in the Inputs section and type in the required value.

The Font output, only displays the Font size attribute.

Note: If the Font size attribute is remotely driven, the associated graphic form needs to be displayed in preview mode in the SmartUI Designer before the reported size changes.
