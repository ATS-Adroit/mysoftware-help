Defining colors

You can define the color of a color spider by individually manipulating its A, R, G and B sub-properties. Click for more details:

For instance, by driving one or more of these color constituents remotely, you can create a constantly varying color to configure a color property of a graphic form or one of its form components.

Note1: The R, G, B color constituents, specify the relative intensity of red, green, and blue respectively in the resultant color.

Note2: The A constituent, however, specifies the required transparency of this color, which is only supported by specific color properties e.g. for the Backcolor property of a button.

Note3: If any of the R, G or B properties are being remotely driven, you need to preview the graphic form in the SmartUI Designer, before you can view the changing colors.

Note4: Only Integer values can be used to specify the values of these constituents, from 0 to 255.

To define a color using its ARGB sub-properties

  1. If necessary, add and/or select the required color spider and/or open its configuration view. For details, see Adding color spiders. 
  2. Right-click its title bar and select Add ARGB Properties.

Note: Once you add these color sub-properties you cannot remove them from this spider.

This adds the following four additional Integer inputs to the Inputs section:

Note: All four of these inputs only accept Integer values from 0 to 255.

  1. A: The Alpha property, representing the transparency of this color.

    Transparency determines how much of the background is visible “through” this color.

    A value of 0 is completely transparent so that only the background and not the specified color will be visible and a value of 255 is not transparent at all.

Note: For the following color properties, a value of 0 creates a color that has none of the specified color in it.

  1. R: The Red property, representing the red component of the color.
  2. G: The Green property, representing the green component of the color.
  3. B: The Blue property, representing the blue component of the color.
  1. The value of these inputs can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or it can be typed in manually. For details, see Creating silks.

Note: If a String or Double value is typed in, the cell will not accept this input until either this value is removed or an Integer value is entered instead.

Tip: When typing in a value manually, double-click the value column to the right of the A, R, G or B input name in the Inputs section and type in the required value.

The color input, only displays the color defined by these R, G, B properties and not the A (transparency) property.
