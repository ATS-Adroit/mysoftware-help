Monitoring values

Specify the value that should be monitored for the defined states, so that when this value falls within a defined state, the spider returns the value associated with this state.

To monitor a value

  1. If necessary, add and/or select the required Multi-State spider and/or open its configuration view. For details, see Adding Multi-state spiders.

Tip: Double click the title bar of this spider to open its configuration view.

  1. In the Inputs section, drag the required data element and/or property (Data spider) or output from a spider onto the Value input. For details, see Creating silks.

Note: Ensure that the data type of this value either a String, Integer or Double, since any other value cannot be monitored.

  1. The value of the Value output, will then be determined by the current value of the Value input, as follows:
  • For String values: if the current value matches any of the states then this output is set to its associated value.
  • For Double or Integer values: if the current value falls within the range of a state then this output is set to its associated value.
  • If the current value cannot be matched to any of the states, then NO VALUE is outputted.

Note: These states are processed in order from top to bottom, until the first match is found, after which the remaining states are ignored.
