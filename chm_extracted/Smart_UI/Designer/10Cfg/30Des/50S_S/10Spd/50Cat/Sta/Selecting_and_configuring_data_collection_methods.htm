Selecting and configuring data collection methods

The veracity of the data collected from the monitored analog (floating point) value, depends upon the method of data collection.

Note1: The currently selected data collection method, is specified by the Data Collection Method output.

Note2: By default, the Stream Event method is selected, which collects data for any new incoming value.

To select and configure the required data collection method

  1. Select the required Statistical Functions spider.
  2. Right-click its title bar and select Configure.

The Configuration configuration dialog is displayed to select and configure the required data collection method for this spider.

  1. In the Choose a Sampling Method dialog, select the required data collection method, as follows:

Note1: The selected data collection method applies to all the subsequently added values.

Note2: All the data collection methods use the streaming data sampling approach, whereby the collected input values are treated as being part of a single sample.

  1. Stream Event: This data collection method, collects data for all new incoming values. This is the default selection and requires no further configuration.
  2. Time Based: This data collection method, only collects data for new incoming values, which are recorded within the specified interval of time, which needs to be specified.
  1. When using the Time Based method, open the Configure Time Based dialog and enter the required interval of sampling time during which new incoming values are added to the collected data, , in hour(s), minute(s) and /or second(s).

Note: This specified duration is started when the first value is received.
