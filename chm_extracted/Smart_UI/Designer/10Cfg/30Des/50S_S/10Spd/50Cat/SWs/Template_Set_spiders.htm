Template Set spiders

The Template Set spider can change the active template set at runtime.

The available template sets can either be referenced by name or by means of an index. For details on template sets, see Working with template sets.

Note: This spider does not need to be connected to any other spider, in order to function.

  • To add this spider to the spider workspace.
  • To specify the required template set by its name.
  • To specify the required template set by its index.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default, since this spider will usually be triggered by this method.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Set Name

String

A drop-down list of all the template sets added to this spider workspace.

For details on selecting template sets by name, see Specifying the required template set by name.

Set Index

Integer

A linear index, used to provide an alternate means of referencing the template sets that have been added to this spider workspace.

In that the template set called ‘Default’ will always occupy index 0, followed by the order of templates listed in the Set Name list.

For details on selecting template sets by index, see Specifying the required template set by index.

Note: If an illegal or out of range value is specified for this value then the template set called ‘Default’ will be referenced instead.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

Active Set Name

String

The name of the template set that is the currently selected active template set for this spider workspace.

Active Set Index

Integer

The index of the template set that is the currently selected active template set for this spider workspace.

Set List

DataSet

This contains all the template sets that have been configured for this spider workspace.

Tip: This can be used to populate a ComboBox, which can then be used to drive or set these template sets etc.
