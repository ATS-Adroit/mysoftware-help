Expression spiders

The Expression spider can create user-defined calculations. Click for more information:

This calculation is a sequence of operators and their operandsthe term(s) or sub-expression(s) that an operator acts upon., which are evaluated and resolved to produce the result. Click for more details:

This is a cumulative expression. For details, see Working with expressions.

The operators have both an associativitythe order in which an operator acts upon its operand(s). See operands. and precedence (defining the order in which their operands are evaluated). See the Available operators.

In addition to numbers, input variables (i#), output variables (j#) and other sub-expressions, these operands can also include mathematical functions. See the Available mathematical functions.

Note1: Add the necessary input and/or output variables to the spider first and manually assign their values initially to quickly debug the expression and ensure that it evaluates correctly. For details, see Adding input variables or Adding output variables.

Note2: You are unable to complete entering an expression that contains input and output variables that do not yet exist.

Tip: When creating or editing a complex cumulative expression, right-click the title bar of this Expression spider and select Edit Expression..., which displays a much larger text box.

Examples of use:

Such calculations can be used for adding or accumulating values, implementing advanced control strategies, creating sophisticated information displays and reports, etc.

For instance, to toggle a Digital value: [j1=not(i1)] where i1 is the digital input and j1 is connected to the silk out.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now! : This will cause this spider to immediately be triggered.
  1. Edit Expression... : This can be used when creating a complex cumulative expression to display a multi-line edit box. For details on creating expressions, see Creating expressions.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Expression

String

This is a single-line edit box, which is used to specify simple expressions. For details, see Creating expressions.

Note: If creating a complex cumulative expression, right-click the spider's title bar and select Edit Expression... to display a multi-line edit box, which facilitates the editing of these expressions.
  1. New Input, this section contains the input types configured for this spider.
New Input Function

+ Input Variable

This will add a variable called i# to the Inputs section, where # is a unique number starting from 1, which can be used within the expression of this Expression spider. For details, see Adding input variables.

Note1: You must create the required input variables that the expression requires in order for the expression to be successfully computed.

Note2: Input variables can also be removed from this spider. For details, see Removing input and output variables.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

Result

Double

Displays the result of the last assignment statement (outputvariable = expression) within the Expression input, if the Evaluated output is True, otherwise if it will continue to display the result of the last valid expression, if any.

Evaluated

Boolean

Indicates the success (True) or failure (False) in calculating the specified expression.

Note: If the specified expression is valid and all of its input and/or output variables are added and have the correct data types, then the Evaluated output in the Outputs section, will be True.
  1. New Output, this section contains the output types configured for this spider.

Note: The output name of a spider is case sensitive.

New Output Function

+ Output Variable

This will add an input called j# to the Outputs and section, where # is a unique number starting from 1, which can be used within the expression of this Expression spider. For details, see Adding output variables.

Note1: You must create the required output variables that the expression requires in order for the expression to be successfully computed.

Note2: Output variables can also be removed from this spider. For details, see Removing input and output variables.
