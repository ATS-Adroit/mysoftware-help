Performing Custom queries

You can allow your users to type in their own SQL queries, in a text field and then pass this text to a Query spider so that it can perform this custom query 'on-the-fly'. Click for more details:

Note: The specified query cannot contain parameters.

This facility is provided in addition to using the Query spider to perform pre-defined queries your OLE DB datasources.

To perform a Custom query

This procedure describes how to perform a Custom query by having users specify the query in a TextBox control, so its results can be displayed on a graphic form within a DataGrid control.

 

Prepare the graphic form:

  1. Open a new graphic form in the Design workspace. (If necessary, add a project and a graphic form first)
  2. Add a TextBox control to this graphic form from the Toolbox - this will be used to specify the required query that the Query spider should perform.
  3. Add a DataGrid control to this graphic form from the Toolbox - this will be used to display the records returned by the Custom query.
  4. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the TextBox control in the graphic form.

Add and configure the Query spider to run the Custom query:

  1. Add a Query spider. For details, see Adding Query spiders.
  2. Double click the title bar of this spider to open its configuration view.
  3. Select the required query from the Inputs section of this spider, as follows:
  1. Select the SmartUI Server containing the required OLE DB datasource from the Server list box.

Tip: Use the Default Server selection, when referring to the SmartUI Server that you use to log in, instead of its actual name as this makes it easier to transfer this spider to another SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server.. 

  1. If necessary, select the required OLE DB datasource from this list of available OLE DB datasources on this Server.

The first OLE DB datasource created on this Server is selected by default.

  1. Select the Custom Query category from the Query Type list.
  1. In the property pane (on the right of the spider workspace) open the Appearance category of the TextBox control's properties and drag the Text property onto the Query Name input to connect it via a silk.
  2. Clear the Confirm Action checkbox unless you want a confirmation dialog to appear before this query is performed.
  1. Now configure this spider to be triggered when the text of this TextBox changes i.e. after a user specifies the required query to perform from the Event Trigger section of this spider, as follows:
  1. Select the name of the TextBox control from the Event Object list box, this is typically 'textBox'.
  2. Select the TextChanged event from the Event Name list box.

Connect the Query spider to the DataGrid control:

  1. Select the DataGrid control in the graphic form.
  2. In the Outputs section of the Query spider, drag the Return Object output onto the Data category of the DataGrid control's properties (in the property pane on the right of the spider workspace) and drop it onto the DataSource property.

Note: The Outputs section also contains the Return Information output which displays how many rows were returned or describes any errors, while the Boolean Success output, which displays the result of the execution of this query. 

Test that a custom query can be performed:

  1. Click the Run toolbar button of this graphic form.
  2. Specify the required query to perform in the TextBox control and see if the DataGrid control correctly displays the results of this query.
  3. Save the graphic form by pressing its Save toolbar button to save these changes.
