Adding AND spiders

Add an AND logic spider to create a logical expression and, if necessary AND its result with another Boolean input.

To add an AND spider

  1. Open the required spider workspace.
  • Either use the New Spider toolbar button to add one or more spiders at a time.
  • Or right-click the spider workspace and select the Create New Spider item.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Logic sub-menu and its AND item.
  1. This spider is given a default name, created by appending a unique number to the end of its name.

Tip: It is recommended to give a spider a more descriptive name than its default name, to identify the function that it performs. For details, see Renaming spiders.

This adds an instance of this spider to the spider workspace, in collapsed mode, displaying its distinctive icon beneath its title bar.
