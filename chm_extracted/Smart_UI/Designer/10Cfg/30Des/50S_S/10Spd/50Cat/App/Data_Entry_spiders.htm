Data Entry spiders

The Data Entry spider displays a dialog so that users can enter a data value.

Note: This change in value can be confirmed and/or logged to the event log.

 

  • To add this spider to the spider workspace.
  • To enable a user to change or enter a data value.
  • To configure the data entry dialog.
  • To confirm data entry changes.
  • To log data entry changes.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is enabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is disabled by default.
  4. Trigger Now!: This will cause this spider to immediately be triggered.

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Default Value

 

Numeric, Boolean, String

The initial value, if any, that is displayed in the value edit box of the dialog by default. For details on configuring this dialog further, see Configuring data entry dialogs.

Minimum

Numeric, Boolean, String

The lowest value, if any, that can be specified for this value.

Note1: Any value that is LOWER than this CANNOT be specified. Instead, the entered value; the Minimum and Maximum labels and their values will be displayed in red.

Note2: This is ignored when String values are entered.

 

Maximum

Numeric, Boolean, String

The highest value, if any, that can be specified for this value.

Note1: Any value that is HIGHER than this CANNOT be specified. Instead, the entered value; the Minimum and Maximum labels and their values will be displayed in red.

Note2: This is ignored when String values are entered.

 

Caption

String

The caption (title) and text that is displayed in the caption image bar at the top of the dialog. This is 'Input Required...' by default.

When specifying this text, the following two placeholders can be used:

{0}: The Default Value.

{2}: User name, of the currently logged in user.

Message

String

The informative message or instruction that is displayed above the value edit box within the dialog itself. This is 'Change the value to:' by default.

Note: No placeholders can be used in this text.

Confirm change?

Boolean

This enables or disables the display of a confirmation dialog before the value is changed. For details, see Confirming data entry changes.

Note: A confirmation dialog will ONLY be displayed if the Default Value input has been specified.

Confirmation message

String

The informative text that is displayed by the confirmation dialog. This is 'Change the value from {0} to {1}?' by default.

When specifying this text, the following placeholders can be used:

{0}: The Default Value.

{1}: New (entered) value

{2}: User name, of the currently logged in user, when the value was changed.

 

Log change event?

Boolean

This enables or disables the logging of an event to an event log when the value is changed. For details, see Logging data entry changes.

For details on configuring or viewing the location of the Server event log where this event will be logged, see General Server settings.

Event Log message

String

The text that is displayed by the logged event. This is '[{2}] changed the value of {3} from {0} to {1}' by default.

Note: If more than one data element or spider value is set by this spider (i.e. if the Value output is connected to more than one destination), then a separate event is logged to the event log for EACH destination.

When specifying this message, the following placeholders can be used:

{0}: The Default Value.

{1}: New (entered) value

{2}: User name, of the currently logged in user, when the value was changed.

{3}: The name of the spider or data element, whose value has been changed.

Note: This displays the name of the spider or data element that the Value output is connected to.
Show input dialog? Boolean Typically this should be enabled unless you are simply setting the Value output to the Default Value input, in which case it can be disabled.
 
  1. Outputs, this section contains the outputs from this spider.
OutputDataFunction

Value

Data Element

This contains the value that was entered or specified by the dialog.

Event Log message

String

The text that is displayed by last event that was logged by this spider.

Success

Boolean

This output will either be:

  • True: if the Finish button of the dialog was selected i.e. the Value was successfully entered.
  • False: if the Cancel button of the dialog was selected i.e. the Value was NOT entered.
