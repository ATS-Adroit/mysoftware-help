Adding output variables

Add an output variable to the Expression spider.

To add one or more output variables

  1. If necessary, add and/or select the required Expression spider and/or open its configuration view. For details, see Adding Expression spiders.
  1. In the New Output section, double-click the + Output Variable entry.

This will add an input called j# to the Outputs and section, where # is a unique number starting from 1.

Note: The value of this output can be used to supply the input of another spider or Data spider (e.g. property or data element) via a silk. For details, see Creating silks.

  1. Repeat this until all the required output variables have been added.

Note1: When using this input variable within your expression, ensure that you type in this j# input name correctly.

Note2: If an expression uses output variables, these need to be added and the correct values need to be assigned to them before the expression can be evaluated and its Result output produced.
