Levels And Layers spiders

The Levels And Layers spider allows users to change the visible level of a graphic form at runtime.

The levels that have been added to this graphic form can either be referenced by name or by means of an index.

For details on levels and layers, see Working with levels and layers.

Note: This spider does not need to be connected to any other spider, in order to function.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is enabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.

Note: This triggering only occurs when the spider workspace is running. For details, see Working with spider workspaces.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Level Index

Integer

A linear index, used to provide an alternate means of referencing the levels that have been added to the graphic form that is associated with this spider workspace.

The first (leftmost) level in the Level and Layers tool window, is index 0, followed in order by the other defined levels.

For details on selecting levels by index, see Specifying the required level by index.

Note: If an illegal or out of range value is specified for this value then the previously selected level is referenced instead.

Level Name

String

A drop-down list of all the levels that have been added to the graphic form that is associated with this spider workspace.

For details on selecting levels by name, see Specifying the required level by name.
  1. Outputs, this section contains the outputs from this spider.

Note: Some or all of these outputs can be used to supply the inputs of other spiders or Data spiders (e.g. properties or data elements). 

Output Data Function

Active Level Index

Integer

The index of the level that is currently visible in the graphic form associated with this spider workspace.

Active Level Name

String

The name of the level that is currently visible in the graphic form associated with this spider workspace.

Level List

DataSet

This contains all the levels that have been configured for the graphic form associated with this spider workspace.

Tip: This could populate a ComboBox, which can then be used to drive or set these levels etc.
