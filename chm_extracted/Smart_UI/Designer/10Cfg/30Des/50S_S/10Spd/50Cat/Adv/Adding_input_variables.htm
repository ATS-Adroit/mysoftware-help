Adding input variables

To create one or more input variables for the current script in the Script Engine spider .

Note: The values for these variables can either be typed in manually or can be provided by other spiders or Data spiders (e.g. data elements or properties).

To add one or more input variables

  1. If necessary, select the required Script Engine spider and/or open its configuration view.
  2. In the New Input section, double-click the + input var entry.

This will add an input called var # to the Inputs section, where # is a unique number starting from 1.

Tip1: When creating a silk, you can simply drag onto the + input var entry directly, in the New Input section, to add an input to the Inputs section and connect it to the silk in one easy step. For details, see Creating silks.

Tip2: When typing in a value manually, double-click the value column to the right of the var # input name in the Inputs section and type in the required value.

  1. Repeat this until all the required input variables have been added.

Note1: In order to use these input variables within your script, ensure the IneedSpiderInfo interface has been implemented. For details, see Working with INeed Interfaces.

Note2: If a script uses input variables, these need to be created before the script is run; otherwise a runtime error will result.
