Configuring data entry dialogs

 

To configure the dialog provided by the Data Entry to allow users to enter a data value at runtime.

Note: Only single-value data can be entered using this spider i.e. tabular (dataset) data cannot.

To configure the data entry dialog

If necessary, add and/ or select the required Data Entry spider and/or open its configuration view. For details, see Adding Data Entry spiders.

In the Inputs section:

Note1: The value of these inputs can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or it can be typed in manually.

Note2: The Minimum and Maximum inputs are IGNORED when a String value is specified.

Tip: When typing in a value manually, double-click the value column to the right of the input name in the Inputs section and type in the required value.

  1. If necessary, use the Default Value input to specify an initial value that will be displayed in the edit box of the data entry dialog.
  1. If necessary, use the Minimum and Maximum inputs to specify the range within which a numerical value MUST be specified.

Note: Numerical values that do not comply with these limits CANNOT be entered. Instead, the incorrectly entered value; the Minimum and Maximum labels and their values, in the dialog, will be displayed in red until a valid numerical value is specified.

  1. If necessary, use the Caption input to specify the caption (title) and text that is displayed in the caption image bar at the top of the dialog.

    This is 'Input Required...' by default.

    When specifying this text, the following two placeholders can be used:

  1. {0}: The Default Value.
  2. {2}: The user name, of the currently logged in user.

  1. If necessary, use the Message input to specify the informative message or instruction that is displayed above the value edit box within the dialog itself.

    This is 'Change the value to:' by default.

Note: No placeholders can be used in this text.
