Confirming operator action changes

In addition to performing various value-manipulating operations on a numerical input by the Operator Action spider, you can also confirm this change in value and if so, to specify the confirmation message, as follows:

Note: A confirmation dialog is ONLY displayed when the Input Value input is specified.

Tip: When typing in a value manually, double-click the value column to the right of the input name in the Inputs section and type in the required value.

To confirm operator action changes

  1. If necessary, add and/or select the required Operator Action spider and/or open its configuration view. For details, see Adding Operator Action spiders.
  2. In the Inputs section, enable (set to True) the Boolean Confirm Change? input.
  3. If necessary, customise the text that is displayed by the confirmation dialog before the value is changed, by using the String Confirmation Message input to specify it. 

This text is 'Change the value from {0} to {1}?' by default.

When specifying this text, the following placeholders can be used:  

  1. {0}: The Input Value.
  2. {1}: The modified value.

Tip: You can customise the formatting of the values specified by {0} and {1} to display decimals etc. For details, see Working with value formatting.

  1. {2}: The user name, of the currently logged in user, when the value was changed.
