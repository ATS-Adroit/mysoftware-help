Filtering out a row

Retrive the required row from the connected datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows. data, so that you can obtain the values of each of its columns as outputs of this Data Row Splitter spider.

Note: Ensure that required dataset data has been specified, so that its columns are exposed as outputs. For details, see Exposing dataset columns.

To filter out a row from the specified dataset data:

  1. If necessary, select the required Data Row Splitter spider and/or open its configuration view.
  2. In the Inputs section:
  1. Use the Filter Column input to specify the name of the column to retrieve the row from this dataset data.
  2. Use the Filter Key input to specify the value that must be matched by the specified Filter Column in order to identify the required row.

Note: The value of these inputs can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or it can be typed in manually.

Tip1: When creating a silk, it is also possible to simply drag onto the + input var entry directly, in the New Input section, to add an input to the Inputs section and connect it to the silk in one easy step. For details, see Creating silks.

Tip2: When typing in a value manually, double-click the value column to the right of the input name in the Inputs section and type in the required value.

This selects the FIRST row, from the dataset data, that matches the specified criterion.

In other words, when the spider is triggered, the column values of this selected row will be assigned to their corresponding outputs in the Outputs section. For details, see Triggering spiders.

IMPORTANT: This spider does NOT sort the specified dataset data BEFORE selecting the first matching row.
