Creating variable data elements

Create variable data elements for any data elements that you need to dynamically the name of and if necessary to configure their values.

Example:

In this example a variable data element concatenates the {AgentServer}.{PUMP} inputs to dynamically specify the value of any pump on any Agent Server, which are specified via graphic form aliases.

To create one or more variable data elements

  1. If necessary, add and/or select the required Variable Data Element spider and/or open its configuration view. For details, see Adding Variable Data Element spiders or Selecting spiders or Displaying spider configuration views.

  2. If required, create the required number of named inputs, each of which can be used to replace a portion of a data element name, instead of or in addition to using the default {0}, as follows: in the New Input section, double-click the + New Input entry and specify the required name of this input.

    This adds the specified name in {} to the Inputs section.

  3. In the New Output section, double-click the + Variable DE entry.

This will add 2 inputs, namely vde # [DE Name (Segment)] and vde # [Return DE] to the Inputs section and an output called vde # to the Outputs section, where # is a unique number starting from 0.

  1. Specify the required data element name for this vde # [DE Name (Segment)] input.

IMPORTANT: The value of this input should NOT be supplied by another spider or Data spider (e.g. property or data element) via a silk, but instead should be typed in manually.

Double-click the value column to the right of the vde # input name in the Inputs section and type in the required value.

Tip: Use an Extended Data Element spider to quickly and easily obtain this required data element name. Simply link the required data element to this spider and then copy (CTRL+C) and paste (CTRL+V) its Name input into the value column of this vde # input. For further details, see Extended Data Element spiders.

When specifying the name of the required data element, the string input {0} and/or any named inputs, should specify the variable portion/s of the data element name/s that are to be dynamically driven by another spider or string type input.

For example if the data element was ‘MyServer.DatasourceName.DataElement’, then ‘MyServer.{0}.DataElement’ can dynamically change the name of the required datasource at runtime.

Tip: You can also concatenate the string input {0} and/or any named inputs to replace more than one portion of a data element name. For example: {AgentServer}.{PUMP}.value allows you to dynamically specify the value of any pump on any Agent Server.

  1. Specify the required value, of the {0} and/or the named inputs, which will be dynamically inserted into the variable data element input at runtime. Values can either be typed in directly or obtained from another spider, data element or property, for details, see Creating silks.
  2. If necessary, specify the value that will be written to the dynamically modified data element, specified by the vde # [DE Name (Segment)] and {0} inputs, by specifying this value in the vde # [Return DE] input.

Note: The value of this input should typically be supplied by another spider or Data spider (e.g. property or data element) via a silk, so that it can dynamically vary, however it can be typed in manually.

  1. If necessary, connect the associated vde # output to the required destination for the dynamically modified data element (specified by the vde # [DE Name (Segment)] and {0} inputs), such as another spider or property etc.
  2. If necessary add other variable data elements and/or other named input variables and repeat this until all the required variable data elements have been added and configured.

Note: To remove an unnecessary named input or variable data element, right click it in the Inputs section and select Delete.
