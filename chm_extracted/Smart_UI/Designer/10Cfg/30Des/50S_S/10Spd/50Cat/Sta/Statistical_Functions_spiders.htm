Statistical Functions spiders

The Statistical Functions spider monitors an analog (floating point) value, by using one of the built-in data collection method to calculate statistical information (maximum, minimum, mean, standard deviation and total).

Note: All the data collection methods use the streaming data sampling approach, whereby all the collected input values are treated as being part of a single sample.

  • To add this spider to the spider workspace.
  • To collect data from an analog (floating point) value.

Note: At any time during the monitoring period, click the Reset button to clear all the collected data, resetting the calculated output values to 0.

  • To select and configure the required data collection method.

Note: By default, the Stream Event method is selected, which collects sample data for any new incoming value.

  • To clear the collected data.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Delete Spider: This can be used to remove this spider from the spider workspace. For details, see Removing spiders.
  2. Trigger Spider From Event: This enables the spider to be triggered by means of an event. For details, see Triggering a spider from an event. This is disabled by default.
  3. Enable Silk Triggering: This enables the spider to be triggered by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is enabled by default.
  4. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  5. Trigger Now!: This will cause this spider to immediately be triggered.
  1. Configure: This displays the configuration dialog to select and configure the required data collection method. For details, see Selecting and configuring data collection methods.

 

Inputs and outputs: This describes the available inputs and outputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

Analog Value

Double

The analog (floating point) value, from which data is collected to calculate statistical information, which is displayed in the Outputs section. For details, see Collecting data.

Reset

Boolean

[A Button] To clear the collected data for Analog Value, which resets all of the calculated outputs to 0, except for Minimum and Maximum which are set to the current Analog Value at runtime. For details, see Clearing collected data.
  1. Outputs, this section contains the outputs from this spider.
Output Data Function

 Data Collection Method

String

The sampling method by which the data is collected.

 Minimum

Double

The minimum value of all the data currently collected.

 Maximum

Double

The maximum value of all the data currently collected.

Total

Double

The sum of all the data currently collected.

Mean

Double

The arithmetic mean or average of all the data currently collected.

Standard Deviation

Double

The standard deviation of all the data currently collected.

Note: At any time during the monitoring period, click the Reset button to clear all the collected data, resetting the calculated output values to 0.
