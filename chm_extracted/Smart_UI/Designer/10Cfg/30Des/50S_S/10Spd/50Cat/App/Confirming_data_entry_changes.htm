Confirming data entry changes

In addition to configuring the dialog displayed by the Data Entry spider, you can also confirm this change in value and if so, to specify the confirmation message, as follows:

Tip: When typing in a value manually, double-click the value column to the right of the input name in the Inputs section and type in the required value.

To confirm data entry changes

If necessary, add and/ or select the required Data Entry spider and/or open its configuration view. For details, see Adding Data Entry spiders.

In the Inputs section:

  1. Use the Boolean Confirm change? input to enable or disable the display of a confirmation dialog before the value is changed.

Note: A confirmation dialog will ONLY be displayed if the Default Value input has been specified for this Data Entry spider.

If this is enabled (True) then use the Confirmation message input to specify the confirmation text that is displayed by the dialog.

This is 'Change the value from {0} to {1}?' by default.

When specifying this text, the following placeholders can be used:

  • {0}: The Default Value.
  • {1}: The newly entered value.

Tip: The formatting of the values specified by {0} and {1} can also be customised to display decimals etc. for details, see Working with value formatting.

  1. {2}: The user name, of the currently logged in user, when the value was changed.
