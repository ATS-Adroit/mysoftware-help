Adding performance counters

Add performance counters to monitor key indicators of the performance of your hardware and/or software.

To add one or more performance counters

  1. If necessary, add a Performance Counter spider. For details, see Adding Performance Counter spiders.

Note: If a Performance Counter spider has already been added to this spider workspace, it is not necessary to add another spider, the existing spider can be used instead.

  1. If necessary, select the required Performance Counter spider and/or open its configuration view.
  2. In the New Output section, double-click the New PerformanceCounter entry.

This will open the Add Performance Counters configuration dialog.

  1. Open the Category name list and select the category that contains the required performance counter.
  2. Open the Counter name list and select the required performance counter.

This will immediately select the default instance of this counter in the Instance name list and add the description of this counter to the Description edit box and the Value field, will display the current value of this counter too.

  1. If the Instance name list is not “Empty” and you require an instance other than the selected instance, open this list and select the required instance of this counter.

If necessary, the Value field, will change accordingly.

  1. Click the Add button to add this performance counter.

This will add an entry to the Added Performance Counter list, which indicates the specified category, counter and instance of this performance counter, which are the same as the entries in the relevant lists.

Note: By default, this list is sorted in ascending order using the CategoryName column.

  1. Continue adding other performance counters, by repeating steps 3-6 or click the OK button to close this configuration dialog and add these performance counters to the Outputs section, each identified by their specified CounterName.

Tip: Clicking Cancel will close this configuration dialog and not add the listed performance counters to the spider.

Note1: To display these performance counters on a graphic form or use them within other spiders, it is necessary to connect them to the required properties (Data spiders) or spiders, by means of silks. For details, see Creating silks.

Note2: It is also possible to immediately send the values of these performance counters to their respective spiders when the Server starts up. For details, see Sending spider outputs at startup.
