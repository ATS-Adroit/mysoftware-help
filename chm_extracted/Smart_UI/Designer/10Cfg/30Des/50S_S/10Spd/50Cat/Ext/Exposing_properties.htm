Exposing properties

Use the Hidden Property spider to expose and/or manipulate properties of the specified object that are normally hidden.

These properties will either be displayed as inputs, if they are writable and/or outputs, if they are readable.

To expose the required properties of the selected object

Note: It is only possible to expose properties once an object has been selected. For details, see Selecting the required object.

  1. Select the required Hidden Property spider.
  2. Right-click its title bar and select Expose Object Properties.

The Property Browser configuration dialog is displayed to expose one or more of the properties of the specified Object input for this spider.

To manually specify one or more properties:

In the Expose Object Properties dialog on the right:

    1. Specify the name of the required property in the Property Name edit box.

Note: Property names are case sensitive, if the specified case is incorrect this property will not be recognised and therefore cannot be manipulated. 

    1. Clear the checkboxes, which determine whether you want this property to have an associated input and/or output, as follows:
    1. Clear the CanRead checkbox, if the specified property cannot be read from (e.g. a write only property), this will prevent this property from being added to the Outputs of this spider. 
    2. Clear the CanWrite checkbox, if the specified property cannot be written to (e.g. a read only property), this will prevent this property from being added to the Inputs of this spider. 
    3. Click the Add button.

This adds the specified property to the Added Inputs and/or the Added Outputs columns, depending on which checkboxes were cleared.

    1. If necessary, add another property manually or select an existing property instead.
    2. Click the Finish button, once all the required properties have been added.

To select one or more existing properties:

    1. In the Expose Object Properties dialog on the right:
    1. Either click the View Properties button, to immediately display the existing properties for the specified object in the Select Properties dialog on the right.

Note: The tree of properties will only be displayed if the properties of this object are already known by the reflection spider.

If they do not appear, then click the Browse button and manually locate the assembly that defines these properties instead.

    1. Or click the Browse button, to manually locate the assembly, which defines the properties of the specified object.

      For example the System.Windows.Forms.dll assembly, could be browsed in for a Windows Control.

      The properties defined by the selected assembly are then displayed in the Select Properties dialog on the right. 

Note: The onus is upon the user to ensure that the correct assembly is selected.

In the Select Properties dialog on the right:

    1. If necessary, expand the tree until the necessary properties are exposed.
    2. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the checkboxes of the required properties, so that they are ticked .

Note: Do not click on the names of the properties themselves.

    1. Click the Finish button to add these selected properties to the spider.
