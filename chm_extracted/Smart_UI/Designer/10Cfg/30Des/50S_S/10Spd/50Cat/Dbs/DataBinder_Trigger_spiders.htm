DataBinder Trigger spiders

The DataBinder Trigger spider displays or to saves changes made to the data of a table in a DataBinder. Click for more information:

For details on DataBinders, see About DataBinders.

Technically speaking the DataBinder Trigger spider interacts with the BindingSource component associated with the specific table.

Note: In order to use this spider you need to add a VIZNETDataBinder component to a graphic form and connect it to the required DataBinder.

Typically, this spider is required when you have not used the Create Controls option when adding a VIZNETDataBinder component to a graphic form. Or you want to add a button to load or save the data of a table.

 

  • To add this spider to the spider workspace.
  • To fetch data from a DataBinder table.
  • To update changes made to a DataBinder table.

Configuration

Spider menu: This describes the available menu items and their default settings for this spider. 

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Detail View: This can be used to display the configuration view of this spider, so its name, description, inputs and outputs can be configured. For details, see Working with spider configuration views.

Tip: Double-click the title bar of the spider to display or hide the configuration view of the spider.

  1. Trigger Spider From Event: This enables the spider to be triggered (which will run its script) by means of an event. For details, see Triggering a spider from an event. This is enabled by default.
  2. Enable Silk Triggering: This enables the spider to be triggered (which will run its script) by any silks that are attached to the inputs of this spider. For details, see Triggering spiders. This is disabled by default.
  3. Propagate Outputs At Startup: This enables the spider to supply the silks connected to its outputs with values as soon as its spider workspace enters into running mode. For details, see Working with spider workspaces or Sending spider outputs at startup. This is disabled by default.
  4. Trigger Now!: This will cause this spider to immediately be triggered.

 

Inputs: This describes the available inputs displayed by the default configuration view of this spider.

This default configuration view of this spider, contains the following sections:

  1. Inputs, this section contains the inputs to this spider.
Input Data Function

DataBinder Name

List

This lists the names of all the VIZNETDataBinder components of this graphic form.

Select the name of the required component.

Table Name

List

This lists the names of all the tables in the DataBinder associated with the selected VIZNETDataBinder component.

Select the table that you want to interact with.

Function

List

Select the function that you want to perform on the data of this table, as follows:

Fill: To fetch the data from this table in the database. This displays the data of this table in all the controls that are linked to this table. For details, see Linking controls to BindingSource components.

Update: To save any changes made to this data to this table in the database.
 

  1. Event Trigger, this section is used to specify the event that is used to trigger this spider.

    This is typically a control added to the graphic form, such as a Button control, which uses its Click event to perform the action.

    For details, see Triggering a spider from an event.
