Changing data element referencing

By default the namespaceone or more names separated by periods (or dots), where each name represents an individual item and the entire namespace indicates the relationship or lineage of the leftmost term i.e. grandparent.parent.child. of a data element (and its Data Element spider) specifies the SmartUI Server that it is located on, which definitively describes a data element but is also very inflexible.

For this reason, it is possible to specify how the SmartUI Server component of this naming convention is specified for each Server that provides data into or out of a spider workspace.

The default data element (and Data Element spider) unambiguous naming convention:

[MACHINENAME] ServerName.DatasourceName.[datasource-specific structure].itemName

Although, this convention definitively describes a data element it is also very inflexible.

For instance if the same SmartUI Server is located on a different computer then this namespace will no longer be valid and its associated Data Element spider will not connect to this data, unless it is removed and the data is reconnected manually.

For this reason, it is possible to specify how the Server component of this naming convention is specified for each SmartUI Server that provides data into or out of a spider workspace. Therefore, provided the names of their respective datasources and data elements remain unchanged, it is possible to easily:

  • Change the SmartUI Server computer on which the data from one or more of the existing SmartUI Servers are located.
  • Import a graphic form, containing associated spiders into a project on another SmartUI Server, for instance if you decide to work off-line.

To change the SmartUI Server name(s) of data elements within a spider workspace:

  1. Open the required spider workspace.
  2. Right-click the spider workspace itself and select Link To New Server....

This displays the Select New Server Names configuration dialog, which lists the current names used for the SmartUI Server(s) that supply data to and from this spider workspace.

  1. To modify the name used to refer to a Server, do one of the following:
  1. Select the list box, to the right of the required name and edit this name directly.

Note1: Removing only the "[MACHINENAME] " portion from the SmartUI Server name, will reference this data from the first SmartUI Server that matches this name, from any computer.

Note2: Removing the entire "[MACHINENAME] ServerName" name, will cause this data to reference the default SmartUI Server connection instead.

  1. Select the drop-down list box button at the right of this field and select the required SmartUI Server name from the list of current connections that have been made to SmartUI Servers from this computer.
  1. Click the Finish button.
