Decrementing numerical values

Decrease a numerical value by a configurable amount.

Note: This action is ONLY performed ONCE irrespective of how many times this spider is triggered, until its input values change or when the required Action Type changes.

Tip: This action can change the current template set within the Template Set spider. For details, see Template Set spiders. 

To decrease a numerical value by a specific amount

  1. If necessary, add and/or select the required Operator Action spider and/or open its configuration view. For details, see Adding Operator Action spiders.

In the Inputs section:

  1. Open the Action Type list box and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking.Decrement.
  1. Specify the numeric value on which this action is to be performed, in the Input Value input.

Note1: This value can either be supplied by another spider or Data spider (e.g. property or data element) via a silk, for details, see Creating silks, or it can be typed in manually.

Note2: Only Boolean or numerical values can be typed in.

Tip: When typing in a value manually, double-click the value column to the right of the input name in the Inputs section and type in the required value.

  1. Specify the numeric value by which the Input Value is to be decreased, in the Increment/Decrement Value input, either via a silk or by typing it in manually.

When this spider is triggered, the value of the Increment/Decrement Value input is subtracted from to the Input Value input value and this result is assigned to the Output Value output in Outputs section. For details on triggering spiders, see Triggering spiders.

Note1: The Boolean Value output in Outputs section, contains the Boolean equivalent of this Output Value output i.e. FALSE when it is zero, otherwise TRUE.

Note2: This operation is only performed if the Input Value and Increment/Decrement Value inputs contain numerical / Boolean values.

Note3: If a String value is supplied then the spider will try to convert the string value to a number before using it. If it cannot be converted, the input is meaningless and will not be used.
