Monitoring digital values

Monitor a digital (Boolean) value, so that you can record the number of On (1) and Off (0) events that occur and the individual and total time of these events.

Note: At any time during the monitoring period, click the Reset button to reset all of the output values to 0 and restart their counters.

To monitor a digital (Boolean) value

  1. If necessary, add and/or select the required Counter spider and/or open its configuration view. For details, see Adding Counter spiders. 
  2. In the Inputs section:
  1. Drag the required data element and/or property (Data spider) or output from a spider onto the Digital Input input. For details, see Creating silks.

Note: Ensure that the data type of this value is Boolean, i.e. either 0 or 1, since any other numerical value will not record any events.

  1. Set the Start Stop input to 1, to begin the monitoring period.

The monitored period will end when this Start Stop input is set to 0 or any other value except for 1.

Note: The value of this input can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or it can be typed in manually.

Tip: When typing in a value manually, double-click the value column to the right of the Start Stop input name in the Inputs section and type in the required value.

  1. The following outputs in the Outputs section are calculated for this value, during the monitored period:

Note: The times are displayed in the following format: hours:minutes:seconds.

Tip: At any time, you can reset these counters (set the values of all the outputs to 0 and restart their counters).

  1. Off Counts: The total number of incidents or events when the Digital Input was in the Off state (0) over the monitored period or since the last reset.
  2. Current Off Time: When the Digital Input is currently in the Off state (0), this value displays the actual time of this duration, which is incremented every second, while Digital Input remains in the Off state.
  3. Last Off Time: This displays the last duration of time, during the monitored period or since the last reset, when the Digital Input was in the Off state (0).
  4. Total Off Time: The total time at the Digital Input has spent in the Off state (0), this is effectively the sum of all the Last Off Time periods during the monitored period or since the last reset.
  5. On Counts: The total number of incidents or events when the Digital Input was in the On state (1) over the monitored period or since the last reset.
  6. Current On Time: When the Digital Input is currently in the On state (1), this value displays the actual time of this duration, which is incremented every second, while Digital Input remains in the On state.
  7. Last On Time: This displays the last duration of time, during the monitored period or since the last reset, when the Digital Input was in the On state (1).
  8. Total On Time: The total time at the Digital Input has spent in the On state (1), this is effectively the sum of all the Last On Time periods during the monitored period or since the last reset.
