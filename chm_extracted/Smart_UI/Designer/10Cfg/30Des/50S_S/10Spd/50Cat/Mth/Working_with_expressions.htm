Working with expressions

Each Expression spider requires a user-defined calculation expression string to be defined for its Expression input.

Example:

This is a cumulative expression, where each sub-expression is placed on a new line. These sub expressions can use input and/or output variables and calculate their results immediately, providing they are valid.

Examples of expressions:

WARNING! Do not press ENTER to create a new line, since this will only end the editing of this expression - instead press CTRL+ENTER to create a new line to insert each new expression.

Note1: Add the necessary input and/or output variables to the spider first and manually assign their values initially to quickly debug the expression and ensure that it evaluates correctly. For details, see Adding input variables or Adding output variables.

Note2: I# or i# and J# or j# are the only valid representations of the input and output variable names, where # is a unique number starting from 1.

Tip: When creating or editing a complex cumulative expression, right-click the title bar of this Expression spider and select Edit Expression..., which displays a much larger text box.

Click for more information:

This allows expressions like:

j1=i1*2

j2=j1+1

which yield two results.

The Result output, is the result of the last assignment statement that is completed i.e. outputvariable = expression.

From the example above, Result would be the value of j2 and not j1.

Each expression is simply a sequence of operators and their operands, which is assigned to an output variable.

When several operations occur in an expression, each part is evaluated and resolved in a predetermined order called operator precedence. For details, see Available operators.

The operands can be: numbers, input variables (i#), output variables (j#), other sub-expressions or mathematical functions. For details, see Available mathematical functions.

Tip1: This order of precedence can be overridden through the use of brackets.

Tip2: When specifying the expression string, press CTRL+ENTER to create a new line, which helps make sense of complicated expressions.

Tip3: Make use of the right-click menu to cut, copy and/or paste sections, as necessary.

Tip4: Name the Expression spider appropriately and/or make use of its description field to add further comments or notes regarding the purpose of this expression. For details, see Renaming spiders or Annotating spiders.

Note1: The Evaluated output, specifies whether this expression has been successfully evaluated (True) or not (False).

Note2: The input and/or output variables need to be added and the correct values need to be assigned to them before the expression will be able to be evaluated.

Expression examples

j1 = sin(3.3) + i1 * sqrt(23)

j2 = cos(0.343)

j3 = pow(x, 3) + i2 / 3

 

abs(value)

j1=abs(i1)

if i1 = -5.21 then j1 = 5.21

 

cos(value)

j1=cos(i1)

if i1 = 0 then j1 = 1

 

exp(value) where 2.71828182845904523547 is carried to the power of i1

j1=exp(i1)

if i1 = 2 then j1 = 7.38905609893065

 

log(value) this log is to base e and not 10

j1=log(i1)

if i1 = 2 then j1 = 0.693147180559945

 

not(value)

j1=not(i1)

if i1 = 0 then j1 = 1 and vice versa

 

pow(x,y)

j1=pow(i1,i2)

if i1 = 3 and i2 = 2 then j1 = 9

 

sin(value)

j1=sin(i1)

if i1 = 1 then j1 = 0.841470984807897

 

sqrt(value)

j1=sqrt(i1)

if i1 = 9 then j1 = 3
