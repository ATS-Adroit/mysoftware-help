Activating template sets

Activate a template set so that its associated silks can be enabled. Click for more details:

Only when a silk is enabled can the spiders that it connects perform their functions. In this way template sets are able to determine which spiders can work.

Note1: Any silk associated with the Default template set will ALWAYS be enabled, irrespective of the currently active template set.

Note2: Any silks that are created are immediately associated with the currently active template set.

Note3: The active template set can be changed using a Template Set spider. For details, see Template Set spiders.

Note4: Only one template set can be active at a time.

PLEASE NOTE: Spider template sets have nothing to do with TemplateGOs or SmartUI Templates and should not be confused with them!

To activate the required template set:

  1. If necessary, open the required spider workspace.
  2. Right-click the spider workspace and select the Template Sets menu.

This displays a menu listing the available template sets, in the order in which they were added.

Note: The template set called ‘Default’ will always appear in this list.

  1. Select the name of the required template set, to display its specific menu and select Activate.
