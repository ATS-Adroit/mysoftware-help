Importing spiders and silks

This allows you to bulk configure spiders, silks and their template sets in the spider workspace. Click for more details:

Instead of manually configuring spiders, silks and their template sets in the spider workspace, you can also bulk configure them:

Simply export the spiders and/or silks configuration to a Microsoft Excel XML file, perform the necessary bulk configuration of the provided spreadsheets and then import this new configuration.

WARNING! All NAMES are CASE-SENSITIVE. Therefore ENSURE that the CORRECT case is used when editing the exported file, otherwise they may NOT be recognised when IMPORTED.

Tip1: This exported Microsoft Excel XML file can be used to quickly add a large number of silks on different template sets to different spiders and to quickly view and edit all the spiders’ configurations in a single spreadsheet.

Tip2: To add an imported silk to more than one template set, , separate the different template set names with semi colons ";".

The Import Configuration spider workspace option, can be used to import the configuration of spiders and/or silks from a Microsoft Excel XML file into the selected spider workspace. This will re-configure the spider workspace to the configuration specified in this file.

Note: Importing can be used to re-configure and create spiders and silks and will not delete any spiders or silks that are not configured in the imported file.

To import spider and/or silk configuration into a spider workspace:

  1. If necessary, open the required spider workspace.
  1. either press the Import Configuration toolbar button, from the spider workspace toolbar.
  1. or right-click the spider workspace and select the Import Configuration menu item.

This displays the Import Configuration dialog of the Import Wizard.

  1. Specify the full path and name of the XML file that contains the spider and/or silk configuration that is to be imported into this spider.
  1. either type this in manually, in which case, ensure that the specified path, file name and (.XML) extension is correctly specified, otherwise this file cannot be opened and imported.
  2. or select the browse button to the right of the edit box and browse for the required folder and .XML file name.
  1. Click the Next button to open the specified file so that the spider and/or silk configuration contained within it can be imported into this spider workspace. If the specified file could not be opened, see Troubleshooting importing spiders and silks for possible reasons.

The Map Worksheets dialog of the Import Wizard is displayed to specify the spreadsheets within this file that contain the required silk and/or spider configuration.

Tip: If the exported file has not been edited, the default spreadsheet names will be correctly selected.

  1. If importing silk configuration into this spider workspace, use the Silk Linking list to specify the name of the spreadsheet, within this Microsoft Excel XML file, that contains the required silk configuration.
  2. If importing spider configuration into this spider workspace, use the Spider Definitions list to specify the name of the spreadsheet, within this Microsoft Excel XML file, that contains the required spider configuration.
  3. Click the Next button once the necessary spreadsheet name(s) have been identified. If an error is displayed, see Troubleshooting importing spiders and silks for possible reasons.

After the spiders referenced within the XML file are compared with those present within this spider workspace, the Spider Configuration dialog of the Import Wizard displays the following results:

Note: This dialog will be displayed even if ONLY the SILK configuration is being imported, so that any referenced spiders that do not exist can be created.

  1. The top list, displays the spiders that are ONLY referenced within the XML file and which need to be created.
  2. The middle list, contains any duplicate spiders or the spiders referenced in the XML file that ALREADY exist in this spider workspace.

Note: Empty the checkbox of any spider that should NOT be imported, so that its existing configuration is not modified.

  1. The bottom list, displays any spider-specific errors that have been detected that will prevent them from being successfully imported.

For further details on these lists and their columns and they can provide important information concerning the success of importing these spiders, see Troubleshooting importing spiders and silks.

  1. Click the Next button, when the required duplicate spider(s) have been selected for importing and the other details concerning the importing of this spider configuration is satisfactory.

After the silks specified within the XML file are compared with those present within this spider workspace, the Silk Configuration dialog of the Import Wizard displays similar results as the previous dialog.

  1. Click the Next button, once the required duplicate silk(s) have been selected for importing and other details reported concerning the importing of this silk configuration is satisfactory.

This will display the Template Sets dialog of the Import Wizard, which simply lists all the template sets specified in the XML file, that will be imported into the current spider workspace.

  1. Click the Next button, if the required template set(s) are listed.

This will display the Import Details dialog of the Import Wizard, this displays a summary of the spiders, silks and template sets that will be imported. This simply summarised the results displayed by the previous dialogs.

  1. Click the Next button, which completes the importing process, if the displayed summary of spiders, silks and template sets is satisfactory.

This will display the Import Results dialog of the Import Wizard, which displays the results of importing the spider and/or silk configuration into this spider workspace.

Tip: It is highly recommended that close attention be paid to this dialog, since it provides detailed information concerning the MANUAL configuration that still needs to be performed and all the spiders and/or silks that could not be imported for other reasons.

Note: Silk names are specified using the following format, in this dialog: SourceSpiderName.outputname -> DestinationSpidername.inputname.

  1. The top list, provides a list of MANUAL configuration items that need to be performed in order for the spiders and/or silks that have been imported to be fully configured. For instance, some of the inputs or outputs of the imported spiders may need to be added manually.

  1. The middle list, displays all the spiders and silks that could NOT be imported into this spider workspace and also provides the reason for this.

    For instance this lists any property spiders and their silks, whose corresponding control and its specified property do NOT exist in the graphic form associated with this spider workspace. 

  1. The bottom list, displays all the spiders and silks that were successfully imported into this spider workspace.
  2. Click the Finish button to close the Import Wizard and return to this spider workspace.
