Spider workspace toolbar

The spider workspace provide a toolbar, at the top, to assist in the adding, arranging and configuring spiders and silks, which provides the following tools from left to right:

  1. New Spider : This displays a tabbed spider selection pane at the top of the spider workspace, from which one or more spiders can be added to the spider workspace. For details, see Adding spiders. 
  2. Spider locating tools: Either locate required spider by means of the general list box or use the Advanced Find utility instead. For details, see Finding spiders.

Tip: The Advanced Find method is recommended to locate a spider in a spider workspace that contains a large number of spiders. Since spiders are located per category instead of within a single list.

  1. Template Set tools: Either create a New Template Set or select the active template set from the list box. For details, see Adding template sets or Activating template sets.
  2. Spider workspace configuration tools: Either Import additional configuration or Export some or all of the existing configuration of this spider workspace to or from a Microsoft Excel XML file. For details, see Importing spiders and silks or Exporting spiders and silks.

Tip: By exporting it is possible to quickly add a large number of silks on different template sets to different spiders and/or to quickly view and edit all the spiders’ configurations in a single spreadsheet.

  1. Spider arrangement tools: The following tools can arrange the spiders in this spider workspace:
  1. Collapse All Spiders : To hide the configuration views of all the spiders that have been added to the spider workspace. For details, see Hiding spider configuration views.

Tip: This is the best method of closing a large number of spider configuration views at once, although Data spider configuration views are not as easy to reopen.

  1. Rearrange All Spiders/Regions : To neatly and logically arrange the spiders, regions and silks that have been added to this spider workspace to graphically illustrate the flow of data. For details, see Rearranging spiders.
  2. Hide Unselected Spiders/Regions : A display option, which when enabled, hides the spiders and silks except those that are directly associated with the currently selected spider or form component. In addition to hiding ALL the unselected spiders and regions, three other selective hiding filters can be applied. For details, see Hiding unselected spiders.
  1. Overview : This displays a rectangular overview pane to help you navigate within the spider workspace, so that you can select the portion of the entire workspace that the Spider Configuration window displays.
