Creating silks

Silks are created, within a spider workspace to connect Data spiders (properties and data elements) and/or other spiders together. Click for more information:

Silks are created by dragging the output of one spider to the input of another.

Note1: A silk will only be created, if the data type of both the specified output and input entries are compatible. If necessary the output can be converted to data type of the input. For details, see Converting output data types.

Note2: When the spider workspace is running, the silk’s output spider will be triggered, whenever the value of the silk’s input spider changes. For details, see Triggering spiders.

To create a silk originating from a Data spider:

  1. Open the required spider workspace.
  2. If necessary, display the required tree pane adjacent to the spider workspace by using the pane display bar and expand this tree to display the required node e.g. property, data element etc. For details, see Working with pane display bars.
  3. Ensure that you are also able to see the required destination for this silk e.g. spider or Data spider (property, data element, virtual data element).

Note1: If connecting to a spider, this may require adding the required spider to the spider workspace and moving it, if necessary. For details, see Adding spiders.

Note2: If connecting to a Data spider (property, data element, virtual data element), this may require displaying the required tree pane adjacent to the spider workspace by using the pane display bar and expanding this tree to display the required node.

  1. Drag the silk from the required tree node e.g. property, data element etc. to connect it to the required destination.

Note1: A Data spider will be added to the spider workspace when this node (property, data element, virtual data element) is dragged from the tree, which is demonstrated by a blue line appearing to the left of this node.

Note2: It is possible to inadvertently add other Data spiders to the spider workspace, by dragging this node (property, data element, virtual data element) over any other node in this or another tree. However any Data spider that has no silks connected to it will automatically be removed when the spider workspace is saved. For details, see Saving spider workspaces.

To create a silk originating from a spider:

  1. Open the required spider workspace.
  2. If necessary, add the required spider(s) to the spider workspace. For details, see Adding spiders.
  3. Open the configuration view of the spider, whose output you want to link to the destination spider or Data spider (property, virtual data element). For details, see Displaying spider configuration views.

Tip: Double-click the title bar of the spider to display or hide its configuration view.

  1. If this configuration view contains a New Outputs section, you may want to create a custom output first. For details, see Creating customised spider outputs.
  2. Ensure that you are able to see the required destination for this silk e.g. spider, property or virtual data element.

Note1: If connecting to a spider, this may require moving this spider appropriately or adjusting the size of the spider workspace by using the pane display bars and splitter bars, where necessary. For details, see Working with pane display bars.

Note2: If connecting to a Data spider (property, virtual data element), this may require displaying the required tree pane adjacent to the spider workspace by using the pane display bar and expanding this tree to display the required node.

  1. Drag the silk from the required entry beneath the Outputs section of this spider to connect it to the required destination.

To connect a silk to a spider:

Once a silk has been dragged from either a Data spider (property, data element) or from another spider, complete the required link to this spider, as follows:

Note: The required spider must be visible in the spider workspace in order to connect the silk to it.

  • If the configuration view of this spider is already displayed, then select the required compatible entry beneath the Inputs section that the silk to required to connect to and release the left mouse button.

Note: If this spider’s configuration view contains a New Inputs section, you can immediately create a custom input, by selecting the required compatible entry beneath the New Inputs section and releasing the left mouse button. For details, see Creating customised spider inputs.

  • If the configuration view of this spider is not displayed, then when the mouse pointer is dragged over the title bar or icon of this second spider:
  1. If this spider only has one entry in its Inputs section, which has a compatible data type, then simply release the left mouse button to create the silk will automatically connect to this input.
  2. If this spider has more than one entry in its Inputs section, then its configuration view will automatically be displayed. Select the required input entry, with a compatible data type, and release the left mouse button to create the silk.
  3. If this spider does not currently have any inputs configured, but New Inputs types are available, then its configuration view will automatically be displayed. Drag the silk directly onto the required new input type to create this input and the silk simultaneously.

To connect a silk to a Data spider:

Once a silk has been dragged from either a Data spider (property, data element) or from another spider, complete the link to the required property, as follows:

Note: The node e.g. property, data element etc. must be visible in the required tree in order to connect the silk to it.

  1. Drag the silk to the node e.g. property, data element etc. in the required tree, with a compatible data type, and release the left mouse button.

Note1: Data spiders are added to the spider workspace when this node (property, data element, virtual data element) is dragged from the tree, which is demonstrated by a blue line appearing to the left of this node.

Note2: You can add other Data spiders to the spider workspace, by dragging this node (property, data element, virtual data element) over any other node in this or another tree. But any Data spider that has no silks connected to is removed when the spider workspace is saved. For details, see Saving spider workspaces.
