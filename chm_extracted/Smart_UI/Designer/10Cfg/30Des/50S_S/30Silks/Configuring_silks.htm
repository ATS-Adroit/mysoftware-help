Configuring silks

When right-clicking a silk in the spider workspace, the Silk menu is displayed, listing all the silks within this vicinity. Each silk is represented as follows: SourceSpiderName.outputname -> DestinationSpidername.inputname.

Selecting any of these listed silks will display the following menu of available options:

Note: Menu items that are enabled will have a tick mark to the left of them.

  1. Select: Use this option to highlight this silk to distinguish it from all other silks. For details, see Selecting silks.

  2. Trigger Output Spider: When this is enabled and the spider workspace is running, the silk monitors the output of the source spider that it is connected to.

    When this output changes, the silk fetches the data and passes it to the input of its destination spider and then triggers this destination spider.

    This default triggering Behaviour can also be disabled if required. For details, see Triggering spiders or Disabling silk triggering of spiders. 

  3. Delete: This will remove this silk from the spider workspace. For details, see Removing silks.

WARNING! The selected silk and any attached Data spider(s) will immediately be removed from the spider workspace. 

  1. Template Sets: This menu can be selected to associate this silk with one or more template sets. So that it will be enabled when this template set is activated.

    This will allow the spiders it connects able to transfer their data and therefore perform their functions. For details, see Working with template sets.
