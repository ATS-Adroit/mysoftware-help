Working with silks

Silks connect spiders and/or Data spiders (properties and data elements) within the spider workspace. Click for more information:

Each silk connects the output of a spider to the input of another. For details, see Creating silks.

In this way, the silk serves as a simple conduit that copies the value from the first spider to the second spider, whenever the second spider is triggered. For details, see Triggering spiders or Working with spiders.

Silks do not provide a bidirectional value transfer; each silk indicates the direction in which the value transfer is performed by means of an arrow.
