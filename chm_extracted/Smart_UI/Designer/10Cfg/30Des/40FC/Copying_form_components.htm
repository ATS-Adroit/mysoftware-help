Copying form components

You can copy added form components either within the same graphic form or to another graphic form. Once copied these form components can then be modified as normal. Click for more details:

In addition to copying the selected form components themselves, you can ALSO copy any spiders that have been associated with the properties of these form components and/or any Behaviours that have been configured for this form component - which further reduces the amount of designing required.

To copy BOTH the form components and their associated spiders and/or Behaviours:

  1. Open the graphic form containing the form components you want to duplicate. For details, see Opening graphic forms. 
  2. Select the required controls or graphic elements. For details, see Selecting multiple controls or Selecting multiple graphic elements.
  3. Either right click and select the Copy with Spiders or Copy with Behaviours option or hold down the SHIFT key and then selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Copy from the Clipboard group of the Home tab of the SmartUI Designer ribbon.
  4. If necessary, open the graphic form in which these form components are required or if the graphic form is already open, then select its tab, so that it is currently displayed in the Design workspace.
  5. Select Paste from the Clipboard group of the Home tab of the SmartUI Designer ribbon.

The pasted selected form components will be offset, so that they are placed to the right and below their original position, by a grid width and height in this graphic form.

This ALSO does the following in the Spider Configuration tool window associated with this graphic form:

  • adds and renames the spiders, associated with these pasted form components.
  • creates new Behaviours for the pasted form components, with new spiders and new Behaviour regions, which adhere to the following naming convention: ControlName.BehaviourName.

Tip: It is also possible to use the keyboard shortcuts of SHIFT+CTRL+C and CTRL+V, to copy and paste these form components too. Only ensure that the required graphic form is currently selected before using the CTRL+V shortcut. 

 

To ONLY copy form components without their associated spiders and/or Behaviours:

  1. Open the graphic form containing the form components you want to duplicate. For details, see Opening graphic forms. 
  2. Select the required controls or graphic elements. For details, see Selecting multiple controls or Selecting multiple graphic elements.
  3. Either right click and select the Copy option or selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Copy from the Clipboard group of the Home tab of the SmartUI Designer ribbon.

This will ONLY copy the selected form components and not any spiders and/or Behaviours that have been connected to their properties.

  1. If necessary, open the graphic form in which these form components are required or if the graphic form is already open, then select its tab, so that it is currently displayed in the Design workspace.
  2. Select Paste from the Clipboard group of the Home tab of the SmartUI Designer ribbon.

The pasted selected form components will be offset, so that they are placed to the right and below their original position, by a grid width and height in this graphic form.

Tip: It is also possible to use the keyboard shortcuts of CTRL+C and CTRL+V, to copy and paste these form components too. Only ensure that the required graphic form is currently selected before using the CTRL+V shortcut. 

 

These methods PASTE the object at the same location (co-ordinates) on the destination graphic form as the object was on the original graphic form.

To specify the location of the PASTED object: right click where you want the object and select Paste.
