Arranging graphic elements

The following tools are provided to assist in the otherwise difficult process of arranging graphic elements:

Note: The Design tab of the ribbon provides tools for arranging and designing form components on the current graphic form. For details, see Tools for editing and arranging vectors and/or controls.

  1. The graphic form itself provides a grid and other design features. For details, see Graphic form design properties.
  2. The graphic elements provide specific moving, arrangement and/or resizing functionality. For details, see Editing graphic elements.
  1. The Workspace group of the Design tab of the ribbon provide tools to assist in arranging the selected graphic element/s. For details, see Workspace tools for arranging form components.
  2. A right-click menu provide the following tools to group and adjust the order of display of the selected graphic element/s:
Tool Function Description

Create Vector Group

This combines the selected graphic elements into a single graphic element.

Note: Once created the Tasks list of the vector group (accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control) provides the Child Behaviours list, to display all the Behaviours added to its component vectors, so that these can be edited or deleted or added. For details, see Child Behaviours.

Ungroup

This breaks up all selected groups of graphic elements.

Note: This only disassociates the selected groups, hence any selected groups contain grouped graphic elements these component groups remain grouped.

Bring To Front

If more than one graphic element overlies another, this moves the selected graphic element(s) to the top, where they are most visible.

Bring Forward

If more than one graphic element overlies another, this moves the selected graphic element(s) one position upward towards the topmost element.

Send Back

If more than one graphic element overlies another, this moves the selected graphic element(s) one position downward towards the bottommost element.

Send To Back

If more than one graphic element overlies another, this moves the selected graphic element(s) to the bottom, where they are least visible.

To display the right-click menu:

  1. Open the graphic form containing the required graphic elements. For details, see Opening graphic forms. 
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. these graphic element(s) you want to arrange. For details, see Selecting multiple graphic elements.
  2. If necessary, click the graphic element that needs to be the primary graphic elementwhen a group of graphic elements are selected, this is the first graphic element that is selected and its attributes will be used if this group of graphic elements are formatted. See graphic element..
  3. Right-click and select the required tools from this menu.
