Editing graphic elements

After adding one for more graphic elements can be edited as follows:

Note: Graphic elements need to be selected before they can be edited. For details, see Selecting graphic elements.

Tip: The RoundedRectangleRadiusproperty, specified in pixels, adds support for rounded corners for the following graphic elements: Rectangle, Text, Picture and Button - by default this is 0 (disabled), except for Button which is 2. Values from 5 onward result in rounded corners.

  1. Moving: Drag the selected graphic elements and/or controls to their required location.

    Note1: By default, when moving a selection, it snaps (jumps) to the snaplines (displayed in blue) of the other form components, so as to be aligned with these components.

    This means that you are not able to place this selection in certain places on the graphic form.

    Note2: When moving a selection, the X and Y axis displacement (in pixels) of the current position relative to its original position is displayed next to the center-point in red, so that you can know when to release the mouse button.

    Tip: Hold down the ALT key while dragging to disable the default this snapping mode and provide free movement.

  1. Sizing: The current selection provides sizing handlessmall boxes that appear around the perimeter of a selected item, which if dragged changes the size of this item. See drag. that can be dragged to resize all the graphic elements in the selection.

    When the mouse cursor passes over a sizing handle it changes into a double-headed arrow (), indicating the directions in which the selection can be sized.

    Note: When resizing Text graphic elements, the text itself will ALSO be resized.

    Tip: To draw perfect squares and circles, hold down the CTRL key while resizing their graphic elements.

  1. Rotating: Use the rotation handle above the center of the vector as its rotation site for rotating the selection.

    When the mouse cursor approaches the outer edge of the rotation site it changes into a rotation cursor (), which when dragged rotates the selection clockwise or anti-clockwise.

    Note1: Each selection provides a center-point indicated by a circle () around which it rotates. If necessary, drag this center-point to another position before rotating the selection.

    Note2: When rotating a selection, the angle (in degrees) of the current rotation relative to its original position is displayed next to the center-point in red, so that you can know when to release the mouse button. Clockwise rotation is positive and anti-clockwise rotation is negative.

    Note3: If necessary, the center-point can be reset by right-clicking and selecting the Reset Center-point item. Graphic elements provide a task menu, opened by clicking its icon, which also contains a Reset Center-point item.

  1. Editing nodes: Graphic elements that are collections of basic shapes have nodes at the start and end of each constituent, represented as a small square box (). Nodes allow these constituent shapes to be moved, deleted and added.

    For instance the Polyline which is made up of separate lines, the Spline is made up of curves.

    Nodes are edited using the node pointer (), as follows:

    • Move nodes by dragging them, if the node is attached to two constituents BOTH of them will readjust to their new starting or ending position.
    • Delete nodes by pressing CTRL and clicking the required node, this removes the constituents attached to this node.
    • Add nodes by pressing SHIFT and selecting the existing node that is to be the start or end of the new constituent. This adds the new node on top of the selected node, which needs to be dragged to the required position.

     

  1. Properties: Each graphic element has properties, which affect how it appears and behaves etc. Properties can either be manually configured or driven by external values for animation purposes.

    For instance, most graphic elements can be colored and filled (indicates a rising level from 0 to 100%). For details, see coloring and filling graphic elements.

    Other important properties:

    • Location and size - to dynamically adjust the size and location of this graphic element at runtime.
    • StartPoint and EndPoint: adjusts the size and location of a Line.
    • Rectangle: adjusts the location and dimensions of a Rectangle, Ellipse, Scale and Text.
    • Closed: closes a Polyline or Spline if set to True - this automatically joining the beginning and ending points.
    • ScaleType: changes the displayed scale of a Scale. Supported scale types
    • Scale vector: the DivisionsPosition property changes where the scale appears within the vector i.e. on the Left, Centre or Right of it.
    • Button vector: important properties: Hovercolor: displayed when the mouse pointer hovers over this button; Presscolor: displayed when the mouse clicks this button.
    • Text vector: the Boolean TextScaling property is True by default. Set this property to False if you do not want to resize the text when the vector is resized. Warning! This also means that the text will not rotate and will remain horizontal regardless of the rotation of this Text vector.
    • Text, TextAlign, Textcolor: change the content and appearance of the text of a Text.
    • RoundedRectangleRadius, specified in pixels, adds support for rounded corners for the following graphic elements: Rectangle, Text, Picture and Button - by default this is 0 (disabled), except for Button which is 2. Values from 5 onward result in rounded corners.

    Note1: The Properties tool window displays the available properties of the selected graphic element/s.

    Note2: If more than one graphic element is selected then only the properties shared by all the selected graphic elements are available.

  1. Behaviours: Graphic elements and grouped graphic elements provide a task menu, opened by clicking its icon, which can add one or more display Behaviours.

    These Behaviours use external data to typically modify the appearance of its associated item. For details, see About Behaviours.

    Note: Only one of each of the Behaviours can be added.
