Available graphic elements

The Vectors list of the Toolbox tool window, contains the following fundamental vector-based graphical elements:

Note: Once added, vectors (graphic elements) can be edited and arranged. For details, see Editing graphic elements or Arranging graphic elements.

Tip1: A Vector Group can also be created to house one or more graphic elements. For details, see Arranging graphic elements.

Tip2: To speed up the drawing of vectors, support has been added for the predictive drawing of certain vectors. For details, see Predictive vector drawing.

  1. Button: to create a button control.

To add a button:

  1. Select the Button graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the button.

Important properties:

  1. Hovercolor: displayed when the mouse pointer hovers over this button;
  2. Presscolor: displayed when the mouse clicks this button.
  3. Line: to create a straight line between two points.

To add a line:

  1. Select the Line graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the line to start from.
  3. Click on the graphic form, where you want the line to end.

A straight line will connect these two points.

Tip: These points can also be adjusted using the StartPoint and EndPoint properties.

To add a vertical or horizontal line:

  1. Select the Line graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the line to start from.
  3. Hold down the SHIFT key.
  4. Click on the graphic form, where you want the line to end.

A horizontal or vertical line will connect these two points, depending upon the relation of the second point to the first.

Tip: These points can also be adjusted using the StartPoint and EndPoint properties.

  1. Rectangle: to create squares and/or rectangles.

Tip: You can round the corners of a Rectangle vector by setting its RoundedRectangleRadius property as required.

To add a rectangle:

  1. Select the Rectangle graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the rectangle to appear and drag to define the correct size.

Tip: If you just click without dragging then a default rectangle appears with its top left corner at the specified location.

Note: If necessary, you can both color and/or fill this shape. For details, see coloring and filling graphic elements.

To add a square:

  1. Hold down the CTRL key.
  2. Select the Rectangle graphic element from the Vectors list of the Toolbox window.
  3. Click on the graphic form, where you want the square to appear and drag to define the correct size.

The width is made equal to height or vice versa (whichever is smaller) to create a square.

Note: If necessary, you can both color and/or fill this shape. For details, see coloring and filling graphic elements.

To add a circle:

  3. Click on the graphic form, where you want the circle to appear and drag to define the correct size.

The width is made equal to height or vice versa (whichever is smaller) to create a circle.

Note: If necessary, you can both color and/or fill this shape. For details, see coloring and filling graphic elements.

To add an arc:

  1. Select the Ellipse graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the circle to appear and drag to define the correct size.
  3. Set its boolean VisibleBackcolor property to False.
  4. Configure the ArcStartAngle and ArcSweepAngle properties to define where the arc should start and stop.

  1. Picture: to display an array (sequence) of pictures of the following formats (.bmp, .gif, .jpg, .jpeg, .png, .ico) based on an index.

To add a picture sequencer:

  1. Select the Picture graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want this.

Use its Pictures property to define a list of indexed pictures and then drive its PictureIndex property to select which picture to display.

Important properties:

  1. Pictures: to define the list of indexed pictures. This can be configured by clicking this vector's glyph and selecting the Choose Pictures link from the Tasks menu. This displays the Image Collection Editor, where you can click the Add button to browse in the required images and/or use the and arrows to determine the required sequence of images in this list.
  2. DrawPicturesAtOriginalsizes: this Boolean property, when enabled, resizes the Picture vector to the size of the currently displayed picture - this is enabled (True) by default.
  3. PictureIndex: determines which picture is displayed by this vector, with the first picture (PictureIndex= 0) as the default.
  4. Polyline: to create a series of connected straight-line segments that can be closed to create a polygon shape.

To add a polyline:

  1. Select the Polyline graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the polyline to start from.
  3. Click at each of the ends of the lines that are required to make up this shape and right-click to end.

Tip1: If you want to close your polyline, set its Closed property to True (this automatically adds a line joining the beginning and ending lines).

Tip2: If necessary, you can both color and/or fill this shape (if closed). For details, see coloring and filling graphic elements.

To add a node (line) to an existing polyline:

  1. Select the polyline graphic element in the graphic form.
  2. Hold down the SHIFT key.
  3. Position the mouse pointer over the node () that the new line should be joined to, so that the cursor becomes the node-editing cursor () and click on this node.

This adds a new node on top of the selected node.

  1. Release the SHIFT key.
  2. Drag this new node to the required position.
  3. If necessary, add another node by repeating steps b to e.

To remove a node (line) from an existing polyline:

  1. Select the polyline graphic element in the graphic form.
  2. Hold down the CTRL key.
  3. Position the mouse pointer over the node () that the new line should be joined to, so that the cursor becomes the node-editing cursor () and click on this node.

This removes this node and its line from the polyline.

  1. If necessary, remove another node by repeating steps c again.
  2. Release the CTRL key.

Tip: If you have removed the incorrect line, then press the Undo button from the Edit toolbar to restore it.

  1. Scale: to create a graduated scale e.g. a sliding control.

To add a scale:

  1. Select the Scale graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the scale to appear and drag to define the correct size.

Tip1: If you just click without dragging then a default scale appears with its top left corner at the specified location.

Tip: Hold down the CTRL key while dragging to ensure that its width is made equal to height or vice versa (whichever is smaller).

Important properties:

  1. MinValue: The minimum value at the low end of the scale.
  2. MaxValue: The maximum value at the high end of the scale.
  3. Major: The number of major divisions over the scale range.
  4. Majorcolor: The color of the major ticks.
  5. MajorLength: The length of the major ticks.
  6. MajorLineThickness: The thickness of the major ticks.
  7. Minor: The number of minor divisions between major divisions.
  8. Minorcolor: The color of the minor ticks.
  9. MinorLength: The length of the minor ticks.
  10. MinorLineThickness: The thickness of the minor ticks.
  11. ScaleType: specify the scale to be a round type scale (gauge) or square/rectangular in nature.
  12. ScaleStartAngle: The starting angle for the round scales corresponding to the position of the MinValue.
  13. ScaleSweepAngle: The angular range between the MinValue and MaxValue for round scales.
  14. DrawScaleEdgeLine: Draw a line along the outer or left edge of the scale.
  15. ScaleEdgeLinecolor: The color of the line segment along the edge of the scale.
  16. ScaleEdgeLineThickness: The thickness of the line segment along the edge of the scale.
  17. DivisionsPosition: changes where the scale appears within the vector i.e. on the Left, Center or Right of it.
  18. DrawTest: this draws a scale test.
  19. ScaleTextcolor: The color to use for the scale test.
  1. Text: to create static text labels.

To add text:

  1. Select the Text graphic element from the Vectors list of the Toolbox window.
  2. Click on the graphic form, where you want the text to appear and drag to define the correct size.

Tip1: If you just click without dragging then a default scale appears with its top left corner at the specified location.

Tip2: Hold down the CTRL key while dragging to ensure that its width is made equal to height or vice versa (whichever is smaller).

Important property:

  1. TextScaling:
  2. this Boolean property is False by default.

Note: If set to True, then when resizing this vector, the text itself will also be similarly resized.

  1. set this Boolean property to False if you do not want to resize the text when the vector is resized.

Warning! If set to False, then the text will not rotate and will remain horizontal regardless of the rotation of this Text vector.
