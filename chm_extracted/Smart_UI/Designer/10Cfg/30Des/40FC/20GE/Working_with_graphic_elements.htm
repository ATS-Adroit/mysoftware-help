Working with graphic elements (vectors)

Graphic elements are form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. that provide drawing functionality for the graphic form. These are added to graphic forms from the Vectors list of the Toolbox tool window.

This list contains fundamental vector-based graphic elements that can be used to construct both simple and complicated items, depending upon your requirements. For details, see Available graphic elements.

Click for more information:

Note1: Once added, graphic elements can be edited and arranged. For details, see Editing graphic elements or Arranging graphic elements.

Tip: The RoundedRectangleRadiusproperty, specified in pixels, adds support for rounded corners for the following graphic elements: Rectangle, Text, Picture and Button - by default this is 0 (disabled), except for Button which is 2. Values from 5 onward result in rounded corners.

Note2: Import pre-configured graphical objects to speed up the process of creating a graphic form. For details, see Exporting and importing graphic elements.

Note3: A graphic element is attached to a particular layer of the graphic form, so that it will only be displayed when its associated layer is displayed.

Tip: If necessary, after you have added a form component to a layer, you can move it to another layer, by right clicking it and selecting its Move to layer item (provided that this graphic form provides two or more layers).

Note4: Behaviours can be added to all visible form components to use their properties to display the value of your data. For details of Behaviours, see About Behaviours.

Tip1: Right-clicking a graphic element in the graphic form, displays a menu of further configuration options.

Tip2: Use the SHIFT+CTRL+C shortcut to copy a graphic element AND its added Behaviours and then paste it as usual.

When you configure your graphic forms to dynamically resize, you will ensure that your graphic elements are resized in line with the displayed size of the SmartUI Operator window. For details, see Statically or dynamically resizing graphic forms.

Note: Dynamic graphic form resizing is not intended to replace the standard docking and anchoring which is recommended for preserving the layout of the graphic form, but instead acts as a failsafe measure.
