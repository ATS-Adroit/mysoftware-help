coloring and filling graphic elements

All graphic elements that provide an enclosed graphic area can be colored using a specific color style and filled. Click for more details:

The selected color style determines the appearance of the surface of the graphic element.

These graphic elements include Ellipse, Rectangle, Polyline, Spline, Text and Scale.

In addition to being colored, these graphic elements can also be filled, in other words, they can indicate a rising level from 0 to 100%. This appearance of this rising level is also displayed by using a specific color style.

The following properties can be used when coloring and filling graphic elements:

Note: These properties can be viewed and configured in the Properties tool window.

Property / (Category) Function

(Appearance)

 

Backcolor

This property configures the default appearance of the graphic element, which is determined by selecting and configuring the required color style. For details, see Graphic element coloring styles.

Note: When driving the Backcolor property of vectors, its Solid sub-property is added and configured automatically.

Fillingcolor

This property configures the painted appearance of the rising level used when a graphic element is being filled.

This rising level fills the graphic element by the percentage specified by the FillPercent property.

Its appearance should be distinguished from the default appearance determined by the Backcolor property and is determined by selecting and configuring the required color style. For details, see Graphic element coloring styles.

FillPercent

This Double property specifies the required percentage of the graphic element that should be filled, when using the appearance specified by the Fillingcolor property, with 0 being the lowest point of the graphic element and 100 being the highest.

Any percentage of the graphic element not covered by the Fillingcolor property coloring, will display the default appearance determined by the Backcolor property instead.

VisibleBackcolor

IMPORTANT This Boolean property either enables or disables the ability of this graphic element to be colored and therefore whether its filling will be seen.

If this setting is disabled then the graphic element will not be colored (and its filling will be invisible), despite the configuration of the other coloring properties.

This property is only enabled (True) by default, for those graphic elements that are closed, such as ellipses or rectangles etc.
