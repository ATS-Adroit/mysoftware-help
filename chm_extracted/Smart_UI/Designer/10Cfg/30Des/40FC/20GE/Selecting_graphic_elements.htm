Selecting graphic elements

You typically need to selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. more than one graphic elementa form component that typically provides drawing functionality for the graphic form. See form component. to arrange or bulk-edit them. Click for more details:

Graphic elements are shape-aware, in other words, they can only be selected by clicking within the borders of their shape.

Also if a graphic element has a hole in it (rectangles and ellipses can have holes using the Innersize property), clicking inside this hole will not select it either.

When you select or highlight a group of graphic elements one of them, usually the first graphic element that is selected is the primary graphic element. This primary graphic element will be shaded, while the other graphic elements will appear as normal.

Tip: Once a group of graphic elements is selected, click on the graphic element that you want to be the primary graphic element and the color of its sizing handles will change accordingly.

When applying formatting options to this selected group of graphic elements, this primary graphic element will be the one from which all of the other graphic elements obtain sizing and formatting options.

Note: In order to de-select the currently selected graphic elements, click outside of the group.

To individually select multiple graphic elements:

  1. Open the graphic form, which contains the required graphic elements. For details, see Opening graphic forms. 
  1. Hold down either the CTRL key or the SHIFT key and click on the required graphic elements.

Tip: The first graphic element, that is clicked, will become the primary graphic elementwhen a group of graphic elements are selected, this is the first graphic element that is selected and its attributes will be used if this group of graphic elements are formatted. See graphic element..

 

To bulk select multiple graphic elements:

  1. Open the graphic form, which contains the required graphic elements. For details, see Opening graphic forms.
  1. Hold down the SHIFT key.
  2. Click where you want the upper-left corner of the intended group of graphic elements to be located, and drag to where you want the lower-right corner of the group of graphic elements to be located.

A grey rectangle will indicate the currently selected area.

All the graphic elements within this selected region, will be selected and grouped.

Any controls within this region are also selected, but are not added to this graphic element group and therefore have their own primary controlwhen a group of controls are selected, the sizing handles of this control are white and its attributes will be used if this group of controls are formatted.
