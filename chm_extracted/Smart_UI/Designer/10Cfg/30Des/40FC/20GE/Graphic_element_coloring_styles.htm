Graphic element coloring styles

When a graphic element is required to be colored and/or filled, its Backcolor and Fillingcolor properties need to be configured respectively.

When configuring these properties, the color Settings dialog, can be displayed to select and configure the required coloring style.

Note: These coloring styles and their configurable elements are also exposed as sub-properties, which can be individually configured or manipulated, if required.

To display the color Settings dialog:

  1. Open the required graphic form. For details, see Opening graphic forms.
  2. In the Design workspace, select the required graphic element(s). For details, see Selecting graphic elements.
  3. Open the Properties tool window. For details, see Accessing tool windows.
  4. Select the Fillingcolor or Backcolor property and press the browse button that appears to the right of its value cell.

Note: If one of the selected graphic elements is a line or group, then these properties will not be displayed.

 

 

To select and configure coloring styles using the color Settings dialog:

Select the required coloring style, using the color Style list, which displays the following methods:

  1. Solid:The selected graphic element(s) are painted using a solid color. Configuration:
    1. color: Use this color edit box to select the color that will be used to paint the selected graphic element(s)
    2. Transparency: If required, specify the required transparency of this color. This number determines how see-through the painted color is i.e. whether it is possible to see things through this color or not. The default setting of 255 is not transparent at all, while 0 makes the painted color entirely invisible.

     

Gradient

: The selected graphic element(s) are painted using a multicolor linear gradient.

Configuration:

  1. Transparency: If required, specify the required transparency of this color. This number determines how see-through the painted color is i.e. whether it is possible to see things through this color or not. The default setting of 255 is not transparent at all, while 0 makes the painted color entirely invisible.
  2. Angle: This determines the angle, from the vertical, of the colors added to this multicolor gradient fill. The default value of 0 is vertical, 90, is horizontal, 180 is an inverted vertical and 270 is an inverted horizontal.

Note: To set the angle, either press ENTER or use the buttons of this control to specifying the required angle.

  1. Position:This can be used to create a multicolor gradient by defining the positions and colors of each color. Each defined color is blended with its adjacent color(s) using a linear color gradient. The position of each color is specified BOTH as a fractional percentage from 0 to 1 and graphically using color position markers () along a slider .
    Apart from the mandatory color positions at 0 and 1, additional color position markers can be added or removed as required.

Note1: By default there are three color position markers, which have the following colors configured: at 0 (black), 0.5 (white) and 1 (black).

Note2: Once a color position marker is added, it can be dragged left or right between its two adjacent color position markers, to change its current position.

Note3: The currently selected color position marker is black, while the unselected markers are white.

Tip: When selecting a color position marker, try to select the left or right corner of the triangle of this marker.

To add a color position marker:Simply double-click at the required position along the slider to specify where a color is desired.

To change the color of a color position marker:

Select the required color position marker, so that it becomes solid black and then select the required color using the provided color edit box.

Note: When a color position marker is added, its default color is black.

To delete a color position marker:Select the required color position marker, so that it becomes solid black and then press the DELETE key to remove it.

  1. Hatch:The selected graphic element(s) are painted using a hatch style. Configuration:
    1. HatchStyle: Select the required hatching style from this extensive list of pre-defined hatching styles.

    Tip: Use the sample in the top right corner of this dialog to experiment before selecting the required style.

    1. Forecolor:Use this color edit box to select the hatching or crisscrossing color that will be used when painting the selected graphic element(s).
    2. Backcolor: Use this color edit box to select the background color of this hatching style, which will be used when painting the selected graphic element(s).

    Note: This should not be confused with the Backcolor property of the graphic element itself.

     

  1. Texture:The selected graphic element(s) are painted using a selected image that adopts the selected wrapping mode. Configuration:
    1. Browse Image: Select this button to browse for the required image that will be used to paint the selected graphic element(s). This dialog displays all the supported image file types.
    2. WrapMode: If the selected image is smaller than the selected graphic element, this determines how this image will be used to cover the remaining area of the selected graphic element, as follows:

Note1: The sample in the top right corner of this dialog can be used to indicate how the currently selected painting style appears. However, this may not display the exact appearance on the actual graphic elements, especially when using the Shape coloring style or when displaying the selected transparency.

Note2: The Apply button will apply the currently selected painting style to the selected graphic element(s). This also applies any subsequent changes made to the painting style to these graphic element(s) to immediately view any changes to its appearance. However once pressed, you are unable to cancel any changes that are made.
