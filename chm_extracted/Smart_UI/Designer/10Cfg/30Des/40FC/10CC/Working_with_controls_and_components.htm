Working with controls and components

Controls and components are form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. that typically provide the required user interface for the end-users of a graphic form. These are added to graphic forms from the Toolbox tool window.

Controls and components differ in the following respects:

  1. Controls: a visible form component that displays data or accepts user input in the graphic form. Controls are attached to a particular layer, so that it will only be displayed when its associated layer is displayed.

Note1: Certain controls provide specific or specialised functions. For details, see Specialised controls.

Note2: Once added, controls can be edited and arranged. For details, see Editing controls and Arranging controls.

Note3: Import pre-configured controls to speed up the process of creating a graphic form. For details, see Exporting and Importing controls.

Tip: If necessary, after you have added a form component to a layer, you can move it to another layer, by right clicking it and selecting its Move to layer item (provided that this graphic form provides two or more layers).

  1. Components: a hidden form component that provides additional functionality to this graphic form and to some or all of its form components. Components although drawn on the graphic form, it is actually added to the entire form and not to any particular layer.

Note1: This additional functionality may either provide additional properties to the controls or may need to be implemented programmatically or through the use of spiders.

Note2: Components provide their own properties, which affect how they behave.

Note: Once added, BOTH controls and components expose their individual properties in the Properties tool window, where they can be manually configured. For details, see Properties tool window.

Tip: You can also automate the manipulation of these properties. For details, see Animating graphic forms.

When you configure your graphic forms to dynamically resize, you will ensure that your controls are resized in line with the displayed size of the SmartUI Operator window. For details, see Statically or dynamically resizing graphic forms.

Note: Dynamic graphic form resizing is not intended to replace the standard docking and anchoring which is recommended for preserving the layout of the graphic form, but instead acts as a failsafe measure.
