Specialised controls

Apart from the general WYSIWYG Window Form controls, the following is a selection of controls that provide additional or specialised functions:

Name Icon Description

AlarmViewer

Performs the same functionality as an Adroit Alarm Viewer window. For details, see AlarmViewer controls.
AdroitHistoricalAlarmViewer Allow users to view and/or locate and/or filter and/or print and/or export their historical Adroit alarms, that are stored in the AlarmManagement agent SQL Server database. For details, see AdroitHistoricalAlarmViewer controls.

Charts

(Bar, Column, Line, Pie, XYPlot or Surface)

Charting controls that report both live and historical data, using a (horizontal) bar, (vertical) column, line, pie, XY plot or surface chart. For details, see Charting controls.

How to chart discreet data.

How to chart dataset data.

How to chart databinder data.

ContextMenuStrip

Provides a right-click or shortcut menu for the graphic form. For details, see ContextMenuStrip components.
DataGrid Displays the data provides a spreadsheet-type user interface for data elements of type datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows.. For details, see DataGrid controls.

EventViewer

Exposes the events recorded in an event log file, so that these events can be monitored. For details, see EventViewer controls.
FileBrowser Allows SmartUI users to display to view, edit, upload and/or delete documents pertaining to ALL the ISA S88 / S95 hierarchical levels of your SmartUI project or to simply view the documents within a specific folder on the SmartUI Server computer. For details, see FileBrowser controls.
Gauges Numerous customizable gauges, which all use the same properties and behave uniformly, so they can be easily interchanged. For details, see Gauge controls.

MenuStrip

Provides a dockable menu that is displayed on the graphic form. For details, see MenuStrip components.
SecurityManager Configures and and manages user security in the SmartUI Operator to configure, which previously could only be performed using the SmartUI Designer. For details, see SecurityManager controls.
TableLayoutPanel Adds and arranges controls in a table, so that these controls can change dynamically as the application environment changes. For details, see TableLayoutPanel controls.

TemplateGO

Displays an existing graphic form within another graphic form. For details, see TemplateGO controls.
TemplateGOContextNav To typically view the Default context of the Context View in the Operator, to display the graphic forms associated to the nodes of this context. For details, see TemplateGOContextNav controls.

TemplateGONavToolbar

Creates an entire graphic form navigational system. For details, see TemplateGONavToolbar controls.
TimePicker Specifies (or displays) a time (day, hour, minute and second) by using spin controls, which is stored in milliseconds. For details, see TimePicker controls.
TrendConfigurator Customises the values trended by an associated LineChart control, according to their requirements, which they can then reload when they next logon. For details, see TrendConfigurator controls.

VIZNETBindingNavigator

Provides a toolbar of commands that allows a user to interact with the data a table or View of a DataBinder. For details, see VIZNETBindingNavigator controls.

VIZNETDataBinder

Exposes the data of a DataBinder to other controls and components on a graphic form. For details, see VIZNETDataBinder components.

WebBrowser

Displays a web page (a URL) in a graphic form. For details, see WebBrowser controls.

For more information about using controls and components in graphic forms, see Working with controls and components.
