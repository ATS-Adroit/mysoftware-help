Adding and Configuring Series

Each charting control displays one or more series that provide the charted values and which are usually chart specific.

The following Types of series are available:

  • Line: a series of points that are usually connected to form lines.
  • XYPlot: a series of points that are plotted from two sets of values, one providing the X or horizontal coordinate and the other providing the Y or vertical coordinate of each point.
  • Surface: a series of points that are plotted from three sets of values, one providing the X or horizontal coordinate, another providing the Y or vertical coordinate of each point and the third providing the Z or height coordinate of each point.
  • Pie: a series of slices or segments to form a complete pie or circle. Typically you only use one series per chart.
  • Bar: a series of horizontal bars representing values.
  • Column: a series of vertical columns representing values.

 

The configuration dialog allows you to create each series from the following sources of data:

  • Single valued data. For instance time-stamped data from a SCADA application, such as a tank value.
  • datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows. data. For instance a field within a table of an OLE DB database.
  • Data from a BindingSourceAllows other controls and components on the graphic form to access the data of their associated table or View. Typically created by the VIZNETDataBinder component for each table and View of its associated DataBinder. component for a table or View of a DataBinder that you have added to this graphic form.

To add and/or configure a series: 

  1. If necessary, display the Series Setup dialog of the chart configuration dialog, as follows:
    1. If necessary, add a charting control to the required graphic form. For details, see Adding Charting controls.
    2. If necessary, right click the charting control and select the Edit Chart... menu option to display the configuration dialog
    3. If necessary click the Series Setup heading in the left pane of the configuration dialog to display the Series Setup dialog.
  2. If necessary, click the Add Series button below the series grid to add a new series to this chart.

Note: A FastLine series provides less configuration options than a Line series so that it is drawn faster and is recommended for trending real-time data.

  • Line: a series of points that are usually connected to form lines. If selected this provides: the Line Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Line series or Configuring value labels.
  • Pie: a series of slices or segments to form a complete pie or circle. Typically you only use one series per chart. If selected this provides: the Pie Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Pie series or Configuring value labels.
  • Surface: a surface or three dimensional shape that is plotted from three sets of values, one set provides the X or horizontal coordinate and the other provides the Y or vertical coordinate of each point and the third set provides the Z or height dimension. If selected this provides: the Surface Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Surface series or Configuring value labels.  
  • XYPlot: a series of points that are plotted from two sets of values, one providing the X or horizontal coordinate and the other providing the Y or vertical coordinate of each point. If selected this provides: the XYPlot Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a XYPlot series or Configuring value labels.
