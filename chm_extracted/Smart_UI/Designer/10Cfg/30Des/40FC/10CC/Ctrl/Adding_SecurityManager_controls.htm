Adding SecurityManager controls

Add a SecurityManager control to allow to users configure and manage user security.

IMPORTANT: You need to implement security of the host graphic form to ensure that ONLY the users with the necessary permissions have access to this control!

To add a SecurityManager control to a graphic form:

  1. Open the required graphic form.
  2. If necessary, open the Toolbox tool window.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Security category.
  2. If this category does not appear, then do the following to add it:
    1. Right click in the Toolbox window and select the Add Controls item.
    2. Scroll down the Custom Controls dialog until you can see the SecurityManager checkbox.
    3. If you cannot see the SecurityManager checkbox, click the Browse .NET Control button and click the plugins -> VIZNET Controls -> Security folders and select the VIZNET.UI.CustomControls.Security.SecurityManager.dll file and click Open. This adds the SecurityManager checkbox to the Custom Controls dialog.
    4. Check this SecurityManager checkbox.
    5. Click Finish.
  3. If necessary, use the scrollbar to display the SecurityManager control within this category.

Tip: It is also possible to use the mouse-wheel (if provided by your mouse) to quickly scroll through the list of form components.

  1. Click the SecurityManager control.
  2. On the graphic form, click where you want the upper-left corner of this control to be located.

This control is then added to the layer of the graphic form which is currently being edited.
