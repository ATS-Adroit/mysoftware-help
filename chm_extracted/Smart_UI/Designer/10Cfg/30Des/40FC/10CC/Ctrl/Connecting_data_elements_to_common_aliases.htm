Connecting data elements to common aliases

If the graphic form specified by a TemplateGONavToolbar control has one or more aliasa property of a graphic form or its form components that is exposed, so that it can be independently configured when this graphic form is displayed within a TemplateGO control., then data elements can be connected to one or more of these aliases.

Since the specified aliases are COMMON to ALL the specified graphic forms, they can typically be used to configure the values of common data elements. In other words values that need to be displayed on more than one graphic form.

To connect data elements to aliases:

  1. Ensure that this TemplateGONavToolbar control has selected a graphic form.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. this TemplateGONavToolbar control.
  2. If necessary, click the glyph, which is usually displayed in the top left corner of this control, to display the menu of tasks
  3. Click the Open TemplateGO Aliases... hyperlink to display the TemplateGO Alias Setup configuration dialog.

This displays the list of aliases defined in the selected graphic form and their currently associated data elements, if any.

  1. Select the required Alias name.
  2. Click the Browse ... button to display the Data Element Selection configuration dialog.

This contains an explorer view of all of the datasources each Server connection in the Enterprise Manager.

  1. Expose the required data element to be assigned to this alias.
  2. Select the required data element.

Tip: It is also possible to select the required data element by double-clicking on it.

  1. Click Finish.
  2. If necessary repeat steps 5 to 9 until all the required aliases have been the necessary values.

Note1: It is not necessary for all the configured aliases to be assigned values.

Note2: If more than one property is associated with the same alias name then when this alias is assigned a value, all these properties will be set to this value.

 

For details on how aliases can be used to allow you to configure specific properties of the graphic form you display within another, see Working with aliases.
