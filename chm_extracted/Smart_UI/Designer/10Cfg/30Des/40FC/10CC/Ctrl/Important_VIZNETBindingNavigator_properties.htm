Important VIZNETBindingNavigator properties

The following Boolean properties can be used to display or hide the functionality provided by the toolbar of the VIZNETBindingNavigator control:

 

Property / (Category) Function

(Misc)

 

BindingSource

Select the BindingSource component of the required table or View from the list, that this VIZNETBindingNavigator control should communicate to.

Note: Typically, you will not need to change this setting as it is configured by the VIZNETDataBinder configuration dialog.

ShowAddButton

This Boolean property determines the visibility of the Add New Record button and so can allow users to add records from the associated table.

Note: The DataBinder MUST contain all the primary key column/s for this table, before your users can remove records from this table.

Tip1: Instead of determining this setting once for all users, it is possible to use graphic form security to only display this button for users that have the necessary security privileges to add records.

Tip2: Disable this setting for all Views, which cannot be edited.

ShowCancelButton

This Boolean property determines the visibility of the Undo All Changes button.

Tip1: Instead of determining this setting once for all users, it is possible to use graphic form security to only display this button for users that have the necessary security privileges to add records.

Tip2: Disable this setting for all Views, which cannot be edited.

ShowCount

This Boolean property determines the visibility of the Total Number of Items (Records) field.

ShowDeleteButton

This Boolean property determines the visibility of the Delete Record button and so can allow users to remove records from the associated table.

Note: The DataBinder MUST contain all the primary key column/s for this table, before your users can remove records from this table.

Tip1: Instead of determining this setting once for all users, it is possible to use graphic form security to only display this button for users that have the necessary security privileges to add records.

Tip2: Disable this setting for all Views, which cannot be edited.

ShowLastInPage

This Boolean property determines the visibility of the Move to Last Record in Page button.

 

 

ShowLoadButton

This Boolean property determines the visibility of the Load Data button.

Tip: If the AutoLoad property of the associated VIZNETDataBinder component is enabled, then this button can be hidden, as the data is automatically fetched when the graphic form is displayed.

ShowLookup

This Boolean property determines the visibility of the Lookup, Filter and Find controls, only hide this when users do not need to search for records.

ShowMoveFirst

This Boolean property determines the visibility of the Move to First Record in Database button.

ShowMoveFirstInPage

This Boolean property determines the visibility of the Move to First Record in Page button.

ShowMoveLast

This Boolean property determines the visibility of the Move to Last Record in Database button. 

Tip: Hide this button if it will cause a very lengthy delay in fetching a large number of records from a database over the Internet.

ShowMoveNext

This Boolean property determines the visibility of the Move to Next Record button.

ShowMovePrevious

This Boolean property determines the visibility of the Move to Previous Record button.

ShowPosition

This Boolean property determines the visibility of the Current Position field.

ShowTableName

This Boolean property determines the visibility of the table name.

ShowUpdateButton

This Boolean property determines the visibility of the Update Changes button.

Tip1: Instead of determining this setting once for all users, it is possible to use graphic form security to only display this button for users that have the necessary security privileges to add records.

Tip2: Disable this setting for all Views, which cannot be edited.
