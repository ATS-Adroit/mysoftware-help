Designing menus on-screen

Both the ContextMenuStrip and MenuStrip components provide an on-screen menu designer as an easy way to create new menus and new menu items.

To create and name a new menu, sub-menu or menu item: this adds a ToolStripMenuItem control with a specific name to the menu component.

  1. If necessary, select this menu component, in the component section below the grid of the graphic form
  2.  Type the required name into the new menu item edit box of the menu.

Note: You cannot name two items with the SAME name.

To add a default-named menu item, combo or text box or separator: this adds a default control to the menu component and, in the case of ContextStripMenu components can also add a separator line.

  1. If necessary, select this menu component, in the component section below the grid of the graphic form
  2. If necessary, hover over the new menu item edit box to display the list box button.

Example:

  1. Click the list box button to add one of the following items:
  2. MenuItem: a default ToolStripMenuItem control. For details, see ToolStripMenuItem controls.
  3. ComboBox: a default ToolStripComboBox control. For details, see ToolStripComboBox controls.
  4. Separator: a default ToolStripSeparator control to logically group like menu items/options together.

Note: This is ONLY provided for the ContextStripMenu component.

  • TextBox: a default ToolStripTextBox control. For details, see ToolStripTextBox controls.

Note: You cannot use this on-screen menu designer to edit existing menu items.

 

For details on editing existing menu items, see Editing menus.
