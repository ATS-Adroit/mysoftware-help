Setting row heights and column widths in the TableLayoutPanel

All the rows and columns of controls in the TableLayoutPanel control have an associated style which sets its sizeType property or style that determines how the available space in the TableLayoutPanel control is allocated for each column and row.

Note: This sizeType property is of particular importance when auto sizing this TableLayoutPanel control.

The Column and Row Styles editor is launched by the TableLayoutPanel control to edit this styles in one of the following ways:

  • By selecting the Edit rows and columns... right click menu option or Tasks menu hyperlink.
  • Configure the Columns property of the TableLayoutPanel control.
  • Configure the Rows property of the TableLayoutPanel control.

If necessary select Columns or Rows from the Show list box and then configure the sizeType property of each one, as follows:

Note: If these styles are empty or there are more rows/columns than styles, the default style is "Autosize".

  • Absolute: The row or column is sized to an exact number of pixels (allocates the full space).
  • Autosize: The row or column is automatically sized to share space with its peers, so that it takes up the minimum size necessary to fully contain the largest control in the column/row (allocates as much as is needed to fit the controls in the column/row).
  • Percent: The row or column should be sized to a normalised percentage of remaining space (allocates the distribution of the remaining space).

The Autosize property of the TableLayoutPanel control affects the way in which the available space in the TableLayoutPanel control is allocated for each column and row when this TableLayoutPanel control is auto sized and hence affects how the configured sizeType property of each row and column style operates, as follows:

Autosize How this affects the current row height or column width sizeType setting
false

The TableLayoutPanel control proceeds from left to right, and allocates space for the column or row or in the following order.

  • If the sizeType property is set to Absolute, this allocates the number of pixels specified by the width or height of the TableLayoutPanel control.
  • If the sizeType property is set to Autosize, this allocates the minimum number of pixels to fully contain the largest control in the column/row.
  • After space for all Absolute and Autosize columns or rows is allocated, any columns or rows with sizeType set to Percent are used to proportionally allocate the remaining free space.
true

Similar to the previous interaction, with the exception that the Percent columns or rows are treated as if they were Autosize.

Examples of configuring column widths in the TableLayoutPanel control

Example I: Percentage styled columns attempt to fill the remaining space, so you would configure a 200px wide table with 20px absolute, an auto sized column and a 100% column, as follows:

1.Column1 Absolute: 20 px

2.Column2 Autosize: whatever the preferred size is... say this measures to be 100px

3.Column3 Percent: 100%: 200 - 20 - 100 = 80px.

Example II: If there are two percentage style columns, the 80 pixels would be divided up between the two columns in proportion to one another - so if we had 20% and 80% it would be:

1.Column1 Absolute: 20 px

2.Column2 Autosize: whatever the preferred size is... say this measures to be 100px

3.Column3 Percent: 20%: (200 - 20 – 100) = 80px remaining space. 80px * .20 = 16px.

4.Column4 Percent: 80%: (200 - 20 – 100) = 80px remaining space. 80px * .80 = 64px.

Example III: Exactly the same as above but the two percentage style columns are both 75%, the 80 pixels would be split equally between the two normalised columns:

1.Column1 Absolute: 20 px

2.Column2 Autosize: whatever the preferred size is... say this measures to be 100px

3.Column3 Percent: 75% (normalises to 50%): (200 - 20 – 100) = 80px remaining space. 80px * .50 = 40px.

4.Column4 Percent: 75% (normalises to 50%): (200 - 20 – 100) = 80px remaining space. 80px * .50 = 40px.
