MenuStrip components

This component provides a dockable menu for the graphic form.

Example:

This shows a menu created for a MenuStrip component (containing two menus, a text box and combo box) at the top of the graphic form, its default docking location:

Apart from menus and menu items you can also add text boxes and combo boxes to this menu, as follows:

Note: Each item that you add to the menu is actually a separate control, so that you can drive or assign their properties via spiders like any other control.

  • ToolStripMenuItem control: a selectable option, which can be a menu, sub menu and/or menu item.
  • ToolStripTextBox control: either displays a value or allows the user to enter text in an application.
  • ToolStripComboBox control: displays an editing field combined with a ListBox, allowing the user to select from the list or to enter new text.

 

In addition to navigation, you can use this menu to:

  • raise events to trigger spiders or scripts and/or
  • display or provide a means of specifying important values.

Tip: Use the Contents window to assist you in editing the Behaviours of any controls or vectors you have added to a MenuStrip component. For details, see Contents tool window.

How to create a menu system on a graphic form: this describes the recommended procedure for creating a dockable menu for a graphic form.

  1. Add this component to the required graphic form. For details, see Adding menu controls.
  2. Use the on-screen menu designer to define the required menu system. For details, see Designing menus on-screen. 
  3. If you want your users to be able to dock this menu along the edges of the graphic form at runtime, then right click the menu and select the Embed in ToolStripContainer menu item.
  4. Right click the menu and select the Select menu and its Form menu item.

This displays all the added menu items and/or controls in the property pane of the Spider Configuration window.

  1. Assign the properties of these menu items and/or controls to/from their necessary sources, which could be data elements, spiders, other controls etc.
  2. Save the changes you have made to this graphic form.
  3. Test that the menu for this graphic form works as desired in Run mode.

Note: If you need to edit an existing menu item or control, then you need to edit the Items property of this component. For details, see Editing menus.

 

To add this component to a graphic form: A component needs to be added to a graphic form before it can be used and configured.

Configuration options

  • A Tasks menu: this is displayed by clicking the glyph for this component (at the top left corner of its menu), which allows you to specify the docking options for this menu and/or its painting method and/or to edit its menu items.
    • Embed in ToolStripContainer: this allows this menu toolbar to be dragged around the screen (so that it can be docked on any side of the graphic form) at runtime.
    • Insert Standard Items: This feature is NOT currently supported.
    • RenderMode: To change the painting style of the menu provided by this component, by specifying who has the responsibility for rendering (painting) the menu.
    • Dock: To specify its default docking setting. Example:

    • GripStyle: This specifies the ‘drag’ region of the toolbar (you can click and drag the toolbar from the Grip area – often shown as four vertically aligned dots on the leftmost side of the toolbar).
    • Edit Items… : To edit the existing menu items that you have added. For details, see Editing menus.
  • On-screen menu designer: this is an easy way to create new menus and new menu items to define the required (hierarchical) menu system.
  • Important properties: this describes the important properties used to configure this menu.
    • Dock: To specify its default docking setting. Example:

      Simply click the area in which this item should be docked, as follows:

    • GripStyle: This specifies the ‘drag’ region of the toolbar (you can click and drag the toolbar from the Grip area – often shown as four vertically aligned dots on the leftmost side of the toolbar).
    • Items: To add and/or edit menu items for this menu system. For details. see Editing menus.
    • RenderMode: To change the painting style of the menu provided by this component, by specifying who has the responsibility for rendering (painting) the menu.
    • ToolStripMenuItem control: this lists the important properties of the menu items and sub menus of this menu.
    • ToolStripTextBox control: either displays a value or allows the user to enter text in an application.
    • ToolStripComboBox control: displays an editing field combined with a ListBox, allowing the user to select from the list or to enter new text.

    • Select: This menu selects the graphic form (Form) to display all menu and sub menu items in property pane of spider workspace so as to assign or set their properties.
    • Edit Items… : To edit the existing menu items that you have added. For details, see Editing menus.
