Important TemplateGO properties

Although a TemplateGO control appears to have the same properties as a standard graphic form, it also exposes the following additional properties:

Note: These properties can be viewed and configured in the Properties tool window.

Property / (Category) Function

Autosize

This Boolean property determines whether this control will automatically resize itself to display a graphic form, if this control is smaller than the graphic form that it contains. This is disabled (False) by default.

AutoScroll

This Boolean property either enables or disables scrollbars that appear if the control is smaller than the graphic form that it contains. This is disabled (False) by default.

Note1: Its sub-properties determine how much smaller the graphic form needs to be before these scrollbars appear.

Note2: By enabling the Autosize property this control will initially be resized to the size of the graphic form it contains, after which its size can be adjusted as necessary.

Aliases

This property exposes any specified aliases of the hosted graphic form (properties of its form components), so that values can be assigned to them, if required. For details, see Working with aliases. 

AutoResize

This Boolean property enables or disables the automatic resizing of the control to fit the size of the graphic form that it is hosting.

This feature is disabled (False) by default.

GraphicForm

Although this property can be used to specify which graphic form is contained by this control it is not generally recommended because the specified graphic form will ONLY be loaded at runtime.

In other words, the specified graphic from will ONLY be displayed when the graphic from containing the control is opened in Run mode or when using the Operator.

This property also requires the required graphic form to be manually linked to it. For details on using this property, see Connecting TemplateGO controls to graphic forms. 

GraphicFormPath

This is the generally recommended method of specifying which graphic form is contained by this control.

Click on the provided browse button and browse in the graphic form that you want to contain within this control.

The specified graphic form will immediately be displayed in this control in the Design viewing mode, so that any further configuration can easily be performed. For details on using this property, see Connecting TemplateGO controls to graphic forms. 

MaxDepth

Given that the TemplateGO is a control within a graphic form, that can contain a graphic form itself, it is possible for circular references to be created i.e. for this control to display its own graphic form.

In this case, instead of opening an infinite number of graphic forms, this Integer property specifies the maximum number of instances of each graphic form that can be opened.

For instance if MaxDepth is set to 2 and GraphicFormA contains TemplateGOControlA, which hosts GraphicFormB containing TemplateGOControlB, which hosts GraphicFormA – then 2 instances of GraphicFormA and 2 instances of GraphicFormB will be opened.

Run

This Boolean property is able to start and stop the spider engine (spider workspace), associated with the graphic form that this control is hosting.

By default, this is enabled (True) so that the spider workspace of the contained graphic form is started.

Subscribe

This Boolean property, determines whether the graphic form that is contained within the TemplateGO control will display any changes that are made to its original after it has been contained or not, as follows:

  1. If it is enabled (True) then any changes made to the original graphic form will immediately appear in the graphic form contained within the TemplateGO control.
  2. If disabled (False), then the changes made to the original only appear when the graphic form containing the TemplateGO control is reloaded (refreshed). This is the default setting.
