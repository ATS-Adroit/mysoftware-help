Dragging data to charting controls to configure series

Charting controls display one or more series of data that typically added and configured by using the chart configuration dialog.

However, for each series that is added to a chart, the following series attributes can be independently driven: color, Description (Desc), Maximum value (Max), Minimum value (Min), engineering unit (Unit), value (Value/DataSet) and/or its visibility (Visible).

Note1: The Max, Min and Unit attributes can only be driven when this series is being charted using a custom left (Y) axis.

Note2: By default the Desc attribute, is hidden in the data legend - to display this set the DescWidth property of the charting control from 0 to the required width, this is only displayed by default for imported Adroit trends.

IMPORTANT: When configuring the value (Value/DataSet) attribute - this method should ONLY be used for series of data elements containing SINGLE VALUES and NOT datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows. data or data from a BindingSourceAllows other controls and components on the graphic form to access the data of their associated table or View. Typically created by the VIZNETDataBinder component for each table and View of its associated DataBinder. component. If you do want to specify DATASET data, then you need to configure this series to DataSet, in the Edit Chart configuration dialog first and then drag this data to it.

To drag the required data element to drive a series attribute:

Things you need to do first:

  • Add the required charting control to the graphic form.
  • Add a series to this control, as follows:right click the control and select New XXX Series from the menu, where XXX is the required series type.
  • Display the graphic form in the editor and ensure that this charting control is visible.

 

  1. If necessary, open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, open the required datasource in the Enterprise Manager and expose the required data element.
  1. Drag this data element from the Enterprise Manager onto the charting control in the Design workspace.
  2. Select To Control Property… and the name of the selected charting control.
  3. If the Series property is displayed, select it. Otherwise, select Customise…:

    The Edit Common Properties dialog is displayed.

    1. Ensure that you highlight the Series property, by selecting its name, before clicking Finish.

    Note: Checking this property will add it to the list of immediately available properties for this control.

Note: If only one series was added this is immediately connected to it

  1. If one or more series has been added to this charting control:

The Select Item To Connect To dialog is displayed, which provides the following columns:

  1. The Input item column, specifies the name of the series and then the specific series attribute in braces e.g. line1 [color]
  2. The Currently Linked column, displays the data element that is currently being used to drive this series attribute.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the name of the series and the required series attribute that the selected data element should drive and click Finish.

WARNING! Since more than one data element can be connected to a single series, ensure that only the required data element is connected to each series attribute, as specified in its Currently Linked column.
