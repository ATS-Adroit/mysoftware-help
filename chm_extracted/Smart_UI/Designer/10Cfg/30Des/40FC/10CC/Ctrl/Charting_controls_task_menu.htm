Charting controls task menu

The Tasks menu of the charting controls, provide the following tasks or common configuration options for configuring the chart:

Note1: It is recommended that the configuration dialog be used to configure the charted series. To launch the configuration dialog:right click the charting control and select the Edit Chart... menu option.

Note2: This menu of tasks is displayed when the control is initially added and can be accessed by clicking its smart taga glyph that usually displayed in the top left corner of the selected control or vector that when clicked displays a list of the commonly used configuration tasks. glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control.

Appearance Settings

  • Show Title: To hide or display the main heading of the chart.
  • Chart Title: To specify the text of the main heading of the chart.
  • Chart Legend Position: To specify where you want the legend displayed relative to the charting area.
  • Chart Legend Style: To specify what the legend on the chart itself (not the data legend) displays i.e. names or values of the series. Typically you display series values for pie, bar and column charts and series names for Line and XYPlot charts, these are the default selections.
  • Use Series color in Legend Font: If enabled, the text color used for the names of each series in the chart legend (not the data legend) use in the colors of the series themselves; otherwise these names are displayed in black. 
  • View 3D: To display the chart in three dimensions, which adds depth to your chart and allows you to rotate, zoom and/or move the plotting area of the chart.
  • Show Toolbar: To display a toolbar that allows your end users to manipulate and configure this chart themselves
  • Show Data Legend: To display the data legend for this chart.
  • Data Legend Height Autosize: If checked, this automatically increases the size of the data legend grid to display all the trended series.

  • Data Legend Height : To manually specify the size of the data legend of this charting control, in pixels.

    Note: Depending on the number of series, this size could result in one or more of the series not being displayed by the data legend grid, in which case use the scroll bar to see the hidden series.

  • Data Legend Fractional Digits: To specify the number of significant places to use when values are rounded off in the data Legend.
  • Background Image: to browse for an image to display in the background of this charting control.

Data Settings (for Line and XYPlot charts ONLY)

  • Realtime: To trend real time data against a date time X axis. Disable this when you want to report historical data. Typically this is only required by Line and XYPlot charts.
  • Extrapolate Data: To extrapolate data (estimate its value) from its last known value. More details:In other words, when the value of a charted series is not received, its extrapolated value is charted instead of inserting a gap where this value should have been.
    If enabled, this displays the Extrapolate Data as Bad color option, which if enabled charts any extrapolated data using the Bad data color (configured using the Bad color color box).
  • Historical Data Sample Rate (ms): To limit the retrieved number of historical data points to improve the performance of historical trending. More details:

This Integer property, mainly applies to the LineChart series and serves to limit the retrieved number of historical data points to improve the performance of historical trending. This data sampling rate is specified in milliseconds.

Historical data sampling is AUTOMATICALLY DISABLED when the specified sample rate is SMALLER than 10 x your current time frame window. In other words, the default sample rate of 5 seconds is only applied when the time frame window is greater than 50 seconds.

Setting this sample rate to 0 PERMANENTLY DISABLES historical data sampling and always returns all the available historical data.

Series Configuration

  • New XXX Series, where XXX is the type of series: this adds the specified series to the charting control.
  • Delete Series...: To display the Delete Series... dialog, in which you check the checkbox/es of the series you want to delete and then click Finish to remove them from the chart.
  • Allow Runtime Configuration of Series: check this checkbox to allow users to add values (data elements) to a charting control in runtime mode.
