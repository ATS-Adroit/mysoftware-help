Operating charting controls

This topic briefly explains how end-users are able to interact with charting controls, in run-time i.e. typically when its graphic form is opened in the SmartUI Operator.

General charting control interaction:

Charting toolbar: This toolbar allows your end-users to print and/or preview the chart, change the magnification of the charted data, rotate the chart and if necessary chart additional data, amongst other actions.

Tip: You can hide or show this user toolbar, by using the following shortcut: CTRL+M.

Note: Enable the (Appearance) ToolbarVisible property of this charting control to display this toolbar. The appearance of certain tools are also controlled by Boolean properties.

Chart interaction: Users can interact with the plot area of the chart, as follows:

  1. Display or hide series: Check or clear the relevant checkboxes in the series legend (on the chart), if these appear.
  2. Zooming in: To zoom into a particular region of a chart
    1. Click the top left most corner of the area that needs to be magnified or enlarged in the trend.
    2. Hold the left mouse button down and drag down towards the bottom right hand corner of the required area.
    3. This will display a dashed box that defines the area of the graph that will be enlarged.
    4. Release the left mouse button once the required area has been defined.

Tip: The  toolbar button provides generalised zooming functionality, by decreasing the scaling by 10%.

Note: When using a Line or XYPlot to trend real-time values, the width (Interval) of the chart cannot be changed when zooming.

Tip: When using a Line or XYPlot to trend real-time values, scroll back by one interval and then zoom in.

  1. Panning (moving the trended data): Right-click and drag to move to data that is above, below, to the left or right of the current chart area.

Note: This is especially useful if you have zoomed into historical data when using a Line or XYPlot to trend real-time values.

  1. Reset zooming and panning (return to original magnification and location):

Click anywhere in the graph, hold the left mouse button down and drag upwards towards the top left hand corner and release the left mouse button.

Note: Ensure that a sizable area has been defined before releasing.

Tip: It is also possible to use the Zoom home functionality provided by the toolbar to reset the zooming.

 

Line and XYPlot charting control interaction:

Trending of data: The Line and XYPlot charting controls can trend live data, as follows:

  1. When the charting control is displayed in run-time any historical data for the data elements connected to its series, is fetched from the relevant datasource(s) and displayed.

Note: The configuration of the TimeInfo property determines whether this charting control displays real time or historical trending. For details, see Important charting control properties.

  1. If this charting control has been configured for real time trending, then as the current data is received from the relevant datasources, this data is immediately plotted.

Note: The rate at which the data is fetched is dependent upon the configuration of its Interval property.

  1. If this charting control has been configured for historical trending, then only the data recorded for these data elements during the specified period of time will be displayed.

Note: The charted time period can also be altered at runtime, however any changes made will NOT be saved. For details, see Modifying chart time at runtime.

Charting data legend: The data legend is typically displayed beneath Line and XYPlot charting controls to provide statistical information about the series:

Each of the following columns, which are listed from left to right, can be sorted and resized, as required:

  1. Series:  The names of the charted series of data.
  1. Minimum: The lowest value of each series for the currently displayed “window” of charted data, which is updated continuously.
  1. Maximum: The highest value of each series for the currently displayed “window” of charted data, which is updated continuously.
  2. Average: The average value of each series for the currently displayed “window” of charted data, which is updated continuously.

Note: When the Scroll line to view historical values toolbar option is enabled, two additional columns are added to the legend after this column, namely Historical and Time, which display the value and the date and time of the historical value currently selected by the scroll line.

  1. Current: The current or last value of each series of charted data, which is updated continuously.
  2. Count: The number of values/points plotted by the current series.
  3. Std Dev: The standard deviation of the current series or a measure of the degree of variance within this series.
  4. Errors: When doing historical trending, this displays any historical data retrieval errors for this series.

Note: Enable the (Appearance) DataLegendVisible property of this charting control to display this toolbar.

Tip: The height of this legend and the widths of these columns can also be configured using the DataLegend properties of the charting control.
