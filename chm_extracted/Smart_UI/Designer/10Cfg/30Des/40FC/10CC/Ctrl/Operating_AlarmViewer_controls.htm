Operating AlarmViewer controls

This topic briefly explains how end-users are able to interact with the AlarmViewer control and the alarms that it displays.

Note: When the AlarmViewer control is opened in the SmartUI Operator all the alarms within its connected alarm list, that complies with the specified filtering (if any) are displayed. For details on filtering alarms, see Filtering datasets.

Tip: If you associate graphic forms to agents, then by double clicking an alarm in the list of an AlarmViewer control, the graphic form associated with this agent will be displayed. See Associating graphic forms to agents.

End-user interaction:

  1. Sorting of columns: Click the heading of the column that you want to sort the displayed data by. This will sort the column in ascending order icon: , click the column heading again to sort the column in descending order icon: .

Note: Only the selected columns are displayed. For details, see Selecting alarm columns.

  1. Resizing of column widths: Position the mouse pointer to the left of the column heading until the pointer changes to the following icon . Either double-click to auto-size the column to fit the largest entry or click and drag to the required column size.
  2. Setting number of displayed alarms: When the Show All checkbox is checked this control will only display the number of alarms currently specified by the Maximum Alarms Visible spin control. However, when the Show All checkbox is cleared then the number of displayed alarms can be selected using the Maximum Alarms Visible spin control.

Note: The ShowAllAlarms and MaxAlarmsVisible properties determine the initial configuration of these controls. For details, see Important AlarmViewer properties.

Tip: The specified number of displayed alarms will only be the most recent alarms, when the Alarm Time column is sorted in descending order.

  1. Acknowledging of alarms: Select the required alarm and click the relevant button that is displayed beneath this AlarmViewer control, as follows:

  1. Global Acknowledge: When an alarm is globally acknowledged, any remote stations that are also viewing this alarm, do not need to acknowledge this alarm, as they will see that it has been globally acknowledged elsewhere.

    Note: If a globally acknowledged alarm is removed from the alarm list, then the alarm will no longer be visible to the remote alarm windows.

    Tip: To globally acknowledge ALL the displayed alarms, click the More options link (in the bottom right corner of the AlarmViewer control) and its Global Acknowledge All option.

  2. Local Acknowledge: When an alarm is locally acknowledged, any remote stations that are also viewing this alarm, will also need to acknowledge this alarm, even though they will see that it has been acknowledged elsewhere.

    Tip: To locally acknowledge ALL the displayed alarms, click the More options link (in the bottom right corner of the AlarmViewer control) and its Local Acknowledge All option.

The acknowledged alarm will then change to the required color combination. For details, see Customizing alarm colors.

Note: The following Boolean properties of the AlarmViewer determine which of these alarm acknowledgment options are available: AlarmGlobalAcknowledgeButtonEnabled, AlarmGlobalAcknowledgeAllMenuItemVisible, AlarmLocalAcknowledgeButtonEnabled and AlarmLocalAcknowledgeAllMenuItemVisible.

  1. Inhibiting (shelving) alarms: you can both inhibit (shelvealarm shelving is the process of removing an alarm from the entire alarm system for a specific time period. This also known as inhibiting an alarm.) and uninhibit alarms via the More options link (in the bottom right corner of the AlarmViewer control), as follows:

To inhibit (shelve) alarms:

Note: Once you inhibit an alarm it is both acknowledged and cleared so it is removed from the alarm list.

  1. Select the alarms that you want to inhibit (shelve) in the list.
  2. Click the More options link (in the bottom right corner) and its Inhibit selected alarms option.

IMPORTANT: This option is only enabled when one or more alarms are selected.

In the Inhibit alarms with reason dialog:

Tip: The list of the currently selected alarms are provided to check if the required alarms are selected.

  1. Specify the required Inhibit until date and time, which by default is 24 hours from the current time. Either as a specific Date and time (which cannot be in the past) or Forever, which effectively deactivates this alarm.
  2. Specify the required Reason for shelving (inhibiting) these alarms.

The Operator (the currently logged in user) is also automatically added to this alarm inhibiting event.

  1. Click the Inhibit button.

 

To uninhibit alarms:

Note: After uninhibiting an alarm that was active, it is put back into an active state so that it reappears in the alarm list.

  1. Click the More options link (in the bottom right corner) and its View inhibited alarms option.

In the View inhibited alarms dialog:

  1. Select which of the alarms that have already been inhibited in this alarm list that you want to uninhibit, either using the Select All button or manually select the required ones.

By default this list is sorted by the Inhibit until column in descending order, so that the alarms that are configured to be inhibited for the longest time are displayed at the top of the list.

The Operator (the currently logged in user) is also automatically added to this alarm uninhibiting event.

  1. Click the Uninhibit button.

Note: The following Boolean properties of the AlarmViewer determine which of these alarm inhibiting options are available: AlarmInhibitSelectedAlarmsMenuItemVisible and AlarmViewInhibitedAlarmsMenuItemVisible.

 

  1. Specifying Reasons and/or Notes: This is ONLY possible if your Adroit installation uses the AlarmManagement agent, as follows:

Note: The Reasons and Notes button is ONLY displayed if the Boolean AlarmReasonsAndNotesButtonVisible property of this control is set to True, this is False by default.

  • Either, select a current alarm and click the Reasons and Notes button to specify any reasons or notes for this alarm or to view ALL the instances of this specific alarm that currently require reasons and/or notes to be specified.

Tip: Click the View all button in the dialog, if you want to see ALL the alarm instances that currently require reasons and/or notes to be specified

  • Or simply click the Reasons and Notes button to view ALL the alarm instances that currently require reasons and/or notes to be specified.

This either displays the Alarm Reasons and Notes dialog or an error message if your Adroit installation does NOT use an AlarmManagement agent.

To specify a reason for an alarm:

  1. If necessary, select the required alarm instance from the Current Incidents grid.
  2. Click the required reason from the Reasons list.

This displays the list of configured sub-reasons for this reason in the Sub-reasons list.

  1. Click the required sub-reason.
  2. Click the Commit button to save this change to the database.

To specify a note for an alarm:

  1. If necessary, select the required alarm instance from the Current Incidents grid.
  2. Type this note into the Notes text box.
  3. Click the Commit button to save this change to the database.

The AlarmViewer control, like the Adroit Alarm Viewer window, displays the active alarms within the alarm list of an Alarm or AlarmList agent. For details, see AlarmViewer controls.
