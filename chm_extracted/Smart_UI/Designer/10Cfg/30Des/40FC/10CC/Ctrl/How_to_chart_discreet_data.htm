How to chart single valued or discreet data

Charting controls allow you to report both live and historical single valued (discreet) data.

An example of single valued (discreet) data is time-stamped data from a SCADA application, such as a tank value.

To chart discreet data:

  1. Ensure that you have added a datasource that exposes this data.
  1. Add the necessary charting control to this graphic form. For details, see Adding Charting controls.

The chart configuration dialog is launched, which provides a number of sections of chart configuration. This topic describes these sections and their most important configuration items.

Tip: For advanced configuration options, click the Advanced View > button at the bottom of this configuration dialog.

  1. Click the Series Setup heading (section) in the left pane of the configuration dialog to display the Series Setup dialog.
  2. Click the Add Series button below the series grid to add a new series to this chart.

WARNING! Do not rename these series, since this name corresponds to a separate component on the graphic form that provides advanced series settings.

  1. If necessary, choose and configure the required Type of series to display your data in this charting control.

The following types of series are available:

Note: The available series types are dependant upon the selected charting control.

  • Bar: a series of horizontal bars representing values. If selected this provides: the Bar Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Bar series or Configuring value labels.
  • Column: a series of vertical columns representing values. If selected this provides: the Column Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Column series or Configuring value labels.
  • FastLine: a series of points that are usually connected to form lines. If selected this provides: the FastLine Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a FastLine series or Configuring value labels.

Note: A FastLine series provides less configuration options than a Line series so that it is drawn faster and is recommended for trending real-time data.

  • Line: a series of points that are usually connected to form lines. If selected this provides: the Line Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Line series or Configuring value labels.
  • Pie: a series of slices or segments to form a complete pie or circle. Typically you only use one series per chart. If selected this provides: the Pie Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Pie series or Configuring value labels.
  • Surface: a surface or three dimensional shape that is plotted from three sets of values, one set provides the X or horizontal coordinate and the other provides the Y or vertical coordinate of each point and the third set provides the Z or height dimension. If selected this provides: the Surface Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a Surface series or Configuring value labels.  
  • XYPlot: a series of points that are plotted from two sets of values, one providing the X or horizontal coordinate and the other providing the Y or vertical coordinate of each point. If selected this provides: the XYPlot Style tab to specify how to display the series and a Series Marks tab to optionally specify additional labels for each or some of the values for this series. For details, see Displaying a XYPlot series or Configuring value labels.

Tip: You can connect several data elements to a single series to independently drive its following attributes: color, description, maximum and/or minimum values, engineering unit, value and/or its visibility. For details, see Dragging data to charting controls to configure series.

  1. If necessary, change the assigned color of this series by double clicking the color field to display the color edit box to select the required color. For details, see Selecting colors.

The Visible checkbox determines whether the series is initially displayed or hidden when this chart is displayed. However, a user may configure this at runtime by using the checkboxes in the legend of the chart (if these are displayed, which is the default setting).

  1. Select Values as the type (source) of data that for the values of this series in the Datasource field.
  • If you have selected a FastLine, Line, Surface and XYPlot series, then use the Values tab to specify this data.
  • If you have selected a Bar, Column and Pie series, then use the Values List tab to specify this data.
