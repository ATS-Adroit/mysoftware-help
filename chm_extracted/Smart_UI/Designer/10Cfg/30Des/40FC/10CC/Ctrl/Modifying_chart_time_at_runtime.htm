Modifying chart time and/or navigation at runtime

Note: This only applies to Line and XYPlot charts.

If necessary, the Line or XYPlot charting control can be altered by your end-users at runtime, to:

  • configure the charted time details for a real-time or historical trend.
  • specify which standard chart time navigation tools are displayed by the chart toolbar and/or to display 5 tools that change the chart timespan (chart duration), each of which can be customised as needed.

Ensure the following Boolean properties of this charting control are enabled: ToolbarVisible, TimeDetailsButtonVisible and TimeDetailsButtonEnabled.

Note: Any configuration of the charted time period that is performed in runtime will not be saved.

Select the Modify the time details toolbar button from the toolbar.

To modify the charted time details at runtime: use the Time Details tab to configure the charted time period and interval for a real-time or required charted time period for a historical trend.

Configure the charted time period from theTime Details tab of the Time Details configuration dialog, as follows:

Tip: For ease of use, this tab uses the previously specified Period Type and Timespan time dimension e.g. Hours, Days etc.

To configure the charted time period for a real-time trend:

  1. Select the Real-time (Current - Timespan) from the list of available Period Type methods for calculating the trended time period.
  2. If necessary, specify the required duration of time that is displayed, by selecting the required time dimension e.g. Hours, Days etc., from the list box to the right of the Timespan edit box and then specifying the required amount in this edit box.

Note: The Timespan property is a sub-property of the TimeInfo property. 

For instance, if the trended data is being compacted together then reducing this time-span will result in the data to becoming more clearly differentiated.

  1. If necessary, specify the required update rate for the trended data, in milliseconds, in the Interval edit box.

    This specifies the interval or period of time in milliseconds that the trend advances in real time (shifts across the screen) or by which it is scrolled, by using the Scroll Left or Scroll Right tools (when provided by the chart toolbar).

Note1: The Interval property is a sub-property of the TimeInfo property. 

Note2: The Interval property is not required for static trends.

To configure the charted time period for a historical trend:

Note1: The Timespan property is a sub-property of the TimeInfo property. 

Note2: IGNORE the Real-time (Current - Timespan) option!

Select one of the following Period Type methods for calculating the required time period:

  • End Datetime - Timespan: This calculates the required starting date and time, by subtracting the Timespan from the End date and time:.
    • If necessary, change the currently specified End date and time, which is displayed as: day month year hours:minutes:seconds. For details, see Changing the date and/or time.
    • If necessary, specify the required duration of time that is displayed, by selecting the required time dimension e.g. Hours, Days etc., from the list box to the right of the Timespan edit box and then specifying the required amount in this edit box.
  1. Start Datetime + Timespan: This calculates the required ending date and time, by adding the Timespan to the Start date and time:
    • If necessary, change the currently specified Start date and time, which is displayed as: day month year hours:minutes:seconds. For details, see Changing the date and/or time.
    • If necessary, specify the required duration of time that is displayed, by selecting the required time dimension e.g. Hours, Days etc., from the list box to the right of the Timespan edit box and then specifying the required amount in this edit box.
  1. Start Datetime to End Datetime: This calculates the required time-span to be displayed by this charting control, by subtracting the Start date and time from the End date and time:
    • If necessary, change the currently specified Start date and time, which is displayed as: day month year hours:minutes:seconds.
    • If necessary, change the currently specified End date and time, which is displayed as: day month year hours:minutes:seconds.

    For details, see Changing the date and/or time.

To configure the chart time navigation tools at runtime: use the Navigation tab to specify which chart time navigation tools are displayed by the chart toolbar and/or configure up to 5 tools that configure custom chart timespans (chart durations).

Use the Navigation group of the Navigation tab of the Time Details configuration dialog, to specify which of the following chart time navigation and/or configuration tools you want the chart toolbar to provide, by checking or clearing the relevant checkboxes:

Note: The Interval and Timespan properties are typically configured in the Time Details tab of this Time Details dialog.

  • Show RealTime: when enabled (checked) this displays the Go to real time mode tool in the chart toolbar, which moves the chart right (forward in time) until the real time values of the data are displayed in the chart.
  • Show Page Right: when enabled (checked) this displays the Page Right tool in the chart toolbar, which moves the “window” of displayed data right (forward in time) by the period of time specified by the current width of the chart (i.e. by the chart Timespan property).
  • Show Scroll Right: when enabled (checked) this displays the Scroll Right tool in the chart toolbar, which moves the “window” of displayed right (or forward in time) by the period of time specified by the Interval property.
  • Show Scroll Left: when enabled this displays the Scroll Left tool in the chart toolbar, which moves the “window” of displayed left (backward in time) by the period of time specified by the Interval property.
  • Show Page Left: when enabled this displays the Page Left tool in the chart toolbar, which moves the “window” of displayed data left (backward in time) by the period of time specified by the current width of the chart (i.e. by the chart Timespan property).
  • Show Custom Navigation: This enables (checked) the Custom Navigation group that always displays five tools that when selected configure the Timespan property of this chart to specific time durations. The specified duration becomes the label of each tool. The default chart durations are, as follows: 1 hour, 12 hours, 1 day, 7 days and 30 days.

Note: You can customise the required Timespan and time units of each of these five tools , as needed.
