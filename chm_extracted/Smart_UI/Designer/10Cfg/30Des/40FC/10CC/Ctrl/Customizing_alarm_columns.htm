Customizing alarm columns

You can customise both the columns and their widths that are displayed by the AlarmViewer control, when listing each alarm.

Tip: To quickly display or hide columns, double click the required column to add it to the other list.

To customise the alarm columns and/or their widths:

  1. If necessary, add this control to the required graphic form. For details, see Adding AlarmViewer controls.
  2. In the Design workspace, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the AlarmViewer control.
  3. Open the Properties tool window.
  4. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the AlarmColumnInfo property, which is listed in the Alarm category.
  5. Click the browse button in the value column to the left of this property.

This will display the alarm column selection dialog.

Example:

To hide a column from display:

  1. Select the column in the left Visible Columns list that should be hidden.
  2. Click the button to add it to the right Hidden Columns list.

To display a previously hidden column:

  1. Select the column in the right Hidden Columns list that should be displayed.
  2. Click the button to add it to the left Visible Columns list.

To specify the required width of a column:

  1. Select the column in the left Visible Columns list.
  2. Specify the required number of pixels in the Width field, in the central property pane, the default value depends on the selected column.

To change the order in which a column is displayed in this control:

Select the column in the left list, whose order of display needs to be changed.

Either click the Move up button to move this column up the column listing. This will move to column closer to the left of the control, so that it is more prominent or easier to be displayed.

Or click the Move Down button to move this column down the column listing. This will move to column closer to the right of the control, so that it is less prominent or harder to be displayed.
