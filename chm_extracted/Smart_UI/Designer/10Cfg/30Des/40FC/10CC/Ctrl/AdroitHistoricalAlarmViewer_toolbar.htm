AdroitHistoricalAlarmViewer toolbar

This toolbar allows end-users to view and/or locate and/or filter and/or print and/or export the historical alarms they require and/or configure the display of this grid and its columns at runtime.

Note: The ToolbarVisible property displays or hides this toolbar, which is displayed by default. The availability of certain of its tools are also dependant upon Boolean properties.

Tools provided for AdroitHistoricalAlarmViewer controls:

  1. Paging : When paging is used to browse the available alarms in this grid, these controls allows you to move between the available pages and/or define the required page size (the number of alarms on each page).

    Note: The Use Paging checkbox in the Tasks menu (UsePaging property) determines whether this control uses paging, which is enabled by default, if set to False all of these controls are disabled (greyed out). 

  2. Columns : This displays the Columns Configuration dialog so that users can choose which columns are displayed in the grid, their order and their specific properties. For details, see Configuring AdroitHistoricalAlarmViewer columns.
  3. Constraints : This displays the Constraints Configuration dialog to further refine the displayed alarms to eliminate unnecessary alarms. For details, see Configuring AdroitHistoricalAlarmViewer columns.
  4. Filter: This menu, enables or disables the use of filters and/or allows you add and/or remove filters that you want to create:
    • Enable Filtering : when enabled this is highlighted, which allows you to add and/or use filters to restrict or limit the number of displayed alarms, this option can be enabled by default.
    • Add Filter...: this displays the Add Filter dialog, which allows you to define the required filter as follows:
      1. Specify a descriptive name for this filter so that you can easily identify what it does in the Filter Name field.
      2. If necessary click the default And and select how this condition is required to relate to other conditions specified for this filter. For details, see the Available relationships:

        Note: It is possible to separate your conditions into groups, which act like parentheses in this logical expression.

      3. Click the Plus button or press the INSERT or + key to define the required condition that must be met in order for alarms to be displayed, as follows:
      4. If necessary, click the [DateTime] item to select the required column in the grid that this condition applies to. For details, see the Available columns:

      5. If necessary, click the Equals to specify the required operator or what the values of this column need to do in order to successfully fulfill the requirements of this condition. For details, see the Available operators:

      6. Click the <enter a value> to specify the specific value requirement of this condition.

      Note: To remove a condition, click its Delete button or press the DELETE or - key.

      Tip: You will notice that at the bottom of this dialog, the actual filter query syntax is specified, which you can write down and type this into the FilterString edit field, when creating predefined filters.

    • Delete All Filters: to delete all filters that have been added using this Filter menu, this will NOT remove any predefined filters i.e. any filters that were already in the filter list box when this graphic form was opened.
  5. Enable Find : When this tool is selected, the Find bar is displayed beneath the toolbar, so that users can type in a string so that ONLY rows containing this specified text string is displayed.
  6. Print Preview : This displays a WYSIWYGWhat you see is what you get print preview of the grid, that provides additional options, such as selecting which printer to use and other options that configure the printed output, which you can preview before using.
  1. Printing : This immediately sends the grid and its current contents to the printer, using the print settings specified via the Print Preview dialog; which is the default printer unless otherwise specified!
  1. Exporting : Export the columns and rows of the grid to a number of different document formats, such as PDF or HTML typically for reporting purposes or to CSV or the applicable MS Excel spreadsheet format typically to allow you to perform third party application reporting of this data.
  1. Alternate Row color : This enables the display of the odd and/or even rows in different colors to make it easier to differentiate between the different alarms in the grid, which depend upon whether these have been configured via the Appearance tab of the relevant configuration dialog. For details, see Configuring AdroitHistoricalAlarmViewer appearance.
  1. General Configuration : This tabbed dialog allows you to configure the generally applicable settings of this control, namely: how it is updated with the most recent alarms via its DataSource tab; configuring its Columns; configuring the applicable Constraints, such as the time period of applicable alarms and/or specifying its Appearance, such as configuring its alternate row colors. For details, see General configuration settings.
  2. Manual Refresh : Populates the grid with the latest contents of the Alarm Management table, so this action updates the grid with the most recent alarms.

Note: This button does not appear when subscription updates are used to update this grid with more recent alarms. For details, see Configuring how to update AdroitHistoricalAlarmViewer controls.

  1. Help : This displays this help topic.
