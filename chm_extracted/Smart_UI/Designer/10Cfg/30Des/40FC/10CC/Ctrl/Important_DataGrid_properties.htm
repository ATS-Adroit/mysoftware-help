Important DataGrid properties

The following list describes the functions of some of the more important properties that can be used to configure this control:

Note: These properties can be viewed and configured in the Properties tool window.

Tip: Since ONLY ONE table can be displayed by the DataGrid control there is no need to configure properties that are concerned with multi-table or related table navigation etc.

Property / (Category) Function

(Appearance)

 

BorderStyle

This determines how the borders of this control are displayed.

GridLineStyle

This determines how the grid lines between the cells of this control are displayed.

CaptionText

This String property can be used to specify the text that should appear in the blue bar at the top of this control, this text is displayed in the font specified by CaptionFont.

Note: This only need to be specified if the caption is displayed, see CaptionVisible.

Font

This specifies the font that is used when displaying text within the control.

(colors)

 

Forecolor

This is the color of the text (the font color) used when displayed data in the rows of the grid.

Note: Any Fore… color indicates the text color (font color) that will be used.

Backcolor

This is the background color of the cells when displaying data within the even-numbered rows of the grid i.e. rows 0, 2, 4, 6 etc. Default is white.

Note: Be careful to select a color that will not obscure the reading of display of the data. Use the colors available on the System colors palette to avoid this issue.

AlternatingBackcolor

This is the background color of the cells when displaying data within the odd-numbered rows of the grid i.e. rows 1, 3, 5, 7 etc. Default is white. This color therefore creates a visual means of differentiating successive rows in the grid.

Note: Be careful to select a color that will not obscure the reading of display of the data. Use the colors available on the System colors palette to avoid this issue.

Backgroundcolor

This determines the color behind the grid itself, for instance if only a few rows are contained in the grid.

(Data)

 

DataSource

This property should be connected to the required data element of type dataset. For details, see Connecting datasets to DataGrid controls.

(Display)

 

CaptionVisible

This displays or hides the caption i.e. the blue bar that at the top of this control by default.

Note: If this is hidden then more data can be displayed within this control.

ColumnHeadersVisible

This displays or hides the column headings within the grid.
