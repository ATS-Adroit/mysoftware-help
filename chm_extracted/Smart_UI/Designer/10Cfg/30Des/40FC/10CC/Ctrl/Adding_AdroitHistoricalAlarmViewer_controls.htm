Adding AdroitHistoricalAlarmViewer controls

Add an AdroitHistoricalAlarmViewer control to allow users to view and filter their historical Adroit alarms, that are stored in the AlarmManagement agent SQL Server database.

To add a AdroitHistoricalAlarmViewer control to a graphic form:

  1. Open the required graphic form. 
  2. If necessary, open the Toolbox tool window.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Adroit category.
  2. If necessary, use the scrollbar to display the AdroitHistoricalAlarmViewer control within this category.

Tip: It is also possible to use the mouse-wheel (if provided by your mouse) to quickly scroll through the list of form components.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the AdroitHistoricalAlarmViewer control.
  2. On the graphic form, click where you want the upper-left corner of this control to be located, and drag to where you want the lower-right corner of the control to be located.

This control is then added to the layer of the graphic form which is currently being edited.
