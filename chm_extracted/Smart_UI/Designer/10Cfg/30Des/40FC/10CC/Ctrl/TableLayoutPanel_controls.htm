TableLayoutPanel controls

The TableLayoutPanel control allows you to add and arrange controls in a table, so that these controls can change dynamically as the application environment changes.

Each cell in this table typically contains a single control.

Note: While you can add a container control such as a Panel to add multiple controls in a cell this can complicate your layouts.

Using this control provides the following advantages:

  • it changes dynamically as the application environment changes. In other words, the added controls can proportionally resize, when the parent control is resized or text length changing due to localization etc.
  • you can add any Windows Forms control to a cell in this TableLayoutPanel control, allowing you to construct sophisticated layouts
  • controls can span (cross) multiple rows and columns, which also allows you to construct sophisticated layouts
  • being a table, this control can easily expand, by adding additional rows and/or columns to accommodate new controls, without you needing to manually re-configure the alignment of the other controls
  • through the use of row and column styles, you can specify how the Height (row style) or Width (column style) should be calculated

However, Microsoft recommends that you use the TableLayoutPanel control sparingly and provides the following Recommendations for using TableLayoutPanel controls.

IMPORTANT: When you DELETE a TableLayoutPanel control an error occurs because it is only PARTIALLY removed at design time, so you need to save, close and reopen the graphic form to complete the removal of this control and its added controls.

WARNING: Immediately after deleting a TableLayoutPanel control, although this control and/or the added controls may remain on the graphic form, any further configuration of them will be lost as these will be removed the next time you save and reopen this graphic form.

How to use this control to layout your controls on a graphic form: this describes how to add and arrange controls in a TableLayoutPanel control on a graphic form.

  1. Add this control to the required graphic form. For details, see Adding TableLayoutPanel controls.
  2. Either use the Tasks menu or the right click menu items provided by this control to add, insert and/or remove rows and columns, as needed.
  3. If necessary, determines how the available space (in the TableLayoutPanel control) is allocated for each column and row. For details, see Setting row heights and column widths in the TableLayoutPanel.

  4. Add controls to a TableLayoutPanel by dragging and dropping the controls in the relevant cells of the TableLayoutPanel control.

    Note: Each control that is added to a TableLayoutPanel becomes a child control that inherits several additional properties, which when used together with its existing properties can assist in its layout within this table.

  5. Layout the controls in this table, by using their existing and additional properties. For details, see Laying out controls in a TableLayoutPanel.
  6. Test that the layout of the controls in this graphic form are working as desired in Run mode.

To add this control to a graphic form: A control needs to be added to a graphic form before it can be used and configured.
