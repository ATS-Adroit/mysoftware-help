TemplateGO controls task menu

The Tasks menu of the TemplateGO control, provide the following tasks or common configuration options for displaying a graphic form:

Note: This menu of tasks is displayed when the control is initially added and can be accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control.

Appearance

  1. Browse for Graphic Form...: the Graphic Form Selection configuration dialog allows you to select the required graphic form to display. For more details, see Connecting graphic forms to TemplateGO controls.

Instance

This section allows you to quickly construct (clone) graphic forms from pre-configured graphic forms. Click for more details:use a TemplateGO control to add the required graphic form to (the required location on) a new graphic form and then copy its controls and/or graphic elements and their spiders to the new graphic form.

  1. Use Container Control: If checked, this copies all the controls from the child graphic form into a container control on the parent graphic form and link them to their configured spiders. If unchecked, the controls are directly added to the parent graphic form, where they currently are.
  2. Type of Container Control: choose to use a Panel or GroupBox to house the controls of the child graphic form on the parent graphic form.

The GroupBox allows you to add a title and a border around the controls.

  1. Backcolor of the Container Control: specify the default color of the container control. See Selecting colors.
  2. Location of the Container Control: specify the default location, in pixels, of the left bottom corner of the container control on the parent graphic form.
  3. Use TemplateGo size: if checked (default), then the container control will be the SAME size as the child graphic form. If unchecked, then specify the height and width of the container control, in pixels in the size of the Container Control edit box.
  1. Convert GO to an Instance: this link adds the controls of the specified child graphic form to the parent graphic form and removes the TemplateGO control.

Parameters

  1. Open TemplateGO Aliases...: the TemplateGO Alias Setup configuration dialog allows you to connect the required data elements to the aliases of the selected graphic form. For more details, see Connecting data elements to aliases.

Note: You cannot configure aliases until you have browsed in a graphic form.

Behaviours

  1. New Behaviour: To add a Behaviour to this control. See About Behaviours.
