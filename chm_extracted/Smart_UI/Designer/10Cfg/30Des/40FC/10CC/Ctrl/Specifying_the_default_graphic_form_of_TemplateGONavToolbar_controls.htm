Specifying the default graphic form of TemplateGONavToolbar controls 

Specify the graphic form that this TemplateGONavToolbar control displays by default. For instance:you may want this control to display an overview graphic form.

Note: This displays the specified graphic form in this control so that you can see exactly how it appears at runtime.

To select the default graphic form:

  • Either use the Browse for Graphic Form task: this task is provided by the Task menu, which is displayed when the control is initially added and can be accessed by clicking its glyph, which is usually displayed in the top left corner of the selected control.

Using the Browse for Graphic Form task:

    1. If necessary, add the TemplateGONavToolbar control to the required graphic form. For details, see Adding TemplateGONavToolbar controls.
    1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. this TemplateGONavToolbar control.
    2. If necessary, click the glyph, which is usually displayed in the top left corner of this control, to display the menu of tasks
    3. Click the Browse for Graphic Form... hyperlink to display the Graphic Form Selection configuration dialog.

This contains an explorer view of all of the projects and their graphic forms configured within the Projects category of each Server connection in the Enterprise Manager.

    1. Select the required graphic form within this explorer view.

Tip: It is also possible to select the required graphic form by double-clicking on it.

    1. Only check the Include Server Name in selection checkbox if you SPECIFICALLY want this control to ONLY connect to this specific Server, otherwise if unchecked the control will look for this graphic form on the currently specified default (logon) Server.
    2. Check the Exclude Project Name (Relative Path) checkbox option, if you want to ensure that the specified graphic form will still be located when the project name is renamed or when this graphic form is copied to another project, while preserving its relative path.
    3. Click Finish.

The fully qualified namespace of the currently selected graphic form is displayed in the field at the bottom of the explorer view, which adheres to the following format:

ProjectName.{Folder(s)Name(s)}.GraphicFormName, where {..} indicates that the Folder(s)Name(s) are optional and depend upon the organization of this project.

Note: If the Exclude Project Name (Relative Path) checkbox is checked then this does NOT provide the ProjectName portion.

If the Include Server Name in selection checkbox is checked then this also includes the following at the beginning: [MachineName] ServerName.

    1. The specified graphic form should be displayed within the control.

Note: This control can be configured to automatically resize to contain this graphic form, by enabling its AutoResize property.

 

  • Or use the GraphicFormPath property of this control to browse for the required graphic form.

Using the GraphicFormPath property:

    1. If necessary, add the TemplateGONavToolbarNavToolbar control to the required graphic form. For details, see Adding TemplateGONavToolbarNavToolbar controls.
    1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. this TemplateGONavToolbar control.
    2. Open the Properties tool window, navigate to the GraphicFormPath property and select it.
    3. Click on the browse button to the right of its value cell.

The Graphic Form Selection configuration dialog is displayed, which contains an explorer view of all of the projects and their graphic forms configured within the Projects category of each Server connection in the Enterprise Manager.

    1. Select the required graphic form within this explorer view.

Tip: It is also possible to select the required graphic form by double-clicking on it.

    1. Only check the Include Server Name in selection checkbox if you SPECIFICALLY want this control to ONLY connect to this specific Server, otherwise if unchecked the control will look for this graphic form on the currently specified default (logon) Server.
    2. Check the Exclude Project Name (Relative Path) checkbox option, if you want to ensure that the specified graphic form will still be located when the project name is renamed or when this graphic form is copied to another project, while preserving its relative path.
    3. Click Finish.
