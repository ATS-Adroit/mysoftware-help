Laying out controls in a TableLayoutPanel

Each control that is added to a TableLayoutPanel becomes a child control that inherits several additional properties, which when used together with its existing properties can assist in its layout within this table, as follows:

Note: The TableLayoutPanel provides a number of properties that can be used for designing its layout. For details, see Important TableLayoutPanel properties.

Tip: Being a table, this TableLayoutPanel control can easily expand, by adding additional rows and/or columns to accommodate new controls, without you needing to manually re-configure the alignment of the other controls.

Stretching and aligning controls

You can use the Anchor property of the control to align to a particular side (e.g. Left will stick it to the Left side). Using opposing anchors, the control can be stretched. E.g. Anchor=Left|Right will stretch to fill the width. The Dock property works in a similar manner.

Adjusting the distance from the cell edge

The Margin property of control can adjust the distance from the edge of the cell.

If you change the Anchor to be Top|Left and change the Margin to be (20,3,0,0) the control will be 20 pixels from the left edge and 3 pixels from the top.

Spanning controls across multiple rows and columns

Cells can be merged in the TableLayoutPanel control by spanning controls across rows and/or columns, as follows:

Example:

To span a control across two columns: select this control in the TableLayoutPanel control and set the ColumnSpan property of this control to 2.

This allows this control to occupy the next (rightmost) column in addition to the column that it is currently in - now you need to resize this control accordingly to occupy all or part of the next column.

To span a control across two rows: select this control in the TableLayoutPanel control and set the RowSpan property of the control to 2

This allows this control to occupy the next (bottommost) row in addition to the row that it is currently in - now you need to resize this control accordingly to occupy all or part of the next row.

To span a control across two columns and three rows: select this control and set its RowSpan property to 3 and its ColumnSpan property to 2.

Positioning controls within the table

Cell: the current position or location of this control in the table, which is specified by: Column, Row properties, which are integers starting from 0 (the first column and row).

Note: The Column and/or Row properties cannot be externally driven to change the location of a control within the TableLayoutPanel control's table.
