TrendConfigurator controls

The TrendConfigurator control provides users the ability to configure and save trended values (pens) in a set, which they can then reload when they next logon. In this way, each user can customise the values trended using an associated LineChart control, according to their requirements.

The following improvements have been made to the TrendConfigurator control:

  • an optional inbuilt LineChart can be used;
  • a new Adroit DataSource Mode is provided that allows you to directly browse, list and select Adroit data element names for each pen, without requiring the need for scripting, a database or Agent group to list Adroit data elements for pens;
  • the list of set names in the Set Name drop-down list can be sorted in alphabetical order;
  • Each pen provides advanced settings that affect how the series of this pen will be charted or how the vertical Y-Axis of the LineChart for the pen is displayed;
  • the list of available pen (charted) values in the Pen drop-down list can be sorted in alphabetical order;
  • the new Advanced Set Configuration dialog allows users to configure the display of the bottom (X) chart axis of each set;
  • users can also configure the chart axes of the associated LineChart at runtime and
  • users can now export and import the configuration of all the sets in the currently logged on user’s profile to and from an XML file to bulk configure these.

To add this control to a graphic form: A control needs to be added to a graphic form before it can be used and configured.

Note: The TrendConfigurator control is located in the Data section of the Toolbox window, where the LineChart control is.

How to configure the TrendConfigurator control:

Open the Tasks menu, which is typically displayed when this control is initially added and can be accessed from the glyph of this control to configure this control (some settings like the Column Settings tab are only available in the TrendConfigurator Setup dialog, which is launched by clicking the Configure TrendConfigurator link).

Choose how (from which product) this TrendConfigurator control will obtain the tags (values) to use for the pens that will be charted, by selecting and configuring the required DataSource Mode:

Note: Each mode provides its own data configuration which affect the default Column Settings that are available.

  • Adroit: In this case the tags (values) are located within an Adroit Agent Server, so specify the name of the required associated Adroit database, from the Adroit DataSource drop-down list.

If you want default Adroit tags to be available for selection from the Pen drop-down list at runtime, then click the browse (...) button to the right of the Default Data Elements field to browse in a list of predefined tags that are unique to this TrendConfigurator control.

Note: Any tags that you specify will always appear in the Pen drop-down list at runtime and cannot be removed from this list at runtime.

Tip: This also be configured via the DefaultDataElements property (but not via the TrendConfigurator Setup dialog).

If necessary, users can also browse in additional tags to the Pen drop-down list at runtime via the browse (...) button to the right of this field.

Note: These additional tags can be removed from the Pen drop-down list at runtime, by selecting the required tag in the list and clicking the button on the right.

Since this mode expects the list of tags that are to be charted to be directly browsed in, the Column Settings tab of the TrendConfigurator Setup dialog provide the following options:

Note: Both the Area and Device columns are disabled and hidden as they are not used to locate the browsed in tags in this mode.

  1. Pen: this column displays a drop-down list of all the browsed in tags.

    Specify the width (in pixels) of this column in the Pen (Tag Name) Column Width field.

  2. Title: this is the Series name for this charted Pen.

    Specify the width (in pixels) of this column in the Title (Series Name) Column Width field.

    Note: By default this column displays the description of the tag as this is usually more descriptive than the tag name itself. However, if you want the series to display the tag name [AgentName.Property(Slot)Name] instead then uncheck the Use Pen (Tag) Description for Series Names instead of Tag Names checkbox in the General Settings tab (the UsePenDescForSeriesName property).

  • MAPS: In this case the tags (values) are located within a MAPS project so specify the required project from the MAPS Project drop-down list.

You also need to select the name of the required associated Adroit database, from the Adroit DataSource drop-down list.

This will expose all the tags that you want your users to trend (contained within the required plant areas and their devices) and automatically populates the provided lists with their values.

Since each MAPS project enforces an extended physical hierarchical structure of automation projects specified by the ISA S88 and S95 standards, when specifying which values (tags) need to be trended, the Column Settings tab of the TrendConfigurator Setup dialog provide the following options:

Note: Of these columns only the Pen and Title is mandatory, both the Area and Device columns can be hidden if needed.

  1. Area: this is the Area level of physical structure of automation projects described by the ISA S95 and S88 standards. The level above this is the Site level. The Area contains one or more Process Cells or PLCs, which in Adroit-speak are communicated to via Devices.

    Typically, when displayed this column provides a drop-down list of all the configured areas of this MAPS project.

    Note: If necessary, you can use the PresetArea property to specify a static value that is automatically selected for this column, that disables its drop-down list to prevent any other value from being specified.

    Tip: If necessary, hide this column from appearing in the control by unchecking the Show Area Column checkbox.

    Specify the width (in pixels) of this column in the Area Column Width field, which if it provides a list of values also needs to accommodate the width of the drop-down list button.

  2. Device: this is the Process Cell level of physical structure of automation projects described by the ISA S95 and S88 standards. Which in SCADA projects equate to the PLCs of each defined plant Area. This is called Device, since Adroit uses a Device to communicate to each PLC, within a Plant Area. Each Device contains one or more values (Pens).

    Typically, when displayed this column provides a drop-down list of all the configured devices (for the specified area) of this MAPS project.

    Note: If necessary, you can use the PresetDevice property to specify a static value that is automatically selected for this column, that disables its drop-down list to prevent any other value from being specified.

    Tip: If necessary, hide this column from appearing in the control by unchecking the Show Device Column checkbox.

    Specify the width (in pixels) of this column in the Device Column Width field, which if it provides a list of values also needs to accommodate the width of the drop-down list button.

  3. Pen: this is the Unit and Equipment module and the Control module levels of the physical structure of automation projects described by the ISA S95 and S88 standards. This contains the values (tags) within the specified Device.

    Typically, this column displays a drop-down list of all the tags contained within the specified Device of the specified Area of this MAPS project.

    Specify the width (in pixels) of this column in the Pen (Tag Name) Column Width field.

  4. Title: this is the Series name for this charted Pen.

    Specify the width (in pixels) of this column in the Title (Series Name) Column Width field.

    Note: By default this column displays the description of the tag as this is usually more descriptive than the tag name itself. However, if you want the series to display the tag name [AgentName.Property(Slot)Name] instead then uncheck the Use Pen (Tag) Description for Series Names instead of Tag Names checkbox in the General Settings tab (the UsePenDescForSeriesName property).

  • AEMS: This mode allows you to connect to the required AEMS DataSource and to chart sensor tags from the EMS Datasource tree, which are located with the specified Adroit DataSource.
  • Custom (via Script\Spider): this was the legacy and fairly complicated method of allowing Adroit users to use this control by storing the Adroit tags in a database and then using scripting and/or the Spider engine to populate and drive the required tag-locating drop-down lists.

Note: This method has been superceded by the simpler Adroit mode.

Tip: Driving both the Area and Device drop-down lists are optional, if you do not wish to select a list of tags per device per area and just want to drive the Pen column drop-down list with a list of all tags instead.

By default the TrendConfigurator control will use the inbuilt LineChart since the Use Built-in LineChart checkbox is checked in the Tasks menu and in the General Settings tab of the TrendConfigurator Setup dialog.

Note: This is only checked for new TrendConfigurator controls to preserve backwards compatibility.

If you want the TrendConfigurator control to connect to an external LineChart control, then uncheck the Use Built-in LineChart checkbox (UseBuiltinChart property) and select the required LineChart to link this control to (on the same graphic form) from the Line Chart drop-down list (the ChartName property).

If you want the TrendConfigurator to sort the list of set names in the Set Name drop-down list in alphabetical order, then check the Sort Set Names checkbox (SortSetNames property).

By default this setting is unchecked, so that they are listed in the order that they are created to preserve backwards compatibility with existing TrendConfigurator controls.

If you want the TrendConfigurator to sort the list of available pen (charted) values in the Pen drop-down list in alphabetical order, then check the Sort Pen Dropdown checkbox (SortPenDropDown property).

By default this setting is unchecked, so that they are listed in the order that they are created to preserve backwards compatibility with existing TrendConfigurator controls.

If you are going to export the data to a 3rd party application, such as MS Excel then use the Series DateTime Format edit field to specify the required data time format specifier to format how the date and time of each series appears. The default is d, which is the short date format e.g. 8/20/2004.

Note: By default, the run-time configuration of all TrendConfigurator controls are stored in a user profile variable called TrendConfigurator. Therefore if you want to maintain separate lists of sets for your TrendConfigurator controls, then rename this variable of each TrendConfigurator control in the The Setting Name to use to load and save the Set configuration to the Users Profile field of the General Settings tab of the TrendConfigurator Setup dialog (or use the UserProfileSetting property).
