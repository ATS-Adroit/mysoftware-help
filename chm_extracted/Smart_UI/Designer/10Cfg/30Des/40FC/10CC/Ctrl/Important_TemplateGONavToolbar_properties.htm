Important TemplateGONavToolbar properties

Although the following properties are useful when configuring a TemplateGONavToolbar control to create a hierarchical menu structure or graphic form navigation system, you should typically use the smart taga glyph that usually displayed in the top left corner of the selected control or vector that when clicked displays a list of the commonly used configuration tasks. Tasks menu to configure this control. For details, see TemplateGONavToolbar controls task menu .

Note: These properties can be viewed and configured in the Properties tool window.

Property Function

Autosize

This Boolean property determines whether this control will automatically resize itself to display a graphic form, if this control is smaller than the graphic form that it contains. This is disabled (False) by default.

AutoScroll

This Boolean property either enables or disables scrollbars that appear if the control is smaller than the graphic form that it contains. This is disabled (False) by default.

Note1: Its sub-properties determine how much smaller the graphic form needs to be before these scrollbars appear.

Note2: By enabling the Autosize property this control will initially be resized to the size of the graphic form it contains, after which its size can be adjusted as necessary.

Aliases

This property exposes all the specified aliases of BOTH the default hosted graphic form AND the graphic forms added to the toolbar, so that values can be assigned to them, if required. For details, see Connecting data elements to common aliases. 

GraphicFormPath

This property is used to specify the default or overview graphic form displayed by this control. For details, see Specifying the default graphic form. 

ShowPreviewPane

If this Boolean property is enabled (True), a preview window (tooltip) is displayed when you hoverposition the mouse pointer over a specific item on the screen. over a toolbar item. The contents of this tooltip is determined by the ToolStripDisplayStyle property, as follows:

  • None: no tooltip is displayed
  • Text: this displays the graphic form path
  • Image: this displays an enlarged representative view of the graphic form
  • ImageAndText: this displays BOTH elements.

ShowToolbar

This Boolean property allows you to hide or display toolbar at design time.

ToolbarLocation

This allows you to graphically change the docking position of the toolbar, along the four sides of the control.

ToolStripDisplayStyle

This allows you to specify how you want to identify the toolbar items, the following options are available: None, Text (only), Image (only) or ImageAndText (the default).

Note: If you select a display style requiring images, then you need to configure this control to provide condensed images of each graphic form, see Adding toolbar item images.
