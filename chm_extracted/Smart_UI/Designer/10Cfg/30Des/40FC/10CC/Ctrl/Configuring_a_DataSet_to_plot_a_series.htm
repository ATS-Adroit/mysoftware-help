Configuring a Dataset to plot a series

The DataSet tab allows you to specify which of the fields of a table are used to chart a series, as follows:

Note1: This tab is ONLY displayed if the Datasource field of the currently selected series specifies DataSetDataElement.

Note2: The Use Field Indexes option allows you to specify the fields of the table by using their indexes and NOT their names, so that you continue to obtain their data even if these names are changed at a later time.  

  1. Click the browse button to the right of the DataElement edit box to use the Data Element Browser dialog to select the required dataset, as follows:

    This dialog displays a tree view of all the datasources and their data elements that are contained within the connected Servers, like that displayed by the Enterprise Manager.

    The value selected initially by this browser is determined, as follows:

    • If you have NOT selected a data element for the current field, then it displays the last data element, that you browsed in, using ANY DE browser.

    Tip: This is particularly helpful, when you are working with the SAME datasource, as it expands this datasource in the tree, highlighting the last browsed-in data element, which you can use as a reference.

    • If you have browsed in a data element for the current field, then this then data element is automatically selected for you.
    • If necessary, expand the datasources in the tree, to expose the required data element, by clicking their plus boxes .

    The name of the currently selected data element is displayed at the bottom of this configuration dialog.

    • Double click the required data element.

    The Data Element Browser dialog provides the following features to assist you in this task of selecting the required value:

    1. The Recently selected elements list, which displays the last 10 selected data elements - so that these data elements can be quickly selected again, whose display is controlled by the or button in the top right hand corner.

    If the data element, in this Recently selected elements list, does not have an associated icon, then either this data element does not exist or, in the case of the Adroit datasource, that you have not opened the associated Agentgroup in the Adroit datasource tree and so if this data element is selected it will not be found in the Browser window.

    1. The ability to display the current value of the data elements you are currently or have previously selected, by clicking the button in the top right hand corner, which adds the Watches column to the Recently selected elements list (when this is displayed) and the icon and current value to the right of the currently selected data element at the bottom of this dialog.
    2. A data element searching capability to quickly locate similarly-named values without manually browsing for them: simply type the required search criteria into the Search in browser for edit box and all the data element names containing the specified search string are displayed in a list providing the name of the data element and its path. If necessary, click the button to return to the tree view.

    By default, to speed up searching on large Adroit Agent Server projects, the searching stops at the agent and not the slot level.

    1. The tree view provides the full Enterprise Manager context sensitive right click menu functionality. So in the case of using an Adroit datasource you can create the required agent/s when configuring a Behaviour.
    2. When selecting tags from an Adroit datasource, you can also create on-the-fly agents by editing the selected data element string to create another tag. In this case, when you click Finish, a message is displayed asking whether you want to create this new tag or not, if you select Yes then this tag is created and selected.

    For instance this could be a table from a database that is connected to an OLE DB datasource.

Note: You only need to press the Set button if you need to specify a different DataSet value from the one you previously selected. 

This populates the other fields with table/s and their fields that are contained within the specified DataSet.

  1. Select the table that contains the fields that you want this line series to represent from the Table list box.

For a line series: these options are displayed when the Type field of the currently selected series specifies Line.

  1. Specify the field to plot on the Y axis from the YValue Member list box, this is typically a value field.
  2. Specify the field to plot on the X axis from the XValue Member list box, this is typically an ID field.
  3. Specify the field to use to label the points of this line series from the Label Member list box, this is typically a String field.
  4. If necessary, specify the field to use to color the points from the color Member list box, as follows:this column must be of type system.object and contain the name of the required system colors objects such as color.White, color.Blue etc. which is usually done in code.  

Typically you will use the YValue, XValue and Label members.

For a pie series: these options are displayed when the Type field of the currently selected series specifies Pie.

  1. Either select the field that specifies the size of each slice from the PieValue Member list box, this is typically the required value field. This is the recommended as it is more widely applicable.
  2. Or select the field to specifies the size of each slice as an angle, in degrees, from the Angle Member list box, as follows:if necessary, instead of using values to specify the size of each slice, you can specify the angular displacement of the required slices i.e. values starting from 0 and ending at 360. 
  1. Select the field that labels each slice of this pie series from the Label Member list box, this is typically an ID field.
  2. If necessary, specify the field to use to color the slices from the color Member list box, as follows:this column must be of type system.object and contain the name of the required system colors objects such as color.White, color.Blue etc. which is usually done in code. 

Typically you will only use the PieValue and Label members.

For a bar series: these options are displayed when the Type field of the currently selected series specifies Bar.

  1. Specify the field to plot on the Y axis from the BarValue Member list box, this is typically a value field.
  2. Specify the field to provide values to label each bar of this series from the XValue Member list box, this is typically an ID field. 
  3. Specify the field to provide text strings to label each bar of this series from the Label Member list box, this is typically a String field.
  4. If necessary, specify the field to use to color the bars from the color Member list box, as follows:this column must be of type system.object and contain the name of the required system colors objects such as color.White, color.Blue etc. which is usually done in code.  

Typically you will only use the BarValue and Label members.

For a column series: these options are displayed when the Type field of the currently selected series specifies Column.

  1. Specify the field to plot on the Y axis from the BarValue Member list box, this is typically a value field.
  2. Specify the field to provide values to label each column of this series from the XValue Member list box, this is typically an ID field. 
  3. Specify the field to provide text strings to label each column of this series from the Label Member list box, this is typically a String field.
  4. If necessary, specify the field to use to color the columns from the color Member list box, as follows:this column must be of type system.object and contain the name of the required system colors objects such as color.White, color.Blue etc. which is usually done in code.  

Typically you will only use the BarValue and Label members.

For a Surface series: these options are displayed when the Type field of the currently selected series specifies Surface.

  1. Specify the field to plot on the Y axis from the YValue Member list box, this is typically a value field.
  2. Specify the field to plot on the X axis from the XValue Member list box, this is typically an ID field.
  3. Specify the field to plot on the Z axis from the ZValue Member list box, this is typically an date time field.

Note: There is NO color member, this is determined by the color Mode you select from the Surface Style tab.

  1. Specify the field to use to label the points of this Surface series from the Label Member list box, this is typically a String field.

Typically you will use the YValue, XValue, ZValue and Label members.

For an XY plot series: these options are displayed when the Type field of the currently selected series specifies XYPlot.

  1. Specify the field to plot on the Y axis from the YValue Member list box, this is typically a value field.
  2. Specify the field to plot on the X axis from the XValue Member list box, this is typically an ID field.
  3. Specify the field to use to label the points of this XY plot series from the Label Member list box, this is typically a String field.
  4. If necessary, specify the field to use to color the points from the color Member list box, as follows:this column must be of type system.object and contain the name of the required system colors objects such as color.White, color.Blue etc. which is usually done in code.  

Typically you will use the YValue, XValue and Label members.
