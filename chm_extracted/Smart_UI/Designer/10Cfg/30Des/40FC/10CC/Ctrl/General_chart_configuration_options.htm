General chart configuration options

The chart configuration dialog provides the following generally applicable configuration sections:

To launch the configuration dialog:right click the charting control and select the Edit Chart... menu option.

  • Title: To specify the main Header title of the chart.

    Tip: You can also specify this by using the tasks menu of the charting control.

  • Titles Setup: To configure the display of the chart titles and, if necessary, to add additional chart titles.
  • Legends Setup: To display the chart legend and specify and what the elements of each series are displayed in the legend and the format of these elements.

    Specify which elements of each series are displayed in the legend (names or values) from the Legend Style list.

    If the legend displays values, then use the Text Style to specify their required value/s and format.

    Note: Typically you display series values for Pie, Bar and Column charts and series names for Line and XYPlot charts, which are the default selections.

    Other noteworthy options:

    To allow your users to select which series they want charted, ensure that the Checkbox option if checked.

    To display a legend for this chart, ensure the Visible option is checked.

  • 3D Settings: To display the chart in three dimensions to add depth to your chart and rotate, zoom and/or move the plotting area of the chart.

    To enable these settings ensure the 3 Dimensions checkbox is checked.

    The 3D % spin control specifies the required depth or third dimension of this chart.

    The Horiz Offset moves the plotting area left/right.

    The Vert Offset moves plotting area up/down.

    Tip: The Default Settings button always brings the chart back into the viewing area.

    Use the Quality list box to specify how the chart should be plotted. The is a tradeoff between speed and the level of detail, with the lower options in this list becoming progressively more detailed and therefore slower.

    Tip: Change this Quality setting to Best Speed for SurfaceChart controls for better performance, since the drawing of these charts is sluggish as they require a lot of processing.

  • Fill Effects Settings: To configure how the chart and/or plot area or graph is colored and/or shaded.

    Note: The ‘Walls’ of the Plot Area appear when the chart is in 3D mode.

Note1: Since most of these settings alter the display of the chart, use the preview pane to customise these settings to meet your needs.

Note2: The preview pane uses RANDOM data, NOT the actual data that you are charting.
