TimePicker controls

The TimePicker control allows users to specify (or display) a time (day, hour, minute and second) by using spin controls, which is stored in milliseconds.

Example:

How to specify the required time value: this describes how to add and configure a TimePicker control so users can specify the required time value.

Note: This assumes that you already have the required unsigned Double or compatible variable to store this time value in milliseconds.

  1. Add this control to the required graphic form. For details, see Adding TimePicker controls.
  2. Click its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs. (usually displayed in the top left corner) and select the Bind Value Behaviour from the New Behaviour list
  3. Select the From Control Property option from the Bind Value Behaviour dialog.
  4. Select TimeValue in the From Property list.
  5. Select ValueChanged in the Trigger On Event list
  6. Select the value that you want to store the time in milliseconds from the To Data Element field, typically by clicking the browse button and using the data element browser.
  7. Click the Finish button.
  8. Save the changes you have made to this graphic form.
  9. Test that when you specify a new time in the TimePicker control that the specified value is updated in Run mode (this can by done by adding a Label control to the graphic forms and connecting the value to its Text property via drag and drop).
  10. If necessary perform whatever additional numerical or formatting manipulation is required to convert this time value into an appropriate value and format, for instance if this needs to be saved to a database field etc.

How to display a time value in milliseconds by using this control: this describes how to add and configure a TimePicker control so users can view the required time value.

Note: This assumes that you already have the required unsigned Double or compatible variable that contains the time value in milliseconds.

  1. Add this control to the required graphic form. For details, see Adding TimePicker controls.
  2. Drag the value (typically an unsigned Double) onto the TimePicker control
  3. Select the name of the required TimePicker control from the To Control Property... menu
  4. Select its TimeValue property (if this property is not displayed in the list, click the Customise... option and scroll down to and check the TimeValue checkbox and click the Finish button).
  5. Test that this TimePicker control displays the correct time in the graphic form in Run mode.

To add this control to a graphic form: A control needs to be added to a graphic form before it can be used and configured.

End-user interaction

Users either specify the required Day, Hour, Minute and Second by using the provided spin controls or view the time using these fields.
