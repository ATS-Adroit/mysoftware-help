AdroitHistoricalAlarmViewer controls task menu

The Tasks menu of the AdroitHistoricalAlarmViewer controls, provide the following tasks or common configuration options for configuring this control:

Note1: The Initial and/or General Configuration dialogs can perform most of these configuration tasks. To launch this configuration dialog:right click the AdroitHistoricalAlarmViewer control and select the General Configuration Settings menu option.

Note2: This menu of tasks is displayed when the control is initially added and can be accessed by clicking its smart taga glyph that usually displayed in the top left corner of the selected control or vector that when clicked displays a list of the commonly used configuration tasks. .

General Settings

  • Server: Specify the name of your SmartUI Server that contains the required OLEDB Datasource.
  • Datasource: Select the OLEDB Datasource on this SmartUI Server that is connected your AlarmManagement agent SQL Server database.
  • Best Fit Columns: This checkbox is checked by default to force all the displayed columns in the grid to automatically resize their widths so that their contents fit in the control without requiring any horizontal scrolling.
  • Columns: Click the browse (...) button to choose which columns are displayed in the grid, their order and their specific properties as you would when using the Columns tab of a relevant configuration dialog. For details, see Configuring AdroitHistoricalAlarmViewer columns.

  • Use Paging: This checkbox is checked by default to group the available alarms in the grid into pages of alarms. Paging makes it easier for users to browse a large number of alarms.

    Note: When unchecked this disables (greys out) the 4 paging navigation buttons and the Page size edit field on the left of the toolbar .

  • Page size: This is ONLY displayed when paging is used to specify the default number of alarms that are displayed on each page.
  • Enable Filtering: This checkbox is checked by default to allow users to add and/or use filters to restrict or limit the number of displayed alarms initially. However, even if unchecked users can still select the Enable Filtering option from the Filter tool menu to use filters.

  • Predefined Filters: This allows you to create general-purpose filters that always appear in the Filter list of the toolbar, which your users can immediately use to refine the displayed alarms. More details:

    Click the browse (...) button to display the CustomFilter Collection Editor.

    Click the Add button, then specify the required FilterName and its FilterString of this filter

    Tip: An easy way to determine the required FilterString, is to run the graphic form and then click the Filter tool menu of the toolbar and select the Add Filter... item and then click the + button or press the INSERT key and define the required filter that you want and then write down the filter string displayed at the bottom of this Add Filter dialog and type this into this FilterStringedit field.

    FilterString Examples:

    DateTime <= 2015-08-03 : [DT] <= #2015-08-03#

    Incident Begins with D : [Incident] Like 'D%'

  • Enable Find: This checkbox is checked by default to displays the Find bar beneath the toolbar, so that users can type in a string so that ONLY rows containing this specified text string is displayed. However, even if unchecked users can still select the Enable Find tool to display the Find bar themselves.

  • Group Summaries:These are summaries or group-specific calculations that are ONLY displayed when you group data, by dragging the relevant column/s into the grouping bar above the column headers. More details:

    Note: By default these summaries are displayed next to each grouped item, whether expanded or collapsed, unless you specifically specify the ShowInGroupColumnFooter field, in which case the group summary bar is displayed and this group summary will be displayed in the column for each specific group is displayed.

    Click the browse (...) button to display the GroupSummary Collection Editor.

    Click the Add button, then specify the required summary, by specifying the following fields:

    • FieldName: the field that the summary operation applies to, this is the actual name of the database field, for instance DT and not the displayed description, in this case DateTime
    • ShowInGroupColumnFooter: if this is left BLANK then the specified summary is displayed next to each grouped item, whether expanded or collapsed; otherwise the group summary bar is displayed and this group summary will be displayed in the column for each specific group is displayed.
    • SummaryDisplayFormat: display format of the resultant summary calculation and any additional text that this should provide, for instance: {0:n0} rows
    • SummaryType: the type of the summary calculation that is required, for instance: Count.

    Tip: A useful group summary is displaying the number of rows contained within each group, which you can configure as follows:

    FieldName: DT

    ShowInGroupColumnFooter: leave this BLANK

    SummaryDisplayFormat: {0:n0} rows

    SummaryType: Count

  • Refresh Mode or Subscription Update Mode: Select the required method used to refresh this control with recent alarms, depending on how the Historical Incidents table of the AlarmManagement database has been connected to this control. For more details, see Configuring how to update AdroitHistoricalAlarmViewer controls.

Appearance Settings

  • Toolbar Visible: This checkbox is checked by default to displays the toolbar in the control, so users can use its tools to view and/or locate and/or filter the historical alarms they require and/or configure the display of this grid and its columns at runtime.
  • Toolbar color: specify the required background color of the toolbar, since this is NOT changed by the selected Look and Feel Skin.
  • Look and Feel Skin: select the required theme which ONLY affects the color and formatting of the grid; although you can separately configure the background color of the toolbar via the Toolbar color.
  • Alternate Row colors: This checkbox is unchecked by default to not enable the Alternate Row color tool by default to display the odd and/or even rows in the grid with the colors specified by the Appearance tab of the relevant configuration dialogs, since these colors are not configured by default.
