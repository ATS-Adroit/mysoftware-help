TemplateGOContextNav controls

In addition to viewing the defined contexts in the Context View window in the Operator you can also use this control to displays all the graphic forms and object instances that have been added to your defined contexts.

Typically this control is used to view the Default context in the Operator, to display the graphic forms associated to the nodes of this context and/or any additional graphic forms added to the nodes too.

This is a modified TemplateGO, which provides the Context View window pane on the left and a TemplateGO on the right.

This control is located in the Templates category of the Toolbox tool window.

Configuration options:

The Tasks menu of this control, provides the following task:

Note: This menu of tasks is displayed when the control is initially added and can be accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control.

  1. Browse for a Default Graphic Form to load...: the Graphic Form Selection configuration dialog allows you to select the graphic form that this control displays when it is initially loaded. For more details, see Selecting the default graphic form of the TemplateGOContextNav control .

End user interaction:

Double clicking a node (that has an associated graphic form) in the left Context View pane, displays the associated graphic form in the TemplateGO pane on the right.

Note: This only occurs if the Use default checkbox was checked when associated the graphic form to this node, which is the default option.

Tip: Double clicking a node also expands or collapses it in the Context View pane.

When object instances are selected they display their associated wizard graphic and the appropriate process values for this object. You can also right click the object instances and select:

  • Show attributes - this is only displayed when the selected item is an object instance and lists all the attributes and values that are defined for this object.
  • Show children - this displays all the children of this item:
    • If this is an agent, then its slots are displayed as sub-items in the tree.
    • If this is an object instance, then all the defined child instances are displayed as sub-items in the tree etc.
