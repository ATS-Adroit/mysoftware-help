Exporting charts

This exports the current chart as an image file and/or to export the current chart configuration settings as a template file(.ten) and/or to export the charted data to a file.

Note: The (Toolbar) ExportChartButtonVisible property needs to be enabled to display this toolbar button.

To export the chart:

  1. Click the Export Chart toolbar button from the toolbar of the required charting control to display the TeeChart Export configuration dialog.

To export the chart as a picture: this saves the current chart as an image, either in one of the supported image file formats and/or to the clipboard so that it can be pasted into another application.

  1. Select the Picture tab.
  2. If necessary, specify the required Format of the image file
  3. If necessary, use the Options tab to specify whether the colors are to be left unchanged (Default) or set to Grayscale.
  4. If necessary, use the size tab to specify the required Width and Height of the image in pixels and if you want to Keep aspect ratio or not.
  5. Either click Copy to copy the currently configured image to the clipboard.
  6. Or click Save... to specify required path and filename of the currently selected Format.

To export the current chart configuration settings: this can save these settings and the current series data to a template file (.TEN), which can be imported into another charting control so that it can have the same look and feel.

  1. Select the Native tab.
  2. If necessary, you can Include Series Data along with the chart configuration settings.
  3. Check the File size checkbox to obtain an estimate of the size of this template file.
  4. Either click Copy to copy the chart configuration settings to the clipboard.
  5. Or click Save... to specify required path and filename of the template (.TEN) file.

  To import a chart configuration settings template file, which configures the chart accordingly, see Importing chart templates.

To export the data of the charted series: this can save this data to one of the following file types: text, xml, an html table or an Excel spreadsheet file.

  1. Select the Data tab.
  2. Select the required Series from list box.
  3. Specify the file Format for this data from the 4 options.
  4. Specify what other elements to include with the data, such as:
  5. Point Index: to display a zero based index of the charted values.
  6. Point Labels: to display the labels of the data points, if currently specified by the charted values.
  7. Header: This adds a row at the beginning of this file that describes the columns.
  1. Specify the delimiting character to use within the specified file Format, if necessary.
  2. Either click Copy to copy the currently configured data to the clipboard.
  3. Or click Save... to specify required path and filename of the selected file Format.

Tip: The Advanced View of the Style tab when configuring Line and FastLine series allow you to specify the required Value Format and DateTime Format of the exported values.

  1. Click the Close button when you have finished the exporting operations.
