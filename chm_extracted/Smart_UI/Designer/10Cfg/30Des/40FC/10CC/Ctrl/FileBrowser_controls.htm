FileBrowser controls

 

The FileBrowser control typically allows SmartUI users to display to view, edit, upload and/or delete documents pertaining to ALL the ISA S88 / S95 hierarchical levels of your SmartUI project or to simply view the documents within a specific folder on the SmartUI Server computer.

In other words, you need to use this control if your users need to access and/or manage documents (click for more details: for instance, you could add Excel worksheets, PDFs, and/or JPGs to provide easy and controlled access to product specifications, standard operating procedures, drawings etc.) associated with the entire site (MAPS Project) or plant area or unit at runtime within the SmartUI Operator. Since SmartUI natively only opens allows documents associated to each specific item of equipment.

 

To add this control to a graphic form: A control needs to be added to a graphic form before it can be used and configured.

Note: The FileBrowser control is located in the Custom section of the Toolbox window.

What you need to do before you can use the FileBrowser control:

Add this control to the required graphic form.

  1. If you intend to use this to display the documents of a SmartUI project, then ensure that the ProjectName property of this control specifies the name of the required SmartUI project.
  2. If you simply want to displays all the documents in a specific folder, then ensure that the DocumentPath property of this control specifies the required path to this directory on the SmartUI Server computer.

End-user interaction:

To operate this control: This describes how users view, edit, upload and/or delete documents provided by the FileBrowser control, at runtime.
