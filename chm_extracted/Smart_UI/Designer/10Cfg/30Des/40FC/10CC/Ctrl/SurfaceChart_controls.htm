SurfaceChart controls

These controls are typically used to plot surfaces or three dimensional charts, from points that are plotted from three sets of values. In other words one set provides the X or horizontal coordinate and the other provides the Y or vertical coordinate of each point and the third set provides the Z or height dimension.

A typical usage is if you have a curve and you want to see how this curve changes from day to day. In this case the X = period (e.g. 12am-12pm); Y = value and Z = date time e.g. number of days.

Note: You can create template charting controls, since the applicable Series values of chart controls support the use of curly brackets {} to create aliases for SmartUI Templates or data element substitutions for wizards.

Tip:Drawing surface charts is sluggish as they take a lot of processing – so it is recommended to change the Quality setting in the 3D Settings page of this configuration dialog to Best Speed for better performance.

How to chart data within a surface chart: this describes the recommended procedure for creating a surface chart on a graphic form to report your data.

This assumes that you have already added the necessary datasources to expose the data that you want to chart.

  1. If necessary, add this control to the required graphic form. For details, see Adding Charting controls.
  2. Click the Series Setup heading in the left pane of the chart configuration dialog to display the Series Setup dialog.
  3. Add the series that you want to chart and specify the data that each series should represent and if necessary specify the various options that affect how the series is charted. For details, see Adding and Configuring Series.

A Surface series is added by default. Typically you will require more than one Surface series. 

  1. If necessary, click the Axis Setup heading in the left pane of the bar chart configuration dialog to configure the axes of this chart for each of the series and their labelling and/or scaling and/or to create custom axes. For details, see Configuring axes for a series.
  2. Click the 3D Settings heading in the left pane of the bar chart configuration dialog and ensure that its Quality setting is set to Best Speed for better performance, since drawing surface charts requires a lot of processing and can therefore be sluggish.
  3. If necessary, you can specify titles for the chart and configure the legend and other 3D configuration and chart area display settings. For details, see General chart configuration options. 
  4. Click the Finish button once you have performed the initial configuration of the chart.
  5. If necessary, use the tasks provided by the displayed tasks menu to perform any additional configuration of the chart. For details of these options, see Charting controls task menu.
  6. If necessary, configure additional properties of this charting control, for instance: to hide the chart toolbar and enable the runtime configuration of the chart, some of which are chart specific. For details of the more important properties, see Important charting control properties.
  7. If necessary, add charting tools to this chart to provide additional user interaction options. For details, see Charting tools.
  8. Save the changes you have made to this graphic form.
  9. Test that the chart reports the data correctly and provides the necessary user interaction in Run mode, some of which are xyplot chart specific. For details, see Charting control toolbar.

Configuration options:

  • A configuration dialog to configure the display of the chart and its series. This simplifies chart configuration and provides a preview pane in which you can see the effects of the various display options before they are implemented. To launch the configuration dialog:right click the charting control and select the Edit Chart... menu option.

Note: The configuration dialog is the ONLY way in which you can chart data from a DataBinder. This configuration dialog also can assist you to chart DataSet data and/or data that consists of single values.

Tip: You can connect several data elements to a single series to independently drive its following attributes: color, description, maximum and/or minimum values, engineering unit, value and/or its visibility. For details, see Dragging data to charting controls to configure series.

  • A right click menu, which launches the configuration dialog and provides alternate methods of adding and removing series and/or charting tools.
  • A Tasks menu, accessed from the glyph of the charting control, which provides fast access to common display configuration options instead of launching the configuration dialog. The configuration dialog, however, should still be used to configure the charted series.
  • Important properties, this describes the functions of the important properties that can configure this charting control, some of which specifically apply to xyplot charts.
  • A toolbar, which allows your end-users to interact with and configure this chart at runtime.
