Adding menu components

Add a menu component to provides a menu system for your graphic form.

To add a menu component:

  1. Open the required graphic form.
  2. If necessary, open the Toolbox tool window.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Windows Forms category.
  1. If necessary, use the scrollbarto display the required component within this category.

Tip: It is also possible to use the mouse-wheel (if provided by your mouse) to quickly scroll through the list of form components.

  1. Click the required menu component, as follows:
  2.  ContextMenuStrip: to create a right click menu for this graphic form.
  3. MenuStrip: to create a dockable menu on this graphic form.
  4. Click on the graphic form to add this component to the graphic form.

The menu is added to the top of the graphic form, by default.

 

For more details about opening graphic forms, see Opening graphic forms.
