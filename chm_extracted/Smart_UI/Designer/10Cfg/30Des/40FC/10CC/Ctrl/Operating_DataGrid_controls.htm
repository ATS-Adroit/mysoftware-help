Operating DataGrid controls

This topic briefly explains how end-users are able to interact with the spreadsheet-type user interface provided by the DataGrid control and the data it displays. More information:

Note1: ONLY the data in the dataset, that complies with the specified filtering (if any) is displayed. For details on filtering data within a dataset, see Filtering datasets.

Note2: By default, only the changed data that is displayed. However you can also append any new or modified data to the end of the data that is currently displayed. For details, see Displaying both existing and updated dataset data.

End-user interaction:

  1. Sorting of columns: Click the heading of the column that you want to sort the displayed data by. This will sort the column in ascending order icon: , click the column heading again to sort the column in descending order icon:.
  2. Resizing of column widths: Position the mouse pointer to the left of the column heading until the pointer changes to the following icon . Either double-click to auto-size the column to fit the largest entry or click and drag to the required column size.
  3. Adding of rows: If necessary, scroll down to the last row of the grid and click the * icon to add another row to this dataset.

Note: This is only useful, if the datasource is being updated with changes made by the user. For details, see Updating datasources with datasets.
