Typical usage scenarios for TableLayoutPanel controls

This topic describes a number of ways in which to use the TableLayoutPanel control:

Auto Localization

To ensure that your controls containing your localised text automatically grow, then configure your TableLayoutPanel control as follows:

  1. Ensure that the Autosize property of this TableLayoutPanel control is set to False.
  2. Set the sizeType property of the columns or rows containing the text (labels/textboxes) to Autosize
  3. Set the sizeType property of columns or rows containing their fields (edit boxes) to Percent and configure this percentage appropriately.

Proportionally distribute space on resize

This means that when the graphic form is resized at runtime that its controls do not overlap one another, then configure your TableLayoutPanel control as follows:

  1. Ensure that the Autosize property of this TableLayoutPanel control is set to False.
  2. Ensure that all the columns and/or rows containing controls that you want to proportionally resize have their sizeType property set to Percent.

Consider the following detailed example, which creates a graphic form that auto sizes two ListBox controls:

  1. Add a TableLayoutPanel control and add 5 columns and 2 rows.
  2. Set the Anchor property of the TableLayoutPanel control to top, left, bottom, right.
  3. Insert a Label in row 1 column 1, with the text "Name:".
  4. Anchor this Label to the right side of its enclosing cell via its Anchor property.
  5. Insert a TextBox in row 1 column 3.
  6. Set the inherited ColumnSpan property of this TextBox to 3 (this will permit the person’s name to extend into the last two columns).
  7. Insert ListBox controls in row 2, columns 1 and 3. Anchor all four sides of these controls.
  8. Insert a Button control in row 2, column 5 and anchor it to the top and left of the cell.
  9. Set the CellBorderStyle of this TextBox to Single.

Non-resizable dialogs

To configure a dialogs with a fixed border:

  1. Configure the Autosize property of the TableLayoutPanel control to true.
  2. Configure the AutosizeMode property of the TableLayoutPanel control to GrowAndShrink.
  3. Configure the Autosize property of the graphic form to true.
  4. Configure the AutosizeMode property of the graphic form control to GrowAndShrink.

Resizable dialogs

To configure a dialog that provide controls that the user can resize as needed. In general, items such as labels and buttons will not need to be modified by the user. Controls that do need to be resizable are multi-line text boxes, data grids, etc...

In this case:

  1. Configure the Autosize property of the TableLayoutPanel control to false.
  2. Configure the Autosize property of the graphic form to false.
  3. Configure the Anchor property of the TableLayoutPanel control to top, bottom, left, right.

The controls that need to grow will need to be anchored top, bottom, left, right.

The other controls should be anchored however you want them to look on the form.

Hiding or showing all the controls added to a TableLayoutPanel

A TableLayoutPanel is also useful when you need to show and hide a group of controls on a graphic form based on some condition.

Instead of showing and hiding the individual controls, you can group the controls that you need to show and hide and place them on two different TableLayoutPanels and show and hide the respective TableLayoutPanels by using their Visible property.
