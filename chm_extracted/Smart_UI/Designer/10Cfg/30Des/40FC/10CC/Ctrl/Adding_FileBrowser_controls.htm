Adding FileBrowser controls

Add a FileBrowser control to allow SmartUI users to display to view, edit, upload and/or delete documents pertaining to ALL the ISA S88 / S95 hierarchical levels of your MAPS project or to simply view the documents within a specific folder on the SmartUI Server computer. For details, see FileBrowser controls.

To add a FileBrowser control to a graphic form:

  1. Open the required graphic form.
  2. If necessary, open the Toolbox tool window.
  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Custom category.
  2. If necessary, use the scrollbar to display the FileBrowser control within this category.

Tip: It is also possible to use the mouse-wheel (if provided by your mouse) to quickly scroll through the list of form components.

  1. Click the FileBrowser control.
  2. On the graphic form, click where you want the upper-left corner of this control to be located, and drag to where you want the lower-right corner of the control to be located.

This control is then added to the layer of the graphic form which is currently being edited.

For more details about opening graphic forms, see Opening graphic forms.
