TemplateGONavToolbar controls

This control allows you to create a hierarchical menu structure or toolbar of graphic forms so your end-users (operators) can navigate between them, by selecting the required toolbar or menu item, this controls displays the associated graphic form. For details, see How to create a graphic form navigational menu from a TGONavToolbar control.

Note: The currently selected menu item is persistedthis is temporary form of saving, for instance it can be session based or only while an object is open. by means of a color change.

This TGONavToolbar control consists of the following two areas:

  • The toolbar (menu), typically at the top of the TGO that contains all the sub menus and their menu items that are all linked to the appropriate graphic forms of your project/s.
  • The Template Graphic Object (TGO) control, which is the large area, typically, below the menu bar in which each Graphic Form (GF) is loaded.

The TGONavToolbar control provides a menu (toolbar) designing grid, which is launched by clicking the Browse for Toolbar Graphic Forms... task of Tasks menu (which is itself launched by clicking the smart taga glyph that usually displayed in the top left corner of the selected control or vector that when clicked displays a list of the commonly used configuration tasks. glyph of this control).

Using this menu (toolbar) designing grid, you can create this menu navigation structure quickly, for instance, you can:

  • import your existing project structure by clicking the Add Project button in the menu (toolbar) designing grid.
  • bulk configuring multiple rows at once, either in the provided menu designing grid and/or by exporting the menu to CSV, bulk configuring the menu in an external editor and then importing the edited menu into this control again.
  • provide advanced configuration of some or all of the menu items and their associated graphic forms via behaviours or graphic form scripts or spiders, since this control exposes and uniquely names every menu item (see the Toolbar Item Name column in the menu-designing grid).

Advanced TemplateGONavToolbar control configuration:

  • Decide which side of the control that you want the toolbar to be positioned, by configuring the ToolbarLocation property; by default this is located at the top of the control.
  • Decide how you want your end users to identify the toolbar items, by configuring the ToolStripDisplayStyle property, to specify whether you want the items to display text and/or images, by default both text and images are displayed.

  • Decide whether you want a preview pane (tool tip) to open when your end users hover over a toolbar item.

    This tool tip displays the path of the graphic form and/or an enlarged representative view of the graphic form depending upon your configuration of the ToolStripDisplayStyle property, by configuring the Boolean ShowPreviewPane property.

    Tip: If the ShowPreviewPane property is enabled the path of the graphic form and/or an enlarged representative view of the graphic form is displayed when a user hoversalso called a mouse hover, is the action of putting the mouse cursor (pointer) over a designated area. over a toolbar item, similar to the way the taskbar works.

  1. If you created an overview graphic form, then configure this control to display it by default. For details, see Specifying the default graphic form.

  2. Create the menu items (and sub-menus) for the graphic forms that you want your end users to navigate between.

    If necessary configure the order of these menu items and/or change their identifying text. For details, see Configuring the graphic form navigational menu.

Advanced TemplateGONavToolbar control configuration:

For details, see Connecting data elements to common aliases.
  • If you want to display images for your toolbar items, then you need to ensure that this control receives condensed images of each of the graphic forms from the Server. For details, see Adding toolbar item images.
  1. Save the changes you have made to this graphic form.
  2. Test that this graphic form navigation system works as desired in Run mode.
