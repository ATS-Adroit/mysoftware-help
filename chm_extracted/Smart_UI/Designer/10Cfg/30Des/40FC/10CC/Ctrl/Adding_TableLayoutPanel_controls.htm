Adding TableLayoutPanel controls

Add a TableLayoutPanel control to add and arrange controls in a table on a graphic form.

To add a TableLayoutPanel control to a graphic form:

  1. Open the required graphic form.
  2. If necessary, open the Toolbox tool window.
  3. If necessary, expand the Windows Forms group in the Toolbox window.
  4. Locate the TableLayoutPanel control.

If you cannot find this control in the Windows Forms group, then do the following:

  1. Close the Designer.
  2. Open the Adroit Config Editor.
  3. In the left hand side expand the Advanced node and click on the Designer item.

Example:

  1. Scroll down to the ControlsExcludeList setting, which is in the Misc section, when these settings are displayed in Categorised mode.

Example:

  1. Edit the ControlsExcludeList by deleting the “System.Windows.Forms.TableLayoutPanel;” from this setting.
  2. Click the Finish button to close the Adroit Config Editor.
  3. Restart the Designer.
  4. Open the graphic form and locate the TableLayoutPanel control in the Windows Forms group of the Toolbox.
  1. Select the TableLayoutPanel control.
  2. On the graphic form, click where you want the upper-left corner of this control to be located.

This control is then added to the layer of the graphic form which is currently being edited.
