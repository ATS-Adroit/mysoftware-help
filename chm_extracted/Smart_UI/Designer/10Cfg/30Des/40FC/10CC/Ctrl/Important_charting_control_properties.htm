Important charting control properties

This describes the functions of some of the more important properties that can be used to configure the charting controls.

Note: These properties can be viewed and configured in the Properties tool window.

General charting properties: properties that display the charting toolbar, enable the chart to configured in runtime and change the main title of this chart, amongst others

Property Function
AntiAliased

This Boolean property, which is True by default, uses antialiasing to smooth the edges of the drawn chart.

Note: You can turn this off to improve the charting speed but then the chart will appear more jagged.

DataLegendDigits

This Integer property allows you to specify the number of significant places to use when values are rounded off in the data Legend.
Direct2DMode This Boolean property, which is False by default, uses GDI+ to chart the data, which is slower as the charting is only performed by the CPU and by the graphics card. When you set this property to True, then the charting is done using Direct2D, which is faster as this is performed using the graphics card and not the CPU.
PrintingSettings

Allows you to configure the default print settings that are applied when this chart is printed, by configuring the following sub-properties accordingly:

  • Grayscale: By default this is False to print the chart in full color, but if set to True it will print the chart in shades of grey (greyscale).
  • Landscape: By default this is False to print the chart in portrait orientation mode, but if set to True it will print the chart using the landscape orientation mode.
  • MarginUnits: Either specified as a HundredthsInch (hundredths of an inch) or as Percent.
  • PrintPanelBackground: Prints a transparent Chart Panel when set to False.
  • Proportional: Sets the print dimensions of the chart proportional to those onscreen when set to True.
  • Resolution: Sets chart printing detail resolution, from 1 to 100.
  • UseAntiAlias: By default this is False to print the chart using standard printing quality, but if set to True it will print the chart using high printing quality using a higher pixel resolution.

Title

This String property can specify the name of this chart.

Note: If this property is cleared i.e. a blank string then more space is provided within the control for charting the data.

ToolbarVisible

This Boolean property toggles the display of the charting toolbar. This toolbar allows end users allows your end-users to print and/or preview the chart, rotate the chart and if necessary chart additional data, amongst other actions. For details, see Charting control toolbar.

Note: This toolbar is best suited to real time trending, as it allows one to move back and forward between the historical and real time data. For details, see the TimeInfo property below.

View3D

This Boolean property determines whether this chart is by default displayed in three dimensional view or not, by appropriately configuring the View chart in 3D mode toolbar button.

ViewName

This String property, determines whether the configuration changes performed by the Runtime Configuration toolbar button will be saved, as follows:

  • If empty, the runtime configuration of series will NOT be saved.
  • If not empty, this specifies the name of the variable that is used to save the runtime configuration of series to the profile of the currently logged in user. For details, see Configuring charted series at runtime.

Note1: If a value is specified, this automatically enables the (Appearance) ViewButtonEnable property to display the Runtime Configuration toolbar button.

Note2: If the value is deleted, this automatically disables the (Appearance) ViewButtonEnable property.
However, this property can still be manually enabled if necessary, although any runtime configuration will then NOT be saved.

 

Line, Surface and XYPlot charting control properties: properties that display the data legendand configure its height and column widths and visibility, display toolbar buttons and configure the charting time interval amongst others.

Property / (Category) Function

Badcolor

This specifies the line color that is used to indicate that the plotted points have a bad status i.e. when data points are missing, incorrectly reported or extrapolated.
  Data Legend-specific properties:

DataLegendVisible

This Boolean property toggles the display of the data legend that appears at the bottom of this control, which is used to display statistical information concerning the charted values. For details, see Operating charting controls.

Note: The data legend settings only apply if the data legend of this charting control is displayed, which is determined by the (Appearance) DataLegendVisible property.

DataLegendHeight

This Integer property allows the height of the data legend of this charting control to be specified, in pixels.

Note: Depending on the number of series, this size could result in one or more of the series not being displayed by the data legend grid, in which case use the scroll bar to see the hidden series.
Data LegendHeightAutosize This Boolean property toggles the ability to automatically increase the size of the data legend grid to display all the trended series.

SeriesWidth

This Integer property allows the width of the Series column in the data legend of this charting control to be specified, in pixels.

MinWidth

This Integer property allows the width of the Minimum column in the data legend of this charting control to be specified, in pixels.
MinVisible This Boolean property can hide (False) or display (True the default) the Minimum column in the data legend of this charting control.

MaxWidth

This Integer property allows the width of the Maximum column in the data legend of this charting control to be specified, in pixels.
MaxVisible This Boolean property can hide (False) or display (True the default) the Maximum column in the data legend of this charting control.

AveWidth

This Integer property allows the width of the Average column in the data legend of this charting control to be specified, in pixels.
AveVisible This Boolean property can hide (False) or display (True the default) the Average column in the data legend of this charting control.
CurrentWidth This Integer property allows the width of the Current column in the data legend of this charting control to be specified, in pixels.

CntWidth

This Integer property allows the width of the Count column in the data legend to be specified, in pixels.
CntVisible This Boolean property can hide (False) or display (True the default) the Count column in the data legend of this charting control.

SDevWidth

This Integer property allows the width of the Std Dev column in the data legend to be specified, in pixels.
SDevVisible This Boolean property can hide (False) or display (True the default) the Std Dev column in the data legend of this charting control.

ErrorsWidth

This Integer property allows the width of the Errors column in the data legend to be specified, in pixels.
ErrorsVisible This Boolean property can hide (False) or display (True the default) the Errors column in the data legend of this charting control.
  Charting data-specific properties:

ExtrapolateData

This Boolean property toggles the ability of charted data to be extrapolated from its last known value.

In other words, when the value of a charted series is not received, instead of inserting a gap in the trend where this value should have been, its last known value is charted instead.
HistoricalDataSampleRate

This Integer property, mainly applies to the LineChart series and serves to limit the retrieved number of historical data points to improve the performance of historical trending. This data sampling rate is specified in milliseconds.

Historical data sampling is AUTOMATICALLY DISABLED when the specified sample rate is SMALLER than 10 x your current time frame window. In other words, the default sample rate of 5 seconds is only applied when the time frame window is greater than 50 seconds.

Setting this sample rate to 0 PERMANENTLY DISABLES historical data sampling and always returns all the available historical data.

TimeInfo

This composite property contains a number of sub-properties that specify the time-specific properties for the chart, as follows:

Note1: This property only applies to Line and XYPlot charts.

Note2: This property can also be configured at runtime, but any changes made will not be saved. For details, see Modifying chart time at runtime.

RealTime This Boolean property determines whether the trending will be real-time (True) or historical (False).

This also determines which of its sub-properties need to be configured to set the required trending period:

  1. Real time trending: When RealTime is True, then the initial view of the trend will display data scrolling in realtime.
    When the trend is opened, it will fetch the historical data (if there is any) for the initial data period. This trending period is calculated as follows:
    1. TimeSpan  This specifies the time period that the real-time trend window displays. This value can be specified, as follows: "[-]d.hh:mm:ss.ff, where: "-" is an optional sign for negative TimeSpan values, the "d" component is days, "hh" is hours, "mm" is minutes, "ss" is seconds, and "ff" is fractions of a second.

    Note1: If an integer is typed into this value box it will be assumed to be a multiple of days.

    Note2: The StartTime and EndTime properties are meaningless for real time trending.

    1. Interval This specifies the required update rate for the trended data (in milliseconds) i.e. how often the trend must update with the latest real time data and shift the data across the screen.

     

  1. Historical trending: When RealTime is False, then the initial view of the trend will display the historical data specified between the start and end time, although it is also possible to view data that is being logged currently too.This trending period is calculated as follows:
    1. TimeSpan  This specifies the interval that is required between the StartTime and EndTime. This value can be specified, as follows: "[-]d.hh:mm:ss.ff, where: "-" is an optional sign for negative TimeSpan values, the "d" component is days, "hh" is hours, "mm" is minutes, "ss" is seconds, and "ff" is fractions of a second.

    Note: If an integer is typed into this value box it will be assumed to be a multiple of days.

    1. StartTime This specifies the date and time, in the past, at which the trend is required to begin. This date and time is displayed in the format specified by your current Regional Settings.
    2. EndTime This specifies the date and time, in the past, at which the trend is required to end. This date and time is displayed in the format specified by your current Regional Settings.

    Note1: The TimeSpan, StartTime and EndTime properties are all linked i.e. changing the StartTime will recalculate the EndTime using the specified TimeSpan.

    Note2: The Interval property is not required for static trends.

    Tip: You can configure the (Data) HistoricalDataSampleRate property to improve the performance of historical trending.
  Toolbar - specific properties:

PageLeftVisible

This Boolean property toggles the display of the Page Left toolbar button used to move back quickly in time.

PageRightVisible

This Boolean property toggles the display of the Page Right toolbar button used to move forward in time.

ScrollLeftVisible

This Boolean property toggles the display of the Scroll Left toolbar button used to move back in time.

ScrollRealTimeVisible

This Boolean property toggles the display of the Go to real time mode toolbar button used to move forward in time until the real time values of the data are displayed.

ScrollRightVisible

This Boolean property toggles the display of the Scroll Right toolbar button used to move forward quickly in time.

ScrollLineButtonVisible

This Boolean property toggles the display of the Scroll line to view historical values toolbar button used to enable/disable a vertical black and blue scroll line to display these historical values in the data legend.

Tip: Enable the (ScrollLine) ShowScrollLineMarkers property, to display the point at which each scroll line intersects the series of the chart, by means of a dot, which has the same color as the series.

TimeDetailsButtonEnabled

This Boolean property toggles the enabling of the Modify the time details toolbar button that allows the charted time period to be altered in runtime mode. For details, see Modifying chart time at runtime.

Note: If this property is disabled, while the TimeDetailsButtonVisible property is enabled then this button will appear greyed out in the toolbar.

TimeDetailsButtonVisible

This Boolean property toggles the display of the Modify the time details toolbar button.

ViewButtonEnable

This Boolean property toggles the display of the Runtime Configuration toolbar button that allows series (data elements) to be added to the chart in runtime mode. For details, see Configuring charted series at runtime.

Note: Any series (data elements) that are added at runtime will ONLY be saved if the (Behaviour) ViewName property is NOT empty.
