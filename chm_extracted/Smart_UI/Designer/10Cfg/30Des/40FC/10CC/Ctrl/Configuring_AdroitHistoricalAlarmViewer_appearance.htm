Configuring AdroitHistoricalAlarmViewer appearance

The AdroitHistoricalAlarmViewer control allows you to change the color of the following components within this control via the Appearance tab of the Initial Configuration and the General Configuration Settings and Configure Appearance Settings dialogs:

Specify the color used for the odd and/or even rows in the grid, so that it is easier for users to differentiate the different alarms displayed in the grid. For details, see Selecting colors.

Note: These colors are only displayed when you enable the Alternate Row color  tool for the grid

Decide whether you want to display either the odd and/or the even rows in different colors, by enabling their respective checkboxes and then configuring their back and text colors. While the Back color defines the color of the row itself, the Text color defines the color of the text of the row.

By default both of these checkboxes are unchecked, so all the rows are displayed in their default color, defined by the currently selected Look and Feel Skin.

Toolbar color: specify the required background color of the toolbar, since this is NOT changed by the selected Look and Feel Skin.

Note: The default color of 0 for the odd and even row colors and the toolbar color, means a non-configured color, which uses the grid defaults.

Look and Feel Skin: select the required theme which ONLY affects the color and formatting of the grid; although you can separately configure the background color of the toolbar via the Toolbar color setting.

By default the Look and Feel Skin (color theme) is set to Office 2010 Silver and the toolbar and the odd and even row colors are not configured.
