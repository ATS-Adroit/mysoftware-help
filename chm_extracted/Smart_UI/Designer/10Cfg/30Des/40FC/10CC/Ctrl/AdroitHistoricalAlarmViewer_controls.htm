AdroitHistoricalAlarmViewer controls

The AdroitHistoricalAlarmViewer control allow users to view and/or locate and/or filter and/or print and/or export their historical Adroit alarms, that are stored in the AlarmManagement agent SQL Server database.

From Adroit 8.4 onward, an unlicensed AlarmManagement agent provides the Historical alarm mode option, which only saves your historical acknowledged alarms, so that you can see the full life-cycle of each alarm in each row of the Adr_AM_HistoricalIncidents table. For more details, see Historical Alarm mode.

 

How to use the AdroitHistoricalAlarmViewer control: this describes the recommended procedure for using this control to view and filter historical alarms.

  1. Ensure that you have an AlarmManagement agent that is logging alarms to a SQL Server database.

  2. If necessary, create the project and the graphic form that you want this control to be on.
  3. Add this AdroitHistoricalAlarmViewer control to the required graphic form. For details, see Adding AdroitHistoricalAlarmViewer controls.

  4. In the DataSource tab of the Initial Configuration dialog, the Server should already specify your current SmartUI Server, if necessary select the required one; if you already have an OLEDB Datasource for your AlarmManagement agent SQL Server database, select the name of this datasource from the list box or click the New button to create this OLEDB datasource. For details, see Creating a new OLEDB datasource.

  5. In the Historical Data Update Settings section, select how you want this control to refresh itself with more recent alarms. For details, see Configuring how to update AdroitHistoricalAlarmViewer controls, which ALSO describes the TWO methods of linking the Alarm Management database table to this control.

    Note: You do not need to configure any of these settings now, you can launch these configuration dialogs later, if needed.

  6. In the Columns tab of the Initial Configuration dialog, choose which columns are displayed, their displayed names, their order and their specific properties, such as their widths; whether they autosize; whether the alarms will be sorted by their contents and how; whether they display a summary and what type and/or whether they should be frozen. For details, see Configuring AdroitHistoricalAlarmViewer columns.

    By default the control is sorted in Descending order of the Date Time column, so that the latest alarm is displayed at the top.

  7. In the Constraints tab of the Initial Configuration dialog, you can further refine the displayed alarms to eliminate unnecessary alarms; in other words you can configure this control to only return a specific number of the topmost alarms and/or how you want to specify the time period of applicable alarms that will be retrieved. For details, see Configuring AdroitHistoricalAlarmViewer constraints.

    By default, the topmost alarm constraint is disabled and the alarms for the last day are returned, since the 'Now - Timespan' option is used to specify the time period, with the Timespan being set to 1 Day.

  8. In the Appearance tab of the Initial Configuration dialog, you can change the colors the following components within this control: the background and foreground color of the odd and even rows; the background color of the toolbar and the color theme used for the grid. For details, see Configuring AdroitHistoricalAlarmViewer appearance.

    By default the Look and Feel Skin (color theme) is set to Office 2010 Silver and the toolbar and the odd and even row colors are not configured and so use the grid defaults.

  9. Open the Tasks menu and configure one or more of the following settings not provided by the Initial Configuration dialog:
    • to determine whether paging is used to help users browse a large list of alarms;
    • to predefine general-purpose filters that always appear in the Filter list of the toolbar, which your users can immediately use to refine the displayed alarms;
    • to create group summaries (group-specific calculations) that are ONLY displayed when you group data, by dragging the relevant column/s into the grouping bar above the column headers;
    • and whether to hide or show the toolbar.

To add a AdroitHistoricalAlarmViewer control to a graphic form: A control needs to be added to a graphic form before it can be used and configured.

Note: This controls is located in the Adroit section or category of the Toolbox window.

Configuration options:

  • A Tasks menu, which can be accessed by clicking its smart taga glyph that usually displayed in the top left corner of the selected control or vector that when clicked displays a list of the commonly used configuration tasks. . For details, see AdroitHistoricalAlarmViewer controls task menu.
  • A right click menu, that provides the following configuration dialogs also provided by the Tasks menu:
  • Configure Constraints: this dialog configures this control to only return a specific number of the topmost alarms and/or how you want to specify the time period of applicable alarms that will be retrieved. For details, see Configuring AdroitHistoricalAlarmViewer constraints.
  • Configure DataSource Connection: this dialog allows you to connect to the AlarmManagement database table and/or to select how you want this control to refresh itself with more recent alarms. For details, see Configuring how to specify the database and/or update AdroitHistoricalAlarmViewer controls.
  • Configure Appearance Settings: this dialog can change the colors the following components within this control: the background and foreground color of the odd and even rows; the background color of the toolbar and the color theme used for the grid. For details, see Configuring AdroitHistoricalAlarmViewer appearance.
  • General Configuration Settings: this tabbed dialog allows you to configure the generally applicable settings of this control, namely: the specifying and/or updating of its AlarmManagement database; columns configuration; configuring the applicable constraints and/or specifying its appearance. For details, see General configuration settings for AdroitHistoricalAlarmViewer controls.

End-user interaction:

A toolbar, which allows your end-users to view and/or locate and/or filter and/or print and/or export the historical alarms they require and/or configure the display of this grid and its columns at runtime.

A grouping bar, that allows you to drag column heading into it to define a hierarchical grouping mechanism to define how the available data is categorised into groups and/or sub-groups.

Tip: Each group can also display summaries, which can be configured via the Group Summary item of the AdroitHistoricalAlarmViewer Tasks list.
