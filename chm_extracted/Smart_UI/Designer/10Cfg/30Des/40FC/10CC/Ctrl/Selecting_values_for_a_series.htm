Selecting values for a series

The Values List tab allows you to specify individual values for each of the slices of a pie series or each of the columns or bars within a column or bar series, as follows:

Note: This tab is only displayed if the Datasource field of the currently selected bar/pie/column series specifies ValueDataElement.

If necessary, specify the number of values (slices/bars/columns) that this series should contain by using the arrow buttons of the slices/segments spin control. You will notice that these values are added to the previewed chart.

To configure each value within this series: this allows to specify the value, label and color of each slice/bar/column.

  1. Open the Values List list box and select the index number of the required value.

  2. Click the browse button to the right of the Value DataElement edit box to use the Data Element Browser dialog to select the required value, as follows:

    This dialog displays a tree view of all the datasources and their data elements that are contained within the connected Servers, like that displayed by the Enterprise Manager.

    The value selected initially by this browser is determined, as follows:

    • If you have NOT selected a data element for the current field, then it displays the last data element, that you browsed in, using ANY DE browser.

    Tip: This is particularly helpful, when you are working with the SAME datasource, as it expands this datasource in the tree, highlighting the last browsed-in data element, which you can use as a reference.

    • If you have browsed in a data element for the current field, then this then data element is automatically selected for you.
    • If necessary, expand the datasources in the tree, to expose the required data element, by clicking their plus boxes .

    The name of the currently selected data element is displayed at the bottom of this configuration dialog.

    • Double click the required data element.

    The Data Element Browser dialog provides the following features to assist you in this task of selecting the required value:

    1. The Recently selected elements list, which displays the last 10 selected data elements - so that these data elements can be quickly selected again, whose display is controlled by the or button in the top right hand corner.

    If the data element, in this Recently selected elements list, does not have an associated icon, then either this data element does not exist or, in the case of the Adroit datasource, that you have not opened the associated Agentgroup in the Adroit datasource tree and so if this data element is selected it will not be found in the Browser window.

    1. The ability to display the current value of the data elements you are currently or have previously selected, by clicking the button in the top right hand corner, which adds the Watches column to the Recently selected elements list (when this is displayed) and the icon and current value to the right of the currently selected data element at the bottom of this dialog.
    2. A data element searching capability to quickly locate similarly-named values without manually browsing for them: simply type the required search criteria into the Search in browser for edit box and all the data element names containing the specified search string are displayed in a list providing the name of the data element and its path. If necessary, click the button to return to the tree view.

    By default, to speed up searching on large Adroit Agent Server projects, the searching stops at the agent and not the slot level.

    1. The tree view provides the full Enterprise Manager context sensitive right click menu functionality. So in the case of using an Adroit datasource you can create the required agent/s when configuring a Behaviour.
    2. When selecting tags from an Adroit datasource, you can also create on-the-fly agents by editing the selected data element string to create another tag. In this case, when you click Finish, a message is displayed asking whether you want to create this new tag or not, if you select Yes then this tag is created and selected.

Note: You only need to press the Set button if you need to specify a different value from the one you previously selected. 

  1. If necessary, edit the default value name in the Value Label field, which is used to describe this value in the legend.
  2. By default, the first 20 values have a random color. If necessary, change the assigned color of this series by double clicking the Value color field to display the color edit box to select the required color. For details, see Selecting colors.
