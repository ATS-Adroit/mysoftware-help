Manually assigning values to aliases

The final step of configuring aliases is assigning values to the aliases so that you can configure their assigned properties.

Note: Aliases are only exposed if specified graphic form has implemented them.

To manually assign values to aliases defined in the hosted graphic form:

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the required graphic form (that has configured aliases), which this TemplateGO control displays.
  1. Select this TemplateGO control on the graphic form.
  2. If necessary, open the Enterprise Manager.
  3. If necessary, open the required datasource in the Enterprise Manager and expose the required data element to be assigned to the first alias.
  1. Drag this data element from the Enterprise Manager onto the TemplateGO control in the Design workspace.
  2. Select To Control Property…
  3. If the Aliases property is displayed, select it.

    Do the following if this property does not appear in this list:

    Select the Customise…option to display the Edit Common Properties dialog.

    Highlight the required property, by selecting its name, before clicking Finish.

    Note: Checking this property will also add it to the list of immediately available properties for this control.

Tip: If only one alias was added to this contained graphic form, then this value is immediately assigned to this alias.

  1. If there are more than one aliases:

The Select Item To Connect To dialog is displayed.

Select the name of the required alias, which is to be assigned this value and click Finish.

  1. If necessary repeat steps 4 to 8 until all the required aliases have been the necessary values.

Note: It is not necessary for all the configured aliases to be assigned values.

If one or more of these values need to be modified before they are assigned to these aliases, then add one or more spiders and modify the values of these data elements as necessary before manually assigning them to an alias.
