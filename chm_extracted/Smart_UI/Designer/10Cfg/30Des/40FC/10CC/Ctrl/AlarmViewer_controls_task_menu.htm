AlarmViewer controls task menu

The Tasks menu of the AlarmViewer controls, provide the following tasks or common configuration options:

Note: This menu of tasks is displayed when the control is initially added and can be accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs. usually displayed in the top left corner of the selected control.

General Settings

  1. Alarm Type: Specify the type of agent used to display this list of alarms, either an AlarmAgent or AlarmListAgent.
  2. Auto Refresh: If enabled, then when Adroit updates this alarm list the AlarmViewer control will also be updated.
  3. Show All Alarms: If enabled, the AlarmViewer control displays all the alarms in the list. If disabled, then the AlarmViewer control ONLY displays the number of alarms specified by its MaxAlarmsVisible property. In this case ONLY this number of the most recent alarms are displayed.
  4. Show Priority colors: If enabled, the AlarmViewer control displays the Priority colors, which you configure using the Alarm colors setting. These priority colors allow the operators to see the alarm priority in addition to its acknowledged state to know which alarms to react to first.
  5. Show Alarm StatusBar: If enabled, the status bar below the AlarmViewer control is visible. This status bar displays the time that this list of alarms was last updated. You can disable this to conserve the real-estate of your graphic form.

Alarm Entries Settings

  1. Alarm colors: Configure the colors that the AlarmViewer control uses to indicate the acknowledged state and/or alarm priorities. See Customizing alarm colors.
  2. Alarm Font: Configure the font that the AlarmViewer control uses for its alarms. See Selecting fonts.
  3. Alarm DateTime Fomatting: If necessary, specify a format string to customise the display of the dates and times displayed by the AlarmViewer control, by using one or more of the following data and time format specifiers:

Commonly used date and time format specifiers: These produce standard date and time formats.

These date and time format strings, consist of a single format specifier character from the following table.

Note: If the format string is longer than a single character (even if the extra characters are white spaces), the format string is interpreted as a custom format string.

The following table describes these standard date and time format strings.

Note1: The output produced by some of these format specifiers is influenced by the current Regional Options settings. Computers using different settings will generate different results.

Note2: The example outputs specified in this table assume that a DateTime value of 8/20/2004 11:12:45 AM is assigned to input 0.

Format Specifier Name Notes Format string = Output

d

Short date pattern

This formatting may vary.

{0:d} = 8/20/2004

D

Long date pattern

This formatting may vary.

{0:D} = Friday, August 20, 2004

t

Short time pattern

This formatting may vary.

{0:t} = 11:12 AM

T

Long time pattern

This formatting may vary.

{0:T} = 11:12:45 AM

f

Full date/time pattern (short time)

Displays a combination of the long date and short time patterns, separated by a space.

{0:f} = Friday, August 20, 2004 11:12 AM

F

Full date/time pattern (long time)

This formatting may vary.

{0:F} = Friday, August 20, 2004 11:12:45 AM

g

General date/time pattern (short time)

Displays a combination of the short date and short time patterns, separated by a space.

{0:g} = 8/20/2004 11:12 AM

G

General date/time pattern (long time)

Displays a combination of the short date and long time patterns, separated by a space.

{0:G} = 8/20/2004 11:12:45 AM

M or m

Month day pattern

This formatting may vary.

{0:m} = August 20

R or r

RFC1123 pattern

This formatting always adheres to the following defined standard pattern: "ddd, dd MMM yyyy HH:mm:ss G\MT".

Note: The time displayed is for local, rather than universal (GMT) time.

{0:R} = Fri, 20 Aug 2004 11:12:45 GMT

s

Sortable date/time pattern; conforms to ISO 8601

This formatting always adheres to the following custom pattern "yyyy-MM-ddTHH:mm:ss".

{0:s} =2004-08-20T11:12:45

u

Universal sortable local date/time pattern

This formatting always adheres to the following defined standard pattern: "yyyy-MM-dd HH:mm:ssZ".

Note: The time displayed is for local, rather than universal (GMT) time.

{0:u} = 2004-08-20 11:12:45Z

U

Universal sortable GMT date/time pattern

Note: The time displayed is for the universal (GMT), rather than local time.

{0:U} = Friday, August 20, 2004 9:12:45 AM

Note: This currently non-sortable format is caused by .NET.

Y or y

Year month pattern

This formatting may vary.

{0:y} = August, 2004

Custom date and time format specifiers: If the commonly used date and time format specifiers do not provide the type of formatting you require, you can use custom format strings to further enhance your output.

Combine one or more of the following custom format specifiers to construct a format that yields the output you prefer.

The following table describes the custom format specifiers and the results they produce.

Note1: The output produced by some of these format specifiers is influenced by the current Regional Options settings. Computers using different settings will generate different results.

Note2: The example outputs specified in this table assume that a DateTime value of 8/20/2004 1:14:48 PM is assigned to input 0.

Format Specifier Name Notes Format string = Output

d

Single or double digit day

Displays the current day of the month, as a number between 1 and 31, inclusive. If the day is a single digit only (1-9), then it is displayed as a single digit.

Note: If this single 'd' format specifier is used alone, without other custom format strings, it will be interpreted as the standard short date pattern format specifier.

{0:%d} = 20

dd

Double digit day

Displays the current day of the month, as a number between 1 and 31, inclusive. If the day is a single digit only (1-9), it is formatted with a preceding 0 (01-09).

{0:dd} = 20

ddd

Abbreviated day name

Displays the abbreviated name of the day.

{0:ddd} = Fri

dddd (or more d's)

Full day name

Displays the full name of the day.

{0:ddddd} = Friday

f, ff, fff, ffff, fffff, ffffff, fffffff

Second fractions

Displays seconds fractions represented by a number of digits, which are determined by the number of f's that are used (up to 7 digits).

Note: If this single 'f' format specifier is used alone, without other custom format strings, it will be interpreted as the full (long date + short time) format specifier.

{0:%f} = 7

{0:ffff} = 7724

g (or more g's)

Era

Displays the era (A.D. for example) .

Note: If this single 'g' format specifier is used alone, without other custom format strings, it will be interpreted as the standard general format specifier.

{0:gg} = A.D.

h

Single or double digit hour

Displays hours in the range 1-12, representing whole hours passed since either midnight (12)  or noon (12). If this format is used alone, then the same hour before or after noon is indistinguishable. If the hour is a single digit (1-9), it is displayed as a single digit.

Note: No rounding occurs when displaying the hour. For example, a time of 5:43 returns 5.

{0:h} = 1

 hh (or more h's)

Double digit hour

Displays hours in the range 1-12, representing whole hours passed since either midnight (12) or noon (12). If this format is used alone, then the same hour before or after noon is indistinguishable. If the hour is a single digit (1-9), it is formatted with a preceding 0 (01-09).

{0:hhh} = 01

H

Single or double digit hour, 24hr format

Displays hours in the range 0-23, representing whole hours passed since midnight (0). If the hour is a single digit (0-9), it is displayed as a single digit.

{0:H} = 13

HH (or more H's)

Double digit hour, 24hr format

Displays hours in the range 0-23, representing whole hours passed since midnight (0). If the hour is a single digit (0-9), it is formatted with a preceding 0 (01-09).

{0:HHHHH} = 13

m

Single or double digit minute

Displays minutes in the range 0-59, representing whole minutes passed since the last hour. If the minute is a single digit (0-9), it is displayed as a single digit.

Note: If this single 'm' format specifier is used alone, without other custom format strings, it will be interpreted as the standard month day pattern format specifier.

{0:%m} = 14

mm (or more m's)

Double digit minute

Displays minutes in the range 0-59, representing whole minutes passed since the last hour. If the minute is a single digit (0-9), it is formatted with a preceding 0 (01-09).

{0:mmmm} = 14

M

Single or double digit month

Displays the month, as a number between 1 and 12, inclusive. If the month is a single digit (1-9), it is displayed as a single digit.

Note: If this single 'M' format specifier is used alone, without other custom format strings, it will be interpreted as the standard month day pattern format specifier.

{0:%M} = 8

MM

Double digit month

Displays the month, as a number between 1 and 12, inclusive. If the minute is a single digit (0-9), it is formatted with a preceding 0 (01-09).

{0:MM} = 08

MMM

Abbreviated month name

Displays the abbreviated name of the month.

{0:MMM} = Aug

MMMM (or more M's)

Full month name

Displays the full name of the month.

{0:MMMM} = August

s

Single or double digit second

Displays seconds in the range 0-59, representing whole seconds passed since the last minute. If the second is a single digit (0-9), it is displayed as a single digit only.

Note: If this single 's' format specifier is used alone, without other custom format strings, it will be interpreted as the standard sortable date/time pattern format specifier.

{0:%s} = 48

ss (or more s's)

Double digit second

Displays seconds in the range 0-59, representing whole seconds passed since the last minute. If the second is a single digit (0-9), it is formatted with a preceding 0 (01-09).

{0:sss} = 48

t

Abbreviated A.M./P.M. designator

Displays the first character of the A.M./P.M. designator. If the total number of whole hours passed is less than 12, then the P.M. designator is used. Otherwise, the P.M. designator is used.

Note: If this single 't' format specifier is used alone, without other custom format strings, it will be interpreted as the standard long time pattern format specifier.

{0:%t} = P

tt (or more t's)

Full A.M./P.M. designator

Displays the full A.M./P.M. designator. If the total number of whole hours passed is less than 12, then the P.M. designator is used. Otherwise, the P.M. designator is used.

{0:ttttt} = PM

y

Single or double digit year

Displays years, by omitting the first two digits of the year. If the year is a single digit (1-9), it is displayed as a single digit.

Note: If this single 'y' format specifier is used alone, without other custom format strings, it will be interpreted as the standard short date pattern format specifier.

{0:%y} = 4

yy

Double digit year

Displays years, by omitting the first two digits of the year. If the year is a single digit (1-9), it is formatted with a preceding 0 (01-09).

{0:yy} = 04

yyyy

Four digit year

Displays years, including the century. If the year is less than four digits in length, then preceding zeros are appended as necessary to make the displayed year four digits long.

{0:yyyy} = 2004

z

Single or double digit time zone offset in hours.

Displays the time zone offset for the system's current time zone in whole hours only.
The offset is always displayed with a leading or trailing sign (zero is displayed as "+00"), indicating hours ahead of Greenwich mean time (+) or hours behind Greenwich mean time (-). The range of values is –12 to +13.
If the offset is a single digit (0-9), it is displayed as a single digit with the appropriate leading sign.
The displayed offset is affected by daylight savings time.

{0:z} = +2

zz

Double digit  time zone offset in hours.

Displays the time zone offset for the system's current time zone in whole hours only.
The offset is always displayed with a leading or trailing sign (zero is displayed as "+00"), indicating hours ahead of Greenwich mean time (+) or hours behind Greenwich mean time (-). The range of values is –12 to +13.
If the offset is a single digit (0-9), it is formatted with a preceding 0 (01-09) with the appropriate leading sign.
The displayed offset is affected by daylight savings time.

{0:zz} = +02

zzz (or more z's)

Full time zone offset (hours and minutes)

Displays the full time zone offset for the system's current time zone in hours and minutes.
The offset is always displayed with a leading or trailing sign (zero is displayed as "+00:00"), indicating hours ahead of Greenwich mean time (+) or hours behind Greenwich mean time (-). The range of values is –12:00 to +13:00.
If the offset is a single digit (0-9), it is formatted with a preceding 0 (01-09) with the appropriate leading sign.
The displayed offset is affected by daylight savings time.

{0:zzzz} = +02:00

:

Time separator

Separates the components within a displayed time.

{0:hh:mm:ss} = 01:14:48

/

Date separator

Separates the components within a displayed date.

{0:dd/mm/yyyy} = 20/14/2004

%c

Standard format specifier usage override for identical custom format specifier characters.

Where 'c' is both a standard format specifier and a custom format specifier, this will display the custom format pattern associated with the format specifier. Otherwise 'c' would be interpreted as a standard format specifier.

{0:%d} = 20

Alarm Columns Settings

  1. Show Alarm Column Headings: If enabled, then the names of the columns of the alarm list are displayed. You can disable this to conserve the real-estate of your graphic form.
  2. Alarm Columns: Select which columns you want this alarm viewer to display and/or specify their required column widths. See Customizing alarm columns.
