Important TableLayoutPanel properties

The following list describes the functions of some of the more important properties that the TableLayoutPanel provides:

Note: These properties can be viewed and configured in the Properties tool window.

Tip: Since ONLY ONE table can be displayed by the DataGrid control there is no need to configure properties that are concerned with multi-table or related table navigation etc.

Property Function

Auto sizing

 

Autosize

This property affects the way in which the available space in the TableLayoutPanel control is allocated for each column and row when this TableLayoutPanel control is auto sized and hence affects how the configured sizeType property of each row and column style operate, as follows:

false

The TableLayoutPanel control proceeds from left to right, and allocates space for the column or row or in the following order.

  • If the sizeType property is set to Absolute, this allocates the number of pixels specified by the width or height of the TableLayoutPanel control.
  • If the sizeType property is set to Autosize, this allocates the minimum number of pixels to fully contain the largest control in the column/row.
  • After space for all Absolute and Autosize columns or rows is allocated, any columns or rows with sizeType set to Percent are used to proportionally allocate the remaining free space.
true

Similar to the previous interaction, with the exception that the Percent columns or rows are treated as if they were Autosize.

For details on editing the sizeType property, see Setting row heights and column widths in the TableLayoutPanel.

Layout

 

CellBorderStyle

This property determines if the cell is outlined with a border or not. By default no border is displayed (None), however you can specify the following options: ◦

  • None – No borders.
  • Single – A single-line border.
  • Inset – A single-line sunken border.
  • InsetDouble – A double-line sunken border.
  • Outset – A single-line raised border.
  • OutsetDouble – A double-line raised border.
  • OutsetPartial – A single-line border containing a raised portion.

Columns

Launches the Column and Row Styles editor, setting the Show field to Columns to edit the sizeType property of the available column styles that determines how the available space in the TableLayoutPanel control is allocated for each column.

For details on editing this sizeType property, see Setting row heights and column widths in the TableLayoutPanel.

Note: This sizeType property is affected by the current Autosize TableLayoutPanel property setting.

Rows

Launches the Column and Row Styles editor, setting the Show field to Rows to edit the sizeType property of the available row styles that determines how the available space in the TableLayoutPanel control is allocated for each row.

For details on editing this sizeType property, see Setting row heights and column widths in the TableLayoutPanel.

Note: This sizeType property is affected by the current Autosize TableLayoutPanel property setting.

Note: The ColumnCount and RowCount properties are automatically incremented/decremented when you add and remove rows and columns in design time and the GrowStyle property appears to be ignored.

Inherited control properties

 

Layout

For details on laying out controls in a TableLayoutPanel control, see Laying out controls in a TableLayoutPanel.

ColumnSpan

This integer value, whose default value is 1, allows this control to occupy (span) more than one (rightmost) columns in addition to the column that it is currently in.

Note: After setting this property, you need resize this control accordingly to occupy all or part of the allocated columns.

RowSpan

This integer value, whose default value is 1, allows this control to occupy (span) more than one (bottommost) row in addition to the row that it is currently in.

Note: After setting this property, you need resize this control accordingly to occupy all or part of the allocated rows.

Location

 

Cell

The current position or location of this control in the table, specified by the Column, Row properties.

Column

The (vertical) column in which this control is located, which is an integer starting from 0 (the first column).

Note: This property cannot be externally driven to change the location of a control within the TableLayoutPanel control's table.

Row

The (horizontal) row in which this control is located, which is an integer starting from 0 (the first row).

Note: This property cannot be externally driven to change the location of a control within the TableLayoutPanel control's table.
