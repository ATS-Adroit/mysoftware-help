Configuring charted series at runtime

If necessary, additional values (data elements) can be added to a charting control in runtime mode. Click for more details:

How these values are added depends upon the series they are added to as follows:

  • Line or XYPlot series: an entirely new series is added for this value.
  • Pie, Bar or Column series: a new value (slice/bar/column) is added to the specified series.

Ensure the following Boolean properties of this charting control are enabled: (Appearance) ToolbarVisible, and (Toolbar) ViewButtonEnable.

Note1: To save this runtime series configuration, ensure that the (Behaviour) ViewName property is NOT empty.

Note2: At least one series must be added to the charting control, in order for charted series to be configured at runtime.

Tip: Unlike other runtime configuration performed on this control, however, these added series can be saved to the profile of the currently logged in user. This allows per user customization of the charted series.

To configure charted series at runtime:

  1. Select the Runtime Configuration toolbar button from the toolbar of the required charting control:
  2. If it is the first time that series are being configured during runtime, for this user or if the previous runtime configuration was not saved, then this will display the Data Element Browser configuration dialog and then the Series Configuration configuration dialog. Otherwise the Series Configuration dialog is immediately displayed.

The Series Configuration dialog: use this to add and/or modify previously-saved series, ONE at a time, as follows:

Tip: Uncheck the Show checkbox to hide a series and prevent this value from being charted.

  • If you need to add a value then click the Data Element field in the blank row at the end of the list and click the browse button to display the Data Element Browser configuration dialog to select the required value.
  • If you need to edit an existing value, click the browse button to the right of the Data Element field to display the Data Element Browser configuration dialog to select the required value.

Use the Data Element Browser configuration dialog to select the required value, as follows:

This dialog displays a tree view of all the datasources and their data elements that are contained within the connected Servers, like that displayed by the Enterprise Manager.

The value selected initially by this browser is determined, as follows:

  • If you have NOT selected a data element for the current field, then it displays the last data element, that you browsed in, using ANY DE browser.

Tip: This is particularly helpful, when you are working with the SAME datasource, as it expands this datasource in the tree, highlighting the last browsed-in data element, which you can use as a reference.

  • If you have browsed in a data element for the current field, then this then data element is automatically selected for you.
  • If necessary, expand the datasources in the tree, to expose the required data element, by clicking their plus boxes .

The name of the currently selected data element is displayed at the bottom of this configuration dialog.

  • Double click the required data element.

The Data Element Browser dialog provides the following features to assist you in this task of selecting the required value:

  1. The Recently selected elements list, which displays the last 10 selected data elements - so that these data elements can be quickly selected again, whose display is controlled by the or button in the top right hand corner.

If the data element, in this Recently selected elements list, does not have an associated icon, then either this data element does not exist or, in the case of the Adroit datasource, that you have not opened the associated Agentgroup in the Adroit datasource tree and so if this data element is selected it will not be found in the Browser window.

  1. The ability to display the current value of the data elements you are currently or have previously selected, by clicking the button in the top right hand corner, which adds the Watches column to the Recently selected elements list (when this is displayed) and the icon and current value to the right of the currently selected data element at the bottom of this dialog.
  2. A data element searching capability to quickly locate similarly-named values without manually browsing for them: simply type the required search criteria into the Search in browser for edit box and all the data element names containing the specified search string are displayed in a list providing the name of the data element and its path. If necessary, click the button to return to the tree view.

By default, to speed up searching on large Adroit Agent Server projects, the searching stops at the agent and not the slot level.

  1. The tree view provides the full Enterprise Manager context sensitive right click menu functionality. So in the case of using an Adroit datasource you can create the required agent/s when configuring a Behaviour.
  2. When selecting tags from an Adroit datasource, you can also create on-the-fly agents by editing the selected data element string to create another tag. In this case, when you click Finish, a message is displayed asking whether you want to create this new tag or not, if you select Yes then this tag is created and selected.
  1. After selecting the required value, the Series Configuration dialog should automatically be displayed so that you can configure this series, as follows:
    1. Check the Show checkbox of the row to chart this value.
    2. If this is a Bar or Column chart, if necessary, change the Type of series used to chart value to a Line series if this is required, the default is Bar/Column.
    3. Further configuration depends upon the type of series specified in the Type column for this value:

Configuration required for a Line or XYPlot series:

  1. If necessary, change the Series field to specify the correct description of this series in the legend. By default this is name of the first series that is added to this charting control. Double-click this name in order to edit it or select the name of an existing series from the list box.
  2. If necessary, change the charting color of this value. For details, see selecting a color from the color edit box.
  3. If you need to prevent the interpolation between successive data points then check the Steps checkbox, this is particularly useful when charting discreet data such as Boolean or digital values.
  4. If you want to chart this series on a custom left (Y) axis then check the Axes checkbox.

Configuration required for a Pie, Bar or Column series:

  1. If necessary, change the Series field to specify the name of an existing pie, bar or column series, as configured in the charting configuration dialog. Double-click this name in order to edit it or select the name of an existing series from the list box.

Note: If the specified name differs from the current series then a new pie or set of bars and columns is added for this value.

Tip: The default series name is the name of the first series that is added to this charting control.

  1. Specify the Label that describes this new value of the specified series. Double-click this name in order to edit it.
  2. If necessary change the charting color of this value. For details, see selecting a color from the color edit box.
  1. Select the Finish button once all the values have been configured as required to close the Series Configuration configuration dialog.
