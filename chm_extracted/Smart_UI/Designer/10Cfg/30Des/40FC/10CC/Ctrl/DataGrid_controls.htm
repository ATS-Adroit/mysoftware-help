DataGrid controls

This control provides a spreadsheet-type user interface for data elements of type datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows., by displaying this data in a series of rows and columns. Click for more information: 

This also provides formatting options for the grid itself and allows this data to be modified by the end-user too, if required.

How to create a parameterised database query and view it in a DataGrid control

Tip: For a detailed step-by-step procedure of using ListBox and ComboBox controls to display and interact with databases (data elements of type datasettabular data or data that is contained within one or more tables; each table contains one or more columns and each column consists of one or more rows.), see How to use ComboBox (and ListBox) controls to interact with databases.

Note1: The DataGrid control also displays any updated data. For details on whether this updated data should be appended to or replace the existing data, see Displaying both existing and updated dataset data.

Note2: This DataGrid control is only able to display a single table, therefore if you need to perform data mining on multiple tables, create a query that returns the required single table and use this DataGrid control to display this table instead. For details on creating this query, see About queries.

Note3: A number of other controls can also display dataset data. For details, see Filtering datasets.
