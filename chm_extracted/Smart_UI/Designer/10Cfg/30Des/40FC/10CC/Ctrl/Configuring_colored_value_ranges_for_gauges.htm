Configuring colored value ranges for gauges

If you like you can add colored value ranges to a Gauge control, these can be added to help your operators to immediately determine in which general range of values the current value is which needing to study the gauge closely.

Example:

This screenshot demonstrates the typical use of color to represent the different value ranges, where red typically indicates high or over-limit values and more neutral colors to indicate the values within the normal operating range:

This assumes that you have added the required gauge control to the required graphic form.

To configure colored value ranges for a Gauge control:

  1. Either right click the gauge or click the glyph of this control and select the Configuration option

This displays the Configuration configuration dialog.

  1. In this dialog, select the Ranges tab and then specify the required number of ranges you need to define in the Number of Ranges field, you can define up to 5 different value ranges (or value groupings) on a gauge .
  2. For each range, select the required number of this range in the Range list box and then, specify the following details:
  • Start Value: the value at which this range (group of numbers or state) begins.
  • End Value: the value at which this range (group of numbers or state) ends.

Note: If you specify the same Start Value and End Value for two ranges then the second range will overwrite the first.

  • Offset:this specifies the position of this value color range within the gauge control. More details:

Tip: Typically you should NOT configure this field and leave its default value unchanged.

With a value of zero being on top of the graduations of the scale.

Positive values move this value range outward.

Negative values move this value range inward.

The default value is 20, which keeps the value range above the scale graduations.

  • color: Specify the color used on the gauge to indicate this value range (group of numbers or state). For instance, you would typically use red to indicate high or over-limit values and more neutral colors to indicate the values within the normal operating ranges.

Tip: To delete a range, select the required row and press the DELETE key.
