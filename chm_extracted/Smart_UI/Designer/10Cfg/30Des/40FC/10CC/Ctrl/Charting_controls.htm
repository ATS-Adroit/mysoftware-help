Charting controls

Charting controls allow you to report both live and historical data. Click for more details: typically the Line, Surface and XYPlot charting controls are used to trend live data, while the Pie, Bar and Column charting controls are used to report historical data.

Note: You can create template charting controls, since the applicable Series values of chart controls support the use of curly brackets {} to create aliases for SmartUI Templates or data element substitutions for wizards.

Each charting control displays one or more series, as follows:

  • BarChart: Each charted series is either a series of horizontal bars representing values or a series of points that are usually connected to form lines.
  • ColumnChart: Each charted series is either a series of vertical columns representing values or a series of points that are usually connected to form lines.
  • LineChart: Each charted series is a series of points that are usually connected to form lines.
  • PieChart: Each charted series is a series of slices or segments to form a complete pie or circle. Typically you only use one series per chart.
  • SurfaceChart: Each charted series is a surface or three dimensional shape that is plotted from three sets of values, one set provides the X or horizontal coordinate and the other provides the Y or vertical coordinate of each point and the third set provides the Z or height dimension.
  • XYPlotChart: Each charted series is a series of points that are plotted from two sets of values, one providing the X or horizontal coordinate and the other providing the Y or vertical coordinate of each point.

How to chart and/or report data from a database

Configuration options:

  • A configuration dialog to configure the display of the chart and its series. This simplifies chart configuration and provides a preview pane in which you can see the effects of the various display options before they are implemented. To launch the configuration dialog:right click the charting control and select the Edit Chart... menu option.

Note: The configuration dialog is the ONLY way in which you can chart data from a DataBinder. This configuration dialog also can assist you to chart DataSet data and/or data that consists of single values.

Tip: You can connect several data elements to a single series to independently drive its following attributes: color, description, maximum and/or minimum values, engineering unit, value and/or its visibility. For details, see Dragging data to charting controls to configure series.

  • A right click menu, which launches the configuration dialog and provides alternate methods of adding and removing series and/or charting tools.
  • A Tasks menu, accessed from the glyph of the charting control, which provides fast access to common display configuration options instead of launching the configuration dialog. The configuration dialog, however, should still be used to configure the charted series.
  • Important properties, this describes the functions of the important properties that can configure this charting control, some of which specifically apply to xyplot charts.
  • A toolbar, which allows your end-users to interact with and configure this chart at runtime.

End user interaction:

  • A toolbar, which allows your end-users to interact with and configure this chart at runtime.
  • A legend and other methods of interacting with the charting controls, some of which are chart specific. For details, see Operating charting controls.
