Arranging controls

It is usually necessary to align, position and size more than one controla visible form component used to display data or accept user input in the graphic form. See form component. when designing and modifying the user interface of your graphical forms.

To arrange controls using the layout toolbar:

  1. Open the graphic form containing the controls you want to arrange.
  2. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the control(s) you want to arrange. For details, see Selecting multiple controls.
  3. If necessary, click the control that needs to be the primary controlwhen a group of controls are selected, the sizing handles of this control are white and its attributes will be used if this group of controls are formatted. See control..
  4. Select the tool to perform the required arranging task from the Workspace group of the Design tab of the ribbon. For details, see Workspace tools for arranging form components. 

Note1: When manually resizing a control, any sizing handlessmall boxes that appear around the perimeter of a selected item, which if dragged changes the size of this item. See drag., which are grey, cannot be modified.

Note2: To prevent the selected control(s) and/or graphic form from being re-positioned, right click and select Lock.

  1. A right-click menu also provides the following tools to adjust the order of display of the selected control/s:
Tool Function Description

Bring To Front

If more than one control overlies another, this moves the selected control(s) to the top, where they are most visible.

Send To Back

If more than one control overlies another, this moves the selected control(s) to the bottom, where they are least visible.

 

The following tools can also assist with arranging controls:

  1. The graphic form itself provides a grid and other design features. For details, see Graphic form design properties.
  2. The controls provide specific moving and/or resizing functionality. For details, see Editing graphic elements.
