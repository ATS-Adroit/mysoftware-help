Exporting and importing controls

You can export one or more configured controls for reuse, by importing them into the same or other graphic forms. Click for more details:

In this way it is possible to create a library of commonly used controls, whose properties are fully or partially configured – instead of creating these controls from scratch each time they are required.

Note: Only the controls and their MANUALLY configured properties can be exported, in other words any spiders, Behaviours or other methods that are used to configure their properties will NOT be exported.

To export controls:

  1. Select the required control/s. For details, see Selecting controls.
  2. Right-click and select the Export Selection menu option.

This will display the Save As dialog.

Note: An Invalid Selection error message is displayed if no controls are currently selected when this option is used.

  1. Browse for the required folder and then type in the required file name and press the Save button.

Note1: The name and especially the extension of this file is immaterial and does not affect the importing process.

Note2: If only a file name is specified then the .XML file extension is provided.

This will save the selected controls to the specified file.

Note: When these controls are imported, their location depends upon where the cursor is in this graphic form.

To import controls:

  1. Ensure that the Windows Explorer and the SmartUI Designer application windows are positioned in such a way that the exported file containing the required controls is visible in Windows Explorer and the required graphic form into which these controls are to be added is also visible in the SmartUI Designer.
  2. Drag the file containing the exported controls from Windows Explorer into the required graphic form in the SmartUI Designer.

Note: The imported controls are initially added to this graphic form in the SAME position from which they were exported.

The imported controls are immediately selected so that they can be moved to another location, if necessary.

Note: Only the attributes of the imported controls are imported.
