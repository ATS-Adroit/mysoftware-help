Editing controls

You can edit each controla visible form component used to display data or accept user input in the graphic form. See form component. that you add to a graphic form, as follows:

Note: You need to select controls before they can be edited. For details, see Selecting controls.

  1. Moving: Drag the selected control/s to their required location.

    Note: By default, when moving a selection, it snaps (jumps) to the snaplines (displayed in blue) of the other form components, so as to be aligned with these components.

    This means that you are not able to place this selection in certain places on the graphic form.

    Tip: Hold down the ALT key while dragging to disable the default this snapping mode and provide free movement.

  1. Sizing: The current selection provides sizing handlessmall boxes that appear around the perimeter of a selected item, which if dragged changes the size of this item. See drag. that can be dragged to resize all the controls in the selection.

    When the mouse cursor passes over a sizing handle it changes into a double-headed arrow (), indicating the directions in which the selection can be sized.

  1. Properties: Each control has properties, which affect how it appears and behaves etc. Properties can either be manually configured or driven by external values for animation purposes.

    Note1: The Properties tool window displays the available properties of the selected control/s.

    Note2: If more than one control is selected then only the properties shared by all the selected controls are displayed.

    Note3: A componenta hidden form component that provides additional functionality to this graphic form and some or all of its form components. See form component. also has properties, which can affect how they behave.

Please Note: To specify an ampersand character '&' in a text property of a control, type in && and not just &.
Since if only one '&' character is specified then when displayed, the & character does not appear and the following word is underlined instead.

  1. Behaviours: Controls provide a task menu, opened by clicking its icon, which can add one or more display Behaviours.

    These Behaviours use external data to typically modify the appearance of its associated item. For details, see About Behaviours.

    Note: Only one of each of the Behaviours can be added.

     

Note: To make it easier to design and arrange controls, the visibility of controls cannot be modified in Design mode. This restriction, however is lifted in Run mode and in the Operator.
