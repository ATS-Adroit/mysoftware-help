About glyphs

When you select a form component, it displays one or more glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs. that provide alternate methods for their configuration, as follows: 

  1. Tasks menu glyph:displayed in their top right corner of form components that support smart tag functionality.

Example:

This shows the Tasks menu glyph of a selected Button control:

When the glyph is clicked:

  • A menu of form component-specific tasks is displayed and
  • If this is a visible form component, behaviours can be configured. For details of Behaviours which can use the properties of the form component to display the value of your data, see About Behaviours.

  1. Property event triggers glyph: displayed in the lower right corner of visible form components that are used as an event trigger for any spider on a graphic form. Click for more details:in other words whose properties are triggered by events to provide their values to other spiders/properties/data elements.

Example:

This shows the Property event trigger glyph of a selected Button control:

When the glyph is clicked: you can configure the triggering event for each property that is being triggered by an event, as follows:

  1. Select the name of the required spider or control, that must perform the required event or action, from the Event Object list.
  2. Select the action or event that must be performed on the selected Event Object, from the Event Name list.

Note1: This displays a prioritised list of events with the most commonly used (mouse and keyboard) events or actions being placed first in the list.

Note2: This only displays the events supported by the spider or control, specified by the Event object list.
