Working with form components

Form components are added to graphic forms during their design to provide the required user interface for the end-users of a graphic form. For details, see Adding form components.

This is a general term, which encompasses all the items that can be added to graphic forms, of which there are three types:

  1. Controls: a visible form component that displays data or accepts user input in the graphic form. For details, see Working with controls and components.
  2. Components: a hidden form component that provides additional functionality to this graphic form and to some or all of its form components.
  1. Graphic elements: a visible form component that provides drawing functionality for the graphic form. For details, see Working with graphic elements.

Note: Graphic elements are ALWAYS placed “behind” controls on a graphic form.

 

Note1: The Design tab of the ribbon provides tools for arranging and designing form components on the current graphic form. For details, see Tools for editing and designing vectors and/or controls.

Note2: Form components display glyphs, which provide alternate configuration methods. For details, see About glyphs.

Note3: All visible form components provide "Behaviours" that use their properties to display your data. For details of Behaviours, see About Behaviours.

Note4: Graphic forms provide features that make adding form components easier. For details, see Graphic form design properties.

Note5: You can import XAMLpronounced "zammel", stands for Extensible Application Markup Language, which describes objects, properties and their relation between them and can create any kind of objects (graphical or non-graphical). XAML documents generally provide vector graphics and/or user interface controls. XAML is part of the Microsoft Windows Presentation Foundation (WPF). documents containing vector graphics and/or Buttons and Textblocks into graphic forms. See Importing XAML documents into graphic forms.

Tip1: Copy form components within the same graphic form or to another graphic form to reduce your design time. For details, see Copying form components.

Tip2: Use the SHIFT+CTRL+C shortcut to copy a control or graphic element AND its added Behaviours and then paste it as usual.

When you configure your graphic forms to dynamically resize, you will ensure that your form components are resized in line with the displayed size of the SmartUI Operator window. For details, see Statically or dynamically resizing graphic forms.

Note: Dynamic graphic form resizing is not intended to replace the standard docking and anchoring which is recommended for preserving the layout of the graphic form, but instead acts as a failsafe measure.
