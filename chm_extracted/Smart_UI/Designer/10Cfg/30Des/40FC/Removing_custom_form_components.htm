Removing custom form components

If necessary, you can remove any custom form component from the Toolbox tool window, when it is no longer needed. Click for more information:

Note1: This will only remove these form components from being displayed within the Toolbox, so that can no longer be selected when designing graphic forms.

Note2: To completely remove these form components from your computer, it is necessary to navigate to the folder specified by the CustomControlsRelativePath setting of the Designer and remove the required files manually. For details on accessing this setting, see Advanced Designer settings.

WARNING! It is your responsibility to ensure that you only remove the files associated with the custom form components that you want to remove.

To remove custom form components from the Toolbox:

  1. If necessary, open the Toolbox tool window in the SmartUI Designer.
  2. Right-click an existing category heading and select Add Controls.

Note: The category, in which a form component is added, is dependent upon which form component is selected and NOT upon the category that is right-clicked.

This displays the Custom Controls dialog, which alphabetically lists all the form components located within the specified custom controls folder (and its sub-folders).

Tip1: Use the Name, Namespace, Assembly and/or Directory columns within this dialog to locate the required form components, as needed.

Tip2: Select the column heading of a column to sort the list using this column and to change the sorting order between ascending  and descending order.

  1. If you cannot see a checkbox for the required control, click the Browse .NET Control button and browse to the file location, typically within the plugins folder and select the DLL of this control and click Open. This adds a checkbox for this control to the Custom Controls dialog.
  1. Uncheck the checkbox(es) of all the custom form component(s) that you no longer want to appear in the Toolbox tool window and click Finish.

Tip: Double-clicking on a row, within this dialog, will check or empty its checkbox. 

  1. The form component(s), whose checkboxes were cleared will be removed from the Toolbox tool window.

Note: If all the custom form components within a custom category were removed, the custom category will also no longer appear in the Toolbox tool window either.
