Child Behaviours

The Child Behaviours item is typically provided by vector groups or wizard instances to add Behaviours to their component elements and/or to edit and remove their existing Behaviours.

The Child Behaviours dialog is typically launched by selecting, the Child Behaviours link of the Tasks menu or by right clicking and selecting the Child Behaviours menu item of a vector group , such as any of the Static Graphics provided from the Shapes Wizards and Examples ribbon tab) that you add to your graphic forms.

Example of the Tasks menu of a vector group showing the Child Behaviours link:

Note: Although child Behaviours are provided when you select a wizard instance it is NOT recommended that you manually edit your wizard instances after adding them to graphic forms - instead modify the wizard and then update its instances in the required graphic forms.

When adding Behaviours to the child components, select the name of the required component from the list box:

Example of list showing all the child components and its child name filtering field:

Tip: If there are a large number of components, you can type the first letters of the required components in the bottom edit field of this list to filter or limit the displayed components.

Then click the button to select which Behaviour you want to add and then configure this selected Behaviour.

Use the second list to select which child component you want to edit or delete their existing Behaviours.

The Advanced view displays the Normalise vector positions checkbox which by default is checked and moves the vectors from their original position to the relative position of this wizard instance or vector group. If unchecked then the vectors will remain at their originally specified location.
