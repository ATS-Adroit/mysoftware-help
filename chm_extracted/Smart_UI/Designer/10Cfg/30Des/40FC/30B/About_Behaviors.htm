About Behaviours

Behaviours can animate or provide additional functionality to controls and graphic elements (vectors) that you add to your graphic form.

Click for more details:In other words you can typically use Behaviours to display the values of your data, either actually or graphically, by using the available properties of the selected control or graphic element and to perform other functions too.  

Available Behaviours

The following Behaviours can be added to controls and/or graphic elements (vectors):

Tip: You can use the Behaviours tab of the SmartUI Designer ribbon to add, edit or remove these Behaviours and in some cases the Child Behaviour option. For details, see Child Behaviours.

  • Bind Value: to drive a data element (value) to and/or from the value of a property of a control or vector.

  • Color: to assign colors to the two states of a digital (Boolean) value; to blink a specific color property or the VISIBILITY property either continuously or triggered by a value.

    You can also define states of color based on specific value ranges to provide a visual indication of a value.

    You can also define states of color based on a bit mask - a specific sequence of bits that are set (to 1) for up to 32 bits to provide a visual indication of each bit mask.

  • Display Value: to display and if necessary format a value.
  • Execute Command: to perform commands, such as launching an application or opening, closing or printing a graphic form or logging a user on or off and/or switching users.
  • Flip Bitmap: to create a defined sequence of images or a multi-image display, which can only be added to a Picture vector.
  • Location: to dynamically move the object linearly in a defined X-Y direction by means of a monitored value.
  • Operator Action: typically provides methods that allow end users to change a value at runtime.
  • Percentage Fill: to dynamically fill the object by means of a monitored value.
  • Rotation: to dynamically rotate the object by means of a monitored value.
  • size: to dynamically resize the object linearly by means of a monitored value.
  • Tooltip: to display additional information usually concerning this object when the mouse cursor (pointer) hoversalso called a mouse hover, is the action of putting the mouse cursor (pointer) over a designated area. over it.
  • Visibility: to display or hide this object depending on a value.

Note: The behaviour configuration dialogs typically provide an Advanced View button that displays more advanced configuration options.

Tip: Use the Copy with Behaviours right click option or the SHIFT+CTRL+C shortcut to copy a control or graphic element AND its added Behaviours and then paste it as usual.

 

Tip1: When adding a Behaviour to a SmartUI TemplateA graphic form that has one or more configured aliases and is therefore designed to be displayed within a TemplateGO control. , you can use {} notation to automatically create an alias for any data element field. For more details, see Working with SmartUI Templates.

Tip2: When adding a Behaviour to a wizardA pre-drawn and/or pre-configured skeleton of graphical objects and their assigned Behaviours (if any), which has placeholders (substitutions) for data elements., you can use {} notation to automatically create a substitution for any data element field. For more details, see Working with wizards.

To add a Behaviour to a control or graphic element:

Ensure that you have added the required control or graphic element to the graphic form.

  1. Select the required control or graphic element.

  2. If necessary, select the Behaviours tab from the SmartUI Designer ribbon.

    Note: Any Behaviour that cannot be applied to this control or graphic element will be greyed out.

  3. Select the required Behaviour from the relevant group.

Tip: You can also select its glyph to display its task menu and then select the required Behaviour from the New Behaviour drop down list.

This displays the configuration dialog of this Behaviour.

Tip: When you add or edit a Behaviour you can name it, which makes it easier to identify the spiders and their regions associated with your Behaviours.

To edit a Behaviour of a control or graphic element:

  1. Right click the required control or graphic element to the graphic form.
  2. Select the required BehaviourName# menu item, where BehaviourName is the name of the added Behaviour and # usually only appears if more than one of same type of Behaviours have been added. For example: Execute Command1

Tip: You can also select its glyph to display its task menu and then select the required link beneath the Behaviours heading.

This displays the configuration dialog of this Behaviour.

Tip: The Behaviours tab of the SmartUI Designer ribbon provides the Edit Behaviour list box that lists all the Behaviours configured for the currently selected form component. Clicking its browse button displays the configuration dialog of the currently selected behaviour.

To remove one or more added Behaviours from a control or graphic element:

  1. Select the required control or graphic element.

  2. If necessary, select the Behaviours tab from the SmartUI Designer ribbon.

  3. Select the Remove command from the Remove group.

Tip: You can also select its glyph to display its task menu and then select the Removelink beneath the Behaviours heading.

This displays the Behaviour Removal configuration dialog.

  1. Select (check the checkboxes) of the Behaviour/s that you want to remove from this list in the Behaviour Removal configuration dialog.

WARNING! Ensure that ONLY the Behaviour/s you do not require is selected, since no deletion confirmation dialogs are displayed.

  1. Click the Finish button to remove the selected Behaviour/s or Cancel to abort.
