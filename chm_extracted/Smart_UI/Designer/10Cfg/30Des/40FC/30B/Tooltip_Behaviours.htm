Tooltip Behaviours

This Behaviour can be applied to controls and graphic elements (vectors) to display additional information usually concerning this object when the mouse cursor (pointer) hoversalso called a mouse hover, is the action of putting the mouse cursor (pointer) over a designated area. over it.

These tooltips are similar to those associated with toolbars, in that when the mouse pointer hovers over the object, a rectangle containing text appears.

Tip: Apart from displaying the user-specified text, the tooltip can also display the values of one or more data elements.

To add a tool tip to a control or vector:

  • Add or edit an Tooltip Behaviour to display its configuration dialog.
  • Specify the text for this tooltip to display in the Tooltip text edit box.

Tip:You can use the ENTER key to move to the next line of text.

In addition to text, you can add the value of one or more data elements, as follows:

Specify the required values and, if necessary, their required formatting, in the table below the Tooltip text edit box, as follows:

  • Click the browse button to the right of the Data Element edit box to select the required data element (value), as follows:

This dialog displays a tree view of all the datasources and their data elements that are contained within the connected Servers, like that displayed by the Enterprise Manager.

The value selected initially by this browser is determined, as follows:

  • If you have NOT selected a data element for the current field, then it displays the last data element, that you browsed in, using ANY DE browser.

Tip: This is particularly helpful, when you are working with the SAME datasource, as it expands this datasource in the tree, highlighting the last browsed-in data element, which you can use as a reference.

  • If you have browsed in a data element for the current field, then this then data element is automatically selected for you.
  • If necessary, expand the datasources in the tree, to expose the required data element, by clicking their plus boxes .

The Data Element Browser dialog provides the following features to assist you in this task of selecting the required value:

  1. The Recently selected elements list, which displays the last 10 selected data elements - so that these data elements can be quickly selected again, whose display is controlled by the or button in the top right hand corner.

If the data element, in this Recently selected elements list, does not have an associated icon, then either this data element does not exist or, in the case of the Adroit datasource, that you have not opened the associated Agentgroup in the Adroit datasource tree and so if this data element is selected it will not be found in the Browser window.

The ability to display the current value of the data elements you are currently or have previously selected, by clicking the button in the top right hand corner, which adds the Watches column to the Recently selected elements list (when this is displayed) and the icon and current value to the right of the currently selected data element at the bottom of this dialog.

A data element searching capability to quickly locate similarly-named values without manually browsing for them: simply type the required search criteria into the Search in browser for edit box and all the data element names containing the specified search string are displayed in a list providing the name of the data element and its path. If necessary, click the button to return to the tree view.

  • either typing in the required formatting string directly and/or
  • clicking the browse button and using the Format String Editor configuration dialog to specify and/or preview the specified formatting.

Insert the specified data element values into the text of the Tooltip text edit box, as follows:

  • EITHER: select the required row (data element) in the table and drag it to the required location in the Tooltip text edit box.
  • OR: select the required row (data element) in the table, click where in the Tooltip text edit box you want this value inserted and then click the Insert selected Data Element into Tooltip text at Cursor button immediately below the Tooltip text edit box.
  • Use the Tooltip position grid to determine the placement of the tooltip description box, relative to the object that it is added to.
  • Use the Tooltip preview section to test the placement and formatting of the tooltip text, since when your mouse cursor moves over the Hover here text in the Tooltip preview section, the tooltip with the current settings appears.

Note: Since the Tooltip Preview displays exactly what is typed into the Tooltip text edit box, only the data element placeholders appear and if the Tooltip text edit box is empty then no tooltip appears.

  • If necessary, click the Advanced View button to specify some or all of the following additional configurable options:

Tooltip settings: specify the font and/or background and text colors of this tooltip, as follows:

  • Click the browse button to the left of the Text font field and use the Font selection dialog to select the required font. For details, see Selecting fonts.
  • To specify custom background and text colors, uncheck the Use windows default tooltip color settings checkbox, then use the relevant color edit box to specify the required Background color and Text color for this tooltip. For details, see Selecting colors.

Tip: Use the Tooltip preview section to try out these tooltip settings.

Tooltip delays: configure the following delays, in milliseconds:

  • before the tooltip appears (Delay time before open) and
  • how long the tooltip is displayed for (kept open) after it appears (Delay time after open).

Event Trigger: specify which event of this control or graphic element (vector) triggers this Behaviour, as follows:

  • Either select the required event from the list of common or frequently used events.
  • Or click the browse button and use the Event Selector to select the required event.

Tip2: When adding a Behaviour to a wizardA pre-drawn and/or pre-configured skeleton of graphical objects and their assigned Behaviours (if any), which has placeholders (substitutions) for data elements., you can use {} notation to automatically create a substitution for any data element field. For more details, see Working with wizards.

To add a Behaviour to a control or graphic element:

Ensure that you have added the required control or graphic element to the graphic form.

  1. Select the required control or graphic element.

  2. If necessary, select the Behaviours tab from the SmartUI Designer ribbon.

    Note: Any Behaviour that cannot be applied to this control or graphic element will be greyed out.

  3. Select the required Behaviour from the relevant group.

Tip: You can also select its glyph to display its task menu and then select the required Behaviour from the New Behaviour drop down list.

This displays the configuration dialog of this Behaviour.

Tip: When you add or edit a Behaviour you can name it, which makes it easier to identify the spiders and their regions associated with your Behaviours.

To edit a Behaviour of a control or graphic element:

  1. Right click the required control or graphic element to the graphic form.
  2. Select the required BehaviourName# menu item, where BehaviourName is the name of the added Behaviour and # usually only appears if more than one of same type of Behaviours have been added. For example: Execute Command1

Tip: You can also select its glyph to display its task menu and then select the required link beneath the Behaviours heading.

This displays the configuration dialog of this Behaviour.

Tip: The Behaviours tab of the SmartUI Designer ribbon provides the Edit Behaviour list box that lists all the Behaviours configured for the currently selected form component. Clicking its browse button displays the configuration dialog of the currently selected behaviour.

To remove one or more added Behaviours from a control or graphic element:

  1. Select the required control or graphic element.

  2. If necessary, select the Behaviours tab from the SmartUI Designer ribbon.

  3. Select the Remove command from the Remove group.

Tip: You can also select its glyph to display its task menu and then select the Removelink beneath the Behaviours heading.

This displays the Behaviour Removal configuration dialog.

  1. Select (check the checkboxes) of the Behaviour/s that you want to remove from this list in the Behaviour Removal configuration dialog.

WARNING! Ensure that ONLY the Behaviour/s you do not require is selected, since no deletion confirmation dialogs are displayed.

  1. Click the Finish button to remove the selected Behaviour/s or Cancel to abort.
