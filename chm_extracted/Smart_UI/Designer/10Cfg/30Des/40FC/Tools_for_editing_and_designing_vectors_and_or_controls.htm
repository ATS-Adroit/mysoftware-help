Tools for arranging and designing vectors and/or controls

The SmartUI Designer provides a number of tools to assist with arranging and designing form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. on the currently displayed graphic form.

These tools are located within the Design tab of the SmartUI Designer ribbon, which is displayed by selecting the Design tab from the SmartUI Designer ribbon

The Design tab provides the following groups of tools:

  • Vectors: tools for ONLY working with vectors (graphic elements). For details, see Vector tools for editing and designing vectors.
  • Workspace: tools for arranging and organizing ALL form components. For details, see Workspace tools for arranging form components.
  • Font: click a form component or a displayed text property, then use this to select or modify its font.
  • color: this section provides the following color-property specific tools:
  • color selection control: click a form component or ANY of its color properties to change its color.

Click for more details on how to use this selection control: either use the top two scroll buttons to move up and down the rows within this selection control or click the bottom button to expand the selection control to display all the available selection options, which collapses once you have made your selection.

The following tool ONLY applies to configuring graphical elements (vectors):

  • Gradient selection control: click a vector or vector group and then either click Gradient to apply the currently selected gradient or click the drop down list button to the right to change the current gradient by selecting one of the pre-defined Gradient Types and/or changing the required gradient color and/or the Intensity or transparency of the gradient fill.

The following tool ONLY applies to configuring the Backcolor property of a form component:

  • Format Painter: click the form component whose Backcolor you want to copy to another form component, then click the Format Painter option and then click the required form component whose Backcolor property you want to configure.
  • Snapping: tools that assist in aligning or positioning form components with respect to existing form components, when dragging them within the graphic form.

Note: Changing the current snapping method used for a graphic form, requires the graphic form to be saved and reloaded.

Select the required snapping method that you want to use from the Snap Mode list box, as follows:

Note: Unless the Enable Vector Snapping Check checkbox is checked, the selected snapping method ONLY applies to the controls on the graphic form and not the vectors.

Tip: This checkbox should typically only be unchecked when using the SnapLines option, which can be very irritating especially when there are a lot of vectors that are randomly placed on the graphic form.

  • Off: to turn off all snapping of form components - if you find this feature annoying and/or want to manually align your form components.
  • SnapLines: to use snap lines, which are typically blue, when dragging controls to the sides of the existing controls (and if the Enable Vector Snapping Check checkbox is checked, these lines are also displayed when dragging vectors and this also allows controls and vectors to be snapped to the sides and/or centers of vectors).

Note: When dragging controls that contain text, pink snap lines appear to align the text with the text of other controls. These pink snap lines are not displayed for vectors that contain text.

  • Grid: controls (and if the Enable Vector Snapping checkbox is checked then also vectors) align their top left corners to the nearest grid point when moved and resized (snapping to the nearest grid point in the direction of the resize).

Note: When this option is enabled, you can specify the distance, in pixels, between each grid point by using the Grid size spin control.

Tip: When this option is enabled and you nudgeto move a form component in typically 1 pixel increments, by using the arrow keys. form components, they are nudged the distance, in pixels, specified by the Grid size spin control. Although nudging does not necessarily snap to the grid, it only moves the form components the specified distance.

  • Shapes: add commonly-used pre-configured vector shapes to your graphic form instead of configuring them yourself via the Vectors group of the Toolbox window, which are classified into the following groups: Basic Shapes, Advanced Shapes and Pipework.
