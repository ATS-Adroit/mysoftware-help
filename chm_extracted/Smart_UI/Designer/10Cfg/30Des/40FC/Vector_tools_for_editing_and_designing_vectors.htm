Vector tools for editing and designing vectors

The Vectors group of the Designtab from the SmartUI Designer ribbon, provides the following tools for editing vectors (graphic elements) added to the currently displayed graphic form:

Tool Function Description

Create Vector Group

To group the selected vectors, so they are easier to manage and move.

Tip: Use the Contents window to assist you in displaying (and editing) each contained vector and/or control and their configured Behaviours in a vector group. For details, see Contents tool window.

Note: Once created the Tasks list of the vector group (accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control) provides the Child Behaviours list, to display all the Behaviours added to its component vectors, so that these can be edited or deleted or added. For details, see Child Behaviours.

Break Vector Group

To break a group of vectors into their component vectors, so that these can be individually edited.

Reset Center

To reset the center point of the selected vector.

Rotate Right 90

Rotate the vector to the right by 90 degrees.

Rotate Left 90

Rotate the vector to the left by 90 degrees.

Flip Vertical

Flip the vector vertically (in the y dimension) around its configured center point.

Note: If the center point is at its center, then this command may not change the appearance of the vector, if the shape is vertically symmetrical.
Flip Horizontal

Flip the vector horizontally (in the x dimension) around its configured center point.

Note: If the center point is at its center, then this command may not change the appearance of the vector, if the shape is horizontally symmetrical.

Rotate

To specify the required rotation of the selected vector around its configured center point, as follows:

  • type in the required number of degrees in the edit box.
  • click the left button and select one of the pre-defined rotation angles.

If necessary, reapply the specified rotation angle, by clicking the right button.
