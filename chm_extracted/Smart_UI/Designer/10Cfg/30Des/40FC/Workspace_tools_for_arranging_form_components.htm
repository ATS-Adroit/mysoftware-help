Workspace tools for arranging form components

The Workspace group of the Design tab from the SmartUI Designer ribbon, provides the following groups of tools for arranging and/or organizing ALL form components i.e. BOTH controls and vectors for the currently displayed graphic form:

Note: Many of these tools require selecting more than one form component. In this case the term "primary form component" is used to indicate either the primary controlwhen a group of controls are selected, the sizing handles of this control are white and its attributes will be used if this group of controls are formatted. See control. or primary graphic elementwhen a group of graphic elements are selected, this is the first graphic element that is selected and its attributes will be used if this group of graphic elements are formatted. See graphic element., depending upon the selected form component type.

  1.  Alignment: these tools align the currently selected form components with each other using the selected primary form component as the alignment reference.
    ToolAlignmentDescription

    Align To Grid 

    Snaps the top left of the selected controls to the closest grid.

    Align Lefts

    Positions the left-most edges in line with the primary form component.

    Align Centers 

    Positions the centers in line with the primary form component.

    Align Rights

    Positions the right-most edges in line with the primary form component.

    Align Tops

    Positions the tops in line with the primary form component.

    Align Middles

    Positions the middles in line with the primary form component.

    Align Bottoms

    Positions the bottoms in line with the primary form component.

Snap lines: these tools align vectors and controls in a graphic form.

When you drag a control, the following two lines appear:

  • A blue line, which indicates the alignment of this control.
  • A light grey line, which indicates the recommended distance between controls.
  1.  size: these tools change the size of the selected form components, using the selected primary form component as the sizing reference.
    ToolSizingDescription

    Make Same Width 

    Adjusts the width of all selected form components to the width of the primary form component.

    size To Grid

    Adjusts the width and height of the selected form component(s) to the closest grid.

    Make Same Height 

    Adjusts the height of all selected form components to the height of the primary form component.

    Make Same size

    Adjusts both the width and the height of all selected form components to the width and height of the primary form component.

  2. Spacing: these tools change the horizontal and/or vertical spacing between the selected form components. 
    ToolSpacingDescription

    Make Horizontal Spacing Equal

    Makes equal space between the selected form components using the outermost form components as endpoints.

    Increase Horizontal Spacing

    Increases the horizontal spacing by one grid unit relative to the primary form component.

    Decrease Horizontal Spacing

    Decreases the horizontal spacing by one grid unit relative to the primary form component.

    Remove Horizontal Spacing

    Removes the horizontal space so that the form components are aligned with their edges touching, relative to the primary form component.

    Make Vertical Spacing Equal

    Makes equal space between the selected form components using the top and bottom form components as the end points.

    Increase Vertical Spacing

    Increases the vertical spacing by one grid relative to the primary form component.

    Decrease Vertical Spacing 

    Decreases the vertical spacing by one grid relative to the primary form component.

    Remove Vertical Spacing

    Removes the vertical spacing so that the form component's borders are touching, relative to the primary form component.

    Note: If a spacing tool does not produce the results you want, try to manually rearrange some of the form components and repeat this tool.

  3.   Layout: these tools center and/or change the order of the selected form component(s) on the graphic form.
    ToolLayoutDescription

    Center Horizontally 

    Aligns the middles of the selected form component(s) to a horizontal line in the middle of the graphic form.

    Center Vertically

    Aligns the centers of the selected form component(s) to a vertical line in the center of the graphic form.

    Bring To Front 

    Moves the selected form component(s) to the front of all other form components on a graphic form.

    Send To Back

    Moves the selected form component(s) behind all other form components on a graphic form.

    Note: Graphic elements will ALWAYS be placed “behind” controls on a graphic form.

  4. View Tab Order : this toggles the display of the tab ordering of the controls and wizards added to this graphic form, which are displayed as numbers in a blue box in their top left corners, which you can re-order by clicking the required boxes to change their numbers to establish the required order.

    Note: When a control is inside a container (such as part of a wizard) this becomes a floating number that allows you to specify the tab order of the controls within this container too.
