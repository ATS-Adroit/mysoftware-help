Including third-party form components

In addition to using the default form components provided by the Toolbox tool window, you can add third-party form components to further customise your graphic forms. Click for more information:

Before a third-party form component can be added to a graphic form, it needs to be added to the Toolbox tool window first.

Note1: Any form components added to the Toolbox, will ONLY be stored in the profile assigned to the currently logged in user, if its Automatically update profile option is enabled. For details, see Customizing connections and work environment. This is stored in the User Profile Settings of your profile in the ToolboxItems variable.

Note2: It is also possible to remove third-party form components. For details, see Removing custom form components.

Adding third-party form components, involves the following two-step process:

  1. Copy the files of the required form component(s) to the appropriate folder.
  2. Add the third-party form component(s) to the Toolbox tool window.

To copy the required form component(s) to the appropriate folder:

  1. By default, the files for the required form component(s) need to be copied into the Plugins folder, which is relative to the installation folder of the SmartUI Designer, which is typically: C:\Program Files\Adroit Technologies\Adroit.

Note: The CustomControlsRelativePath setting of the SmartUI Designer designates the name of this sub-folder, which is the central repository for all custom form components. For details on accessing this setting, see Advanced Designer settings.

  1. The category in which these form components will be listed in the Toolbox tool window, is determined, as follows:
  1. The name of the category is usually determined by the name of the folder in which they are placed. Therefore instead of copying the files directly into this folder, it is possible to create one or more aptly named sub-folder(s) and copy these files into the required folder(s) instead.

Note: Form components are also able to specify their required category programmatically.

  1. By default, this icon identifies a custom category in the Toolbox tool window. However, this icon can also be customised, by placing an icon file called default.ico into each of the relevant folder(s) instead. 

To add the third-party form component(s) to the Toolbox:

  1. If necessary, open the Toolbox tool window in the SmartUI Designer.
  2. Right-click an existing category heading and select Add Controls.

Note: The category, in which a form component is added, is dependent upon which form component is selected and NOT upon the category that is right-clicked.

This displays the Custom Controls dialog, which alphabetically lists all the form components located within the specified custom controls folder (and its sub-folders).

Tip1: Use the Name, Namespace, Assembly and/or Directory columns within this dialog to locate the required form components, as needed.

Tip2: Select the column heading of a column to sort the list using this column and to change the sorting order between ascending  and descending order.

  1. If you cannot see a checkbox for the required control, click the Browse .NET Control button and browse to the file location, typically within the plugins folder and select the DLL of this control and click Open. This adds a checkbox for this control to the Custom Controls dialog.
  1. Check the checkbox(es) of the required form component(s) that you want to add and click Finish.

Tip: Double-clicking on a row, within this dialog, will check or empty its checkbox. 

  1. The form component(s) are added to the Toolbox tool window within the category that is either specified by each form component itself or by the name of the folder in which it is located.

Note: If this category does not exist, it will be added to the top of the existing categories.
