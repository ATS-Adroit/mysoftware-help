Working with datasources

A datasource is the actual connection to each source of data wherever it is physically located. By using its associated datasource plugin, a datasource is able to:

  • Expose the connected data to the Server as data elements.
  • Provide any special functions so that users can further interact with this connected data.

Note1: A datasource can only be created if a datasource plugin for this specific data exists.

Note2:The licensing of the Server determines, which datasource plugins are available for use and therefore the sources of data the Server is able to connect to. For more information on licensing the SmartUI Server, see Licensing the Server.

For further details concerning the data architecture, see About datasources and data elements.

Datasources can be added and removed within the Datasources category of the required Server connection in the Enterprise Manager. Click for more information:

  1. For details, see Adding datasources, Removing datasources or Working with connections.
  2. Instead of manually duplicating a datasource (and its configuration) from one Server to another, it is possible to export and import datasources. For details, see Exporting datasources.
  3. Once added, a datasource can be opened or closed to display or hide its data elements and/or special functions. For details, see Opening datasources or Closing datasources.
  4. Due to the client-server model that is used, it is possible for one or more Designers to be connected to the same Server and add, remove and/or modify existing datasources.
  5. For this reason it is possible to update specific datasources and to lock a datasource, so as to be able to exclusively modify it. For details, see Updating datasources or Locking datasources.
  6. Access to datasources, their data elements and/or its special functions can be controlled, if necessary. For details, see Securing datasources.

Tip: The Watches tool window can be used to quickly view (and if possible modify) the real-time value of data elements of any datasource in the Designer. For details, see Watches tool window.
