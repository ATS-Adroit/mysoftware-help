The following datasources can be added per Server connection in the Enterprise Manager, within its Datasources category, provided that the required datasource plugin exists. For details, see Working with datasources or Working with connections.

Note: Some of these datasources may not be obtainable, due to specific licensing restrictions. For more information on licensing the SmartUI Server, see Licensing the Server.

Datasource Purpose

Adroit

Exposes the configured agents and their slots, within a specific Adroit Agent Server. For details, see Adroit datasources.

Event Log

Exposes the events within the Windows event logs of a specific computer. For details, see Event Log datasources.

OLE DB

Exposes the data within a specific OLE DB compliant database or data store. For details, see OLE DB Datasources.

How to chart and/or report data from a database

Simulation

Exposes a wide variety of different types of generated data. For details, see Simulation datasources.

Note: This resides upon the Server itself.

Server Scripts

Stores scripts that can either be run on the Server or the Client. For details, see Server Scripts datasources.

Note: This does not connect to outside data.
