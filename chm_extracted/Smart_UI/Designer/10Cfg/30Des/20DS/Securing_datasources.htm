Securing datasources

Once a datasource has been added, its data and its additional functionality, if provided, is exposed.

Depending upon the sensitivity of this data and/or the exposed functionality, you may need to control the access to these items. Both the datasource itself and its data can be secured using the data element security. For details, see Working with data element security.

This allows one to specify which user(s) and/or group(s) are allowed to view, configure and remove these items and/or who is able to configure their security settings. For details on how to control the access to the datasource and its data elements, see Assigning security permissions to data elements.

Note: If the currently logged on user, does not have the necessary security permissions, then he/she may not even be able to see the datasource in the Enterprise Manager and/or some or all of the data elements. Furthermore he/she may be unable to configure or delete some or all of the data elements that are visible.

Tip: If you need to reset the configured security settings for any reason, then right click the datasource and select the Reset configured security item.

Note: Ensure that the specified allowed user(s) and group(s) are also associated with the required policies, so that they may be able to add and/or remove the specified datasource and in necessary, use its special functions. For details, see Available policies.

If the datasource also exposes additional functionality, this can also be secured using the special function security. For details, see Working with special function security.

This allows one to specify which of the allowed user(s) and group(s) are able to use these functions and/or who is able to configure their security settings. For details on how to control the access to the special functions, see Assigning security permissions to special functions.

Note: If the currently logged on user, does not have the necessary security permissions, then he/she may not even be able to see some or all of the special functions.
