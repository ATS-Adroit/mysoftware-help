Scheduling script objects

When a script is required to perform routine services that are required at specific time periods, you can schedule these server scripts to automatically be triggered at the correct times. 

To schedule a script:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. Click the plus box to the left of the Server Scripts datasource or its icon .

Tip: It is also possible to display the script objects by double-clicking on this name or icon. 

  1. Right-click the required name of the script object or its icon and select Script Scheduling.

The Schedule Script configuration dialog is launched

  1. Specify the required Schedule Type from this list, as follows:
  2. Interval: the default option, to trigger this script every ## seconds, as specified by the Trigger the script every spin control. The default value of 0 does NOT trigger the script

IMPORTANT: In order to use the Interval Schedule Type, you must specify an interval that is >= the MinimumScriptSchedulingTime setting in the Server and Service .CONFIG file [in the DatasourceSettings group].

  • One Time: to Trigger the script at the following Date and Time, which you specify as follows:select the required date and/or time unit and either type in the required unit or use the spin control's arrows to select this.
  • Daily: to Trigger the script Daily at the following time, which you specify as follows:select the required time unit and either type in the required unit or use the spin control's arrows to select this.
  • Weekly: to Trigger the script Weekly, synchronised at the following Date and Time, which you specify as follows:select the required date and/or time unit and either type in the required unit or use the spin control's arrows to select this.  
  • Monthly: to Trigger the script Monthly, synchronised at the following Date and Time, which you specify as follows:select the required date and/or time unit and either type in the required unit or use the spin control's arrows to select this.
  1. If you need this script to be performed as soon as the Server starts up, then check the Trigger on startup checkbox.
  2. Specify the user account (User Name and Password) that this script should be run under, in the Run the script under the following user section.

Note: A User Name and Password must be specified for scripts that interact with other datasources. In other words, those scripts that read and/or write data elements or call special functions etc.
