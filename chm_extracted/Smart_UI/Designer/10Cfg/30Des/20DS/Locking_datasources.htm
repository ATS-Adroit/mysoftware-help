Locking datasources

Due to the client-server model of SmartUI more than one user can modify the same datasource exposed by a SmartUI Server.

But if you want to be the only user that is able to modify a datasource, then you can lock this datasource in the Enterprise Manager.

Click for more details:

Note1: Only users that have the necessary security permissions can do this. For details, see Securing datasources.

Note2: Although other users are unable to modify a locked datasource, they can still view and display this datasource.

Note3: A locked datasource can either be unlocked by the same user who locked the datasource or by any user with global security access to this SmartUI Server (typically an Administrator).

Note4: You can identify a locked datasource in the Enterprise Manager by its red text.

Note5: A datasource remains locked until it is unlocked, so it remains locked even when the user that has locked it has logged off the SmartUI Server. For details, see Unlocking datasources.

To lock a datasource:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. Right-click the relevant datasource name or icon and select Lock.

This changes the text of this datasource item to red in the Enterprise Manager.
