Simulation datasources

The Simulation datasource provides a wide variety of different types of data for simulation or testing purposes, when you cannot connect to an actual datasource. Click for more information:

Each simulation datasource, contains a number of simulation categories, whose data is either unchanging (static) or mathematically generated and therefore constantly varying. This simulated data is essentially a dependable source of data, which can be used when testing the animation of your graphic forms within the design phase. 

Note: It is also possible to use a Simulation spider to create and configure simulated data too, which is mathematically generated. For details, see Simulation spiders.

This datasource is added to the Datasources category of the required Server connection in the Enterprise Manager. For details, see Adding Simulation datasources.

A Simulation datasource is identified in the Enterprise Manager by its specified name and its icon . When this datasource is opened the simulated data is displayed, in the following hierarchy:

  1. The simulated data categories are listed alphanumerically beneath this datasource.
  2. Each category can be expanded to reveal its simulated data, which is also displayed alphanumerically. The icons used to represent this data, vary according to the category selected.

Tip: It is recommended to use this data, when animating graphic forms and not their simulation properties, if any, which are all static values.

  1. Most of the simulated data, can be further expanded to reveal the following properties that govern the generation of their simulated values, which are also listed alphanumerically:
Property Description

Amplitude

The maximum value that will be generated for this output.

DE

This contains the first simulated value of this data element.

Note: It is not recommended to use this property when animating graphic forms, since it will NOT update.

Frequency

The cycle time of the simulation item in Hz, the lower the number the less the simulated values change.

Name

The fully qualified name of the simulated data, including its simulation category.

Running

This Boolean value, indicates whether this simulated value is being generated (True) or not (False), when the graphic form is in Run mode. For details, see Opening graphic forms.

ShortName

Only the name of the simulated data.

SimulationType

 

This specifies the format or generation of the simulated values:

  • DATASET: A DataSet consisting of 2 columns and 2 rows.
  • RAMP: A value increasing linearly, in increments specified by Frequency, from 0 to the Amplitude and then decreasing linearly back to 0.
  • SIN: Sine values between + and - Amplitude.
  • SQUARE: Values are squared between 0 and the Amplitude.
  • STATIC: An unchanging value.
  • CPU: The name of the performance counter used to obtain the % processor time of the system.

UpdateRate

The time in milliseconds between successively generated values.

Note: Although the BulkSimulDE### data within the Bulk simulation category cannot be expanded, they too are RAMP values, where the number indicated by ### specifies the seed number from which the value begins to ramp upwards from.
