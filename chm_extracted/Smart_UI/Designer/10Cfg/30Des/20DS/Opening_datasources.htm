Opening datasources

Datasources can be ‘opened’ or expanded in the Enterprise Manager just like any other component. When a datasource is opened, it will expose its data elements and/or each special functionoptionally provided by a datasource plugin to perform additional functionality forinteracting with each datasource and / or its data.. For details, see Working with datasources.

To open a datasource:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  1. If necessary, expand the name of the default Server connection . For details on connections, see Working with connections.

Tip: The connection name is prefaced by the Server computer name.

  1. If necessary, expand the Datasources category.
  1. Click the plus box  to the left of the required datasource name and its icon.

Tip1: You can also open a datasource by double-clicking on its name or icon.

Tip2: Right-click on the datasource name or its icon to display a list of actions that can be performed.

  1. If necessary, navigate this specific datasource until the required data element or special function is located. For details on navigating specific datasources, see Available datasources.
