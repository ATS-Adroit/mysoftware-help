Event Log datasources

An Event Log datasource exposes the events contained within the Windows event logs of the specified computer. Click for more details:

These events can be used to gather information about any hardware, software, and/or system problems that this computer may be experiencing. For instance, certain applications make use of the Application event log to record application-specific events, such as errors, warnings and other relevant information.

This datasource is added to the Datasources category of the required SmartUI Server in the Enterprise Manager. For details, see Adding Event Log datasources.

Click for advanced Event Log datasource usage information:

You can configure this datasource to specify the following GLOBAL settings: the required polling interval to retrieve updated events and the maximum and minimum number of events to retrieve and user authentication if using a remote event log. For details, see Configuring Event Log datasources .

In addition, the datasource can also be updated, locked or removed, if necessary.

Note1: The Event Log service enables the viewing of the event logs on a computer. Access to this service is usually provided by default when one accesses the computer, either locally or remotely.

Note2: You can control the access to this Event Log datasource (NOT its exposed event groupings and their events). For details, see Securing datasources.

An Event Log datasource is identified in the Enterprise Manager by its specified name and its icon . When this datasource is opened, the events of the specified computer are displayed, in the following hierarchy:

  1. The names of the event log file(s) , containing all the events have been logged to these files, are listed alphanumerically beneath this datasource.
  2. Within each event log file name the events are further grouped by their source names i.e. the name of the software that logged the event, which are listed alphanumerically.

Each event contains a number of fields or columns of data. For details, see Columns of event data.

Note1: Use the EventViewer control to display these events in a graphic forms. For details, see EventViewer controls.

Note2: Typically data updates from the Event Log datasources ONLY send CHANGED data after each polling period. In order to show ALL the historical data AND any new events that come through, CHECK the Append Data Updates checkbox of the required Property spider . For details, see Displaying both existing and updated dataset data.
