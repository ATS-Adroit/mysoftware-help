Adding Event Log datasources

Add an Event Log datasource to expose the events contained within the Windows event logs of the specified computer. Click for more information:

Note1: Only users that have the necessary security permissions can do this. For details, see Securing datasources.

Note2: After adding an Event Log datasource, you can specify its polling interval, the maximum number of events to retrieve etc. For details, see Configuring Event Log datasources.

To add and configure an Event Log datasource

Click for generic instructions on how to add and name a datasource:

  1. Open the Enterprise Manager.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  1. Right-click on the name of the required SmartUI Server or its icon and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Add Datasource.

The Add Datasource configuration dialog is launched displaying each datasource plugina generic type of data supplier that interfaces between the Server and this specific type of data, so that it is exposed to the Server in the format of data elements. See data element. that you can connect to.

Note: Only the datasource plugins, which have been licensed, appear in this list.

  1. Click the datasource you require and then click the Finish button.

Tip: You can also simply double-click the required datasource.

The Add A New Datasource configuration dialog is displayed to configure this datasource:

  1. Type an appropriate name for this datasource into the Name edit box.

When naming this datasource, please be aware of the following:

WARNING! Once a datasource has been named, it is NOT possible to rename it later.

Note1: The following non-standard text characters are NOT supported for datasource names: \ / : * ? < > | # "

Note2: Datasource names are case sensitive.

Note3: The specified name cannot be the same as any other datasource that has been already been connected to this Server.

Tip: Although the datasource name can be up to 50 characters long - use a descriptive name that is as concise as possible. This will ensure that users will BOTH easily identify and navigate to it within the Enterprise Manager.

To configure an Event Log datasource

  1. Specify the name of the computer to connect to.

Tip: You can leave this BLANK if you want to connect to the event log on your default Server computer i.e. the Server that you have logged in to initially.

  1. Type the name of the required computer into the Machine edit box.

Note1: Ensure that the computer that you wish to connect to is located within the same domain as the Server specified by the default connection.

Note2: If you press ENTER after finishing this name, the connection to this computer name will attempt to be created.

Tip: Instead of typing in the literal network name of the computer, it is also possible to specify the IP address of the required computer.

  1. If this event log is located on a remote computer that the currently logged on user cannot connect to, then uncheck the Use Integrated Authentication checkbox and type in the required User Name and Password in these edit boxes.
  2. Click the Test Connection button to ensure that the Server is able to successfully connect to this computer.

Note: If the connection was not tested successfully, ensure that the computer name is correctly typed in and that this computer is within the same network as the Server specified by the default connection. 

  1. Click Finish once the connection has been successfully tested and the datasource has been named.

This adds a Event Log datasource to the Datasources category in the Enterprise Manager, which can be identified by its specified name or icon .
