Create Table queries

Queries provide common tasks for managing your database that is connected to an OLE DB datasource.

The Create Table Queries can create tables in the database with specific structures. Click for more information:

If necessary specify primary keys and lookup columns (foreign keys) for fields.

By parameterizing the table and/or field names you can create a library of common table configurations, in which you only perform the laborious configuration once for all.

Note1: If necessary, parameterise the table and/or the field names to specify them before performing the query.

Note2: This query is ONLY able to create a SINGLE table.

 

To add and configure a Create Table query:

Add a Create Table Query:

Click for generic instructions on how to add, name and specify the creation method for a query:

  1. Open the Enterprise Manager.
  2. If necessary, expand click the plus (+) box to the left of the current icon or nameServers.
  3. If necessary, expand the name of the required SmartUI Server connection .

Tip: This connection name is prefaced by the SmartUI Server computer name.

  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required OLE DB datasource name or its icon .
  3. Right-click Queries or its icon and select the Add XXX Query option, where XXX is the required query category.

Tip: Alternatively, simply double click the subfolder of the required query category .

  1. Specify the required Query Name in the Add XXX Query configuration dialog:

    WARNING! Once a query has been named, it is NOT possible to rename it later.

    Note: The specified name cannot be the same as any other query that has been already been specified.>

    Tip: Give this query a meaningful and concise name so that its purpose can be clearly identified - try not to use all 55 characters.

  1. If supported by this query category - choose how you want to create this query, by selecting one of the following options:
    • XXX Query Wizard:This default option uses a structured configuration dialog to create the query. This method is especially recommended for those who are not familiar with the SQL querying language.

    Tip: Advanced users can use the configuration dialog to perform the basic configuration such as specifying the required tables and their fields and then customise the added commands using the final dialog, which is the SAME dialog provided by the Custom Query option.

    Note: This generates a generic SQL statement and will work with all types of OLE DB databases.

    • Custom Query: This method is intended for those users who are already conversant with the SQL querying language and want to quickly create their query. For details, see Creating customised queries.
  2. Click Next, once the query is named and the required method of its creation is selected.

Configure this Create Table query:

Note: This configuration dialog does NOT provide a Preview button to prevent incorrect tables from being added to your database. Therefore please ensure that you configure the values for these fields correctly.

The Tables and Fields dialog is displayed.

  1. Specify the table name.
  2. To specify a fixed (unchangeable) name for this table, enter this name in the Specify a New Table Name edit box.
  3. To specify a parameter for this table, so that it can be changed before the query is performed, check the Parameterised Table Name checkbox. This is recommended if you need to create more than one table with the identical structure.

Note1: This ignores any name added to the Specify a New Table Name edit box.

Note2: If necessary edit the parameter name for this table in the Custom Query dialog.

  1. Specify the columns (fields) of this table, as follows:

To add a column (field) to this table:

  • To specify a fixed (unchangeable) name for this column (field), enter this name in the Column Name entry.
  • To specify a parameter for this column, so that it can be changed before the query is performed, check the Parameterised checkbox. This is only recommended if you have parameterised the Table name and different tables required identically configured fields with different names.

Note1: This ignores any name added to the Column Name entry.

Note2: If necessary edit the parameter name for this column in the Custom Query dialog.

  1. If necessary, select the required data type for the values of this column (field) from the Type list box.
  2. If necessary, change the default width of the selected data type in the size entry.
  3. If necessary, specify whether this column is able to have NULL values or not, by checking or clearing the Allow Nulls checkbox accordingly. Typically null values are NOT required in primary or foreign key columns.

To remove a column (field) from this table:

  1. Select the row that defines this column and press the DELETE key.

To set or clear a column (field) as a primary key for this table:Typically primary key columns have unique values, which are used to identify rows in this table.

  1. Right-click the row that defines this column and select Set Primary Key.
  2. This adds or removes the PK row identifier.

To assign a default value for a column (field):

  1. Select the required row and enter it into the Default Value field.

Note: Please ensure that you specify the correct default values these fields, as there is no error checking.

To automatically increment the value of a NUMERIC column (field):Typically required for primary key fields containing ID numbers.

  1. Select the row of that defines this column that has a numerical data Type.
  2. If necessary, select the Column tab below the list of columns.
  3. Select Yes from the Identity list box.

Note: Select Yes(Not For Replication) when you want the identity values of all the replicated rows to remain unchanged, while the identity values of rows native to this table will change as required.

  1. Specify the number to start incrementing from, in the Identity Seed spin control (either by typing it in directly or using the arrows to select it).
  2. Specify how many numbers to increment each value by in the Identity Increment spin control (either by typing it in directly or using the arrows to select it). For instance the default of 1 creates consecutive numbers.

To configure a column (field) to be a foreign key:Typically, foreign keys are created to create a relationship with another table.

  1. Select the row of that defines this column.
  2. If necessary, select the Column tab below the list of columns.
  3. Check the Lookup Column checkbox.

This displays the Lookup tab.

  1. Select the Lookup tab below the list of columns.

The Lookup Field tree view displays all the tables and fields of the database connected to this OLE DB datasource.

  1. Select the field (from another table) that this column should be linked to.
  2. If necessary use one or both of the following rules to ensure that values in this column remain synchronised with the lookup field's values:

Note: The default NO ACTION rule does not attempt to keep the values of these fields synchronised.

On Update Rule: when the reference ID of the lookup table changes then CASCADE ensures that any changes made will cascade down to this table.

On Delete Rule: when the reference ID of the lookup table is deleted then CASCADE ensures that the changes made will cascade down to this table and this value will become NULL.

  1. Click Next, once the required fields and their values have been defined, to end the query configuration dialog.

The Custom Query dialog is displayed, which allows you to manually configure this query, if necessary.

Note: This dialog should be used to rename any parameters that were specified for table and/or field names.  

  1. If necessary, type or modify the existing SQL querying commands in the SQL Query editor, which highlights keywords and makes it easier to customise your queries.
  1. Click Finish, once you are satisfied with this query.

This adds this query with its specified name beneath the Create Table Queries subfolder of the Queries folder of the applicable OLE DB datasource, in the Enterprise Manager. 

 

To perform a Create Table query using a Query spider: this procedure describes how to perform a Create Table query by clicking a Button control and to display the result of this operation in a TextBox control on a graphic form.

This procedure assumes that the Create Table query has been added and configured.

Prepare the graphic form:

  1. Open a new graphic form in the Design workspace. (If necessary, add a project and a graphic form first)
  2. Add a Button control to this graphic form from the Toolbox - this will be used to trigger the Query spider so that it will perform the query.
  3. Add a TextBox control to this graphic form from the Toolbox - this will be used to display the results of performing this query.
  4. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the TextBox control in the graphic form.

Add and configure the Query spider to run this query:

  1. Open the Spider Configuration tool window.
  2. Right-click the spider workspace itself and select the Create New Spider menu.
  3. Click the Databasing sub-menu and its Query item to add a Query spider.  
  4. Double click the title bar of this spider to open its configuration view.
  5. Select the required query from the Inputs section of this spider, as follows:
  1. Click the Server containing the required OLE DB datasource from the Server list box.

Tip: Use the Default Server selection, when referring to the Server that you use to log in, instead of its actual name as this makes it easier to transfer this spider to another Client.  

  1. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the required OLE DB datasource from this list of available OLE DB datasources on this Server.

The first OLE DB datasource created on this Server is selected by default.

  1. Click the required type in the Query Type list.

The Select Query category is selected by default.

  1. From the Query Name list box, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the name of the required query.

Note: It is important to name your queries clearly, so that it is easy to select the correct one.

  1. If this selected query contains parameters, then the names of these parameters will be added as additional inputs to the Inputs section.

    Note1: The value of each parameter input can either be provided by a property or data element via a silka line with an arrow at its end, which links the output of one spider to the input of another. or can be typed in manually. For details, see Creating silks.

    Note2: If using SQL, please ensure that all the date parameters for this query adhere to the universal date time standard for SQL, which is yyyy-mm-dd.

    Tip: When typing in a value manually, double-click the value column to the right of the parameter name in the Inputs section and type in the required value.

  1. It is recommended to use the Confirm Action checkbox to display a confirmation dialog before this query inserts a record into your database.

This spider performs this query to insert a record, when it is triggered.

WARNING! Please ensure that you have provided values for ANY parameters used by this query BEFORE triggering this spider otherwise an error will be displayed.

Note: You will notice in the Event Trigger section of this spider that this Query spider is triggered by clicking the Button control.

Connect the Query spider to the TextBox control:

  1. If necessary, open the property tree by using the pane display bar on the right border of the central spider workspace pane. For details, see Working with pane display bars
  2. In the Outputs section, drag the Return Information output onto the Appearance category beneath this TextBox control in the property tree and when this category expands, drop it onto the Text property.

Note: The Return Information output either describes the reasons for NOT deleting a record or how many records were removed.  

Test that the query is correctly displayed:

  1. Click the Preview toolbar button of this graphic form.
  2. Press the Button control, if you used Confirm Action the confirmation dialog should be displayed.
  3. The TextBox control should either display an error message or how many records were deleted.
  4. Save the graphic form by pressing its Save toolbar button to save these changes.

To edit this query.

Tip: Right-click the required Create Table query and select Edit Create Table Query.

To delete this query.

Tip: Right-click the required Create Table query and select Delete Create Table Query.

 

For details of parameterizing queries, see Working with parameters.
