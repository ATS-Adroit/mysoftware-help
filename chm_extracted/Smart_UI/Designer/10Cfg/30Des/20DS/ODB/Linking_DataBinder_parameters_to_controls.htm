Linking DataBinder parameters to controls

If your DataBinder has parameterised constraints, then you need to do the following:

  1. Add a VIZNETDataBinder component to a graphic form and link it to this DataBinder.
  2. Add controls to this graphic form to allow users to specify the values of each parameter.

Tip: You can also use the controls added by VIZNETDataBinder component for this.

  1. Link the parameter to the required controls, by configuring the VIZNETDataBinder component to specify which control’s property will supply the value of each parameter.
  2. Test that your DataBinder allows your users to make use of the required data. For details, see Utilizing data with VIZNETBindingNavigator controls.

To link controls to parameters in a DataBinder:

Note: This procedure assumes that a graphic form already has a VIZNETDataBinder component that is associated with the required DataBinder. For details, see Accessing data within DataBinders.

  1. If necessary, add the controls required to specify the value/s of the configured parameter/s to this graphic form.

Typically these controls are either TextBox controls, which allow users to type in their own values or ComboBox controls, which allow users to select values from an pre-existing range of options.

For instance, you can use the Text property of a TextBox control to supply the value of a parameter.

  1. Ensure that your graphic form is in Design mode, if not press the Design toolbar button at the top of the graphic form.
  2. Select the required VIZNETDataBinder component.

Tip: Components are beneath the actual form of the graphic form.

If necessary, display the Properties tool window.

  1. Select the ParameterSourceList property of this VIZNETDataBinder component in the Properties tool window.
  2. Click the downward arrow to the right of (Collection).

The left pane lists the names of the tables selected in this DataBinder and the View, which adheres to the following naming convention *[DataBinderName]View.

Note: If a table or View has one or more parameters, a plus box will appear to the right of its name, in the left pane.

  1. Double click the required table or View first item in the right pane that has a plus box to expand it.

This displays the names of all the configured parameters.

Tip: Giving your parameters descriptive names, makes it easier to pair parameters with controls.  

  1. Select the name of the required parameter.
  2. Specify the name of the control that will provide the value of this parameter in the Control (top) list box in the right pane.

Tip: This is why you need to add the required controls first.

  1. Select the property of this control that will contain the value for this parameter in the Property (bottom) list box on the right pane.
