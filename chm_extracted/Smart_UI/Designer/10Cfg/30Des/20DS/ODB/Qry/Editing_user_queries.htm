Editing queries

Once a query has been added and created for an OLE DB datasource , it is able to be edited.

To edit a query created for an OLE DB datasource:

 

  1. Open the Enterprise Manager.
  2. If necessary, expandclick the plus (+) box to the left of the current icon or name the Servers .
  3. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the Server computer name.

  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required OLE DB datasource name or its icon .
  3. If necessary, expand Queries or its icon .
  4. If necessary, expand the query category that contains the required query.
  5. Right click the name of the required query or its category-specific icon and select Edit ... Query (where ... refers to the category name).
  6. The Edit ... Query configuration dialog is launched, displaying the Change the query dialog, which allows you to manually modify this query.
  1. Change the required commands to perform the required query or to execute a stored procedure in the SQL Query edit box.

When creating or editing constraints within this query, parameters can be added so that their requirements can be dynamically specified. For details on specifying and using parameters, see Working with parameters.

Note: The Preview button, provides as easy way to debug your query as you manually edit it. Clicking this button will return all the fields, in the pane at the bottom of the configuration dialog, that the current query would return. In this way you can ensure that your query does return what you want it to.

Note: When previewing queries containing parameters, a dialog box will be displayed for each parameter, allowing you to provide a temporary value for them.

  1. Click Finish, once you are satisfied with this query.

 

For details on adding and creating queries, see Adding user queries.
