Adding queries

After connecting your database to an OLE DB datasource, queries can be added to provide common tasks for managing your database.

For a practical example of using Select queries one of which uses parameters, which are supplied by controls on a graphic form, see How to chart and/or report data from a database.

To add a query to an OLE DB datasource:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Datasources category.
  2. If necessary, expand the required OLE DB datasource name or its icon .
  3. Right-click Queries or its icon and select one of the following options:

Tip: Alternatively, simply double click the required subfolder.

  1. Add Select Query: To select a sub-set of your data, to tailor your data to suit a specific use or requirement. For a detailed description on how to add, configure and perform this query, see Select queries.

Tip: Use a DataBinder instead if you want users to modify this data or have it dynamically updated. For details, see About DataBinders.

  1. Add Insert Query: To insert records into a specific table, by specifying the values of selected fields. For a detailed description on how to add, configure and perform this query, see Insert queries.
  2. Add Update Query: To update the values of specific fields within one or more tables of a database. For a detailed description on how to add, configure and perform this query, see Update Queries.
  3. Add Delete Query: To delete records from a table of the database, when fields meet specific criteria. For a detailed description on how to add, configure and perform this query, see Delete Queries.
  4. Add Execute Statement: To run predefined stored procedures or user-functions of the database. For a detailed description on how to add, configure and perform this query, see Execute Statements.
  5. Add Create Table Query: To create a table in the database, if necessary specifying primary keys and lookup columns (foreign keys) for fields. For a detailed description on how to add, configure and perform this query, see Create Table queries.
  6. Add Drop Table Query: To delete a table from the database. For a detailed description on how to add, configure and perform this query, see Drop Table queries.
