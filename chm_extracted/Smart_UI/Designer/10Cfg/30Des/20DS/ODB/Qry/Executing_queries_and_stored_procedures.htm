Executing queries and stored procedures

OLE DB datasource queries are performed using the Query spider.

To execute a query using a Query spider:

  1. If necessary, add the required OLE DB datasource and create the required query.
  2. If necessary, add a project and a graphic form.
  3. Ensure that the required graphic form is opened and displayed in the Design workspace.
  4. If necessary, add the necessary controls to trigger and/or display the results of this query to the required graphic form.
  5. Open the Spider Configuration tool window.
  6. Right-click the spider workspace itself and select the Create New Spider menu.
  7. Click the Databasing sub-menu and its Query item to add a Query spider.
  8. Double click the Query spider to open its configuration view.
  9. In the Inputs section:
  1. Open the Servers list box, to display the list of the names of all the connected Servers that are available.
  2. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Server, which contains the OLE DB datasource that this query has been created for.

Tip: Use the Default Server selection, where possible, when referring to datasources on the login Server to simplify the importing of this spider. Otherwise this Server input will need to be reconnected after this spider has been imported. 

  1. Open the OLEDB Data Source list box and select the name of the required OLE DB datasource.
  1. Select the type of query (action) that you want to execute from the Query Type list box to display the list of available queries.
  1. Select the name of the required query from the Query Name list.
  2. If this query contains parameters, these will be added as additional inputs to the Inputs section.

Note: The value of these parameter inputs can either be supplied by another spider or Data spider (e.g. property or data element) via a silk or can be typed in manually. For details, see Creating silks.

Note: If using SQL, please ensure that all the date parameters for this query adhere to the universal date time standard for SQL, which is yyyy-mm-dd.

Tip: When typing in a value manually, double-click the value column to the right of the parameter name in the Inputs section and type in the required value.

This spider will perform this query, whenever it is triggered.

  1. If necessary, connect this query to the properties of the required controls on the graphic form to trigger this spider to perform this query and/or to display its results.
  1. If necessary, click the Preview button to display the results of this query in the DataGrid.
  2. Save the graphic form by pressing its Save toolbar button to save these changes.

 

For details of the various types of queries that are provided, see About queries.

For details of parameterizing queries, see Working with parameters.

For details on triggering spiders, see Triggering spiders.
