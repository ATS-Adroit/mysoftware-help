About databases

SmartUI has improved its support for databases in this version with the new DataBinder functionality that can both view and/or modify the data within a database. Also queries now provide common tasks for managing your database, each with its own structured configuration dialog. Due to these improvements you can now use SmartUI as the generic front-end for all your databases to manage, view and configure their data.

SmartUI connects to all the commonly used databases such as Access, Oracle or SQL Server, to name a few. In other words, SmartUI can expose the data (tables and fields) within any OLE DBThe open standard for accessing data from a variety of sources. Once your database is connected to an OLE DB datasource, create a DataBinder to allow your users to view and/or modify your data. DataBinders allow you to create sub-sets or views of your data to select only the data that meets each specific need. 

Unlike Select queries that return static snapshots of the selected data, however, DataBinders remain in constant communication with the database, so that this data can be dynamically modified.

To display and/or modify the data within a DataBinder, create a graphic form and add a VIZNETDataBinder component. This launches a configuration dialog to select which tables and their fields to display and then automatically generates and adds the necessary controls and components to this graphic form to view and/or modify the records within each table.

You can also create Queries to manage your database. Queries are divided into the following categories or tasks, each providing its own configuration dialog to assist in the creation of this task: Select, Insert, Update, Delete, Execute Statement, Create Table and Drop Table.

You can either use a structured configuration dialog or, if you are familiar with the SQL querying language, simply create your own custom query.

Once you create a query, use the Query spider to execute this query, which unlike the Special Function spider, only lists the available OLE DB datasources, classifies the queries into their categories and can confirm the action of a query before it is performed.
