Adding OLE DB datasources

Add an OLE DB datasource to expose the data contained within an OLE DB compliant database or data store. Click for more information:

Note1: This can only be performed if the currently logged on user has the necessary security permissions. For details, see Securing datasources.

Note2: The required OLE DB data or service provider must be installed on both the SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. and Server computer, as BOTH computers need to access the required data store.

Note3: It is necessary to know all the information necessary to connect the required OLE DB data provider.

Note4: Once an OLE DB datasource has been added, each table is monitored by the SmartUI Server, at a configurable rate for new or updated data. For details, see Specifying OLE DB table polling interval.

Tip: When editing an OLEDB datasource connection, the Data Link Properties dialog uses the previously supplied details, so you only need to specify the changed details NOT all of them.

To add and configure an OLE DB datasource

Click for generic instructions on how to add and name a datasource:

  1. Open the Enterprise Manager.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  1. Right-click on the name of the required SmartUI Server or its icon and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Add Datasource.

The Add Datasource configuration dialog is launched displaying each datasource plugina generic type of data supplier that interfaces between the Server and this specific type of data, so that it is exposed to the Server in the format of data elements. See data element. that you can connect to.

Note: Only the datasource plugins, which have been licensed, appear in this list.

  1. Click the datasource you require and then click the Finish button.

Tip: You can also simply double-click the required datasource.

The Add A New Datasource configuration dialog is displayed to configure this datasource:

  1. Type an appropriate name for this datasource into the Name edit box.

When naming this datasource, please be aware of the following:

WARNING! Once a datasource has been named, it is NOT possible to rename it later.

Note1: The following non-standard text characters are NOT supported for datasource names: \ / : * ? < > | # "

Note2: Datasource names are case sensitive.

Note3: The specified name cannot be the same as any other datasource that has been already been connected to this Server.

Tip: Although the datasource name can be up to 50 characters long - use a descriptive name that is as concise as possible. This will ensure that users will BOTH easily identify and navigate to it within the Enterprise Manager.

To configure the OLE DB datasource

  1. Connect to the required OLE DB data, by clicking the browse button to the right of the Connection String edit box.

This will display the Connection Properties dialog.

Typically do NOT change the Data source from the default of .NET Framework Data Provider for OLE DB, unless you are connecting to a SQL Compact database. More details: in which case, click the Change... button and choose the datasource that corresponds to the correct version of SQL Compact and then the dialog will change so that you only need to browse in the required database file and specify the required password, if any.

  1. Use the OLE DB Provider list box to select the appropriate OLE DB provider for the type of data you want to access, from the list.

Note: This list contains all the OLE DB data or service providers currently installed on this Client computer, however, it is important to ensure that selected OLE DB data provider is ALSO installed on the required Server computer too.

  1. Either type in the necessary details to connect to the required data store or click the Data Links... button and use the Connection tab for the selected OLE DB provider to provide the necessary details to connect to the required data store. For more details, click the Help button to view the provided help. Click OK when finished.

WARNING! Please ensure that the required security credentials (authentication) are always supplied when connecting to a remote computer, even if connection is correctly tested without specifying them.

Since once the Server has successfully connected to a computer, any further connections made to this computer will work whether the correct authentication is supplied or not.

Note: If the required data store is password-protected, ensure that the Allow Saving Password checkbox is checked.

Tip: You can navigate directly to the Connection tab by double-clicking the desired provider.

  1. Click the Test Server Connection button to ensure that the Server is able to successfully connect to this OLE DB data store.

If the connection was not tested successfully:

  1. Ensure that the connection to this data store has been correctly configured, by clicking the browse button to the right of the Connection String edit box and ensure that the connection details are correctly specified. 
  2. Ensure that the SmartUI Server computer is also able to access this specified data store, since the connection is initially made relative to the Client computer.
  1. Click Finish once the connection has been successfully tested and the datasource has been named.

This will add this specified OLE DB datasource to the Datasources category in the Enterprise Manager, which can be identified by its specified name or icon .

To display the connection details of an OLEDB datasource:

Right click the OLEDB datasource in the Enterprise Manager and select the Connection Details option.

Note: If the connection string for this OLEDB datasource contains a password, it is hidden in *'s for security reasons.
