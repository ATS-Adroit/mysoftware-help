Accessing data within DataBinders

After adding a DataBinder to a database (OLE DB datasource), you need to add a VIZNETDataBinder component to a graphic form and link it to this DataBinder using the provided configuration dialog.

This configuration dialog can automatically generate controls on this graphic form to access to your data, so that your users can view, navigate and/or modify it. The most notable of these controls is the VIZNETBindingNavigator control, which allows your users to utilise your data. Alternatively, create your own controls for this purpose. Click for more information:

Note1: The VIZNETDataBinder component does not provide direct access to this data, instead records are retrieved from the database in pages or set quantities. For more details, see VIZNETDataBinder components.

Note2: The VIZNETDataBinder component provides data-specific properties that affect whether changes to your data are updated and how the records are retrieved.

If your DataBinder contains parameters:

  • add controls to this graphic form so that your users can specify these values
  • then configure the VIZNETDataBinder component to link each parameter to the required control. For details, see Linking DataBinder parameters to controls.

How to chart databinder data: this describes how to chart the data within a DataBinder.

To access data within a DataBinder:

  1. Open a graphic form. (If necessary, create a project and add a graphic form to it first.)
  2. In the Toolbox window open the Data category and select the VIZNETDataBinder component.
  3. Click on the graphic form to add this component, which launches the DataBinder configuration dialog.
  4. Select the OLE DB datasource name that represents your required database from the Select DataSource list.
  5. If necessary, select the name of the required DataBinder from the Select DataBinder list.
  6. Select which of this DataBinder's tables to display on this graphic form, from the left Select the Tables to View list.

Note: Only the tables that are checked will be displayed.

The Create Controls option is selected, by default. This automatically generates controls on this graphic form that allow users to display and navigate and/or modify the records within the selected tables.

Note: Only clear this option if you are an advanced user and want to create your own controls and link them manually to the DataBinder. For more details, see VIZNETDataBinder components.

  1. If using Create Controls:

You can adjust the display order of a table by selecting the required table name and clicking the or buttons to promote or demote its displayed order accordingly. Tables appear from top to bottom, in the specified order.

For each selected table:

Note: Only the checked items are displayed.

  1. If necessary, select which of its available fields should appear individually on the graphic form, in the Required Field Controls tab of the right list:

    In this case each selected field will have an associated label, indicating the name of this field and an appropriate control containing the value of this field for the currently displayed record.

    This control, which is typically a TextBox, can both display and/or modify this value.

    Tip: Adjust the display order of a field by selecting the required field name and clicking the or buttons to promote or demote its displayed order accordingly. Fields appear from top to bottom, in the specified order. Fields may appear in two or more columns, depending on the size of the control used to represent their table.

This is recommended when information on a specific item is required, such as information about a particular user or asset.

  • If necessary, select which of its available fields should appear in a DataGridView control, in the Required DataGrid Columns tab of the right list:

    Tip: Adjust the display order of a field in the DataGridView control by selecting the required field name and clicking the or buttons to promote or demote its displayed order accordingly. Fields appear in the specified order, from left to right.

This is recommended when you want to view large amounts of data in a spreadsheet-like view.

  • If a relationship exists between two selected tables, then use the DataGrid Lookup Columns tab of the right list to specify the column (known as the Lookup column) which describes the ID column of the other table. So that the descriptive entries will be displayed and used instead of the IDs.
  1. Select Finish, once you are happy with your configuration.

The relevant components and/or controls are added to this graphic form and the tasks pane is displayed. For details of these tasks, see VIZNETDataBinder components task menu.
