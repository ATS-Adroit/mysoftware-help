Alarm Shelving via the Manage Configured Alarms graphic form

This graphic form allows you to inhibit (shelvealarm shelving is the process of removing an alarm from the entire alarm system for a specific time period. This also known as inhibiting an alarm.) or uninhibit every configured alarm in an Agent Server, regardless of its alarm list or whether it is active or not.

For instance, if you have planned maintenance for a specific plant section, then you can use this graphic form to select all the alarms in this section and inhibit them until the scheduled maintenance is over.

This graphic form is part of the default System Information project.

To assist you in the process of shelving (inhibiting) alarms, this graphic form provides the following functionality:

  1. Display the list of alarms to inhibit (shelve) or uninhibit:
  • Typically filter or limit the list of configured alarm to only those that contain the specified Filter by text (this searching is case insensitive and you need to click the Filter button to begin the search). For instance this could specify the required plant area code or equipment code to display the required tags.
  • However, you can also Show All the configured alarms too, at any time to remove the specified filter.

Both of these actions work upon the current list of configured alarms, if you want to include all the latest configured alarms in the associated Agent Server then click the Refresh button to update this list.

If necessary, you can export all the located inhibited (shelved) alarms to a .CSV file for subsequent reporting or analysis, by clicking the Export inhibited alarms to CSV button and then specifying the location and name of this file, which uses the following default naming convention: Alarms (Inhibited=#).csv, where # are the number of inhibited alarms.

This graphic form also indicates both the number of alarms that are currently Uninhibited and Inhibited (shelved) in this list.

This list simply displays the Alarm (the tag name and its alarm type), its Alarm Agent (the alarm list in this alarm is configured to be displayed) and the Inhibited Until columns.

When an alarm is inhibited then the Inhibited Until column of this list displays the date/time at which this alarm inhibition (shelving) is specified to end, unless the alarm was configured to be inhibited forever, in which case it simply displays FOREVER.

Tip: You can sort this list by clicking on the required column header, so by clicking the Inhibited Until column will display all the inhibited alarms at the top of the list.

  1. Select the alarms to inhibit (shelve) or uninhibit:

Once you have displayed the list of alarms to inhibit (shelve) or uninhibit, typically via filtering, then either Select All the displayed alarms or manually check the checkboxes of the required ones.

To inhibit the selected alarms:

  1. Specify the required Inhibit until date and time, as follows:

  • as a specific Date and time, this is the default option which automatically inhibits the selected alarms until the next day (24 hours from the current time), although you can specify any time period, as long as it is not in the past,

    otherwise you can inhibit the selected alarms for:

  • the next 12 hours Now plus 12 hrs, for the next 4 hours Now plus 4 hrs, for the next hour Now plus 1 hr, or Forever, which effectively deactivates the selected alarms.
  1. Specify the required Reason for shelving (inhibiting) these alarms.

The Operator (the currently logged in user) is also automatically added to this alarm inhibiting event.

  1. Click the Inhibit button.

IMPORTANT: If one or more alarms are selected that have been previously inhibited this will NOT change their previous inhibited configuration but only configure the selected uninhibited alarms.

To uninhibit the selected alarms:

The Operator (the currently logged in user) is also automatically added to this alarm uninhibiting event.

  1. Click the Uninhibit button.

IMPORTANT: If one or more alarms are selected that have been previously uninhibited this will NOT change their previous uninhibited configuration but only configure the selected inhibited alarms.
