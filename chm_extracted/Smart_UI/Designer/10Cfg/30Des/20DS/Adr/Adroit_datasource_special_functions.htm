Special functions of Adroit datasources

The following is the list of special functions provided by the Adroit datasouce, in alphabetical order, that can be used to configure the Adroit datasource itself or its connected Agent Server:

Note1: This topic is ONLY intended for advanced users only who already have advanced knowledge of Adroit and as such ONLY the parameters and/or returned data of these special functions have been described.

Note2: Access to these special functions can be controlled. For details, see Working with special function security.

Special Function Name Parameter
Name Data type Data type description
AcknowledgeAlarms alarmsToAcknowledge [AlarmAgentName, AlarmToAck]

A two dimensional String array, where:

  • the first dimension represents the name of the Alarm agent and
  • the second is the name of the alarm to acknowledge.
AddAlarmRoute alarmAgent String Name of the Alarm agent to contain this route.
alarmLists String Comma separated list of AlarmList agents for this route.
audioDevices String Comma separated list of audio agents for this route e.g. Beeper or Multimedia
outputs String Comma separated list of output agents for this route e.g. AlarmManagement, Notify, EventOutput
eventLogs String Comma separated list of EventLot destinations for this route e.g. LOCAL or the required remote computer name
AddToGroup group String Name of the agent group
agents String Comma separated list of agents to be added to this agent group
AlarmTag tagName String Name of tagA fully qualified named value in Adroit (agentName.slotName). to alarm
alarmAgent String Name of Alarm agent to manage this alarm
alarmType Integer Name of the alarm type of this agent i.e. the alarming condition
alarmRoute Boolean The alarm route number to annunciate this alarm
alarmAck String Whether acknowledgement of this alarm is required or not
ChangeAlarmRoute alarmAgent String Name of the Alarm agent that contains this alarm route.
route Integer Alarm route to modify
alarmLists String Comma separated list of AlarmList agents for this route.
audioDevices String Comma separated list of audio agents for this route e.g. Beeper or Multimedia
outputs String Comma separated list of output agents for this route e.g. AlarmManagement, Notify, EventOutput
eventLogs String Comma separated list of EventLot destinations for this route e.g. LOCAL or the required remote computer name
CreateTag tagName String Name of tagA fully qualified named value in Adroit (agentName.slotName). to create
agentType String Type of agent to create e.g. Analog, Digital, Counter
tagDescription String An optional description that describes the intended purpose of this tag.
DeleteTag tagName String Name of tagA fully qualified named value in Adroit (agentName.slotName). to delete
EditDatasource connectionString String The connection string of the Agent Server, which is typically “ComputerName.AgentServerName”
GetCurrentServerConnection NONE   Returns a String containing the current Agent Server connection string, which is either “ComputerName.AgentServerName” or “” if this connects to the local Agent Server
GetServerList NONE   Returns a String array of the Agent Servers that are currently enumerated by way of broadcasts
LogTag tagName String Name of agent (tag) to log
slotName String Name of slot (variable) to log
logPeriod Integer The logging period, in days
logSet Integer The zero-based log set index (the index of the first log set being 0)
logRate Integer Logging rate, in seconds
logCompression Integer Logging compression method: 0 – Actual; 1 – Average; 2 – Maximum; 3 – Minimum
logFile String

For the Adroit proprietary logging: the path and file name of the .LGD log file.

For SQL (OLE DB) logging, the SQL connection string.
RemoveFromGroup group String The name of agent group from which to remove agents
  agents String Comma separated list of agents to remove from this agent group
Save NONE   Saves the currently opened Adroit agent database (WGP file) of this Agent Server.
ScanTag tagName String Name of agent (tag) to scan
slot String Name of slot (variable) to scan
device String Name of the Device agent to manage the scanning
scanAddress String The required IO address of the front-end device e.g. PLC
scanRate Integer If this is a polled protocol driver, then specify the required poll rate of this scanned point
scanDeadband Integer The value deadband of this scanned point, above which the value is scanned.
scanOutputEnable Boolean Whether this scanned point should be output enabled or not
ValidateOEMBitMask mask Integer An Integer bit mask to be validated against the OEM bitmask in the Licence agent of the Agent Server. This returns a True / False validation
