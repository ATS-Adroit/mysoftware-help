Adroit datasources

Adroit is a SCADA product that is used to supervise and control processes. The Agent Server is the storage facility for all the real time and historical data. Click for more details:

This data is stored and managed by intelligent objects, known as agents, of which there are different types. Each agent contains externally accessible data attributes, or slots, which in addition to being displayed can, if necessary, be used to interact with and configure their agent too.

Tip: See Moving from the Classic Adroit UI for Classic UI feature equivalents in SmartUI.

An Adroit datasource exposes the configured agents and their slots of either a standalone Adroit Agent Server on a specific computer or to an Adroit Cluster (a set of two replicated Agent Servers).

Note: When displaying Adroit tags you can display bad-tag status indicators on relevant controls and/or vectors. For details, see Bad tag status indicators.

This datasource is added within the Datasources category of the required SmartUI Server in the Enterprise Manager. For details, see Adding Adroit datasources.

Click for advanced Adroit datasource usage information:

When connecting to an Adroit Cluster, the Adroit datasource seamlessly switches between the two Agent Servers in the cluster, when one becomes unavailable.

However, the automatic tracking of the active master Agent Server within the cluster is NOT supported. The Adroit datasource connects to the primary Agent Server (first specified Agent Server) and connects to the secondary (Partner Server) when the primary fails. Therefore the Adroit datasource does not connect to the master Agent Server, if the Agent Server it is currently connected to becomes the standby.

The Adroit datasource can be updated, locked or removed, if necessary. For details, see Updating datasources, Locking datasources or Removing datasources.

Note1: You can also configure the Agent Server. For details, see Configuring the Agent Server.

Note2: It is possible to use the Adroit Agent Server licence to license the SmartUI Server. For details, see Alternative Adroit licensing method.

Note3: When adding an Adroit datasource, one remote connection will be used, from the Adroit license of the connected Agent Server.

Note4: When data is fetched from this Adroit datasource, scan point licenses will be used, from the Adroit license of the connected Agent Server.

Note5: If necessary, the access to this Adroit datasource, its agents and their slots can be controlled. For details, see Securing datasources.

An added Adroit datasource is identified in the Enterprise Manager by its specified name and its icon .

Note: If the following icon is displayed: , then there is a problem connecting to the specified Agent Server. For details, see Troubleshooting Adroit datasources.

When this datasource is opened, the agents and their slots contained within the specified Agent Server are displayed, in the following hierarchy:

Note: If necessary, the common Header slots of each agent, including the GROUP agents can also be displayed. For details, see Including header slots.

  1. The AgentGroup is displayed immediately below the Adroit datasource, which contains all the agents that have been configured on this Agent Server and their slots.
  2. The agent types are listed alphabetically beneath the AgentGroup. This specifies all the possible categories of agent that can be configured by this Agent Server. Click for more details:

Note1: Only the agent types with a plus box to their left actually contain configured agents.

Note2: The common Header slots, if included, of the GROUP agents are listed in the *Group Slots list beneath each agent type, that has configured agents. For details, see Including header slots.

  1. The configured agents are listed alphabetically beneath their applicable agent type.
  2. The specific data or slots of each configured agent are listed alphabetically beneath their applicable agent.

Note: The default display of floating point numbers in Adroit is determined by the Regional Settings of the computer the Operator (or Designer) is running on. This allows the default number of displayed decimal places to be customised etc.
