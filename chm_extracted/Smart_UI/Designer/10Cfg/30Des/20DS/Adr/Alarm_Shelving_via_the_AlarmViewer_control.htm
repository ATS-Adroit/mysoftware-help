Alarm Shelving via the AlarmViewer control

The AlarmViewer control allows you to inhibit (shelvealarm shelving is the process of removing an alarm from the entire alarm system for a specific time period. This also known as inhibiting an alarm.) or uninhibit any active alarm in an alarm list (of a specific Alarm or AlarmList agent).

Tip: The Manage Configured Alarms graphic form allows you to inhibit (shelve) or uninhibit every configured alarm in an Agent Server, regardless of its alarm list or whether it is active or not. For details, see Alarm Shelving via the Manage Configured Alarms graphic form .

To inhibit (shelve) alarms:

  1. Select the alarms that you want to inhibit (shelve) in the list.
  2. Click the More options link (in the bottom right corner) and its Inhibit selected alarms option.

IMPORTANT: This option is only enabled when one or more alarms are selected.

In the Inhibit alarms with reason dialog:

Tip: The list of the currently selected alarms are provided to check if the required alarms are selected.

  1. Specify the required Inhibit until date and time, as follows:

  • as a specific Date and time, this is the default option which is set to inhibit the selected alarms until the next day (24 hours from the current time), although you can specify any time period as long as it is not in the past,

  • otherwise you can inhibit the selected alarms Forever, which effectively deactivates the selected alarms.
  1. Specify the required Reason for shelving (inhibiting) these alarms.

The Operator (the currently logged in user) is also automatically added to this alarm inhibiting event.

  1. Click the Inhibit button.

Note: Once you inhibit an alarm it is both acknowledged and cleared so it is removed from the alarm list.

To uninhibit alarms:

  1. Click the More options link (in the bottom right corner) and its View inhibited alarms option.

In the View inhibited alarms dialog:

  1. Select which of the alarms that have already been inhibited in this alarm list that you want to uninhibit, either using the Select All button or manually select the required ones.

By default this list is sorted by the Inhibit until column in descending order, so that the alarms that are configured to be inhibited for the longest time are displayed at the top of the list.

The Operator (the currently logged in user) is also automatically added to this alarm uninhibiting event.

  1. Click the Uninhibit button.

Note: After uninhibiting an alarm that was active, it is put back into an active state so that it reappears in the alarm list.

In addition to providing the options required to inhibit (shelve) and uninhibit alarms the More options link (in the bottom right corner of the AlarmViewer control) also provides the ability to globally acknowledge ALL the alarms displayed in the alarm list.

Typically the AlarmViewer control displays the Global Acknowledge, in which case the Global Acknowledge Alloption is provided. However, if the Local Acknowledge button is displayed then this option becomes Local Acknowledge All.
