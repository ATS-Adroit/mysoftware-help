Object Model Template Export Import Utility

The Object Model Template Export and Import utility lets you export or import one or more of your existing Object Model Templates to and from a proprietary .TEF (Template Export File) file.

You typically open the Object Model Template Export and Import utility via the Adroit Utilities on the Desktop and then select this utility from this menu.

Export one or more of your existing Object Model Templates

This utility lets you move your Object Model Templates or Configuration from one computer to another and also for backup purposes.

Note:  Since these templates are obtained directly from your hard drive, you do NOT need the SmartUI Server to be running.

  1. Select the Export tab to open the template browser and detail panes.

  2. Click the Get Template button, which lists both user and system templates directly from your hard drive, so you do not require the SmartUI Server to be running.
  • Note:  This only lists the Object Model Templates of the currently Active Configuration, which you can check via the Configuration page of your SmartUI Config Editor.
  • The left-panel displays the Templates tree. Select the Templates folder checkbox to list all available templates and their folder structure in the System and User folders .
  • Note:  The folders that contain templates with configuration issues and problematic templates will display an error icon to assist you in locating these problematic templates.
  • The Export Details panel displays on the displays the Number of templates that have been selected for export:
    • If you select a template entry, then the Templates Details section appears in the right-panel, which displays a summary of its configuration and displays any detected errors.
    • If one of the selected templates has a configuration issue, then the Number of templates label displays an error icon , and the number of Good (error-free) and Bad (errors) templates that are selected for export.
    • Note:  In this case, you will be unable to provide a description and export any templates until the problematic templates are cleared. You should close this utility and fix the issues before attempting to export them.
    • If all the selected templates are configured correctly, then the Number of templates label displays a good icon . You may then enter a Description for these exported templates. The description is displayed when a user attempts to import the templates.
    • Note:  This Description is not displayed in the name of the exported .TEF (Template Export File) file.
  1. Click the Export button when all the problematic templates are cleared.
  • Note:  If you click the Export button with problematic templates are still selected, a message box is displayed detailing the errors. The export process is then forbidden.
  1. When the export process is successful, this automatically creates the following unique file name: “TEF [# templates] date time.tef”, where # is the number of templates being exported, and data and time specify the date and time of the export.
  2. By default, this file will be saved in the same folder that the Object Model Template Export and Import utility is opened. You can, however, select any folder that you want.
Import Object Model Templates from a .TEF (Template Export File) file

Important:  You must shut down your SmartUI Server before you can import templates.

Note:  These templates are imported into a unique folder, which also specifies the date and time of the import, so they will not overwrite existing templates.

  1. Select the Import tab.
  2. Click the Browse for export file button and browse for and select the required .TEF file then click Open.
  • In the left-panel, the Template list contains the names of the templates within the selected export file.
  • Tip:  You can view the source path of an exported template by hovering over its name in the list.
  • Note:  If you hover over the Template name then you can preview the Primary wizard.
  • If you select an exported template, then the Templates Details section appears in the right-panel and displays a summary of its configuration and displays any detected warnings or errors.
  • You should analyse the templates contained in the file to determine that you are importing the required wizards.
  • In the right-panel, the Import details section displays:
    • the Number of templates contained in this export file and lists the import status of them, as follows:
      • Good: all is OK with importing these templates. For example, no configured elements already exists.
      • Warning: a non-critical issue was found when importing these templates. For example, a configured element already exists, such as the primary wizard.
      • Note:  In the case of an existing configured element, this element will not be replaced!
      • Bad: when one or more of these templates cannot be correctly referenced in the export file. For example, typically due to file corruption, then these templates cannot be imported at all.
    • the Description which provides a detailed description of these exported templates, so that you can determine if you have selected the correct templates to import.
    • when an incompatible SmartUI Server version is detected, which prevents these templates being imported, the Source and Destination Server section is then displayed to show the server details and versions. Normally, you may click the Show more button to view this information.
  1. Click the Import button and click Yes to confirm the import.
  • Note:  These templates will be imported into your Active Configuration, which you can check via the Configuration page of your SmartUI Config Editor.
  • Note:  These templates will be imported into a unique folder, which also specifies the date and time of the import, so they do not overwrite any existing templates that have the same name.
  • At the end of this process, the Import results are displayed, listing all the events related to this import.
  • Note:  You should not see any errors in these results. However, if you do, you can attempt to fix them. Depending upon their severity, you should delete this import folder and attempt to reimport the templates.
  1. Click the Open the Templates folder in Windows Explorer button in the top right corner of the utility to view the folder of these newly imported templates, which uses this name format:  
    • “IMPORT_# templates_date_time.tef”, where # is the number of templates that are exported, and data and time specify the date and time of the import.
