Previewing graphic forms and wizards

When you have created a large number of graphic forms or wizards for a project, the SmartUI Designer provides a previewing facility that displays thumbnail snapshots of all the graphic forms and/or wizards located in the immediate or root level of the selected project or its selected folder, so that you can choose the required graphic form or wizard.

Tip: This also allows you to drag a preview image directly onto a graphic form or into the Favorites tool window to create a library of favorite graphic forms (and wizards) that you frequently use - so that you can directly drag them onto graphic forms without having to browse to them first in their relevant projects. For details, see Favorites tool window.

To preview graphic forms / wizards:

In the Enterprise Manager window:

  1. Select the required project or folder .
  2. Right click and select Preview graphic forms.

This displays a scrollable dialog containing preview images of all the graphic forms and wizards in the immediate or root level of this project or selected folder i.e. this does not display graphic forms and wizards in any sub-folders.

Note: This preview image is saved with the graphic form, when it is opened and then saved in the SmartUI Designer.

  1. You can double click a preview image to open the associated graphic form.
  2. You can drag a preview image into the Favorites tool window to create a library of favorite graphic forms and wizards that you frequently use when designing others.

  3. You can drag a preview image directly onto a graphic form:

    If this image represents a graphic form, this displays the menu of the available graphic form insertion options.

    If this image represents a wizard, this displays its substitution dialog.

To preview a graphic form / wizard:

In the Enterprise Manager window:

  1. Select the required graphic form or wizard .
  2. Right click and select Preview graphic form.
