Associating aliases to properties

After adding aliases to a graphic form, you need to assign them to the required properties of this graphic form and/or its added form components, that you want to expose. So that they can be configured for instance, when you add this graphic form to another via a TemplateGO or TemplateGONavToolbar control.

To associate an alias to a property:

  1. Ensure that the required graphic form is opened and displayed in the Design workspace.
  2. In the Design workspace, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the graphic form itself.
  3. Open the Spider Configuration tool window.
  4. If necessary, display the property tree which is located on the right border of the central spider workspace pane.

In the property tree:

  1. If necessary, expand the Objects.
  2. If necessary, use the scroll bar to browse down this property tree until the object with the name of Form is displayed.
  3. If necessary, expand the VIZNET Extended category beneath this Form object to display the Aliases property.
  4. Drag any property onto the Aliases property beneath the Form object to display the configuration view of this specialised Aliases property spider in the spider workspace. Click for more information:

    Note: If only one alias has been added this will immediately add this property to its input, in which case open it using the tip immediately below. 

    Tip: If an alias has already been connected to a property then double-click the blue line to the right of the Aliases property to display the configuration view of this property spider instead.

    The configuration view of the Aliases property spider is displayed.

    Note1: Although the Inputs and Outputs sections both contain the names of all the defined aliases, this procedure is concerned with associating the output alias names to the required properties of the other form components.

    Note2: ANY link made to the aliases listed in the Inputs section of this spider will be ignored. 

  1. Navigate up or down the property tree until the name of the first form component is displayed, that contains one or more properties to be assigned an alias.

Tip: Instead of connecting the aliases to the required properties of the graphic form and/or form components, you can connect them to a Mapping spider instead to make it easier to re-use this graphic form.

  1. If necessary, expose the first property that will be assigned to an alias, by expanding the necessary nodes.
  2. Drag the appropriate alias from the Outputs section of the Aliases property spider onto this exposed property to connect them with a silk (line). For details, see Creating silks.

Tip: It is also possible to navigate and expose the required properties while dragging the required output. Simply position the mouse pointer over the required node and it will expand and move the mouse pointer to the bottom or top of the property pane and it will scroll up or down accordingly.

  1. Repeat steps 9 to 11 until all the required aliases have been associating with the required properties.

Note1: Only associate the required aliase/s with properties.

Note2: It is also possible to associate the SAME alias to more than one properties, in which case all these properties will be assigned the same value.

For details on assigning values to these aliases, once this graphic form is displayed within a TemplateGO control, see Assigning values to aliases.
