Working with aliases

When you use graphic forms within other graphic forms to speed up their construction via TemplateGO controls, aliases allow you to expose specific properties of each graphic form (and/or their form components) that you add.

Aliases therefore allow you to configure these properties and hence customise each SmartUI Template like any other form component that you add to a graphic form. Click for more details:

Aliases expose selected properties of the graphic form and/or its form components to the TemplateGO control, so that these can be independently configured when graphic form is displayed within a TemplateGO control, as follows:

  1. A graphic form can associate any of its properties (or its added form component properties) to aliases (text strings).
  2. When this graphic form is displayed within a TemplateGO control, you can assign values to these exposed aliases.

For this reason, multiple instances of the same graphic form each hosted in separate TemplateGO controls can be separately configured, just like any other form component.

For more information and detailed procedures for this and other methods of re-using graphical components to speed up the process of creating graphic forms, see How to reuse graphical components.

A graphic forms that has one or more configured aliases is known as a SmartUI TemplateA graphic form that has one or more configured aliases and is therefore designed to be displayed within a TemplateGO control..

Tip: Aliases can also be automatically created. For details, see Automatically creating aliases.

How to configure aliases:

  1. Add one or more aliases to a graphic form. For details, see Adding aliases.
  2. Associate a property of this graphic form or any of its added form components to each alias. For details, see Associating aliases to properties. Click for more information:

Tip: Use the Mapping spider to simplify the process of assigning properties to aliases. For details, see Mapping spiders.

Note1: It is not necessary for all the added aliases to be associated to properties.

Note2: If more than one property is associated with the same alias then all these properties will be set to the SAME value that is assigned to this alias.

Once this graphic form is selected by a TemplateGO control, these configured aliases are exposed so that data elements can be assigned to them.

Note: It is not necessary for all the configured aliases to be assigned values.

For details on adding and using TemplateGO controls, see TemplateGO controls.

  1. Add this graphic form to another graphic form via a TemplateGO control. For details, see Connecting TemplateGO controls to graphic forms.
  2. Assign values to one or all of the aliases that are exposed by this TemplateGO control. For details, see Assigning values to aliases.
