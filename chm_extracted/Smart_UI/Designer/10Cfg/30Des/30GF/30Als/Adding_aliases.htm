Adding aliases

Aliases are added to graphic forms to expose specific properties of the graphic form (and/or their form components) so they can be configured when this graphic form is opened at runtime.

Note: After adding aliases to a graphic form, you need to assign them to the required properties of this graphic form and/or its added form components, that you want to expose. For details, see Associating aliases to properties.

To add an alias to a graphic form:

  1. Ensure that the required graphic form is opened and displayed in the Design workspace. For details, see Opening graphic forms.
  2. In the Design workspace, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the graphic form itself.
  3. Open the Properties tool window.
  4. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Aliases property, which is listed in the VIZNET Extended category.
  5. Click the browse button in the value column to the left of this property.

This will display the Aliases configuration dialog.

  1. Click the Add button.

This will add an alias to the Value column of the list of aliases, with the default value of New Alias #X, where X is a unique number.

  1. If necessary, enter the required name of this alias.

WARNING! It is not possible to rename an alias later.

Tip1: Any character can be used when specifying an alias.

Tip2: It is recommended that an alias be given a descriptive name, so make it easier to identify when assigning a value to it.

  1. Click the Finish button when all the required aliases have been added.

 

Note: You can also remove unnecessary aliases from a graphic form.

For details of removing aliases, see Removing aliases.
