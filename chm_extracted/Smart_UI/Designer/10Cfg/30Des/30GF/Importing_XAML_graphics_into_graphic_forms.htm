Importing XAML graphics into graphic forms

You are not restricted to using the SmartUI Designer to design and create the graphics that you want to use in your graphic forms, since the SmartUI allows you to import graphics that have been saved in the XAML document format.

The SmartUI has been optimised to import .XAML documents that are created when saving Microsoft Visio 2010 AND 2013 images as .HTML documents. Since in this case one of the documents created during this process is a .XAML document. Therefore the SmartUI is able to import any Microsoft Visio 2010 or 2013 stencil or image.

Most graphics saved and/or converted to a .XAML document can be imported, there is an 80-90% conversion rate. In particular XAML files containing multiple translated/rotated groups usually are not able to be imported.

Only a few graphics software packages directly export their images into this XAML document format, such as the open source InkScape or Microsoft Blend. However other graphics software packages, while not supporting the .XAML format do provide support for saving images in the .SVGScalable Vector Graphics (SVG) is an XML-based vector image format for two-dimensional graphics. SVG images and their Behaviours are defined in XML text files. This means that they can be searched, indexed, scripted, and compressed. As XML files, SVG images can be created and edited with any text editor, but are more often created with drawing software. document format. In fact these SVG images can be produced by any vector graphics editor, such as Adobe Illustrator, Adobe Flash Professional, CorelDRAW to name a few.

In this case you can download and use a command line utility called SVG2XAML from the Adroit website to convert your .SVG files into .XAML files and then import these created .XAML files into the required graphic forms.

IMPORTANT: When generating these .XAML files from other applications, please ensure that the source files are made as simple as possible, by stripping out unnecessary layers and detail, since complex .XAML files (even though they may be small in size) will increase the required importing time and graphic form size and may even crash the Designer, if it runs out of memory.

To import XAML graphics into a graphic form:

Note: This procedure assumes that you have already exported a graphical image into XAML using your preferred graphical program and that you know where this .XAML document is located.

  1. If necessary, create the required project in the Enterprise manager. For details, see Creating new projects.
  2. If necessary, add the graphic form that you want to insert the graphical image, as follows: right-click on the project name or its icon  and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking.  Create Graphic Form.
  3. Either: right click the graphic form and click the Import XAML Graphics option.
  4. Or: from the Designer ribbon, select the Import tab and click the Import XAML Graphics tool.

This displays the Import XAML Graphics dialog.

  1. Click the browse button to the right of the Browse in a XAML file to import field and select the required .XAML document.

The Base Url i.e. for images field specifies the folder in which any additional images referenced by this XAML document need to located so that they can be included on import.

  1. IGNORE the Advanced View button, as this ONLY contains information relevant when importing legacy Adroit mimics.

Tip: The Preview button, allows you to view the selected XAML document before it is imported.

  1. Click the Finish button.

This converts the XAML document into vector graphic elements on the current graphic form.
