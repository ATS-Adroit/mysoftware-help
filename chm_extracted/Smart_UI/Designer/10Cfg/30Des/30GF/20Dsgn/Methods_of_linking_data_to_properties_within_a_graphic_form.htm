Methods of linking data to properties within a graphic form

Graphic forms are animated during their design process, by attaching any data element to any property of the graphic form itself or its form components.  Click for more information:

Note1: Behaviours provide configuration dialogs that link data to properties. For details, see About Behaviours.

Note2: This visual animation or data binding can be used to configure more than just display properties (for example, the Text property of a TextBox control) if required, such as the sizes of controls, their colors and images.

Note3: It is also possible to link properties to data elements and properties to other properties too, if necessary.

Note4: If a property is connected to a data element that contains more than one value i.e. of type dataset, then the Filter Dataset configuration dialog is displayed, to select which of these value(s) are required. For details, see Filtering datasets.

Tip: Run a graphic form, in order to see what the end-user will see. For details, see Running graphic forms.

Although the process of animating a graphic form can become involved, there are typically only two methods of linking data to properties within a graphic form:

  1. Direct animation: in this case a data element is directly connected to a property, so that it displays the actual data element value(s). This can be achieved in one of following ways:

Note: Although more than one data element can be linked to the same property, most properties will ONLY display the most recently received data element.

  1. You can drag the required data element from the Enterprise Manager and drop it onto the required graphic elementa form component that typically provides drawing functionality for the graphic form. See form component. or controla visible form component used to display data or accept user input in the graphic form. See form component., within the graphic form in the Design workspace. Then select the required property and the necessary spiders and silks will be automatically created for you. For details, see Quickly linking data elements to properties.
  2. If you need to connect a data element to a property of a componenta hidden form component that provides additional functionality to this graphic form and some or all of its form components. See form component., then you need to use the Spider Configuration tool window, to drag the data element, from the explorer tree, on the right, to the required property, in the property tree, on the left. This will manually create the necessary spiders and silk. For details, see Creating silks or Spider Configuration tool window.

  1. Modified animation: in this case one or more data elements are connected to one or more added spiders, which are then connected to one or more properties, so that the properties display modified data element value(s).

    This can only be achieved within the Spider Configuration tool window and involves the following process:

  1. Add one or more spiders to the center spider workspace.
  2. If necessary, configuring one or more of these spiders as required.
  3. Creating silks to connect:
  • one or more data elements to one or more of the added spiders
  • the added spiders together
  • one or more of the added spiders to one or more properties

For details, see Creating silks.

Tip: Whenever a property requires the name of a data element, simply drag the required data element to this property and its name will be automatically extracted to specify this property at runtime.

Note1: If required, only the spiders directly associated with the currently selected form component(s) can be displayed. For details, see Hiding unselected spiders.

Note2: It is possible to change which Servers are used to obtain the required data elements, at any time. For details, see Changing data element referencing.

Note3: Whenever a data element or property is dragged to or from their tree, the appropriate Data spider is automatically added to the spider workspace. For details, see Data spiders.
