Quickly linking data elements to properties

The value of a data element can easily be assigned to a property. Click for more information:

Simply drag the required data element from the Enterprise Manager and drop it onto the required graphic form or graphic elementa form component that typically provides drawing functionality for the graphic form. See form component. or controla visible form component used to display data or accept user input in the graphic form. See form component., in the Design workspace.

Then select the required property and the necessary spiders and silks will be automatically created for you.

Note1: You are unable to link the properties of each componenta hidden form component that provides additional functionality to this graphic form and some or all of its form components. See form component. within a graphic form, in this manner.

Note2: Spiders and silks need to manually created, within the Spider Configuration tool window, in order to perform any other links. Such as the ability to modify or manipulate the values of one or more data elements or properties before they are linked. For details, see Methods of linking data to properties within a graphic form.

Note3: It is also possible to quickly link properties to data elements. For details, see Quickly linking properties to data elements.

To quickly link a data element to a property:

  1. In the Enterprise Manager, ensure that the data element within the required datasource is exposed and visible. For details, see Opening datasources.
  2. In the Design workspace, ensure that the required graphic form has been opened and, if necessary, that the required item is visible. For details, see Opening graphic forms or Design workspace.

Note: It is only possible to quickly link a data element to a property of a graphic form, graphic element or control, but not a component.

  1. Drag the required data element from the Enterprise Manager to the required item in the Design workspace.
  2. Select the To Control Property… submenu.

This lists all the controls at the mouse pointer's location, so that the LAST control that was added to the graphic form is at the TOP of the list and the graphic form (FORM) is at the BOTTOM of the list.

  1. Select the control whose property you want to connect to. Click for more information:

This lists the pre-defined properties of the specified control that you can connect to. By default, this list contains the more commonly used properties of the specified control. 

Note: The onus is upon the user to ensure that the data types of the selected data element and property are compatible.

  • If the property that you require is displayed in this menu, select it.
  • If the property that you require is not displayed in this menu, select the Customise… option.

This displays the Edit Common Properties configuration dialog, which alphabetically lists the properties specific to the selected item.

  1. If necessary, tick any property that you want to appear in the default properties menu for this item, in future.

Note: Any property that has no tick next to it, can only be accessed from within this configuration dialog itself.

Tip: Double-clicking on the name of a property will check or empty the checkbox. 

  1. Highlight the property, whose value is to be supplied by this data element.
  2. Ensure that the required property has been highlighted before clicking the Finish button.

Note1: ONLY the highlighted property, even if it is not currently ticked, will be used as the selected property.

Note2: Any changes made to the default properties menu for the selected item, will ONLY be stored in the profile assigned to the currently logged in user, if its Automatically update profile option is enabled. For details, see Customizing connections and work environment. This is stored in the User Profile Settings of your profile in the DefaultProperties variable.

This will usually create the necessary link immediately. However, if the selected property has more than one input, then the Select Item To Connect To… configuration dialog is displayed. In this case, ensure that the correct input of this property is highlighted before clicking the Finish button.

Note: If this property is connected to a data element that contains more than one value i.e. of type dataset, then the Filter Dataset configuration dialog is displayed, to select which of these value(s) are required. For details, see Filtering datasets.
