Graphic form design properties

Each graphic form provides the following properties to assist in its designing:

Tip: The graphic form size is typically the actual size that the end-user sees, unless you choose to dynamically resize a graphic form to cater for monitors with differing aspect ratios. For details, see Statically or dynamically resizing graphic forms.

Note: These properties are typically listed in the Design category of the graphic form properties. For details on exposing the properties and events of graphic form or its form components, see Properties tool window.

Tip: The Boolean ShowComponentNames property in the Debug category, helps to locate the name of a form component quickly, by displaying the names of all the added form components in their top left corners. This is especially useful when linking to a form component manually in the spider workspace.

Example:

  1. Above the surface of the graphic form, a grid, composed of rows and columns of black dots is displayed, by default. The purpose of the grid is to make it easier to arrange form components. The display of this grid can be toggled on and off, by setting the boolean ShowGrid property accordingly, this if off by default.

  2. The row width and column height of this grid can also be specified, in pixels, by changing its Gridsize property. The default size is 8 pixels wide by 8 pixels high.

    Note: The arrow keys can be used to "nudgeto move a form component in typically 1 pixel increments, by using the arrow keys." the selected control(s) in the direction of the arrow key, in other words by moving them in 1 pixel increments in the direction of the arrow key.

  3. The CanvasObjectSnapsize is the equivalent property, which similarly determine how each graphic elementa form component that typically provides drawing functionality for the graphic form. See form component. is positioned on the graphic form.
  4. You can also display guidelines as to where the current object that you are moving can be snapped to, by setting the boolean ShowSnapLines property to True, this if off (False) by default.
