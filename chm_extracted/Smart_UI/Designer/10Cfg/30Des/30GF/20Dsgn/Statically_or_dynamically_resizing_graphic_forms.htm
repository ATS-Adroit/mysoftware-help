Statically or dynamically resizing graphic forms

There are two ways to specify the size of your graphic form:

  1. Statically: to manually specify the size of the graphic form within the Designer workspace and/or by using the Properties tool window. In this case, the size of this graphic form is the actual size that the end-user will see too.

To statically resize a graphic form in the Designer workspace:

  1. Open the required graphic form.
  2. Click on the graphic form itself to cause the eight sizing handlessmall boxes that appear around the perimeter of a selected item, which if dragged changes the size of this item. See drag. to appear, one at all four corners and one in the middle of each side.
  3. Click and drag one of the white sizing handles that appear on the right and bottom borders of the graphic form.

Note: The sizing handles on the top and left borders of the graphic form are grey because they cannot be moved.

Tip: Pressing the ARROW keys while holding down the SHIFT key allows you to resize the form more precisely.

 

To statically resize a graphic form using the Properties window:

  1. Open the required graphic form.
  2. Click on the graphic form itself to select its properties in the Properties tool window. 
  3. In the Properties tool window, click the size property and enter values for the width and height, separated by a comma. For details, see Accessing tool windows.

Tip:  You can expand the size property to enter the Width and Height values individually.

To dynamically resize a graphic form:

  1. Open the required graphic form.
  2. Click on the graphic form itself to select its properties in the Properties tool window. 

In the Properties tool window:

  1. Click the ResizeChildren property and ensure that it is set to True.
  2. If you want the graphic form scaling to maintain the aspect ratio of this graphic form, which is typically required for small graphic forms, then click the PreserveAspectRatio property and ensure that it is also set to True.

Note1: This disabled the AutoScrolling property of this graphic form, since there is no need to display graphic form scroll bars, in this case.

Note2: Dynamic graphic form resizing is not intended to replace the standard docking and anchoring which is recommended for preserving the layout of the graphic form, but instead acts as a failsafe measure.
