Quickly linking properties to data elements

The value of a property can easily be assigned to a writable data element. Click for more information:

Simply drag the required data element from the Enterprise Manager and drop it onto the required graphic form or graphic elementa form component that typically provides drawing functionality for the graphic form. See form component. or controla visible form component used to display data or accept user input in the graphic form. See form component., in the Design workspace.

Then select the required property and the required event that must occur before this value is transferred and the necessary spiders and silks will be automatically created and configured for you.

Note1: You are unable to link the properties of each componenta hidden form component that provides additional functionality to this graphic form and some or all of its form components. See form component. within a graphic form, in this manner.

Note2: Spiders and silks need to manually created, within the Spider Configuration tool window, in order to perform any other links. Such as the ability to modify or manipulate the values of one or more data elements or properties before they are linked. For details, see Methods of linking data to properties within a graphic form.

Note3: It is also possible to quickly link data elements to properties. For details, see Quickly linking data elements to properties.

To quickly link a property to a data element:

  1. In the Enterprise Manager, ensure that the data element within the required datasource is exposed and visible.
  2. In the Design workspace, ensure that the required graphic form has been opened and, if necessary, that the required item is visible. For details, see Opening graphic forms .

Note: It is only possible to quickly link a data element to a property of a graphic form, graphic element or control, but not a component.

  1. Drag the required data element from the Enterprise Manager to the required item in the Design workspace.
  2. Select the From Control Property… submenu.

This lists all the controls at the mouse pointer's location, so that the LAST control that was added to the graphic form is at the TOP of the list and the graphic form (FORM) is at the BOTTOM of the list.

  1. Select the control whose property you want to connect to a data element.

This lists the pre-defined properties of the specified control that you can connect from. By default, this list contains the more commonly used properties of the specified control.

Note: The onus is upon the user to ensure that the data types of the selected data element and property are compatible.
