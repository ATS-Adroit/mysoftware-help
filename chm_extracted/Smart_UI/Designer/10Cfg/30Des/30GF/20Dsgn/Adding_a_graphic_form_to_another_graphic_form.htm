Adding a graphic form to another graphic form

If you want a graphic form to contain another, drag the required graphic form onto another and then select the appropriate configuration dialog which configures the size of each copy and arranges multiple copies on the host graphic form for you.

Typically you will be dragging a SmartUI TemplateA graphic form that has one or more configured aliases and is therefore designed to be displayed within a TemplateGO control. onto a graphic form. For details, see Working with SmartUI Templates.

The following three options are provided when dragging or copying a graphic form or SmartUI Template onto a graphic form:

IMPORTANT: When copying SmartUI Templates ONLY use the Graphic Form by Reference option as this is the ONLY option that creates TemplateGO controls so that you can configure its aliases.

  • Paste Graphic Form Contents: In this case, ONLY the contents of this graphic form or SmartUI Template are added to this graphic form.
  • Graphic Form by Reference: In this case, each copy of the added graphic form refers to the original graphic form and TemplateGO controls are created for each.

Use this method, if you want ALL the copies of this graphic form to look the same and be centrally configuration.

In other words, when you modify the original (copied) graphic form ALL of its copies on other graphic forms are immediately updated.

However, this means that any change made to a copy will be OVERWRITTEN when the original graphic form is modified.

  1. In Enterprise Manager, drag the graphic form that you want to copy onto the required graphic form.

Tip: These graphic forms do not need to be in the same project.

Note: In this case, ANY further control that you add to the parent graphic form is added next to the last one.

  • Table: The SAME as Flow, except, each copy is added to its own cell, so you can add other controls to each of the configured cells.

Note: In this case each copy has a row and column property and can be spanned over adjacent rows and/or columns.

Use this method if you need to customise most of the copies.

This method requires less administration but you need to configure EACH copy manually.
