Animating graphic forms

Animating a graphic form involves connecting data to the graphic form and its added form components.

The purpose of animating a graphic form, is literally to enliven a graphic form, causing it to both display data and to allow the end-users to interact with and manipulate your data in the SmartUI Operator.

For an example of using a DataBinder to read and/or write data in a database to and/from a control on a graphic form, see How to write and or read database data from a control.

Graphic forms can be animated using one or more of the following interchangeable methods:

  1. Programmatically: Adding scripting to the graphic form to create anevent handlerAn event handler is a method that is inserted into your graphic form script, so that you can determine what actions will be performed when the event that it is managing occurs. See event. for each eventan incident (a significant occurrence) that does NOT require user action, unlike an 'alarm' which DOES require user interaction. exposed by the graphic form and its added controls and components. This is an advanced method that requires a knowledge of scripting. For details, see Graphic form scripting.
  2. Visually: Connecting data to the properties exposed by the graphic form and its form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form., via:
  1. Behaviours: Perform common actions to animate the visible form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. that you have added to your graphic form. For details, see About Behaviours.
  2. Drag and drop, which can be performed in one of two ways:
  • To simply connect a data elementa finite component of data contained within a datasource that behaves in a generic manner; typically a value. See datasource. to a property or vice verse, you can do this directly by means of drag and drop between the Enterprise Manager and the Design workspace. For details, see Quick linking.
  • To modify or manipulate the values of one or more data elements or properties before they are linked, then you need to create the required spiders and silks, within the Spider Configuration tool window. For details, see Methods of linking data to properties within a graphic form.

Note: Spiders and silks provide a visual programming language that can create a rich interactive environment for the end-user of a graphic form, without using scripting. For details, see Introduction to spiders and silks.

Tip: Whenever a property requires the name of a data element, simply drag the required data element to this property and its name will be automatically extracted to specify this property at runtime.

Note1: Although more than one data element can be linked to the same property, most properties will ONLY display the most recently received data element.

Note2:If the status of the accuracy of the data within a data element is set to anything other than GOOD, then any controls displaying this data element in a graphic form will become disabled (greyed out). For details on data elements, see About datasources and data elements.
