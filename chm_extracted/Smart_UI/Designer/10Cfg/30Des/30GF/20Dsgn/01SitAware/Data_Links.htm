Data Links

These wizards often require more than one value, in which case one of these values can be set (written) from this wizard in addition to displaying the other and/or they display a large amount of information about their associated value.

Analogue Data Links

Purpose: to display various statistics for an analogue (floating point) process variable (PV), which are calculated over a during a rolling time period, which specifies the maximum sampling time from "now" (the current time) into the past for the specified period. In this case the values are recorded every second over this timespan and the statistics are calculated from these recorded values. For more information, see Calculating statistics from Analog values.

Certain analogue data links also allow users to configure the required setpoint (SP) value associated with this PV.

PLEASE NOTE: These statistics are ONLY calculated by the Analog agent representing the process variable, when its statsPeriod slot is set to the required sampling period, we recommend a value of 10 (minutes), since the default value of 0 DISABLES the calculation of these statistics, since if used excessively they can affect performance.

Description: A rectangle with a grey background displaying the following information:

  • the analogue process variable (PV) - the value slot of the Analog agent - in black,
  • the units of this value (the unit slot of the Analog agent), if specified, below this in light grey (otherwise it is not displayed) and

  • below this the average value of this process variable (PV) calculated over the rolling period

    Note: This value will always be 0 until you set the statsPeriod slot of this Analog agent to the required sampling period, we recommend a value of 10.

  • below this an optional setpoint (SP) value, in blue, which is a separate analogue whose value can be set from this wizard, by clicking on this value and entering the required value in the input dialog.
  • an alarm priority indication, when applicable and only when the associated alarm bit has been specified

User interaction: Clicking on the Data Link displays a tool tip that contains the following additional statistical information calculated for this analogue process variable (PV) for an agent-specific rolling period:

  • Avg Max: the maximum value recorded for this value during the current rolling period.
  • Avg Min: the minimum value recorded for this value during the current rolling period.
  • Avg Deviation: the standard deviation of all the recorded value during the current rolling period.

Note: These values will always be 0 until you set the statsPeriod slot of this Analog agent to the required sampling period, we recommend a value of 10.

When the wizard displays a setpoint (SP) value, then by selecting this value an operator can enter the required value in the input dialog that opens and then click its Finish button.

 

wzdAnalogueDataLink_NoPriority_v01: only displays an analogue process variable (PV) and its associated statistics without a setpoint (SP) value or alarm priorities.

PLEASE NOTE: The statistics are ONLY calculated by the Analog agent representing the process variable, when its statsPeriod slot is set to the required sampling period, we recommend a value of 10 (minutes), since the default value of 0 DISABLES the calculation of these statistics, since if used excessively they can affect performance.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • The Analog agent name (although this can specify the value slot, but no other slot name).

  • Priority 2 – Normal – Orange

  • Priority 0 – Lowest – Royal blue - reserved for diagnostics alarms or events.

Digital Data Links

Purpose: provides two buttons that allow a user to initiate the starting (turning on) and stopping (turning off) of a Boolean process variable (PV), which only occurs once the applicable operating conditions have been met, and displays a description of the associated equipment that is being turned on/off.

Description: A rectangle with a description of the item of equipment represented by the Boolean process variable (PV) that is being turned on/off in black above two buttons, one entitled "On" and the other "Off" which set the stop and start setpoints and an alarm priority indication, when applicable and only when the associated alarm bit has been specified.

User interaction:

  • Clicking the "On" button sets the start setpoint to initiate the starting of the described Boolean process variable and
  • Clicking the "Off" button sets the stop setpoint to initiate the stopping of the described Boolean process variable.

 

wzdDigitalDataLink_NoPriority_v01: allows a user to initiate the starting (turning on) and stopping (turning off) of a Boolean process variable (PV) and provides a description of the associated item of equipment that is being turned on/off.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • Type in a static description of the item of equipment associated with the Boolean process variable (PV) that is to be turned on/off.
  • Browse in the Digital agent name (which specifies its value slot) representing the Boolean process variable (PV).
  • Browse in the Digital agent name (which specifies its value slot) representing the "On" (start) setpoint (SP), which is set when the "On" button is clicked and signals the requirement to start the specified process variable, which only occurs once the applicable operating conditions have been met.
  • Browse in the Digital agent name (which specifies its value slot) representing the "Off" (stop) setpoint (SP), which is set when the "Off" button is clicked and signals the requirement to stop the specified process variable, which only occurs once the applicable operating conditions have been met.
