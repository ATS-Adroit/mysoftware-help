Displays

A display, textually display the value of the associated process variable.

Analogue Displays

Purpose: to textually display the value of the associated analogue (floating point) process variable (PV).

Description: A rectangle with a light grey background displaying the following information:

  • the analogue process variable (PV) - the value slot of the Analog agent - in black and
  • the units of this value (the unit slot of the Analog agent), if specified, below this in light grey (otherwise it is not displayed)
  • an alarm priority indication, when applicable and only when the associated alarm bit has been specified

 

wzdAnalogueDisplay_NoPriority_v01: displays an analogue process variable (PV) value and/or unit without displaying any alarm priorities.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • The Analog agent name (although this can specify the value slot, but no other slot name).

 

wzdAnalogueDisplay_Priority3_v01: displays an analogue process variable (PV) value and/or unit and will display one of the following alarm priorities ONLY when applicable to do so:

  • Priority 2 – Normal – Orange
  • Priority 1 – Low – Magenta
  • Priority 0 – Lowest – Royal blue - reserved for diagnostics alarms or events.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • Browse in the Analog agent name (although this can specify the value slot, but no other slot name).
  • Browse in the least important (priority 0) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the less important (priority 1) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the normal (priority 2) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).

 

wzdAnalogueDisplay_Priority5_v01: displays an analogue process variable (PV) value and/or unit and will display one of the following alarm priorities ONLY when applicable to do so:

  • Priority 4 – Highest – Red
  • Priority 3 – High – Yellow
  • Priority 2 – Normal – Orange
  • Priority 1 – Low – Magenta
  • Priority 0 – Lowest – Royal blue - reserved for diagnostics alarms or events.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • Browse in the Analog agent name (although this can specify the value slot, but no other slot name).
  • Browse in the least important (priority 0) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the less important (priority 1) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the normal (priority 2) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the second important (priority 3) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).
  • Browse in the most important (priority 4) alarm bit for this Analog agent (when using the default Analog agent alarms choose one of the following slots: Changed, High, High-high, Low, Low-low, Normal, OutofRange, Rate-of-change).

 

Digital Displays

Purpose: to display the value of the associated Boolean process variable (PV).

Description: Typically a rectangle with a light grey background displaying the following information:

  • a radio button control that is filled or empty depending on the value of the associated Boolean process variable (PV) and
  • a description of this Boolean process variable and
  • an alarm priority indication, when applicable and only when the associated alarm bit has been specified.

 

wzdDigitalTextDisplay_NoPriority_v01: this unlike the other Digital Display wizards, simply displays the text corresponding to the status of the value of the associated Boolean process variable (PV) in a white rectangle.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  1. Browse in the Digital agent name (which specifies its textValue slot) representing the Boolean process variable (PV).

 

wzdDigitalDisplay_NoPriority_v01: displays the value of a Boolean process variable (PV) value via a radio button control and a specified textual description.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • The Digital agent name that specifies this Boolean process variable (although this can specify the value slot, but no other slot name).
  • Type in a static description of the item of equipment associated with this Boolean process variable (PV).

 

wzdDigitalDisplay_Priority3_v01: displays the value of a Boolean process variable (PV) value via a radio button control and a specified textual description and will display one of the following alarm priorities ONLY when applicable to do so:

  • Priority 2 – Normal – Orange
  • Priority 1 – Low – Magenta
  • Priority 0 – Lowest – Royal blue - reserved for diagnostics alarms or events.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  • The Digital agent name that specifies this Boolean process variable (although this can specify the value slot, but no other slot name).
  • Type in a static description of the item of equipment associated with this Boolean process variable (PV).
  • Browse in the least important (priority 0) alarm bit for the Digital agent representing the Boolean process variable (when using the default Digital agent alarms choose one of the following slots: Changed, On, Off).
  • Browse in the less important (priority 1) alarm bit for the Digital agent representing the Boolean process variable (when using the default Digital agent alarms choose one of the following slots: Changed, On, Off).
  • Browse in the normal (priority 2) alarm bit for the Digital agent representing the Boolean process variable (when using the default Digital agent alarms choose one of the following slots: Changed, On, Off).
