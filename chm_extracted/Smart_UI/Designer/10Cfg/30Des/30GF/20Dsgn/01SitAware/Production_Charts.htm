Production Charts

Purpose: when operators need to know how a production value is performing against a set target value: this charts the production value and a straight line graph of the set target value for the specific production period.

Description: a line chart with a value axis on the left and a time axis on the bottom, with a straight line in blue drawn from 0 to the specified target value, representing the required production rate and the production value is indicated by means of a grey filled area, so that its actual production rate can be monitored relative to its required production rate.

Note: This production value is only displayed if its value is being logged or if it constantly changes over the specified time period.

User interaction: Click the clock glyph in the top right corner of this wizard to configure the current Production Parameters, as follows:

  • Choose how the period of observing this production value is determined, by specifying the End Production Time, by using one of the following methods:
  • Current to End Time: specify the future dated end time from the Current time (now), by typically typing in the required digits.

Tip: The LEFT and RIGHT arrow keys can be used to navigate between the digits.

  • Current + Timespan: this calculates the required ending time (in the future) by adding the specified Timespan to the Current time (now).

If necessary, specify the required duration of time that is displayed, by selecting the required time dimension e.g. Hours, Days etc., from the list box to the right of the Timespan edit box and then specifying the required amount in this edit box.

  • Start Time to End Time: specify both the required starting and ending time, by typing in the required digits and/or using the calendar to specify the required date.
  • If necessary, change the Target Value that should be met by this production value within the specified production time period.
  • If necessary, click the Reset button to restart the monitoring of this production value, by recalculating the production time period.
  • Click Finish when done or Cancel to ignore any changes made.

 

wzdProductionChart_ShiftAgent_DynamicTarget_v01: this monitors a production value, that is produced during the current shift, as specified by a Shift agent, relative to a production target value which can be externally modified. Therefore if an operator makes a process change, the required production target value can be automatically adjusted to change the required production rate as needed.

Tip: Your operators can also change the target value manually at runtime using the Production Parameters dialog.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  1. Browse in the Analog agent name (although this can specify the value slot, but no other slot name) representing the production value that is to be monitored e.g. ana001.value
  2. Browse in the required Shift agent name that stores the various shift times during which the production value is being produced. This automatically selects the shiftEndTime slot of this agent which specifies the future time that the current shift ends.
  3. Browse in the Analog agent name (although this can specify the value slot, but no other slot name) representing the production target value.

 

wzdProductionChart_StaticTime_DynamicTarget_v01: this monitors a production value relative to a production target value which can be changed during a constant time period. Therefore if an operator makes a process change, the required production target value can be automatically adjusted to change the required production rate as needed.

Tip: Your operators can also change the target value and/or the required production time manually at runtime using the Production Parameters dialog.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  1. Browse in the Analog agent name (although this can specify the value slot, but no other slot name) representing the production value that is to be monitored e.g. ana001.value
  2. Type in the required constant duration of the production time, in hours.
  3. Browse in the Analog agent name (although this can specify the value slot, but no other slot name) representing the production target value.

 

wzdProductionChart_StaticTime_StaticTarget_v01: this monitors a production value using a static time period and target value.

Tip: Your operators can also change the target value and/or the required production time manually at runtime using the Production Parameters dialog.

Required values:

Note: When this wizard is added to a graphic form, all these values are MANDATORY and therefore must ALL be specified.

Tip: These values are listed in the order they are specified in the wizard.

  1. Browse in the Analog agent name (although this can specify the value slot, but no other slot name) representing the production value that is to be monitored e.g. ana001.value
  2. Type in the required constant duration of the production time, in hours.
  3. Type in the required production target value.
