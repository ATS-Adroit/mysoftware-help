Graphic form scripting

Graphic form scripting can programmatically achieve a more interactive user experience. Click for more information:

This allows dynamic scripting code (for animations, algorithmic programming etc.) to be inserted at key events of the graphic form itself and for any controls and components that have been added to it.

Example script.

Note: To prevent the graphic form script from ever being executed, disable the boolean ScriptEnabled property in the VIZNET Extended category of the graphic form. This property can also be configured by default within a SmartUI Designer and Operator. For details, see Designer scripting settings or Operator scripting settings.

The Properties tool window, exposes the events of the currently selected graphic form, control and/or component and enables the required event handler(s) to be automatically inserted into the graphic form's associated script. For details, see Properties tool window.

This script is typically exposed within the Graphic Form Script tool window. This provides the same editing environment as is found in the Script Editor but, unlike the Script Editor, allows one to easily switch between the script and its graphic form in the Design workspace. For details, see Graphic Form Script tool window or Working with scripts.

However, it is also possible to open this script within the Script Editor, to make use of the additional scripting functionality that it provides, such as: managing references; changing script languages and/or debugging the script. For details, see Opening graphic form scripts in the Script Editor.

WARNING! The InitialiseVIZNETComponents() method, within each graphic form script, performs the event handling. It is therefore NOT recommended that the user modify this in any way or comment it out and does so at his/her own risk. 

Automatically adding event handlers to the graphic form script:

  1. Open the required graphic form. For details, see Opening graphic forms.
  2. In the Design workspace, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the required control, component or the graphic form itself.

Note: If more than one control, component and/or graphic form is currently selected, this will only expose the events of the last item selected, known as the primary controlwhen a group of controls are selected, the sizing handles of this control are white and its attributes will be used if this group of controls are formatted.   1. Open the Properties tool window. For details, see Accessing tool windows.
  2. If necessary, select the Events toolbar button, to display all the events exposed for the selected item.
  3. Navigate to the required event, which can either be organised alphabetically or categorically.
  4. Type in an appropriate name for the required event handler, in the value cell to the right of this name e.g. Button1Click.

Tip: It is recommended to give this event handler a descriptive name, to make it easier to identify the item and its event that it will manage.

This will automatically insert a method into the script, which is executed whenever this specified event is raised for this item. This also adds code to the InitialiseVIZNETComponents() method, to initialise this event handler.
