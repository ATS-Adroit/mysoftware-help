Designing graphic forms

Open a graphic form in the Design workspace to design it.

Note: Projects and their folders provide a Preview Graphic Forms option to displays thumbnail snapshots of all the graphic forms located in their immediate or root level to either open the required graphic form or populate the Favorites tool window. For details, see Previewing graphic forms.

Tip: The Shapes Wizards & Examples tab of the Designer ribbon, provides access to the shapes, wizards and/or examples of the default Shapes Wizards and Examples project so that you can easily design your graphic forms. For details, see Working with Shapes Wizards and Examples.

In particular this contains the Situational Awareness category, which contains sub-categories of wizards that allow you to create process control user interfaces that strive to minimise operator fatigue and increase their response times. For more details, see Situational Awareness (or High Performance SCADA).

Design or configure a graphic form for the following reasons:

  1. To provide the functionality or user interface that will allow end-users to interact with and examine the data displayed by the graphic form.
  2. To connect data to this graphic form, gathered from any datasource.
  3. If necessary, to manipulate data before it is displayed on the graphic form.

Note: A Wizard is a pre-drawn and/or pre-configured (animated) graphical object that can be used to simplify and speed up the task of creating graphic forms. For details, see Working with wizards.

The graphic form toolbar provides tools to analyse and/or optimise the structure of your graphic forms. For details, see Optimizing graphic forms or Graphic form statistics.

How to design a graphic form:

  1. Add form components to the graphic form to create the user interface of a graphic form, which you can do by adding one or more Window Forms or a customised controla visible form component used to display data or accept user input in the graphic form. See form component. and componenta hidden form component that provides additional functionality to this graphic form and some or all of its form components. See form component. and also graphic elementa form component that typically provides drawing functionality for the graphic form. See form component..

    For details, see Adding form components.

    Note: The TableLayoutPanel control allows you to add and arrange controls in a table, so that these controls can change dynamically as the application environment changes. For details, see TableLayoutPanel controls.

    Please Note: To specify an ampersand character '&' in a text property of a control, type in && and not just &.
    Since if only one '&' character is specified then when displayed, the & character does not appear and the following word is underlined instead.

    Tip1: Added form components can also be copied within the same graphic form or to another graphic form, effectively reducing their design time. For details, see Copying form components.

    Tip2: It is also possible to reuse controls and/or graphical objects that have been created from one or more configured graphic elements. For details, see Exporting and Importing controls or Exporting and importing graphic elements.

    Note: To make it easier to design and arrange controls, the visibility of controls cannot be modified in Design mode. This restriction, however is lifted in Run mode and in the Operator.

  1. Connect data to the properties of the graphic form and/or the added form components. This is known as animating the graphic form, since it allows the graphic form to both display the data and provide the necessary user interaction with it.

    This can be performed as follows:

    1. Select the icon of most form components to displays a menu of common tasks. Most notably this menu allows Behaviours to be added to controls and graphic elements, which typically display the values of your data, either actually or graphically, by using the available properties of the selected control or graphic element. For details, see About Behaviours.
    2. If you want to simply connect data to a property or vice verse, you can do this by means of drag and drop between the Enterprise Manager and the Design workspace. For details, see Quick linking.

    Note: To make it easier to design and arrange controls, the visibility of controls cannot be modified in Design mode. However, this restriction is lifted, in Run mode and in the Operator.

    IMPORTANT: Some functionality, available in the SmartUI Operator cannot be displayed when running graphic forms in the SmartUI Designer, for instance opening or interacting with graphic forms.

    1. If you require anything more complicated, such as the ability to manipulate or combine the values of the data or properties before they are linked, then you need to perform the required linking yourself. For details, see Animating graphic forms.

    Note: Each graphic form also has an associated script which can be used to add intelligence to the events exposed by the graphic form, its controls and components. For details, see Graphic form scripting.

Tip: SmartUI Templates can automatically create aliases for String properties on graphic forms or their form components and for data elements when configuring Behaviours. For details, see SmartUI Templates and automatic alias creation.

Each graphic form provides the following advanced functionality:

  1. By default, a graphic form consists of a single layer and level, which are used to contain and display the form components, respectively. But additional layers and levels can be added to provide overlays or masking effects. For details, see Working with levels and layers.
  2. If necessary, every displayed text item on this graphic form and all the graphic forms within the project, can be translated into the language(s) used by its intended end-users. For details, see Working with graphic form translation.

Tip1: The graphic form document, itself, provides features that assist in its configuration. For details, see Graphic form design properties.

Tip2: The Window menu shows the graphic forms that are currently open in the Design workspace so that you can easily navigate between them.

Tip3:Press F11 to activate the Fullscreen mode which hides everything except the selected graphic form in the Design workspace, a floating Toolbox window and floating tool and menu bars.

Tip4: When designing a graphic form, click the Run toolbar button, to display exactly what an operator would see when viewing and interacting with the real-time animated graphic form. For details, see Running graphic forms. In Run mode the spider configuration window is greyed out and the ‘Preview’ watermark is displayed in the right hand bottom corner.

 

Adding a graphic form to another graphic form: drag the required graphic form onto another and then select the appropriate configuration dialog which configures the size of each copy and arranges multiple copies on the host graphic form for you.
