Working with substitutions

A Wizard is a pre-drawn and/or pre-configured skeleton of graphical objects and their assigned Behaviours (if any), which has placeholders (substitutions) for data elements, which can simplify and speed up the task of creating graphic forms. But, instead of directly specifying the values that drive these Behaviours, these are replaced with value or static text placeholders (substitutions).

Tip: Wizards that display one or more SmartUI Templates can use their substitutions to drive the values of the aliases of these child SmartUI Templates. For details, see Driving aliases with wizard substitutions.

Adding substitutions to wizards

The following types of substitutions that can be made:

  • value substitutions: these are placeholders for values (data elements) and so you are actually adding Data Element spiders, which allow you to determine which portion/s of the specified data element should be replaced at runtime. Each substituted value must be enclosed in curly braces {}, as follows:
  • if you require the ENTIRE Data Element to be substituted then specify {requiredValueName}
  • if you require multiple parts of the data element name to be separately replaced then specify multiple substitutions, such as concatenating a number of hierarchical levels for this data element: {DataSource}.{Structure}.{DataName}.{Value}.

Note: A data element that is specified without curly braces is assumed to be an existing data element.

  • static substitutions: these are placeholders for text

Substitutions are automatically created for you, by using this {} notation, in the following instances:

IMPORTANT: In the case of String or Text properties, you can choose whether the substitution name enclosed in { } braces is either a static (text) or a value substitution.

  • in the Properties tool window: for any String or Text properties, you can specify the required name enclosed in { } braces.
  • when configuring Behaviours: for any data element field, you can specify the required name enclosed in { } braces.
  • when configuring a charting control, for the applicable Series values specify the required name enclosed in { } braces.
  • when configuring an Adroit Alarm Viewer control, specify the required name enclosed in { } braces for the Alarm List / Alarm Agent value.
  • When you create or edit Data Element spiders and/or click its Substitutions spider toolbar button (or spider menu item) to specify the required substitution/s in the Substitutions dialog for this data element, which is typically used when you have saved a graphic form as a wizard. For more details about Data Element spiders, see Data Element spiders.

Substituting values in wizards

Wizards provide the ability to change (substitute) the values of certain data elements, these substitutions can be configured as follows:

Tip: Not all values require substitutions – some or most values can be assigned to valid (unchanging) values, if desired.

  • when creating and editing wizards: use the Substitutions Overview dialog to manage your substitutions, which displays all the data elements and/or substitutions provided by this wizard, in a single dialog and can be accessed using one of the following methods:
  1. via the Substitutions wizard toolbar button
  2. by right clicking a wizard and selecting Substitutions

This dialog is useful, if you have been using valid data elements to drive specific values in a wizard and now you want to substitute these values. As this helps locate these values easily, without having to sift through the spider workspace.

The method used to locate and manage these values/substitutions depends upon how they have been assigned, as follows:

  • For all data elements or substitutions directly assigned to the controls or vectors (in other words to their properties and/or Behaviours):
    1. Select the required control or vector from the Graphic Objects list to display its configured Behaviours and/or Property spiders (properties), that either have substitutions or data elements assigned to them
    2. This specifies the names of the assigned data elements and hence whether these data element names have configured substitution/s or not.
    3. Then double click the required entries to edit or to create the required substitutions.
  • For all data elements or substitutions indirectly assigned to the controls or vectors (in other words through the use of associated spiders or other indirect methods):
    1. Click the Other tab, which indicates where these data elements have been assigned and the names of the associated data elements and hence whether these data element names have configured substitution/s or not.
    2. Again double click the required entries to edit or to create the required substitutions.
  • when adding a wizard to (or editing a wizard instance in) a graphic form: use the Substitution Assignment dialog, can be accessed using one of the following methods:
  1. by dragging a wizard onto a graphic form
  2. via the Substitution Assignment graphic form toolbar button
  3. by right clicking a wizard instance and selecting Substitution Assignment
  4. by clicking the glyph in the top right corner of a wizard instance and selecting the Substitution Assignment link from its Tasks menu.
  5. by clicking the wizard glyph in the top left corner of a wizard instance.

When you have used multiple substitutions are used to create a single value (data element) name, then click the Context checkbox to display the complete substituted data element name so that you can clearly see which part of this name you are supplying a value for.

Tip: Typically you should only use the data element browser, when the substitution refers to the ENTIRE data element name, otherwise after specifying the required data element, you need to MANUALLY delete the unnecessary portions (which are being handled by other substitutions).

This dialog allows you to specify the Wizard Name, which is the name of the wizard control that is added to this graphic form. By default the name of the wizard is used, which is appended by a unique number if more that one control by this name already exists on the graphic form.

Note: You cannot specify spaces for this Wizard Name, since spaces are NOT allowed in the names of controls.

  • By default the Grouped checkbox is enabled, which groups the vectors and/or controls of this wizard and therefore allows their substitution assignments to be edited after this is added to a graphic form.
  • If you uncheck the Grouped checkbox, then the vectors and/or controls of this wizard and added to the graphic form in situ (where they are dragged onto the graphic form) and you are UNABLE to edit their substitution assignments AFTER adding them to this graphic form, which you will be warned about.

If you specify an invalid substitution value, then on clicking Finish a confirmation dialog appears, warning you of each value substitution that is incorrect, which you can either dismiss and continue (click Yes) or click No and correct the incorrect substitution/s.

Substituting static text in wizards

When specifying a substitution name enclosed in braces for a String or Text property of a control or vector, you can choose whether this will be a placeholder for a value (data element) or whether this will be a static substitution, which is a placeholder for text.

Static substitutions are differentiated by a yellow background in the Substitution Assignment dialog, since they are placeholders for text and not data elements.

Note: If you choose to browse in a data element for a Static substitution, then only its current value is added to the Value column .
