Modifying or editing your wizards

Right clicking a wizard instance on a graphic form provides the following configuration options:

Break wizard instance: to ungroup or break a wizard too, so that its controls and/or vectors behave, as normal, and so their values cannot be re-substituted.

Note: If you unchecked the Grouped option when adding the wizard to this graphic form, then the controls and/or vectors behave, as normal, and so their values cannot be re-substituted.

  • Substitution Assignment: to change the substitution assignments (you can also click the Substitutions graphic form toolbar button) to display the Substitution Assignment dialog. For details, see Working with substitutions.
  • Load source wizard: this opens the wizard that was originally used to create this wizard instance in a separate window of the Design workspace
  • Open source wizard location: this opens the project and/or folder in the Enterprise Manager that contains the wizard that was originally used to create this wizard instance.
  • Create Object Template: create an Object Model Template from this wizard instance, which creates an advanced wizard that also configures the required SCADA-related configuration, such as the required scanning, alarming and logging of this object. For details, see Working with the object model.
  • Child Behaviours: this allows you to either add or remove Behaviours to or from the components of this wizard instance. For details, see Child Behaviours.

Note: Although child Behaviours are provided when you select a wizard instance it is NOT recommended that you manually edit your wizard instances after adding them to graphic forms - instead modify the wizard and then update its instances in the required graphic forms.
