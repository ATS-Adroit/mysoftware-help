Operating graphic forms

Once a graphic form has been designed and saved, it is able to be opened within the SmartUI Operator, so that its associated data can be viewed and interacted with. Click for more information:

For details, see Designing graphic forms or Saving graphic forms.

Note1: The amount of user interaction provided by a graphic form is entirely dependent upon its design.

Note2: You can greatly improve the load times of graphic forms by only using the local cache of the Operator but this does require more administrative overhead. For details, see Updating cached graphic forms.

Note3: A graphic form is able to be opened in the SmartUI Operator regardless of how completely it has been designed.

Note4: One is able to view what a graphic form will look like within the Operator, while still in the Designer by previewing this graphic form. For details, see Running graphic forms.

The display and the amount of interaction that a user has with the SmartUI Operator window, is determined by:

  • the user profile configured for this user in the SmartUI Designer. For details, see Operator customization.
  • and/or the command line argument options used to launch the SmartUI Operator. For details, see Operator command line arguments.

Note: The INITIAL display of the SmartUI Operator and configuration of the work environment can be configured by SmartUI Operator settings. For details, see Operator user interface settings.

To operate a graphic form:

  1. If required launch the SmartUI Operator and log in.

This will display the SmartUI Operator window.

  1. Open the required graphic form in the Projects tool window, as follows:
  1. If necessary, expandclick the plus (+) box to the left of the current icon or name the Servers.
  1. If necessary, expand the name of the required Server connection .
  1. If necessary, expand the Projects category.
  2. Click the plus box  to the left of the project icon  of the required name.

Tip: You can also open a project by double-clicking on its name or icon.

  1. If necessary, expandclick the plus (+) box to the left of the current icon or name its required existing folder(s), until the required graphic form is displayed.
  2. Double click this graphic form.

This will open the selected graphic form in the SmartUI Operator window.

  1. To display the Projects tool window, for instance, to open another graphic form, press CTRL+O or right click and select Toggle Operator Mode.
  2. To switch between more than one graphic form, it is necessary to display document tabs within the SmartUI Operator window, by either pressing CTRL+T or right click and select Toggle Graphic Form Tabs and then select the tab, at the top of the Operator window that corresponds to the name of the required graphic form.
  3. To display the SmartUI Operator window in full screen mode (without a title bar), right click and select Full Screen.
  4. To configure the SmartUI Operator window to always be displayed above all other applications that may be open on your system, right click and select Always On Top.

Note: These are only a few of the configurable options provided by the Operator, for more details, see Customizing the SmartUI Operator work environment.

  1. To close the SmartUI Operator window, either press ALT+F4 or right click and select Exit.
