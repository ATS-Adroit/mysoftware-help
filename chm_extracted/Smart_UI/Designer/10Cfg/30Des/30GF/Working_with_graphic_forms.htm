Working with graphic forms

Graphic forms can graphically represent and manipulate data gathered from any datasourcea connection via a datasource plugin to a particular supply of data, to expose its data to the Server as data elements. See Server; datasource plugin;data element. exposed by any of the connected SmartUI Servers.

Note: A Wizard is a pre-drawn and/or pre-configured (animated) graphical object that can be used to simplify and speed up the task of creating graphic forms. For details, see Working with wizards.

Tip: The graphic form size is typically the actual size that the end-user sees, unless you choose to dynamically resize a graphic form to cater for monitors with differing aspect ratios. For details, see Statically or dynamically resizing graphic forms.

Note: Projects and their folders provide a Preview Graphic Forms option to displays thumbnail snapshots of all the graphic forms located in their immediate or root level to either open the required graphic form or populate the Favorites tool window. For details, see Previewing graphic forms.

Tip: Import graphic forms from existing projects instead of creating them from scratch. For details, see Importing graphic forms or Adding a graphic form to another graphic form.

How to reuse graphical components

What is a graphic form?

A graphic form is a document that opens in the Design workspace that can be designed to graphically display data to the user and to accept input from the user, through the use of form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form.. For details, see Opening graphic forms or Designing graphic forms.

 

A graphic form provides the following features to assist in its design:

  1. A toolbar appears beneath the tab of the displayed graphic form, in the Design workspace, with graphic form-specific tools, such as various options provided for their saving or launching the Script Editor to edit the graphic form script. For details, see Options for saving graphic forms or Opening graphic form scripts in the Script Editor.

    The graphic form toolbar provides tools to analyse and/or optimise the structure of your graphic forms. For details, see Optimizing graphic forms or Graphic form statistics.

  2. Rulers appear along the top and right sides of the graphic form, these can be used when sizing the graphic form itself and when adding, sizing and positioning the form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form.. For details, see Resizing graphic forms or Adding form components.

Note: The units of measurement for these rulers are pixels. 

  1. Depending on the size of the graphic form and the size of the Design workspace, there may be scrollbars to the right and bottom of the graphic form, to allow you to move to every area of the graphic form. Click for more information:

For details on using these scrollbars, see Working with scrollbars.

Tip: It is recommended, while designing the graphic form that the Designer is customised so that the Design workspace is as large enough to view the entire graphic form, if possible. For details, see Customizing the work environment.

  1. Below the graphic form there are two tabs, which allow you to alternate between the Design and Run viewing modes, of the graphic form. For details, see Opening graphic forms.
  2. The graphic form, like its form components, exposes its own properties and events. Click for more information:

For details, see Properties tool window. The sole function of a number of properties of the graphic form is to assist in making its design easier. For details, see Graphic form design properties.

Note: The Aliases property makes it possible for graphic forms contained within TemplateGO controls to behave as configurable form components. For details, see Working with aliases.

Tip: SmartUI Templates can automatically create aliases for String properties on graphic forms or their form components and for data elements when configuring Behaviours. For details, see SmartUI Templates and automatic alias creation.

Tip: Use the Mapping spider to simplify the configuration of any individual properties and/or spider inputs required within reusable graphic forms. For details, see Mapping spiders.

Note1: The Design tab of the ribbon provides tools for arranging and designing form components on the current graphic form. For details, see Tools for editing and arranging vectors and/or controls.

Note2: To prevent the selected control(s) and/or graphic form from being re-positioned, right-click and select Lock.

Note3: To make it easier to design and arrange controls, the visibility of controls cannot be modified in Design mode. However, this restriction is lifted, in Run mode and in the SmartUI Operator.

Tip: The SmartUI Designer title bar displays the full path of the current graphic form - making it easier to identify which graphic form is being edited, since some projects have graphic forms with the same name.
