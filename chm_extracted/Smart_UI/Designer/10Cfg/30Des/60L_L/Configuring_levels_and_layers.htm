Configuring levels and layers

Levels and layers are configured in the Levels and Layers tool window for the current graphic form displayed in the Design workspace. For more details on why you would configure a level or layer for a graphic form and how they work, see Working with levels and layers.

The Levels and layers tool window consists of a grid, where the columns represent the levels and the rows represent the layers, which support the following tasks in order of importance:

Click for more information about each task:

  • Adding levels: each level can be selected by the end-user of this graphic form to display the associated layers and their visible form components.

Note: At runtime, the user can selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. any configured level of a graphic form, so ensure that each level has a unique configuration of layers associated with it.

Tip: Ensure that the first level in the grid contains the graphic form components that need to be viewed by default, since this is the default view of the graphic form.

  • Adding layers: each layer should contain a sub-set of visible form components are need to be selectively hidden or displayed on this graphic form.

Note1: After adding a layer you need to associate it with at least one level.

Note2: Layers that have not been associated with levels are indicated by cells in the grid, which have the default background color.

Tip: If necessary, after you have added a form component to a layer, you can move it to another layer, by right clicking it and selecting its Move to layer item (provided that this graphic form provides two or more layers).

  • Associate layers with levels: so that their visible form components are displayed on the graphic form, when the required level is selected. 

Tip1: A single layer can be added to any number of levels.

Tip2: To quickly determine which layers have been added to each level, each layer or row is assigned its own unique color in this grid when layers are associated with levels.

  • Identifying edited layers: form components are added to the currently edited layer, in the Levels and Layers tool window.
  • Identifying visible levels: identify a level as the visible level, in the Levels and layers tool window, to display the form components associated with its layers in the graphic form.

Tip: When editing a graphic form, it is recommended to add and identify a level containing ALL the controls that will appear at the same time, so that they can be arranged.

  • Renaming layers: to assist the designers in identifying the controls it contains, since the end-user does not see the layer names.
  • Removing layers: to remove BOTH the layer and its added controls.

WARNING! ALL the form components attached to this layer are also removed and cannot be recovered. Therefore save the graphic form before removing any layers. For details, see Saving graphic forms.       

  • Renaming levels: to assist the end-user to identify the contents of this level when its graphic form is displayed at runtime.
  • Removing levels: remove levels that are no longer needed or which are associated with the SAME layers as another level.
  • Hiding or showing configured levels: for instance to hide the levels, if the Levels and Layers tool window is very narrow.

Note: This has no effect upon the display of levels within the graphic form itself.
