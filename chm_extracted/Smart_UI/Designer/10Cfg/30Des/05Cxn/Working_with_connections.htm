Working with connections

A connection is created between a SmartUIClientrefers to either the Designer or the Operator, both of which are client applications of the Server. and SmartUI Server computer to transfer data between these two computers.

Connections are created are follows:

  • During the login process a data connection is created between the SmartUI Client computer and the specified SmartUI Server computer. For details, see Logging in to a Server.
  • Additional connections can be added within the SmartUI Designer to access other SmartUI Servers and their data.  Click for more details:

    For further details, see Adding connections.

    Note1: You can reconnect added connections at login for each user. For details, see Customizing connections and work environment.

    Note2: You can delete any connection that you no longer require. For details, see Deleting saved connections.

    Note3: A default connection can be specified, which is used during the initial login. For details, see Specifying the default connection.

    Note4: These connections can be removed and/or updated to display any recent changes made to the data exposed by these Servers. For details, see Removing connections or Updating connections.

    Note5: You can also save changes made to each of the connected Servers from within the Designer itself. For details, see Saving changes made to connected Servers.

Since ALL data resides within a SmartUI Server, including the roaming profiles and other user-specific settings, it is compulsory to login to the required SmartUI Server to create or modify a connection in order to protect this data.

Furthermore, only a user that is either an allowed usera user account on the Server machine that is added to the list of Allowed Users, which is able to log on to the Server and implement Server security. See user account; Server security. or a member of an allowed group on the SmartUI Server can login.

Tip: To save time when launching a Client, you can specify an automatic login or create login profiles that store different sets of login settings for a specific Client.

When modifying the connection properties, the specified login details are not displayed for security reasons and must be re-entered. For details, see Modifying connection properties.

Each connection consists of the following mandatory properties, apart from the user login details:

  1. Host Name: The network name or IP address of the Server computer that will be connected to.

Note: If this Server uses a port other than 9000 (the default), this becomes: 'HostName:PortNumber'.

  1. Type: The physical connection between this Client computer and the required Server computer i.e. via the LAN or the Internet.
  2. Mode: The method of communicating data between the Client and Server computers, which depends upon the selected Type. For details, see About connection communication methods.
