Troubleshooting failed login attempts

If a SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. has been unable to login to the SmartUI Server computer, a message displays beneath the Password edit box of the Login configuration dialog, to assist you in troubleshooting the error.

The following list indicates the possible error messages and their remedies:

Error Message Remedy

Error! User not allowed to login to environment
  1. Firstly, ensure that the specified user name has been entered correctly and IS added to the Allowed Groups or Allowed Users for this Server. For details, see Adding allowed users and groups.

  2. Secondly, ensure that the password that you are using has been entered correctly and MATCHES the specified user.

    For instance if you are logging in using a DOMAIN user, then provide the DOMAIN password, alternatively, if logging in using a LOCAL user, provide the LOCAL password.

Note: Passwords are case-sensitive.

 

Error connecting to host

...No connection could be made because the target computer actively refused it

The SmartUI Server computer cannot be contacted, ensure that the Server computer is operational and then click the Finish button to retry the login.

Generally this error is caused by the SmartUIServer and SmartUIClient having different versions. Or an application other than the Server is using the specified port.

Note: This error will also occur if the SmartUI Server is NOT licensed.

In this case, run the SmartUI Server as an application (NOT as a service) and ensure that the Server is licensed. For details, see Launching the Server.
The client is connecting with an incorrect version. Please ensure that the client and server are running the same version. The version of the server: [versionNumberOfServer]. The version of the client: [versionNumberOfClient]

As indicated by this message ensure that this SmartUI Client has the identical version installed as the SmartUI Server.

Note: The version number of the Server, as specified by this error message will tell you which version you need to install.
Requested service cannot be found The SmartUI Server computer cannot be contacted, ensure that the SmartUI Server computer is operational and then click the Finish button to retry the login.

A required privilege is not held by the client.

This will occur on all operating systems, if the user account or group that is being used to log on does not have the necessary user rights assigned. For details of the required user rights and how to apply them, see Windows security configuration.
An error occurred. Do you want to attempt to re-connect? The error was: Error! Number of connections licensed exceeded.

This message box is displayed when the SmartUI Server that you are trying to connect to, has no available SmartUI Client licenses.

Close any connected Clients that are not being used and try to login to this Server again. For details, see Disconnecting all the logged on users.

Note: These error messages are determined by the operating system of the Server computer.

Only the most common of which are interpreted. For all other error messages, email or provide the support with the exact wording so as to obtain the required remedy.
