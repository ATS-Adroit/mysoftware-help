Modifying connection properties

You can modify the properties of the SmartUI Server connections that were created either at login or in the Enterprise Manager. Click for more information:

This is usually necessary when a connection is being reconnected and one or more of its original properties have changed or to specify which connection is the default or login connection. For details on reconnecting connections, see Customizing connections and work environment.

Note1: You CANNOT modify the connection Type itself i.e. how the computers are physically connected. In this case remove the existing connection and add an entirely new connection instead. For details, see Removing connections and Adding connections.

Note2: After modifying a connection's properties the Server computer is immediately reconnected using these new settings, therefore it is essential that all the fields are correctly specified.

Note3: The login details are NOT displayed within this configuration dialog for security reasons and need to be re-entered. 

To modify the properties of a connection:

In the SmartUI Designer:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  1. Right-click the name or icon of the required Server connection and select Connection Properties.

Tip: The connection name is prefaced by the Server computer name.

Configure the Connection Settings configuration dialog, as follows:

  1. Specify the required SmartUI Server computer.

As follows, when connecting via the local area network:

  • Either press the Detected Servers... button and double-click the required Server from the list of available Servers, which specifies each Servers' address, port, number of currently connected Clients and version. This is the simplest method.
  • Or type in the name or IP address of the required Server computer, in the Insert the computer's name or it's IP address edit box or click the Network Servers... button below this field to use the Browse for Computer dialog to locate this computer’s name as you would in Windows Explorer.

Note: If the ServerPort setting of this Server is not 9000 (the default), then add a colon “:” after the specified name or IP address to specify this port number.

For instance, the following entries connect to a Server computer using a custom port of 9010: 'localhost:9010' or '10.10.10.124:9010'.

As follows, when connecting via the Internet:

Type in the web location of the SmartUI Server in the Insert the URL to connect to edit box.

This is the web site name and virtual folder specified when installing the SmartUI Web Service of this SmartUI Server as follows: http://webSiteName/virtualFolder

Tip: Click the Test Connection button to ensure that this SmartUI Server can be located at the specified address.

  1. Specify the User login details of the required user account on this Server computer, in the Name and Password edit boxes.

WARNING! ALWAYS specify these details, even if they to remain the SAME - otherwise this connection will FAIL.

Note: Ensure that the specified login details are correct and that this user account is either an allowed user or part of an allowed group on this SmartUI Server computer. For details, see Adding allowed users and groups.

  1. If necessary, open the Communication method list and select the required way in which you want to transfer data between the SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. and SmartUI Server, from the available options. For details on the differences between these communication methods, see About connection communication methods.

Note: The available method(s) depends upon the specified connection Type or how the two computers are physically connected.

  1. Click the Save Login Profile button, if you want to save these connections settings to a login profile, for future use when logging into this Client.

In this case, specify the required name for this profile in the displayed dialog. Try to keep the names less than 35 characters in size.

  1. Click Finish once these communication settings are complete.

Note: If necessary, check the Remember this connection as the default Connection checkbox to make this connection the default connection, which is used when logging into this SmartUI Client.

This SmartUI Client computer will then reconnect to the SmartUI Server using these settings.
