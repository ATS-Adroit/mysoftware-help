Disconnected connections

A disconnected connection is an existing connection whose SmartUI Server is currently unavailable, for whatever reason.

Note: If the default (login) SmartUI Server connection is disconnected when launching the SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. is unavailable, the launching fails until either this SmartUI Server becomes connected or you connect to another available SmartUI Server.

Connections are either identified in the Enterprise Manager of the SmartUI Designer or the Projects tool window of the SmartUI Operator, as follows:

  1. Disconnected connections are identified, by the following icon .

Note: A connection that is currently disconnected needs to be updated in order for the Client to determine whether this Server is available. For details, see Updating connections.

  1. Once this SmartUI Server becomes available, this connection will be identified, by the following icon .

    This icon indicates that the SmartUI Client is not logged in to the SmartUI Server.

    To remedy this, it is necessary to log onto this connection’s Server again. For details, see Modifying connection properties.

Note: This icon will always be displayed whenever the Client is not logged into the required connection’s Server.

  1. Once this SmartUI Server has been successfully logged in to, the connection will again be identified, by this icon and its data will be displayed.

Note: If any of the data on this Server, has been used to animate graphic forms or is mapped to virtual data elements, these values will automatically be fetched from the Server too.
