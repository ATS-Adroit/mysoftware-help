INeed interfaces object reference

INeed interfaces are made available to scripts to provide them access to the various components of the SmartUIServer and/or the Client.

For this reason, the INeed interfaces required by a script will depend upon whether it is required to interact with either the SmartUI Server or the Client or both of them. For details, see Working with INeed Interfaces.

SmartUI Scripting provides the following objects exposed to the Engine through the INeed interfaces:

Note: Clicking on the hyperlinks will move to the start of the object reference for the specified INeed interface.

Type: VIZNET.Shared.Interfaces.IConnection.
