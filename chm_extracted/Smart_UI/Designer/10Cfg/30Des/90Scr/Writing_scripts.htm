Writing scripts

Scripts are typically written within the script editor specified by the profile of the currently logged in user, which also specifies the default scripting language - either Microsoft Visual Basic.NET or Microsoft C# (CSharp). Click for more information:

Note: Graphic form scripts can be created and edited in the Graphic Form Script tool window.

When a script is initially created, default source code (text) is automatically added to it in the default scripting language, which provides the standard functions and other declarations.

For details on specifying the required scripting and debugging environment of the profile associated with the currently logged in user. For details, see Customizing default script editor.

For details on specifying the default scripting language in the user profile, see Customizing default scripting language.

Note1: It is also possible to change the language of the Script Editor and this default source code, if necessary. For details, see Changing scripting languages.

Note2: The onus rests upon the user to be familiar with these programming languages, since assistance with these languages is beyond the scope of this documentation. Articles related to scripting and converting scripts to the .NET Framework, are available on: http://msdn.microsoft.com; http://msdn.microsoft.com/netframework/ and http://www.codeproject.com

Scripts interact with the SmartUI Server and/or the Client through INeed interfaces, which provide programmatic access to their various components. For details, see Working with INeed Interfaces or INeed interfaces object reference.

Scripts can also provide additional functionality by adding references to external assemblies (.DLL files), whose properties, methods etc., are made available to this script and can be implemented within it. For details, see Managing references.

The script whether it interacts with the SmartUI Client and/or the Server always provides the following mandatory functions, which are also specified in the default source code:

  1. The Initialise function: This should contain any pre-execution configuration and variable definitions, since it is executed before the Main function.
  2. The Main function: Unlike other scripting languages this is the ONLY entry point that is provided to the script i.e. once this has finished executing the script will end, unless another process has been launched within it.
