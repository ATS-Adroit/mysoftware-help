Changing scripting languages

Scripts can either be written in Microsoft Visual Basic.NET or Microsoft C# (CSharp) scripting languages.

Typically the profile associated with the currently logged in user, specifies the default scripting language used when creating scripts in the SmartUI Designer. For details, see Customizing default scripting language.

However, you can change this language manually, if necessary, since the currently selected scripting language is used, as follows:

  • for compiling of the script and
  • for providing the default source code (text) that is automatically added to each new script to provide it with the standard functions and declarations.

Note: It should only be necessary to change the scripting language when creating a script, since its script object will store the selected language when it is saved. For details on scripts and their script objects in general, see Working with scripts.

To change the scripting language for a script in the Script Editor:

  1. If necessary, edit the required script.

If the Script Editor is displayed:

  1. Click on the Build menu and select the Languages menu.

The currently selected language will have a tick mark to the right of it.

  1. If necessary, select the required language, either Visual Basic.NET or CSharp.

Note: When the script it saved, its script object will save this language setting

 

Note: If the language of a new script has been changed, it is recommended to change the default text of the script to the selected language too.

WARNING! This will overwrite the currently displayed script with the default text for the currently selected language.

To reset the default text for the script in the Script Editor:

  1. If necessary, edit the required script.

If the Script Editor is displayed:

  1. If more than one script is opened, select the tab of the required script in the Editor workspace.
  2. Click on the Build menu and select the Languages menu.
  3. Select Reset Script Source.

WARNING! This will overwrite the currently displayed script with the default text for the currently selected language. If this is not required select No when the confirmation dialog is displayed.

  1. Click Yes, when the confirmation dialog is displayed; to replace the current text with default text.
