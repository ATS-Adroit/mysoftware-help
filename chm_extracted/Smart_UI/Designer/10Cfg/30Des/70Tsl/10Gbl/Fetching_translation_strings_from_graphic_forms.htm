Fetching translation strings from graphic forms

This allows you to populate the project translation table with unique graphic form and/or graphic form component strings, which you can extract directly from the one or more graphic forms, without having to type them in manually or import and export the translation tables.

Note: This will only obtain strings that are unique and that do not currently exist in the current project translation table.

To fetch translation/s from a graphic form translation table

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. Double-click its Translation object or its icon .

This displays the Translation configuration dialog, which can be maximised and/or manually resized as required.

  1. If necessary, add the required language first. For details, see Adding languages to projects.
  2. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Graphic Form tab.
  3. Click the Fetch button at the bottom of this tab to display the graphic form selection dialog.
  4. Select the graphic form/s or entire projects that contains one or more commonly used translatable strings and click the Finish button to display the list of these translatable strings.
  5. Ensure that only the checkboxes of the strings that you want to translate are checked and click Finish.

Tip: Checking or unchecking the checkbox in the language column heading selects or unselects all the checkboxes in this column.

This only imports the new unique strings into the project translation table and displays a summary of this string value importing process, displaying the number of imported and duplicate strings.

Any new translation strings are appended to the existing translation strings in the Graphic Form tab.

Note: Any languages specified by this graphic form translation table, that are not in the project translation table are automatically added.

  1. If necessary, click the Fetch button and select another graphic form and repeat this process until you have added all the graphic form translation strings you want to translate.
  2. Click the Finish button to close the project translation table.
