Browsing for data translation keys

Data element translation uses the Key column to translate textual data displayed by graphic forms for the current project.

Note: Each Key represents the full string value of a data element, this does not do partial string matches. In other words, only textual data elements (from any datasource) whose values EXACTLY match any of the Key column strings will be translated when the graphic form is displayed.

For example, you can specify the textual states of digital values, such as On or Off so that all of them that these states will be appropriately translated when they are displayed on a graphic form.

To browse for data translation string phrases or keys

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. Double-click its Translation object or its icon .

This displays the Translation configuration dialog, which can be maximised and/or manually resized as required.

  1. If necessary, add the required language first. For details, see Adding languages to projects.
  2. If necessary, selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Data tab.
  3. Click the browse button to the right of the required Key column entry to display the Data Element Browser dialog. For details on using this dialog to select data elements. see Working with the Data Element Browser.
  1. Click the Finish button when you have selected the required textual data element value.

This only imports textual (String) values and displays a summary of this string value importing process, displaying the number of imported and duplicate strings.

  1. If necessary configure other Key values and then click the Finish button when are done.

Bulk key browsing functionality provided for Adroit datasources:

When browsing for textual Adroitslots (values) , the following additional functionality is provided:

Wildcard agent notation:

You can specify the following wildcard notation: AdroitDatasourceName.TagName.*.slot to return all agents that contain this slot. For instance: Adroit.Analog.*.agentDescription

Note1: If a slot is a number or a date/time value then this is not added, since this value cannot be translated.

Note2: A warning is displayed if this operation involves more than 10 000 slots.

Automatically obtain alarm-specific strings for translation:

Either select the entire Alarm agent group or a specific Alarm agent to obtain all the translatable fields for the configured alarms, depending upon the associated agent type, as follows:

All agents assigned to the Alarm agent/s provide the following strings:

  • Alarm Type Messages: the messages displayed by the Alarm Type Message of the Alarm viewer for each alarm type of this agent.
  • The agentDescription slot, which is the textual description of each agent.

Each Digital agent also returns the following slots:

  • state0
  • state1

Each Marshal agent also returns the following slots:

  • [dig00]state0 … to [dig15]state0
  • [dig00]state1 … to [dig15]state1
  • [dig00]description … to [dig15]description)
