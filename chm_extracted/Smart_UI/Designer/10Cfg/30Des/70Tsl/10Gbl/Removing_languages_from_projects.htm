Removing languages from projects

Remove languages from the project translation table that are no longer required by the users of the graphic forms in this project.

To remove a language from a global translation table

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. Double-click its Translation object or its icon .

This displays the Translation configuration dialog, which can be maximised and/or manually resized as required.

  1. Right-click on the required column heading and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. Delete Language.

WARNING! This immediately removes the selected column from both the Graphic Form and Data tabs of the project translation table; therefore ensure that you select the correct column.

Note: You cannot remove the last language from the a project translation table.
