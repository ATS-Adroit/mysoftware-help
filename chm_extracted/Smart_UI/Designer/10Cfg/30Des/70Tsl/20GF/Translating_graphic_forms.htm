Translating graphic forms

Translate each graphic form by using its own local translation table by using the Translation tool window, which provides a number of columns. For further details about the various columns provided by this window, see Translation tool window.

When graphic forms are created the currently specified Graphic Form Language of the user profile of the user that created them becomes the primary or reference language of this graphic form used when importing other languages and CANNOT BE CHANGED. Any subsequent change to this user profile setting ONLY changes the preview language of the existing graphic forms (the language that used to display or preview the graphic form in the Designer).

By default, this is the language of the Windows operating system. For details on how to configure this user profile setting, see Customizing the primary translation language of new graphic forms and the display language of new and existing graphic forms.

Note:You can import existing translations from the project translation table; but we recommend that youPush (copy) translations, either entirely or selectively to the required graphic form/s from the project translation table. This automatically adds any languages to the graphic form translation tables that are missing. For details, see Pushing translations to graphic forms.

The following translation process is recommended:

  1. Ensure the translations for the Graphic Form Language column are correct (whose column header is bold and underlined), either manually or by using the Push operation for this graphic form from the project translation table. For details, see Editing translations within graphic forms.

IMPORTANT: CAUTION should be used when manually editing the entries of the Graphic Form Language column directly in the Translation window as this is the reference column when importing other languages.

Since ONLY the translation entries (rows) of the imported language are imported, whose Graphic Form Language column entries MATCH in BOTH the graphic form and project translation tables.

  1. By default a filter is applied to this translation table to hide all the uncommonly used translatable strings from view, if you need to translate these items to then you can turn this filter off. For details, see Filtering graphic form translation tables.
  2. Ensure that the graphic form translation table contains all the languages required by the end-users of this graphic form. For details, see Adding languages to graphic forms.

Note: The language that your users view the graphic form in, is determined by the Graphic Form Language setting of their associated user profile.

  1. If necessary, import the common translations that have been configured in the project translation table for the added languages; although this is NOT required if you have already performed a Push operation from the project translation table for this graphic form. For details, see Importing global project translations.
  2. Perform the necessary translation of this graphic form by adding any translations that are specific to this graphic form. For details, see Exporting and Importing graphic form translation tables.
  3. If necessary, change the language that this graphic form displays in the Designer (the Preview Languagecolumn, whose column header is bold) to see if the graphic form has been correctly translated. For details, see Specifying the previewed graphic form language.

Note: Only the entries of the Preview Language column entries are updated when the text properties of the graphic form components are directly edited. This is typically the Graphic Form Language column.

  1. If necessary, export the translations of any of the added languages to the project's global translation table, for use within other graphic forms. For details, see Exporting translations to the global project translation table.

 

For details about globally translating projects, see Globally translating projects.

For an overview of the process of translating or localizing projects and their graphic forms, see Working with graphic form translation.
