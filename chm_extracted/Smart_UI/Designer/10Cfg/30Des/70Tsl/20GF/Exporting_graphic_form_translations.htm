Exporting local graphic form translations to the project

You can export translations from the graphic form translation table (the Translation window) for the additional languages you have added (NOT from the Graphic Form Language column whose header is bold and underlined). This should only be performed when all or most of the textual strings of the Graphic Form Language column match those in the global project translation table.

IMPORTANT: ONLY the translation entries (rows) of the exported language are exported, whose Graphic Form Language column entries MATCH in BOTH the graphic form and project translation tables!

Note1: Any translations in the global translation table which do not exist in the Graphic Form Language column of this graphic form translation table will remain unchanged. 

Note2: You can only export ONE language of translations from the graphic form translation table at a time.

To export all the translations for an entire language

This assumes that you have added the required languages performed their translations.

  1. Ensure that the required graphic form is opened and displayed in the Design workspace.
  2. Ensure that the project translation table contains the Graphic Form Language column and that all or most of these textual strings match those in the global project translation table. This can be best achieved by using the Fetch operation of the project translation table for this graphic form. For details, see Fetching translation strings from graphic forms.
  3. Open the Translation tool window. .
  1. Right-click on the heading or one of the cell in this language column and select Export Language to Project Translation Table.

Note: You cannot export the Graphic Form Language column, hence this command is not provided by it.

ONLY the translation entries (rows) of the exported language are exported, whose Graphic Form Language column entries MATCH in BOTH the graphic form and project translation tables.

This will display a confirmation dialog, that displays the success or failure of this export operation.

  1. Click the Finish button to close the translation table.

For details on using these translations in other graphic forms of this project, see Importing global project translations or Pushing translations to graphic forms.
