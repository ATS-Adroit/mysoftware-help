Editing translations within graphic forms

You can manually edit the values of existing translations in the graphic form translation table.

IMPORTANT: CAUTION should be used when manually editing the entries of the Graphic Form Language column directly in the Translation window as this is the reference column when importing other languages.

Since ONLY the translation entries (rows) of the imported language are imported, whose Graphic Form Language column entries MATCH in BOTH the graphic form and project translation tables.

Therefore, it is recommended that you Push (copy) translations, either entirely or selectively to the required graphic form/s from the project translation table. This automatically adds any languages to the graphic form translation tables that are missing. For details, see Pushing translations to graphic forms.

To edit a translation in a graphic form translation table

  1. Ensure that the required graphic form is opened and displayed in the Design workspace.
  2. Open the Translation tool window.
  3. If necessary, add the required language first. For details, see Adding languages to graphic forms.
  4. Double-click the cell you wish to edit, in the required language column.
  5. When the flashing cursor appears at the end of the current text, perform the necessary editing.

Tip: If special characters are required for a language, then install the required input locale and use the required keyboard. For details, see Adding input locales.

  1. Either press the ENTER key or click in another cell to continue translating or click the Finish button to close the translation table.
