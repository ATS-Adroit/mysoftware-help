Status indicators provided by electrical equipment graphics

The SCADA graphical representations provided by each electrical equipment template, provide the following status indicators so that operators can immediately see which operational mode this equipment is in:

Hand (Manual): In this manual control mode, the equipment is manually controlled from either the SCADA or from the field (plant floor).

Simulation: In this testing mode, the associated function block works in the PLC, but does not set any outputs.

Maintenance: In this manual control mode, the equipment is manually controlled from the SCADA and ALSO bypasses any process interlocks.

Note1: The SAME status indicators are also used by the associated faceplate to indicate these operational modes.

Note2: If neither of these operational modes are specified then this equipment is in Automatic (PLC) control
