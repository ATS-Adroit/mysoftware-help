Properties of each hierarchy level (component) of a MAPS project

Note: In Adroit all MAPS-related PLC functionality is disabled.

Each hierarchy level or component of a MAPS project provides its own right click Properties item that can configure certain of its settings EXCEPT its name, such as viewing or changing its Description.

Note: The Description is typically used by the tooltip of the specific component in the tree, equipment descriptions are also added as comments to the PLC program.

Click the following components to display the most important tasks/settings you can achieve by editing/viewing its properties:

Projects : to specify where the PLC projects are saved and those that affect the MAPS reports and other project-specific settings.

  • Project Path: specifies where the following items are saved:
  • the generated project reports, in the Reports sub-folder,
  • the generated project reports, in the Documents sub-folder,
  • Default Project Report: specifies the path and name of the report template used for the project reports. If this is BLANK, the default setting, then the GENERIC project report template is used.

The GENERIC project report template provides the S88/S95 hierarchy, which includes the following separate lists of each hierarchy level:

  • A list of the configured Plant Areas and their settings.
  • A list of the configured PLCs (Process Cells) and their settings.
  • A list of the configured Units and their settings.
  • A list of each configured item of equipment and their signals.

Tip: You can customise this GENERIC project report template, for example, by adding your company logo to its title. For details, see Customizing report templates.   

  • MAPS Reporting Database SQL Connection String: if you want to use some or all of the Adroit Reporting Suite reports to analyse your Adroit alarming data to improve your alarming configuration and/or record any value that an operator manually changes for auditing purposes, then do the following:
  • manually create an empty SQL (SQL 2008 R2 with Advanced Services) database, typically via the SQL Server Management utility (which is installed by the SQL 2008 R2 with Advanced Services installation) and

  • specify the connection string to this database here, typically by clicking the browse button to the right of the MAPS Reporting Database SQL Connection String field and then use the displayed Connection Properties dialog to connect to this SQL database.

    Typically do NOT change the Data source from the default of .NET Framework Data Provider for OLE DB, unless you are connecting to a SQL Compact database. More details: in which case, click the Change... button and choose the datasource that corresponds to the correct version of SQL Compact and then the dialog will change so that you only need to browse in the required database file and specify the required password, if any.

Once this database is specified, then you can right click the MAPS Project in the Enterprise Manager and select the Create Adroit Report Suite right click command, which creates the following agents for this MAPS project: an AlarmManagement, an Audit agent and a DBLog agent, which are configured as follows:

  • The AlarmManagement agent re-creates the S88 MAPS structure of your project for all the alarmed tags.

IMPORTANT: You need to purchase a separate license for the Adroit AlarmManagement agent before you can use this agent to log your alarming data, which you can analyse using the Alarm Management reports.

  • The Audit agent adds all the tags that are output enabled, so that any Operator change in value is audited (logged to this database) for later analysis.
  • The DBLog agent is enabled to start logging and all the agent values logged by the MAPS Templates of this project are also logged to this SQL database.

The names of these created agents use the specified MAPS project name and the specific agent type name. For instance, if the MAPS project name is MYPROJ then the following three agents are created: MYPROJ_AMA, MYPROJ_AUDIT and MYPROJ_DBLOG.

Then after installing the required reports of the Adroit Report Suite you can use them to analyse your alarms and/or audited items and/or the agent values logged by the DBLog agent.

  • Default Operator GF: Browse for the graphic form of this MAPS project that the Operator view should display by default. Typically the Operator view graphic form displays the plant area graphic form. But you can specify a unit or Custom graphic form instead.

    • Since one of the purposes of the Operator View, which is generated by each MAPS project, is to provide navigation through the defined plant areas, PLCs, units and equipment, MAPS projects allow you to Select Operator View Layout, as follows:

    1. Advanced: this view provides a navigational structure of different panes, which each provide buttons that display the available plant areas, PLCs, units and equipment defined in your MAPS project.

      Note: This view is more visually appealing and allows your operators to customise this view by hiding or showing the different panes, as needed.

    2. Simple: this view uses menus and sub menus to navigate through the available plant areas, PLCs, units and equipment defined in your MAPS project.

      Note: This view provides the same functionality as the Advanced view only in a simpler navigational format.

  • Default Screen size: Specify the required screen resolution of ALL the graphic forms of your MAPS project, by selecting the required screen dimensions, in pixels, from the list.

    MAPS then automatically adjusts the size of ALL your graphic forms in this project to fit onto the selected screen resolution.

  • Show Equipment Title: specify whether you want to display or hide the names of your equipment on the graphic forms, by checking or unchecking the Show Equipment Title checkbox, which is checked (displayed) by default. Typically you will hide these equipment names to unclutter their graphic forms or when these names only serve to confuse your operators.
  • Database version: For troubleshooting purposes the installed version of the MAPS database is displayed at the bottom of the MAPS Project Properties dialog.

    • Areas : to configure the associated plant area code, SmartUI Server and Adroit Agent Server

    • Plant Area Code: an OPTIONAL (unique 5-character alphanumeric) code becomes the prefix that is used for all the equipment items that you add to this plant area.

    Note: If you change this code, this will ONLY affect the equipment that you add from this point onward.

    Tip: The use of this code is recommended as it helps to ensure unique and identifiable tag names in the project, that allow you to easily differentiate your plant equipment.

    • The first of the Plant Area Settings, specifies the SmartUI Server Name, which is Defaultwhen this specifies the LOCAL SmartUI Server.

    If necessary, you can specify a remote SmartUI Server, as follows: if you have more than one SmartUI Servers on your network (and their BroadcastEnabled setting is TRUE), then their SmartUI Server names will also appear in this list (in the following format: [ComputerName] Literal Server Name) - simply select the name of the required remote SmartUI Server from the list.

    Typically this SmartUI Server provides a connection to a single Agent Server that contains the SCADA tags for this plant area.

    • Check the Advanced checkbox, if you have MORE THAN ONE Agent Server connected to a SmartUI server to display the Agent Server column and use this column to specify which Agent Server this plant Area should use.
    • Offline: When the Agent Server does not exist or is not available - in this case you are unable to create or synchronise tags.

    Note: If the Agent Server is specified as being Offline then you need to type in an appropriate Adroit Device name when configuring the PLCs.

    • The name of the required Adroit datasource - the connection that is made to an Agent Server from the specified SmartUI Server.

    Note: This is the name of the connection to the Agent Server as specified in the SmartUI Server and is NOT necessarily the name of the Agent Server as it is specified inAdroit.

    PLCs : to specify the name of the associated Adroit device; to allocate the free IO when adding or removing equipment and to specify the correct start and end addresses for each IO type. 

    • Adroit Device Name: specify the name of the PLC device, that has been added to the Agent Server of this PLC's plant Area, which is configured to communicate to this PLC in the field. For details on adding and configuring devices, see Creating and configuring PLC devices in Adroit.

     

    Unit : Only allows you to view or change its description.

     

    Equipment or : to change the SCADA graphic used to represent this item of equipment

    To change the SCADA graphic used to represent this item of equipment:

    1. Right click the required item of electrical or instrumentation equipment and select Properties.
    2. Specify the SCADA graphical representation for this equipment from the Graphic Name list, by clicking the list button (on the left) and selecting the appropriate image (and its orientation) from the list provided by the selected MAPS template.
    3. Click the OK button.
    4. Right click the applicable unit and select Update Graphic.

    To update this unit graphic form with these changes.

    Note: If you edit/view the Properties of equipment that use the default name, the XXXX section to this default is changed to the name of the applicable MAPS template.
