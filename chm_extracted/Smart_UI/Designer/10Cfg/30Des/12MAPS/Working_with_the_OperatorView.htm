Working with the OperatorView

The Operator view graphic form is used by your operators to view and control your process site (MAPS project).

Since one of the purposes of the Operator View, which is generated by each MAPS project, is to provide navigation through the defined plant areas, PLCs, units and equipment, MAPS projects allow you to Select Operator View Layout, as follows:

  1. Advanced: this view provides a navigational structure of different panes, which each provide buttons that display the available plant areas, PLCs, units and equipment defined in your MAPS project.

    Note: This view is more visually appealing and allows your operators to customise this view by hiding or showing the different panes, as needed.

  2. Simple: this view uses menus and sub menus to navigate through the available plant areas, PLCs, units and equipment defined in your MAPS project.

    Note: This view provides the same functionality as the Advanced view only in a simpler navigational format.

This provides a navigational structure of different panes, which each provide buttons that display the available plant areas, PLCs, units and equipment defined in your MAPS project. Your operators can navigate between these graphic forms by using these buttons.

IMPORTANT: This navigation structure is ONLY generated and/or updated when you run the Build Operator View command.

Therefore, after adding Custom graphic forms to your project, right click the MAPS project and select the Build Project option and in the dialog ONLY check the Build Operator View checkbox and click Finish. This will automatically includes these Custom graphic forms in the navigational menus of the Operator view graphic form.

Click for more details on what the Build Operator View option saves:

The Build Operator View option, saves:

  • all the default and custom graphic forms created for the MAPS project, so that these are included in the navigational buttons provided by the Operator view graphic form.

  • the MAPS database structure for this MAPS project so that your operators can continue to control the plant even if the SQL Server is shutdown (or when this MAPS database is inaccessible).

    Since the hierarchical structure presented in the MAPS window, is actually saved to and maintained by the MAPS SQL database.

Note: You can ALSO use the Manage Operator View SmartUI project right click option to specify exactly which graphic forms you want to display in the Operator view graphic forms, by checking or unchecking their checkboxes in the Manage Operator View dialog.

Typically this is required if you create Custom graphic forms for your project and need to hide the default graphic forms automatically generated by the project.

By default the Operator view graphic form displays the plant area graphic form. But you can change this default graphic form by configuring the Default Operator GF MAPS project property (right click the project and select Properties).

 

This graphic form is saved in the root of the MAPS Project folder and its name is prefixed by MAPS Project name followed by '_OperatorView' e.g. MY_PROJECT_OperatorView.

Open this Operator view graphic form in the SmartUI Operator, this graphic form also provides the following menu structure:

  • Use the Tools menu to save a 'workspace', which saves the positions of the various tool windows and the View settings (i.e which are hidden or displayed) and which graphic form is opened by default for the current operator. Click for more details:
  • Save Workspace: This saves the positions of the various tool windows and the View settings (i.e which are hidden or displayed) and which graphic form is opened for the current operator.
  • Reset Workspace: This overwrites your saved workspace with the default workspace settings.
  • Load Workspace: To return your workspace settings to that of the saved workspace.
  • Use the View menu to select which components you want to display or hide to increase the viewing area for the other components.

When viewing the unit graphic forms that display your equipment, click on the graphical representation of an item of equipment, to display its intelligent faceplate..
