Synchronizing SCADA tags

When you assign a MAPS template to an item of electrical or instrumentation equipment the SCADA tags representing the various signals, of the associated function block are added to the MAPS database.

But these SCADA tags are ONLY added to the Adroit SCADA when you synchronise the MAPS database with the Adroit SCADA. Typically you need to perform this SCADA tag synchronization:

  • after you have created the MAPS project using MAPS-1Engineer or when using the MAPS project wizard, if you chose NOT to check the Create tags checkbox for any item of equipment.
  • after adding or removing any equipment to/from the created MAPS project

This process ensures that there are NO differences between the SCADA tags in the MAPS database and in the Adroit SCADA.

IMPORTANT: You need to start the relevant Adroit Agent Server applications before you can Sync Tags.

Note: In addition to adding the SCADA tags to Adroit this also performs the necessary SCADA configuration, as specified by the associated MAPS template, such as scanning, logging, alarming and/or trending these tags.

How to synchronise the SCADA tags in the MAPS database and in the Adroit SCADA:

Tip: If necessary, you can now perform the Sync Tags process in silent mode, if you choose to do so then all confirmation dialogs normally displayed during this process are hidden and you are only presented with the final dialog showing the success or failure of this process.

When creating a MAPS project, each plant Area has an associated Adroit Agent Server that contains the SCADA tags for the equipment within this plant Area.

So you will typically:

  1. Synchronise the SCADA tags in a specific plant area, as follows:

Tip: This is recommended after adding/removing equipment to/from a number of units in a specific plant area

In the MAPS window, right click the required plant Area of the MAPS project and select Sync Tags.

  1. Synchronise the SCADA tags in a specific unit, as follows:

Tip: This is recommended after adding/removing multiple equipment to/from a single unit - so that you ONLY need to synchronises this specific unit and not the entire plant area.

In the MAPS window, right click the required unit of the MAPS project and select Sync Tags.

Note: You can also select the Sync Tags right click option for each electrical or instrumentation equipment that you add.

 

The Sync Tags command displays a splash screen, at the bottom of which you can see the total number of equipment whose tags need to be synchronised and as each item of equipment is analysed, the tag differences are displayed here too.

Note: Depending upon the number of equipment, this process can take some time.

Once the tag synchronization process is finished, the Tag Data dialog is displayed so that you can see which SCADA tags need to be added or removed to/from Adroit.

If you are happy with this result, click Finish to add (and perform the SCADA configuration dictated by the respective MAPS template, such as scanning, logging, alarming and/or trending) or remove the SCADA tags; otherwise click Cancel to abort this operation.

Note: Depending upon the number of tags, this process can take some time.
