Backing up and restoring MAPS projects

You can backup your MAPS projects for safe keeping and/or to move them to another Server and restore them later.

To backup a project:

  1. Right click the required MAPS project in the MAPS window and select the Backup option.

    This creates a copy of your MAPS project and a compressed .ZIP file, whose file name is the date and project name, e.g. 6-14-2011_ACME.zip.

  2. Both this ZIP file and the copy of your MAPS project folder, is saved to the MAPS project path that you specified when creating the project. Typically this is C:\MAPS\ProjectBackups\YourProjectName.

To restore a previously backed up project:

  1. Right click on the MAPS root node of the MAPS window and select the Restore option.
  2. Select the .ZIP file of the required MAPS project that you want to restore.

This will restore this project, if it does not already exist.
