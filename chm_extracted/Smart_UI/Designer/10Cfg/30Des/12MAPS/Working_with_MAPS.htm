Working with MAPS

New Adroit 10 Features

Note: In Adroit all MAPS-related PLC functionality is disabled.

Tip:  If you cannot find what you are looking for in the help file, consult the online forum, which you can access from this URL: http://adroittechnologiesautomation.com

How MAPS implements the S88 / S95 hierarchy: how MAPS implements and enforces an extended physical model of the hierarchical structure specified by the ISA S88 and S95 standards.

Creating a SmartUI project essentially involves assigning a SmartUI template to your electrical and instrumentation equipment.

  • Electrical equipment templates: lists these SmartUI templates and describes their functionality.
  • Instrumentation equipment templates: lists these SmartUI templates and describes their functionality.

After creating a project, you need to:

  • Build the SCADA views: if necessary generate the SCADA tags and construct the views of your process by organizing the equipment graphics and adding the necessary static elements.

Note: This updates the OperatorView, which provides navigation to the other SCADA views and allows your operators to view and control your process site (MAPS project). For details, see Working with the OperatorView.

Tip: Add a FileBrowser control to allow SmartUI users to display to view, edit, upload and/or delete documents pertaining to ALL the ISA S88 / S95 hierarchical levels of your MAPS project or to simply view the documents within a specific folder on the SmartUI Server computer. For details, see FileBrowser controls.

The MAPS project allows you to generate the following reports to help you manage your automation project more effectively:

  • Project report: provides the S88/S95 hierarchy and also includes the following separate lists of each hierarchy level:
    • A list of the configured Plant Areas and their settings.
    • A list of the configured PLCs (Process Cells) and their settings.
    • A list of the configured Units and their settings.
    • A list of each configured item of equipment and their signals.

Tip: You can customise the GENERIC project report template, for example, by adding your company logo to its title. For details, see Customizing report templates.  

Other things you may need to do after creating a MAPS project:

Tip: Each right click option in the MAPS window provides a tool-tip explaining its function - just hold your mouse pointer over it for quick reference.

  • Adding components to an EXISTING MAPS project: while you can add plant areas, PLCs, units and equipment to an existing MAPS project, you should typically only need to add the occasional unit or item of electrical and/or instrumentation equipment.
  • Synchronizing SCADA tags: to ensure that the SCADA tags of any equipment that is added/removed from the MAPS project are ALSO added/removed from Adroit SCADA - by synchronizing the MAPS database with the Adroit SCADA.
  • Changing component properties: each hierarchy level or component of a MAPS project provides its own right click Properties item to configure its settings EXCEPT its name, this describes the important properties and/or describes some of the tasks that can be achieved by using these properties.
  • Updating unit graphic forms: required if you change the SCADA graphic of your equipment by editing their properties.
  • Rebuilding graphics: if you corrupt or make a mistake when configuring the standard graphic form/s and need to reset them to their default configuration.
  • Backing up and Restoring MAPS projects: you can backup your MAPS projects for safe keeping and/or to move them to another Server and restore them later.
  • Deleting a MAPS project: if you have made a mistake when (bulk or manually) configuring your MAPS project or need to remove a test project.
