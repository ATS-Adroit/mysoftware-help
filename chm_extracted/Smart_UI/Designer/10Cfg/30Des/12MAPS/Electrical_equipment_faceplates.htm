Electrical equipment faceplates

Each electrical equipment template provides an intelligent equipment-specific faceplate, accessed by clicking its graphical representation.

The Home () faceplate page is launched by default and provides the following:

Example:

  • The name of this item of electrical equipment at the top.
  • The left Status section contains the following items:
    • The associated ISO 14617 representation, if one exists for this item of equipment
    • One or more of the following status indicators and their meanings:

    Operating mode: Automatic (PLC) control or Field-based control and/or Hand (Manual control)

    Warning (a fault or alarm)

    Interlock (a safety, process and/or start interlock is in effect)

    Simulation (PLC function block works but does not start the equipment)

    Maintenance (manual control with PLC control interlocks overridden)

    • One or more common equipment-specific interlocks and/or faults
  • The top right panel, allows one to change how this item of equipment is controlled and, if necessary, operate this equipment, as follows:
    • The Control Mode section:

    Auto: The equipment is controlled by the PLC.

    Manual: In this control mode, the Desk / Field section determines where this item of equipment is being controlled from.

    • The Desk / Field section: only applies if the Manual control mode is being used, in which case it specifies where this item of equipment is being controlled from, as follows:

    Desk: This equipment is controlled from the SCADA.

    Field: This equipment is controlled via the on/off switch in the field (plant floor).  

    • The Operation section: only applies for the Desk (SCADA) control method, in which case, the equipment can be turned on and off.

The bottom right panel provides the Reset button, which clears all the warnings/errors for this equipment, and one or more of the following buttons that open and close other windows:

: Displays the AlarmEvent page to view any alarms or events associated with this item of equipment.

: Displays any trends associated with this item of equipment.

: Displays the Setup page to change this item of equipment into Simulation or Maintenance modes and to view/set other equipment-specific values, such as alarm limits etc. 

  • Simulation: a testing mode, where the associated function block works in the PLC, but does not set any outputs. For instance, you can use this mode to safely test the whole startup process of a motor.
  •  Maintenance: an manual operational mode in which this equipment bypasses any process interlocks.
