Creating MAPS projects

As mentioned in the overview, MAPS provides a more structured approach to automation projects, such as the adherence to an extended physical model of the S88/S95 hierarchical structure and the need for the engineers to PLAN the following BEFORE creating a MAPS project:

  • Create a complete schedule of all the electrical and instrumentation equipment required in the plant, which is organised according an extended physical model of the hierarchical structure specified by the ISA S88 and S95 standards. For more details, see How SmartUI implements the S88 / S95 hierarchy.

Note: You CANNOT rename the MAPS project names or ANY of the component hierarchy level names once they are specified.

  • Use the MAPS Project Wizard in the SmartUI Designer to manually create your MAPS project. See How to use the MAPS project wizard to add a MAPS project.

Advantage:

  • Being an interactive wizard (series of dialogs), each step of the project performs its own error checking, so any mistakes that you make are immediately picked up and need to be addressed before you can continue.
  • This provides a “first principal” approach of using the MAPS Project Wizard, showing how MAPS uses the S88/S95 extended physical model hierarchy to organise equipment.

 

Each MAPS project, generates the following:

  • a complete SCADA project built using the Adroit SCADA product, which includes the following:
  • All mimics in structured format containing selected graphic objects. Each graphic object has associated faceplates to deliver further management capability.
  • Logging and Alarming configured using templates
