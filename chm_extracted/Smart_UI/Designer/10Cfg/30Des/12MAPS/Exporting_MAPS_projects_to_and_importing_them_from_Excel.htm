Exporting MAPS projects to and importing them from Excel

The main purpose or use of this Export to / Import from Excel functionality is to allow you to bulk configure your MAPS project after creating it using the MAPS project wizard.

For instance, when creating a plant with 100 conveyors, it may be useful to add one conveyor using the MAPS project wizard and then export the project and bulk configure the other 99 conveyors in Excel and then import this modified project.

Note: You need Microsoft Excel 2003 or later installed before you can use this functionality.

Tip: We recommend that you first use the MAPS Project wizard to create at least one Plant Area, PLC, Unit and Equipment – to understand the required syntax and requirements for the fields on each of the worksheets of this Excel file.

To export a project to Excel:

  1. Right click the required MAPS project in the MAPS window and select the Export to Excel option.

  2. Specify the path and file name of the required Microsoft Excel Spreadsheet (.xls file).

    This creates and populates a separate worksheet for each hierarchical component of this MAPSproject.

Note: If you make mistakes during the editing process, the Excel spreadsheet is analysed before the importing occurs and detailed feedback is provided on all mistakes that have been made.

To import a previously exported project:

  1. Right click on the MAPS root node of the MAPS window and select the Import from Excel option.

    This displays the Import from Excel dialog, which you configure as follows:

  2. In the Excel file path field, browse for (specify) the path and file name of the required Microsoft Excel Spreadsheet (.xls file) that contains the required MAPS project that you want create or update.

    Tip: We recommend that you click the Test Excel file configuration button, click for more details: this parses the specified Excel file and ensures that it has been correctly configured (is error free) before doing the import or to report any errors found so that these can be fixed. This step is automatically performed before the import occurs.

  3. Choose whether you want to:

  • Create an entirely new project from the configuration of this Excel file:

    In this case, select the Create new project option and then provide its unique Name and Description.

    MAPS automatically performs the Initialise project, Build Operator View and Rebuild All Graphics tasks, after the specified Excel file is successfully imported, therefore these options are disabled.

    You can choose whether you want to Create Tags after the import is successful, by checking this option which performs a Sync Tag operation…

  • Overwrite an existing project with the configuration of this Excel file:

    In this case, select the Overwrite an existing project option and the required MAPS project from the combo box.

    MAPS automatically performs the Initialise project and Create Tags after the import is successful tasks, after the specified Excel file is successfully imported, therefore these options are disabled.

    However, you can choose whether you want to Build Operator View and Rebuild All Graphics.

    Typically you only need to Build Operator View if you have added an extra Plant Area or PLC or Unit.

    However, in general we recommend that you do NOT Rebuild All Graphics as this overwrites ALL the changes you have made to the default graphic forms. So if you only need to update a few of your Unit graphic forms, then use their Update Graphic right click menu option to do this instead.
