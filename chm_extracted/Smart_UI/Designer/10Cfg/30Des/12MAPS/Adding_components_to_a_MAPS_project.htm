Adding components to a MAPS project

Each component in a MAPS project provides a right click option that allows you to add a sub-component to it.

For example, you can add a plant Area to the MAPS project or a PLC to a plant Area; however you SHOULD have PLANNED for these higher level components already BEFORE creating a MAPS project. For more details, see How to use the MAPS project wizard to add a MAPS project.

You may however, need to add:

  • a unita logical grouping of the electrical and/or instrumentation equipment within a PLC  to a PLC - to represent a complex item of equipment that consists of more than one items of electrical and/or instrumentation equipment, such as a conveyor or
  • an item of electrical or instrumentation equipment to a unit .

BEFOREadding equipment to an existing project (either by adding units or individual items of equipment), ensure that you update the Last Used address for the IO types of the relevant PLC, by clicking the Get Last Used button in the PLC Settings table of the PLC properties.

This ensures that when SmartUI allocates the IO that you do NOT get duplicate addresses being allocated. For details of the other PLC properties and the properties of the other project components, see Properties of each hierarchy level (component) of a MAPS project.

Note: Also do this when REMOVING equipment, to ensure that you do not have ‘holes’ in your allocated addressing and use all the freed up IO.

 

How to add a unit to a PLC of a MAPS project:

  1. In the MAPS window, right click the required PLC and select Add Unit.

The Add unit wizard should open, in which you specify the required Name and Description of this unit and then click Next.

WARNING! You CANNOT rename this unit name.

  1. Specify ALL the types of electrical equipment and their quantities as required for this site (MAPS project) in the Electrical Data page.

Note: You will only advance to the Electrical Data page once all the MANDATORY fields are correctly completed for all the added units.

In MAPS, each type of electrical equipment requires an associated MAPS template. For more details, see Electrical equipment templates.

In the case of complex items of equipment that consist of more than one piece of electrical and/or instrumentation equipment, like conveyors - create a Unit for this item of equipment and associate all the component electrical equipment to MAPS templates.

The Electrical Data page opens so that you can specify the required quantities of MAPS templates to represent your electrical equipment within this process site (MAPS project). Add a row to the Electrical Data table for each type of MAPS template that you need and complete the following fields:  

  • Select the MANDATORY Template Name for this type of electrical equipment from the list.

Default Electrical equipment templates: the electrical equipment templates

Once a template is selected, click the Template Description field to display a description of exactly which type of electrical equipment this MAPS template represents.

  • Specify the MANDATORY Quantity of this type of electrical equipment.

This should specify the TOTAL number of this type of electrical equipment with the entire process site (MAPS project).

WARNING! Once you click the Next button, you are UNABLE to return to this page again, so ensure that this is correctly specified.

Tip: If your estimation is NOT exact, you can always add other MAPS templates manually. 

  1. Click Next to configure each item of electrical equipment in the Electrical Detail Data page.

Note: You will only advance to the Electrical Detail Data page when quantities are specified for all the added electrical equipment templates.

The Electrical Detail Data page opens so that you can configure the individual items of electrical equipment of this process site (MAPS project). Each row of the Electrical Equipment Detail Data table represents an item of electrical equipment that is associated to a MAPS template, which requires the configuration of the following fields:

By default, the quantities of each MAPS electrical equipment template, as specified in the Electrical Data page, are added as individual rows.

Note: Rows can be manually added and configured from scratch, if you need additional items of electrical equipment.

  • The MANDATORY Template Name is the MAPS template that represents this item of electrical equipment (or one of its electrical equipment sub-components in the case of complex equipment).
  • Specify the MANDATORY Unit Name (logical grouping) to which this electrical item of equipment belongs.
  • Specify the MANDATORY Name of this item of electrical equipment, which is used to identify this item of equipment in the SCADA and PLC. By default, the following suggested naming format is provided: a name that is prefixed by the specified plant area code (if any) and an incrementing counter as a suffix.

WARNING! You CANNOT rename this equipment name.

Note: Do not rely on the uniqueness of the specified suffix, if you manually add rows this suffix resets itself to 0001.

Tip: If you specify any duplicate equipment names, these are flagged (one-by-one) when you click the Next button, so that you can correct these.

  • Specify a MANDATORY Description for this item of electrical equipment, which describes its function or purpose.
  • Specify the MANDATORY Graphic that represents this item of electrical equipment in the SCADA representation of this unit. The available graphical representations depend upon the selected template. For details, see Electrical equipment templates.

Typically the provided template graphics will always list one or more ISO representations (of the associated ISO 14617 symbol, if one exists for this item of equipment) at the top of the list, which may be followed by one or more physical representations of this item of equipment.

Ensure that you select the graphical representation, which provides the required orientation of this item of equipment.

Note: To change the Graphic after you have selected it - highlight the name of the selected graphic and press the DELETE key, then the list box appears so that you can choose another graphic.

  • If necessary, check the Create tags checkbox to create the necessary SCADA tags in Adroit for this item of equipment and to perform any other necessary SCADA configuration required by this template, such as scanning, logging, alarming and/or trending.

Note: If you check the Create tags checkbox, this will increase the time required to create the SmartUI project.

If you do NOT check the Create tags checkbox for this item of equipment, then AFTER finishing this wizard, select the Sync tags right click option for this MAPS project in the MAPS window. 

  1. Click Next and specify ALL the types of instrumentation equipment and their quantities as required for this site (MAPS project) in the Instrumentation Data page.

Note: You will only advance to the Instrumentation Data page once all the MANDATORY fields are correctly completed for your electrical equipment and all of their names are unique.

In MAPS, each type of instrumentation equipment requires an associated MAPS template. For more details, see Instrumentation equipment templates.

In the case of complex items of equipment that consist of more than one piece of instrumentation and/or electrical equipment, like conveyors - create a Unit for this item of equipment and associate all the component instrumentation equipment to MAPS templates.

The Instrumentation Data page opens so that you can specify the required quantities of MAPS templates to represent your electrical equipment within this process site (MAPS project). Add a row to the Instrumentation Data table for each type of MAPS template that you need and complete the following fields:  

  • Select the MANDATORY Template Name for this type of instrumentation equipment from the list.

Default Instrumentation equipment templates: the instrumentation equipment templates

Once a template is selected, click the Template Description field to display a description of exactly which type of instrumentation equipment this MAPS template represents.

  • Specify the MANDATORY Quantity of this type of instrumentation equipment.

This should specify the TOTAL number of this type of instrumentation equipment with the entire process site (MAPS project).

WARNING! Once you click the Next button, you are UNABLE to return to this page again, so ensure that this is correctly specified.

Tip: If your estimation is NOT exact, you can always add other MAPS templates manually. 

  1. Click Next to configure each item of instrumentation equipment in the Instrumentation Detail Data page.

Note: You will only advance to the Instrumentation Detail Data page when quantities are specified for all the added instrumentation equipment templates.

The Instrumentation Detail Data page opens so that you can configure the individual items of instrumentation equipment of this process site (MAPS project). Each row of the Instrumentation Equipment Detail Data table represents an item of instrumentation equipment that is associated to a MAPS template, which requires the configuration of the following fields:

By default, the quantities of each MAPS instrumentation equipment template, as specified in the Instrumentation Data page, are added as individual rows.

Note: Rows can be manually added and configured from scratch, if you need additional items of instrumentation equipment.

  • The MANDATORY Template Name is the MAPS template that represents this item of instrumentation equipment (or one of its instrumentation equipment sub-components in the case of complex equipment).
  • Specify the MANDATORY Unit Name (logical grouping) to which this instrumentation item of equipment belongs.
  • Specify the MANDATORY Name of this item of instrumentation equipment, which is used to identify this item of equipment in the SCADA and PLC. By default, the following suggested naming format is provided: a name that is prefixed by the specified plant area code (if any) and an incrementing counter as a suffix.

WARNING! You CANNOT rename this equipment name.

Note: Do not rely on the uniqueness of the specified suffix, if you manually add rows this suffix resets itself to 0001.

Tip: If you specify any duplicate equipment names, these are flagged (one-by-one) when you click the Next button, so that you can correct these.

  • Specify a MANDATORY Description for this item of instrumentation equipment, which describes its function or purpose.
  • Specify the MANDATORY Graphic that represents this item of instrumentation equipment in the SCADA representation of this unit - therefore ensure that you select the graphic that provides the required orientation of this graphic. The available graphical representations depend upon the selected template. For details, see Electrical equipment templates.

Typically the provided template graphics will always list one or more ISO representations (of the associated ISO 14617 symbol, if one exists for this item of equipment) at the top of the list, which may be followed by one or more physical representations of this item of equipment with different orientations.

Note: To change the Graphic after you have selected it - highlight the name of the selected graphic and press the DELETE key, then the list box appears so that you can choose another graphic.

  • If necessary, check the Create tags checkbox to create the necessary SCADA tags in Adroit for this item of equipment and to perform any other necessary SCADA configuration required by this template, such as scanning, logging, alarming and/or trending.

Note: If you check the Create tags checkbox, this will increase the time required to create the MAPS project.

If you do NOT check the Create tags checkbox for this item of equipment, then AFTER finishing this wizard, select the Sync tags right click option for this MAPS project in the MAPS window. 

  1. Click Finish to add this unit and its equipment to this MAPS project.

IMPORTANT: If you selected the Create tags checkbox for any electrical or instrumentation equipment, then you need to START the relevant Adroit AGENT SERVER applications BEFORE you CLICK the Finish button so that this process can occur.

If you selected the Create tags checkbox for any electrical or instrumentation equipment, then their associated SCADA tags are created and any other necessary SCADA configuration is performed.

If you chose NOT to check the Create tags checkbox for any item of equipment, then right click this unit and select Sync Tags (see MAPS Project options) and when the Tag Data dialog is displayed click Finish.
