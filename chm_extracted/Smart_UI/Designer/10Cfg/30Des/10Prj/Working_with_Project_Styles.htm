Working with Project Styles

When creating a project, you can choose to associate either a predefined or custom style to the project, which creates a hidden graphic form, called !Style, which configures the following common graphic form display properties to save you design time and ensure a consistent look and feel:

  • size: their physical dimensions, specified in pixels: either select a Predefined width and height, which specify common monitor resolutions or specify your own Custom dimensions.
  • The Backcolor and Forecolor of the graphic form.

Note: Depending on the controls that you add to this graphic form, they may inherit the specified Backcolor.

  • The default Font of the graphic form and any controls that you add to this graphic form.

Note: After applying a style to a project you can further configure this project style by using the Project Style group of the Project tab of the Designer ribbon.

Tip: This also allows you to edit the !Style graphic form to add a banner or a company logo that all your graphic forms will have in common.

Once you have chosen a project style, the Create Graphic Form (Styled) option becomes available to create graphic forms that utilise the currently configured selected style.

Note1: Any change that you make to a project style after creating a styled graphic form will NOT be made to this graphic form - so ensure that you are completely happy with your style before creating your styled graphic forms.

Note2: You can still use the default Create Graphic Form option to add graphic forms to your project that do not use the specified style.

When creating a project, if necessary check the Show Project Styles and Navigation Configuration checkbox (or click the Advanced View button), which displays the Project Style tab.

Either select a predefined style from the Style list and/or modify the various settings as required, to Save As... your own custom style, which is added to the user profile of the currently logged in user, and can be reused when creating other projects.

After applying a style to a project, the Project Style group of the Project tab of the Designer ribbon is enabled, so that you can further configure this project style:

Tip: The caption of this group indicates the name of the currently selected styled project.

In addition to the providing the project style settings, the Project Style group provides the Open Project Style item, which opens the project style graphic form (!Style), so that you can add form components to this project style graphic form, such as a banner (header) or footer or logo or any other element or graphic that all your styled graphic forms have in common and/or configure their default properties.

After editing this project style graphic form, click the Save Project Style item to save these project style changes.

Note: You can only edit the style of a single project at a time.
