Exporting graphic forms

In order to reuse or backup existing graphic forms, it is possible to export graphic forms from the Enterprise Manager to a local or networked hard disk using Windows Explorer.

Note1: This can only be performed if the currently logged on user has the necessary security permissions. For details, see Securing projects.

Note2: An exported graphic form can be imported into any project. For details, see Importing graphic forms.

To export a graphic form to the hard disk:

In the SmartUI Designer:

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. If necessary, expandclick the plus (+) box to the left of the current icon or name its required existing folder(s), until the required folder is displayed.
  3. Right-click on this graphic form or its icon  and selectposition the mouse pointer over the item and press the left mouse button; also known as clicking.  Copy.

In Windows Explorer:

  1. Either create or select the folder that will contain this graphic form.
  2. Right-click on this folder and select Paste.

Tip: Graphic forms can also be exported by dragging them from the Enterprise Manager into the required folder in the Windows Explorer.

Note: Each saved graphic form, is entirely self-sufficient, containing all the data that it requires, such as spiders, levels and layers and translations.
