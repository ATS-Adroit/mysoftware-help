Pasting graphic forms

In order to use a graphic form that has already been designed in another project or folder on the same Server, copy this graphic form using the Enterprise Manager and paste it directly into the required project or folder your project.

Note: You need to copy a graphic form before it can be pasted. For details, see Copying graphic forms. 

To paste a graphic form into a project:

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. To paste into the ROOT of the project: right-click on the project name or its icon  and select Paste.
  3. To paste into a FOLDER of the project:If necessary, expandclick the plus (+) box to the left of the current icon or name its required existing folder(s), until the required folder is displayed. Then right-click this folder name or its icon  and select Paste.

A graphic form with the same name as the copied graphic form will be added beneath the project.

Note: If the name of the graphic form already exists within this level of the project hierarchy in which it is pasted then its name will be appended by a unique number e.g. Graphic Form2, if “Graphic Form” and “Graphic Form1” already exist.
