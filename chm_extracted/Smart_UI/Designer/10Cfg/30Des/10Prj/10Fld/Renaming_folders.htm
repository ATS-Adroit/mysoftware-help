Renaming folders

When folders are created in the Enterprise Manager they are given a default name.

Folders organise the graphic forms in an existing project and so it is recommended to give each a meaningful name. For details concerning the role of folders in projects, see Working with projects.

Renaming folders enhances the organization of your project by making it easier to identify their contents.

Note: This can only be performed if the currently logged on user has the necessary security permissions. For details, see Securing projects.

To rename a folder:

  1. Open the required project in the Enterprise Manager. For details, see Opening Projects.
  2. If necessary, expandclick the plus (+) box to the left of the current icon or name its required existing folder(s), until the required folder is displayed.
  3. Click on the name of the required folder.

This will highlight the current name.

Note: Do not click on its icon .

  1. Type in a completely new name or edit the existing name as required.

Note1: When specifying the folder name, any character can be used.

Note2: You are unable to rename a folder to a name that already exists within this level of the project hierarchy.

Tip: Although the name of the folder is limited to a maximum of 255 characters, it is recommended to use a descriptive name, which is as concise as possible, to ensure easy navigation within the Enterprise Manager tool window.
