Configuring projects

Projects are configured within the Projects category of the required Server connection in the Enterprise Manager, by adding, copying or importing graphic forms and organizing these within a hierarchy of folders. For details, see Working with projects.

Note: Projects are saved in separate folders, with the exact structure of the project being maintained, to easily locate your graphic forms, so that they can be backed up, copied and/or moved. For details, see Locating saved projects.

The following project-specific commands are provided:  

Note: These commands can only be performed if the currently logged on user has the necessary security permissions. For details, see Securing projects.

  1. Open a project : to expose its configured graphic forms and folders.

Add one or more of the following components to your project:

Tip: You could also copy an entire project or folder from another project using Copy sub-items and paste it into this project, although any items that are named the same as the copied items will be overwritten.

  1. Create a graphic form : to add a new graphic form to a project.
  2. Create a wizard: to add a wizard to a project.
  3. Create a folder : to organise graphic forms within a project.

Tip: Projects and their folders provide an an Open ... Folder right click menu in the Enterprise Manager that will open this specific folder in Windows Explorer, when this project is on the same computer, so that content can be manually copied into or out of it.

Note: You can also prevent the unauthorised editing of graphic forms and/or wizards, by password-protecting entire projects, folders and/or individual graphic forms and wizards. For details, see Password protecting graphic forms and/or wizards.

Other possible operations:

  1. Close a project : to hide its configured graphic forms and folders from view.
  2. Remove a project : to delete it and its configured graphic forms and folders.
  3. Rename a graphic form : to change the name of a graphic form.
  4. Export a graphic form : to copy a graphic form to disk for archiving or later re-use.
  5. Import a graphic form : to import a graphic form from disk.
  6. Copy a graphic form : to duplicate a graphic form in another project or folder.
  7. Paste a graphic form : to insert a copied graphic form into a project or folder.
  8. Remove a graphic form : to delete a graphic form.
  9. Open and close a folder : to expose/hide its configured graphic forms and folders.
  10. Rename a folder : to change the name of a folder.
  11. Remove a folder : to delete a folder.

Note: Projects and their folders provide a Preview Graphic Forms option to displays thumbnail snapshots of all the graphic forms located in their immediate or root level to either open the required graphic form or populate the Favorites tool window. For details, see Previewing graphic forms.
