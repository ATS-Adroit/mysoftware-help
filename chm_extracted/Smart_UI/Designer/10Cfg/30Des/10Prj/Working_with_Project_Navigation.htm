Working with Project Navigation

When creating a project, you can choose how you want your end-users to navigate between the various graphic forms provided by your project by selecting the required Navigation Type.

Note1: Each navigation type is a navigation template project and when selected this copies the selected navigation project and their default graphic forms and folders to the root of your project.

Note2: If you use the Default project style, then the style of the selected navigation project is also copied to your project, which you can configure this style as needed to use for any styled graphic forms that you create for this project. For details, see Working with Project Styles.

Once you have chosen the type of graphic form navigation, you can apply a predefined or custom Navigation Theme to define the look and feel of this graphic form navigation.

Note: If you specify the Default navigation theme, then the default colors of the selected Navigation Type are used.

When creating a project, if necessary check the Show Project Styles and Navigation Configuration checkbox (or click the Advanced View button), which displays the Project Navigation tab.

Click on the required image of the Navigation Type tab that describes how your end-users will select the required graphic forms provided by your project.

Note: This will only contain the None theme if you unchecked the Include default projects i.e. Navigation Templates, Shapes Wizards and Examples, and System Information etc. checkbox when creating a new Configuration in Adroit Config Editor.

Selecting any navigation type other than None displays the Navigation Theme tab, so you can choose a theme that defines the following project navigation colors:

Example:

  • Graphic Form Background: this changes the background color of all the project navigation graphic forms and if you are using the Default style, then this also specifies the background color of any styled graphic forms that you create for this project.

Note: The following three colors only affect the graphic form containing the navigation area.

  • Navigation Background:the background of the navigation area containing the buttons used to open the graphic forms of this project.
  • Button Background: the background color of the buttons used to open the graphic forms of this project.
  • Button Text: the text color of the buttons used to open the graphic forms of this project.

You can either select a predefined theme from the Theme list and/or modify the Theme colors as required, to Save As... your own custom theme, which you can reuse when creating other projects.

Tip: Any custom themes that are saved are added to the user profile of the currently logged in user.
