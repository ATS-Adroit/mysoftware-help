Securing projects

Projects manage the creation, translation and storage of their graphic forms. You therefore secure projects to control which users are able to access the project and its configured graphic forms.

Tip: If you need to reset the configured security settings for any reason, then right click the project and select the Reset configured security item.

Access to each project, its folders and/or graphic forms are controlled using data element security. Click for more details: this is because a project is actually a datasource and its configured folders and graphic forms are data elements. For details on how to distinguish the available datasources, see About datasources and data elements.

This enables you to specify which user(s) and/or group(s) are allowed to view, configure and remove these items and/or who is able to configure their security settings. For details on how to use data element security to control the access to each project, its folders and/or graphic forms, see Working with data element security.

In other words, if the currently logged on user, does not have the necessary security permissions, then he/she may not even be able to see some or all of the configured projects and/or their folders and graphic forms.

Furthermore he/she may be unable to configure or delete some or all of the projects and/or their folders and graphic forms that are visible.

 

For details on how to control the access to a project and its individual folders and graphic forms, see Assigning security permissions to data elements.
