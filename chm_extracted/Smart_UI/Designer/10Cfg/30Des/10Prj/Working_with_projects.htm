Working with projects

Projects manage the creation and storage of their graphic forms and make it possible to organise graphic forms through the creation of folders. For details, see Configuring projects or Working with graphic forms.

Projects are created and configured within the Projects category of the required Server connection in the Enterprise Manager. For details, see Creating new projects.

When creating projects you can either specify a style to configure certain default display settings of your styled graphic forms to save you design time and ensure a consistent look and feel and/or to specify how your end-users navigate between them. For details, see Working with Project Styles or Working with Project Navigation.

Note: Projects and their folders provide a Preview Graphic Forms option to displays thumbnail snapshots of all the graphic forms located in their immediate or root level to either open the required graphic form or populate the Favorites tool window. For details, see Previewing graphic forms.

Tip: Projects and their folders provide an an Open ... Folder right click menu in the Enterprise Manager that will open this specific folder in Windows Explorer, when this project is on the same computer, so that content can be manually copied into or out of it.

However, their graphic forms do not need to be created from scratch, since it is possible to both import and export graphic forms to and from a project or to use wizards. For details, see Importing graphic forms or Exporting graphic forms or Working with wizards.

Note1: Access to both the project and its graphic forms can be controlled, if necessary. For details, see Securing projects.

Note2: You can also prevent the unauthorised editing of graphic forms and/or wizards, by password-protecting entire projects, folders and/or individual graphic forms and wizards. For details, see Password protecting graphic forms and/or wizards.

A project exists in two main states:

  • The design state, which is used to add, import and configure or design the graphic forms within the SmartUI Designer.

Note: The amount of user interaction provided by a graphic form is wholly dependent upon its design. For details, see Designing graphic forms.

Tip: The Shapes Wizards & Examples tab of the Designer ribbon, provides access to the shapes, wizards and/or examples of the default Shapes Wizards and Examples project so that you can easily design your graphic forms. For details, see Working with Shapes Wizards and Examples.

In particular this contains the Situational Awareness category, which contains sub-categories of wizards that allow you to create process control user interfaces that strive to minimise operator fatigue and increase their response times. For more details, see Situational Awareness (or High Performance SCADA).

  • The operational or run-time state, which is used to view and interact with these graphic forms, typically within the SmartUI Operator although it is also possible to do this within the SmartUI Designer too. For details, see Operating graphic forms.

Each project is also an internal datasource and its folders and graphic forms are its data elements.

For details on how to distinguish the available datasources, see About datasources and data elements. For this reason each project can also be updated or locked, if necessary. For details, see Updating datasources or Locking datasources.

Note: Projects are saved in separate folders, with the exact structure of the project being maintained, to easily locate your graphic forms, so that they can be backed up, copied, moved or have external content added to them. For details, see Locating saved projects.
