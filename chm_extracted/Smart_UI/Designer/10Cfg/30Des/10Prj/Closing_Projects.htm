Closing Projects

Projects can be ‘closed’ or collapsed in the Enterprise Manager just like any other component.

When a project is closed, it will hide its configured hierarchy of graphic forms and folders.

To close a project:

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the Projects category.
  2. Click the minus box to the left of the project icon of the required name.

Tip: You can also close a project by double-clicking on its name or icon.
