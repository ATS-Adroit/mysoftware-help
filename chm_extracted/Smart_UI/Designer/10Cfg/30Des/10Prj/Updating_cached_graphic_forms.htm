Updating cached graphic forms

By default, each SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. caches the data that it requests from the SmartUI Server to improve its response time.

For instance, if a graphic form that has been cached is opened by the Client, this graphic form is loaded from the local cache instead of retrieving it from the Server via the Internet/LAN so it opens quickly.

Note: Use the (Caching) DataElementCachingEnabled setting to enable or disable this caching for a Client.

By default, a cached graphic form will ONLY be loaded by the Client if it remains unchanged when it is opened again. In other words, no further design changes have been made to this graphic form that is stored on the Server.

If you enable (set to ‘true’) the (Caching) DataElementCachingRetrieveRegardless setting, then the Client will ALWAYS load a cached graphic form from the local cache REGARDLESS of the subsequent changes that have been made to it, since the cache was last updated.

This greatly improves the user experience but requires the additional administrative overhead of ensuring that the local cache is updated to include any changes made to the graphic forms of the project/s that it displays AND then copy this updated local cache to all the Operators that use this project/s.

To save all graphic forms of a project to the local cache file:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  1. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the Server computer name.

  1. If necessary, expand the Projects category.
  2. Right click the project icon  of the required name and select Update Local Cache.

This updates the local cache with all the changes that have been made to the graphic forms of this project.

The local cache data is located within the Caching sub-folder of the SmartUIl installation folder (typically C:\Program Files\Adroit Technologies\Adroit) in the ‘CACHE’ and 'CACHEINDEX' files.

Note: If you need to update more than one project then perform step 5 for each project to add these changed graphic forms to the cache.

To copy the updated local cache to all the Operators that use its project/s:

  • Either: manually copy the Caching sub folder of the SmartUI installation folder (typically C:\Program Files\Adroit Technologies\Adroit) into the SmartUI Operator installation folder of each of your SmartUI Operator computers.
  • Or: copy the updated Caching sub-folder into the Distribution folder with the other files required by the SmartUI Operator and then use the SmartUI Launcher (if supported) to distribute the SmartUI Operator (with the updated cache) to the necessary computers.
