Client Information

This table in the General Information tab of the System Information sample project provides the following SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server.-specific information:

  • UserId: the GUIDGlobally Unique IDentifier that identifies the user that has currently logged onto the Server from this Client. This GUID is automatically generated at runtime and is unique for every sessioneach time an application is started and stopped on a computer constitutes a single session of this program..
  • ClientId: this string provides the following information:
  • the name of the computer the SmartUI Client is running on and
  • the literal name of this SmartUI Client, as specified by its ClientId setting and
  • the GUID that identifies this SmartUI Client, which is automatically generated at runtime and is unique for every session and
  • the IP Address of the SmartUI Server and its TCP/IP port that is used to communicate to this SmartUI Client.
  • Client Address: the IP address of the computer that this SmartUI Client is running on and the TCP/IP port that currently uses to communicate to the SmartUI Server.
  • UserName: the name of the user that is currently logged onto this SmartUI Client.
  • Login time: the date and time at which the current user logged onto this SmartUI Client.
  • Login period: the time that the current user has spent logged into this SmartUI Client (the length of the current login session).

Tip: This Login period is updated every 10 seconds.

  • Message Queue size (for polled modes): This is ADVANCED troubleshooting information that specifies the current number of messages that are being queued on the SmartUI Server for this SmartUI Client, which is periodically requesting the SmartUI Server for these messages (POLLING).
  • Subscription Queue size (for subscription mode): This is ADVANCED troubleshooting information that specifies the current number of messages that are being queued on the SmartUI Server for this SmartUI Client, which is waiting for the Server to send these messages (SUBSCRIPTION).
