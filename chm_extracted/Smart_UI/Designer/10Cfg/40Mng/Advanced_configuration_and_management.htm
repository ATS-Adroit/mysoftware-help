Advanced configuration and management

The Configuration tab of the Designer ribbon, which is typically intended for advanced users, allows you to configure and manage your applications and projects, as follows:

  • Adroit Classic: Setting up the Agent Server and agent database (.wgp) file name and/or installing and configuring protocol drivers and their devices, by accessing the relevant configuration dialog of the Adroit Config Editor utility. For details, see Agent Server Configuration or Drivers Configuration.
  • Adroit SmartUI: Setting up the SmartUI Server, Designer, and Operator, by accessing the relevant configuration dialog of the Adroit Config Editor utility to configure these applications. For details, see Setting up the Server or Setting up the Designer or Setting up the Operator.
  • Open Projects Folder: opens the folder containing the configured projects, in Windows Explorer, when these projects are on the same computer, so that content can be manually copied into the relevant projects.
  • System Backup and Restore: to backup and/or restore the relevant registry settings and all the files and folders containing the user-configuration of the currently specified Configuration, by accessing the relevant configuration dialog of the Adroit Config Editor utility. For details, see System Backup and Restore.
