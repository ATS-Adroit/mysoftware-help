Specifying user and group subsets

When the SmartUI Server is deployed on a domain with a large number of users and/or groups, the user and group lists used when configuring SmartUI security will take a long time to be populated.

Since these delays significantly slow down the security configuration, you can manually specify a subset of ONLY the users and/or groups that will be using the SmartUI Server and its Clients (Designers and/or Operators).

To specify the subsets of users and/or groups

  • Add the users to the UserSubset setting on each SmartUIServer, with each name separated by (";").
  • Add the groups to the GroupSubset setting, with each name separated by (";").

In this case the Server will ONLY use these specified users and/or groups to populate the user and group lists and will not need to contact the domain controller for the complete list of available users and/or groups.

For details of accessing these settings, see Advanced Server settings.

WARNING! Please ensure that the names of the specified users and/or groups are correctly specified, since any misspelt names will be rejected by Windows when they are used.

Note1: By default these settings are empty so that the domain controller provides the complete list of available users and/or groups.

Note2: Ensure that the names of the specified users and/or groups exist on the Workgroup or Domain as specified by the DomainName setting for this Server.
