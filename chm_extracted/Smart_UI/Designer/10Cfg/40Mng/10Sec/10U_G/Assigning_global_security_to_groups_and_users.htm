Assigning global security to groups and users

Each SmartUI Server can give specific users and groups total or global security access to the Server, so that they become “master” users and groups that:

  1. permanently become allowed users and allowed groups i.e. they cannot be removed from the lists of the allowed users and groups maintained by this Server.

Note: This ensures that these users and groups cannot lock themselves out of the SmartUI Server.

  1. are always able to log in to and have unrestricted access to this Server, its datasources and their data.

Note: R restricted security access can only be assigned to non-global groups and users.

For these reasons, it is recommended that:

  1. careful consideration be given to which users and groups are given global security access to a Server.

    Typically, this should only be given to the Administrator user and the Administrators group respectively, which are the default settings.

  2. these global security users and groups should administer the SmartUI Server security by adding the other allowed users and groups and assigning the necessary access rights to each of them.

For details of configuring these global security groups and users, see Server security settings.
