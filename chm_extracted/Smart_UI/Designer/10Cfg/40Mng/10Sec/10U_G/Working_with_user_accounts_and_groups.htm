Working with user accounts and groups

SmartUI security uses the Windows user accounts and groups on each SmartUI Server computer. Click for more details:

  • A user account is created in Windows to specify a user and contains his/her user name and password, which is used during log on.
  • A group is created in Windows to contain one or more users.
  • Ensure that the necessary user rights are assigned to each user and group. For details of the required user rights and how to apply them, see Windows security configuration.
  • The default security applied to all datasources and their data elements, only assigns full access to specific administrative group(s) and/or user(s) that are given global access to this Server. For details, see Assigning global security to groups and users.

Due to the nature of the SmartUI Server security, it is recommended to use a task-based security model, when creating the user accounts and groups within Windows.

  • Where tasks, refer to the categories of users that you need to define, such as "Designers" or "Operators".
  • Each task is assigned the appropriate permissions when accessing this SmartUI Server, its configured datasources and their data elements and/or special functions, if necessary.

Note: When the SmartUI Server is deployed on a domain with a large number of users and/or groups, the lists of users and groups take a long time to be displayed. For details on reducing or eliminating this delay, see Specifying user and group subsets.

Assign users to their tasks by using Windows groups, as follows:

Click for more information about each step:

  1. Create groups for each task that will need to be performed.

Tip: Ideally, the names of the groups should take the names of their tasks, to immediately suggest who should belong to them, such as "Designers" or "Operators".

  1. Assign the necessary users to the relevant groups.

IMPORTANT: Ensure that each user account is assigned a password as you need a password to log onto the SmartUIServer.

Note: It is not necessary to create user accounts for all users since it is also possible to impersonate a user, if necessary. For details, see Impersonating users.

  1. Add the required groups to the Allowed Groups within the SmartUI Designer and assign the necessary access permissions to each of them. For details, see Adding allowed users and groups or Configuring Server security.

Note1: Using Windows groups to populate tasks makes it easier for you to manage large numbers of users.

Note2: Generally, it will be the system administrator's job to populate the defined tasks defined for the application with Microsoft Windows user accounts and groups.

Note3: For details on how to create a user account or group and how to assign users to groups, please refer to your Windows operating system help.
