Adding allowed users and groups

Typically, add each user or group that uses a SmartUI Clientrefers to either the Designer or the Operator, both of which are client applications of the Server. to the lists of allowed users or groups maintained by each SmartUIServer.

IMPORTANT: Ensure that each user is assigned a password, which is MANDATORY when logging onto the SmartUI Server.

Click for more information:

  • Using groups makes it easier for you to manage large numbers of users. For details, see Working with user accounts and groups.
  • It is not necessary to create user accounts for all users since it is also possible to impersonate an allowed user. For details, see Impersonating users.
  • It is also possible to remove user(s) or group(s) from these lists, if necessary.
  • When the SmartUI Server is deployed on a domain with a large number of users and/or groups, there is long delay before the user and group lists are displayed. For details on reducing or eliminating this delay, see Specifying user and group subsets.
  • One or more high-level groups and/or users can have unrestricted access to each SmartUI Server. For more information, see Global security groups and users.

Allowed users and groups are configured for each SmartUI Server in the Enterprise Manager, by using the Security component within the Management category.

To add a user to the allowed users list:

Expand the Security component of the required SmartUI Server, as follows:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  3. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the SmartUI Server computer name.

  1. If necessary, expand the Management category.
  2. Click the plus box  to the left of the Security icon .

Tip: It is also possible to display the security components by double-clicking on this name or icon. 

  1. Expand the Users and Groups icon .
  2. Expand the Users icon .
  3. Right-click the Allowed Users icon or its name and select Set Allowed Users.

The Set Allowed Users configuration dialog is launched.

Note: If the Server is deployed on a domain with a large number of users, its list of Available Users will take a long time to be populated. For details on reducing or eliminating this delay, see Specifying user subsets.

  1. Select the name of the required user from the Available Users list.

Note: The Available Users list may include both local and global users, where applicable.

  1. Click the << button to add this user to the Selected Users list

Tip: You can also add users by double-clicking the required entry in the Available Users list to immediately add it to the Selected Users list.

Note: Only the users listed in the Selected Users list, will be used when configuring access to the Server, the configured datasources and their data elements and/or special functions, if necessary.

  1. Repeat this for all the users that you want to add.

Tip: It is also possible to add users to the Allowed Users list by expanding the All Users icon and dragging the relevant users onto the Allowed Users icon .

Note: If necessary, allowed user(s) can be removed. For details, see Removing allowed users.

 

To add a group to the allowed groups list:

Expand the Security component of the required SmartUI Server, as follows:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  3. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the SmartUI Server computer name.

  1. If necessary, expand the Management category.
  2. Click the plus box  to the left of the Security icon .

Tip: It is also possible to display the security components by double-clicking on this name or icon. 

  1. Expand the Users and Groups icon .
  2. Expand the Groups icon .
  3. Right-click the Allowed Groups icon or its name and select Set Allowed Groups.

The Set Allowed Groups configuration dialog is launched.

Note: If the Server is deployed on a domain with a large number of groups, its list of Available Groups will take a long time to be populated. For details on reducing or eliminating this delay, see Specifying group subsets.

  1. Select the name of the required group from the Available Groups list.

Note: The Available Groups list may include both local and global groups, where applicable.

  1. Click the << button to add this group to the Selected Groups list.

Tip: You can also add groups by double-clicking the required entry in the Available Groups list to immediately add it to the Selected Groups list.

Note: Only the groups listed in the Selected Groups list, will be used when configuring access to the Server, the configured datasources and their data elements and/or special functions, if necessary.

  1. Repeat this for all the groups that you want to add.

Tip: It is also possible to add groups to the Allowed Groups list by expanding the All Groups icon and dragging the relevant groups onto the Allowed Groups icon .

Note: If necessary, allowed group(s) can be removed. For details, see Removing allowed groups.
