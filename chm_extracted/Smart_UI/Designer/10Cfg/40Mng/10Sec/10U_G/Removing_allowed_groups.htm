Removing allowed groups

If necessary, group(s) used by Server security can be removed.

To remove a group from the allowed groups list

Expand the Security component of the required SmartUI Server, as follows:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  3. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the SmartUI Server computer name.

  1. If necessary, expand the Management category.
  2. Click the plus box  to the left of the Security icon .

Tip: It is also possible to display the security components by double-clicking on this name or icon. 

  1. Expand the Users and Groups icon .
  2. Expand the Groups icon .
  3. Right-click the Allowed Groups icon or its name and select Set Allowed Groups.

The Set Allowed Groups configuration dialog is launched.

  1. Select the name of the required group from the Selected Groups list.
  1. Click the >> button to add this group to the Available Groups list.

Tip: You can also remove groups by double-clicking the required group in the Selected Groups list.

  1. Repeat this for all the groups that you want to remove.

Tip: It is also possible to remove groups from the Allowed Groups list by expanding the Allowed Groups icon , right-clicking the required group name or its icon and selecting Remove Allowed Group.
