Available policies

The following policies represent the services or activities performed by a SmartUI Server:

Policy Description

Add New Datasource

The ability to add a datasource of the specified datasource plugin.

Export Datasource

The ability to export a datasource of the specified datasource plugin.

Get Current Datasource List On Server

The ability to retrieve the list of datasources that have been made available on this Server.

Get List OF Datasource Plugins From Server

The ability to retrieve the list of datasource plugins that have been made available on this Server, for which datasources can be created.

Get Special Function List For Datasource

The ability to retrieve each special functionoptionally provided by a datasource plugin to perform additional functionality forinteracting with each datasource and / or its data. provided by the specified datasource plugin. 

Get The Data Element List From Datasource

The ability to retrieve all the data elements from the datasource(s) of the specified internal or external datasource plugin.

Import Datasource

The ability to import a datasource of the specified datasource plugin.

Invoke Special Function

The ability to use (execute) a special function.

Tip: This policy provides the means to globally enable or disable the use of special functions for particular users and groups.

Note: Use special function security to secure specific special functions. For details, see Working with special function security.

Remove Existing Datasource

The ability to remove an existing datasource of the specified datasource plugin.

Note: This does not remove the specified datasource plugin itself, only the datasource that it has created.

Save Server Data

The ability to save the Server’s data.

Submit Transaction

The programmatic ability available to third party developers, which if not used should be left at the default setting.
