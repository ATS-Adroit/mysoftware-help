Working with special function security

Special functions are additional functionality provided by a datasource for interacting with its data (data elements). Click for more details:

  • Special functions can only be secured once the allowed groups and/or users have been added. For details, see Adding allowed users and groups.
  • Special functions need to be separately secured for EACH datasource that is created.
  • Special function security is unaffected by the security settings applied to the datasource itself. For details on securing datasources, see Working with data element security.

  • By securing special functions, you are actually securing specific functionality provided by the datasource itself.

    This becomes especially apparent when the special function is the only provided means for performing a specific action.

The following strategy is the recommended for controlling access to special functions:

  1. Specify which allowed users and/or groups are able to use special functions at all, by associating them to the Invoke Special Function policy. For details, see Associating policies with allowed users and groups.

Note: Additional allowed users and groups may initially be associated to this policy. For details on configuring this security setting, see Server security settings.

  1. Specify which special functions these allowed users for and/or groups are able to use for each datasource, so that they will be able to perform their required duties. For details, see Assigning security permissions to special functions.

In this way, whenever a special function is used:

  • this SmartUI Server first determines whether the currently logged in user is part of the allowed users or groups that are able to use special functions.
  • if so then this SmartUI Server determines whether the user is actually allowed to use the special function associated with this specific datasource, and accepts or rejects the request accordingly.

Note: By default, only those group(s) and/or user(s) that have global security access to each SmartUI Server have access to all special functions. For more information, see Assigning global security to groups and users.
