Applying special function security to allowed groups

Expand the Security component of the required SmartUI Server, as follows:

  1. Open the Enterprise Manager. For details, see Accessing tool windows.
  2. If necessary, expand click the plus (+) box to the left of the current icon or name Servers.
  3. If necessary, expand the name of the required Server connection .

Tip: The connection name is prefaced by the SmartUI Server computer name.

  1. If necessary, expand the Management category.
  2. Click the plus box  to the left of the Security icon .

Tip: It is also possible to display the security components by double-clicking on this name or icon. 

  1. Display the special functions exposed by this datasource.
  2. Right-click the required special function icon or its name and select Security.

Note: This Security option only appears if the currently logged on user has been assigned the Configure Access security permission for this special function.

The Security configuration dialog is launched.

Note: If the Server is deployed on a domain with a large number of groups, its list of Available Groups will take a long time to be populated. For details on reducing or eliminating this delay, see Specifying group subsets.

  1. Use the Groups And Users section to select the required allowed group(s).
  1. Select the name of the required group from the Available Groups list, which contains all the allowed groups configured for the Server.
  2. Click the << button to add this group to the Selected Groups list.
  3. Repeat this for all the allowed group that are to be assigned security permissions for this special function.

Tip: You can also add group by double-clicking the required entry in the Available Groups list to immediately add it to the Selected Groups list.

  1. Use the Special Function Security section to assign the required security permissions to the selected group (s), as follows:

Note:For details on these security permissions, see Available special function security permissions. 

  1. Select a group from the Selected Groups list.

Tip: Select multiple groups from this list, if more than one group is to have the same security permissions assigned to them.

  1. Empty the checkboxes next to the security permissions that do not apply to the currently selected group(s).

Tip: Clicking on the name of the security permission will check or empty its checkbox. 

  1. Repeat this until all of the selectedgroups have been assigned the correct security permissions for the selected special function of this datasource.
