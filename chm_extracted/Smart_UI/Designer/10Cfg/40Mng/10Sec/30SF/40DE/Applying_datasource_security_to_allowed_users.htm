Applying datasource security to allowed users

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the relevant category.
  2. Right-click the relevant datasource name or icon and select Security.

Note: This Security option will only appear if the currently logged on user has been assigned the Configure Access security permission for this datasource.

The Security configuration dialog is launched.

Note: If the Server is deployed on a domain with a large number of users, its list of Available Users will take a long time to be populated. For details on reducing or eliminating this delay, see Specifying user subsets.

  1. Ensure that the Security For Data Element field, beneath the Data Element Information group, specifies the required datasource.
  2. To secure ALL the data elements within this datasource with the selected security permissions, check the Apply To Children checkbox beneath the Data Element Information group.

Note1: The Apply To Children setting applies to all the selected groups and users.

Note2: The Inherit From Parent checkbox has no effect upon the security applied to datasources.

  1. Use the Groups And Users group to select the allowed user(s) that will be assigned security permissions for this datasource.
  1. Select the name of the required user from the Available Users list, which contains all the allowed users configured for this Server. For details see Adding allowed users and groups.
  2. Click the << button to add this user to the Selected Users list.
  3. Repeat this for all the allowed users that are to be assigned security permissions for this datasource.

Tip: You can also add users by double-clicking the required entry in the Available Users list to immediately add it to the Selected Users list.

  1. Use the Data Element Securitygroup to assign the required security permissions to the selected user(s).

Note: For details on these security permissions, see Available data element security permissions.

In addition to these security permissions you can also specify which data elements can be audited and/or have their value changes authenticated. For details, see Configuring the auditing and/or authorizing of value changes.

  1. Select a user from the Selected users list.

Tip: Select multiple users from this list, if more than one user is to have the same security permissions assigned to them.

  1. Empty the checkboxes next to the security permissions that do not apply to the currently selected user(s).

Tip: Clicking on the name of the security permission will check or empty its checkbox. 

  1. Repeat this until all of the selected users have been assigned the correct security permissions for the selected datasource.
