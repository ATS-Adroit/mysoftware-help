Applying datasource security to allowed groups

Select the required SmartUI Server in the Enterprise Manager, as follows:

  1. Open the Enterprise Manager.
  2. Navigate to Servers > [Server Name].
  3. Tip:  The connection name is prefixed by the SmartUI Server computer name.
  1. If necessary, expand the relevant category.
  2. Right-click the relevant datasource name or icon and select Security.

Note: This Security option will only appear if the currently logged on user has been assigned the Configure Access security permission for this datasource.

The Security configuration dialog is launched.

Note: If the Server is deployed on a domain with a large number of groups, its list of Available Groups will take a long time to be populated. For details on reducing or eliminating this delay, see Specifying group subsets.

  1. Ensure that the Security For Data Element field, beneath the Data Element Information group, specifies the required datasource.
  2. If all of the data elements within this datasource are also to be secured using the selected security permissions, check the Apply To Children checkbox beneath the Data Element Information group.

Note1: This Apply To Children setting applies to all the selected groups and users.

Note2: The Inherit From Parent checkbox has no effect upon the security applied to datasources.

  1. Use the Groups And Users group to select the allowed group(s) that will be assigned security permissions for this datasource.
  1. Select the name of the required group from the Available Groups list, which contains all the allowed groups configured for this Server.
  2. Click the << button to add this group to the Selected Groups list.
  3. Repeat this for all the allowed groups that are to be assigned security permissions for this datasource.

Tip: You can also add groups by double-clicking the required entry in the Available Groups list to immediately add it to the Selected Groups list.

  1. Use the Data Element Security group to assign the required security permissions to the selected group(s).

Note: For details on these security permissions, see Available data element security permissions.

In addition to these security permissions you can also specify which data elements can be audited and/or have their value changes authenticated. For details, see Configuring the auditing and/or authorizing of value changes.

  1. Select a group from the Selected Groups list.

Tip: Select multiple groups from this list, if more than one group is to have the same security permissions assigned to them.

  1. Empty the checkboxes next to the security permissions that do not apply to the currently selected group(s).

Tip: Clicking on the name of the security permission will check or empty its checkbox. 

  1. Repeat this until all of the selected groups have been assigned the correct security permissions for the selected datasource.
