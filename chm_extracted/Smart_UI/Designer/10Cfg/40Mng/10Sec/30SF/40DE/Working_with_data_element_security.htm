Working with data element security

Every datasource exposes its data in the form of data elements. It is therefore essential that the access to these data elements be sufficiently controlled to provide the necessary security for your data. Click for more details:

Each data element can be assigned security permissions that determine which users are able to configure its security settings and which users are able to view, set or remove it.

  • For details on how to distinguish the available datasources, see About datasources and data elements.
  • Since datasources are themselves data elements this security also applies to them.
  • Data elements can only be secured once the allowed groups and/or users have been added. For details, see Adding allowed users and groups.
  • Data elements need to be secured separately for EACH datasource that is created.
  • By default, only those group(s) and/or user(s) that have global security access to each SmartUI Server have access to all datasources and their data elements. For more information, see Assigning global security to groups and users.
  • The data element is the lowest level to which Server security can be applied.

The following strategy is the recommended for implementing data element security:

  1. Apply security permissions to the available datasources to ensure that only the necessary datasources are available the allowed users and/or groups for them to perform their required duties. For details, see Assigning security permissions to datasources.

Note: The security permissions applied to a datasource can also be applied to all of its component data elements, if necessary. For details of the available security permissions, see Available data element security permissions..

In addition to these security permissions you can also specify which data elements can be audited and/or have their value changes authenticated. For details, see Configuring the auditing and/or authorizing of value changes.

  1. Apply security permissions to specific data elements within these datasources, so that only the necessary data is available for them to perform their required duties. For details, see Assigning security permissions to data elements.

In this way, the currently logged in user should only be able to see the datasources and their data elements that are necessary to perform his/her function.

Furthermore, whenever any data element is accessed, this SmartUI Server always determines whether the currently logged in user is able to perform the requested data element operation, and accept or reject the request accordingly.
