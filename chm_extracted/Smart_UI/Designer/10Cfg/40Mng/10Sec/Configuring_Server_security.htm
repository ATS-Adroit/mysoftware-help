Configuring SmartUI Server security

The SmartUI Server normally implements security, which is configured by the Security component of the Management category in the Enterprise Manager, as follows:

  1. Select which of the available users and groups on this SmartUI Server computer are "allowed" to log on to and interact with the SmartUI Server. Click for more information:

For details on creating users and groups, see Working with user accounts and groups.

For details creating a sub-set of users and groups, see Adding allowed users and groups.

Note1: You do not need to create user accounts for all users since it is also possible to impersonate an allowed user. For details, see Impersonating users.

Note2: One or more high-level groups and/or users can automatically be given unrestricted access to this Server. For details, see Global security groups and users.

  • The following additional SmartUI Server-specific security measures can be implemented for these allowed users and groups:
  1. Data element security: control the access to each data elementa finite component of data contained within a datasource that behaves in a generic manner; typically a value.
