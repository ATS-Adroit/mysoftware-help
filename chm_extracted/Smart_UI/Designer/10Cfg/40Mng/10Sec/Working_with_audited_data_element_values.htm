Working with audited data element values

For details on how to configure the auditing of values, see Configuring the auditing and/or authorizing of value changes.

The following two secure database connections can contain the audited data elements (values):

  • a mandatory, local SQL Server Compact database that stores the auditing locally on the relevant SmartUI Server computer.

    Note: This database is mandatory because being local its connection cannot be lost (which is the potential point of failure of any auditing system that uses a database) and will always be backed up and restored with the Configuration.

    This database is secured so that it cannot be configured by users but can be read by the SmartUI Server to extract its auditing information.

    This database file is stored in the following folder:

    Active Configuration Path\Audit (For instance, when using the Default configuration this would be: C:\ProgramData\Adroit Technologies\Adroit\SmartUI\Configurations\Default\Audit)

    This SQL Compact file is named according to the configuration name (For instance, when using the Default configuration this is: Default_Audit.sdf).

  • an optional user-defined SQL Server database (although other OLE-DB compatible databases may be provided in future releases), which can be on a remote computer.

    This is performed in the Server Security Settings page of the Adroit Config Editor utility, as follows:

Select the Yes option for the Auditing question at the top of the Server Security Settings page of Adroit Config Editor.

This displays the Connection String field in which you specify the connection string to this optional SQL Server database.

Either type/paste this in directly or by click the browse button to the right of this field and use the Connection Properties dialog to specify the required connection string to the SQL Server database.

Typically do NOT change the Data source from the default of .NET Framework Data Provider for OLE DB, unless you are connecting to a SQL Compact database. More details: in which case, click the Change... button and choose the datasource that corresponds to the correct version of SQL Compact and then the dialog will change so that you only need to browse in the required database file and specify the required password, if any.

To display the Server Security Settings page of settings:

  1. Launch the Adroit Config Editor.

The Welcome section is displayed by default, unless multiple configurations have been created, in which case the Configuration page is displayed by default, which needs to be expanded to display the Welcome section. For details, see Working with Configurations.

  1. Selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the Setting up the Server option.

Note: If this option does not appear then the SmartUI Server may not be installed.

  1. Select the Security Settings option.

Currently the System Information project, provides sample graphic forms (in the Auditing folder) that show you how to use different methods for reporting the audited entries logged to the audit database, namely:

  • Audit Report Example (Script): this graphic form uses a graphic form script to filter the available audit entries according to a specific (initiating) user and a specific date/time range, which are then displayed in a standard DataGridView control.
  • Audit Report Example (Spiders): this graphic form uses spiders (the visual programming language) to filter the available audit entries according to a specific date/time range, which are then displayed in a DevExpress Grid control.
