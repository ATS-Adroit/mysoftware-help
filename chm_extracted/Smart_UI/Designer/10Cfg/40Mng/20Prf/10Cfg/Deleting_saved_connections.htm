Deleting saved connections

The Automatically Update Profile profile setting can save the current SmartUI Server connections using their most recently used settings.

But if one or more of the saved connections refer to SmartUI Servers that no longer exist, then you can remove delete them from your profile.

To remove a saved SmartUI Server connection

  1. Edit the required profile.
  1. In the Profile Configuration dialog, select the Profile Connections dialog, from the left pane.

The Profile Connections dialog, displays the list of connection settings to all the Servers that are currently saved for the users of this profile. 

Tip: Select the title of the Item column to change the sorting order of this list of variables between ascending  and descending  order.

  1. Select the row of connection settings that you no longer require in the Item column.
  2. Click the Remove button.
