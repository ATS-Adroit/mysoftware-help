Customizing default scripting language

User profiles can specify the default scripting language used when creating scripts in the SmartUI Designer.

Scripts are typically written within the Script Editor in either the Microsoft Visual Basic.NET or Microsoft C# (CSharp) scripting languages.

Note: This scripting language can also be manually configured. For details, see Changing scripting languages in the Script Editor.

To customise the default scripting language

  1. Create a profile or edit the profile that applies to the current user.

Tip: Any user not associated with a profile has the Default profile applied to them.

  1. In the Profile Configuration dialog, select the Profile Properties dialog, from the left pane.
  1. Open the Script Language list and select the required scripting language.
