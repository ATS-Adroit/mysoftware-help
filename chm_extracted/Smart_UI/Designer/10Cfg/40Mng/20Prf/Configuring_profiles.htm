Configuring profiles

When a user profile is either created or edited use the Profile Configuration dialog to configure following profile settings:

  • Profile Properties: to change the attributes of the profile itself, the default SmartUI Designer settings and other settings.
    1. Type in the name of this profile in the Profile Name edit box. Click for more details:

      Note: This edit box can only be modified when a profile is being created. For details on renaming existing profiles, see Renaming profiles.

      Tip1: You can use any character for the profile name.

      Tip2: Use a descriptive name, which is as concise as possible - even though you can use up to 64 characters.

    1. Use the Automatically Update Profile checkbox, to remember the current SmartUI Server connections and the organization of the work environment. For details, see Customizing connections and work environment.

    2. Use the Graphic Form Language list, to specify the primary translation language of new graphic forms and the language used to display and operate new and existing graphic forms. For details, see Customizing the graphic form language.

      Note: This setting determines which language your operators will view your graphic forms in.

    3. Use the Show Hints checkbox, to display or hide the tool tips that appear within the SmartUI Designer, which explain common design tasks and remind users about context-sensitive usage tips.
    4. Use the Script Language list, to specify the default language used when creating scripts in the Designer. For details, see Customizing default scripting language.
    5. Use the Add Graphic Form Script Events on Double-click checkbox, to specify how events are added to the graphic form script, if at all. For details, see Customizing the adding of graphic form script events.
    6. Use the Script Editor list to specify which scripting environment is used to edit and debug scripts. For details, see Customizing default scripting environment.
    7. Specify whether you want to Auto Logoff users assigned to this profile and if so specify the maximum period of inactivity before the log off. For details, see Customizing auto logoff settings.
    8. Use the Apply Profile to Users/Groups list to specify which of the allowed user(s) and/or group(s) configured on the Server are to be associated with this profile. For details, see Associating profiles with users.

    Note: Profiles can only be associated with the allowed users and/or groups that have been added to the required Server.

  • Operator Settings: to customise the default display and permitted user interaction within the SmartUI Operator window, such as specifying a graphic form to open by default. For details, see Operator customization.

The display and the amount of interaction that a user has with the SmartUI Operator window, is determined by:

  • the user profile configured for this user in the SmartUI Designer. For details, see Operator customization.
  • and/or the command line argument options used to launch the SmartUI Operator. For details, see Operator command line arguments.

Note: The INITIAL display of the SmartUI Operator and configuration of the work environment can be configured by SmartUI Operator settings. For details, see Operator user interface settings.

  • User Profile Settings: to view the list of profile-specific variables. For details, see Viewing user-specific variables.
  • Profile Connections: to delete any SmartUI Server connections saved by the Automatically Update Profile setting, that you no longer require. For details, see Deleting saved connections.
