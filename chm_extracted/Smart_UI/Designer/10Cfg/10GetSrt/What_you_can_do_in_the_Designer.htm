Not sure what features are available in the SmartUI Designer?

The following links should help you get started:

Possible configuration after installation : a list of possible configuration items that may be required depending upon how the system itself has been setup.

The Designer provides a ribbon that consists of a number of tab that provide context-sensitive tools, to assist you in performing your tasks easily. For more details on the available options, see Working with the Designer ribbon.

Create the basic elements...

  1. Datasources : the available sources of data that you can connect to.
  2. Projects : to create and store graphic forms.
  3. Graphic forms : to graphically represent and manipulate data gathered from any datasource.
  4. Spiders : a visual programming language, which allows data to be transferred and/or manipulated, typically by means of drag and drop.

Import files...

  1. Import your Adroit Classic UI mimics: this describes the best practice process for exporting mimics from the Classic UI and importing these as SmartUI graphic forms.
  2. Import your Adroit Classic UI trends: this describes the best practice process for exporting trends from the Classic UI and importing these as SmartUI graphic forms.
  3. Graphic forms : graphic forms can be imported from other projects and/or Servers.
  4. Spider workspace configuration : to bulk configure spiders, silks and their template sets.

Design graphic forms...

Designing graphic forms: to provide the user interface that will allow end-users to interact with and examine the data displayed by the graphic form.

Tip: The Shapes Wizards & Examples tab of the Designer ribbon, provides access to the shapes, wizards and/or examples of the default Shapes Wizards and Examples project so that you can easily design your graphic forms. For details, see Working with Shapes Wizards and Examples.

In particular this contains the Situational Awareness category, which contains sub-categories of wizards that allow you to create process control user interfaces that strive to minimise operator fatigue and increase their response times. For more details, see Situational Awareness (or High Performance SCADA).

  • Configure levels and layers : to create overlays or masking effects.
  • Add form components : these are tools (the controls, components and/or graphic elements) for produce the user interface of a graphic form.
  • Animate graphic forms: to connect data to the graphic form and its added form components.
  • Translate graphic forms: to internationalise your graphic forms by translating the text of your graphic forms into the language/s required by their end-users. 

Troubleshoot...

  • The Diagnostics & Tools tab of the Designer ribbon allows you to launch a number of utilities directly within the SmartUI Designer, which can be used to troubleshoot and/or engineer your system. For details, see Utilities to troubleshoot and engineer your system.
  • The sample System Information project demonstrates how to use the System datasource and others to provide as little or as muchSmartUI and/or Adroit Server and/or Client troubleshooting functionality, according to your specific requirements. See System Information Project.

Manage...

  1. Users : create roaming user profiles, which simply allow users to retain their same user settings in the Designer and Operator applications regardless of the computer that they use.
  2. Security: configure both SmartUI Client and Server security

Tip: The Adroit Config Editor provides a System Backup and Restore feature that can backup and restore your SmartUI and/or Adroit user-configuration. For details, see System Backup and Restore.

Apply security...

  1. Projects : to control which users are able to access each project and/or their graphic forms. 
  2. Graphic forms : to specify which users can access which properties exposed by the controls added to the graphic form.
  3. Datasources : to secure the data and/or the exposed functionality of each datasource.
  • Data elements : this is how the data of a datasource is exposed and therefore these can be secured to control who may access them in order to provide the necessary security for your data.
  • Special functions: these are any additional functionality that a datasource provides for interacting with its data, therefore you are able to specify who is able to use each one.
  1. Profiles : to ensure that only certain users are able to manage the configuration of the SmartUI Designer and Operator, that can be carried out at a per user level and to limit the access users have within these applications too.

Produce...

Operating graphic forms : after designing a graphic form you can open it in the SmartUI Operator, so that its associated data can be viewed and interacted with.
