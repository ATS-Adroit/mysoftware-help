Working with the SmartUI Designer

The SmartUI Designer allows you to create and design graphic forms, customise its work environmentthe user interface of the Designer i.e. the tool windows, toolbars, menus and the Design workspace. and manage both user and data security at the same time. For details, see Customizing the work environment or Working with security

This broadly describes the main features of the work environment:

  1. Windows: The work environment of the SmartUI Designer consists of two types of windows, the Design workspace and tool windows, of which many are available. 

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

  1. Toolbar, ribbon and menus: Along the top of the program window are the toolbar and ribbon.
  1. Right-click menus: Extensive right-click menus provide support for doing the most common tasks. Place the cursor in the window that you want to work with, press the right-mouse button, and select an option from the menu.
  2. Toolbar: Click an icon on any of the toolbars as a shortcut to dialogs and actions. For details on the toolbar tools and the tools provided by the Home tab of the ribbon, see Generic Designer tools.
  3. Context-sensitive toolbars either appear at the top of the document in the Design workspace or at the top of the Designer window itself. The toolbar that is displayed, depends upon which document is currently displayed in the Design workspace.
  • Toolbars also occur in certain tool windows in which case they can either be on the top (Properties tool window) or the bottom (Toolbox tool window) of the tool window.

  1. Ribbon: Click the required tab to display the relevant tools, whose options are context-sensitive. The following tabs are provided:

  • Home: commonly used tools for connecting to the SmartUI Server, cutting and pasting and managing projects, see Generic Designer tools - this also describes the tools provided by the SmartUI Designer toolbar.
  • View: to manage the tool windows that are displayed, simply enable (icon has yellow background) or disable (icon has white background) the appropriate tool window icons and/or reset the current layout of the tool windows, see Accessing tool windows.
  • Project: tools to configure your projects, by importing specific content into graphic forms and/or editing the style of the currently selected project, if one has been specified, see Tools to import content into graphic forms and Working with Project Styles.
  • Design: tools to assist with arranging and designing form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. on the currently displayed graphic form. For details, see Tools for editing and designing vectors and/or controls.
  • Behaviours: tools to add and/or remove Behaviours from the currently selected form component of a graphic form. For details, see About Behaviours.
  • Shapes Wizards & Examples: provides access to the shapes, wizards and/or examples of the default Shapes Wizards and Examples project to easily design your graphic forms. For details, see Working with Shapes Wizards and Examples.
  • Configuration: typically intended for advanced users, to configure and manage your SmartUI applications and projects. For details, see Advanced configuration and management.
  • Diagnostics & Tools: typically intended for advanced users as it allows you to launch a number of utilities directly within the SmartUI Designer, which can be used to troubleshoot and/or engineer your system. For details, see Utilities to troubleshoot and engineer your system.
  1. Getting help: See Working with the online help and Customizing the work environment for more information.

Tip: Various hints, displayed via tool tips, explain common design tasks and remind users about context-sensitive usage tips. The display of these tool tips can be configured via the Show Hints checkbox of the profile, by default these are displayed. For details, see Configuring profiles.

Generic Designer tools: describes the tools provided by the SmartUI Designer toolbar and the Home tab of the ribbon.
