Context View tool window

The Context View tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms., logically groups or organises the deployed objects according to their defined attributes, so that they can be easily located and searched.

  • All the objects that have identical attributes are added as separate groups or 'contexts'.
  • The grouping created is hierarchical, and objects are further classified or grouped according to their specified values of this attribute. This lets you identify which objects have the same values and those which have been assigned a particular attribute.
    • If, for example, an attribute defines the power rating for equipment:
      • You would see all your equipment that has the same power rating.
      • If an attribute assigns the manufacturer, you could see all the equipment made by each manufacturer.
  • By defining common attributes for your deployed objects, the Context View window can become a handy tool in managing not just your deployed objects, but also your entire process.
  • Important:  These contexts are automatically generated and cannot be edited, indicated by the red key icon in the context list at the bottom of this window.

Organising your objects

You can edit the Default context to create your own logical organisation of your objects and other data, by either:

  • Adding the necessary hierarchy of nodes , or
  • if you have implemented Alarm Management, you can import your existing hierarchy of categories as nodes , with or without the agents that are associated with their configured incidents.
  • For detailed steps to editing the default context, see Editing the Default context.

The following actions are supported by all contexts:

  • Select the required context from the list of contexts in the Context View tab.

  • Search the Context View, by typing the search text that you want into the search box.

    • Any results that match the specified text are displayed in the results pane that expands below the top tool bar of this window.
    • By default, you only search for matching text within the currently loaded context.
    • However, if you click the filter button at the right of the search box, then you can specify which object attributes you want to include in this search, by selecting their relevant checkboxes.
    • If you have specified text that does not occur in the current context but does appear in another defined context that you have selected, then the applicable object name will show in the search results pane along with the full name of the attribute containing the searched text.
    • By default, the Include item name in the filter checkbox is selected.
      • The defined items in the context tree are searched for the specified text, such as the node names and any added data elements or object instance names.
      • If this checkbox is not selected then these item names in the context hierarchy are excluded from the search.
    • Items displayed in the Context View, provide the following right-click options, when applicable:
  • Show attributes - this is only displayed when the selected item is an object instance and lists all the attributes and values that are defined for this object.
  • Show children - this displays all the children of this item:
    • If this is an agent, then its slots are displayed as sub-items in the tree.
    • If this is an object instance, then all the defined child instances are displayed as sub-items in the tree etc.

Tip:  By default, the Context View window is also displayed in the SmartUI Operator

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

To access the Context View tool window:

  • Click the Context View tab, on the right-side of the SmartUI Designer application window.
  • For more information, see Accessing tool windows.
