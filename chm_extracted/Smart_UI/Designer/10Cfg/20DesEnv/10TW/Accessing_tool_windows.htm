Accessing tool windows

Accessing a tool or dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. can be difficult as it does not have a fixed location.

Choose one of the following methods to access the required tool window:

Tip: Dragging an item over a docked window tab, selects this window tab so that it can be dragged into this tool window.

  1. To access a tool window in its default location: click on the name or icon of its tab.
  1. To access a tool window from a customised location: if the tool window is in docked mode, locate it manually and if necessary click on the name and/or icon of its tab.

Note: If the tool window has been auto hidden then its icon and/or name of its tab will be located at the top, bottom, left or right of the application window.

If the tool window is in floating mode, simply click on its title bar.

  1. To access a tool window that cannot be located:
  1. Open the View tab of the ribbon.

The Content section displays the list of icons of the tool windows currently available in the SmartUI Designer application window - hovering over each icon displays the associated name of the tool window.

  1. If the entry is not selected (icon has a white background): click this item to turn it on (the background changes from white to yellow).
  2. If the entry IS selected (icon has a yellow background): click this item to turn it off (the background changes from yellow to white), then open the View tab again and select this icon again.
  1. This will immediately locate and open the required tool window in the SmartUI Designer application window.

The Spider Configuration Mode section of View tab of the Designer ribbon determines the visibility and user interaction within the Spider Configuration window, as follows:

Note: When changing from one mode to another, you need to close all open graphic forms.

  • Beginner: (default selection for new installs) the Spider Configuration window is not accessible at all and therefore does not appear in the Content list. This provides the added advantage that graphic forms open faster, since the visual components of the configured spiders are not loaded.

Note: This mode is required when using graphic forms that have an excessively large number of spiders.

  • Intermediate: the Spider Configuration window can be accessed (is added to the Content list) but is not displayed by default and any spider regions associated with configured Behaviours cannot be accessed (they remain closed).
  • Advanced: grants full access to the Spider Configuration window and opens this window.

However, with regard to spider regions associated with configured Behaviours, you are ONLY able to edit the existing spiders and are therefore prevented from:

  • dragging spiders into or out of this region
  • adding spiders to this region
  • deleting spiders from this region

Note: Tool windows can be arranged to increase the available designing space.

  1. To reset the layout of your tool windows: select one of the following options provided by the View tab of the Designer ribbon:
  2. Reset Window Layout: Restores the docked tool windows to the saved layout. This layout is saved when the Designer is closed (or when the default layout is applied).
  3. Reset to Default Layout: Restores the docked tool windows to the default or standard layout (specified by the product not the user).

Note: When this is performed the current layout is overwritten with this layout.

Tip: Use this option when your last saved layout is messed up, so that you can return your Designer to a functional state.
