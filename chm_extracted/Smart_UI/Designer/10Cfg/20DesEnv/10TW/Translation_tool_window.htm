Translation tool window

This tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms. contains the translation table for the graphic form that is currently is opened and displayed in the Design workspace and contains the following columns:

  • The Properties column: this contains each string property of every form component added to this graphic form. However, this translation table can be filtered to hide unnecessary entries from view.
  • The Graphic Form Language column: this is the language column, whose language description in its column heading is bold and underlined. It is typically next to the Properties column and is automatically added (i.e. is not manually added).

This language was configured when the graphic form was created and CANNOT BE CHANGED. It was the Graphic Form Language of the user profile of the user that initially created this graphic form, which by default is the language of the Windows operating system. For details on configuring this user profile setting, see Customizing the primary translation language of new graphic forms and the display language of new and existing graphic forms.

IMPORTANT: CAUTION should be used when manually editing the entries of the Graphic Form Language column directly in the Translation window as this is the reference column when importing other languages.

Since ONLY the translation entries (rows) of the imported language are imported, whose Graphic Form Language column entries MATCH in BOTH the graphic form and project translation tables.

Note1: This column therefore provides limited translation functionality compared to the other language.

Note2: By default this is also the Preview Language column.

  • Additional graphic form language columns: any additional language columns that you add to provide additional translations for the Graphic Form Language column. Typically you will add any languages that users of your graphic forms (your operators) require.

    Note: The language that your users view the graphic form in, is determined by the Graphic Form Language setting of their associated user profile.

    These language columns can be imported or exported or removed and therefore provide the necessary commands for these actions.

  • The Preview Language column: this is an OPTIONAL language column, whose language description in its column heading is bold and is the language that used to display or run the graphic form in the Designer, which is displayed when:
  • the Graphic Form Language of the user profile was changed to this language after creating this graphic form
  • a user manually selects another of the added language columns as the current preview language to test out its translations via the right click Preview Language operation.

Note1: Only the currentPreview Language column entries are updated when the text properties of the graphic form and its components are directly edited.

Note2: By default, the Graphic Form Language column is the Preview Language column.

For further details about translating graphic forms and their configured graphic form components, see Translating graphic forms.

To access the Translation tool window:

  1. Click the Translation tab, which is at the bottom of the Designer application window, by default. For details, see Accessing tool windows.

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

Tip: If you right-click on any item in the Translations tool window, a menu will open with the available options, if any, for working with that item.
