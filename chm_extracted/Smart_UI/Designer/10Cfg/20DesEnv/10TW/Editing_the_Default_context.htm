Editing the Default context

The Context View tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms., provides the Default context, which is the only context that you can edit to create your own logical organisation of your objects and/or other data, by either:

  • manually adding the necessary hierarchy of nodes (contextual areas)

  • or if you have implemented Alarm Management, you can import your existing hierarchy of categories, with or without the agents that are associated with their configured incidents.

Tip: You can use the TemplateGOContextNav control to display the graphic forms associated with the nodes and/or added to the nodes of this Default context. For details, see TemplateGOContextNav controls.

To edit the Default context:

Select the Default context from the list of contexts to the left of the bottom tool bar of this window.

Click the Edit button in the bottom tool bar of this window to create your own logical organisation of your objects and/or other data, by either:

You can then either Save the recent changes made to this Default context since it was last saved or Cancel these changes, by selecting the appropriate tool from the bottom tool bar of this window.

  • manually create the necessary hierarchy of nodes , which are like folders in the Context View, each of which typically represent a specific contextual area and can contain additional nodes or a graphic form associated to them or have data elements and/or object model objects added to them:

    Add or Edit a node to specify the Node Name, which is the literal description used when navigating the defined hierarchy and Node Descriptor, which is typically a 3 character code to reference the specific contextual area that is represented by this node. For more details, see Configuring Node names and descriptors.

    Once you have created your hierarchy of Nodes, which typically represent specific areas of your context, then you can add the following items to it either by clicking the relevant tool from the top tool bar of this window or right clicking the node and selecting this option from the menu:

    • Associate a graphic form to a node. For details, see Associating a graphic form to a node .

    Tip: The following icon indicates that a node has an associated graphic form:

    Note: You can also remove this associated graphic form via the right click option.

    • Browse for Data Element to add it to a node: Typically adding data elements to the various nodes of the Context View is useful for design time and not run-time, as it allows you to logically group your agents and other data together in the contextual areas that they are used.

    However, you can use this facility to add additional graphic forms to your nodes, which can be opened at run-time, if need be, since graphic forms are simply data elements of projects. For details on browsing for data elements, see the Data element browser.

    • Create an object instances in a node: This Default context lends itself to the creation of object instances, especially those whose name and substitution/s use a predefined naming convention that specifies the context in which the instance is created. For details, see Creating contextually sensitive object instances.

    • Deploy an object instances in a node: Once an instance has been added to a node it can be deployed or redeployed at any time. For details, see Deploying an Object Instance.

  • or click the Import from alarm management in the bottom tool bar of this window to import a pre-configured context from the Alarm Management agent, which requires that you have at least one pre-configured Alarm Management agent.

    Note: You only need to specify which Alarm Management agent, you want to use, if you have more than one.

    This displays the Include agents? confirmation dialog:

    • if you click Yes then you also import the agents that are associated with the configured incidents in addition to the Alarm Management hierarchy of defined categories.

    • if you click No then you ONLY import the Alarm Management hierarchy of defined categories.

For more details about the Context View window, see Context View tool window.
