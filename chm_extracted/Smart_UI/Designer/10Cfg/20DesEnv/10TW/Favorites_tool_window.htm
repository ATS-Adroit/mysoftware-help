Favorites tool window

This tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms. allows you to create your own custom set (library) of your favorite graphic forms and wizards, which you frequently use. This helps to speed up the process of designing your graphic forms, since you can directly drag these from this tool window onto your graphic forms without having to find them in their relevant projects.

Note: Projects and their folders provide a Preview Graphic Forms option to displays thumbnail snapshots of all the graphic forms located in their immediate or root level to either open the required graphic form or populate the Favorites tool window. For details, see Previewing graphic forms.

  • These graphic forms (which are typically SmartUI Templates) are displayed within TemplateGO controls in the graphic forms that you design. For details, see TemplateGO controls and/or SmartUI Templates.
  • These wizards can be dragged as-is onto the graphic forms that you design. For details on using wizards, see Working with wizards.

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

To access the Favorites tool window:

Click the Favorites tab , on the right side of the Designer application window, by default. For details, see Accessing tool windows.
