Contents tool window

This tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms. displays the contents of the following grouped items on the currently displayed graphic form, so that you can edit each contained vector and/or control and their configured Behaviours:

  • menu strip components. For more information, see MenuStrip components.

  • vector groups. For details on creating vector groups, see Vector tools for editing and designing vectors.

    Note: Once created the Tasks list of the vector group (accessed by clicking its glypha glyph is a specific graphic symbol, for instance employed by form components, which when clicked launch alternate configuration dialogs., which is usually displayed in the top left corner of the selected control) provides the Child Behaviours list, to display all the Behaviours added to its component vectors, so that these can be edited or deleted or added. For details, see Child Behaviours.

  • Generic Containers (typically created to contain Wizards). For more information about wizards, see Working with wizards.

 

Check the Behaviours only checkbox to only display the Behaviours of the currently displayed vector/s and control/s in this window.

Click the Collapse All / Expand All button to hide or show every vector and control and their configured Behaviours.

Tip: Behaviours are displayed in blue for ease of reference.

 

To edit configured Behaviours: double click the Behaviour

To remove configured behaviours: right click the Behaviour and select Remove Behaviour.

To access the Contents tool window:

Click the Contents tab, on the right side of the Designer application window, by default. For details, see Accessing tool windows.
