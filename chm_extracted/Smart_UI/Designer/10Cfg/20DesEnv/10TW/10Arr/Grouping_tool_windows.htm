Grouping tool windows

Tool windows can be grouped together or tab-docked into the same window.

This automatically creates a tab, at the bottom of this grouped tool window, by which each of the windows can be accessed. Click for more details:

This and other techniques can be used to conserve space within the work environment. For details, see Arranging tool windows.

The tool window tab, that is created, consists of both the tool window name and icon. For details of the names and icons that will be used for all the tool windows provided by the Designer application window, see Available tool windows

Note: Grouped tool windows behave exactly the same as a single tool window i.e. occupying the same area on the screen. For this reason the tool windows within a group cannot be displayed simultaneously.

To add tool window/s to one or more grouped tool windows:

  1. Locate and open the required tool window or group of tool windows. For details, see Accessing tool windows.

Note1: Ensure that this tool window is not Floating or being auto hidden, if so deactivate these features first.

Note2: Double-clicking the tab of a grouped window, frees this window from the group so that it can be re-docked as required. Double-clicking it again docks it in its former position.

  1. Click in the title border of the tool window that is to be moved.
  2. Drag this window or group of windows into the required tool window.
  3. Select the tab menu option from the displayed overlay docking menu.

Note: The position of the mouse pointer determines which docking menu option is selected.

This will display a shadow over the selected tool window, indicating the position of the tab for the tool window/s being dragged - if correct then release the mouse button to accept this position.
