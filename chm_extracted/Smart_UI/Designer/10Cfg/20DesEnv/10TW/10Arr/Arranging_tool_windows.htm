Arranging tool windows

The primary reason for arranging tool windows is to increase the viewing and editing space provided by the Design workspace. For details, see Design workspace.

Note: Accessing a tool window can be difficult as it does not have a fixed location. For details on this and for how to reset your current layout of your tool windows in the Designer, see Accessing tool windows.

Although tool windows can be either be arranged singly, it is also possible to group one or more tool windows together. Once grouped, these tool windows behave exactly the same as a single tool window, even occupying the same area on the screen. For details, see Grouping tool windows.

For this reason, the following techniques, for conserving space in the work environment, can be similarly applied to both single or grouped tool windows alike:

  1. Docking tool windows: To typically snap a tool window to one of the four borders of the Design workspace. For details, see Docking tool windows.
  1. Floating tool windows: To separate the tool window from the Designer application so that it floats on top of the other windows where it CANNOT be docked. For details, see Floating tool windows.
  1. Automatically hiding and showing tool windows: To minimise a tool window along the respective edge of the Designer application window. For details, see Automatically hiding and showing tool windows.

Note: Auto hidden windows are incompatible with many of these other methods of arrangement.

  1. Hiding and displaying available tool windows: The View menu displays a content sensitive list of the currently available tool windows and can be used to hide and display these windows. For details, see Hiding and displaying available tool windows.
  2. Displaying tool windows on different monitors: If you have a second monitor, and your operating system supports using it, you can choose which monitor to display your tool windows on. For details, see Displaying tool windows on different monitors.

Note: If necessary, your profile can be used to save any changes you make to the location of the tool windows. For details, see Customizing connections and work environment.
