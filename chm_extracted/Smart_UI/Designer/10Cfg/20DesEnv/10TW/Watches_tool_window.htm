Watches tool window

This tool windowtool windows are dockable windows, which provide several arrangement options to increase the size of the Design workspace window used for designing graphic forms. makes it possible to quickly view (and if possible modify) the real-time value of data elements in the SmartUI Designer.

Tip: Dragging an item over a docked window tab, selects this window tab so that it can be dragged into this tool window, which is particularly useful when dragging data elements into this Watches tool window.

Instead of connecting these values to forms components and then running and previewing a graphic form in the Design workspace. For details, see Running graphic forms.

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

This tool window is divided into two panes, namely:

  1. The left pane contains an explorer tree view, which provides the identical user interaction as the Enterprise Manager to add new datasources or expose data elements of existing datasources that can be added to the watches list. For details, see Adding datasources, Opening datasources or Enterprise Manager tool window.

Note: This pane is hidden (collapsed) by default.

  1. The right pane contains the list of monitored data elements (watches), which provides the following columns:
  • Name: The data element namespace, which adheres to the following format: DatasourceName[.SubDivisions].DataElementName, where the SubDivisions are optional and depend upon the structure of the data within the selected datasource. 
  • Value: the value of the data element if this value can be converted into a string, if not then this will display its data type instead - in this case click the associated to provide an alternate (specially formatted) view of this data.

The value of this data element can be modified, by double clicking the necessary cell in this column and specifying the new value. However, this value will only remain if this datasource allows the value of this data element to be changed, otherwise it will revert to its original value.

Note: Any errors are marked in red.

  • Alternative views : certain types of data require specific formatting before their data can be fully appreciated. For instance dataset data needs to be tabularised.

    For this reason visualisers or alternate views are provided for viewing the values of the following data types:

  • System.Data.DataSet:

DataSet Visualiser: To view the data of this dataset in a table.

The top of this dialog provides the Table drop down list to select the name of the required table.

The fields of the selected table are displayed at column headers.

Note: The records are ONLY viewable, you cannot edit them.

Use the Close button to close this dialog.

  • System.String

Text Visualiser : To view the String data in a plain text editor.

The top of this dialog provides the Name of this data element.

The text is displayed on separate, numbered lines. Namespaces can be expanded and collapsed.

Use the Close button to close this dialog.

HTML Visualiser: To view the String data in an HTML editor.

The top of this dialog provides the Name of this data element.

The text is HTML formatted and any HTML-keywords are highlighted.

Use the Close button to close this dialog.

XML Visualiser: To view the String data in an XML editor.

The top of this dialog provides the Name of this data element.

The text is XML formatted and any XML-keywords are highlighted.

Use the Close button to close this dialog.

  • Type: the type of data contained by the data element as a namespace, which adheres to the following format: DataTypePrefix.DataType e.g. System is the prefix used for all Microsoft specific data types. 
  • Trend: a trend of this value as it changes over time or if the value is not displayed then this is provides the latest timestamp of this data element.
  • Last Updated: the latest timestamp of this data element, indicating when it was last updated.
  • Status: this specifies whether the value of this data element was able to be successfully read or not i.e. either GOOD or BAD (which could also indicate that the connection was lost).

Note: These panes are separated by a pane display bar, which can either hide or display the left pane or adjust the relative size of both panes. For details on using a pane display bar, see Working with pane display bars.

To access the Watches tool window:

  1. Click the Watches tab, which is at the bottom of the Designer application window, by default. For details, see Accessing tool windows.

To add a data element to the watches list:

  1. Expose the required data element in the left explorer pane.
  2. Drag the data element into the watches list.
  3. The data element will be added to the end of the list.

Note: Data elements are only temporarily added to this watches list, once the current user logs off the list will be emptied.

To remove a data element from the watches list:

  1. Right-click the required row to remove a data element from the watches list.

WARNING! The row that is right-clicked is immediately removed from the watches list.
