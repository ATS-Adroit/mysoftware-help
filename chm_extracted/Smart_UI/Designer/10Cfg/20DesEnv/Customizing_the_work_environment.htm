Customizing the work environment

The SmartUI Designer has been created to be an adaptable tool that allows you to work in the manner that is most convenient and comfortable for you. This topic describes some of the ways in which you are able to customise the work environment to suit your needs exactly.

Note: To ensure that the data provided by the connected Server(s) is secured, the level of access granted to the users of the Designer can be individually configured, see Working with security.

The work environmentthe user interface of the Designer i.e. the tool windows, toolbars, menus and the Design workspace. of the Designer consists of two types of windows, the Design workspace and tool windows. For details, see Design workspace or Working with tool windows.

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

The work environment can be customised on a per user basis through the creation of profiles, which provide the following customizable settings:

  1. Customise the positions of the menus, tool windows and toolbars within the Designer. This allows you to perfect the organization of the work environment. This will also save any connections that are made to other Servers within the Enterprise Manager. For details, see Customizing connections and work environment.

Note: Profiles can also be used to customise the display and the permitted user interaction of the SmartUI Operator. For details, see SmartUI Operator customization.

 

You are also able to customise the form componentsa general term encompassing all the controls, components and / or graphic elements that can be added to graphic forms, to provide the required user interface for its end-users. See control; component; graphic element; graphic form. that can be used when designing graphic forms, by including third party components and/or importing ActiveX controls into the Toolbox tool window. For details, see Designing graphic forms or Including third party form components.
