Design workspace

The Design workspace is the main work area, which is always opened in the center of the SmartUI Designer application window. This contains all the currently open documents.

Only one document can be displayed within this window at a time, where it can be viewed and/or configured as required.

Note1: Increase the viewing and editing space provided by the Design workspace, depending on how you arrange the tool windows in the work environment.

Note2: Press F11 to activate the Fullscreen mode which hides everything except the selected graphic form in the Design workspace, a floating Toolbox window and floating tool and menu bars.

Each document that is opened is identified by means of a tab, which is displayed at the top of this window, to easily selectposition the mouse pointer over the item and press the left mouse button; also known as clicking. the required document.

If one or more documents are already opened, then this tab is added to the right of any existing tabs. Click for more details: 

Note: The number of letters displayed by the tab, depends upon the number of documents that are currently opened and the size of the Designer workspace window, since all the tabs are visible, regardless of the number of documents that are opened.

Tip1:It is recommended not to open too many documents at once, since eventually only the first letter of each tab is visible, making the identification of the required document very difficult.

Tip2:The Window menu shows the graphic forms that are currently open in the Design workspace so that you can easily navigate between them.

Depending upon the document displayed in the Design workspace, various buttons are also displayed to the right of the tabs at the top of this window, as follows:

  • By default, the following button  is displayed, which when clicked automatically selects the most recently opened document i.e. the rightmost tab.
  • When a graphic form is displayed, this  button appears in the top-right corner, which if pressed closes the graphic form.

To display an opened document in the Design workspace

  1. Simply, click on the tab, associated with the document you require.
