Working with Find and partial Replace

The primary purpose of a graphic form is to display data elements (tags). Over the years a number of separate mechanisms have been created to make this process as easy as possible and/or to facilitate their duplication to save on their engineering time. This means that:

  • locating all the references of a tag on a graphic form is a non-trivial task and so this tool is essential and

  • not all of these mechanisms allow the tag to be externally replaced by this tool, without breaking the mechanisms themselves.

    Since these mechanisms fall into two main categories:

    • those that directly link a tag to an component on a graphic form. More details:

      • properties of controls or vectors. See Quickly linking properties to data elements.
      • inputs of appropriate spiders. See Working with spiders.
      • Behaviours. See About Behaviours.

    • those that use some sort of intermediary mechanism to indirectly link the tag to a graphic form. More details:

      • Graphic form aliases. See Working with aliases.
      • Graphic form scripts. See Graphic form scripting.
      • Behaviours that belong to wizard instances. See Working with wizards.
      • Data elements that belong to wizard instances

    and it is these indirect mechanisms that prevent the direct replacing of the tag with another.

To work around this limitation, the following two utilities have been created which have different capabilities or uses:

Note: These searches are not case-sensitive.

  • The GLOBAL Find utility in the Project group of the Home tab of the SmartUI Designer ribbon, enables you to select one or more graphic forms of one or more projects to find where text, typically a tag (agent name), has been referenced and used, you can then export the list of located references to Excel.

    Note: This utility only appears when the Spider Configuration Mode section of View tab of the Designer ribbon is set to Advanced, since it is intended for advanced users only.

    This utility can save much time when redesigning large projects and when creating and maintaining multiple SCADA systems in keeping track of your agents or other graphic form components.

    Note: You need to close all open graphic forms before you can use this tool and you cannot perform any other action in the Designer while this utility is open.

  • The LOCAL Find and Replace utility in the graphic form toolbar, searches for the specified text, typically a tag (agent name), in the currently selected graphic form and unlike the other utility provides:

    • an Edit column in the Find Results tab that allows you to edit the indirect mechanisms so that you can change these references to the required replacement one at a time;

    • the Replace tab to replace the direct references to the searched for text with the specified replacement and
    • a moveable dialog, so that you can carry on working on others things or can find and replace text in more than one currently open graphic form.

    This utility also allows you to export the list of references to the searched for text to Excel, if needed.

To find text in the graphic form/s

To replace DIRECT text references in a graphic form

To find text in the graphic form/s:

  • If you need to search one or more graphic forms of one or more projects, then click the GLOBAL Find utility in the Project group of the Home tab of the SmartUI Designer ribbon.

    Note: This utility only appears when the Spider Configuration Mode section of View tab of the Designer ribbon is set to Advanced, since it is intended for advanced users only.

  • If you need to search one or more of the currently open graphic forms for a full or partial tag name and replace the direct references and/or edit their indirect tag referencing mechanisms to manually change this tag, then click the LOCAL Find and Replace utility in the graphic form toolbar.

The Find tab is displayed by default, which allows you to specify the text, typically this would be the full or partial agent (tag) name, that you want to locate in the Text to find field. More details:

You can click the browse button to the left of this field and use the data element browser to select the required tag that you are looking for.

Tip: This search does not need to support wildcard characters, since any reference to the specified text is located.

  • For the GLOBAL Find utility, select the required project/s and/or the graphic form/s from the Look in tree. More details:

This lists all the available projects on the default SmartUI Server.

When a project is selected it will load all the graphic forms in this project, which may take some time for large projects.

By default all the graphic forms are selected to be searched in this project. If you only want to search specific graphic forms and EXCLUDE others, then clear the checkboxes of the graphic forms you do not want searched.

  • For the LOCAL Find and Replace utility, Look in specifies the full path of the currently open graphic form that will be searched for the specified text.

Click the Find button, which displays the located references to the specified text in the selected graphic form/s of the selected project/s in the Find results tab of the Results section.

The references to the specified Text to find are classified in each graphic form into the following two groups, for ease of reference:

  • Replaceable: These are the references that can be directly replaced, whose Replaceable column is Yes.

IMPORTANT: If the Text to find refers to a tag (or a portion of a tag name) this does NOT display ALL these direct (replaceable) tag references!

This ONLY lists the Behaviours that currently contain this tag, ignoring all references of the spiders and/or controls that are directly linked to this tag. When the tag is not used by a Behaviour then a SINGLE reference to its DataElement spider is added to the list, regardless of how many spiders and/or controls are directly linked to this tag.

Note: When replacing this text ALL the direct (replaceable) tag references ARE replaced.

  • Unreplaceable: Manually Editable in Local Find: These are the greyed out references that cannot be directly replaced, whose Replaceable column is No.

The references, in both lists, are further classified by their Type, which is one of the following:

  • Behaviours: this Type typically include any of the following Behaviours containing the complete or partial tag name: Bind, color, Display value, Execute Command, Location, Operator Action, Percentage fill, Rotation, size, Tooltip and Visibility.
  • Properties: this Type contains:
  • any TEXT Property of a control containing the complete or partial tag name and the Results indicate the name of the control and then the name of the Property OR
  • the Graphic Form Script, that contains the complete or partial tag name and the Results indicate the line in this script in which it was located OR
  • any aliases configured for this graphic form, which contain the complete or partial tag name
  • Spiders: this Type only displays those spiders to which the complete or partial tag name has been specifically connected to, as follows:

IMPORTANT: Furthermore this only displays the spiders to which the specified agent name is directly (initially) connected and NOT the spiders that reference this spider.

  • when searching for a complete tag name, this section typically only contains DataElement spiders (which in turn can be linked to multiple spiders, such as Mathematical spiders etc.) and Application spiders.
  • when searching for a partial tag name, this section can also contain String Format and Variable Data Element spiders.

For the LOCAL utility:

  • clicking a row in the Find Results tab selects the object that the row pertains to, in other words:
  • the applicable control is selected on the graphic form that, for instance, has the selected Behaviour and/or
  • the applicable spider is selected in the Spider workspace.
  • the Edit column provides browse buttons next to each reference that is NOT directly replaceable so that their indirect tag referencing mechanism can be edited to change this tag reference to the required one, as follows:
  • Any Behaviour or tag reference within a wizard: displays the Wizard substitutions dialog.
  • Aliases: opens the Edit aliases dialog.
  • Graphic Form Script: opens the Script Editor displaying this script.

Note: Any errors are displayed in red at the bottom of this Find tab.

You can export the references listed in Find results to an Excel Formatted XML document for reference purposes. Simply click the Export button to specify the name and location of this (*.xml) file. More details:

By default, the file name is called FindResults.xml and is saved into the current Configuration folder.

This file displays the Search Text and then lists the located references of this text in a table with the following columns for ease of reference: Graphic Form, Object, Type, Details, Replaceable, Reason, where the Reason column provides the reason when the Replaceable entry is No .

The Advanced View button displays the Exclude property spiders checkbox, since it is NOT typically recommended to uncheck the checkbox to include all property spiders and their inputs in the search.

To replace DIRECT text references in a graphic form:

You can ONLY perform a replace when using the LOCAL Find and Replace utility in the graphic form toolbar.

IMPORTANT: There is no undo mechanism - so be VERY SURE before replacing tag references.

Note: You need to find the required full or partial tag name first before you can replace it with something else.

Click the Replace tab, which adds the Replace with field.

Specify the text in the Replace with field that you want to replace the text that you have already searched this graphic form for, which is specified in the Text to find field for the currently displayed graphic form (as specified in the Look in field).

Having performed a Find all the results in the Find results tab, whose Replaceable column is Yes are selectable (not greyed out) and ONLY these can be directly replaced.

Either manually check the individual checkboxes of the required results that you want to replace or click the Check All.

Note: If you perform a Check All ONLY the non greyed out results are selected (those whose Replaceable column is Yes) .

Click the Replace button.

IMPORTANT: There is no undo mechanism - so be VERY SURE before replacing tag references.

All the references to the selected results are replaced. For instance this only lists the Behaviours that currently contain the searched for tag, ignoring all references of the spiders and/or controls that are ALSO directly linked to this tag. However ALL of these references will be replaced when this Behaviour is selected.

Once the text in the Text to find field has been replaced with the text in the Replace with field for the currently displayed graphic form (as specified in the Look in field) then the graphic form is searched again for any references to the text in the Text to find field to identify:

  • any Find results whose Replaceable column is Yes that you may want to directly replace or
  • any Find results whose Replaceable column is No that CANNOT be directly replaced, in this case you need to click their browse button in the Edit column, so that their indirect tag referencing mechanism can be edited to change this tag reference to the required one, as follows:
  • Any Behaviour or tag reference within a wizard: displays the Wizard substitutions dialog.
  • Aliases: opens the Edit aliases dialog.
  • Graphic Form Script: opens the Script Editor displaying this script.
