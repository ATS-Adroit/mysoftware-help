Working with scrollbars

Scrollbars provide easy navigation when designing and operating large graphic forms that exceed the height and/or width of the workspace.

In addition to the normal usage of scrollbars, the following additional navigation options are available:

If you right-click a vertical scrollbar, the following options are displayed:

Name Function

Scroll Here

Scrolls window vertically to location where you have clicked.

Top

Scrolls window to top of window.

Bottom

Scrolls window to bottom of window.

Page Up

Scrolls window up a page width.

Page Down

Scrolls window down a page width.

Scroll Up

Scrolls window up incrementally, similar to clicking the scroll bar arrows.

Scroll Down

Scrolls window down incrementally, similar to clicking the scroll bar arrows.

 

If you right-click a horizontal scrollbar, the following options are displayed:

Name Function

Scroll Here

Scrolls window horizontally to location where you have clicked.

Left Edge

Scrolls window to left of window.

Right Edge

Scrolls window to right of window.

Page Left

Scrolls window left a page width.

Page Right

Scrolls window right a page width.

Scroll Left

Scrolls window left incrementally, similar to clicking the scroll bar arrows.

Scroll Right

Scrolls window right incrementally, similar to clicking the scroll bar arrows.
