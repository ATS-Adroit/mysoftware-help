Utilities to troubleshoot and engineer your system

The Diagnostics & Tools tab of the SmartUI Designer ribbon, is typically intended for advanced users as it allows you to launch a number of utilities directly within the Designer, which can be used to troubleshoot and/or engineer your system.

For ease of access, these utilities are classified into the following general groups:

IMPORTANT: Of the following tools that affect the Agent Server, these ONLY work when the Agent Server is installed on the local computer, they are NOT able to access remote Agent Servers.

Monitoring:

Tool Name Description
Scanning Monitor This utility is designed to assist experienced users in fine-tuning the scanning subsystem to achieve optimal performance, by providing an intuitive report-like view of advanced diagnostic information. For details on how to use this utility, see How to use the Scanning Monitor Utility.
Driver Monitor

This utility allows users to monitor the operation of their installed protocol drivers and provides many diagnostic capabilities, such as the Datascope window, which displays the data that is being transmitted between the SCADA and the front-end device (typically a PLC). For details on how to use this utility, see Working with the Driver Monitor.
Agent Server Monitor

This utility is typically provided for advanced users for diagnosing or troubleshooting the Agent Server. For details of the provided information, see Working with the Agent Server Monitor.
OPC Browser This utility allows you to display all the items within an OPC Server and if necessary, you can browse for and select the required address of particular OPC items. For details on how to use this OPC Browser to obtain an OPC item address, see Browsing for OPC Item Addresses.

Diagnostics:

Tool Name Description

WGP Inspector

This utility inspects the structure of your existing Agent database (.WGP) files. For details on how to use this utility, see Working with the WGP Inspector.

Editing:

Tool Name Description
UDT Agent Type Designer This utility creates agent types (templates) that duplicate the structure of any User-Defined Types (UDT) used by your PLCs, by adding properties (basic data types) to them and if necessary to configure status slots for the purposes of alarming. For details, see How to use the UDT Agent Type Designer.
Custom Agent Designer

This utility allows you to create user-defined agent types, for instance to represent complex devices that ordinarily would be represented by multiple instances of analog, digital or other common agent types. For details, see How to Use the Custom Agent Designer.

Information:

Tool Name Description
Adroit File Version Information This utility, displays the file versions and revisions (and driver revisions) of the files in the Adroit installation folder, by default, although you can view any folder.

Tip: This is especially useful when running on Windows 7 or later, since Windows Explorer disallows access to this information.

By default this utility ONLY displays these details for the .exe, .dll and .ocx files - although the Show version information for all files checkbox allows you to obtain this information for ALL files in the specified folder.

  • The File Revision column specifies the Adroit file revision, which is specified as the last digit after the last dot (period), such as for adralarm.dll this is 8.4.2.35 which, in this case, indicates that this is revision 35 of this Adroit 8.4.2 file.
  • The FileVersion column specifies the Microsoft Windows file version, which for this same file is 8.4.0.0, which is not that useful.

The Export button, exports the file list to the c:\temp\adrfileinfo.csv file and displays this file in the default .CSV file editor.
SmartUI File Version Information

This utility obtains the versions of all the .DLL and .EXE files in the SmartUI installation folder (including its sub-folders) and you can export this version list to a .CSV file.

This is primarily a troubleshooting tool, so that users can email the .CSV file of these file versions to support, so that support can quickly determine if the installed files are the latest or which files may be causing a problem. For details on using this utility, see How to use VIP Version.

Licensing:

Tool Name Description
Adtech Licensing Utility

Adroit is licensed via the Agent Server and this licensing typically occurs via a HASP software protection key, which is programmed in accordance with the required license. 

This utility allows you to get, view and/or update your Adroit product license. For details, see Working with the Adtech Licensing Utility.

Other Tools:

Tool Name Description
Scheduler

This utility allows you to run commands and utilities run today, tomorrow, or on a particular day of the week or month at a specific time. For details, see Scheduling Commands and Utilities.
