Generic Designer tools

The SmartUI Designer toolbar appears at the top, which provides the following tools:

Tool Function Description

Undo 

Undoes the last operation that was performed.

Redo

Repeats the last operation that was performed.

 

The Home tab of the SmartUI Designer ribbon, also provides the following commonly used tools, which are classified for ease of use into the following groups:

Connection:

Tool Function Description
Connect To connect to or log onto the required SmartUI Server computer.
Disconnect To disconnect from the current SmartUI Server computer.
Refresh

To update the current connections, for the following reasons:

  • To display any recent changes made to the data exposed by these SmartUI Servers i.e. the changes that have been made to their datasources.
  • To determine if a disconnected connection is now available. For details, see Disconnected connections. 
Save Server Data To save all configuration changes made to the default (login) Server. For more details and how to save the configuration changes of other connected Servers, see Saving changes made to connected Servers.

For more details about using connections, see Working with connections.

Clipboard:

Tool Function Description

Cut

Removes the selected item and places it into the clipboard, so that it can be pasted one or more times.

Copy

Copies the selected item and places it into the clipboard, so that it can be pasted one or more times.

Paste 

Inserts the last item that was placed into the clipboard at the specified location.

Project:

Tool Function Description
New Folder To add a new folder to the currently selected project to organise its graphic forms.
New Graphic Form

To add a new graphic form to the currently selected project.
New Graphic Form (Styled)

To add a new graphic form to the currently selected project that using the style of this project to configure its default appearance, only if one has been specified. For details, see Working with Project Styles.
New Project To add a new project to contain graphic forms and/or folders.
New Wizard To add a new wizard to the currently selected project. See Working with wizards.
Delete To delete the currently selected project, folder or graphic form.
Find

To find where a tag (agent name) has been referenced and used throughout a project. See Working with Find and partial Replace.

Note: This utility only appears when the Spider Configuration Mode section of View tab of the Designer ribbon is set to Advanced, since it is intended for advanced users only.

Tip: To replace this text you can use the Find and Replace utility in the graphic form toolbar.

For more details about using projects, see Working with projects.

Graphic Form:

Tool Function Description
Save To save any changes that have been made to the currently displayed graphic form.
Save As

To save the currently selected graphic form to another graphic form name within the same project.
Save All To save any changes that have been made to all the currently opened graphic forms.
Close Graphic Form To close the currently selected graphic form.
Close All Graphic Forms To close all the currently opened graphic forms.

Agent Server

Tool Function Description
Open Configurator

To edit or configure the agents within an Adroit Agent Server. See Working with the Agent Configurator.

Note: When there is more than one Adroit datasource available, a list is provided to select which Agent Server to configure.
