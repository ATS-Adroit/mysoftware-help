Working with configuration dialogs

Configuration dialogs are used extensively for the purposes of configuration.

A configuration dialog is essentially a common dialog that configures a process that can consist of one or more steps or components.

Note: When a configuration dialog is launched within an application, all further user interaction with this application is prevented until the configuration process is either finished or cancelled.  

Configuration dialogs provide the following navigational features:

  1. The left pane contains a tree view, containing the headings of the steps or components that can be configured, using this configuration dialog. This pane can be hidden from view.

Tip: Click on the required heading to select this configuration step.

  1. The right pane, which is always displayed, contains the dialog in which the configuration of the displayed step or element can be performed.
  2. The left border of this right pane contains a pane display bar, which can either hide or display and adjust the relative size of the left pane of the configuration dialog. For details on using a pane display bar, see Working with pane display bars.
  1. Buttons at the bottom of the configuration dialog, such as the following commonly used buttons:
  1. Cancel: To close the configuration dialog and abort the configuration process, so that any configuration changes that have been made will be lost.
  2. <<Previous: To display the dialog of the previous step or element of the configuration process.
  3. Next>>: To display the dialog of the next step or element of the configuration process.

Note: Depending upon the position of the current dialog in the sequence of steps, either the <<Previous or Next>>buttons may be disabled.

Tip: Instead of using the <<Previous and Next>>buttons, click on the required step or element in the left pane of the configuration dialog.

  1. Finish: To save the configuration changes made and close the configuration dialog.
