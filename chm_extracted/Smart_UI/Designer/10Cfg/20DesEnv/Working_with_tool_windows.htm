Working with tool windows

The work environmentthe user interface of the Designer i.e. the tool windows, toolbars, menus and the Design workspace. of the Designer consists of two types of windows: the Design workspace and tool windows. For details, see Design workspace.

Note:  Each tool window is a dockable windowa window that can be either be attached to a docking area or that can float anywhere on the screen. See floating mode; docked mode; docking area. whose location can be customised to increase the viewing and editing space provided by the Design workspace.

For more information, see Arranging tool windows.

Tool windows have been used extensively within the work environment of the Designer. For details, see Available tool windows.

Since tool windows are dockable, they have the following two display modes:

  1. Dockable mode, in which a tool window is usually attached to the Designer, typically along any of the four borders of the Design workspace window, where it can be accessed by means of a tab - if more than one tool window is currently docked at this location. For details, see Docking tool windows.

Note: A tool window in Dockable mode can be undocked by double-clicking its title bar, in which case it is able to be moved to another location etc, however this is can at any time be re-docked.

Tip: Dragging an item over a docked window tab, selects this window tab so that it can be dragged into this tool window.

  1. Floating mode, in which a tool window becomes a separate window, with a thin title bar and can appear anywhere on your screen and CANNOT be docked.

    A floating tool window is always on top of all other windows and can be resized as required. For details, see Floating tool windows.

Tip: Simply double-click the title bar of a tool window to change from one display mode to another.

Tool windows now provide the Window Position title bar icon, that can be used to perform many arranging tasks. For details, see Arranging tool windows.
