Working with Show (All) Information

To assist in troubleshooting your graphic forms, the SmartUI Operator can allow a control or vector, on the displayed graphic form, to display the list of all the data elements connected to its properties, to do the following:

  1. to view the quality (good or bad) status of the data element
  2. allow you to copy this data element name and
  3. in the case of Adroit can allow you to edit this tag.

Enable this troubleshooting facility, as follows:

  • To enable this for ONLY the topmost control or vector currently under the mouse pointer (for the current TEMPLATE SET), right-click and select Show Information.
  • To enable this for ALL the controls and vectors on the graphic form (for the current TEMPLATE SET), press CTRL+S or right-click and select Show All Information.

Any control or vector that has this troubleshooting facility enabled, indicates this by displaying the icon in the top right corner.

Example

Clicking on the icon, displays the Elements menu item, which displays the list of datasources whose data elements (values) have been connected to the properties of the selected control or vector.

Clicking the name of the required datasource displays the list of only its data elements that are connected to the properties of the selected control or vector.

This list of data elements graphically indicates the quality of these data elements, by displaying good data elements in green and the bad data elements in red.

Tip: For Adroit datasources, you can also use the bad-tag status indicators, if displayed, to further troubleshoot any bad tags connected to the controls or vectors of your graphic forms. For details on using these, see Bad tag status indicators.

Clicking one of the displayed data elements in this list display, the following datasource-specific options:

  1. Copy : to copy the specified, fully qualified data element name to the clipboard (containing the datasource name and full path to this data element), for reference purposes.
  1. Edit: for Adroit datasources ONLY, this option opens the Adroit Agent Configurator with this tag (agent) selected (if it can be found), so that it can be edited.

Note: Since this option ONLY applies to Adroit datasources and even then the editing of tags in the SmartUI Operator poses a security risk, so the display of this option is controlled via the AllowEditTags Boolean setting of the Operator Settings page of the profile dialog, which is False (hidden) by default.
