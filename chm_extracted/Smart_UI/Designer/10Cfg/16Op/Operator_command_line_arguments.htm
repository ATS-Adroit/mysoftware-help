Operator command line arguments

The SmartUI Operator provides the following command line argument options that can customise its display and the permitted user interaction within the SmartUI Operator:

Click for more usage details and examples:

Note1: Many of these settings can also be configured by the user profiles configured for users in the SmartUI Designer.

Note2: Any command line options that you specify will override the respective user profile Operator-customization settings. 

Note3: If you need to customise more than one Operator then you need to create separate shortcuts for each required Operator and customise each separately.

You can either specify a single command line parameter, such as: “VIP Operator.exe” -gf “TestProject.Folder1.GraphicForm”

Or you can combine the command line parameters that you require, such as:

“VIP Operator.exe” -p 1 -gf “TestProject.Folder1.GraphicForm” -t “False” –s 800,600

StartupBorderStyle

-bs

Integer value between 0 and 6, as follows:

0 = None;

1 = FixedSingle;

2 = Fixed3D;

3 = FixedDialog;

4 = Sizable;

5 = FixedToolWindow;

6 = SizableToolWindow

4 (Sizable)

StartupLocation

-l

x,y : Pixel location of the Operator window e.g. 100,100

Note: Do not specify any spaces.

Tip: Depending on the configuration of your monitors, it may be necessary to specify negative numbers to move the Operator to the required monitor.

0, 0

Startupsize

-s

x,y : Pixel size of the Operator window e.g. 800,600

Note: Do not specify any spaces.

800, 600

StartupWindowPosition

-p

Integer value between 0 and 4, as follows:

0 = Manual;

1 = CenterScreen;

2 = WindowsDefaultLocation;

3 = WindowsDefaultBounds;

4 = CenterParent

0 (Manual)

StartupWindowState

-ws

Integer value between 0 and 2, as follows:

0 = Normal;

1 = Minimised;

2 = Maximised

0 (Normal)
