Disconnecting all the logged on users

The Activity Monitor is able to manually disconnect the SmartUI Server from all of its logged on users, if required. For further details regarding the Activity Monitor and its functionality, see Working with the Activity Monitor.

This option should be used when all the available Client connection licenses need to be freed up for the SmartUI Server, but where it is not possible to visit each Client to disconnect them individually. For more information on licensing the SmartUI Server, see Licensing the Server.

WARNING! This forces all the currently logged on users to log on to this Server again. 

To disconnect all the logged on users (Clients) from the SmartUI Server:

Open the Activity Monitor
  1. Launch the Server as an application by clicking the Start menu, Programs, Adroit 10, and the SmartUI Server item.
    • Click the Launch Activity Monitor to open the Activity Monitor.
  1. Note:  The Activity Monitor is only displayed if the ActivityMonitorFormEnabled setting for this Server is enabled. For more information on this setting, see Advanced Server settings.

    The ActivityMonitorFormTitle setting specifies the title of this application.  
  1. Warning:  The Server window is not displayed if the SmartUI Server is running as a service.
  1. If the server is already running, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  • Tip:  When the SmartUI Server is running as an application, you may also press the ALT+TAB KEYS repeatedly until the task switcher displays the Server window, then select Launch Activity Monitor.
  1. If the server is already running as a service, then right-click the Service Manager icon in the Taskbar tray to open the Service Manager dialog, then select Launch Activity Monitor.
  2. The Activity Monitor opens and displays information on the Local Machine tab.

 

  1. Click the Disconnect All Users link from the Tasks panel.
  2. Click the Yes button of the confirmation dialog.
