Launching the SmartUI Server

Important:  The SmartUI Server must be licensed. If not, the Server will not run as an application or service.
For more information on licensing the SmartUI Server, see Licensing the Server.

After installing, the SmartUI Server can be run as either:

  1. An application, in which case the Activity Monitor provides additional Server-related functionality.
    • For details, see Working with the Activity Monitor.
    • To run the Server as an application:
      1. Click the Start menu, Programs, Adroit 10 then select the SmartUI Server option.
  1. A service within Windows, in which case the Service Manager can control (i.e. start/stop) this service.
    • For details, see Working with the SmartUI Service Manager.
    • To run the Server as a service:
      1. Use the SmartUI Service Manager to start or stop this service as follows:
      2. Click the Start menu, Programs, Adroit 10 then select the SmartUI Se rvice Manager item.

To manually start and stop or configure the VIP Server service:

  1. Click the Start menu then Control Panel > Administrative Tools then the Services option.
  2. Locate the VIP Server entry in the list.
  3. Right-click this entry and select Start or Stop.
  • Tip:  Select Properties… to select your preference in the Services environment for the Startup type or the Log on account that should be used for this service.
  • Tip:  It is recommended that you run the SmartUI Server as an application, during the initial designing phase and make use of the diagnostic features provided by the Activity Monitor.
  1. The SmartUI Server is installed into the SmartUI installation folder, which is typically: C:\Program Files\Adroit Technologies\Adroit\SmartUI
  2. Note:  The SmartUI Server, despite its method of launching, is able to log events for diagnostic purposes. For more information, see Diagnosing the Server.
  • Best Practice:   Once the configuration is complete run the SmartUI Server as a service, which ensures that it does not shutdown when you log off.
