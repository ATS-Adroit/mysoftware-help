Locating saved profiles

All the profiles created for this SmartUI Server and their configuration are saved separately so that these profiles can be easily replicated to other Servers, if necessary. For details, see Replicating profiles or for details on the other data saved by the Server, see Locating saved data.

Tip: The Adroit Config Editor provides a System Backup and Restore feature that can backup and restore your SmartUI and/or Adroit user-configuration. For details, see System Backup and Restore.

  1. This data is saved to the files named ‘Profile’. For details, see Saving data files.

Note: Backup files are only created, for these saved files, if one or more of the profiles have the Automatically update profile setting checked. For details, see Customizing connections and work environment.

Note: Each Configuration is completely separate or insular, containing its own files, application settings and/or registry keys. For details, see Working with Configurations.

  1. By default the profiles are stored in the Data subfolder of the Default configuration folder (typically C:\ProgramData\Adroit Technologies\Adroit\SmartUI\Configurations\Default\Data), although this location can be customised, if necessary. For details, see Server directory settings.

Note1:When selecting a customised location for this data, it is recommended to keep it within the installation folder, for instance, within a sub-folder so that it is easier to backup and keep track of this data.

Note2:If a custom folder is specified, ensure that this folder exists.

Note3:If these Profile files are removed then only the standard default profile will apply to all the allowed users and groups for this Server.
