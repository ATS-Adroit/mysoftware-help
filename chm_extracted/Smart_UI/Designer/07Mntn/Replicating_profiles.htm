Replicating profiles

If necessary, you can create one or more standard profiles for all of your SmartUI Servers by replicating them.

To replicate profiles

  1. Create and configure the required profiles on a single Server. For details, see Creating profiles and Configuring profiles.
  2. Ensure that these profiles are appropriately configured and that they are saved. For details, see Saving the Server.
  3. Copy the required Profile data files from this SmartUI Server to the required folders of the other Servers. For details on the required data files and their location, see Locating saved profiles.

This will immediately add these profiles to these SmartUI Servers.

Note: It will still be necessary to ensure that the correct users and/or groups are assigned to each of these profiles on each of the SmartUI Servers.
