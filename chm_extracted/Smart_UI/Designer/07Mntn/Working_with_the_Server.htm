Working with the SmartUI Server

The SmartUI Server is a "data portal" which exposes data from a number of disparate sources that are both external and internal to it.

Note: SmartUI Servers can be clustered to handle their combined workload evenly and to provide continued operation in the event that one or more fail.

This is the only component of the SmartUI that requires a licence before it can be launched. For more information on licensing the SmartUI Server, see Licensing the Server.

Note: It is possible use the SmartUI Server freely, with a Designer and an Operator connections for 2 hours, after which the Server must be restarted.  

The SmartUI Server can either be run as:

  • An application, in which case the Activity Monitor provides additional Server-related functionality. For details, see Working with the Activity Monitor.
  • A service within Windows, which ensures that it will not shutdown when you log off and where you can use the SmartUI Service Manager to manage (start/stop) this service. For details, see Working with the SmartUI Service Manager.

The SmartUI Server can either be automatically saved on shut down and/or can be manually saved. For details, see Saving the SmartUI Server.

Tip: The Adroit Config Editor provides a System Backup and Restore feature that can backup and restore your SmartUI and/or Adroit user-configuration. For details, see System Backup and Restore.

Troubleshooting

The Server also provides methods for logging Server-related events in varying degrees of detail, for both diagnostic and auditing purposes. For details, see Diagnosing the SmartUI Server.

The System datasource provides a view into the Server and exposes information and functions pertaining to the SmartUI Server itself and the SmartUI Clients (Operators and/or Designers) that are connected to it. See System Information.
