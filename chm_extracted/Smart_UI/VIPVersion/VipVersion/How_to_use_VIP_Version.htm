VIP Version

The VIP Version application is a diagnostic tool that obtains the versions of all the .DLL and .EXE files in a folder (including its sub-folders) and can export this version list to a .CSV file. This also displays the currently installed VIP version.

This is a troubleshooting tool, so that users can email the .CSV file of the file versions of their VIP installation to support, so that support can quickly tell if the installed files are the latest or which files may be causing the current problem.

How to use VIP Version:

  1. Launch the VIP Version application.

By default, this immediately obtains the versions of the files in this folder (and its sub-folders).

  1. If necessary, specify another folder whose file versions you want to obtain, as follows: either by using the Browse Folder toolbar button or the File menu, Browse Folder... option.  
  1. Wait until all the versions of ALL the applicable files in this folder are obtained. The progress bar at the bottom should indicate 100%, as follows:

Note: Although some file version numbers are separated by commas ',' these are converted to periods '.' when this list is exported.

If necessary, re-check the file version numbers of the selected folder and its sub-folders, as follows: either by using the Check File Versions toolbar button or the File menu, Check File Versions option or the bottom right hand corner button.  

  1. Export the current list of files and their versions to a .CSV file, as follows:either by using the Export to CSV toolbar button or the File menu, Export to CSV option.

A confirmation dialog indicates the location of this saved .CSV file  

By default this file is saved to the folder in which the VIP Version application is being run from.

  1. Please make a note of the location of this .CSV file.
  2. Email the saved .CSV file to the support department.
  3. Close the VIP Version application, as follows:either by using the top right hand corner button  or the File menu, Exit option or the bottom right hand corner button.
