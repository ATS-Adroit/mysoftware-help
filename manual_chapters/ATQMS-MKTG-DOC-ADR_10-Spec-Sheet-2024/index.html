3. Notes
Hard disk speed is of great importance when it comes to disk intensive operations like storing data. This applies to all forms whether logging to
write performance typically hinders overall performance of the system especially when it comes to historical data storage and retrieval
It is recommended that enterprise grade drives be used. Enterprise grade disk drives are characterised by greater reliability in that rated mean
time between failures (MTBF) tends to be several orders higher than standard desktop grade drives. Caution must be exercised when considering
drives with faster rotational speeds as well as solid state drives since reliability varies greatly depending on model and manufacturer
Network speed represents only part of network performance, and it is important to consider network latency (turnaround time) when
understanding overall performance. A "fast" network with high latencies will result in an overall poor performance when considering more
"chatty" transactional network traffic such as that between Adroit Client and Server Applications.
Similarly, network stability also comes into play. It is vital that the network supporting any SCADA system be stable.
The minimum CPU specification indicated are determined based on the median size and configuration for projects in general. However, it is
possible to configure and execute projects on less performant hardware, based on the experience and testing of the project execution. CPUs
including the Intel Atom C series and Intel Atom P Series could be utilized, especially for HMI projects. A minimum of two cores are required.
The On-Premise Secure Mobile Gateway requires the end-user or integrator to ensure that the necessary cyber security measures are in place
if cloud based access will be provided.
For the On-Cloud version, the Cyber Security measures are part of the Adroit Data Center services.
For further information please consult with your Sales Representative.
