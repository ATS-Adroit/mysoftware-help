SQL Server Reporting Services platform. The technology is distributed as a free add-on solution to Adroit
SCADA.
The suite consists of report packs and a Report Deployment Utility. Each report pack includes a set of
reports specifically designed to report relevant and accurate information on the Adroit system and
This document provides a basic introduction to Adroit Technologies and the Adroit Report Suite valueadd system, with a brief overview of the Adroit SCADA software package for the purpose of convenience
and reference.

Since 1992 Adroit Technologies, a company based in South Africa, have been developing SCADA/HMI
software solutions for the industrial automation and process control industries. With over 20,000

3.1. Database Platform
The Adroit Report Suite is built on the Microsoft SQL Server 2008 R2 database platform with SQL Server
Reporting Services (SSRS). Adroit is now shipped with SQL Server 2014 Express with Advanced Services
(SSRS) and with the Adroit Report Suite. The Adroit Report Suite is a free add-on, although some of the
report packs are based on data from licensed Adroit agents.
3.2. Report User Interface is Internet Explorer
The Report Suite front end is essentially a set of switchboard reports (built-in SSRS) used to navigate
between report sets and to select which reports to view. Each set of reports are based on a standard
Adroit logging mechanism such as the Alarm Management agent, the DB Log agent and also the Adroit
Agent Server auditing.
3.3. Report Packs
The report sets are developed and distributed as report packs, which require installation and deployment
to the SQL Reporting Server.
A report pack is a combination of Reporting Services Reports, Data Sources, Components and Resources
all in one manageable "pack" which is made available as installation files for easy installation.
When a new version of a report set is made available it will be distributed as a new report pack which
will include the updated reports as well as the scripts required to update existing databases if needed.
The Report Deployment Utility is shipped with the Adroit Report Suite and has been developed to assist
with report pack deployment and also with running of the latest updates' scripts should this be required.
3.5. Data Sources
Each set of reports has a SQL Data Source. This data source is the actual database that the reports will
extract data from to present to the end-user. It is possible to change the data source to another valid
database at any point (i.e. alarm management reports must be linked to an alarm management
database), including connecting to the demonstration dataset installed with the Report Suite. The data
sources can be managed through the Adroit Report Deployment Utility.

6. Getting Started
6.1. Install SQL Server 2008 R2 Reporting Services
Adroit is shipped with SQL Server 2008 R2 Express with Advanced Services (Reporting). Please refer to
the "SQL Server 2008 R2 Express Installation Guide" document before installing.
It is possible to use an existing SQL database (SQL 2005 and above) for the Report Suite database and
for the Adroit data. It is also possible to use an existing Reporting Services server, but it must be version
2008 R2.
6.2. Install the Adroit Report Deployment Utility
The Adroit Report Deployment Utility was created to help you create and deploy report packs. The report
packs consist of Reporting Services' reports, data sources and components. The Utility interacts with
SQL Server Reporting Services' web service.
6.3. Install Report Packs
Each report pack is a combination of Reporting Services reports, data sources, components and
resources all in a manageable set of XML files. Installing a report packs simply copies these files to the
correct location in Program Files. Once installed, these packs are available for the Report Deployment
Utility.
6.4. Deploy the Installed Report Packs
The Adroit Report Deployment Utility can now be used to deploy the installed report packs to the
Reporting Services server. During the deployment process the data source for each report pack must be
connected. The data source is the database where the appropriate Adroit data has been logged, i.e. the
Alarm Management reports must be connected to a valid Alarm Management database.
6.5. Run SQL Update Scripts
The latest SQL update scripts should be run against the Adroit database using the Adroit Report
Deployment Utility (see user's manual). This ensures that the database has all the required functionality
to support the Report Suite reports.
6.6. Create a Report Suite Desktop Shortcut
A desktop shortcut can be added through the Adroit Report Deployment Utility (see user's manual). The
Adroit Report Suite basically opens Internet Explorer to the correct SQL Report Server web page.
6.7. Open Report Suite
To start reporting, click on the Report Suite desktop shortcut. This shortcut will open the default web
browser to the Adroit Report Suite navigation switchboard.
NOTE: the Adroit Report Suite must be run in Internet Explorer 9 or later as the default browser.

9. Running Reports
9.1. View Report Button
Before a report will run, it must have at least one value for each of the report parameters. If a report
has valid default report parameters it will run immediately when the report is opened.
In order to run a report manually, the View Report button must be pressed. This button is available in
the report parameters window which can be opened by clicking on the Show/hide Parameters button
(shown below). If report parameters are changed the report can be re-run by clicking on the View
Report button.
9.2. Selecting Report Parameters
Report parameters constrain the data set retuned in the report. Often a parameter itself is constrained
by a previously selected parameter, but it is important to select parameters in the correct order.
Parameters should be selected from left to right and   to bottom to ensure that constrained parameters
are properly constrained.
9.2.1. Date Time Parameters
The date time parameters determine the reporting period for the report. When the parameters are
selected using the date picker the default time will be midnight (00:00 AM). It is possible to type in the
hour if a specific date time range is required.
