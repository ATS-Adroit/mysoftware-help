1. Summary
Adroit Air is an alarm notification platform that enables user to receive alarms and process data directly
on their smart device.
2. Introduction
This document deals specifically with the Adroit Air datasource functionality. Throughout this document
it is assumed that users have downloaded the mobile app and registered an account. Adroit Air requires
internet access. All configuration and notification delivery runs through HTTPS.
3. Installation
The installation should be run on the SmartUI Server. Make sure that the SmartUI Server and any clients
have been stopped. Run the installation. Follow the prompts and complete the process. This process
should be completed on all the PC's that have SmartUI Designer installations. After installation, the
SmartUI Server and clients can be started again.
4. Initial Setup
From the designer, add the Adroit Air datasource by right-clicking on the Datasources node in the
Enterprise Manager tree, and selecting "Add datasource". Select "Air" from the configuration wizard and
click finish. If you have already created an Adroit Air account for the administrator user, proceed to the
login section. If not, complete the registration process first.
4.1.
From the "Add Datasource" wizard, click the "Register" link. Fill in the required fields on the register
window. Make sure to use a valid email address. Finish the registration process. When the registration
completes, you can proceed to login.
4.2.
Login
Enter the login credentials of the administrator user. If you have forgotten the password for this user,
click the "Forgot password" link. This will send an email to the administrator's email address with
instructions to reset the password.
4.3.
Create Project
If the login succeeds, you will be able to create a project. An Adroit Air user can only be the administrator
to one project. If your administrator account already has a project associated, you will be able to
continue with the current one or remove the existing project and create a new one. Deleting a project
will erase all the configuration for that project.
Enter the name of your project and click "Add project". Once the project is created, you can finish the
wizard and complete the process.

5. Initial Configuration
At this point you should see the Air datasource in the Enterprise Manager tree. If you do not see it, try
refreshing the "Datasources" node in the tree. Right click on the Air datasource and select "Configure".
The first step is to add the required Adroit Air users to the project. Any app user that wishes to be
included in the project should have sent an ID to the specified email address. Typically, this would be
your Adroit Air administrator user. The administrator user is added automatically to the user list after
the project is created.
5.1.
Invite users
Enter the ID's of the users you wish to invite in the User ID text box and invite them one by one. When
you click invite, a unique One Time Pin (OTP) will be sent to that user's Air app. The user should report
this OTP back, at which point you can select the user in the Pending Users box, enter the OTP in the
OTP textbox and validate it. If validation succeeds, the user will be added to the project. If the user
does not receive the OTP, you can resend the invite to the appropriate user ID.
5.2.
Activate Users
By default users are added in the "Active" state. A user can be de-activated at any point. An inactive
user will not receive any notifications and will not consume a license; however, a user can be fully
configured while inactive.
5.3.
Licensing
If no Adroit Air licenses are found, you will be given 1 licence for demo purposes. Licensed users appear
at the   of the "Available users" list and are indicated with a white background. Only users that are
both licensed and active will receive any notifications. If limited licensed are available, de-activate lower
priority users to make licenses available for higher priority users.

6. Alarm Configuration
Alarms are assigned to available users from the "Alarms" tab. Each
user can be linked to a single alarm agent or alarm list agent on any
available Adroit datasource. Multiple users can be linked to the same
agent. Changing the minimum priority setting will prevent lower
priority alarms from being sent to the user. Changes will be applied
when the "Finish" button is clicked on the wizard.
The configured agents will be monitored for changes. Whenever a
new alarm becomes active or an existing alarm clears, an updated
list of alarms will be sent to the appropriate users. Updates will be
sent to users at a one minute interval. Filter options have been
added.
7. Text Messages
Text messages can be sent to test the system or to deliver some
specific information to a user. Text messages can be up to 1000
characters long. Basic text formatting like tabs and line feeds are
allowed. Filter options and selective deletion of messages have
been added.

8. Process Data
From the "Process data" tab, new process data messages can be
configured. Click on "Add process data message" to add a new message.
Browse the data element that will trigger this. Messages can be sent at
a maximum rate of once per minute. Click on the message to configure
the message content. A total of 24 configured messages allowed.
Up to 20 data element values can be included in the message content.
Browse in the required data elements and set the required formatting
(either manually or by using the format browser). Insert the data
elements at the required point in the message by pressing the "Insert
selected data element at the cursor" button.
Now select which users should receive this message. A process data
message can be sent to any number of available users.
Apply the changes and configure more messages if required.
When the trigger value for a specified messages changes to true, the
latest value of all the data elements in that message will be read and
inserted into the message (using the specified format) and the message
will be sent to all the configured users. If the trigger is toggled again
before a minute has passed, the trigger is cached. Once a minute has
passed the message will be raised again. Only one trigger will be cached
per message, meaning if the trigger toggles 5 times in a minute, the
message will only be sent once, with the latest data element values.
Filter options and selective deletion of messages have been added.
9. Links to Other Adroit Mobile Applications
If you have a Performance Anywhere (PA) server running, you can view the pages natively in the Adroit
Air application. To access PA from the app, you first need to specify the address of the PA server for
your project in the Adroit Air datasource. On the project settings page of the datasource configuration
window, enter the URL of the PA server. This URL should be reachable from the internet, or at least
from a network available to any app instances that need to use this feature. Once you save this setting,
it will be pushed to all of the Air clients available on the project.
When the app receives this setting, it will automatically load a new page in the project view and load
the login page of PA. At this point the user could login manually on this interface, but it is recommended
to store the credentials in the app in order to automatically login every time the page is loaded. To set
this up, go to the settings for the project in the app, and enter the relevant username and password
(note that this is not the Adroit Air credential, but rather the credentials required to log into the PA
server - typically domain credentials: [domain]\username).
Now when the user returns to the PA page in the app and taps the refresh button, the page will reload
and will login automatically. The page will be set to run automatically. While it is possible, users should
avoid attempting to make design changes to the page from the app as the real estate available makes
this an arduous task.
